Correctness is only as stable as the reference answer, checklist, judge prompt, and current accessibility of the supporting web/media evidence. A judge match does not prove the agent found the intended evidence path, and a mismatch may reflect answer phrasing or stale web pages.

The release uses protected/encrypted answer handling, and the repository warns against careless plaintext exposure. License and redistribution status for web-derived media/evidence should be audited item by item before using the dataset for training or public redistribution.
