MM-BrowseComp is a 2025 arXiv benchmark for multimodal browsing agents. It asks whether agents can answer hard questions whose evidence may be buried in web pages containing text, images, and videos, rather than only text-search pages.

The paper reports 224 challenging questions, while the official GitHub repository later announces an expanded 400-question release. The evaluation surface is a question, a reference answer, multimodal web evidence, and a checklist/judge-based scoring path; it belongs in the atlas as a live multimodal browsing evaluation, not as static training QA.
