论文在 GSM8K、MATH-500、MMLU-STEM、AIME'25 和 MINERVA-MATH 上评估准确率、平均响应长度与 Accuracy Efficiency Score。以 Qwen2.5-3B-Instruct 的 GSM8K 消融为例，作者复现的 DAPO 为 85.6 准确率、平均 290 token，三轮扩展的 BFS-PO 为 86.2、269；去掉最优优先选择后为 86.0、311；改用全局优势而非分支局部优势后为 85.7、271；去掉长度惩罚后为 86.1、275。这些比较支持一个较窄的结论：在论文设定下，所报告的搜索与分支优势设计会影响准确率—长度权衡。它们不能证明未公开 rollout 记录正确、多样、无污染或可复用。论文还称共享前缀的 KV-cache 复用使训练相对其 DAPO 设定平均加速 1.37 倍，但目前没有实现或日志可供独立审计。官方仓库现在只有占位 README 与示意图，并称未来将提供实现和实验资源；未核验到代码、模型、checkpoint、数据或 release。
