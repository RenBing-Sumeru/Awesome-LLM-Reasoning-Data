BFS-PO replaces independent group sampling with best-first refinement. For each question, the policy first samples a group of complete outputs. A parser/string-match verifier identifies correct final answers, and the shortest correct complete path becomes the current best path. The method chooses the highest-entropy token on that path that has not already been used for backtracking, conditions generation on the prefix through that token, and adds a new group of continuations to the tree; the reported experiments use three expansion iterations. Only complete paths are judged, so no PRM labels partial reasoning. Leaf rewards combine terminal correctness with DAPO's Soft Overlong Punishment, internal node values average child rewards, and each branch receives an advantage relative to the value of its backtracking node. These tree-local advantages, rather than the selected concise path as an SFT target, drive the policy update.
