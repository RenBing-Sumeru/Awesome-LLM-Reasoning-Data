The evaluation pipeline is: present the task input, run the model or agent in the specified substrate, collect the submitted artifact, execute or apply the scorer, and aggregate the result under the official leaderboard/reporting policy. The substrate is Aider coding harness over C++, Go, Java, JavaScript, Python, and Rust tasks.

The verifier/reward component is Problem tests and edit-format checks. Outputs are interpreted only through that contract; training or optimization use is not assumed. Reproducibility depends on pinning the task version, harness or judge version, model settings, release license, and hidden/public split policy.
