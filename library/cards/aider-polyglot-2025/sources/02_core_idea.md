One-sentence contribution: Aider Polyglot evaluates coding-edit ability across C++, Go, Java, JavaScript, Python, and Rust using selected Exercism problems and repository-level test feedback. The core mechanism is to turn a realistic task substrate into an observable input-output-scoring contract rather than only reporting model impressions.

Inputs come from Exercism coding exercises and Aider editing setup.; outputs are Patch or repository edit plus test outcome.; feedback is Problem tests and edit-format checks. It belongs under benchmark/evaluation surfaces because the central artifact is the measurement contract. Closest comparisons are other benchmark surfaces in the same domain, but this card should be read at the level of the released task object and scorer rather than as a broad model capability claim.
