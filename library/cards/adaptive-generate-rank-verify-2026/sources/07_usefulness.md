Use this paper when a system has a fast but noisy ranker and a slow high-confidence checker, especially for code execution, formal checking, or exact-answer evaluation. The practical checklist is to log candidate scores and verifier outcomes, estimate the score-success curve on held-out prompts, meter every verifier call, and compare against fixed budgets at equal terminal correctness. It provides a principled reason not to report pass rates without the cost of obtaining a verified answer.
