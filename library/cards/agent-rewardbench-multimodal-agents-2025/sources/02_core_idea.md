The main artifact is Agent-RewardBench, containing roughly 1,140 image-text agent examples across perception, planning, and safety. Each record organizes a task input, visual or environmental state, candidate response or trajectory, evaluation evidence, and a preference, score, success, or critique label, together with task provenance and capability categories. Quality control relies on constructing better–worse behavior pairs for real multimodal-agent tasks and verifying scenario-specific failures, making the release suitable for training, evaluation, or auditing rather than ordinary question answering.
