The paper introduces Agent-RRM, a multi-faceted reasoning reward model, and three integration strategies: Reagent-C uses textual critique for refinement, Reagent-R uses scalar reward guidance, and Reagent-U unifies both. Released training data contains agent trajectories with generated reasoning, critiques, and scores, including Reagent-RRM-RL-90K. The contribution is a structured feedback contract for agent trajectories rather than a single terminal label, enabling both language-level correction and reward-based reinforcement learning.
