The released trajectory–critique–score records can train agent critics, generative verifiers, or process reward models. Reagent-C is useful when a system can afford a second attempt, Reagent-R when training requires a compact scalar, and Reagent-U when both channels are available. Researchers can use the dataset to compare outcome, process, and textual feedback under one agent base. The method is less appropriate for tasks where critiques cannot be verified and mistakes could trigger irreversible real-world actions.
