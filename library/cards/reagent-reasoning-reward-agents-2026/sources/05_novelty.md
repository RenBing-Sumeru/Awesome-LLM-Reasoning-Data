Earlier agent reward models generally output one scalar or binary outcome, while self-refinement methods generate text critiques without integrating them into RL reward. Agent-RRM changes the feedback object to a three-part record: reasoning trace, focused critique, and overall score. Reagent-U then tests a unified consumption mechanism. The novelty is not generative judging or reinforcement learning separately, but the explicit multi-channel contract and systematic comparison of how each channel changes agent learning.
