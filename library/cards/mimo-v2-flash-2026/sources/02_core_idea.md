The report describes general SFT, specialized-teacher RL/SFT, and a final MOPD stage. MOPD combines a teacher reverse-KL signal with ORM advantages, while agent tasks also use programmatic code or tool checks, LLM judges, and multimodal web verification. The student supplies on-policy trajectories, so the data object includes both authored responses and interaction episodes.

For the disclosure ledger, the key contribution is a relatively explicit mixed-feedback and environment surface: the report names code, terminal, web, search, and synthetic function-calling settings, and it describes the roles of teacher-KL and ORM feedback. It is not a release of the tasks, trajectories, environment implementations, teacher routing, or reward details needed for an independently reusable recipe.
