Under a maximum of 50 actions and temperature 0.0, GPT-5 + UI-Ins-7B is the strongest paper-reported planner-executor system at 51.7% overall SR, with 54.0% on 116 GUI-only tasks, 62.2% on 45 user-interaction tasks, and 51.6% on 40 MCP tasks. Gemini-3-Pro + UI-Ins-7B reaches 46.3% overall and Claude-4.5-Sonnet + UI-Ins-7B reaches 43.8% (Paper Table 6).

The strongest reported end-to-end result is Doubao-1.5-UI-TARS at 20.9% overall, evaluated only on compatible categories; it has no MCP score. Qwen3-VL-235B-A22B reaches 9.5% overall, 4.4% user-interaction, and 5.4% MCP SR. Consequently, the 51.7-versus-20.9 comparison mixes model capability, planner-grounder decomposition, and action/tool support; it is not a controlled proof that modular agents are intrinsically superior (Paper §§4.3–4.4).

Behavior metrics add important boundaries. GPT-5 averages 27.8 steps, 1.11 user queries, UIQ 0.40, and 2.23 MCP calls. Gemini averages fewer steps (24.2) and more MCP calls (2.63), but only 0.36 queries and UIQ 0.19. Low step counts can reflect early failure: GUI-Owl-7B averages 20.6 steps at only 4.5% SR (Paper Table 7 and §4.5).

The authors manually inspect failures and report five recurring patterns: hallucinating missing facts instead of asking, MCP output overflowing context, forgetting already modified files, arithmetic/logic error, and missing temporal-spatial grounding (Paper §4.6). These are qualitative examples rather than prevalence estimates.

Current official artifacts materially improve auditability beyond the paper: task/evaluator code and model-specific trajectory bundles are public. In the inspected `seed-2.0-pro.json.gz`, 161 task entries contain task goal, step records, prediction/action, optional user/tool fields, token usage, terminal score/reason, and video-frame metadata; 101 score 1.0 and 60 score 0.0. This confirms retention of failures in that bundle, not complete publication of every paper-era run. All benchmark scores remain author-reported and were not independently reproduced for this Card.
