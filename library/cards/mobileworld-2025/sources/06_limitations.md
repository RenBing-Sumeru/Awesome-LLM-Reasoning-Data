- **Verifier scope and false results.** Deterministic does not mean complete. Text matching can reject equivalent wording or accept a matching string without validating retrieval; database/storage/callback checks inspect selected fields and can miss harmful side effects. The official changelog reports expired Mattermost sessions causing false negatives before an April 2026 fix, demonstrating environment-dependent verifier failure.
- **User simulation.** GPT-4.1 sees hidden task context and follows a restrictive response prompt. Scores therefore depend on its version, refusal boundary, phrasing, and availability. A real user may provide incomplete, contradictory, or privacy-sensitive information, so benchmark UIQ is not direct evidence of human-facing quality.
- **MCP replay and security.** External schemas, endpoints, credentials, search indices, repository content, and returned documents can change. Tool output may overflow context, and malicious or compromised content could prompt-inject the agent. The paper evaluates orchestration accuracy but does not present an adversarial MCP security suite or immutable response cache.
- **Split and contamination.** The paper exposes one 201-task evaluation set, no train/validation/test partition, and no near-duplicate or pretraining-contamination audit. Task fixtures contain internet-derived material, and MCP tasks query public live sources. Using these tasks or public trajectories for training would contaminate future MobileWorld evaluation unless a new held-out split is created.
- **Release drift.** There is no GitHub tag or Release tying code, Docker image, AVD/backend snapshots, task/evaluator files, MCP configurations, and trajectory logs to the ACL results. Public trajectory bundles and leaderboard updates are later additions. The Mattermost fix and floating “latest” image workflow make commit-only replay insufficient.
- **Trajectory completeness and encoding.** Model bundles cover different task subsets; a complete paper-era 201-task success/failure manifest for every reported model is not established. The inspected bundle retains 101 successes and 60 failures but contains visibly corrupted text in some records, so training reuse requires encoding repair and provenance checks.
- **Rights, privacy, and safety.** The root repository is Apache-2.0, but forked apps, Docker components, internet-derived fixtures, third-party assets, MCP outputs, and community-submitted traces may have separate terms. Fixtures include resume-, contact-, email-, calendar-, and message-like records; record-level origin, consent, redaction, and external API data-handling policies are not disclosed. Destructive tasks also need sandboxing despite snapshot reset.
