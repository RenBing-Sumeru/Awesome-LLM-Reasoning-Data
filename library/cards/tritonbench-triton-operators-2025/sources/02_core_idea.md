The main contribution is the first comprehensive open benchmark for Triton-operator generation. Its real-world channel preserves 184 open-source implementations and invocation patterns, while its interface-aligned channel turns PyTorch operations into Triton-generation tasks. The repository provides task data, evaluation scripts, LLM outputs, and performance-metric directories. Each candidate is first checked for compilation and output correctness and then compared with a reference implementation on specified GPUs. Thus, records are not merely prompt–code pairs but operators, inputs, reference functions, candidate implementations, correctness states, and performance measurements for evaluation, SFT, feedback optimization, and cross-hardware analysis.
