KernelBench evaluates general GPU-kernel generation from PyTorch workloads, while earlier Triton data largely consist of tutorials or code from individual projects. TritonBench combines Triton language requirements, real open-source operators, and interface-aligned tasks in one evaluation, recording both correctness and efficiency on industrial GPUs. It is not the first work to measure kernel latency, but it establishes the first dual-channel, batch-runnable public protocol for Triton operators. Unlike code benchmarks that report only `pass@k`, it treats performance regression as a distinct failure mode.
