Triton offers Python-like GPU programming, but correct block partitioning, memory layouts, and parallel optimization still require substantial expertise. Strong performance on ordinary Python does not show that a code model can generate compilable, numerically correct, and efficient Triton operators. Existing kernel benchmarks also tend to focus on CUDA or a few handcrafted tasks, without systematic evaluation against industrial GPUs and PyTorch-style interfaces.

TritonBench builds two evaluation channels: 184 real Triton operators collected from GitHub and a collection of generation tasks aligned with PyTorch interfaces. The framework runs functional tests and efficiency measurements on widely deployed GPUs, subjecting model outputs to compilation, numerical-equivalence, and performance checks.
