对 `environment_agent_trajectory_data` 赛道而言，Odysseys 适合作为运行时生成轨迹的评测规范。它把长程提示和起始 URL 连接到 OSWorld 环境配置、时序截图/动作、逐 rubric 判断、部分得分、完全成功、步数和效率，因此适合评估冻结的 computer-use 智能体并研究失败定位。

它不应被列为 SFT、偏好、奖励模型或 RL 训练数据：发布制品没有论文实验回合语料，论文也只把 rubric 得分用于评测。用这些得分做 RL 仅是未来工作。不过，研究者可以基于公开任务和评分器自行采集有版本记录的新轨迹语料，前提是自行提供环境、智能体、安全控制和运行保留策略。

用于比较前，应固定任务 JSON 和仓库提交，保留所有完整与不完整运行，把崩溃/超时记为显式结果，缓存 judge 输入输出，并记录 VM、浏览器和网络状态。纵向评测应维护可行性检查和版本化替换，而不是在网站漂移时静默修改任务。
