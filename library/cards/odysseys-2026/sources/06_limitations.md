Release boundaries are substantial. Raw participant histories, the 696 retained journey labels, item-level source mappings, rejection decisions, cluster assignments, complete successful and failed model trajectories, screenshots, result files, Gemini responses, and human labels are absent. Project-page recordings are selected examples, not a complete run manifest.

Lineage counts conflict internally: the main construction description retains 696 of 2,380 journeys, while Appendix A.5 refers to 2,380 “refined journeys” as hard-task-generation inputs. The exact denominator and seed pool for the 80 generated hard tasks are unresolved. The README also says tasks always start at Google, but release inspection finds 130 Google starts and 70 other starting URLs.

Scoring has three risks. Gemini 3.1 Flash Lite Preview is a mutable preview judge without pinned API snapshot, temperature, seed, retry log, or cached outputs. Chronological screenshots and actions may omit hidden DOM state, saved-file correctness, off-screen evidence, and long-range side effects. Finally, public tasks omit generation-time rubric weights, making released scoring unweighted and preventing reproduction of any weighted internal QA state.

Replay is nondeterministic because live sites change and configs use no proxy or fixed IP. No site snapshots, exact OSWorld revision, VM/browser image, credentials, locale, reset manifest, or environment cache is released. Default omission of incomplete runs can inflate aggregates if crashes and timeouts are not explicitly failures.

Privacy protection includes reported consent, PII rewriting/removal, and withholding browser histories, but consent text, compensation, IRB status, retention/deletion, withdrawal, and privacy-audit details are unknown. Although tasks are intended to be read-only or low impact, agents have broad browser/VM capabilities; allowlists, credential isolation, download/malware controls, robots/ToS enforcement, and incident containment are undocumented. MIT covers repository code/data, not third-party site content or unreleased histories.
