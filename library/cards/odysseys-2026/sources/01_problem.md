Existing web-agent benchmarks often emphasize short, single-site tasks and one terminal success signal. Odysseys targets multi-site work that may require research, comparison, synthesis, and creation of a persistent deliverable across dozens of browser/VM interactions. A single holistic pass/fail label cannot expose which requirements were met, which phase failed, or whether an agent made useful partial progress.

The released evaluation object is 200 task records with 1,225 rubric checkpoints. Each task has a SHA-1 ID, conversational instruction, starting URL, reference step count, difficulty, SimilarWeb categories, and 3–12 rubrics; each rubric has a requirement and a verification description. The mixture is 45 easy, 46 medium, and 109 hard tasks, with a mean of 6.1 rubrics.

This is not a released trajectory corpus. The repository contains the 200 task/rubric rows, 200 generated OSWorld task configs, a converter, and scoring code. The 2,380 labeled participant journeys, the 696 retained journey labels, full model action histories, chronological screenshots, results, and human-agreement labels are not public. The appropriate `training_use` is therefore evaluation only.
