For `environment_agent_trajectory_data`, Odysseys is useful as an evaluation specification for trajectories generated at run time. It connects a long-horizon prompt and starting URL to OSWorld environment configuration, ordered screenshots/actions, per-rubric judgments, partial score, perfect success, step count, and efficiency. This makes it suitable for evaluating frozen computer-use agents and studying failure localization.

It should not be listed as SFT, preference, reward-model, or RL training data: the released artifact has no paper-run episode corpus, and the paper describes rubric scores for evaluation. Using those scores for RL is future work. Researchers can nevertheless use the public tasks and scorer to collect a new, versioned trajectory corpus if they supply their own environment, agents, safety controls, and run retention policy.

Before comparative use, pin the task JSON and repository commit, preserve every complete and incomplete run, count crashes/timeouts as an explicit outcome, cache judge inputs/outputs, and record VM/browser/network state. For longitudinal evaluation, maintain feasibility checks and versioned replacements rather than silently editing tasks when websites drift.
