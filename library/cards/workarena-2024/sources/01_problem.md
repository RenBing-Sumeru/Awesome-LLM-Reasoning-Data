WorkArena: How Capable Are Web Agents at Solving Common Knowledge Work Tasks? asks how to close this gap: Enterprise knowledge work requires stateful interaction with business software, but general web benchmarks mostly cover consumer sites or static tasks. The primary source is https://arxiv.org/abs/2403.07718; public status is ICML 2024 / PMLR 235 / arXiv (2024).

Decision boundary: It is collected as an enterprise browser-agent environment and benchmark, not as an unrestricted workplace automation claim. The evaluation surface is a ServiceNow workplace goal, seeded instance state, role or credential context, browser observations, actions, business-object changes, and terminal validator output. This makes the paper useful for the atlas because the data object and feedback rule can be audited together.
