WorkArena: How Capable Are Web Agents at Solving Common Knowledge Work Tasks? 回答的问题是：企业知识工作需要在业务软件中进行有状态交互，而通用网页基准多覆盖消费者网站或静态任务。主来源是 https://arxiv.org/abs/2403.07718；公开状态为 ICML 2024 / PMLR 235 / arXiv（2024）。

决策边界：它应作为企业浏览器智能体环境和基准收录，不是无限制 workplace automation 证明。评测面是：一个任务包含 ServiceNow 工作目标、种子实例状态、角色或凭证上下文、浏览器观察、动作、业务对象变化和终止验证输出。它对 atlas 的价值在于任务对象和反馈规则可以一起审计。
