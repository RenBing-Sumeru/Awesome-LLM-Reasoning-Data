The official model card reports INTELLECT-3 scores of 98.1 on MATH-500, 90.8 on AIME24, 88.0 on AIME25, 69.3 on LiveCodeBench, 74.4 on GPQA, 14.6 on HLE, and 81.9 on MMLU-Pro. These results support improvement over the GLM-4.5-Air base in the evaluated settings.

The official release also provides the model weights, `prime-rl`, `verifiers`, and environment access. This supports claims about artifact availability, but it does not prove that an independent user can exactly reconstruct the original training mixture or reproduce the full run without the missing frozen manifests and settings.
