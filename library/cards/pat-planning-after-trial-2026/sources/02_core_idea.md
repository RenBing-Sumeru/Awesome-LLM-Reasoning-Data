The core policy is Planning-after-Trial. A generator samples several direct implementations and a sandbox executes them on tests. A fully passing candidate terminates the run immediately. Consistent failure is treated as evidence that the specification exceeds the generator’s direct capability, which is when a planner produces a top-level implementation and subproblem specifications.

Each planned subproblem is solved recursively with the same trial-first rule, and verified helper functions are composed into the final program. This lets PaT pair a cheap generator with a more capable planner: the larger model is not paid for on easy tasks, but is reserved for structural intervention after a concrete verification failure rather than an uncertain learned difficulty prediction.
