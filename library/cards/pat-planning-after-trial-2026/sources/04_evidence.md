On the foundational benchmark average, PaT raises Qwen3-4B from 76.05% for standard inference to 83.13%, at normalized cost 4.85; FunCoder reaches 81.18% at cost 8.31. The paper attributes the difference to avoiding unconditional planning: standard Qwen3-4B directly solves about 76% of these problems, so PaT calls the planner only for the remaining failures.

The heterogeneous configuration is the clearest cost result: it reports performance comparable to a large homogeneous model while reducing inference cost by about 69%. The evidence is strong for code tasks with usable execution tests, but it does not prove that a failed public test set identifies all hard tasks or that passing generated tests predicts hidden-test correctness. The cost calculation also depends on stated market token prices.
