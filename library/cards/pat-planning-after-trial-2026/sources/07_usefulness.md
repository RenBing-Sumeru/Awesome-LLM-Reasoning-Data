Use PaT when a code agent has reliable sandbox feedback and a clear price gap between a fast generator and a strong planner. Log direct candidates, every test result, planning triggers, subproblem depth, planner calls, and hidden-test outcomes. The important deployment comparison is not only Pass@1: measure how often direct trials succeed, how much planner work each failure triggers, and whether equal-cost Best-of-N or static planning would be preferable for the real task mix.
