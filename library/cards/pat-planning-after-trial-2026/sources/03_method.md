Given specification x, the generator first produces a Best-of-N set of direct programs. The system executes every candidate in a sandboxed Python runtime against a test set. If one passes all tests, it returns it. If none pass, the planner decomposes x into subproblems; those are recursively solved, tested, and composed with the planner's top-level implementation.

The evaluation uses HumanEval, MBPP, their EvalPlus variants, and difficulty-stratified xCodeEval, across Qwen3 sizes plus Llama and DeepSeek-Coder models. Results measure Pass@1 and token-price-based inference cost. The heterogeneous setting deliberately uses an efficient small generator and stronger planner, while the homogeneous setting tests whether the policy itself improves the frontier without changing model family.
