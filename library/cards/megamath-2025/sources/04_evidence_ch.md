该论文报告了数学 HTML 提取、MinHash-LSH 设置、fastText 种子构建、代码过滤标准、混合比例、问答提示和代码合成格式的控制预训练消融。 TinyLlama-1B 充当许多管理消融的代理模型； Llama-3.2-1B 和 Llama-3.2-3B 支持更大规模的持续训练演示。评估涵盖十个数学基准，并带有 CoT 和程序辅助提示。

官方 LLM360 GitHub 存储库提供 Web 和代码管道材料以及下载说明，而 Hugging Face 托管语料库。 HF 卡报告 Parquet、英语、单个当前列车分割、大约 217M行、大约 1.12 TB。这些工件支持重用和检查，但基准改进是有关经过测试的训练设置下下游实用程序的证据，而不是证明每条记录都是正确的、经过许可的或未受污染的。
