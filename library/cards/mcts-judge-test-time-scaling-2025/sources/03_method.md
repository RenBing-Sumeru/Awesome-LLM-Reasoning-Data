Inputs are a programming problem p and candidate code c, optionally with examples or reference code depending on the evaluation condition. The reported benchmarks are HumanEval-X (164 tasks in five languages), 100 randomly selected competition-level APPS tasks, and BigCodeBench (1,140 Python tasks); five base models include Qwen2.5-Coder-14B, DeepSeek-Coder-V2-16B-Instruct, Codestral-22B, Llama-3.1-8B-Instruct, and GPT-4o-mini.

The main configuration uses tree depth 9, eight MCTS rollouts, UCT exploration constant 3, LLM/UCT selection weights 0.1/0.9, terminal reward 1.1, temperature 0.4, top-p 0.95, top-k 40, and maximum output 2,048 tokens. GPT-4o generates tests; each is validated five times. At a leaf, three stored tests are sampled and each simulated seven times. A majority determines each output, all selected cases must pass for h(x)=correct, and agreement between h(x) and the trajectory judgment supplies the terminal reward. Cumulative rewards guide weighted final-trajectory selection. BigCodeBench items without meaningful input-output pairs substitute simulated discussion signals.

The data needed for replay includes prompts, action inventory, tree topology, visit counts, Q values, UCT and self-assessment weights, every node analysis, test generation/validation attempts, sampled cases, seven execution simulations per case, aggregate decisions, reward propagation, and final sampling. None of these run-level records or a pinned implementation was confirmed as released; all experiments are reported on a single 80GB H100.
