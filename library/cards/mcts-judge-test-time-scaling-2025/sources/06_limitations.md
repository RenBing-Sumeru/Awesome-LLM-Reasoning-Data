The verifier is fully LLM driven: GPT-4o generates and validates expected outputs, and the search model simulates execution rather than running code. Shared model biases, arithmetic mistakes, unsupported language behavior, malformed tests, and false expected outputs can become self-confirming rewards. Requiring all sampled tests to pass is asymmetric but does not remove false positives when the tests miss a bug. For some BigCodeBench tasks the method falls back to simulated discussions, weakening the already non-executable predicate.

The APPS experiment uses a random 100-task competition subset, but the immutable item list and seeds were not confirmed. Search cost depends on prompts, proprietary GPT-4o behavior, and eight-rollout stochasticity. The paper acknowledges reliance on GPT-4o and promises code, the test-case data flywheel, and documentation upon acceptance; no official release was confirmed. Raw trees, failed cases, reward records, reference-use flags, exact model endpoints, licenses for generated artifacts, and contamination controls remain unknown. LLM-panel trajectory ratings add another judge layer rather than human ground truth.
