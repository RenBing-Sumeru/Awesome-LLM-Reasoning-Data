SETS has three prompted operations: Sampling, Self-Verify, and Self-Correct. It first draws m independent solutions. Each branch is self-verified; if the verification is parsed as correct, that branch stops, otherwise the model receives the query plus all solution–feedback pairs from the branch and proposes a revision. The loop continues for at most n correction rounds, after which the last revision is retained even if still self-verified as incorrect.

The paper's judgment function is rule-based over verification text: if the response contains the designated statement that the solution is incorrect, the branch continues; otherwise it is treated as correct. After all branches finish, exact matching groups their structured final answers, the most frequent answer wins, and ties are broken randomly. SETS combines repeated sampling with SELF-REFINE-like revision without an external reward model. The novelty is the two-dimensional allocation over branch count and correction depth, not the invention of sampling, self-verification, self-correction, or majority voting individually.
