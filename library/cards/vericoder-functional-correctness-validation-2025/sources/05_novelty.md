Prior RTL augmentation mainly rewrites specifications or generates code and filters by compilation. VeriCoder’s novelty is not simulation itself, but a closed loop connecting test generation, simulator execution, and RTL repair, with tests also revisable when they misread the specification. This changes the acceptance rule: only code that survives functional feedback and passes the final testbench becomes training data, rather than treating all compilable code as positive. The model architecture and standard SFT objective are not the main innovation.
