The main contribution is a feedback-driven pipeline for functionally validated RTL augmentation. Starting from existing natural-language–RTL pairs, GPT-4o-mini generates testbenches that are executed in an HDL simulator. On failure, the RTL is iteratively repaired from logs, and tests are revised when they conflict with the specification. The released expanded_origen_126k contains about 126K natural-language, Verilog, and passing-test records. It upgrades the reward contract from “compiles” to “behaves correctly on specified simulations,” supporting RTL SFT, rejection sampling, and execution rewards.
