The key evidence is a controlled fine-tuning comparison between functionally unvalidated data and VeriCoder’s validated data using the same base-model setting. Functional correctness is measured by simulation pass rates on VerilogEval and RTLLM. VeriCoder reports relative gains of up to 71.7% and 27.4% over prior best results, while ablations show that compile-only filtering is substantially weaker than test-feedback data. This supports the value of functional validation, but teacher-generated tests do not prove full specification correctness.
