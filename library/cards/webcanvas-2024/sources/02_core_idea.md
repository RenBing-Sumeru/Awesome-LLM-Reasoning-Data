One-sentence contribution: WebCanvas evaluates web agents on online environments through Mind2Web-Live and key-node intermediate-state checks. The main contribution is an online evaluation framework with a key-node metric, Mind2Web-Live, and annotation/testing tools for maintaining current tasks.

The data object contains task instruction, online page state, action trajectory, key-node target, evaluation function, task success, completion score. Success is decided by all required key nodes or task-level criteria are satisfied under the current online evaluation setup. Closest comparisons are static web benchmarks, tool-use datasets, or code benchmarks in the same domain, but the direction label here is the concrete evaluation surface and its verifier rather than a general capability claim.
