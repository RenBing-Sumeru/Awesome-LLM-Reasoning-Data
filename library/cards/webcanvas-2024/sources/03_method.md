Inputs are refined Mind2Web-style live web tasks with annotation tools and testing pipelines. Outputs are task instruction, live page observation, action trajectory, key-node state, evaluator output, task success, and completion metrics. The substrate is online web environments whose interfaces and content can change over time.

Pipeline: 1. construct or load the task instance; 2. run the model or system under the official harness; 3. collect actions, observations, answers, or predicted structures; 4. apply key-node checks over intermediate states plus task success and efficiency metrics; 5. aggregate scores only under a pinned version of the benchmark. Reproducibility requires pinning paper=https://arxiv.org/abs/2406.12373, project=https://www.imean.ai/web-canvas, code=https://github.com/iMeanAI/WebCanvas, data=https://huggingface.co/datasets/iMeanAI/Mind2Web-Live, plus the exact split, runtime, scorer, prompt/scaffold, and release revision.
