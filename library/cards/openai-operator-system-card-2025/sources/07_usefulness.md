Use this Card as a conservative reference when comparing frontier agent reports. It supports a narrow but important claim: OpenAI publicly reports specialized computer-use supervision, broad source classes, and reinforcement learning for CUA. It does not support building a compatible dataset, reproducing an RL objective, treating benchmark or red-team records as reward data, or asserting that the system uses RL with verifiable rewards.

For post-training research, the Card separates three ledger columns that are often collapsed: disclosed training ingredients, disclosed evaluation and safety evidence, and unreported implementation details. It can guide audit requests for source manifests, demonstration schemas, reward contracts, environment pins, decontamination controls, and replay documentation. Until those artifacts are available, the Operator report should be used as a bounded disclosure record rather than a reusable agent-training recipe.
