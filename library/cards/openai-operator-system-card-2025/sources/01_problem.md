Operator is a January 2025 research preview of OpenAI's Computer-Using Agent (CUA): a GPT-4o-based model that operates graphical interfaces by observing screens and using cursor and keyboard actions. The official report explains that the capability was developed with specialized supervised computer-use data and reinforcement learning, but it does not expose a reusable post-training dataset or recipe.

For a frontier-report ledger, the key problem is therefore evidentiary rather than performance-related: which parts of the data and feedback pipeline are actually disclosed? This Card separates the report's explicit claims from unreported task records, rewards, environments, and lineage. It does not treat the reported safety evaluations or red-teaming as training data.
