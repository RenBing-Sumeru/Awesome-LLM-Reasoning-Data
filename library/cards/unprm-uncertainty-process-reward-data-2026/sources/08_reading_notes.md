1. **Positioning:** UnPRM uses uncertainty to reduce wasted search in automatic process labeling.
2. **Method handle:** It generates solutions, selects uncertain prefixes, verifies continuations, and trains a PRM.
3. **Data handle:** About 40K JSON records contain problems, answers, steps, and Boolean labels.
4. **Evidence anchor:** It improves labeling efficiency and aggregation on ProcessBench, MATH, and GSMPlus.
5. **Reuse decision:** It fits verifiable mathematics; fix the model, sampling budget, and answer rules first. Before deployment, uncertainty calibration and answer normalization should also be checked for stability.
