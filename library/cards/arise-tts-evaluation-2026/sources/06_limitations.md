ARISE relies on binary task outcomes and generated-token counts, which may not represent partial credit, execution latency, tool costs, user value, or safety risk. Its asymmetric penalties are a normative choice: another deployment may value avoiding a regression differently from recovering an error. Adaptive sampling improves reliability but still consumes evaluation budget and introduces threshold choices. The metric should therefore accompany, rather than replace, task-specific analysis and a transparent report of the decoding, budget, and correctness protocol that generated the underlying transitions.
