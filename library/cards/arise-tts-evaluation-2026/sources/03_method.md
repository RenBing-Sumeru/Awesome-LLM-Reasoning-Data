For each sample and scaling iteration, the method records binary correctness and token consumption. It computes a contribution from each adjacent pair of iterations rather than from all possible pairs. Improvements are weighted by the ratio of earlier to later tokens, while degradations receive the inverse, negative weight; this makes the penalty for using more computation to lose correctness stronger than the reward for a similarly sized improvement. The final score averages these sample-level contributions.

ARISE then uses an initial probing phase to estimate coefficients of variation for accuracy and token use. Its dynamic sampling mechanism allocates more evaluation runs when those statistics indicate unstable measurements. The paper applies this protocol to contemporary reasoning models across mathematical reasoning, code generation, and agentic tasks. The relevant record is a sequence of per-sample outcomes and costs at explicit compute levels, which is precisely what a scaling comparison must preserve for later audit.
