Use ARISE when publishing or auditing a quality-cost scaling curve. Store per-sample correctness, total generated tokens, compute level, decoding seed, and trial count instead of only reporting aggregate accuracy. Then calculate which samples improved, which regressed, and how much extra computation each transition consumed. The adaptive protocol is useful when some prompts are highly variable and others are stable, because it avoids spending identical evaluation effort everywhere. It is particularly valuable for detecting a system that looks better on average while becoming less dependable on already solved cases.
