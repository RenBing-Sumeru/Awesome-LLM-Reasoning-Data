For the Frontier Reports and Data Disclosure Ledger track, this card is a concrete example of why “open” must be decomposed. An auditor can separately mark model weights, dataset rows, media availability, source terms, construction tools, training recipes, run configurations, verifier rules, and evaluation harnesses. Nemotron Nano V2 VL is strong on weights, a substantial public dataset, named stage totals, and OCR tooling; it is weaker on complete run manifests, record-level lineage, filtering decisions, and decontamination.

Data builders can reuse the released conversation schema, subdataset processing tags, Megatron Energon preparation, and NVPDFTex outputs. Researchers can study curriculum interference and recovery by treating stage order as an experimental variable. Document and video teams can inspect tiling, frame sampling, long-context packing, CommonCrawl PDF QA, and compiler-derived OCR as distinct construction paths rather than one homogeneous corpus.

A responsible downstream ledger should add immutable source revisions, per-record upstream identifiers, media terms, annotation generator and revision, transformation history, acceptance decisions, duplicate groups, benchmark-overlap decisions, stage membership, sampling weight, and file checksum. Without those fields, the public artifacts support adaptation and partial analysis but not exact replay of NVIDIA's training mixture.
