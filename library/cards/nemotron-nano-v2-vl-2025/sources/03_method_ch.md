论文披露的五个阶段如下：

- 阶段 0：约 220 万个多模态样本、最多 360 亿 token，数据取自阶段 1；冻结语言模型和视觉编码器，只训练连接器。
- 阶段 1：在 16,384 token 上下文下训练约 3,250 万样本、1,125 亿 token。其中约 650 万文本推理样本占 400 亿 token，2,600 万多模态样本约占 720 亿 token。具名领域包括数学、科学、代码、多语言理解、对话、工具使用、安全、描述生成、VQA、OCR、文档、定位和函数调用。
- 阶段 2：在 49,152 token 上下文下训练约 1,100 万样本、550 亿 token。它复用阶段 1 的 25%，并加入约 140 万视频与多图样本、170 亿 token。非问答来源通过模板或模型生成的问答转成 QA；CommonCrawl PDF 经 NeMo Retriever Parse 解析后构造多页问答。
- 阶段 3：在 49,152 token 上下文下使用 100 万代码推理样本、150 亿 token，目的是修复此前下降的编程表现。
- 阶段 4：使用约 7.4 万个长上下文样本、120 亿 token，平均长度 16 万 token，训练最大长度为 311,296。

推理轨迹由人工编写，或由 Qwen2.5-VL-32B-Instruct、GLM-4.1V、GLM-4.5V 生成。Qwen2.5 与 Qwen3 家族从 OCR 文本或描述中生成问答；阶段 2 的部分数据由 Qwen2.5-VL-72B-Instruct 重新标注。精确提示、模型修订、候选数量、过滤规则与接收率均为 unknown。

训练使用 Megatron、Transformer Engine 和 Megatron Energon；采用 FP8，并让部分层保留 BF16；优化器为 AdamW，配合线性预热与余弦退火，还使用在线均衡感知序列打包和 loss square-averaging。视频按每秒两帧采样，最多 128 帧；超过 64 秒时均匀抽取 128 帧。每次训练所对应的精确代码与配置修订没有固定下来。

公开数据把每条记录表示为 id 和多模态 messages。内容可引用文本、图像、视频或音频，并附带可选的来源及媒体元数据。部分子集在 tar 分片中包含媒体，另一些只给标注和获取上游媒体的说明。NVPDFTex 是另一条构造路径：它把 LaTeX 编译为页面 PNG 和含边界框、类别标签、文本的布局 JSON，用于生成 OCR 真值。
