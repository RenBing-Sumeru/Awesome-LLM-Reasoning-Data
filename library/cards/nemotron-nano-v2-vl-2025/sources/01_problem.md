NVIDIA Nemotron Nano V2 VL addresses two linked problems. The modeling problem is to add image, document, video, and long-context abilities to a reasoning language backbone without permanently losing its text and code capabilities. The disclosure problem is to determine what the report actually makes reproducible: the consumed training mixture, released data, model weights, construction tooling, or only evaluation results.

The report documents a five-stage supervised fine-tuning schedule. Broad multimodal training initially damages text coding and long-context behavior; later code-only and long-context stages are introduced as capability-recovery steps. This makes dataset ordering and reuse part of the claimed method, not incidental implementation detail.

For audit, four ledgers must remain separate. The paper gives approximate per-stage sample and token consumption, including reuse. The model card describes a 39,486,703-sample, 270-dataset, 27.7 TB training inventory. Nemotron VLM Dataset V2 is an actual public artifact with 8,147,599 samples across 51 subdatasets. Benchmark tables evaluate model behavior. None of those four surfaces alone proves a complete, record-level data recipe.
