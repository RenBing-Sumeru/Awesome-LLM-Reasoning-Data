The core idea is that token efficiency and throughput jointly determine quality under a time limit. In memory-bound autoregressive inference, modestly increasing the number of concurrent branches can raise hardware utilization with little immediate latency penalty. Conversely, speculative decoding can improve sequence-wise throughput so that longer reasoning becomes feasible within the same time budget.

The paper frames branch-wise parallelism and sequence-wise parallelism as competing uses of concurrency. Neither should be maximized blindly: more branches eventually have diminishing returns, and longer speculative drafts can push the system into a compute-bound regime. A latency-optimal scaling policy allocates both resources according to the model, task, and serving hardware rather than following a fixed token budget.
