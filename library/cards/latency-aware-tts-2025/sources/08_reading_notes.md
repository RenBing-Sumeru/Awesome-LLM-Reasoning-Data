Read the accuracy–latency curves alongside the accuracy–token curves. Inspect the hardware, batch size, decoding engine, speculative model, branch aggregation, and latency definition, because any of them can reverse a comparison. A reproduction should fix the task and wall-clock budget, sweep branch count and draft length, and report utilization plus tail latency. The most useful ablation removes one concurrency mechanism at a time; it reveals whether a claimed gain comes from more search diversity, faster sequential generation, or a hardware artifact.
