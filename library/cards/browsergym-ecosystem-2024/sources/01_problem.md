BrowserGym is an arXiv 2024 paper, revised in 2025 and accepted in TMLR, about infrastructure for web-agent research. The problem is benchmark fragmentation: WebArena-like sites, MiniWoB-style tasks, WorkArena enterprise workflows, WebLINX traces, and other web benchmarks expose different observation spaces, actions, evaluators, logging, and experiment-management conventions.

The evaluation surface is a gym-like browser task instance with an instruction, browser state/observation, allowed actions, an agent trajectory, and a benchmark-specific terminal score or predicate. The decision boundary is environment and evaluation infrastructure for web agents; it is not a new single benchmark, a model-training recipe, or a universal judge. Its atlas value is the adapter contract that makes cross-benchmark trajectories and scores auditable only when the benchmark version and evaluator are pinned.
