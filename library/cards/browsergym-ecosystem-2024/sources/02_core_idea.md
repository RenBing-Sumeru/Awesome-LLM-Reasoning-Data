The contribution is a reusable ecosystem that wraps heterogeneous web-agent benchmarks behind a shared BrowserGym environment and pairs it with AgentLab for agent construction, experiment execution, and analysis. The core mechanism is not a single scoring rule; it is a normalized API for browser observations, actions, task setup, termination, logging, and result aggregation.

The data object is an environment rollout: task instruction, browser observation, action command, page state, terminal event, score, and logs. The feedback contract is delegated to each adapter's original evaluator or environment predicate. Closest comparisons are standalone WebArena/VisualWebArena/WorkArena/MiniWoB/WebLINX harnesses and general RL gym interfaces. The direction label is benchmark-infrastructure for browser agents.
