The prior baseline is each web-agent benchmark shipping its own harness and logging conventions. BrowserGym changes the reuse surface: benchmarks become adapters under a common environment API, and AgentLab gives a common experiment-management layer for agents and analyses.

The direction signal is infrastructure-level standardization for web-agent evaluation. The quality signal is the official ServiceNow repository, OpenReview/TMLR status, package structure, leaderboard space, and multi-benchmark experiment. What is not new: browser automation, gym APIs, and benchmark-specific success functions. Before reuse, inspect each adapter's license, hidden/public split, live-site dependencies, evaluator fidelity to the original paper, and whether normalization masks benchmark-specific constraints.
