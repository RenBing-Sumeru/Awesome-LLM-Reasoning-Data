The paper's main evidence is an implemented ecosystem and a large multi-benchmark experiment: six state-of-the-art LLMs are compared across six popular web-agent benchmarks exposed in BrowserGym. The reported finding is not only a leaderboard result; it shows that model rankings vary by benchmark type, with Claude 3.5 Sonnet leading on most benchmarks and GPT-4o stronger on vision-related tasks in the reported setting.

Instance-level evidence comes from runnable adapters, logged browser trajectories, environment predicates, and benchmark-native scores. The evidence boundary is the adapter boundary: if a wrapped benchmark has unstable websites, hidden state, noisy success predicates, or different prompts, BrowserGym makes the run more organized but does not remove those risks. Scores should be compared only under the same BrowserGym/AgentLab release, browser backend, benchmark split, and agent scaffold.
