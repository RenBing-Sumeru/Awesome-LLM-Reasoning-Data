The paper releases SETA-Env, listed as 4,567 Harbor-style environments in the candidate table and summarized as over 4,500 in the abstract. Each environment contains an instruction, Docker resources, a reference solution, and tests whose outputs provide deterministic terminal rewards. SETA-Synth converts diverse sources, while SETA-Evol creates difficulty- and diversity-controlled variants for terminal RL such as GRPO. Because the July 2026 release is still new, counts, fields, and licence should be tied to a specific Hugging Face commit.
