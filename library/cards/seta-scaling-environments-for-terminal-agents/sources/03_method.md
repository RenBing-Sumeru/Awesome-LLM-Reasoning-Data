1. **Standardize source tasks:** SETA-Synth extracts objectives from text, code, and existing task sources and rewrites them into a common Harbor instruction and environment specification.

2. **Generate environments and references:** Build Docker resources, oracle solutions, and tests, then execute them to confirm startup and reference success.

3. **Evolve difficulty and diversity:** SETA-Evol creates variants from qualified environments and adjusts complexity using model success or task features while avoiding duplicates and trivial cases.

4. **Unify verification and RL:** Both pipelines share tests, fail-to-pass, and stability checks. Qualified environments become RL prompts and terminal tests compute rewards.
