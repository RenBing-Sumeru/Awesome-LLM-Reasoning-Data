The main source is Bespoke-Stratos-17k, whose full student-training setting contains 16,710 mathematics and coding question-solution pairs; experiments also use a random 1,000-pair subset. The RLT first receives a short supervised warm-up on example traces reformatted into the answer-conditioned interface. The paper does not publish the warm-up membership as a separate manifest.

Teacher RL runs for 125 GRPO steps with batch size 1,024 and group size 64. Generation uses temperature 0.7, top-p 1.0, no top-k, min-p 0.0, repetition penalty 1.0, and maximum context 16,384. Optimization uses AdamW, constant learning rate, reference-model synchronization every 32 steps, and mixup 0.9; the reported run uses one node with eight H100 GPUs. A frozen Qwen2.5-7B-Instruct supplies the dense reward.

After RL, the teacher recollects explanations for the same question-solution pairs. Distillation generation uses temperature 0.7 and maximum context 32,764. The raw explanations plus known solutions supervise Qwen2.5-7B-Instruct or Qwen2.5-32B-Instruct students. The appendix notes that larger students can suffer from cropped traces and describes collecting up to 16 candidates per pair to find a context-fitting trace. Candidate counts, discarded traces, per-row rewards, selected-trace lineage, and exact 1,000-pair indices are not released.
