Reinforcement-Learned Teacher 从 Qwen2.5-7B-Instruct 初始化，并同时接收每道题的问题与已知答案。它输出带标签的答案和解释部分。用于下游 SFT 时，解释令牌被提取为学生的推理格式，后接已知答案，从而形成问题—推理—答案记录，不再经过额外语言模型后处理。

教师奖励包含两个依赖学生的分量。第一项计算冻结学生读完解释后，对答案令牌给出的平均与最小对数概率；第二项在解释令牌上使用 KL 散度，惩罚只有教师看见答案后才显得合理、从学生仅见问题的上下文却构成跳步的内容。格式违规得 -1。GRPO 在组内优化相对奖励；该奖励是可学性代理，不是逐步形式验证器。
