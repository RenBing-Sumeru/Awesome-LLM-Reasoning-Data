Prior work baseline: whole-image LLaVA and box-only grounding assistants. The actual change is unifying multiple region granularities in one serialized dialogue contract. This is a direction signal because it changes the serialized data object and its selection contract, not merely the backbone. The inherited model family, source tasks, autoregressive loss, and common benchmarks are not new. Before reuse, inspect models may learn annotation conventions instead of robust spatial grounding.
