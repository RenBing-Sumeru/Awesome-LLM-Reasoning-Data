1. **Ecological realism:** Zebra-puzzle tools return short deterministic facts and omit permissions, failures, and open semantics. Results do not directly transfer to web or enterprise APIs.

2. **Optimal-query assumption:** The lower bound uses known generation structure and ignores the cost of parsing tool documentation. Cross-system comparisons should also report tokens and latency.

3. **Strategy adaptation:** If training contains the same generator, models may learn structural shortcuts. Training and evaluation need strict separation by configuration and random seed.
