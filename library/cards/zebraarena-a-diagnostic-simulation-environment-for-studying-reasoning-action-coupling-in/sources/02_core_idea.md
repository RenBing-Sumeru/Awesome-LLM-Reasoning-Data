ZebraArena tasks are parameterized by puzzle size, number of missing clues, and the distribution of information across tools; the official data is organized by these configurations and supports further procedural generation. Each task contains constraints, facts available only through targeted calls, a unique canonical solution, and a theoretical optimal query count. Evaluation records final accuracy, call count, overhead relative to optimum, and performance under budgets. It is an extensible simulation environment rather than one fixed-size QA table.
