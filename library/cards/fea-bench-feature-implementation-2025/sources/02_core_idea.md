FEA-Bench releases 1,401 feature-implementation tasks from 83 real Python repositories. Construction first uses rules to select pull requests containing newly added code and test changes, then applies intent filtering to remove refactoring, documentation-only changes, and pure bug fixes. Requirement descriptions, base commits, gold patches, fail-to-pass/pass-to-pass tests, and environment information form the final instances.

Its verifier follows a SWE-bench-style harness: tests for the new feature fail at the base revision and pass after the gold patch, while existing behavior must not regress. Because of licensing and company-policy constraints, the public Hugging Face release directly hosts only essential attributes, and some repository content must be fetched from GitHub. It is therefore primarily a reproducible benchmark rather than a fully mirrored training corpus.
