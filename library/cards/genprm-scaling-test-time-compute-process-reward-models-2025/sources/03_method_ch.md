1. **建立候选轨迹。** 从 MATH 收集带标准答案的问题，并为每题生成多条分步解答，保存完整前缀与当前待判步骤。
2. **估计相对进度。** 比较加入当前步骤前后的后续可解程度，产生候选步骤标签，而不是只按最终答案回填所有步骤。
3. **执行代码验证。** 对包含可计算结论的步骤生成 Python 程序并运行，以执行结果修正或增强自动标签。
4. **合成判断理由。** 强模型根据题目、前缀、当前步骤和验证结果生成 rationale；格式错误、结论冲突或执行异常的记录被删除。
5. **形成训练数据。** 约 23K 条记录用于生成式 SFT；模型训练和测试时采样只作简要后续使用。
