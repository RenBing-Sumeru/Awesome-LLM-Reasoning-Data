论文构建约 23K 条 MATH 过程监督记录，每条以题目、推理前缀、当前步骤、正确性结论和判断理由为核心。标签通过相对进度估计判断当前步骤是否提高后续求解成功率，再对可计算内容生成并执行 Python 检查，最后由强模型综合题目、步骤和执行结果合成 rationale。该数据主要用于生成式 SFT、步骤判定和推理时多次采样。

关键是单条记录能够还原输入、过程状态、反馈依据和接受结果。该工作围绕MATH 轨迹、相对进度估计、代码执行和生成式判断理由组织数据，使研究者可以追踪标签由何种 verifier、judge、环境或执行工具产生，并将其用于ProcessBench 与数学答案修正。许可、人工核验、格式和去污染若未披露，应继续标为待核验。
