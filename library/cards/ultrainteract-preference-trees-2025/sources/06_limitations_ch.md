# 局限

- **答案正确不等于推理过程正确。** 多数接受信号只检查最终答案、测试用例或执行结果，因此中间论证有误的轨迹仍可能保留；复用前应按任务类型抽样检查逐步忠实性，不能把 `response` 直接视为已验证推理。
- **中心消融没有统一全部数据预算。** 移除 UltraInteract 或通用混合数据会同时改变组成和记录数量，所以 53.6 与 37.0 或 47.7 的差距不能归因于单个树组件；声称单条记录更有效之前，应在固定样本数和 token 预算下复现。
- **发布谱系仍需核对。** 当前 SFT 文件有 288,579 条记录，而表 1 报告 286,979 个正确答案；当前偏好文件有 219,522 条记录，而论文报告 219,819 个偏好对，聚合数据的 MIT 标签也不能解决全部上游条款；再分发前应固定版本、解释数量差异并逐一审计来源许可。
