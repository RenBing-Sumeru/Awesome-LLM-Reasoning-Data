核心贡献是 Formally Verified Automated Programming Progress Standards（FVAPPS）：4,715 个 Lean 4 编程—证明任务，其中 1,083 条经过更严格人工整理和质量控制。每个 JSON/Lean 记录可包含原 APPS 题目、函数定义骨架、可执行 `#eval`/`#guard_msgs` 示例、待证明 theorem、难度和质量标记；Lean 4.12.0 是官方生成与 baseline 的固定版本。与只给 theorem statement 的证明集不同，FVAPPS 同时评测 program synthesis 和 correctness proof；公开数据约 46.8 MB、MIT 许可，可用于 proof SFT、verified code generation 和 Lean kernel reward。
