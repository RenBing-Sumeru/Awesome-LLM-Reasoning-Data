The main contribution is the Formally Verified Automated Programming Progress Standards (FVAPPS): 4,715 Lean 4 programming-and-proof tasks, including 1,083 more carefully curated and quality-controlled samples. JSON or Lean records may include the original APPS statement, function skeleton, executable `#eval` or `#guard_msgs` examples, theorem holes, difficulty, and quality tags. Lean 4.12.0 is the fixed generation and baseline version. Unlike proof sets containing only theorem statements, FVAPPS jointly evaluates program synthesis and correctness proofs. The public dataset is about 46.8 MB under MIT and supports proof SFT, verified-code generation, and Lean-kernel rewards.
