Critic-V separates a Reasoner from a Critic. The Reasoner generates multimodal reasoning, while the Critic provides natural-language revision feedback. The Critic is trained with DPO on critique preferences ranked by rule-based reward, and its feedback iteratively updates the Reasoner’s textual policy. The official repository releases Critic-V training and evaluation assets. The core preference object combines an image, question, original reasoning response, two candidate critiques, and a chosen/rejected ranking produced by rule-based reward. The paper does not present it as a large general dataset with a standalone data card and stable count, so reuse should follow the repository version actually used.
