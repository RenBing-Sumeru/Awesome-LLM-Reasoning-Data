# 阅读笔记

- **定位：**CogCoM 用公开的视觉操作链替代仅含答案的视觉监督，中间视觉结果可以被检查。
- **方法抓手：**GPT-4 规划，GroundingDINO/PaddleOCR 执行，深度优先搜索选择金答案路径，专家编写数学链，再用适配器转为多轮问答。
- **数据与产物：**CC-BY-SA-4.0 发布含 80,827 条自动记录、4,518 条测试记录和 6,998 条数学记录，字段包含 `com_founds`、`final_com` 及图像。
- **证据锚点：**论文的匹配消融加入 7 万条操作链后，TextVQA 从 64.5 变为 71.1，MM-Vet 从 45.9 变为 46.1，MathVista 从 34.8 变为 35.7。
- **复用决定：**仅在重放步骤、保留失败与生成分母、协调组件权利并检查训练评测重叠后，用于带证据的视觉 SFT。
