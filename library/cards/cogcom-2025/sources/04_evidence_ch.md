# 证据

**受控数据消融。**CogCoM-chat 在其他设置不变时，分别加入或移除 7 万条自动生成的操作链记录。加入数据后，TextVQA 从 64.5 提升到 71.1，MM-Vet 从 45.9 提升到 46.1，MathVista 从 34.8 提升到 35.7。这是公开轨迹数据在共享混合之外产生贡献的最强证据，但不同任务增益差异很大，实验也没有把计划文字与视觉操作返回值的作用分开。

**构造质量边界。**自动流程在 35.55% 的规划样本上找到以金答案结束的路径，其余分支被丢弃。论文称人工检查发现大部分保留路径正确，但没有给出独立的逐步错误率；小型或少见对象的构造成功率更低，过大的定位框也可能偶然得到正确最终答案。
