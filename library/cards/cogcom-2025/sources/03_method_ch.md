# 方法

1. **选择源任务并定义操作。**输入是 TextVQA、ST-VQA 和 TDIUC 的图像问答三元组，以及 MathVista、ChartQA 的图形数学题。流程定义 OCR、定位、裁剪放大、计数、计算和画线六类原子操作，并保留源金答案作为终止目标。若任务没有稳定答案或无法用操作与证据路径表示，则停止。
2. **生成语言计划。**把问题、操作定义、五个手写示范和输出格式交给 GPT-4-turbo，使其编写逐步操作调用与描述，并把工具结果保留为变量。每一步必须包含操作名、参数或变量引用和结果槽，格式错误的计划不进入视觉执行。
3. **执行视觉操作并搜索路径。**GroundingDINO、PaddleOCR 和本地裁剪、计数、计算实现会填入框、文本、图像或数值，并对多种结果形成分支树，再用深度优先搜索寻找路径。只保留最后一个操作返回金答案的路径；对于过大的定位框仍需单独审计，因为答案一致不证明每个中间结果正确。
4. **加入专家数学链并序列化。**十位专家为 MathVista 和 ChartQA 编写推理步骤与操作结果；所有链按派生图像切分为多轮、多图像问答示范。论文约有 7 万条自动链和 7 千条专家数学链，当前发布分别提供 80,827、6,998 条记录及 4,518 条测试记录。需要核验专家结果、限制图像轮数，并保留来源和划分身份。
5. **训练并评估消费者。**将操作链与其他问答、定位和对话数据混合，对 CogVLM 风格的 17B 模型进行分阶段次词训练，并在轮次间保留键值记忆。评测覆盖问答、定位、数学、幻觉和操作链质量；数据消融必须固定非操作链数据、骨干和训练设置，也不能把最终答案准确率当作逐步忠实度。

**可复现性：**应核验 ICLR/arXiv 论文、官方代码库、CC-BY-SA-4.0 数据版本、图像包和真实 Parquet/JSONL 字段。需要固定源基准版本、五个示范、GPT-4 快照、视觉模型检查点、操作代码、搜索规则、答案归一化、划分映射、轮数上限和训练混合。API token 与成本、完整失败分支、语义去污染、组件权利协调和独立逐步准确率均未完整披露。
