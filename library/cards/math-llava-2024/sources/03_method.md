# Method

1. **Select a seed pool.** Input: image-question-answer triples from 24 public datasets. Process: GPT-4V labels 10k sampled images for clarity and comprehension complexity, and two ViT classifiers propagate those labels. Output: clear candidates with complexity scores. Check / stop rule: discard predicted-unclear images and select 40k records at a 2:3:4:1 complexity ratio across sources.
2. **Mine new questions from each image.** Input: a selected image, its seed question, and five task families. Process: cluster source questions with TF-IDF and K-Means, sample task-specific demonstrations, and ask GPT-4V for up to five nonduplicate definite-answer questions. Output: 200k new image-question-answer records. Check / stop rule: prompts forbid uncertain questions, duplicated seed content, and answers longer than the requested short form; there is no independent correctness checker.
3. **Transform the seed question.** Input: each of the 40k original questions and its image. Process: GPT-4V separately creates a harder multi-step version, a semantically equivalent rephrasing, and a shorter underspecified version answerable with the image. Output: 120k additional records, producing MathV360K when combined with seeds and mined questions. Check / stop rule: preserve the seed answer for rephrased and underspecified variants, while prompt compliance is the reported acceptance boundary.
4. **Train and evaluate the consumer.** Input: MathV360K and LLaVA-1.5-13B. Process: fine-tune the language model and projection layer for two epochs at learning rate 2e-5 and batch size 16. Output: Math-LLaVA and results on MathVista, Math-V, MathVerse, and MMMU. Check / stop rule: benchmark answer accuracy measures the final consumer; ablations hold the base architecture fixed while changing selected and synthesized data components.

**Reproducibility:** verify the ACL paper, the 174.6 MB public annotation JSON, image acquisition instructions, Apache-2.0 training code, source-license table, ViT labeling prompts, and GPT-4V synthesis prompts. A faithful rebuild must also freeze GPT-4V and ViT revisions, cluster seeds, the source snapshot, and image-level splits; temperature, retry policy, random seeds, API cost, and a synthetic-answer error rate are not disclosed.
