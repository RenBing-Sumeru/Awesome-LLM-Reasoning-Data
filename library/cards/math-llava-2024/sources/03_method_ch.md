# 方法

1. **选择种子池。**输入是二十四个公开数据集的图像、问题和答案三元组。处理过程先让 GPT-4V 给随机抽取的一万张图像标注清晰度与理解复杂度，再用两个 ViT 分类器推广标签。输出是带复杂度分数的清晰候选。检查/停止规则是丢弃预测为模糊的图像，并按 2:3:4:1 的复杂度比例跨来源选出四万条记录。
2. **从每张图像挖掘新问题。**输入是一张入选图像、种子问题和五类任务。处理过程用 TF-IDF 与 K-Means 聚类源问题，抽取任务专属示例，再让 GPT-4V 最多生成五个不重复且有确定答案的问题。输出是二十万条新图像问答。检查/停止规则通过提示禁止不确定问题、重复种子内容和超出短答案格式的输出，但没有独立正确性检查器。
3. **变换种子问题。**输入是每个原问题及其图像。GPT-4V 分别生成需要更多步骤的难题、语义等价改写和依赖图像才能理解的简短欠明确版本。输出是十二万条附加记录，与种子和新问题合并成 MathV360K。检查/停止规则要求改写与欠明确版本保留原答案，而论文报告的验收边界主要是提示遵循。
4. **训练并评估消费模型。**输入是 MathV360K 与 LLaVA-1.5-13B。处理过程以 2e-5 学习率、批量十六训练两个周期，并更新语言模型与投影层。输出是 Math-LLaVA 及其在 MathVista、Math-V、MathVerse 和 MMMU 上的结果。检查/停止规则由基准答案准确率决定；消融保持基础架构不变，只改变筛选和合成数据组件。

**复现要点：**应核验 ACL 论文、174.6 MB 的公开标注 JSON、图像获取说明、Apache-2.0 训练代码、源许可表、ViT 标注提示和 GPT-4V 合成提示。严格复现还需固定 GPT-4V 与 ViT 版本、聚类随机性、源数据快照和图像级切分；论文没有披露温度、重试策略、随机种子、接口成本及合成答案错误率。
