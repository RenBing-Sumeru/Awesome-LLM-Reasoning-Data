# Novelty

Earlier visual instruction sets usually reuse each image with few questions, so the image rather than the question inventory limits supervision. Math-LLaVA changes the auditable data decision by first stratifying images for clarity and complexity and then applying four named question-expansion operations to the same seed pool. Its component ablation makes selection, image mining, difficulty, paraphrase consistency, and underspecification separately inspectable. LLaVA fine-tuning, GPT-4V synthesis, and image-QA aggregation are not individually new.
