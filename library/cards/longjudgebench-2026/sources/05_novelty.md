Short-form meta-evaluation treats output length as the main variation. LongJudgeBench changes the evaluation surface to document-level organization, coverage, depth, cross-section consistency, and scenario-specific criteria. Its novelty is benchmark breadth across long-form protocols, not a new judge model.
Its distinction from Long-form RewardBench is not merely length: much of the latter’s gold data comes from an LLM-as-a-judge pipeline, which can create circularity. LongJudgeBench uses expert direct scores, preferences, rankings, and reference verification, retaining protocols in a unified format; its audit object is judge–human agreement.
