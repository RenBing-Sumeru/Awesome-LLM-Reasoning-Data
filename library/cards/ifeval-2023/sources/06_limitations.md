Correctness is relative to the implemented checkers. A brittle response can pass by satisfying the surface predicate, and a useful response can fail if it violates a measurable constraint.

The benchmark covers only selected verifiable instructions; it does not measure multi-turn task completion, factual grounding, reasoning quality, or user preference. Strict and loose scores are not interchangeable, and scores can move with evaluator code, prompt wrappers, decoding settings, or dependency behavior.

The public release creates contamination risk. License and redistribution terms should be checked at the artifact level before mirroring the data or using the checker as a reward signal.
