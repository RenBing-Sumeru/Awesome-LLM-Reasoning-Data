- **Terminal-verifier risk:** a deterministic script is reproducible only for the state fields and service responses it actually queries. Missing predicates can create false positives, overly strict snapshots can create false negatives, and public evaluator code can invite verifier gaming. No task-level error rate, adversarial test, or independent evaluator audit is reported; this is a curator risk inference from the feedback contract.
- **Dynamic-environment risk:** some ground truth is retrieved in real time, and the task substrate mixes mutable remote services, accounts, APIs, credentials, and local containers. An unchanged agent can receive a different score after data, permissions, service behavior, or availability changes. `claim_done` or normal loop termination does not protect against this brittleness because correctness is checked afterward.
- **Version-drift risk:** Toolathlon-Verified on 2026-06-30 substantially revised prompts, ground truths, evaluators, and infrastructure relative to the paper. The checked repository commit is `3b647e6` and the checked Hugging Face revision is `01deb37`, but there is no repository tag, GitHub Release, or immutable manifest tying paper version, code, container image, external services, evaluators, and archives together. Paper and current leaderboard scores are therefore not directly comparable.
- **Contamination and split risk:** one public 108-task pool is reused across every released run; no train/dev/test split, hidden test set, public/private partition, systematic near-duplicate audit, or benchmark-overlap study is disclosed. Prompts, ground truths, evaluator code, and trajectories expose direct contamination and evaluator-gaming surfaces. A canary plus `DECONTAMINATION.md` and `decontamination.json` exist, but the detailed files are gated and were not inspected.
- **Release, rights, and privacy risk:** raw trajectory archives are gated, so exact episode inventory, hashes, redaction diffs, omitted/corrupt-run policy, and file-level completeness are unknown. The paper is CC BY 4.0, but no general-purpose license was verified for repository code, task assets, ground truths, environment snapshots, trajectories, or third-party application content. The release reports credential/endpoint sanitization, yet independent redaction recall, consent, and third-party-content rights remain unknown.
- **Construction and reproducibility risk:** per-task source URLs, contributor attribution, rejected-task counts, reviewer decisions, agreement, and acceptance thresholds are undisclosed. Provider temperature and top-p inherit upstream defaults in the current release; model endpoints, total token/compute budgets, reset procedures, and external-service versions are not normalized or immutably pinned. The paper's observed tool-call errors, long-context degradation, premature stopping, and 15%–35% overlong-output incidence can therefore reflect both agent behavior and scaffold/environment choices.
