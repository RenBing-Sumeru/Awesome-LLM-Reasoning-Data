- **终态 verifier 风险：** 确定性脚本只能对其实际查询的状态字段与服务响应实现可复现检查。谓词遗漏可能产生 false positive，过严快照可能产生 false negative，公开 evaluator code 还可能诱发 verifier gaming。论文没有报告逐任务错误率、对抗测试或独立 evaluator 审计；这是依据反馈契约得到的 curator risk inference。
- **动态环境风险：** 部分 ground truth 实时获取，任务 substrate 又混合可变的远程服务、账号、API、credential 与本地容器。即使智能体不变，数据、权限、服务行为或可用性改变后，分数也可能变化。`claim_done` 或正常 loop termination 不能消除这种脆弱性，因为正确性在其后才被检查。
- **版本漂移风险：** 2026-06-30 的 Toolathlon-Verified 相对论文实质修改了 prompt、ground truth、evaluator 与 infrastructure。已检查仓库 commit 为 `3b647e6`，Hugging Face revision 为 `01deb37`，但没有 repository tag、GitHub Release 或不可变 manifest 把论文版本、代码、container image、外部服务、evaluator 与 archive 绑定起来。因此，论文分数与当前 leaderboard 分数不可直接比较。
- **污染与划分风险：** 一个公开的 108-task pool 被每次发布运行重复使用；论文未披露 train/dev/test split、hidden test set、public/private partition、系统化近重复审计或 benchmark overlap 研究。prompt、ground truth、evaluator code 与轨迹形成直接污染和 evaluator gaming 表面。发布包含 canary，并指向 `DECONTAMINATION.md` 与 `decontamination.json`，但详细文件受 gated access 限制，未被检查。
- **发布、权利与隐私风险：** 原始轨迹 archive 受 gated access 限制，因此精确 episode inventory、hash、redaction diff、omitted/corrupt-run policy 与文件级完整性均为 unknown。论文采用 CC BY 4.0，但仓库代码、任务资产、ground truth、环境快照、轨迹及第三方应用内容均未核验到通用许可证。发布声明已清理 credential/endpoint，但独立 redaction recall、consent 与第三方内容权利仍为 unknown。
- **构建与复现风险：** 逐任务来源 URL、贡献者归属、rejected-task 数量、reviewer decision、agreement 与 acceptance threshold 均未披露。当前发布的 provider temperature 与 top-p 继承上游默认值；model endpoint、总 token/compute budget、reset procedure 和外部服务版本没有归一化或不可变固定。论文观察到的 tool-call error、long-context degradation、premature stopping 与 15%–35% overlong-output incidence 因此可能同时反映智能体行为以及 scaffold/environment 选择。
