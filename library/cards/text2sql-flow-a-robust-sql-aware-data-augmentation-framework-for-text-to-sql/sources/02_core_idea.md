SQLFlow contains 89,544 annotated examples across databases associated with Spider, BIRD, EHRSQL, and related sources. The paper also defines SQLFlow-Part with 67,570 `SELECT`-only queries for size-matched comparisons. Records include database/schema, natural-language question, SQL, execution-verification outcome, reasoning trace, and structural category. A modular Database Manager executes across database engines. The verifier runs SQL against the corresponding database and checks expected semantics; the data support both SFT and structure-aware few-shot retrieval.
