After fine-tuning on SQLFlow, Qwen2.5-Coder-7B improves execution accuracy from 73.4% to 82.0% on Spider-dev, 50.9% to 59.2% on BIRD-dev, and 24.3% to 56.1% on EHRSQL. Masked-alignment retrieval using SQLFlow as a knowledge base reaches 61.0% on BIRD-dev and 83.5% on Spider-dev. These results support utility, but questions and SQL share one synthesis pipeline, so linguistic naturalness and schema leakage still need auditing.
