AgentRx was submitted to arXiv on 2026-02-02 as a preprint on diagnosing failed AI-agent executions. The problem is not ordinary task-success benchmarking: agent runs can be long, probabilistic, multi-agent, and mediated by noisy tools, so a terminal failure does not identify the first unrecoverable mistake. The data object is a failed trajectory containing messages, tool calls, tool outputs, observable state, failure events, a critical failure step, and a root-cause category. The feedback contract is step-level human annotation plus a later diagnostic system that emits a critical step and taxonomy label from evidence. It belongs in the atlas as trajectory-level failure attribution data for agent evaluation and audit.
