The prior baseline is agent evaluation by final success, generic LLM-as-judge scoring, or failure labels that do not necessarily identify the first unrecovered error. AgentRx changes the object from a terminal outcome to a step-indexed causal failure record and changes the feedback contract from a single score to constraint violations plus taxonomy-guided adjudication. The direction signal is useful for agent-debug data because each accepted diagnosis should name the failing step, evidence, and category. What is not new: LLM judging, tool-schema checking, and qualitative coding are existing components. Before reuse, inspect whether the trajectories can be redistributed, whether Flash data is private, whether judge prompts and model versions are pinned, and whether the taxonomy covers the target domain.
