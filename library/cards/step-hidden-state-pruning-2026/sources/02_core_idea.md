STEP uses the last-layer hidden state at a reasoning-step boundary as an early signal of trace quality. A lightweight two-layer MLP maps this representation to a correctness score, and the running average of step scores ranks active traces. Unlike output confidence or surface similarity, the signal is trained from internal representations that already encode how a reasoning path is developing.

Pruning is coupled to the inference system. STEP does not remove a trace at an arbitrary interval; it watches KV-cache utilization and, at saturation, removes the active trace with the lowest score. This immediately releases memory, avoiding preemption and cache reconstruction. The resulting allocation rule spends compute on the traces most likely to be useful precisely when hardware capacity makes continuing every trace expensive.
