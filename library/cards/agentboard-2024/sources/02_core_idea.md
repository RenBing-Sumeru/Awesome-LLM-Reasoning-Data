The one-sentence contribution is an analytical board for multi-turn agents that unifies diverse environments and adds fine-grained progress-rate metrics beyond final success. The core mechanism treats each benchmark as a partially observable interaction process, logs the trajectory, and measures both whether the task is solved and how much of the intended path the agent completed.

Closest comparisons are AgentBench-style success-rate suites and single-domain web/tool benchmarks. AgentBoard changes the audit object from "did the agent finish?" to "what progress did the agent make before termination?" The direction label is diagnostic agent evaluation. What is not new is running LLMs in interactive environments; the new reusable piece is the progress-aware scoring layer tied to trajectory analysis.
