AgentBoard asks how to evaluate multi-turn LLM agents when final success alone hides partial progress and failure location. The primary source is "AgentBoard: An Analytical Evaluation Board of Multi-turn LLM Agents" (arXiv:2401.13178, NeurIPS 2024 Oral), with the paper-linked official repository at https://github.com/hkust-nlp/AgentBoard. The evaluation surface is a partially observable interactive episode in one of nine environments, drawn from 1,012 curated tasks, where the agent observes state, acts, receives environment feedback, and is scored by success plus process-oriented metrics.

The decision boundary is agent evaluation and diagnostic benchmarking, not a training corpus and not a generic leaderboard detached from environment traces. AgentBoard is useful for the atlas because it makes progress within a trajectory part of the feedback contract: a model can fail the terminal task while still receiving measurable partial-progress evidence. Reuse requires pinning task versions, repository revision, model/scaffold settings, API behavior, parsing rules, and the exact definition of progress metrics.
