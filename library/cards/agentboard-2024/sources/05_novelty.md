The prior-work baseline is success-rate evaluation in interactive agent benchmarks. AgentBoard changes the scoring contract by adding progress-aware metrics and framing tasks as partially observable decision processes. The direction signal is that agent benchmarks should expose failure location and partial achievement, not only terminal completion.

The quality signal is the combination of a paper-described framework, 1,012 curated tasks, and an official code/data repository. What is not new is the idea of testing LLMs in tool and web environments. Before reuse, inspect whether progress annotations are task-specific, whether task versions changed, how failures/timeouts are encoded, whether API-backed environments drift, and whether public tasks have contaminated later models.
