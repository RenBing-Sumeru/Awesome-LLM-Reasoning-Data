Inputs and construction. TensorBench targets Scorch at five pinned commits. An undisclosed LLM agent explores local checkouts under the Appendix A authoring prompt; later sessions receive the prior task list to discourage duplicates. This produces all 194 feature descriptions and four refactor descriptions, while the authors write one refactor. The authors inspect all 199 descriptions, but do not supply reference implementations or maintainer-written hidden tests. Feature descriptions ask the evaluated agent to implement behavior and write tests; refactor descriptions request behavior preservation.

Evaluation pipeline. For each task and each of seven scaffold/model pairs, the harness builds or selects the task image, starts a frozen working copy, sends the stored description as one user message, and enforces a two-hour wall-clock cap. The evaluated systems are two Claude Code configurations, three Codex CLI configurations at xhigh effort, Gemini CLI, and OpenHands with Qwen3-Coder. There is one episode per pair, yielding 7 × 199 = 1,393 runs. The harness captures the working-tree diff and, when supported, the structured CLI session log.

Verification and outputs. Grading never trusts the agent's live checkout. It applies the extracted unified diff in a fresh Docker container at the pinned base commit, rebuilds the Scorch C++ runtime, and runs the full pytest suite. The outcome is successful iff after.failed == 0. Public task records expose instance_id, repo/base commit, language, setup/test commands and timeout, description, relevant files, task type, and categories. The paper says the release also contains diffs, agent outputs, trajectories, before/after pytest logs, report.json files, a flattened matrix, image digest, and audit code.

Reproducibility boundary. The Hugging Face v1.0 artifact verifies the 199 task records plus Dockerfile, run_tests.sh, and metadata. The project-linked benchmark GitHub URL returned 404 during curation, so harness source, predictions, trajectories, evaluation outputs, Docker digest, and their licenses/checksums remain unverified. Exact authoring-generator settings, empirical decontamination, hidden validation, and provider-dated model snapshots are also undisclosed.
