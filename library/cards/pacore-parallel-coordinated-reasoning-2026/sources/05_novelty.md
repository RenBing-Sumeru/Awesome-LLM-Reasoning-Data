Most parallel test-time methods either select one completed answer or concatenate too much branch history into the next prompt. PaCoRe makes compression and synthesis a trained capability: compact messages are the state passed between rounds, and the model is trained to recover useful cross-branch evidence even when no individual trajectory is sufficient. This is the mechanism intended to break the direct coupling between context length and total reasoning volume.

The novelty is not parallel sampling alone, and not simply RLVR. It is a learned coordination interface whose behavior must be assessed at equal message, branch, and token budgets. Before reuse, readers should check whether message compression loses crucial evidence, whether the model truly synthesizes rather than votes, and whether cached first-round trajectories change the online-cost interpretation.
