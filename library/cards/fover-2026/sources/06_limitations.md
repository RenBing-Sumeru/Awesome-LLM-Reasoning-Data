- **Semantic fidelity:** Isabelle can accept a proof of a mistranslated theorem. The release has no field that certifies agreement between the informal word problem, candidate answer, generated statement, and formal theorem.
- **Local versus global proof validity:** replacing non-target Isabelle steps with `sorry` isolates one command but can hide dependency, scoping, or improperly discharged-assumption errors. The paper proposes combining local and solution-level checks for extensions but does not apply that contract to all released data.
- **Restricted logic distribution:** FLDx2 cases using `assump`, including proof-by-contradiction patterns, are removed to simplify the Z3 wrapper. This narrows both proof structures and possible error types.
- **Failure observability:** invalid-format attempts, rejected generations, retry counts, acceptance rates, prover logs, exception categories, timeout outcomes, and mappings from environment failure to label are not released as row-level audit fields.
- **Balancing semantics:** the LastStepBalanced recipe balances the final supervised label and uses `mask_history: true`; it does not demonstrate that every intermediate-label distribution is balanced or calibrated.
- **Version drift:** official Hugging Face cards say they contain materials for a previous paper version. Two model-specific 40K datasets and four raw variants do not transparently identify the single final-ACL mixture, and a raw Llama formal-proof set is not present in ACL Table 1.
- **Contamination:** no decontamination or source-to-evaluation overlap analysis is reported for the related math and logic domains.
- **Evaluation scope:** Best-of-7 uses seven generated candidates, minimum-step aggregation, selected benchmark samples, and mostly paired comparisons to untuned backbones. Individual cells decline, and benchmark improvement is not proof of label accuracy or semantic data quality.
- **Reproduction gaps:** FOVER-40K generation temperature, sampling and retry budget, production seeds, exact final dataset revisions, complete construction compute, and a frozen end-to-end manifest remain `unknown`.
- **Rights:** the project states CC BY 4.0 for data and Apache-2.0 for code and lists upstream licenses, but downstream users must still preserve attribution and audit the terms of each source and base model.
