过程奖励模型需要逐步推理标签，但人工标注成本高且标注者一致性可能较低；Monte Carlo rollout 标签又需要反复调用模型，并继承采样噪声。FoVer 研究形式验证工具能否在形式任务上提供更低成本、可审计的步骤标签，以及用这些标签训练的 PRM 能否迁移到自然语言推理。

数据对象是 FOVER-40K：形式逻辑轨迹和 Isabelle 定理证明轨迹，以及与有序步骤对齐的二元正确性标签。终稿报告 40,000 个带标签步骤：10,000 个 Llama 3.1 8B 的 FLDx2/Z3 步骤、10,000 个 Qwen 2.5 7B 的 FLDx2/Z3 步骤，以及 20,000 个从 GSM8K 级来源生成的 Qwen 2.5 7B Isabelle 步骤。对话格式字段把这些标签转换成 `correct` 或 `incorrect` token 目标，用于全参数 PRM 训练。

这是一项数据构造研究，并不能证明形式 verifier 已解决语义对齐问题。Z3 与 Isabelle 验证的是构造后形式环境中的命题；它们不能证明 LLM 生成的 Isabelle statement 忠实表达了原始文字题。官方数据集变体还声明其内容对应论文的早期版本，因此与 ACL 终稿表 1 精确对应的发布版本仍只得到部分确认。
