The CVPR 2026 paper and official Hugging Face card agree on the core scale: 31,725 human-verified trajectories, 317,993 interaction steps, 428 domains, 10.02 steps per trajectory on average, and 1.07 minutes per task on average. The abstract rounds the step count to 318K. The HF file manifest at revision `ae99f420a646866fd3f6d70ca5984efa0eca5a77` contains raw JSON and image archives, partial full-page screenshot archives, high-level Parquet, and low-level Parquet; the repository reports a total size of about 837 GB.

The clearest training evidence is controlled within the paper, not a direct quality audit of the release. On WCB-L with Qwen2.5-VL-3B, direct LCRL scores 0.487, adding CoT-SFT scores 0.603, adding SGRL scores 0.629, and combining both scores 0.658. The strongest reported 7B WebChain variant reaches 81.4 in the paper's aggregate public-GUI benchmark table. A matched scaling study uses 4K, 20K, and 150K action-step subsets and reports a positive trend, but the text does not enumerate the plotted scores, so this Card does not manufacture them.

WebChainBench contains 1,200 held-out interaction steps split into short- and long-chain subsets, balanced across short, medium, and long histories. It counts a prediction as correct only when both action type and action behavior match. This is useful evidence for the stated grounding/planning decomposition, but the checked artifacts do not provide a deterministic split manifest, cross-benchmark decontamination report, or proof that every valid alternative action is accepted.

Release evidence narrows the paper's “open-source” language. The Hugging Face repository is publicly visible but manually gated, and WebChain Academic Research License v1.0 grants approved non-commercial academic use while restricting commercial use, substantial redistribution, mirroring, and re-identification. The arXiv v3 links an author repository, but its checked tree contained only `README.md`, `trajectory_info.png`, and `webchain_table3_benchmark_results.png`; no implementation or license file was present. Thus the dataset's gated availability is verified, while an end-to-end code release is not.

The paper states that collection, redaction, and review preserve privacy and that no PII is released. This is recorded as an author claim. No per-record redaction evidence, audit sample, estimated miss rate, consent protocol, or site-level compliance log was available to independently test it.
