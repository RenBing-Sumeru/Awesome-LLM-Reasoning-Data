Prior tool-use data work can generate queries from APIs, randomly sample tools, or directly distill a strong model. MAGNET does not claim that tools, function calls, SFT, or preference optimization are new. Its closest comparison set includes APIGen, ToolAce, Hammer, and direct teacher trajectory distillation. The concrete change is to make a multi-turn dependency path the intermediate construction object. Local dependency graphs and Merge/Insert/Split operations target different multi-turn failure classes before query generation. Reference calls and outputs then become hidden context hints for positive trajectories, while SFT-model errors selected by a teacher judge become deliberately misleading hints for negatives. This locates the novel data interface between executable call reference and behavior trajectory, rather than treating a tool-call answer as a single flat label.

The quality signal is conditional: Table 4 isolates components in one training setup and Appendix C gives limited FSP-overlap statistics. What remains unestablished is release-level trace quality, realistic failure coverage, verifier calibration, portable API dependency extraction, and generalization beyond English pure-text signatures. The recipe should be compared with an environment that records real API versions and per-turn execution outcomes before reuse.
