权威记录为 ACL 2025 长文（第 32600-32616 页；arXiv:2503.07826v1）。它针对多轮函数调用：agent 必须组合调用、使用此前输出，并在函数或参数缺失时作出响应。论文区分三类失败：用户问题未显式说明的嵌套调用、跨对话轮次的长依赖，以及本应澄清而不应调用的无关或信息不足请求。（论文 §1、Figure 1）

相关数据对象是一段 agent episode，而不只是一个答案：函数签名与依赖边、逐轮用户问题、带参数的参考函数调用、返回的 tool output、模型动作序列，以及用于偏好训练的一条正轨迹和一条负轨迹。论文从 5,011 个 API 的池构造该对象，随后报告 34,000 条正向 SFT 实例和 4,556 个 mDPO 对。它没有发布 episode、稳定 ID、环境包或 split manifest。（论文 §3.3-3.7、Table 1）

本卡归入 `environment_agent_trajectory_data`，因为 tool call、observation 与多轮状态是该记录不可缺少的部分。它不是公开 rollout 语料，也不是独立 reward 数据集。论文及附录足以支持对配方的 L4 描述，但发布状态仍为 partial：读者无法回放所声称的工具交互，也无法独立检查正/负轨迹对。
