The official record is an ACL 2025 long paper (pp. 32600-32616; arXiv:2503.07826v1). It targets multi-turn function calling, where an agent must compose calls, use prior outputs, and respond when functions or parameters are missing. The paper distinguishes three failures: nested calls not explicit in the user query, long dependencies across conversation turns, and irrelevant or underspecified requests that should trigger clarification rather than a call. (Paper §1, Figure 1)

The relevant data object is an agent episode, not just an answer: function signatures and dependency edges; per-turn user query; reference function calls with arguments; returned tool outputs; model action sequence; and, for preference training, a positive and negative trajectory. The paper constructs this object from a 5,011-API pool, then reports 34,000 positive SFT instances and 4,556 mDPO pairs. It does not release the episodes, stable IDs, environment package, or split manifest. (Paper §§3.3-3.7, Table 1)

This Card belongs in `environment_agent_trajectory_data` because tool calls, observations, and multi-turn state are essential to the intended record. It is not a public rollout corpus or a standalone reward dataset. The paper and appendices support an L4 description of the recipe, but release status remains partial: a reader cannot replay the claimed tool interactions or independently inspect the positive/negative pairs.
