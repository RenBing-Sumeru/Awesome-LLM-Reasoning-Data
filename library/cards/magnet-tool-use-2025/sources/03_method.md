**Function substrate → paths.** Collect StableToolBench source-code functions and BFCL-v3 multi-turn implementations; rewrite BFCL-v3 names/descriptions so the implementation is not exposed to models. Keep StableToolBench functions with parameters that pass simulated calls, yielding 5,011 APIs across 49 cleaned categories. For each API, sample 30 same-category/class candidates and ask Gemini-1.5-pro-002 whether output-to-input dependencies create graph edges. Random walks produce initial function-signature paths. (Paper §3.4)

**Path operations → query/reference sequence.** Merge combines consecutive path turns; Insert adds an implicit or later reused function; Split marks a turn with `miss params` or `miss func`. Back-translation makes a user query from each signature; forth-translation makes an executable call using query and preceding outputs. The documented prompts cap a turn at three parallel calls. Executed reference calls yield the next observation. Path length, graph decisions, exact operation sampling, service versions, and replay logs are not released. (Paper §§3.3-3.4; Appendix A)

**References → trajectories.** Gemini-1.5-pro-002 receives correct call hints to generate positive trajectories. To create negatives, collect ten trajectories from the SFT model for each instance; have Gemini judge each turn against the reference and classify incorrect calls/summaries among nested, short-dependency, long-dependency, wrong-summary, and missing-function/parameter errors; use selected incorrect calls as wrong hints when sampling a negative trajectory. Shuffle function order and remove trajectories with strings such as `Bad request` or `does not match`. (Paper §§3.5-3.6; Appendix A)

**Training.** Train Qwen2.5-Coder 7B/14B on 34,000 positive trajectories, then apply mDPO plus MLE to 4,556 positive/negative pairs. Reported SFT settings include peak LR 1e-5, batch 64, warmup and linear decay. For mDPO, 7B is full-tuned at 5e-7/batch 32; 14B uses LoRA at 1e-6. Appendix B reports 16 A100 GPUs, maximum length 8,172, Adam, 0.1 warmup, and selected one-epoch SFT. No released configuration, model revision, data records, or environment permits exact reconstruction.
