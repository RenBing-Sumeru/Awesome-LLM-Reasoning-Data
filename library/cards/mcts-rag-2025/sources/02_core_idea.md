The central contribution is to place adaptive retrieval inside a UCT-guided reasoning tree. At each node, the system may answer directly, continue reasoning, split the question, retrieve for the current question, retrieve for decomposed subquestions, or summarize prior work. The reported main setting uses four rollouts, maximum depth 5, at most two subquestions, concurrent action expansion, and the top 10 retrieved documents; the paper also studies 8, 12, and 16 rollouts.

The feedback contract is mixed and model-relative. For an action, multiple completions are grouped by answer equivalence. The majority-cluster frequency supplies confidence, and mean log-likelihood within that cluster supplies a node reward that is backed up into Q and N. At the end, semantically consistent answer candidates are grouped; node rewards along a trajectory are multiplied, accumulated by answer group, normalized, and used to choose the highest-scoring group. Gold answers score the benchmark after inference, not the search branches during inference.

This contract is not an independent factual verifier. A model can be consistently wrong, and likelihood can favor fluent but unsupported reasoning. Retrieval changes the information available to later nodes, so a trace is fully interpretable only if queries, returned documents, ranks, corpus or API revisions, reflection decisions, node statistics, and selection scores are retained. The official release provides code paths that can generate some of these objects locally, but not the paper-run records themselves.
