The principal audit limitation is release completeness. `Final Solutions.json` represents terminal solution nodes and `Rollout Solutions.json` one node per rollout; neither is a structured all-node tree archive. A recursive text tree is optional, but no paper-run `.tree` files are committed. Consequently, the release does not expose every expanded or rejected branch, parent-child edge, action decision, Q/N/V/UCT history, selected path, pruning reason, or terminal status from the reported experiments.

Retrieval lineage is also absent. Retrieved context may appear inside generated text, but there is no paper-run ledger of queries, document IDs or URLs, ranks, timestamps, corpus revisions, retrieved passages, reflection decisions, or skip/prune reasons. The paper's Bing/LangChain description and the public Cohere/Azure/FAISS implementation are not reconciled. Live services, mutable indexes, and the hard-coded GPT-4o query helper introduce retrieval and API drift; missing credentials, indices, dependency pins, and model/service revisions prevent exact replay.

The feedback record is incomplete. Runtime code computes answer confidence, survival rates, combined scores, and Q/N/V/UCT values, but the checked discriminator output persists correctness booleans rather than full score vectors. No paper-run semantic clusters, rejection reasons, node values, or selection ledger is released. Self-consistency and likelihood are model-relative signals, so confident agreement is not proof of factual correctness.

Budget attribution is limited to aggregates. The repository can write arguments and aggregate call or token totals and can print elapsed time, but no paper-run seeds, configurations, per-example model calls, generated tokens, retrieval calls, latency, failures, hardware, or monetary costs are committed. The paper-run temperature is unknown, and public script or parser defaults differ from the main four-rollout setting.

Finally, small benchmark inputs do not establish provenance for the larger retrieval corpora or generated outputs. The code is MIT-licensed and the ACL paper is CC BY 4.0, but upstream dataset, retrieved-document, and derivative-trace rights remain source-dependent. No decontamination or benchmark/pretraining-overlap analysis is reported, and aggregate benchmark gains must not be treated as evidence that a released trace dataset is high quality—because such a paper-run dataset was not released.
