In many multi-turn benchmarks, later user messages are weakly connected to the preceding answer, or evaluation only checks final task completion. Preference datasets compress feedback into chosen/rejected labels and lose what the user actually identified. FB-Bench models feedback itself as a categorized data object and jointly annotates the original deficiency and revision checklist. Its novelty is the explicit connection among feedback semantics, prior failure, and required revision, allowing errors to be attributed to feedback comprehension rather than generic response quality.
