Inputs are Plan-Generate-Refine-Validate pipeline creates task instructions and self-contained websites. Outputs are task instruction, website files, ground truth, answer type, solution steps, browser actions, observations, final answer, and judge result. The substrate is self-contained static websites served locally and executed in Chromium-like browser evaluation.

Pipeline: 1. construct or load the task instance; 2. run the model or system under the official harness; 3. collect actions, observations, answers, or predicted structures; 4. apply validation replay and final-state or submitted-answer comparison against ground truth; 5. aggregate scores only under a pinned version of the benchmark. Reproducibility requires pinning paper=https://arxiv.org/abs/2604.10988, project=https://github.com/yuandaxia2001/WebForge, code=https://github.com/yuandaxia2001/WebForge, data=https://huggingface.co/datasets/yuandaxia/WebForge, plus the exact split, runtime, scorer, prompt/scaffold, and release revision.
