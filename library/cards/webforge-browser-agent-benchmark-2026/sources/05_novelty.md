The novelty is not browser automation itself; it is binding automated website generation, validation, and difficulty-controlled benchmark release into a reproducible environment surface.

The prior-work baseline is narrower task lists, static benchmarks, or less stateful evaluation surfaces. What changes is the combination of task object, environment or data substrate, and feedback contract. What is not new is benchmarking or model scoring in general. Before reuse, inspect split policy, release license, artifact revision, scorer implementation, prompt/scaffold, and whether public examples have entered training data.
