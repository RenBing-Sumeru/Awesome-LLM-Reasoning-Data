One-sentence contribution: WebForge generates self-contained browser environments and WebForge-Bench tasks to evaluate browser agents without relying on drifting live websites. The central idea is an automated environment-generation pipeline with difficulty control, followed by validation and benchmark scoring.

The data object contains task instruction, domain and difficulty vector, website files, ground truth, solution steps, browser action, observation, final answer, judge result. Success is decided by the browser run reaches the expected final state or answer under the official judge and action budget. Closest comparisons are static web benchmarks, tool-use datasets, or code benchmarks in the same domain, but the direction label here is the concrete evaluation surface and its verifier rather than a general capability claim.
