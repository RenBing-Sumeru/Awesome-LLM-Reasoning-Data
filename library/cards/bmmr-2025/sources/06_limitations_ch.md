- **参考轨迹作者身份未知。** 流程从“题目—推理路径—答案”三元组开始，之后又提到修订，却没有逐条说明原始轨迹来源、模型或人类作者、修订历史和被拒替代。
- **公开 Train 元数据过少。** Viewer 仅暴露 `id`、`conversations` 和 `image`。语言、题型、UNESCO 标签、难度、来源文档、转换谱系、一致率、人工判定和许可字段均不在公开行级 schema 中。
- **选择级联无法重放。** 精确 prompt、模型版本、温度、seed、动态阈值变化、逐阶段数量、被弃 ID 和逐来源存活率均为 unknown。按设计保留中等一致率项目，也会主动改变观测到的难度分布。
- **过程 target 定义不足。** 论文先为完整轨迹得到规则式正确性标签，再描述在每个步骤后加入二元标签；但没有完整说明中间步骤如何获得彼此不同的标签、部分正确如何处理，以及如何防止终局结果泄漏。
- **验证器产物缺失。** 所检查的官方产物没有公开 BMMR-Verifier 的基础 checkpoint、14 万个训练对、32 路轨迹、规则输出、逐步骤标签、训练代码、权重、校准数据和推理实现。
- **一致性不等于准确性。** 与 GPT-4o 和人类标签高度一致，可能来自共享错误。1,000 个标注样本、标注者的学科身份、仲裁流程、标注者间一致性、置信区间、假阳性/假阴性率和对步骤切分的稳健性均不可用。
- **公开评测只看结果。** GitHub grader 抽取 boxed answer、匹配选项并归一化数值或符号形式；它无法发现“以错误推理得到正确答案”的情况，也不能复现论文报告的过程分数。
- **人工工作报告需要协调。** 方法部分报告 40 名标注者参与数据核查，另有大学生标注 1,000 条验证器样本；NeurIPS checklist 则把 crowdsourcing 与 human-subject research 标为不适用。该标注安排可能不属于这些 checklist 类别，但招募、薪酬、同意、培训、工作量与监督信息均为 unknown。
- **许可主张冲突。** 最终论文 checklist 称 BMMR 为 CC-BY-4.0，且所有来源属于 public domain；实时 Hugging Face 页面标记为 MIT，代码仓库则为 Apache-2.0。没有逐记录权利矩阵证明书籍、考试、网站、既有数据集、图像和派生轨迹的再发布权。
- **未进行去污染审计。** 重写与增强旨在减少记忆与猜测，但没有 exact、near-duplicate 或 semantic overlap ledger 覆盖来源集合、BMMR-Train、BMMR-Eval、模型预训练数据和其他 benchmark。
- **统计与比较仍有限。** 主要结果没有 error bar。受成本限制，高价 proprietary model 只在 5,400 题分布匹配 TestMini 上评测，而非完整 Eval；论文在同一宽泛讨论中同时使用完整集与子集结果。
- **覆盖仍有限。** BMMR 只含中文与英文，也没有覆盖所有 UNESCO 学科；论文还聚焦静态图像，而非视频、音频、具身环境或交互式反馈。
- **发布持续变化。** 没有不可变包把论文、代码、Train、Eval、验证器、prompt、模型版本和 hash 绑定在一起；所检查的 GitHub 仓库也没有正式 release。

这些限制不否定语料价值，而是约束可作出的结论：下游提升说明公开 Train 对象在作者设置下能影响模型，不能证明每条记录都正确、合法可复用、无污染或过程忠实。
