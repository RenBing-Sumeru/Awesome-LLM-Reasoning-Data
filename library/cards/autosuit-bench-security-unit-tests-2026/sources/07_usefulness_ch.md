1. **安全代码评测：** 对 code model 同时报告功能 pass@k、安全 pass@k 和双通过率，按语言、CWE 频率和任务类型拆分，而不是只给平均分。

2. **RLVR/verifier 数据：** 在沙箱执行两套测试，功能和安全均通过才给完整奖励；功能通过但安全失败可作为负样本训练 reward model 或修复 agent。

3. **漏洞修补训练：** 使用 `vulnerable_code`、CWE 描述和安全参考构造 SFT，再在未见 CWE 上测试迁移。若任务涉及真实仓库、多文件或供应链风险，应增加集成测试和静态/动态安全工具，不能直接把 AutoSUIT 分数当作生产认证。
