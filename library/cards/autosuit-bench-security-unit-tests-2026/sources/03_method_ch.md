1. **整理漏洞对象：** 从 CWE 参考代码和可自动执行的安全示例中组织脆弱/安全实现，统一方法签名、文件名、依赖和自然语言描述，覆盖四种编程语言。

2. **生成双套测试：** 为每个样本构造功能测试 `U_f` 与安全测试 `U_s`；前者检查正常输入输出，后者触发对应 CWE 的危险路径。安全参考实现应通过两套测试，脆弱实现应通过功能测试但在安全测试失败。

3. **迭代自动验证：** 在隔离目录编译或解释参考代码，反复修正无法编译、测试不区分或不稳定的样本；只保留满足预期差分行为的任务，并记录缺失安全套件等例外。

4. **模型评测：** 将输出写入指定文件，分别执行两套测试并解析通过/失败断言；论文采用允许部分测试得分的 relaxed pass@k。复现需固定编译器、JUnit/pytest 依赖、超时和 sandbox。
