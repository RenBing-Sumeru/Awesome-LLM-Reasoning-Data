The dataset provides 951 executable examples across 232 CWEs, substantially broader than manually constructed collections restricted to top categories. In all languages and tasks, model functionality pass rates are consistently higher than vulnerability pass rates, showing that ordinary code benchmarks systematically overestimate security readiness. Models perform better on common CWEs and degrade on lower-ranked, long-tail categories.

The two suites also provide instance-level evidence: the same output can pass functionality and fail security, directly exposing code that runs but remains vulnerable. However, relaxed pass@k awards partial credit for passing some assertions and should not be interpreted as production security. Twenty-seven C examples lack security suites and support functional evaluation only.
