AutoSUIT releases 951 examples covering 232 CWE categories across C, C++, Java, and Python. The language distribution is 113 Python, 365 Java, 277 C, and 196 C++ examples. Records contain a natural-language specification, CWE description, optional vulnerable code or secure-code prefix, a secure reference implementation, and complete functional and security test sources.

The data supports four tasks: standard code generation, generation with CWE context, vulnerability patching, and code completion. Its key feedback contract is the dual test suite. Functional tests preserve intended behavior, while security tests are designed to fail when the target CWE is present, requiring models to satisfy both rather than obtaining a security score by deleting functionality or avoiding inputs.
