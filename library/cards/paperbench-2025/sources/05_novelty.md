PaperBench's main contribution is an end-to-end, auditable decomposition of research replication. It links a paper-specific task package to an executable repository, a clean reproduction pass, an author-reviewed weighted rubric, and per-leaf model judgment. The 3-stage isolation makes a useful distinction between code that merely exists and evidence that can be regenerated, while the blacklist check attempts to preserve from-scratch conditions.

The benchmark is also unusually explicit about multiple grading dimensions: 8,316 leaves over 20 papers encode implementation, execution, and result agreement. Yet this richness belongs to the evaluation contract, not to a released trajectory dataset. The paper reports 646 runs, but the repository does not publish their complete interaction histories and artifacts. For an atlas of reasoning data, that distinction is itself novel and important: task packaging, verifier code, and run-level supervision are different release objects with different reuse claims.
