PaperBench 正式发表于 ICML 2025，并收录于 PMLR 267；它考察人工智能智能体能否从零复现一篇机器学习论文的实证贡献。评测集包含 20 篇 ICML 2024 Spotlight 或 Oral 论文。每个任务把原论文、作者补充说明、资产、黑名单、配置和隐藏的分层 rubric 组织在一起；一次运行理论上还会产生工具调用日志、代码仓库快照、提交物、新鲜容器执行证据、监控结果和逐叶评分。

最关键的计数边界必须明确：8,316 表示 20 篇论文上的 rubric 叶节点总数，其中 Code Development 为 3,674 个、Execution 为 4,076 个、Result Match 为 566 个；它不是轨迹数量。论文另行报告了 646 次实验运行。因此，公开基准能够支持任务级评测，却没有暴露可直接用于轨迹分析或训练的完整运行级语料。
