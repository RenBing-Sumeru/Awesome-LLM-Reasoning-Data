The contribution is a paired benchmark-and-audit design for LLM-as-a-judge: construct a hard multi-turn question set and a live human-preference arena, then compare LLM judges against expert and crowd judgments rather than treating the LLM judge as ground truth. The core mechanism is to run model answers through controlled judging modes, measure judge-human and human-human agreement, and expose failure modes with targeted bias tests.

The data object is a preference-evaluation record: prompt or conversation context, candidate model responses, response order, judge identity or human-vote source, tie or win/loss outcome, optional scalar grade, and enough model/task metadata to reproduce an aggregate score. The feedback contract is human preference as the reference signal for judge agreement, plus GPT-4 judgments as the scalable evaluator being audited.

Closest comparisons are closed-ended capability benchmarks such as MMLU, HumanEval, and GSM8K; instruction or conversation datasets that do not stress current chat assistants as much; and earlier ad hoc LLM-as-judge uses without systematic human agreement and bias analysis. The direction label is preference-based evaluation with an auditable LLM judge, not reward-model training data by default.
