AndroidControl is useful for recipes that test data-scale effects, app/task split design, accessibility-tree parsing, and hierarchical instruction use in mobile agents. A reusable record should preserve episode id, app id or category when available, goal, step instruction, screenshot bytes or path, screenshot dimensions, accessibility tree bytes, action JSON, action index, split membership, scale subset, parser version, and evaluator version. For atlas work, it is a high-value example of environment-agent trajectory data where the audit focus is generalization split integrity.
