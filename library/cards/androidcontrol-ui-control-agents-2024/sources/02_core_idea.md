The contribution is both a dataset and a scaling study for UI control. AndroidControl collects over 15,000 human demonstrations on 833 Android apps across 40 categories, with both high-level goals and low-level step instructions. The feedback contract is offline action prediction and generalization evaluation: model actions are compared against logged JSON actions under the dataset split and parser rules. Closest comparisons are AITW and smaller UI-control corpora; AndroidControl changes the emphasis from only "can the agent imitate a trace" to "how does scale and app/task OOD splitting affect control behavior." It is a direction signal for mobile-agent data curation, not a claim that scale alone solves live app control.
