Use this paper to design an inference controller that has a budget B and can choose solution count S and verification count V. Log the model and prompt used for each role, token lengths, solution answers, verification rationales, Yes probabilities, aggregation rule, total latency, and success rate by difficulty. These records let a system estimate its own λ and find its own crossover between self-consistency and verification. The official repository is especially useful because it exposes scripts for solution generation, verification generation, success-rate plots, and released model/data resources rather than leaving the budget accounting implicit.
