Reproducibility depends on several mutable components: repository code, task JSON, the VMware image, OSWorld-derived runtime, scientific applications, modified plugins, external APIs, and model endpoints. The release does not bind them with one tag or manifest. Reset semantics are only partially operationalized through initializers and snapshots; authentication, startup timing, missing accessibility trees, hardware performance, and external downloads can change feasibility.

No official train/dev/test split or decontamination audit is reported. All 169 tasks are an evaluation set, and public exposure creates future contamination risk. The paper does not measure overlap with scientific tutorials, model training data, OSWorld tasks, or other science benchmarks. The Hugging Face viewer's `train` label should not be interpreted as an endorsed training partition.

Trajectory retention is under-documented. Five ZIP archives are public, but there is no record-level inventory with task ID, model/API revision, observation condition, seed, actions, timestamps, evaluator output, terminal reason, success, failure, timeout, or corruption status. Consequently, the balance of successful and failed episodes and preservation of intermediate artifacts cannot be audited.

The GitHub repository and environment page declare MIT, while the trajectory page has no visible license declaration. VMware, scientific applications, plugins, task assets, screenshots, and generated traces may carry separate rights. Privacy procedures for screenshots, terminal logs, downloaded data, API prompts, and secrets are undisclosed. The README recommends environment variables for API keys but provides no complete redaction audit.

Agents receive broad VM powers, including terminal commands, application scripting, APIs, and a documented VM password for sudo in the evaluation prompt. Malware/download isolation, network allowlists, credential separation, resource limits, and incident recovery are not specified. Scientific errors may also propagate into files or reports even when encoded evaluator predicates pass.
