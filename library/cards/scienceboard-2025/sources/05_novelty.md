ScienceBoard moves scientific-agent evaluation from answer-only scoring into executable professional workflows. Its distinctive element is application instrumentation: lightweight servers and modified builds expose scientific state that ordinary screenshots and accessibility trees cannot reliably verify. This permits task-specific checks over molecules, GIS layers, celestial simulation time, proof state, files, and documents.

The same environment supports GUI, CLI, and hybrid episodes instead of treating them as separate benchmarks. Agents can switch between visual manipulation, terminal commands, application scripting, answers, and APIs while being evaluated against a shared initialized state. Cross-application documentation tasks additionally test whether experimental outputs can be turned into reports.

This is a benchmark and environment contribution, not evidence that released trajectories are training-ready. Environmental predicates are stronger than visual plausibility for their encoded state, but only cover properties the task author exposes and specifies. Unchecked scientific semantics, side effects, and provenance can remain outside the verifier boundary.
