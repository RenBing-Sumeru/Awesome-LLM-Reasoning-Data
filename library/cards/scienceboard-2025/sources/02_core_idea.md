ScienceBoard's key design is to make professional scientific software both operable and verifiable. It preinstalls tools such as ChimeraX, KAlgebra, Lean 4, GRASS GIS, Celestia, and TeXstudio in a VM and supports mouse/keyboard GUI control, Ubuntu commands, application-specific scripting, answer submission, and predefined API calls.

Visual success is not treated as sufficient. Lightweight servers or modified application builds expose internal state over HTTP. An initializer configures task context, such as a map or protein sequence; after the episode, evaluator templates compare expected and observed values using exact matches, ranges, numerical tolerance, file comparison, and application-specific predicates. The terminal outcome is therefore grounded in environment state rather than an LLM judge.

The data object has two layers. The benchmark layer consists of task JSON, assets, initializers, evaluator specifications, and VM snapshots. The trajectory layer consists of model-generated sequences of observations and actions plus result state. Five ZIP archives totaling about 9.42 GB are listed on Hugging Face, but the release does not provide a normalized record-level manifest that establishes episode counts, task coverage, failures, incompletes, or evaluator linkage.
