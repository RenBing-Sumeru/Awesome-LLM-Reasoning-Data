ScienceBoard 把科学智能体评测从只看答案推进到可执行的专业工作流。其突出之处是应用插桩：轻量服务器和修改后的应用构建暴露截图与无障碍树难以可靠验证的科学状态，从而能针对分子、GIS 图层、天体模拟时间、证明状态、文件和文档编写任务特定检查。

同一环境同时支持 GUI、CLI 和混合 episode，而不是把它们拆成不同基准。智能体可在视觉操作、终端命令、应用脚本、答案和 API 之间切换，同时基于共享的初始化状态接受评估。跨应用文档任务还检查能否把实验输出转化为报告。

这是一项基准与环境贡献，不代表公开轨迹已适合训练。环境谓词对其编码的状态比视觉合理性更强，但只能覆盖任务作者已经暴露和指定的属性；未检查的科学语义、副作用和来源仍可能落在 verifier 边界之外。
