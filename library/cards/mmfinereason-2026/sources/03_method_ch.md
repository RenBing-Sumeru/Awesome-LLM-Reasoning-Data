1. **收集并标准化。** 输入：FineVision、BMMR、Euclid30K、Zebra-CoT-Physics、GameQA-140K 等公开多模态任务。操作：清洗数据，必要时翻译，并映射到统一 schema。输出：约 230 万条样本池。检查：保留来源血缘，并验证图像、问题和答案的对应关系。
2. **生成长推理过程。** 输入：每条标准化提示和视觉输入。操作：让 Qwen3-VL-235B-A22B-Thinking 生成思考轨迹和最终答案。输出：与视觉内容相关的候选推理。检查：强制使用预期的思考/答案结构和长度限制。
3. **过滤质量与重复。** 输入：teacher 候选结果。操作：执行模板和长度检查，移除 50-gram 重复，并比较生成答案与参考答案。输出：181 万条筛选样本，约含 51 亿个解答 token。检查：答案一致只是保留信号，不能证明每个中间步骤都忠实。
4. **估计难度。** 输入：筛选后的样本。操作：让 Qwen3-VL-4B-Thinking 对每题作答四次，以成功率表示相对于 student 的难度。输出：逐题难度观测。检查：所有样本必须使用相同模型、采样协议和答案判定器。
5. **选择紧凑子集。** 输入：难度观测和已通过质量检查的样本。操作：保留 4B student 无法稳定解出的记录。输出：12.3 万条难例子集。检查：子集中的记录必须已经通过质量过滤。
6. **训练并评测。** 输入：181 万条全量语料或 12.3 万条子集。操作：对 Qwen3-VL 2B、4B 和 8B 模型做 SFT，并另行进行 GSPO RL 实验。输出：MFR checkpoint 和 benchmark 分数。检查：比较数据版本时保持 base model 和训练设置一致。

复现要求：官方 Hugging Face collection 已提供三个数据版本及其 schema。复用时仍需核对各来源的图像权利、生成提示、模型 revision、去重实现和答案归一化规则。
