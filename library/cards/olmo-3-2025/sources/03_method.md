For base training, the report tabulates a 9.31T-token Dolma 3 pool and a 5.93T-token final pretraining mix. The final mix contains Common Crawl web text, olmOCRscience PDFs, Stack-Edu code, arXiv LaTeX papers, FineMath, and Wikipedia/Wikibooks. It then continues with a 99.95B-token Dolmino midtraining mix and long-context extensions of 50B tokens for 7B or 100B for 32B. The official pre-training collection exposes pools and mixes, and the Dolma 3 repository describes reconstruction code.

The base-data pipeline includes HTML/OCR extraction, language and heuristic filtering, topic/quality classification, PII filtering for PDFs, global exact/MinHash/suffix-array deduplication, quality-aware upsampling, and proxy-model mixing experiments. Midtraining deliberately adds synthetic math, code, QA, instruction, and thinking-trace sources, then evaluates candidate data with microanneals and larger integration tests. Midtraining and long-context data use AI2 decon against the evaluation harness.

For Think and Instruct, AI2 releases SFT, DPO, and RL datasets and stage models. Think SFT includes generated traces and filtered completions; DPO constructs contrastive pairs, including Qwen 3 32B chosen versus Qwen 3 0.6B rejected completions in one disclosed recipe. RLVR uses different signals by domain: SymPy-normalized reference answers for math, test cases for code, constraint functions for precise instruction following, and Qwen3 32B LLM-judge scores for chat. Think 7B offline difficulty filtering generates eight rollouts per prompt; final RL groups also have size eight. Tool-use data includes real MCP interactions and simulated trajectories, with post-hoc adherence filters.

The official OLMo-core v2.4.0 release lists official 7B and 32B pretraining, midtraining, and long-context scripts and data mixes, plus model cards and checkpoint manifests. It is evidence for released artifacts, not an independent reproduction of every training run.
