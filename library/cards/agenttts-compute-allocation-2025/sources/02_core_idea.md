The paper treats compute allocation as an iterative experiment rather than a fixed heuristic. It first derives three empirical guides: different subtasks prefer different model capacities, repeated sampling has a task-specific optimum rather than unlimited benefit, and the quality of an earlier stage changes the compute needed by later stages. These guides make a budget allocation a causal workflow decision, not a collection of independent knobs.

AgentTTS operationalizes this view with an Agent, an Archive, and an Environment. The Agent proposes allocations and textual search guidelines; the Environment runs those allocations on a small task set and returns metric feedback; the Archive retains trials, feedback, and guidelines for subsequent proposals. The central record is therefore an allocation trial: task and subtasks, chosen model and sample count at each stage, normalized cost, executed outputs, evaluation feedback, and the next search decision.
