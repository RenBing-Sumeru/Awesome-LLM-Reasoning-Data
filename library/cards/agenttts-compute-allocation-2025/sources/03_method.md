For each complex task, the authors enumerate a model pool ranging from 3B to 72B parameters and represent budget in normalized inference FLOPs. A larger model with fewer samples can then be compared with a smaller model sampled more often, while prompt and generation length differences across stages are included in cost conversion. The scaling primitive is repeated sampling with fusion: samples are drawn at temperature 0.9 and the same language model fuses candidate responses, avoiding an additional reward model or verifier.

The search agent begins with model-preference trials, receives execution feedback, stores it in the Archive, and turns the three empirical insights into guidelines for later proposals. The Environment executes each candidate allocation on the actual task platform. Reported experiments cover retrieval-based QA, knowledge-graph QA, task automation, and automated software development across six datasets; each method runs 50 search iterations using 50 training examples and is evaluated on 500 test examples, with GPT-o3-mini as the search agent. The official repository includes the four task families’ data and adapted execution code.
