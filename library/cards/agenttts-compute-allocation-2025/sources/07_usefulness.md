Use this paper when a product has a sequence of LLM stages and a single serving budget must be divided among them. Record the task graph, candidate models, model versions, each stage’s prompt and generation length, sample count, fusion prompt, normalized and actual cost, upstream outputs, downstream inputs, per-stage score, final score, search trial, and search-set versus held-out-set result. A credible deployment comparison should report both the chosen allocation’s end-to-end latency and cost, because an allocation that is FLOPs-efficient may still be impractical under a particular API or tool stack.
