开源原生 GUI agent 虽能完成单步定位，但在长程任务上仍常失败，因为公开轨迹缺少与动作对齐的推理。通用长 CoT SFT 还可能降低坐标定位能力；逐步 RL 只有一条示范动作时，又会把其它有效动作误判为错误。

GUI-Libra 通过把已有网页和移动端轨迹整理为 81K 条推理与动作记录、使用动作加权的混合监督，并在部分可验证奖励下约束 RL 来处理这两个问题。直接产物是一套数据集和面向原生 GUI agent 的两阶段后训练配方。
