1. **清理来源轨迹。** 输入：7 个公开网页或移动端 GUI 数据集。操作：删除不完整、少于 3 步、多于 50 步以及包含不支持复合动作的轨迹。输出：19K 条轨迹、170K 个步骤。检查：记录结构和动作空间必须合法。
2. **补充结构化监督。** 输入：截图、指令、历史、标注动作与坐标。操作：GPT-4.1 生成长推理、动作描述、类型、目标和值，同时保留原坐标。输出：先推理后动作的 JSON 记录。检查：`<think>` 与 `<answer>` 结构必须可解析。
3. **过滤并划分。** 输入：补充后的记录。操作：Qwen3-VL-8B 对每条输入运行 10 次，动作一致率至少为 0.3；原坐标还必须落在 Qwen3-VL-32B 预测的目标框内。输出：81K 个 SFT 步骤、9K 条轨迹，以及按领域和步序平衡的 40K 步 RL 子集。检查：删除动作不一致、坐标错位、过多早期步骤和过量移动端记录。
4. **执行 action-aware SFT。** 输入：完整推理动作记录及其仅动作版本。操作：混合两种监督，并提高动作 token 与定位 token 的权重，默认权重分别为 2 和 4。输出：动作对齐策略。检查：baseline 训练 2 个 epoch，规模加倍的混合集训练 1 个 epoch，以保持样本暴露量可比。
5. **执行保守 RL。** 输入：SFT 策略与 40K 个静态步骤。操作：GRPO 每组采样 8 个回答，使用部分可验证的逐步奖励、KL 正则和成功率自适应的负梯度缩放。输出：GUI-Libra 模型。检查与停止：同时监控离线和在线表现；7B 的 KL 系数为 0.005，其余模型为 0.001。
