Prior GUI-agent recipes either attach short/noisy rationales to trajectories or optimize a demonstrated action as if it were the only correct step. GUI-Libra changes the auditable record by pairing a longer rationale with structured action fields and checking target-coordinate alignment. It also changes consumption: SFT explicitly weights action/grounding tokens, while RL treats single-demonstration reward as partially verifiable and constrains policy drift. Using SFT plus RL is not new; the novelty is their action-aware data and reward contract.
