Cybench asks how well language-model agents can solve professional-level cybersecurity capture-the-flag tasks in an executable environment, and what risks those capabilities imply. The primary sources are the arXiv paper, OpenReview ICLR 2025 Oral record, project page, and public GitHub repository. It is in scope as an agent-environment benchmark with programmatic terminal feedback. It is not a static multiple-choice cyber quiz or a pure code benchmark. A task includes a CTF description, starter files, an initialized command environment, optional subtasks, agent actions, observations, and a flag-based success condition. The atlas value is its concrete environment state/action/feedback loop for high-stakes tool-using agents.
