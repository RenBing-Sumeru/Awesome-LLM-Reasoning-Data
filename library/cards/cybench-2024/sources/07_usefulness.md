Use Cybench as a template for executable agent benchmarks where the environment, action transcript, and terminal predicate are all first-class fields. Preserve task ID, competition/source, files, container image, scaffold, model, web/search policy, command transcript, observations, budget, subtask checks, final flag result, and safety notes. For atlas curation, it is useful as an example of full-episode supervision with both sparse final reward and denser diagnostic checks. It can also guide audits of whether a proposed cyber-agent score reflects real environment interaction or only static knowledge.
