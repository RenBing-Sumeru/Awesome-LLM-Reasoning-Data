The prior baseline is either static cyber knowledge testing or broad agent benchmarks with low cyber specificity. Cybench changes the object to executable CTF episodes with real files, services, command outputs, and flags. It also adds subtasks so partial capability can be audited instead of only reporting zero-one full solves. The direction signal is a high-risk evaluation surface where agent autonomy, tool use, and environment feedback are inseparable. The quality signal is recent professional tasks plus human difficulty calibration. What is not new: CTF flags, shell environments, and agent scaffolds already existed. Reuse requires checking competition data rights, Docker images, network policy, hidden-answer leakage, safety controls, and whether public tasks have entered training corpora.
