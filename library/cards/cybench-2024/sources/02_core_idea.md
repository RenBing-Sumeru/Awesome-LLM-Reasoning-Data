The contribution is a framework and benchmark of forty recent professional CTF tasks from four competitions, each packaged so an LM agent can execute commands and submit flags. The core mechanism is to wrap real cyber tasks in reproducible environments and add subtasks to expose partial progress when full solves are rare. The data object is an executable CTF episode, not a natural-language answer. The feedback contract is environmental: command outputs provide observations, subtasks diagnose progress, and final success requires the correct flag. Closest comparisons include CyberSecEval-style static evaluations and general agent benchmarks; Cybench stresses real exploitation workflows. Direction label: executable cybersecurity agent benchmark.
