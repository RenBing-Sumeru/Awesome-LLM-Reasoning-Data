Dataset documentation existed in scattered forms before this paper, but Datasheets for Datasets made the disclosure unit explicit and reusable across the dataset lifecycle. Its enduring direction signal is that provenance and limitations should travel with the data rather than live only in an inaccessible paper appendix. It is not a substitute for a legal review, a deduplication method, or modern benchmark-contamination testing. Before reuse, inspect the completed datasheet and determine which questions remain unanswered.
