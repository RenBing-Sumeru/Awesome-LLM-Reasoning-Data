The contribution is a documentation analogy: just as a component has a datasheet, a dataset should carry structured information about its motivation, composition, collection process, recommended uses, and related facts. The core mechanism is not automated verification; it is a repeatable disclosure practice that improves communication and accountability between creators and consumers. In this atlas, a datasheet is metadata and audit evidence, not a quality certificate. Compare it with dataset cards and data statements, then return to the primary release for actual provenance, license, split, annotation, and contamination claims.
