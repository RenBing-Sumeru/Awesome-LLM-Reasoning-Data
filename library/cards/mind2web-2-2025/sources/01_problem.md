Mind2Web 2: Evaluating Agentic Search with Agent-as-a-Judge asks how to close this gap: Deep-search agents need to answer long-horizon information needs with sourced evidence, but short web QA and static answer benchmarks do not check whether the answer is complete, current, and attribution-backed. The primary source is https://arxiv.org/abs/2506.21506; public status is NeurIPS 2025 Datasets and Benchmarks / arXiv (2025).

Decision boundary: It is collected as a benchmark and judge framework for agentic search, not as a training dataset or a generic model leaderboard. The evaluation surface is a task record with a long-horizon information need, public/private split metadata, evidence-source requirements, an answer surface, and a task-specific tree-structured rubric. This makes the paper useful for the atlas because the data object and feedback rule can be audited together.
