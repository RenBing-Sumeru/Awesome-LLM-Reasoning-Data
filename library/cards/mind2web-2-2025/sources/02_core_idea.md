One-sentence contribution: Mind2Web 2: Evaluating Agentic Search with Agent-as-a-Judge makes a task record with a long-horizon information need, public/private split metadata, evidence-source requirements, an answer surface, and a task-specific tree-structured rubric. reusable by binding it to a concrete feedback contract.

Core mechanism: The authors build 130 long-horizon tasks with more than 1000 human-hours, evaluate 10 frontier agentic-search systems, and use specialized judge agents rather than one static reference string. Feedback contract: Agent-as-a-Judge applies task-specific rubric trees to score answer correctness and source attribution; reported metrics include Partial Completion, Success Rate, and Pass@3. Closest comparisons are short web-search QA, static answer benchmarks, and earlier Mind2Web-style action benchmarks. Direction label: verifier-anchored agent evaluation, where the reusable unit is task object plus acceptance rule.
