- **Data identity:** 278,496 prompt-response pairs are generated once by one-epoch SFT policies at temperature 1.0 and receive one synthetic winner/loser label. PPO rollouts train the policy, but OCRM refreshes do not append those rollouts or new labels to this fixed comparison set.
- **What changes:** current-policy likelihoods, joint current-to-SFT ratios, transformed loss weights, reward-model parameters, and policy checkpoints change by stage. The exact pair ratio uses the probability product for both responses; language-model runs apply the flattened relative transform with `eta=0.001` and `alpha=0.9`.
- **Feedback and cadence:** Skywork-Reward-Llama-3.1-8B-v0.2 labels and evaluates the main experiments; GPT 4.1 Nano is used in one additional experiment. Main runs refresh after 100,000 policy-training samples, move the KL reference to the previous policy, and reset the PPO value network and optimizer state.
- **Sampling and evidence:** temperatures are 1.0 for fixed-pair generation, 0.7 for PPO rollouts, and 0.01 for evaluation. Only the main Pythia-1B TL;DR comparison uses three seeds; most other settings are single-seed and synthetic-judge based, so performance does not establish preference-data quality.
- **Release and audit boundary:** official MIT code and processed prompt links are available, but the repository has no tagged release and provides no immutable fixed-pair data, stage weights, run logs, or integrated license manifest. At inspected commit `89d4d19a41bcaa187c43dac2e23eb3fafba59e45`, launcher paths do not match the `ocrm` module directory. Support coverage, weight tails, effective sample size, behavior-policy reproducibility, label errors, decontamination, independent evaluation, and diversity remain open.
