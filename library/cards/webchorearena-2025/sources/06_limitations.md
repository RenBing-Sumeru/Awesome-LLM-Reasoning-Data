The authors identify two primary limitations: the paper constructs a benchmark rather than developing a new agent method, and self-hosted simulated websites retain a gap from the live web. The simulation improves control but cannot capture all redesigns, access restrictions, personalization, or open-web side effects. An online extension is left as future work.

The feedback contract has concrete failure surfaces. Exact matching can reject a correct answer with harmless formatting; must-include checks can accept a required phrase without proving the whole response; GPT-4o fuzzy matching can drift or misjudge semantic equivalence; URL and DOM checks see only configured terminal evidence. Multiplying components makes one false negative decisive and does not identify the first erroneous action. No frozen judge outputs, calibration set, adversarial tests, or alternative-valid-answer audit is released.

Replayability remains partial. The paper fixes a 50-step cap, and the repository documents task-order and reset guidance, but the paper-bound WebArena commit, database hashes, browser image, authentication state, dependency lock, API snapshots, and complete reset manifest are unknown. The README describes `affect_environment`, `required_wait`, and a misspelled `strage_state`, while the pinned 532-row JSON exposes `storage_state` and omits the first two fields. Curator inference: this mismatch weakens automatic auditing of state mutation and waiting requirements.

Release and data-governance limits also matter. There is no train/dev/test split, hidden holdout, contamination audit, complete item-level construction lineage, or full successful/failed/crashed run release. The top-level repository and Kaggle dataset are Apache-2.0, but rights for adopted upstream code, seeded website content, screenshots, authentication state, and future trajectories require separate review. Consequently, the benchmark is usable for evaluation under pinned conditions, but the evidence does not justify training reuse or deterministic episode replay.
