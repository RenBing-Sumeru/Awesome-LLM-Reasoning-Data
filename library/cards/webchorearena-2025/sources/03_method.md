Construction starts from the 4 principal self-hosted WebArena sites. 3 author annotators are assigned to each site, with 1 annotator spanning all 4, yielding 10 annotators in total. They explore site content and functions, propose memory-intensive analytical chores, and create templates plus several instantiations for each variable. Early prototypes are executed with a Claude-based agent to expose overly easy designs and model limitations. Annotators are instructed to remove ambiguity in both instructions and evaluation criteria and to standardize output wording when exact matching is intended.

The authors then cross-check tasks with 3 annotators per site and iterate through inference, error analysis, and revision. The final 117 templates yield 532 instances: 117 Shopping, 132 Shopping Admin, 91 Reddit, 127 GitLab, and 65 cross-site. Map tasks are excluded because of insufficient functionality and loss of access to the WebArena team's internal server after April 2025. The paper gives aggregate construction counts, but not task-level authorship, prototype histories, rejected proposals, Claude trial outputs, or selection thresholds.

At evaluation time, BrowserGym or AgentOccam receives an instantiated intent and partial page observations, acts in the configured environment, maintains agent-specific history or memory, and stops with an answer or infeasibility report. BrowserGym offers 15 browser, tab, navigation, messaging, and infeasibility actions and permits multiple actions per step; AgentOccam offers 8 basic, navigation, note/stop, and branch/prune actions with 1 action per step. Both are capped at 50 steps. Experiments use GPT-4o-2024-05-13, claude-3-7-sonnet-20250219, and gemini-2.5-pro-preview-03-25, with scaffold-specific temperatures and token limits documented in Appendix C.

The final answer, URL, and/or page state is scored by `string_match`, `url_match`, and `program_html`. The repository instructs evaluators to preserve task order because later tasks may mutate state, reset after each website, run cross-site tasks after reset, and reset before rerunning failures. Reproduction should pin repository commit `542abc538fd9558362119714989166904d82f5f4`, the 532-row JSON, upstream WebArena/BrowserGym/AgentOccam revisions, browser and database images, authentication state, API model snapshots, task order, and reset schedule. Only the repository commit and task JSON are currently fixed by this Card; the remaining runtime versions are unknown.
