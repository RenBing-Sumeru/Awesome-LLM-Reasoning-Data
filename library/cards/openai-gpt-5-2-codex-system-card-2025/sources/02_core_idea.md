The report's most important reasoning-data contribution is a concrete but incomplete episode-level safety objective: create conflicting user edits during RL rollouts and positively reinforce the coding agent for preserving those edits. The observable state includes at least the evolving workspace and user-produced changes; the disclosed signal distinguishes preservation from reversion. The report does not reveal how preservation is detected, whether the reward is binary or graded, how conflicts are generated, or how this signal is combined with correctness, policy, or task-completion rewards.

A separate evaluation object is much more explicit. An OpenAI PR episode starts from a pre-PR branch of an internal repository, gives a human-written change request, allows an OpenAI-hosted chat agent to use command-line tools and Python to modify files, and succeeds only when all task-specific hidden tests pass. The prompts, tests, and hints are human-written. This is an executable full-episode evaluation contract, not evidence that hidden tests implement the destructive-action training reward.

Relative to the May 2025 Codex addendum, which described real-world coding RL and synthetic or perturbed safety environments at category level, this addendum reveals a specific state intervention and positive-reinforcement condition. Relative to the GPT-5.3-Codex system card, it also gives richer evaluation construction detail. Its direction signal is that preservation of concurrent human work can itself be encoded as an agent-training objective, while its disclosure limit is the absence of the data, detector, reward, and replay stack.
