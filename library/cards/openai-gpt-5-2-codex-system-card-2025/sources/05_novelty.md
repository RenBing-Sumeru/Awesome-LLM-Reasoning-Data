Earlier Codex disclosures established reinforcement learning on coding tasks and synthetic or perturbed safety environments, but did not expose a concrete concurrency-like state intervention. This addendum changes the disclosure granularity: a user model modifies the same evolving workspace during RL, and preserving its changes is named as a positive-reinforcement condition. The new object is therefore not merely a prompt-response pair; it includes workspace state, another actor's edit, the coding agent's subsequent actions, and an episode-level preservation judgment.

The report also separates that training disclosure from an internal PR evaluation with human-written prompts, tests, and hints, pre-PR repository states, command-line/Python actions, and hidden-test success. This separation is valuable because executable tests are often assumed to be the training reward in coding-agent work. Here the report supports that claim only for evaluation, while the training detector remains unknown.

Reinforcement learning, hidden tests, context compaction, sandboxes, and safety training are not individually new. The direction signal is the explicit treatment of concurrent user work as an RL safety target and the disclosure of multiple environment-level evaluation predicates. Reuse still requires checking the user-model policy, conflict taxonomy, preservation detector, reward interactions, repository rights, trajectory retention, split membership, and versioned environment stack.
