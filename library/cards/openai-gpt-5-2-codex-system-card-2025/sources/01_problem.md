OpenAI published this 22-page system-card addendum on December 18, 2025. It documents GPT-5.2-Codex, a GPT-5.2 version optimized for agentic coding, through a narrow training disclosure, product safeguards, and capability and safety evaluations. The Atlas problem is not whether the model scores well, but which post-training records and feedback interfaces the report actually exposes.

The concrete training object is an RL coding-workspace episode in which a separate user model introduces conflicting edits while GPT-5.2-Codex acts. The only disclosed training feedback is positive reinforcement when the model does not revert the user's changes. Task prompts, repositories, workspace observations, tool actions, patches, successful and failed trajectories, preservation labels, reward values, and record lineage are not released.

This work belongs in the Frontier Reports and Data Disclosure Ledger because it exposes one state-changing agent-training intervention while leaving most of its recipe hidden. It does not establish that the human-written prompts, tests, hints, pre-PR repositories, or hidden unit tests from the separate OpenAI PR evaluation entered training. At L4, this Card can support screening and audit of the disclosure boundary, but not training-data reuse or independent reproduction.
