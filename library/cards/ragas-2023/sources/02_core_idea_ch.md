一句话贡献：RAGAS 把 reference-free RAG 评测 指标 转化为可复用 评测面。核心机制是把任务模式与评分、裁判、验证器 或环境谓词绑定。

数据对象是：基准记录包含无参考 RAG 评测指标、提示/任务元数据、模型输出面，以及分数或成功目标。反馈契约是：官方评测器、答案键、裁判、隐藏测试、指标或环境谓词决定成功与否。方向标签为 裁判_reward_meta_evaluation / RAG 评测。

对比时应看 验证器 类型、隐藏/实时 策略、脚手架预算 和 工件发布模式 是否相近。本卡片将 评测用途 与 训练用途 分开，因为当前证据写明：用于评测和审计；除非官方工件明确支持，否则不记录后训练奖励用途。
