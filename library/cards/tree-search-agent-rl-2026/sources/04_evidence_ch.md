实证范围覆盖多个数据集，但边界仍然明确：十一项评估数据集分属单跳检索 QA、多跳检索 QA 和 web-agent QA。论文报告 Tree-GRPO 在这些设置中优于 chain-based agent RL，并研究约 2、4、8、16 的预期 rollout 预算。这些是作者报告的训练与评估结果，不是独立复现。

多项消融支持了对构造机制的判断，而不只是支持最终分数：

- 在论文报告的 Qwen2.5-3B、budget-4 比较中，agent-step 分支优于 token-level 或 sentence-level 分支。这支持把完整 thought-action-observation 交互作为过程单元的设计，但不能证明这一边界在所有环境中都最优。
- 改变 \(M,N,L\) 显示了多样性与复用之间的权衡。更多独立根树改善探索；如果把预算过度集中在共享前缀扩展上，收益最终会递减或下降。因此，前缀复用不能被当作独立证据数量的无成本倍增。
- 当树内分支很少时，树内基线方差较高，训练可能崩溃。论文把树间 advantage 作为重要 fallback，而不是对稀疏或同质奖励的彻底解决。
- 论文失败案例显示，agent 会过早坚持一条只能部分满足问题的路径，在出现新证据后仍不重新考虑，并最终给出错误答案。树结构本身不保证反思或恢复。

论文、理论附录和官方实现直接支持反馈路径：EM/F1 加格式项为所选叶子评分；叶子按 `tree_uid` 分组；树内与树间归一化产生相加后的训练 advantage。代码也支持对发布边界的判断：所选完整响应与统计被打包供在线更新使用，但节点 ancestry 与完整树不被返回，随后树被删除。

理论结果比一般性的过程监督保证更窄。在二值结果下，论文推导树内 GRPO 与 step-level DPO 具有相同的偏好梯度方向，但权重不同。它没有证明每个共享前缀分支点都对终点结果负有因果责任，而且 web-agent 的 F1 是连续值而不是二值。

报告的 benchmark 表现只能说明该训练配方影响了作者评估的策略。它不能证明瞬时树是高质量可复用数据集，不能证明终点 verifier 验证了中间推理，也不能让缺失分支与奖励可被重建。没有核验到独立结果包、原始 rollout 语料或记录级 replay ledger。
