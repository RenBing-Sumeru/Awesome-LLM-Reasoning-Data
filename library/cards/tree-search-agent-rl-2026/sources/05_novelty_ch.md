Tree-GRPO 的区别性贡献不是新的 QA 语料、学习式 judge 或测试时 planner，而是把一种特定的在线数据拓扑——由完整 agent step 构成的共享前缀树——与组相对策略优化结合起来。在固定预期 token/工具预算下，该拓扑比完全独立采样产生更多完成叶子，并使终点结果对比能够在与分支结构相关的分组上发挥作用。

该方法不同于普通 chain GRPO，因为叶子并不是可互换的独立回答。它们带有 ancestry：部分续写共享较早的交互，而 \(M\) 个根仍相互独立。因此方法引入两种比较尺度。树内归一化询问从相关前缀出发的哪个续写更好；树间归一化比较更宽的提示级样本群，并在某棵小树内部缺少奖励方差时提供稳定作用。

它也不同于 value-guided 或 verifier-guided tree search。扩展节点从非答案节点中随机采样，不由 critic、正确性估计或学习式 process reward 排序。程序化 EM/F1 与格式规则只在所选叶子完成后起作用。因此，其新意是 search-to-credit-assignment 配方，而不是宣称搜索策略能够在线识别最佳分支。

论文的结构等价结果在二值结果假设下把树内梯度与 step-level direct preference learning 联系起来。其研究价值在于说明，带结果标签的树如何在没有单独标注步骤对的情况下诱导局部偏好方向。该结论必须保持边界：显式步骤标签与 DPO pair 并未发布，等价关系的权重不同，而且连续 F1 不满足二值假设。

对本图谱而言，最重要的新意是清楚区分三类对象：丰富的内存 agent-step 树、Tree-GRPO 实际使用的所选叶子 batch，以及公开的 code-only release。把三者都称为同一个“数据集”，会抹去对推理数据审计至关重要的选择、拒绝、ancestry 与奖励谱系。
