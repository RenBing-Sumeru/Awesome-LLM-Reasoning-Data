HARM combines SBIC-Explain, a human-validated set of 370,788 LLM-generated NLEs, with a mixture-of-experts reward head. The data exposes three context tiers: text only, classification-aware, and semantics-informed. HARM learns to favor the richer explanation when the added context improves fidelity rather than treating offensive language itself as a defect. The authors release code; the archival dataset license should be checked before redistribution.
