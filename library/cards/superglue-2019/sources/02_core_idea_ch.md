一句话贡献：SuperGLUE 是 GLUE 的更难继任者，把困难英语 NLU 任务、人类基线、诊断探针、软件工具和排行榜规则打包成可复用的评测面。

核心机制是“筛选任务 + 受控评分”。作者从公开任务征集和已有数据集中找候选任务，用 BERT 类机器基线和人类基线筛查；机器已经太容易或人类没有足够训练也很难做的任务被排除。最终任务覆盖 yes/no 问答、自然语言推断、因果多选、多句阅读理解、常识阅读理解、词义消歧和指代消解。

最近的对照是 GLUE。SuperGLUE 保留单一聚合分数、私有测试标签和排行榜，但换成更难的任务分布，扩大任务格式，强化数据使用规则，并保留诊断集。它的新意主要是评测基础设施设计，而不是提出新的模型架构。
