Read the paper as benchmark infrastructure, not as evidence that any one model understands language. The key boundary is between aggregate leaderboard progress and per-instance task correctness.

Suggested reading order: first Table 1 for task objects and metrics, then Section 3 for selection criteria, Section 4 for submission and data-use rules, and Table 3 plus Appendix C for baselines and human estimates.

Keep three labels separate downstream: main task score, broad-coverage diagnostic result, and Winogender bias diagnostic result. They answer different questions and should not be collapsed unless the official evaluation definition requires it.
