For the **Data Construction & Open Release Recipes** track, OpenMathInstruct-2 is useful as a conditional SFT source, a reference implementation for two-axis augmentation, and an audit case for answer aggregation and release drift.

- **Conditional SFT reuse:** pin dataset commit `469216e3f46f4dacf476b382e192485ea51a143e`, verify all shard hashes and exact split counts, inspect row structure, deduplicate questions, rerun target-benchmark overlap checks, and resolve per-source attribution and teacher terms. The CC BY 4.0 repository label does not replace this review.
- **Augmentation design:** compare solution augmentation, question-solution augmentation, and a matched mixture while holding unique questions, total pairs, teacher tokens, and student compute separately fixed. This avoids calling more solutions per prompt the same thing as more task diversity.
- **Answer-aggregation baseline:** reproduce 32-solution extraction and thresholds 0/8/16/24, but retain candidate answers, normalized equivalence classes, vote margins, nulls, ties, parser failures, and sampled manual adjudications. Measure false accepts and false rejects instead of treating the top surface form as ground truth.
- **Process-quality audit:** use original/source answers and majority proxies only as answer-level labels. Add step checking, symbolic validation, or human review if a study needs faithful rationales or PRM supervision.
- **Decontamination audit:** version GSM8K, MATH, AMC 2023, AIME 2024, Omni-MATH, and any target benchmark; publish retrieval neighbors, all ten 405B judgments, removals, and sampled error reviews. Treat the disclosed 1.4% Omni-MATH overlap as a reason to refresh the benchmark ledger.
- **Historical reproduction:** reconstruct both the 2024 release path and the 2026 current Skills path, then explain differences such as the 564 overlong released questions. Pin teacher/source revisions, prompts, containers, random seeds, and per-stage yields before claiming byte-level reproduction.
- **Scaling study:** use the overlapping 1M/2M/5M subsets for controlled training-scale curves, not as independent datasets. Report exact rows and rounded unique-question counts as different denominators.
- **Release-schema improvement:** attach seed ID/revision, exact 405B checkpoint, generation config/run ID, candidate-group ID, extracted answers/votes, filter decisions, contamination results, transformation history, license, and attribution to every row.

Reuse class: conditionally suitable for answer-level mathematical SFT after provenance, rights, quality, and contamination checks; strong for recipe comparison and audit; not safe as a clean evaluation set without an independent overlap analysis. The released object does not directly support PRM, preference learning, RLVR replay, or agent training because it lacks step labels, paired choices, rewards, policy groups, and environment trajectories.
