1. **Select scientific papers:** Papers with public data, reproducible workflows, and clear analytical objectives are selected across four disciplines.

2. **Reconstruct tasks:** Paper methods are converted into task descriptions, data assets, target outputs, and reference Python programs.

3. **Validate with experts:** Nine domain experts review scientific validity, data, code, and outputs and revise ambiguous or non-independent tasks.

4. **Evaluate in sandboxes:** Agents code and execute under fixed environments and attempt limits; verified splits, dependencies, budgets, and data versions must be fixed.
