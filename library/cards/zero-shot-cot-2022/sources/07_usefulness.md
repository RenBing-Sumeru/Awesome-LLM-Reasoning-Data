1. **Evaluation baseline:** when no demonstrations exist, run direct zero-shot and Zero-shot-CoT with the same model/questions, store both calls, and report accuracy plus token/call cost. This reveals whether a task contains elicitable reasoning capacity.
2. **Candidate-rationale generation:** serialize question, cue, rationale, extraction prompt, answer, and checker result, then independently filter the traces before SFT. The output can be a rationale corpus, but only after validation. Do not use the method alone when process correctness, low latency, or unverifiable open-ended answers are required.
