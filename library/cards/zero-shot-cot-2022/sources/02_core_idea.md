Zero-shot-CoT inserts a model-authored rationale between a task question and its extracted answer using one task-agnostic cue, removing the demonstrations required by few-shot CoT. The serialized object is question, exact cue, first-pass rationale, extraction prompt, and final answer; benchmark answer matching judges only the terminal answer, not individual steps. It belongs in rationale-data lineage as an elicitation baseline, not as evidence that generated chains are faithful supervision.
