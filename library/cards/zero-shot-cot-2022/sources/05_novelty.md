Few-shot CoT places human-written rationales in the prompt, while standard zero-shot prompting asks directly for an answer. Zero-shot-CoT changes the inference record by using one generic cue to make the model author its own rationale, followed by a separate answer-extraction call. The new decision is removal of task-specific demonstrations, not a new base model, dataset, or verifier. Its result establishes a strong minimal baseline for visible reasoning, not faithful process supervision.
