1. **诱导理由。** 输入：benchmark 问题、待测 LLM 和固定提示“Let's think step by step”。操作：把提示接到问题后，解码自由形式理由。输出与流转：第一次生成的推理轨迹。检查与停止：没有 verifier 给中间步骤打分；由模型正常停止条件结束生成。

2. **抽取答案。** 输入：原问题和第一次生成的理由。操作：发起第二个、适配任务格式的 prompt，要求给出 benchmark 期望形式的答案。输出与流转：规范化最终答案。检查与停止：抽取格式会决定一条本来有用的理由能否被计分。

3. **评测协议。** 输入：抽取答案和 12 个推理数据集的官方答案。操作：使用各任务的答案匹配规则，并与普通零样本和少样本 baseline 比较。输出：逐任务准确率。检查与停止：只评最终答案；理由忠实性和步骤正确性均未测量。

可复现性：必须固定模型或 API 版本、精确提示、抽取模板、解码参数、benchmark 版本和答案规范化规则。若历史 text-davinci-002 API 不再可用，主结果无法严格复现。
