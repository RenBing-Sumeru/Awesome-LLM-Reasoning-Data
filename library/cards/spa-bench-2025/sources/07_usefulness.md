For the environment-agent-trajectory track, SPA-Bench supplies a concrete episode schema and verifier decomposition. A reusable record should bind task/source ID, language and app versions, device or AVD image, account and external-state snapshot, observation representation, screenshots, actions, logs, completion signal, golden-step budget, rerun provenance, evaluator inputs/version/output, costs, time, and side effects. The current release defines many fields but does not publish episode instances.

For benchmark evaluation, the 340 task rows and 40 cross-app JSONs can support task-coverage analysis, bilingual stratification, difficulty review, app-order/subtask inspection, and evaluator implementation audit. They should not be used to claim training coverage, human demonstration availability, or deterministic execution. GUI Odyssey-derived records need explicit attribution and overlap checks.

The mixed verifier offers an ablation plan: measure OCR-only, GPT-4o-only, action-hidden/action-visible, result-only/reasoned output, reverse-scan versus terminal-frame checks, and alternate-app-order acceptance against released human labels. Those calibration labels are currently missing, so reproduction requires a new labeled audit set and a pinned judge endpoint.

A stronger replay package would publish legal AVD/image digests, APK/app/account/device manifests, cycle and per-task reset logs, external-state cleanup steps, paper-run trajectories/results, failure/rerun ledgers, evaluator responses, and checksums. Physical-device tasks need separate setup and restoration recipes instead of being represented as snapshot-replayable.

Reuse class: safe for evaluation design, task/evaluator inspection, and audit. Training use is blocked because no supported split, trajectory corpus, training recipe, optimizer, or checkpoint exists, and because public task exposure would contaminate evaluation. Any live execution must additionally establish third-party rights, PII/consent handling, isolated credentials, network controls, and safeguards against messaging, posting, account changes, and purchases.
