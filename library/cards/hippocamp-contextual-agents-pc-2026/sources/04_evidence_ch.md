对多种前沿多模态模型和 Agent 方法的评测显示，个人文件上下文仍远未解决：最先进商业模型在 user profiling 上最高仅 48.3%。步骤诊断表明，主要瓶颈并非最终语言生成，而是多模态感知和证据 grounding，长程检索进一步放大失败。由于任务依赖大规模文件系统，结果也反映索引、搜索和上下文管理能力，不能全部归因于基础模型推理。 按步骤分析后，检索到正确文件并不保证回答正确，模型仍常在视觉内容读取或跨文件证据组合阶段失败。 主实验支持当前前沿模型在个人文件上下文中仍受感知和grounding限制，最佳user profiling仅48.3%；它不能把失败全部归因于基础模型，因为索引和搜索基础设施同样影响结果。
