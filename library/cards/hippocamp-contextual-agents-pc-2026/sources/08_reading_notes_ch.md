1. **定位：**HippoCamp 测量 Agent 在设备级个人文件中检索、感知和推断用户上下文的能力。
2. **方法抓手：**构造真实 profile 文件系统、设计证据型任务、采集操作轨迹并按能力阶段密集标注。
3. **数据抓手：**42.4 GB、2K+ 文件、581 个 QA 和约 46.1K 步骤标签。
4. **证据锚点：**最佳商业模型用户画像准确率仅 48.3%，主要瓶颈是感知与证据 grounding。
5. **复用决定：**适合个人助理 benchmark；必须控制文件索引、隐私许可和 profile 泄漏；还应记录文件访问范围、无关文件打开次数和跨模态证据召回；最适合个人助理检索、跨模态context benchmark和阶段error router；最大风险是隐私和索引shortcut，复用前必须审查文件许可及目标环境搜索配置。
