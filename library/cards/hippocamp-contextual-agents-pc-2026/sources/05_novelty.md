Existing computer-agent benchmarks focus on clicking, typing, and application control, while long-context benchmarks usually provide one preassembled text. HippoCamp combines them in a device-scale personal environment where an agent must discover relevant files, understand multimodal content, and form user-specific conclusions, with step labels separating retrieval, perception, and reasoning failures. Its novelty is a user-centric file ecosystem and process diagnosis rather than generic desktop automation. The benchmark therefore measures both information discovery and contextual understanding and is not merely a larger desktop file-search task. User-profile tasks also require synthesizing preferences from multiple weak signals rather than finding one explicit fact. Desktop interaction and long-context QA are not new. The change is combining them in a device-scale personal file ecosystem and using stage labels to separate missing files, misread content, and failed synthesis.
