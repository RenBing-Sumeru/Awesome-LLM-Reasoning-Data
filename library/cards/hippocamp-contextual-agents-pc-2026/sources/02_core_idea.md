HippoCamp builds device-scale file systems totaling 42.4 GB with more than 2,000 real-world multimodal files and diverse user profiles, then constructs 581 contextual QA tasks. The official data also provides about 46.1K densely structured step annotations covering retrieval, file evidence, visual perception, and reasoning phases, enabling diagnosis of user profiling, file search, cross-modal grounding, and multi-step synthesis. Tasks also decompose capability stages into search, evidence perception, and multi-step reasoning, attributing failure to missing files, misread content, or incomplete inference. Mappings between source files and task evidence trace answer failures to concrete files and capability stages. The 42.4GB environment contains over 2,000 multimodal files, 581 tasks, and about 46.1K step labels. Records map source files, target evidence, and agent actions to retrieval, perception, grounding, and reasoning stages.
