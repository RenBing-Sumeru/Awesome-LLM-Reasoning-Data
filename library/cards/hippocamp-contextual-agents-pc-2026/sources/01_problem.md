Personal-computer agents must do more than operate applications. They need to understand long-term user context across thousands of multimodal files, infer preferences from documents, photos, email, and spreadsheets, and answer questions requiring multiple evidence hops. Existing web or software benchmarks use generic environments and lack device-scale personal files and user profiles. These failures determine whether a personal assistant can answer from the user's history and preferences rather than extracting an isolated fact from one file. Personal assistants must synthesize user history and preferences across thousands of files rather than extract one fact. Failure in retrieval, visual reading, or cross-file inference can yield plausible but contextually wrong answers.

HippoCamp constructs realistic personal file systems and stepwise trajectories to diagnose contextual agents by capability stage.
