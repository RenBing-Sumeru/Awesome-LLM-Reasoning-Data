Evaluation of frontier multimodal models and agent methods shows that personal-file context remains far from solved: the best commercial model reaches only 48.3% accuracy on user profiling. Stepwise diagnosis identifies multimodal perception and evidence grounding, rather than final language generation, as primary bottlenecks, with long-horizon retrieval amplifying failure. Because tasks depend on a large file system, results also reflect indexing, search, and context management rather than only base-model reasoning. Step analysis shows that retrieving the correct file does not guarantee a correct answer; models still fail in visual reading or cross-file evidence synthesis. The main experiment supports persistent perception and grounding limits in personal-file context, with best user profiling at 48.3%. It cannot attribute all failure to the base model because indexing and search infrastructure also matter.
