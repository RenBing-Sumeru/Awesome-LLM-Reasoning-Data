Prompt source: For MCTS the paper uses 500 benign and 1,500 malicious image-text pairs; the safety mixture is curated from BeaverTails-V, VLGuard, and SPA-VL, while benign PRISM-CoT examples are adapted from LLaVA-CoT.
Trace author: The PRISM-CoT fine-tuned VLM samples candidate continuations at each of four stages: PROBLEM, CAPTION, REASONING, and OUTPUT.
Answer format: A published PRISM-DPO record exposes a `messages` conversation containing the prompt and an assistant structured reasoning trace, a paired `rejected_response`, and `images`; the paper defines the underlying object as a higher- versus lower-cumulative-reward path at the same reasoning level.
Process fields: image-text prompt; four-stage structured reasoning trace; preferred assistant trace in messages; rejected_response; associated images
Environment or substrate: Offline MCTS over structured VLM reasoning steps, plus a separately released test-time scaling implementation using self-rewarded beam search and Best-of-N.
Verifier or reward: MCTS selects children with UCB (C=1.5). Safety reward is a GPT-4o assessment of malicious-intent detection conditioned on the source human safety category and policy; helpfulness reward compares a node with an LLaVA-CoT reference and is back-propagated. Same-level paths form a DPO pair when the chosen cumulative reward exceeds the rejected one by epsilon and meets theta.
Terminal predicate: A DPO preference is admitted only when a same-level path has Q(chosen) ] Q(rejected) + epsilon and Q(chosen) ]= theta; the paper reports epsilon=0.4 and theta=0.8. Pairs may be non-terminal because collection spans all four reasoning levels.
Generator: At each MCTS node, PRISM-CoT samples k candidate next reasoning steps conditional on the partial structured trace, image, and query.
Filtering rule: Form same-level DPO pairs from paths whose cumulative rewards differ by more than epsilon and whose chosen path reaches theta. The official generation code implements chosen/rejected records with scores, terminal flags, and visit counts, but the released HF DPO schema exposes only messages, rejected_response, and images.
Sampling protocol: Paper Appendix F: 500 benign + 1,500 malicious image-text pairs; k=3 children/node; at most 200 iterations/tree; epsilon=0.4; theta=0.8. The released MCTS config additionally sets temperature 0.8, top_p 0.9, top_k 50, max_tokens 2048, max_depth 5, seed 42, and UCB c=1.5; these are code defaults, not asserted as a complete immutable reproduction manifest.
Inference budget: For the training MCTS, maximum 200 iterations per tree and three candidate children per node. For test-time scaling, the paper measures a relative candidate-comparison budget; the released TTS configuration defaults to beam_width 5 and num_candidates 8, but these settings are distinct from the MCTS data-generation budget.
