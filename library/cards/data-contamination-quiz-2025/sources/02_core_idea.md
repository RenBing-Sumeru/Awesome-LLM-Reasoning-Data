DCQ builds five-option questions from one original record, four word-level perturbations, and a none-of-the-above choice. A Bias Detector Quiz first finds positions the model selects less than chance; Bias Compensator Quizzes place the original in those positions and permute it, then use the best adjusted performance to bound detected verbatim contamination. The official Apache-2.0 repository releases implementation, input CSVs, intermediate results, and per-setting reports, rather than a new broadly licensed benchmark corpus. An interval rather than a point estimate retains uncertainty from position bias and random choice, distinguishing not detected from proven absent.
