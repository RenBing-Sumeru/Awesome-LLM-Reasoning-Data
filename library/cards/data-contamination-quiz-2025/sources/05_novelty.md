Replication approaches prompt a model to continue a leaked string, but their free-form output is sparse and readily blocked. DCQ changes the observation: the model makes a single-letter recognition choice among near-semantic twins. Unlike a plain multiple-choice test, it first measures position bias without any correct answer, inserts originals only into non-preferred positions, and permutes them to avoid both over- and under-estimation. The contribution is this black-box measurement contract, not access to a model's corpus. Single-letter output also reduces the need to reproduce copyrighted text; this is an interface design, however, and does not remove uncertainty in variant quality or recall triggering.
