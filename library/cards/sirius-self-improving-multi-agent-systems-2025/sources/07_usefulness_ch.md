对构建/开放发布轨道而言，SiriuS 是 outcome-selected role data、privileged critique、regeneration、downstream replay 与跨协作/竞争 graph 迭代 role SFT 的可复用蓝图。

可复现发布应为每个 episode 和 role record 保存 source ID/revision、graph/prompt version、predecessor context、outcome、selected repair role、critic feedback、rephrase 前后消息、successor replay、reward、iteration、rejection reason 与 fine-tune binding。失败与未修复轨迹也应可审计。

在这些工件公开前，仓库仅支持 recipe study 与 code inspection，不能复用所称 experience library。报告提升不能认证 intermediate reasoning、污染缺失、许可或可复现性。
