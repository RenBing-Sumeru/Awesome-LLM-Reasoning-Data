GUI-agent data must align an abstract goal with a sequence of observations, intermediate intentions, and executable actions in a changing interface. Instruction-first collection is expensive when humans author and demonstrate full episodes; model-driven variants can propose tasks that are impossible in the current state, cover only familiar functions, or drift from the goal during execution.

OS-Genesis treats the environment as the source of task evidence. Its target object is a multimodal GUI episode containing a high-level instruction, step-level low-level instructions, actions, and states represented by screenshots and accessibility trees. Mobile and web experiments use virtualized environments, including AndroidWorld-style Android apps and WebArena websites. The public mobile Hugging Face release is a derived SFT surface rather than a one-row-per-episode archive: it currently exposes one `train` split with about 51.1K rows and fields `id`, `image`, and two-turn `conversations`.

This distinction matters for audit. The paper's main controlled comparison samples 1,000 trajectories, while the repository publishes separate mobile, web, and benchmark-specific training links plus raw state-action-state triples. Row counts, episodes, and experimental trajectories are therefore different units and should not be conflated.
