The paper's novelty is to make test-time scaling a first-class serving problem. Many reasoning papers specify how to spend extra inference computation but abstract away the irregular workload produced by verifier-guided trees. FastTTS identifies a common execution substrate across several such methods and optimizes the idle slots, memory placement, and prefix locality that this substrate creates. The result is not merely a faster decoder; it is a system tailored to the alternating generate-score-prune structure of reasoning search.

Speculative Beam Extension is particularly distinctive because it spends otherwise idle GPU capacity on future computation while preserving the original search semantics. The combined design connects algorithmic quality with systems metrics through goodput: tokens on paths that will be pruned should not be valued like tokens contributing to a final solution. This framing gives practical weight to latency, cache behavior, and multi-model memory allocation as dimensions of test-time scaling rather than implementation details after the fact.
