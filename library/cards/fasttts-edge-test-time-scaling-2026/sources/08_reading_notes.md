Read the system contribution together with the accuracy constraint. The paper is not claiming that speculative generations are intrinsically better reasoning; it claims they can turn waiting time into useful work without changing the verifier-guided search decision. Its reported goodput is therefore more informative than raw throughput. When comparing it with another serving result, first check whether both systems use the same search width, verifier, memory limit, batching policy, and definition of latency; otherwise a systems gain can be mistaken for a change in the amount or quality of reasoning compute.
