The calibration reward still relies on answer correctness and a task-specific reference-accuracy tag, so it is easiest to reproduce where answers can be checked automatically. A one-to-ten verbal confidence report can be prompt-sensitive, and the stopping threshold may not transfer when model, task mixture, serving policy, or error cost changes. The paper says code, data, and models will be released but the checked version provides no public artifact URL; reproduction should therefore wait for the release and remeasure both calibration and real wall-clock cost.
