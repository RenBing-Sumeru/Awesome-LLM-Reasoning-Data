The core proposal couples Correctness and Confidence Calibration Reinforcement Learning, or C3RL, with Confidence-based Adaptive Scaling, or CAS. C3RL asks a model to emit an answer and a one-to-ten verbalized confidence value. Its reward keeps ordinary answer correctness, rewards confidence that agrees with correctness, and uses a reference-accuracy tag so that calibration is not improved by simply becoming cautiously wrong.

CAS consumes that calibrated output at inference time. After each sampled response, it updates the set of candidate answers and their confidences, then either stops and returns the most confidence-weighted answer or pays for another sample. Thus the object being scaled is a sequence of answer-confidence records, and the allocation decision is grounded in a signal that was explicitly trained to represent correctness likelihood.
