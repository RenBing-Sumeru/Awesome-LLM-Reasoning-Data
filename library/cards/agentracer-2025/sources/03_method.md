The paper begins with 4,655 raw trajectories: 2,170 coding, 1,185 mathematical, and 1,300 general-agentic episodes produced by MetaGPT, AutoGen, Smolagents, AgentPrune, AFlow, and OWL-Workforce. Section 5.1 names MBPP+, KodCode, Blackjack, GAIA, MATH, and GSM8K, whereas Appendix Table 3 additionally lists HotpotQA; record-level task/framework provenance is not released, so this six-versus-seven benchmark-name inconsistency cannot be resolved from the public file.

The construction pipeline is `benchmark task -> framework rollout -> successful/failed trajectory -> DeepSeek-R1 correction or mutation proposal -> environment replay -> binary outcome-flip filter -> responsible-agent/decisive-step pair`. In the failed branch, candidate corrections are tested in step order and the earliest replayed success is kept. In the successful branch, `K` injection points are randomly sampled and the first mutation that replays to failure is kept. The authors report 1,288 coding, 630 math, and 558 agentic labeled pairs, or 2,476 total, followed by a 9:1 split with 266 test items (Appendix Table 3). `K`, seeds, retry rules, replay-attempt counts, ambiguous multi-cause handling, and per-source yields are unknown.

AgenTracer-8B starts from Qwen3-8B and is optimized with online GRPO on `verl`. The paper reports batch size 32, eight candidate rollouts per item, learning rate `1e-6`, eight H100 80GB GPUs, no KL term, and a dynamically decreasing clipping bound. A strict format gate requires think/answer tags and `agentID | stepID`; malformed output receives zero reward. Otherwise reward is a 0.5/0.5 mixture of exact responsible-agent accuracy and a Gaussian step-distance term with sigma 1 (Paper Section 4.2 and Section 5.1). Total steps, sequence/context length, sampling temperature, exact Qwen3 revision, tokenizer, seed bundle, checkpoints, and API/compute cost are undisclosed.

The released artifact is not the training corpus. At commit `bc6bcd94c2e18f62d6712ca70ba268f6684b894f`, `tracertraj-code-test.parquet` contains 127 unique rows with no nulls across its seven top-level columns; histories contain 2-151 items, 2,642 items in total, and only `assistant` roles in this subset. The paper reports 147 coding-test rows. The public rows omit source framework/version, construction branch, correction/mutation, replayed trajectory, terminal output, split, seed, and keep/drop reason.

The repository describes a minimal MetaGPT coding pipeline. Its executable setup needs Python, Node.js/pnpm, an editable MetaGPT install, EvalPlus/KodCode assets, API keys, and local task workspaces. KodCode evaluation is implemented, while generic or MBPP+ evaluation paths are incomplete or placeholder-like; the other five paper frameworks are absent. Reproduction must pin the audited commit, external model/API snapshots, framework/evaluator versions, reset semantics, tool state, task snapshots, and dependencies, none of which are bundled as a paper-scale replay manifest.
