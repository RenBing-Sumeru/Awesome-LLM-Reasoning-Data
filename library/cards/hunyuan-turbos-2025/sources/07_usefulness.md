For `frontier_reports_data_disclosure_ledger`, Hunyuan-TurboS is useful precisely because its disclosure is substantial but not open. The report permits a detailed stage table: base pre-training; annealing and context extension; 3M SFT; teacher-generated adaptive traces; deliberation-driven SFT additions; GRM preference labels; executable-code construction; Stage I reasoning GRPO; Stage II general GRPO; and evaluation. Each row can record its data object, generator, feedback contract, disclosed scale, official artifact, and unknowns.

Data builders can reuse the structural ideas without claiming to reproduce Tencent's corpus. Useful patterns include separating reasoning and non-reasoning SFT, retaining failed attempts for adaptive supervision, mapping each domain to an appropriate verifier, keeping preference labels distinct from RL prompts, maintaining executable environments for code, reporting per-stage counts, and documenting dynamic prompt filtering. A stronger implementation should also retain source IDs, rights, model revisions, generation settings, all candidates, rejection reasons, reward vectors, and run membership.

Auditors can test every ledger independently. For data, ask for immutable manifests and overlap accounting. For feedback, evaluate GRM and Answer Consistency Model calibration and stratify sandbox failures. For RL, request rollout groups, per-component rewards, and discarded prompt histories. For artifacts, inspect whether a repository contains runnable code, whether a model host contains parameter shards, and whether a demo only calls an external service. For evaluation, reproduce stated settings without treating the scores as data-quality labels.

The Card also prevents an important terminology error. Teacher-generated adaptive traces are disclosed, but a separately named final-model distillation stage and distillation-only data total are not. Similarly, access to `hunyuan-turbos-latest` through a service does not constitute open weights. Preserving those boundaries makes the report useful for comparative frontier-disclosure analysis.
