The strongest evidence is the official arXiv v3 report. It supports the 16T pre-training figure, 300B annealing stage, 30B and 20B context-extension stages, 3M SFT count, adaptive-teacher procedure, deliberation loop, about 200K human preference annotations, more than 800K executable code samples, 300K Stage I RL records, 160K Stage II instructions, 16-subtopic reward system, more than 30 scoring services, and RL temperature 1.0. These are report-level disclosures, not a released record inventory.

Tencent's official GitHub repository verifies a project surface and mirrors the technical report. Its checked root contains `README.md`, `Hunyuan-Turbos_Report.pdf`, and `Figures/`; it does not contain training code, model files, datasets, configuration files, or a license file. The official repository therefore supports citation and report availability, not code or weight release.

Tencent's verified Hugging Face organization hosts `tencent/hunyuan-turbos` as a public Space. Its small application calls Tencent's hosted Hunyuan API. The Space is operational evidence of a service demo, not a model repository: it does not expose Hunyuan-TurboS parameter shards, tokenizer files, a model card, or training data. Tencent Cloud documentation also lists `hunyuan-turbos-latest` as a hosted model service. Service access must not be described as open weights.

The report presents LMSYS Chatbot Arena results, a 77.9 percent average across 23 automated benchmarks, and a 6,000-prompt token-efficiency evaluation. Those results support claims about model behavior under the reported evaluation conditions. They do not verify record-level provenance, rights, reasoning validity, judge calibration, sandbox reproducibility, contamination controls, or the quality of unreleased data. The report does not provide controlled ablations that allocate the final behavior to every SFT, deliberation, reward, or RL component.
