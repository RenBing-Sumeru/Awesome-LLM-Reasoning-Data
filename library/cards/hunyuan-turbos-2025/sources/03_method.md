Pre-training is disclosed at stage level. Raw, varied-format sources undergo URL-level filtering and deduplication, block pruning, topic classification, text extraction, domain-specific STEM and code extraction, heuristic filtering, critique-model scoring, mixture modeling, and global semantic deduplication. The model is reported as trained on 16T base pre-training tokens. A subsequent annealing phase uses 300B tokens drawn from high-quality pre-training data, code, mathematics, STEM, instruction-following data including long reasoning traces, and other synthetic samples. Context extension then uses 30B tokens at 32K and 20B at 256K, with a 3:1 short-to-long ratio. Source names, mixture weights, record counts, dates, and rights are unknown.

SFT comprises 3M reasoning and non-reasoning samples. Mathematics comes from educational sources and uses generative reward models and verifiers; code converts open-source code into instructions and applies critic filtering and sandbox execution; logic mixes public or licensed sources with synthesis and tiered model or expert validation; science uses a reference-matching verifier; multilingual data uses augmentation, instruction evolution, back-translation, and human experts. Other domains include creative writing, complex instruction, role play, knowledge QA, multi-turn dialogue, finance, legal, medical, and nearly 1,000 safety categories. Domain proportions, exact sources, licenses, and accepted or rejected records are not released.

Adaptive long-short data generation retains correct Hunyuan-Base short responses. Failed responses are passed to Hunyuan-T1 for repeated continuation until a correct answer appears; all failed attempts and the correct response form the teacher target. Adaptive RL samples different reasoning depths, uses online rejection sampling to estimate difficulty, and applies a length penalty so equally correct shorter traces receive higher reward. Candidate counts, stopping caps, correctness verifier, and decoding settings are unknown.

Deliberation learning compares Hunyuan models on a curated training split, aggregates multi-dimensional Hunyuan-TurboS-based judge scores, and uses human experts to define weakness profiles and add targeted SFT batches. GRM training samples paired responses from multiple Hunyuan-TurboS checkpoints; humans label about 200K high-confidence pairs with reported agreement above 93 percent, and candidate order is swapped to reduce position bias. The annotation rubric, sampling frame, adjudication, and released pairs are unavailable.

The General Reward System includes reference-conditioned GRM, optional GRM-CoT, an Answer Consistency Model, a tool-using critic, a 36-language sandbox on a distributed CPU cluster, domain rules, and score fusion. More than 800K executable, unit-tested code samples are reported; six mainstream languages contribute 100K each, and long-tail languages contribute 10K each. The relation between these constructed code samples, SFT records, reward training, and RL prompts is not fully mapped.

Stage I GRPO uses 300K reasoning records mixed as Code:Mathematics:Logic-and-Science = 2:2:1. Stage II uses 160K general RL instructions and retains 10 percent Stage I reasoning data. The implementation uses token-level GRPO, approximate K3 KL clipped to [0,10], Best-of-N loss only for positive-advantage samples, dynamic sampling, temperature 1.0, removal of consistently solved or failed prompts and zero-advantage samples, and group reward adjustment. Learning rates, group sizes, complete rollout counts, reward weights, and checkpoint schedule are unknown.
