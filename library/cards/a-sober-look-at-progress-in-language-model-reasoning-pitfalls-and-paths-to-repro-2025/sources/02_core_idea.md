The contribution is an audit surface for mathematical-reasoning progress: a fixed evaluation protocol exposes how much an apparent gain depends on evaluation choices rather than a model change. The paper standardizes seeds, model-specific decoding, prompt templates, answer matching, and the execution stack, then contrasts RL and SFT variants on shared benchmarks. Its released Sober Reasoning dataset contains 65.6k CSV evaluation-log rows with model, benchmark, seed, decoding, accuracy, and runtime fields (MIT); it supports evaluation analysis, not SFT or RL training data.
The feedback contract is deterministic answer matching plus repeated-run uncertainty reporting, so a record is evidence about a configured evaluation run rather than a label of intrinsic model quality.
This makes the Card most useful as a reproducibility and comparison reference.
