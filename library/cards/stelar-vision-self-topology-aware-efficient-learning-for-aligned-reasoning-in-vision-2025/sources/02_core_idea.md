STELAR-VISION makes the suitability of a reasoning topology an explicit supervision signal rather than treating every problem as chain-of-thought. Its TopoAug pipeline generates chain-, tree-, and graph-structured responses, labels response correctness and topology-level effectiveness, and uses these records for supervised and preference-based post-training.

The authors release `STELAR-topo_vision_reasoning_preference_123k`, a 123K visual-reasoning preference dataset intended to teach models which topology produces more accurate and efficient reasoning for a given image–question pair.
