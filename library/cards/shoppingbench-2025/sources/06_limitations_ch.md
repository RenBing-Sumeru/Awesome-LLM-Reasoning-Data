最强局限是来源和稳定性。sandbox 基于真实商品文档，因此复用前必须审计再分发权利、商品新鲜度、重复商品、过期属性和区域 marketplace 假设。README 记录了大型压缩商品文件，但本卡片尚未解决许可证和数据权利细节。

评测也会因工具链而漂移。商品搜索索引构建、外部 web-search provider 行为、模型 API 版本、动作格式、重试策略和评测器实现都可能改变分数。Knowledge intent 对是否允许 web search、以及检索信息的新鲜度尤其敏感。

Review 中要保留的失效模式：属性不匹配、商品缺失、约束未满足、指标问题和知识错误。划分/版本边界：比较 agent 或训练轨迹前，要固定 2,410/900 指令划分、测试 JSONL 文件、商品压缩包、搜索索引、评测器代码和运行脚本。
