Evidence for inclusion comes from arXiv API/HTML and the official GitHub repository. The arXiv API verifies title, authors, v4 date, abstract, and AAAI 2026 oral note. The arXiv HTML provides benchmark details: four grounded intent families, a sandbox with 2,746,368 unique products, 3,310 total instructions, a 2,410/900 train/test division, 17 evaluated language agents, and trajectory distillation for Qwen3-4B. The GitHub README verifies the public code path, product-document archive, test JSONL names, environment setup, rollout/evaluation scripts, and SFT/RL training entry points.

These sources are enough for L4 because they identify the paper, current title, venue/status, authors, public artifact trail, evaluation surface, data scale, and feedback metrics. They are not enough for final trust without checking repository license, product-data provenance and redistribution rights, evaluator code, split immutability, and whether the external web-search dependency changes results over time.
