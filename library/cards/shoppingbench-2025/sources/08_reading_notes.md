Read ShoppingBench as three coupled artifacts: an intent-grounded shopping task set, a sandbox/search environment over product documents, and a trajectory-distillation recipe. The benchmark value is in the feedback contract, not only in the model leaderboard.

Key facts to remember: current arXiv title is "ShoppingBench: A Real-World Intent-Grounded Shopping Benchmark for LLM-based Agents"; status is AAAI 2026 oral / arXiv; the benchmark has four intent families; arXiv HTML reports 3,310 instructions and 2,746,368 unique products; the public README lists product/shop/voucher/web test files and rollout/evaluation scripts.

Open review items: license, product-data provenance, exact evaluator edge cases, web-search dependency, split immutability, and whether trajectory distillation data can be reused without contaminating the benchmark.
