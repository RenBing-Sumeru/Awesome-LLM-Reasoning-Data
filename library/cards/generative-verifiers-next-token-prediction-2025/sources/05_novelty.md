The prior-work baseline is an outcome reward model that encodes correctness in a classifier logit or separate scalar head. LLM-as-a-Judge can verbalize a critique but is normally prompted without task-specific verifier training, while DPO uses a preference objective and reference policy to connect generation with scoring. Existing CoT and self-consistency methods already sample reasoning paths and aggregate answers. GenRM does not originate those components.

What changes is the feedback interface and the corresponding training object. Correctness becomes a normal vocabulary decision, allowing one SFT-formatted dataset to contain direct verdict targets, critique-plus-verdict targets, and correct-solution generation targets. Because GenRM-CoT emits its own rationale before the verdict, sampled verifier rationales become inference-time objects that can be marginalized by averaging conditional `Yes` probabilities. The construction recipe further pairs programmatic rationales for clean algorithmic tasks with Gemini 1.0 Pro reference-guided rationales for GSM8K, then filters by final verdict agreement.

For reasoning-data research, this is a direction signal because the reward is no longer adequately described by one scalar column: teacher identity, rationale prompt, privileged reference, retained/rejected rationale rule, candidate-label balance, model version, and vote budget can all change the learned feedback surface. The official release makes direct and rationale targets inspectable for GSM8K, which is more operational than a paper-only reward-model claim. It still does not expose training code, checkpoints, rejected-rationale logs, or an independently clarified license for generated critiques.

The paper's Best-of-N improvements are evidence about the complete verifier pipeline, not proof that language generation is universally superior or that the released records are independently correct. Before reuse, a builder should compare direct and CoT targets under the same candidates, audit reference-guidance leakage, measure calibration and correlated errors, and pin the exact repository snapshot.
