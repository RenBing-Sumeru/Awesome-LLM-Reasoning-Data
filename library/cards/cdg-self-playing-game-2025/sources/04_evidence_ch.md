在论文的 pass@1 / maj@8 / maj@32 主评测中，Llama-3.1-8B-Instruct 经 CDG-2 后，GSM8K 从 85.3 / 91.2 / 93.0 变为 86.8 / 92.0 / 93.1，MATH500 从 49.4 / 58.3 / 63.4 变为 51.7 / 60.7 / 66.0。不过第一轮并非全面提升：GSM8K 只有 pass@1 升至 85.5，其余两项下降；MATH500 三项均降至 49.0 / 56.8 / 62.2。

Qwen2.5-1.5B-Instruct 同样不是轮次越多越好。其 MATH500 从 55.4 / 58.6 / 62.9 经 CDG-1 升至 57.6 / 62.9 / 66.2，但 CDG-2 又回落至 56.1 / 61.5 / 65.6。Llama-3.1-8B-Base 先接受额外 30,000 条 imitation 数据后，MATH500 从 29.4 / 36.5 / 42.6 提升到 CDG-2 的 33.8 / 39.2 / 43.6，而 CDG-1 仍呈混合结果。

论文还评估逐步错误检测、自我纠错和长链推理，但这些实验并未隔离主 CDG 回合语料：逐步错误检测使用多条 Llama 解答和 GPT-4o 标注；自我纠错语料筛选两次作答后最终正确的轨迹并删除循环；长链语料使用 QwQ-32B-Preview 并另行过滤。因此这些结果支持更宽泛训练设计在给定设置中的效用，不能全部归因于已发布的 CDG rollout。

官方代码与论文在角色 prompt、采样次数、答案抽取、阈值筛选、固定拒绝短语和转换格式上相互印证。但 benchmark 数值变化不能证明每条 critique 都找到了真实的首个错误、每条推理都忠实、语料无污染或发布谱系完整。仓库 README 中的评测采用不同解码与 harness，也不应与论文表格混成同一组比较。
