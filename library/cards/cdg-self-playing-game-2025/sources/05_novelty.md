The distinctive supervision signal is not simply self-correction. CDG creates paired pressure in opposite directions: accept a critique when it exposes an error, but reject it when it attacks a correct solution. This turns critique discernment into a game outcome and makes both correction and resistance reusable as training data.

Unlike a process reward model, CDG does not score every reasoning step. Unlike debate with an external judge, it routes critic roles using ground-truth final-answer correctness and judges the exchange by the revised final answer. Unlike ordinary rejection sampling, it trains the agents that generate feedback as well as the agent that consumes it. Helpful and misleading critics are prompted similarly to reduce trivial style cues, though their content can still reveal the role.

The episode therefore has unusual audit value when all branches are retained: it can reveal whether a critique was accepted, whether acceptance improved correctness, and whether an adversarial critique changed a correct result. That value disappears if the release keeps only final SFT conversations without initial correctness, role, multi-sample outcomes, rejection reasons, loop, and verifier provenance.
