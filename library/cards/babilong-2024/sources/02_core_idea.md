BABILong's contribution is a scalable generator that embeds the 20 bAbI reasoning tasks into long distractor corpora so context length can be varied without changing the underlying answer contract. The core mechanism is to keep the support facts synthetic and answer-keyed while adding ordered background sentences until the requested token length is reached. Compared with single-needle retrieval, RULER-like synthetic probes, or short-context bAbI, the object requires fact selection plus chaining, counting, induction, deduction, or path reasoning. The feedback contract is answer accuracy against generated gold answers; reuse should preserve task id, length bin, background source, prompt format, scorer, and dataset version.
