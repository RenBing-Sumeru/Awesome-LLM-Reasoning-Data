AgentTuning mixes complete agent trajectories with general dialogue but keeps much of the original ReAct/JSON coupling and offers little supervision for inappropriate tool calls. Agent-FLAN changes the data decision itself: it converts traces into conversational views, decomposes four capabilities, weights them by learning behavior, and adds negative non-action targets. The direction signal is that representation and missing counterexamples can matter more than simply scaling trajectory count. The source tasks, SFT objective, ReAct traces, and ToolBench APIs are inherited rather than new.
