步骤 1——审计并对齐上游轨迹。
输入：采用 ReAct、JSON 和工具专用格式的 AgentInstruct 与 ToolBench 记录。
操作：删除格式错误记录和少样例示范；ToolBench 必须含最终答案，并删除带 DFSDT 重试前缀的样本；再把固定模板转换为多轮自然对话。
输出并进入下一步：清洗和对齐后的对话进入能力拆分阶段。
检查与停止规则：不符合思考、动作、动作参数结构或 ToolBench 完成规则的记录直接拒绝。

步骤 2——拆分能力。
输入：每条对齐后的推理和工具使用对话。
操作：分别派生推理、工具检索、参数理解和指令或格式遵循的训练视图，并只在助手轮次计算损失。
输出并进入下一步：四个能力专用样本池成为混合配比的候选。
检查与停止规则：保留上游语义和必需目标字段；不包含对应目标能力的视图不能进入该样本池。

步骤 3——平衡数据并加入负例。
输入：能力样本池，以及交叉组合“是否提供工具”和“用户是否请求工具”的查询。
操作：把推理、检索、理解按 1 比 0.25 比 0.75 加权，加入 2,000 条格式遵循样本，并构造未提供却请求工具或提供了无关工具的情形。
输出并进入下一步：形成 24,703 条记录的混合，默认由 10% ReAct 和 90% 对话格式组成，进入 SFT。
检查与停止规则：负例目标必须拒绝不存在的动作，或在工具无关时正常回答而不调用工具，否则删除。

步骤 4——微调并评测。
输入：加权混合，以及 7B、13B 或 70B 的 Llama-2。
操作：采用余弦调度做 SFT，再评测同域任务、HotpotQA、SciWorld、WebArena、T-Eval、Agent-H 和通用基准。
输出并进入下一步：得到 Agent-FLAN 检查点，以及代理表现、幻觉和规模效应的证据。
检查与停止规则：同时比较任务分数和 Agent-H 幻觉分数；论文没有给出一个覆盖全部发布内容的早停阈值。

可复现性：需要固定七个 JSONL 文件、继承的上游版本、转换模板、损失掩码、混合权重、10 比 90 的格式比例、负例提示、模型规模和 Agent-H 修订版。论文未披露上游教师成本、语义去污染结果和统一训练耗时。
