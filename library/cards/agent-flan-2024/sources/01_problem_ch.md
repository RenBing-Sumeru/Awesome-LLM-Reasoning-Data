既有代理 SFT 语料把 ReAct 或 JSON 格式与推理、检索和参数理解缠在一起，模型可能迅速记住容易的语法，却仍不会选择有效工具；这些语料还缺少“何时不应调用工具”的负例。

Agent-FLAN 把继承自 AgentInstruct 和 ToolBench 的轨迹改写为自然对话，拆分并重加权不同能力的训练目标，同时加入明确的工具使用负例。公开产物是含 24,703 条记录和七个分片的 SFT 混合，而不只是 Agent-H 评测集或新的代理运行时。

L4 事实：主来源为 ACL Anthology；正式发表于 Findings of ACL 2024，日期为 2024 年 8 月 11 至 16 日；边界是重新设计的可训练对话，而非 Agent-H 评测面；本图谱关注可审计的能力配比；数据对象包含推理、工具选择、参数、观察和负例条件；已核验正式论文、实际 JSONL、Apache-2.0 条款、规模和筛选规则后收录。
