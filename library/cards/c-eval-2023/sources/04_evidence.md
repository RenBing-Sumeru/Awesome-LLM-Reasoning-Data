The paper reports comprehensive evaluation of contemporary English- and Chinese-oriented LLMs and highlights that, in the original study, only GPT-4 exceeded 60% average accuracy. The official repository states that C-Eval includes 13,948 multiple-choice questions in 52 disciplines, and the Hugging Face dataset now exposes the benchmark records.

Instance-level evidence is the question record plus answer key; the decisive check is exact option correctness after output parsing. Aggregate accuracy is therefore auditable only if the same split, prompt, parsing rule, and release version are used. The evidence boundary is contamination: public release of questions and the later full test-set release make post-release model comparisons less clean unless model training cutoffs and dataset exposure are documented.
