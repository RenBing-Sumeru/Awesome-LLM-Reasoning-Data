1. **Collect agent outputs:** Long reports or code artefacts are collected from deep-research and coding-agent tasks with task context.

2. **Pair rubric criteria:** Task-level rubrics are decomposed into individual criteria and paired with outputs for binary verification.

3. **Annotate compliance:** Humans judge whether each criterion is satisfied and resolve ambiguity, producing 2,458 gold records.

4. **Compare judging strategies:** Judges are tested under alternative prompts, criterion batching, and majority voting; output length, batch size, and model version must be fixed.
