1. Search and select. The authors search Google Scholar, ACL Anthology, HuggingFace Papers, and arXiv with agent-evaluation keywords, then perform forward/backward citation chasing. They include new benchmarks, evaluation frameworks, or significant evaluation methods and exclude agent architectures without a distinct evaluation contribution.

2. Validate coverage. Domain experts, including creators of leading benchmarks and agent architectures, review the selected literature; conference acceptance is a quality signal, while high-impact preprints remain in scope.

3. Organize capability and domain evidence. The survey groups evaluations of planning, tool use, self-reflection, and memory, then covers web, SWE, scientific, conversational, and generalist agents.

4. Analyze benchmark design. It compares data curation, static/dynamic environment, code/tool/GUI interface, metric, and safety; terminal checks include unit tests, state matching, answer matching, or mixed criteria.

5. Map framework granularity. It distinguishes final-response, stepwise, and trajectory assessment, and compares reference-based with reference-free judging. Reproduction requires pinning the paper version and rerunning the disclosed search/selection process; repository updates and expert consultation are time-dependent.
