The central contribution is an evaluation map that links what an agent must do—planning, tool use, self-reflection, and memory—to where it acts—web, software engineering, science, conversation, or generalist settings—and to how a benchmark is constructed and judged. It treats data curation, environment, interface, metric, and safety as orthogonal design choices rather than treating all task-completion scores as equivalent.

No official downloadable dataset is released. The companion GitHub repository is a living literature index, not a benchmark, training corpus, or executable agent-evaluation package. The survey's reusable object is therefore an audit schema: record the task, stateful environment, action interface, terminal predicate, safety constraints, and related fields before interpreting a reported score or selecting a benchmark, and retain those choices in the report.
