AndroidLab's canonical source is the ACL 2025 camera-ready paper (ACL Anthology `2025.acl-long.107`, pp. 2144–2166, DOI `10.18653/v1/2025.acl-long.107`), supplemented by arXiv:2410.24024v2 and the official repository inspected at commit `4bfe108cf3883b710e8e5c6fba288161c830e504`. The work addresses two coupled problems: collecting executable Android demonstrations for instruction tuning and evaluating autonomous agents against reproducible app states and explicit success conditions.

The training data object is a manually executed Android trace. Its public description combines a task/system instruction, interaction history, an XML observation or marked screenshot, analysis/reasoning, and one function-call action; annotation also captures a screenshot and page XML before each operation. The official SFT material is described in LlamaFactory format as 726 traces comprising 6,208 XML-mode steps and 6,053 SoM-mode steps. Exact archive fields, episode IDs, assets, provenance columns, and file hashes remain unverified because `android-lab-train.zip` was not inspected record by record.

The evaluation object is separate: one of 138 tasks across nine apps, a pre-packaged AVD state, an instruction, the agent framework/model, state-action-observation history, and task-specific completion output. The suite contains 93 operation tasks and 45 query tasks. Operation outputs are state sequences; query outputs additionally include a free-form answer.

This belongs to `environment_agent_trajectory_data` because Android state, actions, observations, resets, and terminal judgments jointly define both supervision and evaluation. It does not establish that the broader 10.5K traces / 94.3K steps generated during autonomous and manual collection were all released or used for SFT, and it must not be conflated with AndroidWorld, AndroidControl, or V-Droid. The official paper, code, evaluator, and artifact pointers support a complete bilingual Card, while corpus bytes, licensing, splits, failure retention, and immutable replay remain partial.
