- The public SFT package is described but was not audited record by record. Exact files, field names, trace IDs, media/XML assets, duplicates, record provenance, Drive version, and archive hash are unknown; mutable Google Drive links do not provide immutable release identity.
- The paper and repository disagree on five versus three training epochs. Exact model revisions, optimizer, scheduler, seeds, compute, checkpoint selection, and trainer commits/configs are undisclosed, blocking an exact six-model SFT reproduction.
- No train/validation/test manifest or decontamination method is disclosed. All 726 SFT traces come from the same nine apps as the benchmark, so app-level overlap is certain; item-, instruction-, template-, state-, and task-level overlap remain unknown.
- Failed-data visibility is incomplete. About 500 positive/negative reward-model trajectories exist and self-exploration operation traces were dropped from SFT, but release counts and records for failures, infeasible tasks, skipped or abandoned traces, privacy-filtered samples, rejected expansions, disagreements, and selection decisions are unknown.
- Operation predicates are hand-coded and heterogeneous. XML omissions, localization, alternate valid states, dynamic content, app/version drift, or transient matching pages can cause false positives or false negatives. ROR counts screen change rather than semantic action correctness, and agent Finish is not evaluator success.
- Query scoring depends on GPT-4o-2024-05-13 or GLM-4, judge prompts, retries, APIs, and model behavior that can drift. A semantically valid paraphrase may be rejected or an incorrect answer accepted; immutable judge inputs and adjudication logs are unavailable.
- Fresh AVD/container reset improves isolation, but the release does not pin image or base-state hashes, complete APK/app versions, Android Studio/emulator versions, account/network state, or all setup inputs. Official macOS documentation warns that Android Studio updates may break setup, and screen-size results show geometry sensitivity.
- The repository code is MIT, but the dataset license is unknown. That code license does not establish rights for source tasks, annotations, screenshots/XML, model outputs, apps/APKs, UI content, or preloaded records. Consent, redaction, retention, deletion, compensation, and redistribution details are incomplete.
- The official repository contains a hard-coded credential-like default in evaluation code. This Card does not reproduce the value; reuse requires removal from code/history, rotation or revocation, and secret-free configuration examples.
- AndroidWorld, AndroidControl, and V-Droid are separate data and evaluation objects. Importing their counts, images, rewards, splits, or verifier behavior would create unsupported lineage and invalidate an AndroidLab audit.
