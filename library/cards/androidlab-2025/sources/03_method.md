Inputs begin with task seeds from cited academic datasets, including Android in the Wild and SNIPS, plus hand-written instructions. Undisclosed language models expand the seeds, and humans review realism, feasibility, and executability. Source proportions, expansion prompts, generator snapshots, deduplication, and accepted/rejected task counts are unknown.

The collection and selection pipeline is:

1. Autonomous and manual processes generate 10.5K traces / 94.3K steps in total. This is the broad collection pool, not the SFT set.
2. Human annotators check feasibility, learn the app, and execute tasks on physical Android phones using ADB/ADB Keyboard. The tool records screenshots, page XML, and click, swipe, or text-input operations into a trace log. Phone, Android, app, account, network, and reset versions are not pinned.
3. About 500 manually labeled positive and negative trajectories train a completion classifier; a second annotator and this reward model cross-verify collected human traces. Model architecture, checkpoint, split, calibration, threshold, and adjudication details are unknown.
4. Self-exploration operation data is removed from SFT. Feasibility review, privacy masking, cross-verification, and app membership select 726 human traces / 6,208 XML steps from the nine benchmark apps. Converting observations to SoM leaves 6,053 steps because special pages that cannot be converted are dropped.
5. LlamaFactory or Swift fine-tunes Llama-3.1-8B, GLM-4-9B, Qwen2-7B, Llama-3.2-11B-Vision, Qwen2-VL-7B, and CogVLM2. The camera-ready reports batch 32, maximum sequence length 4,096, learning rate 1e-5, and five epochs; the official repository guide reports the same learning rate but three epochs. Exact reproduction must preserve this unresolved 3-versus-5-epoch conflict rather than choosing silently.

Formal evaluation starts inside the specified app, uses greedy decoding, allows at most 25 steps with a 3-second response interval, and runs every task in a fresh cloned AVD/emulator or new Docker container that is stopped or deleted afterward. Current official configs target Pixel 7 Pro / Android API 33; code fixes geolocation and date (with a Maps.me exception). Operation tasks use UI-tree/device predicates, while query tasks use GPT-4o-2024-05-13 or GLM-4 answer judgment.

Reproduction must pin the repository commit, SFT archive and hash, Docker/AVD image digest, Android/emulator/Android Studio versions, APK/app versions, base snapshot and reset state, time/location/account/network conditions, six model revisions, trainer configs, judge prompts/API snapshots, and random seeds. Train/validation/test splits, item/template decontamination, and trace-level overlap with the 138 benchmark tasks are unknown; app-level overlap is explicit.
