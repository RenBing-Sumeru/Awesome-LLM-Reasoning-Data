FActScore asks how to evaluate factual precision in long-form model generations when a response can mix many correct and incorrect claims. The primary record is Min et al., "FActScore: Fine-grained Atomic Evaluation of Factual Precision in Long Form Text Generation," EMNLP 2023 main proceedings, pages 12076-12100, with DOI 10.18653/v1/2023.emnlp-main.741. The official GitHub repository and PyPI package release the evaluator and accompanying data paths.

The concrete evaluation object is not a whole answer label. It is a topic/entity, a generated long-form response, a list of decomposed atomic facts, evidence retrieved from a selected knowledge source, a support label for each atomic fact, and an aggregate factual-precision percentage. The default public package uses an English Wikipedia snapshot dated 2023-04-01, while the interface allows custom knowledge sources.

The decision boundary is fine-grained factuality evaluation for long-form text. FActScore is not a completeness metric, not a clinical or legal truth verifier, not a pairwise preference dataset, and not a training recipe. Its useful signal is the separation between factual precision at atomic-claim level and other properties such as coverage, helpfulness, style, or answer length.
