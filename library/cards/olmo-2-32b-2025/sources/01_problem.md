An open-weight model can link weights, code, and several dataset viewers while still leaving its full post-training path impossible to reconstruct. Auditing a 32B release requires separating the existence of released artifacts from the source allocation, synthetic-trace authoring, preference construction, reward implementation, licensing, split, and contamination evidence behind a particular checkpoint.

Ai2's OLMo 2 32B release offers a strong public release surface: it links base and instruct checkpoints, OLMo-core, pretraining and mid-training mixtures, an SFT mix, an on-policy preference mix, and an RLVR mix. The same materials leave important boundaries unresolved, especially item-level provenance, the GRPO reward/parser contract, and uniform source rights.
