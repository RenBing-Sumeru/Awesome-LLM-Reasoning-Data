The main contribution combines a verifier, retrieval supervision, and a dataset. BEq attempts bidirectional formal reduction between candidate and reference statements, reducing errors from exact match or one-way implication; it is evaluated on 200 expert-labelled statement pairs. Con-NF contains 961 natural-language–formal theorem pairs involving 1,348 research-level formal objects. A dependency parser creates retrieval training data from library topology, and RAutoformalizer conditions Lean generation on retrieved objects.
