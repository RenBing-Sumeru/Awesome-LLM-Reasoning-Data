该方法包含两层不同反馈。推理时，步骤置信度 C(step) 是该步骤生成 token 概率的几何平均，novelty N(step) 是相对已探索上下文的新 token 比例，候选分数为 C(step) + λ_N N(step)。修改后的 DVTS 将总路径预算 N 分成 N/M 棵独立子树，每层采样 M 个下一步并贪心保留最高分步骤，最后在完成答案间按整链置信度投票；这一内生分数不能验证正确性。搜索前，GRPO 使用 ground truth 校准：正确回答奖励为 1+C(R)^4，错误回答奖励为 1-10C(R)^4，整链置信度 C(R) 侧重最后 k 个步骤。因此程序化答案检查监督的是校准，测试时分支选择仍依赖策略自身的标量信号。
