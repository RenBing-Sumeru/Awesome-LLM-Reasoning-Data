The main contributions are a decoupled planning architecture and the SafeRun-RunPlanning-Benchmark. Each record describes runner ability, goals, weeks, available days, injuries, or preferences, plus structured constraints. The LLM parses soft requirements, while a constraint solver validates workout types, distance, intensity, rest, and week-to-week progression; infeasible requests return conflicts rather than unsafe plans. The data supports planning evaluation, constraint-generation SFT, and safety-verifier research, but is not clinical prescription.
