Outcome-reward RL for multimodal large language models can verify a multiple-choice answer cheaply, but a correct option does not establish that the visual perception or reasoning trajectory was correct. A trajectory that misreads an image and then guesses the right option receives the same terminal accuracy reward as a faithful solution. Dense process supervision could distinguish them, but it requires a process verifier or additional annotation.

Self-Consistency Sampling (SCS) treats this as an online rollout-construction and feedback problem. For each image-question prompt, the relevant data object includes the initial reasoning trajectory, a truncated prefix, stochastic image perturbations, resampled continuations and option answers, the set of distinct answers, accuracy reward, format reward, consistency reward, and the policy update that consumes them. The decision boundary is multimodal multiple-choice RLVR rather than general proof verification: answer agreement is a proxy for stability, not direct validation of every reasoning step.

The paper describes a filtered training mixture from M3CoT, Geometry3K, and ScienceQA. The official Hugging Face release provides prompt-answer JSONL files and an image archive, while the code repository implements training and evaluation. Those artifacts do not establish a complete release of initial trajectories, truncation points, perturbation seeds, all continuations, or per-rollout rewards, so SCS should not be represented as a fully replayable trace corpus.
