The core object is a marginal reward curve: for each prompt and each possible budget increment, estimate how much expected reward would rise if one more unit of computation were assigned. A lightweight predictor reads the base model’s hidden representation and predicts this whole vector. Allocation then chooses the highest predicted next increments across all prompts, rather than assigning the same number of samples to everyone.

This makes difficulty operational. An easy prompt may receive one inexpensive draw, an impossible prompt may receive no extra search, and a hard-but-promising prompt may receive several samples or a strong decoder. The approach applies the same idea to adaptive best-of-k reranking and to routing between weak and expensive decoding procedures, separating the allocation policy from the particular way extra compute is spent.
