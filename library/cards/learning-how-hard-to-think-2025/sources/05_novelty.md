This paper makes “how hard should a model think?” a prediction-and-optimization problem rather than a heuristic threshold. Its predictor targets marginal benefit, not only prompt difficulty or answer confidence, so it can distinguish a difficult query that extra compute can help from one that is unlikely to improve. The allocation rule explicitly couples all requests through a shared resource constraint.

The framework is also intentionally decoder-agnostic. The same learned quantity decides sample counts in search and whether to invoke a stronger procedure in routing. This establishes a reusable bridge between hidden-state probing, reward estimation, and serving-level resource scheduling, and it exposes a practical distinction between online batch-optimal allocation and independently deployable but distribution-sensitive offline policies.
