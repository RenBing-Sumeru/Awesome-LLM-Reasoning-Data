Fixed test-time budgets ignore that prompts differ in both difficulty and solvability. Spending many samples on an impossible program can waste a shared serving budget, while spending only one sample on a hard-but-solvable problem can lose an answer that a few extra attempts would find. Post-hoc difficulty estimates do not solve this because obtaining them may already cost more than the decoding they are meant to allocate.

The paper asks whether the expected marginal value of another unit of decoding can be predicted from a prompt before responses are generated. Such a prediction must support a real allocation decision across a batch or a stream: it must decide whether a prompt receives another sample, a stronger model, or only a cheap default response while respecting a fixed average compute budget.
