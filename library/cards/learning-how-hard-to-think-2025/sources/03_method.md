Training data are formed by estimating rewards at several budgets for each prompt and taking successive differences. A two-layer MLP on the final hidden state, or a LoRA-adapted base model, predicts the vector of marginal gains. Under diminishing returns, the constrained integer allocation has a greedy solution: repeatedly allocate the next unit to the prompt whose predicted next gain is largest. An online version optimizes known batches; an offline version learns bins whose allocations satisfy the budget in expectation.

The experiments instantiate this framework with best-of-k sampling and reranking, then with routing. Code uses StarCoder-15B and unit tests; math uses Mathstral-7B and a two-stage oracle verifier; chat routes between Gemma models or ordinary versus value-augmented sampling. The evaluation compares adaptive allocation with uniform best-of-k or always using the expensive decoder at matched average computation.
