SedarEval releases 1,000 open-ended Chinese queries spanning eight categories of knowledge and reasoning tasks, with a self-adaptive rubric for each question. Instead of a few generic dimensions, every rubric contains primary scoring points, secondary points, and explicit deductions. Human reviewers use these criteria to annotate responses, and a dedicated evaluator LM is then trained for automatic scoring. The main contributions are a Chinese rubric benchmark, human evaluation data with explicit scoring rationales, and an end-to-end pipeline from question-specific criteria to model-based assessment. It is therefore an LLM-as-a-judge and rubric-reward data contribution rather than merely a model leaderboard.
