Correctness and quality are metric-relative. Closed-ended scores can be distorted by answer-format parsing, while open-ended scores depend on reference length, judge prompt, judge model, and comparison baseline. Long inputs do not guarantee faithful long-context reasoning if a system uses retrieval, truncation, or task-specific prompt engineering; the leaderboard therefore asks submitters to expose these settings. The dataset is public and includes source documents from existing corpora, so contamination and license checks are needed before using it as a clean post-training or evaluation holdout. L-Eval should not be read as proving a model uses all 200K tokens unless the specific task and prediction trace show that behavior.
