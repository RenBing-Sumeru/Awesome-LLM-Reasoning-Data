The arXiv abstract and official repository report the core dataset scale: 20 subtasks, 508 long documents, and over 2,000 human-labeled query-response pairs with 3K-200K token inputs. They also report that popular n-gram matching metrics do not correlate well with human judgment for long-context generation, motivating length-instruction-enhanced evaluation and LLM judges. The repository exposes the sample schema, 20 dataset names, evaluation scripts, predictions, and leaderboard submission requirements. Instance-level evidence differs by task: exact answer match for closed-ended examples, reference-based metric or LLM/human comparison for generation examples. The evidence boundary is the metric choice; a single aggregate leaderboard number can mix exact match, GPT-4/3.5 evaluator, F1, ROUGE, prompt engineering, retrieval, and in-domain-data settings.
