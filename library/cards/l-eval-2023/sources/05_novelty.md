The prior baseline consisted of separate long-document datasets or benchmarks that either emphasized shorter contexts, narrower domains, or conventional automatic metrics. L-Eval changes the surface by combining multiple domains, 3K-200K token lengths, closed/open task groups, and explicit metric-bias analysis for open-ended long-context generation. The quality signal is the released data, loader examples, evaluation scripts, leaderboard, human-evaluation tooling, and submission metadata fields that expose retrieval, prompt engineering, and in-domain-data use. What is not new: many component datasets and metrics such as ROUGE/F1, GPT-4 judging, and human pairwise evaluation already existed. Before reuse, inspect source dataset licenses, whether data are test-only, contamination risk from public documents, context truncation policy, and the metric used for each task.
