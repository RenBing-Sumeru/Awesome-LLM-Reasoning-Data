arXiv 摘要和官方仓库报告了核心规模：20 个子任务、508 篇长文档、2000+ 人工标注 query-response pairs，输入长度约 3K-200K tokens。它们还报告常见 n-gram matching metric 与长上下文生成的人类判断相关性不好，因此提出 length-instruction-enhanced evaluation 和 LLM judge。仓库公开样本 schema、20 个 dataset 名称、评测脚本、prediction 文件和 leaderboard 提交流程。行级证据因任务而异：closed-ended 样本是 exact answer match，generation 样本是 reference-based metric 或 LLM/人工比较。证据边界在 metric choice；一个 leaderboard 总数可能混合 exact match、GPT-4/3.5 evaluator、F1、ROUGE、prompt engineering、retrieval 和 in-domain-data 设置。
