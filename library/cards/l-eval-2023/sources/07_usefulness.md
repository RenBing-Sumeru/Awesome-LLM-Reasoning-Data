Use L-Eval as a schema and audit checklist for long-context benchmark design. Preserve document id, full input, instruction list, reference outputs, source domain, declared metric, context length, model context budget, truncation/retrieval policy, prompt engineering flag, in-domain-data flag, judge model, baseline opponent, raw prediction, parsed answer, and per-task score. It is useful for comparing long-context systems only when closed-ended and open-ended metrics remain separated.
