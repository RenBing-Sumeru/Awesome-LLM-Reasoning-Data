L-Eval 要解决的是长上下文语言模型如何评测：模型需要阅读数千到二十万 token 的输入，而不只是找短 needle。主要来源是 arXiv:2307.11088、OpenLMLab 官方仓库、L-Eval 项目页和 Hugging Face 数据；官方仓库标注 ACL 2024 Outstanding。评测对象是长文档，加上一组 instructions/questions 以及 ground-truth 或 reference outputs。benchmark 分 closed-ended 和 open-ended：前者较适合 exact-style metric，后者作者认为 n-gram 指标有长度偏差，应补充 length-instruction-enhanced evaluation 和 LLM/人工 judgment。收录边界是 long-context evaluation surface，不是训练语料或 retrieval 系统。
