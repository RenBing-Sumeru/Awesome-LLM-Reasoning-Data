Inputs are tasks from 26 public academic benchmarks executed through 15 single- and multi-agent frameworks. Appendix F.2 identifies GPT-4.1 and Gemini 3 Flash as the primary base models, but says the model varies by agent/benchmark pair. The collection logs task inputs, agent messages, observations, intermediate artifacts, and terminal answers, then applies the official source evaluator when available to partition runs into successes and natural failures. Counts for these two source partitions are not disclosed.

Natural failures and successes have different roles. PhD-level reviewers inspect sampled natural failures, identify the earliest decisive errors, consolidate recurring patterns into 18 modes across six families, and create per-agent/benchmark applicability profiles. Natural failures are not benchmark instances. Successful runs are injection seeds. For a chosen plausible failure mode, the sampler removes invalid steps and applies position preferences—for example, planning earlier and verification after evidence collection—but exact distributions, attempts per seed, retries, seeds, and thresholds are unknown.

Injection has two model calls. An unnamed frontier model reads the task, reference answer, seed context, and target mode and generates a specific adaptive injection prompt. The original base agent receives that prompt in its step call and produces the erroneous action. The framework replays all earlier actions, substitutes that single action, then lets the original system continue. Static factual tool outputs are returned from a synchronous SQLite cache keyed by the SHA-256 of canonicalized parameters. For page visits, only raw page content is cached; the secondary LLM summary can vary. Browser/code state is rebuilt by replaying actions through fresh Playwright/code-executor instances, and an exception or detected divergence aborts the attempt. Appendix F.3 reports that Bing DOM rotation accounts for 89% of `input_text` replay failures.

Selection retains only post-injection continuations that the task evaluator marks failed. Additional filters remove construction-prompt leakage and cases where the correct answer was already salient before injection. The final reported output is 12,326 failed traces spanning 51% text, 42% image, 7% video and 76% single-agent versus 24% multi-agent. Mean/max length is 7.5/50 steps, with 1,139 words per trace and 152 words per step; multimodal traces average 1.3 images. The paper does not publish successful seeds, natural failures, failed injection attempts, post-injection successes, replay aborts, rejected records, exact rules, or a row schema.

Evaluation prompts 10 frontier models with all-at-once, step-by-step, or binary-search protocols. The default shows the complete trace without the reference answer and asks for Agent Name, Step Number, Error Mode, and a short reason; all traces fit native model context windows without truncation. There is no training optimizer. Reproduction requires the 12,326 rows, source task IDs/versions, model snapshots, taxonomy profile, prompts, cache, environment snapshots, evaluator versions, filter ledger, prediction files, and subset manifests. None except the paper-level description is currently public. (Paper §§3–4; Tables 2–3; Appendices F, J, K.)
