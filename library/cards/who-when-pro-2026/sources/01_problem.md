Who&When Pro is a 2026 arXiv benchmark paper by nine authors for automated failure attribution in AI agents. It asks three linked questions about a failed execution: which agent or component caused the failure, which step was the earliest decisive error, and which error mode best describes that cause. The predecessor Who&When contains 184 text-only traces from 127 agentic systems; Who&When Pro targets broader scale and modality coverage because failures in stronger agents are harder to localize and a terminal wrong answer alone does not identify what should be repaired. (Paper §1; Table 1.)

The paper reports 12,326 failed trajectories drawn from 26 public source benchmarks, nine task categories, 15 agent frameworks, 18 error modes, and text, image, and video. A benchmark instance is described as a source task and reference answer, a full ordered execution with agent messages/actions, tool or environment observations and intermediate artifacts, plus labels for responsible agent, decisive step, and one error mode. It belongs to Environment and Agent Trajectory Data because the attribution target is attached to a state-action episode and depends on the source environment's terminal evaluator, not merely on a standalone answer.

The boundary is equally important. Who&When Pro evaluates diagnosis of already failed traces; it does not train a policy, PRM, reward model, or RL agent, and it does not establish that attribution labels improve self-evolution. The official repository at inspected commit `db3946cae6895c8056b9b482c283fc3949a6654f` contains only `README.md` and one illustration. Its README says evaluation code and benchmark data are not public yet, while the project page's Data button points only to `#`. Thus the paper-scale 12,326 trajectories must not be confused with the public release, which currently exposes zero benchmark rows, zero successful seeds, and zero evaluator scripts. This Card is L4-ready as a reading and audit artifact, not as evidence of a reusable dataset release.
