The closest baseline is failure attribution from naturally failed or synthetically corrupted agent traces. Who&When uses 184 text traces and expert labels; MAST, TRAIL, AgentErrorBench, AEGIS, AgenTracer, and AgentRx expand scale, taxonomy, or attribution methods but remain text-only in Table 1. AEGIS reports 9,533 injected failures, while Who&When Pro reports 12,326 across text, image, and video and includes both single- and multi-agent topologies.

The concrete change is replay discipline. In reroll-based injection, stochastic behavior can diverge before the intended corrupted step, so the injected location is not necessarily the earliest difference from a successful run. Who&When Pro reconstructs a successful prefix, substitutes exactly one action generated by the original base agent under an adaptive error prompt, and retains the resulting episode only when the task evaluator flips to failure. This joins a contrastive success anchor, environment replay, a controlled intervention, a terminal outcome, and agent/step/mode labels in one construction contract.

The components are not individually new. Public benchmark tasks, ReAct and multi-agent frameworks, tool caching, browser replay, LLM-generated error prompts, failure taxonomies, official task evaluators, LLM attribution prompts, and exact/macro-F1 metrics all predate this paper. The contribution is their composition at multimodal scale and the attempt to strengthen label provenance from “a model says this step failed” to “this is the first deliberately changed step relative to a successful execution.” It remains controlled synthetic causality rather than proof of natural causal necessity.

This matters for reasoning data because it introduces an intermediate feedback surface between coarse terminal failure and free-form critique. A future released row could support attribution evaluation, failure-conditioned retrieval, data filtering, or supervised diagnosis. Before such reuse, one must verify the successful-seed link, injection action, task evaluator, replay state, rejected attempts, human corrections, source-task overlap, and rights. Without those objects, the novelty can be studied as a recipe and audit target but not treated as an open training corpus.
