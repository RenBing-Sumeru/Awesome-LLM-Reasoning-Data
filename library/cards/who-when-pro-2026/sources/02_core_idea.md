The contribution is a controlled way to turn a successful agent episode into a failed episode whose first changed action is intended to be the decisive-error label. For a successful seed trajectory, the pipeline chooses an eligible step conditioned on a plausible failure mode. An unnamed frontier model writes an adaptive injection prompt, that prompt is patched into the original base-agent call, and the base agent emits the corrupted action in its own style. The system then resumes from the same agent and records the downstream consequences. A trajectory is kept only if the source task evaluator now marks it failed.

Warm starting is the key mechanism. Earlier injection pipelines can rerun from the beginning, so stochastic actions may drift before the intended injection and make causal attribution ambiguous. Who&When Pro instead replays the successful prefix before substituting one action. Static search, page, and image calls are served from a SHA-256-keyed SQLite cache; stateful browser and code actions are re-executed with fidelity checks that abort divergent attempts. Reverting the substituted action recovers the known successful seed under the construction, so its producing component and coordinate supply the responsible-agent and decisive-step labels. One of 18 taxonomy modes supplies the failure-class label. (Paper §3.3; Appendix F.3.)

The feedback contract is mixed and episode-level. Source benchmark evaluators decide whether an injection changed success to failure; the released description does not provide one uniform evaluator or scalar reward. Attribution models are then scored against constructed labels with responsible-agent accuracy on multi-agent traces, exact decisive-step accuracy, error-mode macro-F1, and Joint accuracy requiring all three. The evaluator can observe terminal task success and the attribution prediction, but it does not prove that the injected action is the unique semantic root cause for a human reader. Three-annotator validation partly audits this gap: majority approval is 94% for step and 90% for both agent and error family, with 2% judged to have no clear decisive error.

Relative to Who&When's small expert-curated text set and AEGIS-style reroll injection, the direction signal is not simply more traces. It is the combination of multimodal full episodes, exact-prefix replay, intervention-conditioned labels, and explicit agent/step/mode evaluation. Its strongest unresolved question is whether those labels and environments remain faithful outside controlled single-error interventions; the unavailable rows and replay assets currently prevent that audit.
