该工作的贡献不只是把 MCTS 用在测试阶段。AlphaMath 把搜索树变成迭代式数据构造底座：终局答案检查产生正、负解题路径；MCTS backup 把稀疏结果与当前价值预测转为步骤结束位置的回归目标；联合训练的策略/价值模型再生成下一轮数据。失败路径不再在 rejection 后被丢弃，而是作为价值模型的一等监督对象保留。

与从人工或 GPT-4 获取完整 rationale 的流程相比，外部语义监督被缩减为题目与最终答案；与普通 rejection sampling 相比，它保留中间搜索统计，并用成功和失败路径共同训练价值头。但与传统 process reward model 相比，它的目标不是独立标注的步骤正确性，而是特定策略、树策略、评估器和有限搜索预算下的状态期望回报估计。

开放发布的贡献也相应有限，但仍有审计价值。第三轮数据集保留所选路径的步骤、先验、Q 值、深度、来源 ID 与最终答案参考，使一些普通 SFT `prompt`/`response` 发布无法支持的检查成为可能。不过，它没有保存全部候选、visit count、父子指针、选择历史或前两轮数据。因此，其新意应理解为“搜索衍生监督配方 + 部分所选轨迹发布”，而不是可完整重放的搜索日志。
