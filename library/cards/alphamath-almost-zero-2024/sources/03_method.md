The main construction starts from DeepSeekMath-Base-7B with a randomly initialized tanh value head that shares the model body with the token-prediction head. It runs three rounds over the same 14,973 question-answer pairs:

1. In round 1, the policy receives two ReAct demonstrations randomly chosen from a pool of 20 and emits Thought/Action/Action Input/Observation steps. From round 2 onward, it uses the paper's zero-shot XML step format.
2. For every question in every round, the system constructs ten MCTS trees. The reported configuration uses `cpuct=1.25`, at most five child expansions per node, at most 40 simulations per tree, maximum depth 8, and generation temperatures between 0.6 and 1.2; the exact temperature assigned to each construction run is not disclosed (Appendix C.3, Table 6).
3. Selection uses a PUCT variant combining the current Q estimate with the length-normalized language-model prior. Expansion samples diverse next steps. A terminal node is evaluated by final-answer correctness; a nonterminal leaf is evaluated by the value head. Backup averages those evaluations into edge Q values.
4. Generated solutions are deduplicated. Paths with code errors in every step are removed even if their final answer happens to match. Incorrect paths are otherwise retained for diversity. Correct paths are prioritized in three tiers: code output consistent with the predicted answer, code correct at every step, and remaining answer-correct solutions (Appendix Algorithm 3).
5. The pipeline samples at most four correct and four incorrect paths per question and round, producing an approximately 1:1 mixture. The paper reports 57,000–59,000 positive paths per round. Correct paths receive language-model loss; all sampled paths receive value regression at step-end tokens. Training uses AdamW for ten epochs with batch size 1,024, learning rate 4e-5, cosine scheduling, 3% warmup, and zero weight decay; the paper text and Table 6 disagree on the default value-loss weight, reporting 0.01 and 0.1 respectively, so that setting requires resolution.

After training, the next checkpoint builds the next round's trees. The official release is specifically the selected round-3 training set generated from the round-2 checkpoint. The Hugging Face revision checked for this Card contains one 115,551-row split; it is not a release of all raw trees, all rejected paths, or all three rounds.

At inference, the value model can guide full MCTS or step-level beam search. The latter samples `B2` children from each retained state and directly ranks new states by the value prediction, avoiding MCTS backup. This inference use is downstream from the construction recipe and should not be confused with additional label verification.
