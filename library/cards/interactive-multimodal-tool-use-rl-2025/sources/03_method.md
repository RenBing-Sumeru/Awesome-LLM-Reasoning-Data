Construction begins with APIGen-MT conversations. GPT-4.1 infers a user specification and ground-truth tool calls; for retail, the synthesized instruction and a harder rewrite are chosen with 50/50 probability. The resulting training set contains about 3,000 retail tasks. Mixed-task RL also selects medium-difficulty DeepScaleR problems with integer answers, after the authors considered GSM8K, DeepScaleR, and DAPO-MATH-17K. Exact task IDs, stage-by-stage retained counts, and the DeepScaleR sample count are unknown (paper §3.1; §4.1; Appendix “Training Data”).

The sandbox starts from tau-bench seed data in a SQLite backend with `Products`, `Orders`, and `Users`. REST endpoints are registered as MCP tools. A GPT-4 ReAct user simulator produces text turns; SeedTTS converts those turns to audio for speech episodes. The agent alternates reasoning/tool-call sequences with user or tool observations until `##STOP##` or the 30-turn cap (paper §2.1, Fig. 2; §2.2).

The rule-based terminal verifier inspects successful write operations and compares tool-call arguments with ground-truth annotations. Complete match yields `R(tau)=1`; any mismatch yields 0. TARL then asks GPT-4.1 to score every turn from the policy, task instruction, ground-truth calls, and complete labeled conversation. Terminal success is weighted 10×, the single major `-1` is weighted 5×, and the remaining turn scores use `1/T` normalization so the positive process contribution is capped at 5. The paper groups totals as perfect 15, good 10–15, good-attempt 0–5, and failed -5–0 (paper §3.2; Appendix judge prompt).

Qwen3-8B is the text policy. Text training alternates retail and DeepScaleR math tasks. Qwen2.5-Omni-7B is the speech-capable policy; instead of SFT, it first receives 30 GRPO warm-up steps on simplified tasks with more explicit instructions, then alternates math, text-only retail, and retail with speech user responses. Batch size is 128, formed from 32 tasks and four rollouts each. The reported settings include temperature 0.7, top-p 0.95, prompt length 4096, response length 1024, actor learning rate `1e-6`, critic learning rate `1e-5`, and training that usually plateaus after 200–300 steps (paper §4.1; §4.3; Appendix “Training Details,” Table `tab:hyperparameters`).

Training uses `verl` and `RL-Factory` with GRPO, PPO, and RLOO comparisons. Directly placing turn rewards on each turn's final token destabilized PPO; the best variant sums TARL into a trajectory reward and assigns it across policy tokens, masking environment tokens. Reproduction must pin the SQLite seed/database state, REST and MCP schemas, GPT-4/GPT-4.1 and SeedTTS versions, prompts, split manifests, random seeds, and rollout retention. None of those paper-specific implementation artifacts is currently linked as a release (paper §2.2; §3.2; §5.1; `paper.tex` commented artifact placeholders).
