This evaluator audit measures cross-language self-consistency, not only one-language reference agreement. Average Fleiss' Kappa is about 0.3, particularly poor for low-resource languages; neither multilingual training nor scale directly fixes it. No official downloadable dataset is identified.

It uses parallel instances so content is fixed while language changes, treating each language verdict as a rater. Five task datasets cover question answering, mathematical QA, translation, summarisation and dialogue; models receive binary and graded judgments. The benchmark surface is therefore language-conditioned verdict variance, not a normal accuracy leaderboard. The authors also test a majority-vote ensemble of open models. The paper identifies no official downloadable package for the assembled evaluation data or prompts.
