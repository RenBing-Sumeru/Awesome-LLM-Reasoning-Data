Read the result as an argument for measuring verifier diversity, not just verifier count. The central table should separate candidate-generation calls from each verifier call and report how agreement, disagreement, and error correlation change as agents are added. A headline best-of-N score is insufficient if the panel has more information or more compute than the baseline. The most informative failure case is a confidently wrong consensus: it reveals whether the panel adds independent scrutiny or merely repeats one latent preference.
