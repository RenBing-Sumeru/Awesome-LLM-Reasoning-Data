Use this work to design an ablation in which generation and verification budgets are independently controlled. Hold the candidate pool fixed, add one aspect verifier at a time, inspect score correlation and marginal accuracy, and compare against a single verifier receiving the same total token or call budget. It is useful for tasks with identifiable complementary checks, such as factual support, calculation, or instruction compliance. It is less suitable when no credible aspect decomposition exists or when verification latency dominates the product requirement.
