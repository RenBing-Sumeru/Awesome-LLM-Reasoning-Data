1. **定义数据对象。** 输入：一项后训练收益报告。操作：判断监督记录是提示-答案对、示范、轨迹、环境交互、偏好、奖励，还是审计记录。输出：具体的记录 schema。检查：若两篇论文的基本对象不同，不能在不说明差异的情况下直接比较。
2. **恢复反馈契约。** 输入：数据对象和训练设置。操作：把反馈归为程序式、环境式或需要判断，并记录终止条件。输出：明确的正确性或效用边界。检查：注明误报、漏报和 verifier 版本。
3. **追踪构造流程。** 输入：保留的数据对象。操作：记录提示来源、轨迹作者、搜索支架、自博弈锚点、verifier 或奖励以及过滤器。输出：可复现的血缘链。检查：区分来源数据、生成轨迹和后续筛选。
4. **按关系解释效用。** 输入：质量、难度、覆盖度和下游结果。操作：把每个测量值绑定到对应 verifier、base model、轨迹分布和来源血缘。输出：有边界的效用证据。检查：不能把某个模型的难度或某个 judge 的正确性视为普遍结论。
5. **分析规模扩展。** 输入：记录数、复用次数、rollout 预算和训练曲线。操作：区分更高性能上限与更高样本效率，追踪独立数据与重复暴露，并记录 test-time compute 的结构。输出：规模决策。检查：保留模型和 verifier 版本。
6. **形成可审计比较。** 输入：前述记录。操作：按对象、构造、反馈、效用和规模比较配方。输出：决策表或发布清单。检查：每项重要结论都应回到对应主来源。

复现要求：这是一项问题驱动的综合，而不是正式 meta-analysis。复用时必须打开引用的主论文，记录其具体模型、数据、verifier 和预算，并随着版本变化更新配套地图。
