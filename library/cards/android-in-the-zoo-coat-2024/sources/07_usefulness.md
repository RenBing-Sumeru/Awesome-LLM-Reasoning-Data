AitZ is useful as a schema for process supervision in mobile GUI agents. A reusable record should keep episode id, episode length, step id, screenshot path, instruction, prior actions, target action, coat_screen_desc, coat_action_think, coat_action_desc, coat_action_result, subset, train/test split, parser version, and annotation provenance if available. For atlas work, it is a compact example of turning GUI trajectories into auditable reasoning traces, with the audit caveat that the reasoning trace is a label to inspect, not an independent verifier.
