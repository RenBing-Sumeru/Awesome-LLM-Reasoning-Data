The contribution is Chain-of-Action-Thought (CoAT) plus the AitZ dataset. CoAT changes the context object for action prediction: instead of only past actions or free-form chain-of-thought, it decomposes each step into screen observation, action thinking, next-action description, and expected action result. The data surface contains 18,643 screen-action pairs with CoAT annotations and more than 2,500 instructions. The feedback contract is action-prediction evaluation, including format hit rate and action-type accuracy in the repository tables, with annotations serving as supervised process labels. Closest comparisons are AITW, Chain-of-Thought prompting, Chain-of-Actions prompting, and later richer mobile GUI datasets such as AMEX.
