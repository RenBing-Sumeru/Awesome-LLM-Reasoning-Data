Correctness is relative to the AitZ JSON annotations and action parser. A process label can be fluent while still being incomplete, over-specific, or inconsistent with the actual GUI affordance. The repository distributes data through Google Drive and Baidu links rather than a versioned dataset registry, so hashes and archive contents should be preserved locally before serious comparison. Reported prompt improvements are measured on action prediction and small sampled comparisons, not on a controlled live Android task suite. Single-subset train-only data and public screenshots also create leakage and contamination risks.
