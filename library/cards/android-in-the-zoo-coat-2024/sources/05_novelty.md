The prior baseline is AITW-style action traces and generic CoT/CoA prompting. AitZ changes the data object by attaching action-grounded semantic labels to screen-action pairs, with separate fields for observing the screen, thinking about the action, describing the action, and describing its result. The direction signal is process-level supervision for GUI agents, which can be used in prompting, finetuning, or error analysis. What is not new: Android trajectories, next-action prediction, screenshots, and natural-language instructions already exist. Before reuse, inspect annotation consistency, hidden prompt choices, download-link durability, split leakage, model API drift, and whether CoAT labels teach useful behavior or merely explain the demonstrator's chosen action.
