Android in the Zoo asks whether mobile GUI agents benefit from explicit action-level reasoning over previous actions, the current screen, the intended next action, and the expected outcome. The primary sources are the 2024 arXiv paper and the official CoAT GitHub repository, whose update log states acceptance to EMNLP 2024 Findings. The decision boundary is annotated Android screen-action data and prompting/evaluation for action prediction, not a live Android environment or a general chain-of-thought safety claim. A data object is a screen-action timestep with fields such as episode id, step id, screen description, action thinking, action description, and action result. Its atlas value is that it exposes process annotations for mobile GUI trajectories.
