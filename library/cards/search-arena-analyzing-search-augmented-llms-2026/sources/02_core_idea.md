Search Arena pairs natural user conversations with two anonymized search-LLM responses, a human choice when cast, and the retrieval context behind both answers. Its 24,069-row official Parquet release contains 12,652 votes from roughly 11,000 users in 136 countries, with about 90 languages; records expose paired messages, timestamps, full system and search metadata, language, and intent. Unlike preference data without evidence context, it can separate what users like from what citations substantiate. User prompts are CC-BY-4.0, but model outputs retain their providers' terms.
