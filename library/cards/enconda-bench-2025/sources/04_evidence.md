The paper reports two linked but non-equivalent evaluation surfaces. In Table 3, Repo2Run with Claude-4 obtains error-type F1 60.6, description accuracy 52.2, fix accuracy 47.3, and Pass@1 22.9. OpenHands with DeepSeek-V3 obtains F1 58.7, description accuracy 51.9, fix accuracy 33.8, and Pass@1 9.1. These are author-reported results under the paper's agent/model configurations; the checked public snapshot does not contain the complete executor or experiment logs required for independent reproduction.

The score pattern supports a bounded conclusion: agents often perform better at identifying or describing setup faults than at producing an executable repair that satisfies the terminal predicate. The paper's case analysis reports overprediction, excessive use of E8 “other,” missed repository-wide path errors, correct diagnosis without command localization, incomplete repair of multi-error READMEs, omission of a suggested fix from the final script, and introduction of new faults. Figure 7 further reports that more output tokens tend to improve description accuracy without consistently improving Pass@1. This is not evidence that the released data are intrinsically high quality or that more tokens reliably solve environment configuration.

The release-scale evidence is independently countable from official artifacts. At commit `86ab7858613b85f4a8316f3cda3c83086b8cf7c2`, full-corpus parsing yields 4,201 main JSONL rows and exactly 9,471 error objects. The directory tree contains 4,201 JSON annotations and 4,201 README texts: 3,216 Markdown, 978 RST, 6 AsciiDoc, and 1 Org file. The released level counts are level0 48; level1 2,072; level2 1,222; level3 94; level4 234; level5 100; level6 173; level7 80; level8 80; level9 38; and level10 60. The error counts are E1 1,969; E2 2,607; E4 1,491; E6 1,602; E7 1,490; and E8 312.

Those checks also reveal unresolved drift. The paper reports 323 repositories, whereas the main JSONL has 320 distinct `repo_name` values, the expanded tree has 321 repository directories, and `repo_info.jsonl` has 329 repository/revision rows. The paper describes levels 1-10, yet the release includes 48 level0 records. E8 matches the paper's 312, but current E1/E2 counts do not fit the paper's approximate “around 1,600” description for the five standard types. No tag, release, changelog, or manifest explains these mappings. The evidence therefore supports the 4,201-task/9,471-error release boundary but not silent equivalence among paper, repository, level, and version statistics.
