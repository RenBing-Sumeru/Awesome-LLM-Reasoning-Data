Existing Solidity benchmarks often use isolated functions or short contracts and compute only compilation or test-based Pass@k, missing real repository calls and joint security and cost concerns. SolEval places generation units in 28 real project contexts and combines Foundry, Slither, and gas profiling into a multi-objective verifier.

The novelty is not a new static analyzer or gas metric. It binds three feedback types to the same repository-level data object, enabling study of correctness–security–efficiency trade-offs, and demonstrates that benchmark records can become SFT data.
