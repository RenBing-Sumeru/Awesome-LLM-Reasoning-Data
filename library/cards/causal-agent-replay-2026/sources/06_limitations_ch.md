因果解释依赖未经验证的建模假设。`state_before` 被视为包含所有决定请求的输入，但 hidden provider state、model weights/build、batching、clock、tool state、environment randomness 与 remote API state 并未被捕获。`do_resample(k)` 也会在没有 common random numbers 的情况下重跑后续全部随机选择，因此其 contrast 是通过 continuation 传播的 total effect，而不是 step `k` 的 isolated direct effect。在 `do_action` 或 Shapley coalition 中强制使用事实 action，也可能在反事实 context 下不合理。

point-of-commitment 规则假设最晚出现的显著 rescue 代表单调的 commitment。核心循环没有对逐 step interval 做 multiple-comparison adjustment，较小的 K 或有噪声的 policy 会导致 false localization 或 abstention。仅存在于仓库的 Who&When 运行直接显示这一点：CI gate 只在 22/121 上触发，且 K 不大于 8 时，76% 的标注 step 从未被 rescue。Shapley 计算昂贵，使用 normal-approximation interval；hard budget 还可能留下过少 marginal contribution，使不确定性无法校准。

反馈与 replay 另有不同的 failure surface。确定性规则可能漏掉语义失败条件；LLM judge 会引入 rubric bias、方差与 prompt-injection 风险。deterministic replay 注入 recorded observations，并检查较粗粒度的 action signature，因此不能证明 live-world reproduction。counterfactual branch 则可能再次调用工具，但 CAR 没有共同的 environment snapshot、reset、sandbox、approval、timeout/retry、idempotency 或 side-effect rollback 协议。现有 adapter 主要支持 single-agent linear loop、每轮一个 tool call 和返回 string 的工具；parallel call、streaming、fan-out 以及 non-linear 或 multi-agent path 受到限制或会被拒绝。

发布审计风险仍然突出。官方 arXiv 只有五页 v1；GitHub `v0.2.0` 包含后续 Who&When 主张，却没有发布 result rows；PyPI 仍为 `0.0.1`。不存在 CAR dataset、split、retention manifest、data card、不可变 trajectory hash、environment image 或 decontamination report。metadata 声明 Apache-2.0，但仓库没有 LICENSE 文本，导入的 Who&When material 权利也未解决。完整 prompt、raw response、tool argument 与 output 可能包含 secret 或个人数据，而 redaction、consent、retention 与 access-control policy 均未披露。
