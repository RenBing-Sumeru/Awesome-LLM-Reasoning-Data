Prior agent replay systems can reissue calls or inspect logs, and prior failure-attribution benchmarks label a responsible agent or step. CAR's concrete change is the audit object and interface: it co-locates exact request-facing decision state, action, observation provenance, root/branch lineage, a specified intervention, a complete branch outcome, and uncertainty-aware causal effects. This lets a reader distinguish message reconstruction, action-match replay, and counterfactual environment replay instead of calling all three “replay.”

The individual ingredients are established: structural causal models, do-interventions, resampling, Wilson and bootstrap intervals, Monte-Carlo Shapley estimation, and mocked synthetic environments are not introduced by CAR. The method-level contribution is their integration with LLM-agent trajectory recording and explicit stochastic replay semantics. The point-of-commitment rule also addresses a specific confound: an early resample rerolls the full suffix, so the largest effect need not be the causal decision; selecting the latest significantly rescuing step encodes a commitment hypothesis rather than treating every contrast as isolated.

Relative to Who&When Pro, AgenTracer, and TraceElephant, CAR is primarily infrastructure and an attribution recipe, not a benchmark-data release. The later repository experiment imports Who&When static logs and substitutes a surrogate world model because the original policies and environment states cannot be replayed. That result is a useful boundary condition, not evidence that static logs have become faithful counterfactual trajectories.

For reasoning-data research, the direction signal is that process supervision for agent failure can be attached to intervention distributions and branch lineage rather than inferred from terminal pass/fail alone. Reuse still requires checking outcome validity, state sufficiency, environment reset and rollback, multiple-comparison behavior, record integrity, privacy, license, and version alignment. Scale or downstream attribution accuracy does not by itself establish a trustworthy data object.
