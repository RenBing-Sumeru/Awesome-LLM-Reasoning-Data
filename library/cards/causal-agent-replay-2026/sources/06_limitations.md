The causal interpretation depends on unverified modeling assumptions. `state_before` is treated as sufficient for every request-determining input, but hidden provider state, model weights and build, batching, clocks, tool state, environment randomness, and remote API state are not captured. `do_resample(k)` also rerolls all downstream stochastic choices without common random numbers, so its contrast is a total effect through continuation, not an isolated direct effect of step `k`. Forced factual actions in `do_action` or Shapley coalitions may be implausible under a counterfactual context.

The point-of-commitment rule assumes the latest significant rescue represents monotone commitment. The core loop does not adjust its per-step intervals for multiple comparisons, and low K or noisy policies can cause false localization or abstention. The repository-only Who&When run makes this visible: the CI gate fires on 22/121 and 76% of annotated steps are never rescued at K no greater than 8. Shapley is computationally expensive, uses normal-approximation intervals, and a hard budget can leave too few marginals for calibrated uncertainty.

Feedback and replay introduce separate failure surfaces. A deterministic rule can miss semantic failure conditions; an LLM judge can add rubric bias, variance, and prompt-injection vulnerability. Deterministic replay injects recorded observations and checks coarse action signatures, so it does not prove live-world reproduction. Counterfactual branches can instead call tools again, yet CAR has no common environment snapshot, reset, sandbox, approval, timeout/retry, idempotency, or side-effect rollback protocol. Current adapters focus on single-agent linear loops, one tool call per turn, and string-returning tools; parallel calls, streaming, fan-out, and non-linear or multi-agent paths are limited or refused.

Release audit risks remain material. The official arXiv has only a five-page v1; GitHub `v0.2.0` contains later Who&When claims without released result rows; PyPI remains `0.0.1`. No CAR dataset, split, retention manifest, data card, immutable trajectory hashes, environment image, or decontamination report exists. Metadata declares Apache-2.0, but the repository has no LICENSE text and the imported Who&When material has unresolved terms. Full prompts, raw responses, tool arguments, and outputs may contain secrets or personal data, while redaction, consent, retention, and access-control policies are undisclosed.
