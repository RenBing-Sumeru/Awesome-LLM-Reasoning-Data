Inference-time search can raise a small language model’s reasoning accuracy, but the usual routes are expensive. Best-of-N retains many long completions, while process reward model search adds another model that must be evaluated at each reasoning step. Both approaches consume GPU memory and compute precisely when the serving system is already handling multiple long chains.

The paper asks whether a reasoning model can decide which partial paths deserve more inference budget using feedback it already contains. Raw next-token probability is not automatically a trustworthy correctness estimate, so the problem is not merely to expose confidence. The signal must be calibrated enough to rank step candidates, preserve useful exploration, and do so without inserting a separate verifier into the inference path.
