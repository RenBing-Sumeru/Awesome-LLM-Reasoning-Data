1. **Position:**  JUDGE-BENCH tests whether LLMs replace humans across twenty NLP evaluations.
2. **Method:**  Data harmonisation, task prompts, eleven judges, and conditional agreement analysis.
3. **Data:**  Twenty human-labelled datasets plus conversion, prompts, and evaluation code are released.
4. **Evidence:**  No model is consistently human-like; expertise and text source materially affect agreement.
5. **Reuse:**  Suitable for judge selection; calibrate every production task with humans first.
