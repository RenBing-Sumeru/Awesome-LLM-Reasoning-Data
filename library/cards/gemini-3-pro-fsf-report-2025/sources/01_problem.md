Frontier safety reports can establish an important capability and mitigation narrative while withholding the data, feedback, and audit artifacts required to inspect a post-training pipeline. For reasoning systems, a statement that reinforcement learning was used is insufficient: prompt provenance, trace schema, reward contract, filtering, rollout construction, and evaluation controls determine whether the claim can be independently assessed.

Gemini 3 Pro is relevant to Track 12 because its official Frontier Safety Framework (FSF) report makes several unusually specific stage-level disclosures. It says supervised fine-tuning uses thought traces generated by reasoning models, and that RL on thoughts includes length penalties while, with minor exceptions, other rewards do not reference thoughts. The same report does not release the underlying prompts, traces, generators, reward implementation, or reproducibility artifacts. This Card records that disclosure boundary rather than treating the report as a training-data release.
