DiffCodeGen is useful for studying execution-grounded filtering of code rollouts. An auditable derivative should preserve the prompt, model and decoding settings, every candidate, reference rule, fuzzing engine and seed, generated driver, accepted and invalid inputs, outputs, errors, exit codes, distance matrix, cluster assignment, fallback reason, and final choice. Benchmark gains are evidence about selector behavior, not data-quality certification; hidden tests, mutation analysis, or human review are still needed.
