The paper studies three candidate-generation routes: repeated sampling with temperature 0.7 and top-p 0.95; beam decoding that retains all beams; and 18 nominally semantics-preserving prompt perturbations. The fuzzing reference is sampled randomly for repeated sampling, is the top beam for beam search, and is the unmodified-prompt response for prompt perturbation.

For scripts, the implementation uses AFL++/py-afl and saves the coverage-guided seed queue. For library functions it uses libFuzzer/Atheris and asks an LLM once to construct a fuzz driver; driver failure causes a fallback to the reference solution. Each candidate is executed on the common collected inputs. Outputs are normalized for line endings, trailing whitespace, and non-string values; failed executions also use error information. Pairwise distance is the fraction of common valid inputs with different execution behavior, or 1.0 when no common valid input exists. Hierarchical agglomerative clustering stops at two clusters, and the within-cluster minimum-distance program is selected.
