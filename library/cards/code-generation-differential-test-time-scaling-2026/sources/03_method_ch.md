论文研究三种候选生成方式：temperature 0.7、top-p 0.95 的重复采样；保留全部 beam 的 beam decoding；以及 18 种名义上保持语义不变的提示扰动。重复采样随机选取一个候选作为 fuzzing 参考，beam search 使用 top-1 beam，提示扰动则使用原始未改写提示生成的候选。

脚本程序使用 AFL++/py-afl，并保留覆盖引导产生的 seed queue。库函数使用 libFuzzer/Atheris，且会额外调用一次 LLM 构造 fuzz driver；若 driver 无法编译或运行，系统回退到参考候选。所有候选在同一组收集输入上执行。输出会统一换行符、删除尾部空白并把非字符串值转为字符串；执行失败时还比较错误信息。两程序间距离定义为它们在共同有效输入上行为不同的比例；没有共同有效输入时距离记为 1.0。层次凝聚聚类在剩余两个簇时停止，再选择较大簇中总距离最小的程序。
