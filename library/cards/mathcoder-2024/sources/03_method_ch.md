# 方法

1. **构造经过核验的种子轨迹。**输入是 GSM8K 与 MATH 训练题、标准答案和 GPT-4。让 GPT-4 编写交替包含推理、Python 与执行输出的 LCE 解答。输出四万九千条题目与解答记录。检查/停止规则是最终答案必须与源数据标准答案一致。
2. **插值并求解新题。**输入是一道较容易的 GSM8K 题、一道较难的 MATH 题、GPT-4，以及第一阶段训练出的 MathCoder-Initial。GPT-4 编写难度位于二者之间的新题并判断相对难度，MathCoder-Initial 为每题生成三条 LCE 解答。输出三万一千条附加记录。检查/停止规则是三个最终答案必须一致，但一致并不等于正确。
3. **序列化并微调。**输入是合并后的八万条轨迹与 Llama-2 或 CodeLlama。用特殊词元分隔自然语言、代码、执行、块和消息，通过跨题掩码拼接样本并训练三个周期。输出 MathCoder-L 与 MathCoder-CL 消费模型。检查/停止规则是在最终方案中只对文本和代码计算交叉熵，屏蔽执行结果的损失。
4. **推理时重放执行。**输入是数学问题与生成中的 LCE 块。贪心生成到块结束；遇到代码时在持久 Jupyter 状态中执行，追加真实结果，再继续生成。输出最多三十二个块的轨迹与最终答案。检查/停止规则是到达答案/消息边界或块上限后终止，再于五项基准上按任务答案评分。

**复现要点：**应核验 OpenReview、`train_80k.jsonl` 快照、嵌套消息结构、特殊词元、答案提取、源切分、插值提示、三次一致性筛选、执行沙箱、模型检查点和 SFT 设置。论文没有披露 GPT-4 版本、采样温度、随机种子、重试次数、构造总词元或成本。
