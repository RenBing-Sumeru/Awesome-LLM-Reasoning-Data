# 证据

**主张一：**在固定消费模型下，插值记录比仅用种子轨迹更有效。**受控配置：**表 4 用同一方案微调 CodeLlama-34B，训练数据分别是四万九千条 GSM8K/MATH LCE 记录，或加入三万一千条插值题后的完整八万条混合。**结果：**五项任务平均分从 66.2 升到 70.2；GSM8K 从 77.3 升到 81.7，MATH 从 44.0 升到 45.2，三个域外任务也全部提高。**边界：**完整混合同时改变记录数与题目分布，不能把收益只归因于插值质量而排除规模效应。

**主张二：**决定性反馈来自真实执行，而不是模型预测的执行文本。**受控配置：**表 5 使用 CodeLlama-34B 与八万条混合；训练时学习执行结果的模型，自己预测结果时平均分为 35.1，由 Python 提供结果时为 69.1；屏蔽执行结果损失并实时执行时达到 70.2。**结果：**实时执行比预测结果高 34.0 个平均分，屏蔽结果损失则从 69.1 变为 70.2。**边界：**这支持运行时反馈契约，不能证明每条训练轨迹正确，也不能保证任意代码执行安全。
