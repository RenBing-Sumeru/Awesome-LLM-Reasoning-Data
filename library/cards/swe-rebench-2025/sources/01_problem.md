SWE-rebench: An Automated Pipeline for Task Collection and Decontaminated Evaluation of Software Engineering Agents asks how to close this gap: Fresh and decontaminated software-agent evaluation needs more than hand-curated static benchmarks; task mining, installation, and quality filtering must be automated. The primary source is https://arxiv.org/abs/2505.20411; public status is NeurIPS 2025 / arXiv (2025).

Decision boundary: It is collected as an automated SWE task collection and evaluation pipeline, not as a single immutable leaderboard set. The reusable object is a mined Python issue task with repository state, install recipe, patch/test_patch, FAIL_TO_PASS/PASS_TO_PASS tests, Docker image metadata, quality labels, and split identity. This matters for the atlas because the object and feedback contract are inspectable together.
