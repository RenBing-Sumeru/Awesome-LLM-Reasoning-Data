
WebArena-Lite covers Reddit, GitLab, CMS, Map, and Shopping in a realistic self-hosted browser environment. Each task is formulated as a POMDP. At a turn, the model observes text-only HTML and its interaction history, emits one Python-style action such as Click, Type, Search, Scroll, Switch Tab, or exit, and receives the next page state. The default prompt encloses a brief rationale in `think` tags and the action in `answer` tags. An episode ends on success, the interaction cap, or exit. Earlier HTML is dynamically reduced to a “Simplified HTML” representation while the complete action history remains available.

Warm-up uses the public 9,460 trajectories from 1,186 valid program-solver samples. The main RL split contains 647 tasks; 165 human-verified tasks are held out for evaluation. Parallel browser instances generate a group of independent current-policy episodes per task from the same starting page. Rollout temperature and top-p are both 1.0, but the group size, total online trajectory count, seeds, task schedule, and default maximum interaction count are not reported in the paper text. Each episode receives a binary reward from a task-specific string, URL, or final-state program check, and M-GRPO computes group-relative advantages without a reported replay-buffer or rollout-filter stage.

Both backbones are instruction-tuned models. The paper uses full-parameter training on one node of eight 80 GB NVIDIA A100 GPUs with DeepSpeed ZeRO-3 offload, gradient checkpointing, FlashAttention-2, and bf16. SFT uses learning rate 5e-5, batch size 128, cosine scheduling, and 5% warm-up; RL uses learning rate 1e-6, batch size 16, KL coefficient 0.001, clip ratio 0.2, maximum context 16,384, and maximum new tokens 1,024. QwQ-32B adds first-person explanatory CoT to existing BC fields only for WebAgent-R1-CoT. The official repository supplies nested environment setup, training, verifier, and evaluation code, but its README does not supply a pinned run manifest, online trajectories, trained checkpoints, or an immutable WebArena snapshot.
