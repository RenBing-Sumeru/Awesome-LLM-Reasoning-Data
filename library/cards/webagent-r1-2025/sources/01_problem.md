
WebAgent-R1 addresses a training-data and optimization gap for text-based web agents. Behavior cloning can teach the browser action format, but a fixed demonstration set cannot expose the current policy to its own errors and alternative long-horizon strategies; earlier web-agent RL systems commonly rely on off-policy replay, trajectory filtering, or an additional outcome reward model. The paper instead studies end-to-end on-policy learning in a self-hosted WebArena/WebArena-Lite environment, where each record is a multi-turn episode: a user intent, text-only HTML observations, accumulated action history, one browser action per turn, environment transitions, and a terminal binary outcome.

The fixed warm-up object is the public WebArena-Lite behavior-cloning set: 1,186 valid training samples comprising 9,460 trajectories produced by program-based solvers. The online RL object is different and must not be conflated with that release: the current policy repeatedly samples browser episodes on 647 training tasks, while 165 human-verified tasks are reserved for evaluation. Those current-policy trajectories are scored by task-specific WebArena rules and grouped for M-GRPO updates. This Card belongs in Rollout, Search, and Test-Time Trace Data because both grouped training-time attempts and interaction-count sweeps materially affect the reported system. The paper and code expose the recipe, but no standalone online-rollout dataset or checkpoint was verified, so L4 review should retain that release boundary rather than treating benchmark success as evidence of reusable data.
