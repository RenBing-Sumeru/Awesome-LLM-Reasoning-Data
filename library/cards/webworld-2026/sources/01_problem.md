WebWorld: A Large-Scale World Model for Web Agent Training asks how to close this gap: Real-web agent training is constrained by latency, cost, rate limits, safety risk, and the scarcity of long-horizon interaction trajectories. The primary source is https://arxiv.org/abs/2602.14721; public status is arXiv preprint (2026).

Decision boundary: It is collected as a world-model/simulator direction for web-agent training, not as a release of verified real trajectories or a deterministic environment. The evaluation surface is an instruction/history/state/action input, a predicted next browser observation or state transition, simulator rollout metadata, and downstream evaluation results. This makes the paper useful for the atlas because the data object and feedback rule can be audited together.
