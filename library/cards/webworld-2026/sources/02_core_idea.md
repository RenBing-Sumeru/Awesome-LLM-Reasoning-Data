One-sentence contribution: WebWorld: A Large-Scale World Model for Web Agent Training makes an instruction/history/state/action input, a predicted next browser observation or state transition, simulator rollout metadata, and downstream evaluation results. reusable by binding it to a concrete feedback contract.

Core mechanism: The authors train web world models from large-scale open-web trajectories and use them for simulation, synthetic trajectory generation, and inference-time search. Feedback contract: WebWorld-Bench uses LLM-judged Factuality Score and Web Turing Score; downstream task success provides extrinsic validation of synthesized trajectories. Closest comparisons are direct live-web training, offline trajectory datasets without learned dynamics, and small or closed web simulators. Direction label: verifier-anchored agent evaluation, where the reusable unit is task object plus acceptance rule.
