1. **一句话定位：** TestGenEval 用 1,210 个真实代码—测试文件对评测模型能否在仓库中生成可运行且有缺陷发现能力的测试。
2. **方法抓手：** 固定项目环境、构造完整生成/片段补全、执行 pytest、测 coverage 和 mutation。
3. **数据抓手：** 11 个 Python 仓库、68,647 条人写测试，并公开 Docker 与任务划分。
4. **证据锚点：** 人工测试中位 coverage 为 60.4%，GPT-4o 生成测试平均仅 35.2%。
5. **复用决定：** 适合测试生成与 verifier 研究；不能把高覆盖率直接解释成高语义正确性。
