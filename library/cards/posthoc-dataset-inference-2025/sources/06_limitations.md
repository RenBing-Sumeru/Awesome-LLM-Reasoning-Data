Methodologically, the test is conditional rather than identificational. It assumes that text-only classification captures generation artifacts while the combined classifier's incremental advantage isolates membership. Hidden correlations between text features and likelihood features can violate that decomposition. Generator memorization, domain mismatch, feature selection, outlier handling, and classifier capacity can alter both false positives and false negatives. A synthetic set that is too distinguishable hides membership, while uncalibrated likelihood gaps fabricate it.

The evaluation does not establish a uniform margin. Although every main-table row lies on the intended side of 0.05, several non-member p-values are 0.06–0.09, and the paper's claim that all exceed 0.1 conflicts with Table 4. Results use known Pile splits, one single-author corpus, deduplicated Pythia checkpoints, and two OLMo subsets. Cross-domain generalization to closed commercial models, unknown training mixtures, adversarially selected suspect sets, other generators, or weaker memorization remains unverified. Choosing token length by observed text-classifier AUC may also introduce analysis flexibility unless fixed prospectively (curator inference).

The target-model access boundary is narrower than the broad legal narrative. Current code loads model weights and calculates token-likelihood-derived MIA features. It does not show that the method works with a closed service that only returns sampled text. Statistical rejection is aggregate evidence under an assumed checkpoint and training-ground-truth setup; it does not reveal which records were used, when they were used, whether use was authorized, or whether legal infringement occurred. Non-rejection is not proof of absence.

Release completeness is partial. The repository is MIT licensed, but the linked Google Drive data has no explicit dataset license or consolidated upstream rights statement. The mutable archive lacks an author checksum and version manifest; checkpoints are not released, the repository has no tagged release, and the README's data-release update conflicts with its stale unfinished-items list. Paper-run learning rate, decoding parameters, seeds, outlier fractions, complete hardware/compute cost, and exact revisions are missing.

Sequence-level splitting is intentionally distribution-matching but places snippets from the same source document across generator partitions, so it is not document-independent evaluation. Excluding selected Pile subsets described as copyright-problematic does not establish license, privacy, or consent for retained material. Releasing synthetic continuations derived from suspect documents may itself require a source- and jurisdiction-specific rights review (curator inference).
