Earlier LLM dataset inference aggregates membership features over a suspect set but relies on a real held-out set that is both known absent from training and distribution-matched. The paper's failure study shows why that assumption is fragile even for randomly shuffled writings by one author. Blind-baseline work had already established that distribution shift can dominate membership attacks, and the post-hoc correction is inspired by prior debiasing work; neither dataset inference nor distribution calibration is introduced from scratch here.

The concrete change is the evaluation object: a shared prefix produces paired natural and synthetic suffixes, and the audit compares a text-only generation-gap model with a text-plus-membership model. Segment-and-shuffle keeps generator training and inference snippets close in distribution, positive weights constrain how likelihood features contribute, and a repeated corrected test yields a set-level decision. The novelty is this combination of synthetic-reference construction and calibrated feedback, not simply using Llama 3 or increasing scale.

For reasoning-data research, the direction matters because it treats provenance checking as a designed data pipeline with explicit negative controls. It offers a pattern for auditing whether a corpus may have influenced a model when no prospective holdout exists. Before reuse, however, practitioners still need a legally reusable corpus, immutable artifact versions, a supported target-model interface, and power/false-positive calibration for their own generator and domain.
