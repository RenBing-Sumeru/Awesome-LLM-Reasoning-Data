The contribution is an interval-valued LLM-as-a-judge evaluation: starting from a single judge run, it extracts rating-token logits, calibrates conformal predictors on human-rated examples, and returns a continuous and ordinal prediction interval with a recommended midpoint. A boundary adjustment aligns intervals with discrete rating labels while preserving or increasing coverage. This changes the evaluation output from an unqualified point score to a score plus an empirically calibrated uncertainty statement. Code and data are released through the authors' repository; the paper does not introduce a new standalone dataset.
