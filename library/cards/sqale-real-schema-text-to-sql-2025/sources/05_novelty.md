Earlier large-scale Text-to-SQL synthesis typically selects a limited set of databases such as those in Spider or BIRD and expands questions or SQL over fixed schemas. Sample counts grow, but the underlying database structures do not. SQaLe changes the starting object of generation: it first extracts and expands schemas from a large body of real code and then generates question–SQL pairs around those structures. Its novelty is neither the first use of LLM-generated SQL nor the first use of execution validation. It makes real-schema coverage the main axis of scaling, so corpus growth also increases database structure, join relations, and query-condition diversity.
