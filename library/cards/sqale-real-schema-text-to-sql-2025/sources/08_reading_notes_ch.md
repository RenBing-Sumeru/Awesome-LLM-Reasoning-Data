1. **一句话定位：** SQaLe 用真实代码中的 schema 扩展可执行 Text-to-SQL 数据，而非只在少量基准数据库上增加问法。
2. **方法抓手：** 关键链路是模式抽取、受约束扩展、问题—SQL 合成和数据库执行筛选。
3. **数据抓手：** 发布 517,676 条三元组、135,875 个 schema；中位模式含 91 表、435 列，格式为 Parquet。
4. **证据锚点：** 规模与结构统计证明 schema 覆盖显著扩大，但没有把执行成功等同于完整语义正确。
5. **复用决定：** 适合未知 schema 泛化与 RLVR；使用前必须抽检问题—SQL 等价性，并固定执行数据库。
