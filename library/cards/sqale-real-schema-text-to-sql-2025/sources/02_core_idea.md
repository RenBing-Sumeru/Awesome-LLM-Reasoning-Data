SQaLe’s central contribution is to use real schemas, rather than a small collection of benchmark databases, as the substrate for data generation. Starting from 22,989 schemas in SchemaPile, the authors expand them into 135,875 database structures and release 517,676 validated schema–question–SQL triplets. The public corpus has a median of 91 tables and 435 columns per schema and contains roughly 13.2 million foreign-key relations, substantially increasing structural complexity. Each record preserves the database definition, natural-language question, SQL query, and execution-related information, supporting both SQL-generation training and deterministic database-execution feedback.
