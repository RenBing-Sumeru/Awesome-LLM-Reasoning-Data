数学与代码生成已经拥有大量结构化推理监督，但逻辑、科学、符号和常识任务的数据仍然稀疏且碎片化。直接用原始代码继续预训练会让有用过程被语法与无关实现细节遮蔽，文本到代码监督则仍以生成代码为目标，难以直接迁移成自然语言推理能力。

CODE I/O 把原始程序改造成可执行函数，再让 teacher 解释给定输入的输出，或给定输出的一组可行输入。程序执行负责检查预测；CODE I/O++ 还保留反馈与一次修订，最终从 454.9K 个函数构造约 3.52M 条 CoT 训练记录。

**L4 事实：**主要来源为 ICML 2025，PMLR 267:34471-34489，https://proceedings.mlr.press/v267/li25t.html；数据对象与判定边界是 prompt、首轮 CoT 预测、执行反馈、可选修订与复查；完整构造与评测证据已核对，但公开发布只覆盖 PythonEdu-Reasoning 子集，且未披露其准确行数。
