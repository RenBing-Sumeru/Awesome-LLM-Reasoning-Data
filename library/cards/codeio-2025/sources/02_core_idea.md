CODE I/O exposes program logic as natural-language CoT by pairing an executable function with a known input or output and asking DeepSeek-V2.5 to predict the missing side; cached-answer matching or re-execution supplies correctness feedback, and CODE I/O++ appends one revision instead of discarding wrong first attempts. These serialized explanations and correction turns are two-stage SFT targets, so the work belongs to instruction/demonstration/rationale data rather than raw-code pretraining or a code benchmark.

Google Scholar citations: 55（checked 2026-07-27；https://scholar.google.com/scholar_lookup?title=CODE+I%2FO%3A+Condensing+Reasoning+Patterns+via+Code+Input-Output+Prediction&author=Junlong+Li&hl=en）

Open dataset: yes, with a documented release limitation. Dataset name: CodeIO-PyEdu-Reasoning. Official URL: https://huggingface.co/datasets/hkust-nlp/CodeIO-PyEdu-Reasoning. Scale: the full paper pipeline creates about 3.52M samples, while the public subset is one 11,225,166,333-byte JSONL file and its exact row count is not disclosed. Record form: `prompt`, `turn_1`, `feedback_1`, optional `turn_2`, and `feedback_2`. File/storage format: `pyedur_full.jsonl`. Domains/languages: English natural-language traces over educational Python functions spanning STEM, systems, logic puzzles, and other reasoning code. Construction and filtering: DeepSeek-V2.5 normalizes code and writes predictions; Python execution filters unusable functions and checks predictions, while wrong responses remain with feedback and optional revision. License/access constraints: public, ungated ODC-BY; only the PythonEdu-Reasoning subset is released because of collaborator compliance requirements. Intended use: reasoning SFT and distillation before general instruction tuning.
