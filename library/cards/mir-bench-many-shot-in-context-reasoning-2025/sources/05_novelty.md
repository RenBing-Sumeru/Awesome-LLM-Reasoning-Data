Induction benchmarks such as ARC and WILT focus on few examples, while Needle-in-a-Haystack mainly tests retrieval, and many many-shot studies still use classification. MIR-Bench changes the information structure: every demonstration comes from the same complex function, each shot provides limited information, and the model must integrate many diverse input-output pairs to predict a new result. The novelty is not simply more examples, but using executable functions, task-selection metrics, and diverse I/O types to construct information-integration saturation curves and distinguish inductive CoT from direct transductive reasoning.
