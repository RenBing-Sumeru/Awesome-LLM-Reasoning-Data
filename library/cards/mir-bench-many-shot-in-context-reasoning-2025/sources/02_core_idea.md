MIR-Bench extracts underlying functions from HumanEval+, MBPP+, and APPS and uses automatic generators to produce input-output demonstrations in diverse formats. MIR-Extended contains 693 functions, while MIR-Core selects 300 tasks that best distinguish few-shot from many-shot capability. Each task can provide up to thousands of shots, and target outputs are computed exactly by the original function. The data object consists of a hidden function, demonstration sequence, query input, and deterministic output for long-context inductive-reasoning evaluation rather than subjective open-ended judging.
