The central data object is table + natural-language claim or question + pandas_code + execution result. PanTabFact is derived from TabFact; its official card reports a 10K–100K scale and fields including id, statement, label, table_caption, table_text, pandas_code, and pandas_eval. It is released as JSON without predefined splits. PanWiki maps WikiTableQuestions to pandas queries. Model fine-tuning demonstrates utility, but the reusable contribution is the executable-query representation and automated correction pipeline.
