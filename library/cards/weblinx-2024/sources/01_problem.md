WebLINX: Real-World Website Navigation with Multi-Turn Dialogue asks how to close this gap: Web navigation agents must follow multi-turn dialogue over real sites, but full pages are too large and dynamic for simple prompt-only models. The primary source is https://arxiv.org/abs/2402.05930; public status is ICML 2024 Spotlight / PMLR 235 (2024).

Decision boundary: It is collected as dialogue-conditioned web navigation data and evaluation, not as a terminal-reward environment like WebShop. The evaluation surface is dialogue context, website/page observation, screenshot, HTML or selected page elements, action history, target next action, website id, and split metadata. This makes the paper useful for the atlas because the data object and feedback rule can be audited together.
