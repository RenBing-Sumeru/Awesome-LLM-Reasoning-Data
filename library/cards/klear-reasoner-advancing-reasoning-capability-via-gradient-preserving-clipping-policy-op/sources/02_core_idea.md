The official KlearReasoner-MathSub-30K release exposes roughly 30K mathematical prompts with verifiable reference answers for SFT and RL data-selection studies. Its main data finding is that a small number of high-quality sources can outperform indiscriminate mixtures and that difficult examples remain valuable when not overfiltered by current-model accuracy. Training first uses long-CoT initialization and then answer-parser rewards under GPPO; the data and algorithmic contributions should be distinguished.
