The final model reaches 90.5% on AIME24, 83.2% on AIME25, and 66.0%/58.1% on LiveCodeBench V5/V6. Data ablations show that selected sources and harder prompts outperform larger but noisier mixtures, while algorithm ablations indicate improved utilization when clipped-token gradients are retained. This supports the combination of difficult data and negative-trajectory learning, but SFT data, RL prompts, and GPPO all change, so individual contributions depend on controlled ablations.
