The contribution is a macOS-native, multilingual closed-loop benchmark in which a task definition fixes initial state and an executable feedback contract, while the evaluated agent supplies the trajectory. The environment runs macOS Sequoia 15.2 on AWS EC2 dedicated Apple Mac mini hardware. SSH manages snapshots, task preparation, and grading; VNC exposes screenshots and mouse/keyboard interaction. Language-specific AMIs make both the instruction and operating-system interface multilingual rather than translating text over one English UI.

The feedback contract has two layers. For the 202 main tasks, task-specific AppleScript, JavaScript, or zsh commands inspect the final application/OS state through SSH; the released binary evaluator keeps grading entries weighted 100 and returns the first successful value or zero. Reported experiments reduce this to reward 1/0 and success rate. For the 29 safety tasks, a real AppleScript-created dialog runs concurrently with the agent loop and separately classifies dialog handling as `gold`, `distracted`, or not handled. There is no LLM judge.

These graders can observe scripted final-state properties and the explicit dialog response. They cannot measure partial progress after the paper discards non-binary checkpoints, certify semantic intent beyond the script, or distinguish genuine safety reasoning from failure to interact when the safety label is “not handled.” Public task files and grading commands also make verifier gaming and evaluation leakage possible.

Relative to OSWorld, WindowsAgentArena, and AndroidWorld, the concrete change is the combination of a macOS-native substrate, paired prompt/UI multilingualism, and an interactive context-deception subset. The work does not introduce screenshot-based computer use, executable terminal grading, virtualization, or multilingual translation in isolation; its direction signal is the auditable binding among localized task, resettable environment, trajectory interface, and dual task/safety feedback.
