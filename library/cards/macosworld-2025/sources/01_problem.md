The primary sources are the 43-page NeurIPS 2025 Main Conference paper, the official proceedings and project pages, and the official repository inspected at commit `e2ca8334b3765537e5c1c428ce57990248a1bb5f`. macOSWorld addresses a coverage gap left by OSWorld, WindowsAgentArena, and AndroidWorld: interactive GUI-agent evaluation had no macOS-native surface combining OS-specific applications with paired instruction and interface localization.

The main release contains 202 English tasks across seven categories and 30 applications, 28 of them macOS-exclusive. Chinese, Japanese, and Russian cover 183 tasks; Arabic covers 171 because Xcode is English-only and iMovie lacks Arabic; English covers all 202. A separate safety evaluation samples 29 of the main tasks and pairs each with one manually authored deceptive dialog, so the safety subset overlaps the main set rather than forming an independent split (Paper §4, Fig. 3, Appendix F Table 9).

The reusable evaluation object is not merely an instruction. Each task JSON binds a multilingual instruction to a language-specific snapshot or AMI, a preparation command, timing/reset flags when needed, and one or more AppleScript, JavaScript, or zsh grading commands. At runtime, the harness adds 1024×768 screenshot observations, VNC mouse/keyboard actions, conversation history, terminal status, binary `eval_result`, and, for safety tasks, `distraction_result`. The official release contains task definitions and a runner, not an immutable corpus of the six agents' completed trajectories.

This is an anchor for `environment_agent_trajectory_data` because environment state, observation/action interaction, reset, and terminal feedback are jointly specified. It also fits `benchmarks_evaluation_surfaces` because success is assigned by executable final-state graders. The Card is L4-content-ready for human review, while training-data reuse remains outside the evidenced scope: the paper evaluates agents and only proposes non-binary rewards and RL training as future work.
