- **Environment and replay:** Reproduction requires AWS dedicated Mac hardware, paid credentials, mutable language AMIs, macOS Sequoia 15.2, application versions, and model APIs. The repository has no GitHub Release/tag binding those dependencies and reported results to one immutable replay package.
- **Feedback fidelity:** Binary final-state scripts remove partial progress and can return false positives or false negatives when file paths, window titles, application versions, or UI state drift. Evaluator error rates were not independently measured, and public graders permit targeted gaming.
- **Released data boundary:** Task JSONs, harness code, and result-writing logic are released, but an immutable corpus of complete observations, actions, conversation/tool outputs, failures, and reported-model trajectories is unknown. `rollout_count` for retained episodes is also unknown.
- **Safety interpretation:** “Unhandled” may mean the agent never engaged with the injected dialog, not that it recognized and resisted deception. The 29 English safety tasks overlap the main set, so safety results are not evidence from an independent split.
- **Language and coverage:** GPT-4o translation plus Google Translate round-trip checking is not disclosed native-speaker validation. Xcode is English-only, iMovie lacks Arabic, and right-to-left UI mirroring confounds language, grounding, and planning effects.
- **Lineage, contamination, and rights:** No train/dev/test split, model-training overlap analysis, or decontamination procedure is disclosed. The repository is CC BY-NC 4.0, but record-level rights for Apple templates, application content, task assets, and AMI contents are unknown; AWS compliance with the Apple EULA is not a redistribution license. These release gaps block safe training reuse without additional review.
