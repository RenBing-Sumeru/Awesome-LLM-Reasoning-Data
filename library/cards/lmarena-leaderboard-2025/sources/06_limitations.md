Limitations center on scorer coverage, release boundary, and snapshot drift. A hidden test, human vote, or judge rubric can be appropriate for the benchmark while still missing important semantic failures. Public visibility can also create contamination risk.

Scores should not be read outside the official harness. Different model scaffolds, sampling settings, browser or tool versions, prompt filters, and hidden-set policies can change outcomes. Official leaderboard, Arena-Rank repository, and LMArena data organization identify the current infrastructure; comparisons must be snapshot-specific.
