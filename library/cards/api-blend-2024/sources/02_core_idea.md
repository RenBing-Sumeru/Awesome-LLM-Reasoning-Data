The contribution is a curated blend of API-calling datasets transformed from existing semantic parsing, dialogue, digital-assistant, ToolQA, ToolBench, API-Bank, ToolLLM, and ToolAlpaca sources into a shared sequence-of-calls format. The mechanism uses FLAN-T5-XXL-assisted conversion for some dialogue data, grammar or heuristic conversion for intent/slot annotations, and off-the-shelf API-form datasets for OOD testing. Compared with ToolLLM, Gorilla, ToolAlpaca, and API-Bank, API-BLEND's direction label is diversified supervised API sequencing plus standardized evaluation by API-F1, Parameter-F1, and LCS-F1.
