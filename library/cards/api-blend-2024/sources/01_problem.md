API-BLEND is a 2024 arXiv / ACL-status paper from IBM Research on training and benchmarking API-oriented LLMs. The problem is that many tool-use datasets are synthetic, single-call, or benchmarked with incomparable metrics, while useful API agents must detect APIs, fill parameters, and preserve call order. The Card includes it as an API sequencing corpus and evaluation surface, not as a live tool environment. A sample is a single natural-language utterance paired with possible APIs and parameters, a gold sequence of API calls, argument names and values, and split metadata.
