Use API-BLEND as a recipe for turning intent/slot and dialogue datasets into API-sequence training examples. Preserve source dataset id, original utterance, conversion method, prompt model where used, candidate API list, candidate parameter list, gold API sequence, parameter values, split, metric, and filtering decision. For atlas curation it is useful because it separates API detection, slot filling, and sequence ordering, and because it exposes how OOD evaluation changes when the model sees a diverse blend rather than one synthetic API family.
