1. 输入是自然语言 utterance、候选 API 列表、候选 slot/parameter 列表，以及源数据集标注。2. 转换流程把源标注改成有序 API calls：SeqSGD 和 SeqMultiWOZ 用 FLAN-T5-XXL 从 API 输出生成摘要 utterance 并过滤不匹配样本；SeqATIS、SeqSNIPS、SeqTopV2 把 intent/slot notation 映射成 API 和参数；SeqToolQA 与 ToolBench 子集主要用于 OOD 测试。3. 输出是带 gold API sequence 和参数的 train/dev/test 样本。4. 反馈契约是 API-F1、Parameter-F1、LCS-F1，分别比较 API 集合、参数和调用顺序。5. 复用要固定源数据版本、转换脚本、过滤规则、prompt model、split 表、指标，以及代码/数据是否已有官方发布链接。
