arXiv 源码表格报告了五个 in-distribution 数据集 split：SeqATIS 11,670/694/774，SeqSNIPS 39,750/2,198/2,199，SeqSGD 6,782/1,092/1,567，SeqMultiWOZ 6,816/485/983，SeqTopV2 94,458/13,477/6,095。OOD 评测面包括 SeqToolQA 358 例、ToolBench HomeSearch/Booking 100/120 例，以及 ToolLLM、API-Bank、ToolAlpaca。论文结果显示 fine-tuned models 的 in-distribution API-F1 很高，但参数预测更难；combined-data fine-tuning 在论文指标下比 ToolLLaMA-2-7B 和 Lynx-7B 有更好 OOD 泛化。逐样本证据是预测 API 名、参数名/值和调用顺序与 gold 的精确比较。
