The prior baseline is mostly synthetic API data, single-call tool corpora, or datasets that do not require sequencing. API-BLEND changes the training object by converting diverse human-annotated or task-adjacent datasets into a shared ordered-call representation and evaluating both in-distribution and OOD transfer. The quality signal is the explicit split table, conversion rules, and stage-aware metrics. API calling, instruction tuning, QLoRA, and source datasets are not new; reuse should inspect semantic fidelity of conversions, license inheritance from each source dataset, normalization of equivalent parameter values, hidden duplication, and whether no-code/no-data artifact status blocks reproducibility.
