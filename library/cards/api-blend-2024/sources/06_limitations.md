Correctness is relative to gold API names, parameter strings, and sequence order, not to execution in a live service. Equivalent parameter formats can be counted wrong, semantically similar slot names can be penalized, and generated utterances may omit or distort source intent despite filtering. The paper itself describes failures from unnormalized slot values and semantically similar parameter names. Artifact status is a major boundary: the local official evidence verifies the paper and source transformations, but not a stable public code/data release link. License inheritance must be checked for every source dataset before redistribution or training reuse.
