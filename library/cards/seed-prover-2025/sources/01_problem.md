Automated theorem provers need more than final-answer supervision: they must learn to decompose Lean goals, react to compiler failures, reuse intermediate facts, and spend inference compute on difficult instances. Seed-Prover studies this setting with lemma-first Lean generation, formally checked reinforcement learning, and light/medium/heavy test-time search. The associated Seed-Geometry system addresses auxiliary-construction search in olympiad geometry.

For a data atlas, the central problem is disclosure. The report names theorem sources, record components, rewards, refinement signals, search budgets, and a 230M-problem geometry corpus, but does not release the training records, failed trajectories, checkpoints, LooKeng interface, geometry corpus, or complete compute ledger. The official repository's `SeedProver/` directory contains successful proof artifacts, not an open training dataset.
