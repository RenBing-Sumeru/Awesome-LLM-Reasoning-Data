The reusable idea is a feedback-rich formal reasoning object. A record can bind a Lean statement to named lemmas, complete lemma proofs, dependency relations, proof difficulty, whole-proof attempts, failed lemmas, compiler feedback, previous-attempt summaries, and a terminal verification result. Lean supplies a strong binary correctness signal, while an additional undisclosed format penalty encourages lemmas to appear before the main theorem.

At inference, the same object supports progressively wider search. Light repeatedly repairs candidates from compiler feedback; medium isolates failed lemmas and proves them before reinserting them; heavy proposes thousands of conjectures, formally proves or disproves them, builds a fact pool, and ranks retained lemmas for a final proof attempt. This separates formal terminal verification from the learned semantic-relevance judgment used to select heavy-search lemmas.
