已披露流程可分为五个相连部分：

1. **提示来源与课程。** RL 使用 Big-Math、NuminaMath、CriticLean、Lean Workbook、DAPO 等公开来源及未披露的内部形式化数据。证明率高于 `1/4` 的题目被视为过易；对单次证明过难的题目，由 proposer 生成更容易的变体。具体快照、配比、数量和划分排除规则未知。
2. **记录构造。** 提示随机加入自然语言提示/证明、相似或已证 lemma、失败 lemma/尝试、前次摘要和 Lean 编译反馈。输出要求命名 `lemma` 位于主 `theorem` 之前；lemma 池可保存陈述、完整证明、难度和依赖。采样概率及保留/失败记录数未报告。
3. **训练契约。** 基于 VAPO 的多阶段、多任务 RL 在 Lean 验证成功时给 `1`，否则给 `0`，并叠加一个鼓励 lemma-first 结构的未披露格式惩罚。难度、质量和最大输出长度随阶段上升；优化器、rollout 总数、硬件、奖励组合及 VAPO 改动未知。
4. **Lean 环境。** 未发布的 LooKeng REPL 提供 `init_state`、`run_tac`、`verify_proof`，支持整段/逐步交互、版本切换、内存控制、原生 Lean 验证和异步并发。多数评测使用 Lean 4.14.0，MiniCTX-v2 使用 4.16.0。
5. **扩展推理。** Light 采样 Pass@8–16 个候选，每个结合编译反馈和自摘要修正 8–16 轮，约等于 Pass@64–256，耗时 1–2 小时。Medium 选择失败 lemma，每个投入 8×8 light 预算，把成功 lemma 回填外层提示，可生成超过 1,000 行的证明；外层总限制未知。Heavy 从空 lemma 池开始，默认生成 5,000 个猜想（每次 10–50 个），以 light 证明/反证，连续数日从已证事实扩展；再按证明率、未披露 LLM 的语义相关性和证明长度排序，删除无关或短证明，保留数百个 lemma，最后运行 medium。

Seed-Geometry 是另一条构造管线。系统根据 20 多年奥赛几何统计程序化生成超过 2.3 亿个需要辅助构造的独特问题，共 380 亿 BPE token，生成时间超过七天。策略从上下文预测辅助构造，扩展 DSL 与 C++/Pybind11 前向链推引擎提供符号终止检查；最终以 GPU 策略进程和异步 CPU 池执行逐步 beam search。语料、引擎、策略、DSL、去重规则和训练代码均未发布。
