1. 构造反事实奖励。以 DeepScaleR 数学题为输入，将答案等价反馈替换为 64 次采样的多数伪标签、非空 boxed 答案格式、伯努利随机奖励或选定的错误多数标签；每条 rollout 得到二元反馈。

2. 训练可比策略。用 GRPO 为每题在线生成 16 条 rollout，归一化组相对优势并更新同一基础模型。主实验为 Qwen2.5-Math-7B；产物是各奖励条件下的 checkpoint，而非新推理数据集。

3. 检验跨族迁移。保持训练设置和奖励菜单，改训 Qwen2.5、Llama3 与 OLMo2 变体，再测 MATH-500 的 pass@1 及 AMC/AIME 的 avg@8；决定性比较是模型家族，而非换了数据配方。

4. 分离机制。通过三种无裁剪变体移除或中和 GRPO clipping，同时跟踪 token 概率与 Python 字符串频率；检查随机奖励涨分是否仍在，结果显示只有启用裁剪时才稳定出现。

复现须固定公开代码和数据目录、模型/chat template、GRPO 裁剪实现、300 步预算及解码设置。主训练用 8 张 A100、学习率 5e-7、rollout batch 64、minibatch 128，不用 KL/熵损失；随机种子覆盖有限。
