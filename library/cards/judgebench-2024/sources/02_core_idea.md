The contribution is an objective response-pair benchmark for testing whether a judge chooses the more correct answer on difficult tasks. The core mechanism converts existing hard datasets into paired model responses and assigns labels from task correctness rather than subjective preference. The released splits contain GPT-4o-generated pairs and Claude-3.5-Sonnet-generated pairs, each record exposing identifiers, source dataset, question, responses, response model, and the correct ordering. The feedback contract is pairwise decision accuracy against the label, with order-swap handling in the runner for many judge styles. Closest comparisons are preference-alignment judge benchmarks such as MT-Bench/Arena-style evaluation, JudgeLM, Auto-J, PandaLM, and reward-model leaderboards; JudgeBench changes the target from preference agreement to correctness discrimination.
