Use JudgeBench as a compact audit surface for judge models, reward models, prompt templates, and answer-order robustness. A reusable schema should preserve `pair_id`, source dataset, original question id, question, response model, both responses, objective label, judge name/model, prompt template, order policy, raw judgment, parsed decision, and split. It is especially useful for separating preference-following from correctness-sensitive judging before reusing a judge in evaluation, reranking, or reward-model pipelines.
