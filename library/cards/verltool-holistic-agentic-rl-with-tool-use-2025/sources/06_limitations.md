- No versioned six-domain rollout corpus is released. Total generated episodes, tokens, storage size, per-domain retained successes, retained failures, timeouts, exceptions, and discarded records are unknown. The paper specifies how some failures affect reward and gradients—especially in SWE—but not whether those episodes are archived or exposed.
- The paper does not pin the training implementation to a commit or tag. arXiv v3 predates GitHub v0.1.0 and v0.2.0; current main is later again, and its SWE training README is incomplete. Reproduction therefore faces version drift across `verl`, vLLM, tool plugins, environment schemas, datasets, models, indexes, databases, containers, APIs, and caches.
- The six verifiers have distinct blind spots. Exact match can reject semantically correct formats; SQL execution on one database can accept a semantically wrong query with the same observed result; the DeepSearch `0.1` call bonus and visual curiosity term can reward unnecessary calls; SWE reward is sparse and sensitive to tests, dependencies, resources, and container state. These are curator inferences from the disclosed reward definitions, not measured failure rates.
- `valid` and `done` are interface signals, not semantic process labels. An action can be syntactically valid while strategically wrong, and a terminal environment can still represent task failure. Observation masking also does not detect corrupted, stale, adversarial, or misleading tool output.
- A uniform item-level split, cross-domain deduplication, benchmark-overlap audit, and decontamination procedure are unknown. Web/search behavior can drift between cached and live sources, and snippet-only evaluation differs from evaluation with an external summarizer.
- The paper is CC BY 4.0 and the repository root is MIT, but there is no complete license chain for upstream datasets, databases, the Wikipedia index, web content and caches, models, containers, submodules, or derived trajectories. The DeepSearch HF task repository has no verified dataset license tag; the SQL reproduction repository's MIT declaration does not establish rights for every upstream asset. Privacy and consent treatment for web/search content are also unknown.
- Appendix A.3 and Table 5/current code disagree over whether the SQL base model is Qwen2.5-7B-Instruct or Qwen2.5-Coder-7B-Instruct. Exact table-to-checkpoint mapping, seeds, variance, and unified hardware/compute attribution are not supplied as a replay manifest.
