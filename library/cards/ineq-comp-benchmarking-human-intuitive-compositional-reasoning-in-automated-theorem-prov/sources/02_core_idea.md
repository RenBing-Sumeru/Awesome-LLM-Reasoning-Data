The official Apache-2.0 Parquet release contains 375 Lean inequality tasks: 75 each in seed, type1, and type2, 100 mix items, and 50 real problems. Type1 emphasizes variable duplication and reparameterization, type2 algebraic rewriting, and mix composes several elementary inequalities. The repository also provides seed proofs and evaluation scripts. Formal statements and Lean proof success are the core objects, making this an evaluation and verifier-guided-search resource rather than a large SFT corpus.
