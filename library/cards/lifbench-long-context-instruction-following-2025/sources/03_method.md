1. **Scenario and task definition:** Three long-context application scenarios and 11 tasks requiring simultaneous satisfaction of multiple constraints are selected.
2. **Base-instruction authoring:** Inputs, target outputs, and verifiable requirements are defined so evaluation does not depend on subjective prose quality.
3. **Automatic expansion:** Context length is increased, instructions are paraphrased, and variables are substituted to create 2,766 instances across six length ranges.
4. **Rubric compilation:** Natural-language constraints are converted into LIFEval checks, with deterministic logic written for each requirement.
5. **Stability evaluation:** Twenty models are compared on overall scores, constraint-level errors, and performance variation across different versions of the same task.
