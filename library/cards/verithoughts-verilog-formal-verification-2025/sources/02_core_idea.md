VeriThoughts releases about 20,173 training records and 291 test problems, forming a large formally checked reasoning dataset for Verilog. Each record contains a reference module `V`, a synthesized question `Q`, reasoning `R`, a model-generated module `V*`, and a formal-consistency label `Lc`. The release includes not only consistent samples but also some inconsistent or question–generated-answer pairs that remain internally coherent, enabling research on data difficulty, hallucinated prompts, and the effect of formal labels on downstream HDL generation.
