Earlier Verilog datasets commonly rewrite GitHub modules into problems or use human-written testbenches to judge final code, usually without full reasoning or formal-consistency labels. VeriThoughts changes the record structure by connecting a reference module with a backward-generated question, reasoning trace, candidate RTL, and equivalence result. Researchers can therefore recombine `Q–V`, `Q–V*`, and consistent or inconsistent subsets. The novelty is not merely using formal verification, but retaining its result as an analyzable supervision dimension instead of only a binary deletion rule.
