**Proxy target and verifier boundary.** Gold locations are derived from code modified by the resolution patch. This is an auditable proxy, not a complete definition of all code relevant to understanding an issue: necessary but unmodified context may be absent, and a modified location may reflect an implementation choice rather than unique relevance. The verifier scores terminal set overlap and does not execute tests, validate a repair, or judge whether intermediate commands and reasoning were efficient or faithful.

**Zero reward is under-specified.** The release preserves 8,281 zero-localization-reward rows, but it does not label whether each zero comes from wrong locations, a missing or malformed finish call, turn-budget exhaustion, environment failure, cancellation, or retry. Generator code distinguishes some of these paths and loss-masks maximum-step no-finish rollouts, yet `loss_mask`, `stop_reason`, and error category are absent from public rows. A zero therefore cannot be treated uniformly as a semantically wrong search.

**Count and group provenance.** The 54,845 released rows exceed the paper's nominal direct-RL budget by 3,645. The 14B release contains 160 additional four-attempt groups; the 4B release contains 379 additional groups, and six 4B groups are incomplete with one through six members. No immutable run manifest explains whether these are restarts, retries, resumed training, evaluations, duplicated logging, or valid extra optimizer steps. Analyses must not assume one released row corresponds to one unique planned training rollout.

**Configuration drift.** The paper specifies four rollouts/four turns for 14B and eight rollouts/six turns for 4B. The inspected scripts default to eight/six for 14B and eight/ten for 4B. Free-form Hydra overrides make paper-matching launches possible in principle, but exact commands and resolved configurations for reported experiments are unavailable. A pinned repository commit is therefore insufficient to recover the paper configuration.

**Replay and reward recomputation.** Rows contain a task key but omit repository URL, base commit, applied bug-inducing patch, patch-derived gold sets, immutable environment or container ID, generating checkpoint SHA, seed, full sampling settings, logprobs, stop reason, and loss mask. Reward recomputation requires an external join to the processed task artifact; exact trajectory regeneration requires additional unreleased state. The code pins SkyRL and OpenHands SDK revisions, but no end-to-end lockfile/run manifest and no complete training guide were found.

**Coverage and contamination.** Gold extraction and experiments are centered on Python repositories. The terminal scaffold may generalize, but extraction rules for other languages, build systems, generated code, renames, and cross-language changes are not established. The paper excludes the 128 training repositories from repositories in SWE-Bench Verified, Lite, and Pro-Python, but reports no issue-text, patch/code-content, near-duplicate, or pretraining-contamination audit. Repository-level separation does not settle these broader overlaps.

**Reward shaping.** The 14B exact-four-turn bonus rewards interaction length independently of localization quality. It may distinguish preferred-length trajectories, but it can also make two equally wrong attempts receive different total training signal. Conversely, a no-finish trajectory at the turn limit is loss-masked even if its search transcript contains useful partial evidence. Without a published top-level total and loss mask per row, downstream users cannot reproduce exposure to all released traces.

**Release scope and lineage.** The public artifact covers 4B and 14B training rollouts only. Evaluation rollouts are released elsewhere, while the 4K success-filtered 1.7B RFT examples and 1.7B RL rollouts are not mapped into this dataset. The relationship among these releases should not be inferred from model names or shared `instance_id` strings without an official manifest.

**Licensing.** The paper is CC BY 4.0 and the code is MIT, but the checked rollout dataset and processed SWE-Smith code-search dataset have no declared dataset license or license file. Rights for upstream repositories, issues, patches, derived targets, and generated chats are not documented as a unified chain. Public downloadability is not authorization for redistribution, commercial training, or derivative release.

The status remains `partial`. The artifact is unusually useful for inspecting repeated terminal-search attempts and failures, but exact training-set membership, failure causes, experiment configuration, record-level replay lineage, broader contamination, and data reuse rights remain unknown.
