This report is a useful blueprint for building auditable agent-training data. It shows how to define the episode object, draw the environment boundary, select a verifier that matches the deliverable, and retain executable evidence. The SWE, Terminal-Gym, search, spreadsheet, and slide pipelines offer concrete patterns for turning noisy real-world sources into tasks with workspaces and success predicates. Its distinction between deterministic verification, agent/rubric judging, and multi-signal acceptance is especially useful for risk-tiering data.

It is not a reusable dataset release. Practitioners can borrow the contract and audit checklist, but cannot reconstruct the reported mixture or training run from public artifacts. Any downstream Card or survey should keep M2, M2.5, and M2.7 evidence separate where relevant and avoid using benchmark leadership as a substitute for corpus documentation.
