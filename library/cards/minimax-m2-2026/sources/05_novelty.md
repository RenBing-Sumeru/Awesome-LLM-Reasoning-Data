The notable contribution is an end-to-end agent-data contract that binds task synthesis, executable workspace construction, trajectory generation, and artifact-specific acceptance. Rather than reducing all agent outputs to textual preference scores, the pipelines use native evidence where possible: tests, runtime state, retrieved sources, recalculated workbook values, or rendered slides. The report also introduces variation across teacher models and agent scaffolds instead of relying on one fixed trajectory source.

Forge complements this contract by placing the policy/environment boundary at the generation interface and decoupling agent rollout, storage, inference, and training. Windowed-FIFO scheduling handles heterogeneous episode duration, while prefix-tree merging and inference optimization target repeated prefixes and rollout cost. None of these ingredients alone is entirely new; the contribution is their coordinated use at long context and across many artifact types. The report’s M2.7 self-evolution case is an operational demonstration, not a released self-improving data system.
