The MiniMax-M2 report targets long-horizon agent training rather than isolated chat completion. Coding, web research, spreadsheet work, slide production, and other knowledge-work tasks can span many model calls, tool observations, mutable artifacts, and context-management operations. A useful training object must therefore include a runnable workspace, an action/observation trajectory, and an acceptance signal tied to the final artifact or environment state.

The report’s data contribution is a family of agent-driven pipelines that construct such objects for software engineering, application development, terminal work, open-web research, office artifacts, finance, spreadsheets, slides, reasoning, conversation, and role-play. The central audit question is whether task construction and reward design preserve objective evidence through these long trajectories. Counts, full schemas, source manifests, teacher identities, and released trajectory artifacts remain undisclosed.
