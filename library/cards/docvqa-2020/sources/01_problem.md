DocVQA: A Dataset for VQA on Document Images defines an evaluation surface in document-vqa, ocr, layout-understanding: whether model outputs or agent trajectories satisfy the task-specific feedback contract. The primary source and artifacts are paper: https://arxiv.org/abs/2007.00398; project: https://www.docvqa.org/; data: https://www.docvqa.org/; doi: https://doi.org/10.48550/arXiv.2007.00398; the local metadata records the source as 2020 / WACV 2021 / arXiv; DocVQA Challenge 2020.

The decision boundary is benchmarks_evaluation_surfaces with roles benchmark and verification contract programmatic. One benchmark instance is: document image, natural-language question, one or more text answers, split/task metadata, and evaluator output such as answer similarity. This is not a model-training recipe unless the paper separately releases training data; the card treats it as evaluation, audit. It matters for the atlas because the reusable object is an evaluation/data record with a named scorer, judge, verifier, reward, or environment predicate rather than an abstract capability claim.
