The key reading boundary is the feedback contract: A reward model succeeds on an instance when it assigns a higher score to the preferred/chosen response than the rejected response. Do not mix aggregate leaderboard scores with row-level verifier evidence, and do not treat public evaluation data as clean training data.

Read the artifact/version notes before comparing models. If the benchmark uses a judge, separate judge agreement from ground truth; if it uses executable checks, separate checker acceptance from broader semantic correctness.
