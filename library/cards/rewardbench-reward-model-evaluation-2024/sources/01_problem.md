RewardBench: Evaluating Reward Models for Language Modeling defines an evaluation surface in reward-modeling, judge-reward-meta-evaluation: whether model outputs or agent trajectories satisfy the task-specific feedback contract. The primary source and artifacts are paper: https://arxiv.org/abs/2403.13787; code: https://github.com/allenai/reward-bench; doi: https://doi.org/10.48550/arXiv.2403.13787; the local metadata records the source as 2024 / Findings of ACL: NAACL 2025 / arXiv.

The decision boundary is benchmarks_evaluation_surfaces with roles benchmark, verifier_reward and verification contract judgment_required. One benchmark instance is: Prompt, chosen response, rejected response, subset/category metadata, reward-model scores, and pairwise correctness outcome. This is not a model-training recipe unless the paper separately releases training data; the card treats it as evaluation, audit. It matters for the atlas because the reusable object is an evaluation/data record with a named scorer, judge, verifier, reward, or environment predicate rather than an abstract capability claim.
