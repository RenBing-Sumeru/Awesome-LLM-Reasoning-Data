BarrierBench contains 100 safety-certificate tasks spanning linear and nonlinear, discrete-time and continuous-time systems. Each task specifies dynamics, initial and unsafe sets, and variable domains, with some requiring controller co-synthesis. Candidate barrier functions are checked by an SMT solver for initial conditions, separation from unsafe states, and invariance along dynamics. Records can include system definitions, candidate functions, solver results, and repair traces. The project releases the benchmark and toolchain; dataset licensing requires confirmation from the download page.
