**输入与构造。** 作者为 flight、hotel、apartment、rental-car 与 restaurant 整理旅行偏好及多种间接 elicitation expression；Table 2 报告最终 82 个 preference 与 902 种 elicitation way。偏好被随机组合为 Travel-22、2222、33、233、333、44、334、444 等难度分层 composition，GPT-4o 生成理想 travel-arrangement statement。对每个纳入的 aspect，GPT-4o 还在人工监督下生成满足全部偏好的 correct option、至少违反一项偏好的 wrong option，以及无关或不现实的 noise option。确切构造 prompt、GPT-4o endpoint、temperature、retry policy、random seed、拒绝数量、curator 分工与 adjudication process 均未披露。

**任务封装与 split。** 八个 JSON 文件保存 scenario 级 preference structure、隐式 utterance、search argument、带类型的 option 与理由、correct/wrong/noise ID、一个 `best_id` 及 `best_id_thought`。官方 release 再把这些任务包装为 single-choice 与 multi-choice 模式下的 32 个 train/test Parquet 文件。对全部 ID 的核验得到 3,122 个唯一任务：2,651 train、471 test，ID 零重叠。两个 choice variant 重复相同 task ID，因此共有 6,244 行序列化记录，但不是 6,244 个唯一 scenario。split 规则、seed、语义近重复检查与去污染均为 unknown。

**Reset 与 action loop。** reset 返回 task description、goal、feedback、step count、episode state、preference count/ratio 与 last reward。每一步必须调用 `interact_with_env(thought, choice, content)`。`search` 请求某个 aspect 的 option，`action` 向用户提问或对话，`answer` 提交 option ID。环境记录 action 与 conversation history，跟踪 active/passive elicitation，并返回模拟用户 utterance、search feedback 与打乱顺序的预生成 option，或 answer feedback。agent 的 `thought` 只是被保存的输出字段，没有独立真实性验证。

**Judge、reward 与环境。** GPT-4o 判断 search text 是否匹配全部 ground-truth argument，并识别所请求 aspect；首次有效搜索奖励 0.2，并暴露对应 option database。GPT-4o 还分类澄清 utterance；针对可用偏好的有效问题会以间接表达揭示该偏好，并奖励 0.2。连续三个非偏好 turn 后，默认环境通过 Python `random.choice` 被动揭示一个剩余偏好。规则代码解析 answer ID：`best_id` 得 1.0，其他 correct ID 得 0.8，wrong ID 默认得 0.0。没有剩余 best option，或 one-choice 模式下每个 aspect 都已记录一个 answer 时，episode 终止；达到 step limit 时截断。

**评测与发布边界。** 主实验采用 GPT-4o 作为 user simulator/judge，temperature 0、最多 20 个 turn、每 turn 最多 2,048 output token，且每个 model-task 运行一次；论文报告使用八张 H200 承载评测。配置中每第五次 search 会模拟失败。公开仓库发布 task/environment data、evaluator code、prompt、schema 与 Parquet 启动记录，但没有论文运行 episode、raw judge output、retry 或 environment log 的完整语料。复现应固定 commit `80506d2`、全部 data file、dependency、environment configuration、确切 model endpoint、prompt、API behavior，以及 Python 和 NumPy 随机性。论文实际只做 evaluation，没有报告 SFT、RL 或 agent-training 实验。
