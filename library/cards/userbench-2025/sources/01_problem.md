UserBench studies a concrete interaction problem: a travel-planning agent receives an underspecified request, must discover implicit preferences through clarification, issue searches against a mock database, and recommend option IDs across flight, hotel, apartment, rental-car, and restaurant aspects. Static answer scoring cannot expose whether the agent asked a useful question, searched with complete constraints, tracked which aspect had been handled, or guessed before enough information was available. UserBench therefore makes the environment and its feedback part of the evaluation surface.

The reusable release is a task/environment specification rather than a corpus of completed trajectories. An underlying JSON task binds a scenario ID and initial request to difficulty, travel dimensions, explicit and implicit preference expressions, structured search arguments, correct/wrong/noise option records, correct IDs, and one designated `best_id` with rationale. Parquet rows wrap the task with system/user prompt messages, split, environment name, ground-truth IDs, and environment-construction arguments. At runtime, an episode adds agent `thought`, search/action/answer calls, simulated-user or database observations, conversation/action history, preference state, scalar rewards, and termination or truncation. No complete archive of the paper's successful and failed episodes was verified.

This object belongs in `environment_agent_trajectory_data` because observations, tool actions, environment responses, state changes, rewards, and terminal conditions define the measurable reasoning process. Its role is evaluation only in this paper: the named train split and discussion of possible SFT/RL support are prospective, not evidence of model training. Current evidence supports L4-depth description of the object, construction, mixed feedback contract, evaluation, release, and audit risks, while the accepted `curation_level` remains `L3_summary_ready`. Construction prompts, judge calibration, semantic split leakage, data-specific rights, and replay manifests remain unknown.
