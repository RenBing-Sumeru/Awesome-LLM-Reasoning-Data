The method first defines a target distribution combining the base diffusion distribution with verifier scores, so that high-scoring outputs are preferred during sampling. For an individual candidate, annealed Langevin MCMC adds local updates determined by the gradient of this target distribution at each denoising stage, alternating with ordinary denoising. For multiple candidates, BFS allocates child nodes in proportion to scores of intermediate predicted samples, or gradually removes weak particles through pruning; DFS follows one path and returns to a higher-noise level for renewed exploration when its score falls below a threshold. Experiments use maze-collision loss, a pretrained Q-function in offline reinforcement learning, and class or attribute verifiers for images, comparing against naive sampling and Best-of-N under matched budgets.
