The method is constrained by several conditions. First, if a verifier favors superficial features, becomes unreliable off distribution, or can be exploited by candidates, search may amplify the wrong objective more efficiently rather than improve real task quality. Second, Langevin step size, reweighting strength, BFS particle budget, DFS threshold, and backtracking distance all affect stability and cost; the paper itself notes that search-based inference needs more hyperparameter tuning than naive sampling. Third, local gradient refinement and tree search add verifier calls, memory use, and wall-clock time, so superiority cannot be claimed from final scores alone. Finally, the subject is continuous diffusion generation: it provides evidence for non-autoregressive test-time scaling, but does not directly establish benefits for language-model chain-of-thought reasoning or tool-using agents.
