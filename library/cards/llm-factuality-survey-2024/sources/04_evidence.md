The survey's evidence base is the factuality literature it analyzes, rather than one newly collected experiment. Its central empirical warning is that factuality evaluation for open-ended generation still has unresolved obstacles. Therefore, an automatic score is not self-explanatory: a reader should ask what counts as factual in that setting, what source or reference information supports the judgment, which generated claims are being assessed, and how the final decision is produced. The same numeric result can be easier to interpret on a tightly specified task than on an unconstrained response containing several claims. Evidence should consequently be read together with the task setting and the judgment procedure.
