Use this paper before choosing a hallucination or factuality benchmark, interpreting a vendor claim, or designing an open-ended evaluation. It helps turn the broad statement “the model is more factual” into a concrete reading checklist: factual with respect to which source or evidence, for what kind of generated claim, under which prompts and task conditions, and judged by what procedure? It is also useful when comparing two results that use different reference materials or automatic measures. The survey does not select a benchmark for the reader; it helps the reader identify which properties a suitable benchmark and judgment setup need to make visible.
