在"数据构造与开放发布"赛道中,SWE-smith 最适合作为一套完整案例:如何把一个经核验的仓库环境扩展成大量可执行训练任务。整理者可以按成本、产率、修改范围、受影响测试和下游轨迹效用比较五种候选路线,而不是把所有合成任务视为同质对象。任务表还适合研究仓库级采样、测试覆盖偏差、问题生成泄漏和环境成本摊销。

论文时点的 5,016 行轨迹快照在匹配 SWE-agent 动作表示后,可用于智能体监督训练和教师蒸馏。更大的后续轨迹修订包含结果、模型、轨迹 ID 和提交补丁字段,并至少保留部分未解决样本,因此可用于失败分析。但不能把其中所有行都当作成功 SFT 子集,也不能在没有确认分片关系的情况下直接相加三个后续分片的行数。

最低限度的复用清单应固定任务和轨迹提交哈希、Docker 镜像摘要、源提交、仓库许可、安装/测试/解析器说明、SWE-agent 与执行框架修订、动作模式、教师身份、运行上限和解码设置。还应说明用途究竟只需成功示范、需要平衡的成功/失败语料,还是要求完整尝试账本。如果重放不能复现保存的 `resolved` 值,应把结果降为未知,而不是把旧标签当作新的验证。

这些任务适合后训练实验、环境与脚手架研究、判定器诊断和合成数据审计。若没有额外隐藏测试与问题质量审查,则不适合作为无污染排行榜基准。
