TrimR first segments generated reasoning using reflection markers and extracts the candidate answer carried by each sub-thought. A pretrained instruction-tuned verifier performs answer-existence and answer-equivalence checks. If consecutive sub-thoughts already support the same conclusion, the controller detects overthinking and can terminate or prompt the model to finish; it also removes repeated material. When no usable conclusion emerges, its underthinking handling supplies a prompt intended to make the reasoning continue more productively instead of merely extending the same pattern.

The paper pairs this controller with an asynchronous online system for high-throughput serving. The larger model and the verifier are not fine-tuned for this procedure. The relevant record at inference time consists of segmented thoughts, verifier outcomes, an intervention decision, and final task output. Thus the added computation is explicitly budgeted: a verifier call is worthwhile only if avoiding redundant long-form decoding offsets its own cost.
