- **没有可检查的发布。** 本卡未核验到作者确认的代码、数据集、项目页、schema、license 或不可变快照。各阶段 generator 分工、环境/库版本、附录以外 prompt、seed、重试/超时策略、文件/split ID 和逐条溯源均无法回放审计。同名第三方数据集不能作为本论文的证据。
- **计数 lineage 不完整。** 表 7 的保留池比表 2 最终 train+test 多出 5,086 条单图问答、376 条多图问答和 1,071 张单图表；多图计数还混用了图对/图像单位。没有后续 attrition 或成员台账解释差额。
- **执行不等于视觉验证。** 数据、渲染和分析程序即使能运行，也可能出现标签重叠、数值不可见、图表误导，或问题依赖不可见源数据。论文本身也指出，72B MLLM 仍会漏检遮挡与布局缺陷。
- **Rationale 可能使用特权信息。** 附录要求答案生成器完全信任分析代码输出，并在不提代码的情况下把它写成由图表像素推得。这会导致事后合理化和视觉上无法复现的计算。
- **学习型筛选校准有限。** Qwen2-VL-2B 质量分类器使用 1,200 条人工纠正样本，只在 107 条验证样本上报告指标。约 5,800 条 instruction 审计先由 Claude 3.5 判断，只对初判错误项做 Claude/人工双重检查；它不能给出全语料误差率，也不能独立验证初判通过项。
- **Reward 与评测是混合契约。** Qwen3-32B 提供开放答案 RL reward，Qwen-Max 判断 benchmark。准确模型 revision、校准、假阳性/假阴性、分歧处理、prompt 敏感性和对抗稳健性均为 unknown。benchmark judge 接受部分表达/单位变化与 5% 数值误差，而闭合题型 RL reward 使用 strict match。
- **RL 不能验证 CoT。** GRPO 排除构造的 CoT path；所需 think block 只按语法获得 format reward。30K 集的规则/模型 reward 数量为 13,692/16,308，只是近似平衡。RL 增益支持该 reward 下的最终答案优化，不支持 explanation 正确性。
- **Split 与污染控制未知。** 论文没有给出不可变 split 规则、模板/来源族分组、近重复检查，也没有审计源图表、复刻风格、few-shot 示例、prompt、ChartQA、ReachQA、CharXiv 或其他评测集的重叠。
- **人工与权利审计不完整。** 论文说明了同意、隐私、补偿、匿名化和人工 benchmark 修订，但没有给出标注人数、资质、说明、agreement 或逐条修改。论文称遵守所用 artifact 的 license，却没有发布收集图表、复刻风格、模板、生成图像/代码或再分发的来源 URL 与权利清单。
- **覆盖范围有限。** 渲染主要基于 Python 并聚焦统计图表；流程图、关系图、其他可视化语言及更大模型/数据规模的 RL 被明确留作未来工作。
