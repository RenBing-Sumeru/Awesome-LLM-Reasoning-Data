Chart templates, programmatic chart rendering, program-of-thought calculation, multimodal filtering, and RLVR each have precedents. ChartM3's distinctive contribution is the breadth and integration of an end-to-end lineage over 62 chart subtypes: a retrieved style/template conditions data-code generation, rendering code turns structured values into pixels, analytical code computes answers, and learned/human filters select records for CoT-SFT, evaluation, or final-answer GRPO.

The pipeline separates several verification roles that should not be collapsed. Program execution checks operational validity; a classifier checks chart presentation; multimodal judges check relevance, accuracy, and logic; sampled models estimate difficulty; humans refine the test set; exact match verifies closed-form RL answers; Qwen3-32B judges open-form rewards; and Qwen-Max judges benchmark predictions. This layered design is more realistic than labeling the whole corpus “programmatically verified.”

Its most revealing feature is also a trace-faithfulness risk: analysis code is executed on source data, and the rationale generator is instructed to conceal that source and narrate the result as visual reasoning. The novelty is therefore a scalable, multi-view construction recipe—not mechanical certification that every explanation reflects information available in the rendered chart.
