DialogTool is useful to the Environment & Agent Trajectory Data track as a schema for stateful conversational episodes. It supports studies of tool abstention, requests for missing arguments, transactional confirmation, App/API routing, argument normalization, use of prior results, error propagation, and role-conditioned response generation. VirtualMobile's deterministic calls can also serve as unit tests for generated tool functions.

A replayable derivative should retain source record and split, dialogue turn, action state, App/API schema version, required/optional arguments, prior and updated environment state, raw call/result/exception, generated response, verifier outputs, model/prompt/version, seed, and reset result. Successes, failures, malformed calls, missing-argument cases, API exceptions, recovery attempts, and timeouts should all remain, with an episode-level completion predicate added separately from component metrics.

The evidence supports evaluation and controlled data generation, not unrestricted training reuse. Before SFT, preference learning, or agent optimization, curators need an official licensed release, decontaminated train/evaluation boundary, source lineage, privacy review, generated-code sandbox, and versioned reset/replay harness. Benchmark performance alone is not evidence that the underlying trajectory corpus is complete or safe.
