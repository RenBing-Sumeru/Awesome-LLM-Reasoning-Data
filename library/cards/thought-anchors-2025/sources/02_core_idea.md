The central intervention operates on prefixes. Let a base trace contain sentences \(S_1,\ldots,S_i,\ldots,S_M\). In the keep condition, generation resumes after \(S_i\); in the remove condition, the prefix ends before \(S_i\), so a replacement sentence and the remainder of the trace are sampled from that point. The paper draws 100 continuations for each condition. These two empirical answer distributions—rather than one selected completion—are the primary feedback object.

Sentence importance is measured in two related ways. Accuracy importance compares changes in the probability of reaching the MATH reference answer. Resampling importance uses KL divergence between the final-answer distributions. Counterfactual importance further restricts the remove/resample side to replacement sentences judged semantically different from the original: all-MiniLM-L6-v2 embeddings must have cosine similarity below 0.8, the reported median over original/resampled pairs. A separate forced-answer branch interrupts the trace at every position, appends text beginning “Therefore, the final answer is \(\backslash\)boxed{”, and samples 100 completions.

The feedback contract is mixed rather than a learned reward. Repository code extracts and normalizes boxed answers, compares them with MATH ground truth, and stores correctness plus empirical distribution metrics such as accuracy, KL-based importance, `different_trajectories_fraction`, and `overdeterminedness`. OpenAI GPT-4o, used during April–May 2025, adds eight-way sentence-function labels and direct-dependency annotations. Those labels are model judgments, not human gold; the terminal correctness predicate remains programmatic.

The released data object keeps multiple layers of this process. Raw problem directories include `problem.json`, `base_solution.json`, `chunks.json`, `chunks_labeled.json`, and `chunk_X/solutions.json`. A continuation record can include the removed chunk, prefix without that chunk, resampled chunk, full CoT, extracted answer, and `is_correct`. The Hugging Face dataset-compatible layer does not flatten these continuations into one row each; instead, each row represents a file with `path`, `filename`, `extension`, `size_bytes`, and textual `content`.

“Thought anchor” is the paper’s interpretation of a sentence with outsized downstream influence, especially a planning or uncertainty-management sentence. The released object supports auditing that interpretation because users can inspect the continuation evidence and negative outcomes beneath a derived score. It does not establish that every high-KL sentence is a semantically faithful cause, that an anchor is always beneficial, or that the trace text fully represents the model’s internal computation.
