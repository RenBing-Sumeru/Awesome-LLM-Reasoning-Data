The contribution is a large cross-domain text-to-SQL benchmark that moves beyond schema-only parsing toward database-value comprehension. BIRD contains 12,751 question-SQL pairs over 95 databases, about 33.4 GB of content, and 37 professional domains. The core mechanism is to pair human-curated questions and SQL with real database contents and evidence, then score generated SQL by execution and efficiency. Closest comparisons are Spider and WikiSQL; BIRD changes scale, value grounding, and efficiency pressure.
