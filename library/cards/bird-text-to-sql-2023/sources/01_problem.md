BIRD was released on arXiv in May 2023 and listed as NeurIPS 2023. It asks whether text-to-SQL systems can operate over large, realistic relational databases where database values, dirty contents, external evidence, and SQL efficiency matter. The evaluation object is a natural-language question paired with a database id, schema/content, optional evidence, and a gold SQL query. The feedback contract is execution accuracy and valid efficiency scoring in the official evaluator. It belongs as a database-grounded reasoning benchmark, not as a conversational DB agent or general SQL training recipe.
