The prior baseline is Spider/WikiSQL-style semantic parsing over smaller or less content-heavy databases. BIRD changes the object by making database values, external evidence, dirty contents, and query efficiency central to evaluation. The quality signal is the public project page, code, train/dev links, leaderboard, and CC BY-SA 4.0 license notation in the official repository. What is not new: SQL execution accuracy and supervised text-to-SQL training. Before reuse, inspect split cleanliness, database redistribution terms, dialect assumptions, evidence availability, VES timeout policy, and contamination from public answers.
