Rather than treating a policy’s ordinary majority vote as truth, the method asks whether the answer survives a deliberately flattened version of that same policy. The harmonic election links exploitation and exploration, while the 0.5 reserve reward and adaptive sampling keep exploration from immediately dominating the update. This is a different intervention from adding an external verifier or more samples; it targets a specific failure of self-generated consensus. It does not solve shared model blind spots, because both distributions can still agree on the same wrong answer.
