The closest PRM data pipelines either label every reasoning trajectory with an LLM judge or estimate step values through many Monte Carlo rollouts. The former is expensive, while the latter is computationally intensive and weak at locating the first error. ActPRM changes which trajectories receive step labels: before annotation, it uses the current PRM’s mean confidence and ensemble disagreement and restricts uncertainty checking to the portion before the predicted first error. Shared backbones, multiple heads, and LLM judges are not individually new. The novelty is their combination into an active annotation loop that concentrates process-supervision budget on trajectories the current PRM cannot judge reliably.
