The central abstraction is a **reasoning flow**: an ordered sequence of outline-level steps, separate from the prose rationale. For 1,000 Magpie-Reasoning-V1-150K questions, the authors manually collect o1 reasoning-flow summaries from the public o1 web interface and estimate each unobserved thought budget from API completion tokens minus returned-response tokens. These triples—question, flow, budget—form demonstrations rather than final SFT traces.

For each new Magpie question, the pipeline retrieves a demonstration by category overlap and budget similarity. GPT-4o predicts how many outline steps are needed, writes the new flow, and expands it one step at a time while seeing previous rationales, the current outline, and the next outline. It then produces the final solution. A second GPT-4o judgment compares the generated answer span with the reference answer and filters the result. The same outline-count mechanism also creates 100%, 50%, and 25% budget variants.
