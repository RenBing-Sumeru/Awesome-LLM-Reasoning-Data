Both the 1K seed set and the claimed 100K collection stem from Magpie-Reasoning-V1-150K, which selects long examples from reasoning, mathematics, and coding/debugging categories. Magpie main-category matches receive 1 point and each matching subcategory receives 0.2; this domain score is multiplied by a budget-similarity score based on the ratio of the smaller to the larger budget. The paper does not disclose source-row IDs, tie breaking, or an immutable selected-row manifest.

The seed object is `(q, S_ref, b_ref)`: a question, an o1 reasoning-flow outline manually copied from the public o1 web interface, and an estimated count of unobserved o1 thought tokens. For a new question, GPT-4o receives the retrieved demonstration, predicts the number of steps, and generates a new outline sequence. Each rationale step is then conditioned on all earlier generated rationale text plus the current and next outline entries. After the outline is exhausted, GPT-4o generates the final solution and the pipeline concatenates the steps and answer.

Filtering is answer-level and model-judged. The Appendix F prompt gives GPT-4o the problem, generated attempt, and reference solution and asks for a Yes/No correctness decision. The paper reports that filtering leaves 76% as correct-answer predictions. This is not a symbolic verifier and does not separately certify every intermediate step. Generation temperature, candidate multiplicity, retries, random seeds, API snapshots, absolute token cap, and per-row judge outputs are unknown.

Thought-budget control changes the enforced number of outlines to produce 100%, 50%, and 25% versions. The paper reports traces with as many as 30 reasoning steps and 20K thought tokens. Its cross-model budget comparison is heterogeneous: OpenAI hidden tokens are inferred from API usage, R1 text inside think-tag spans is counted with a GPT tokenizer, and local-model text inside thought-tag spans is counted separately.

The downstream SFT study trains Qwen-2.5-7B-Instruct and Llama-3.1-8B-Instruct with LLaMA-Factory on four A100 GPUs: BF16, 3 epochs, learning rate `5e-6`, maximum length 8,192, batch size 1, and gradient accumulation 8. A separate GRPO study starts from Qwen-2.5-0.5B-LC, uses 10K integer-answer NuminaMath Olympiad/AMC problems with OpenRLHF and RingAttention on 16 A100 GPUs, and applies length similarity to o1-mini, latex2sympy answer equivalence, and format rewards. Its settings are BF16, 5 epochs, learning rate `5e-7`, maximum length 16,384, batch size 64, and 16 samples per prompt.
