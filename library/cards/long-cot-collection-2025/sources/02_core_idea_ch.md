核心抽象是**推理流**：它是按顺序排列的提纲级步骤，与展开后的自然语言推理文本相互区分。针对 Magpie-Reasoning-V1-150K 中的 1,000 个问题，作者从公开的 o1 网页界面人工收集推理流摘要，并以 API 的 completion token 总数减去返回回答的 token 数来估计不可观测的思考预算。这些“问题—推理流—预算”三元组充当示范，而不是最终 SFT 轨迹。

对于每个新的 Magpie 问题，流水线按类别重合度和预算相似度检索一个示范。GPT-4o 先预测所需提纲步骤数并生成新推理流，再在看到既有推理、当前提纲和下一提纲的条件下逐步扩写，最后生成完整解答。随后，另一次 GPT-4o 判断把生成答案片段与参考答案比较并执行过滤。同一套提纲数量控制还被用于生成 100%、50% 和 25% 三种预算版本。
