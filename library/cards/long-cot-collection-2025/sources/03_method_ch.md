1K 种子集与论文声称的 100K 集合都源于 Magpie-Reasoning-V1-150K；该上游数据从推理、数学以及代码/调试类别中选取长样本。Magpie 主类别相同记 1 分，每个相同子类别再记 0.2 分，领域分数与按较小预算/较大预算之比构造的预算相似度相乘。论文没有披露源行 ID、并列时的处理规则或不可变的入选行清单。

种子数据对象为 `(q, S_ref, b_ref)`：问题、从公开的 o1 网页界面人工抄录的推理流提纲，以及估算的 o1 不可观测思考 token 数。面对新问题时，GPT-4o 接收检索到的示范，预测步骤数并生成新的提纲序列。扩写每个推理步骤时，它会看到此前全部推理文本、当前提纲与下一提纲；提纲用尽后再生成最终解答，并把各步与答案拼接起来。

过滤属于答案级模型判断。附录 F 的提示向 GPT-4o 提供问题、生成尝试和参考解答，并要求输出 Yes/No 正确性判断。论文称过滤后有 76% 被预测为答案正确。这不是符号验证器，也不会逐步证明中间推理。生成温度、候选数、重试次数、随机种子、API 快照、绝对 token 上限和逐行判断结果均未披露。

思考预算控制通过约束提纲数量产生 100%、50% 与 25% 三种版本。论文称轨迹最多可达 30 个推理步骤和 20K 个思考 token。跨模型预算比较采用了不同计量面：OpenAI 的隐藏 token 由 API usage 推算，R1 的 think 标签区段由 GPT tokenizer 计数，本地模型的 thought 标签区段则另行统计。
