Open reasoning-model builders often obtain long chain-of-thought supervision by distilling outputs from an existing long-reasoning model. That can reproduce a capability, but it also inherits dependence on the teacher's undisclosed training history, output policy, and serving interface. This paper asks whether an ordinary short-CoT model can instead write long traces when it receives a compact description of how a long-reasoning teacher organizes its search.

The data problem is therefore more specific than “make responses longer.” A useful example must pair a question with a coherent reasoning-flow plan, allocate an appropriate thought budget, expand the plan without losing context, reach the reference answer, and remain suitable as supervised initialization before RLVR. The paper describes such a collection at 100K scale, but its publication does not provide a usable artifact URL, so the claimed collection and the publicly auditable data object must be kept separate.
