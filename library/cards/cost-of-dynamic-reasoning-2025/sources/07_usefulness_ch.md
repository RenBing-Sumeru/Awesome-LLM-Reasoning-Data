对 Rollout, Search, and Test-Time Trace Data，本研究明确了 agent 成本记录在复用前应保留的 provenance 字段：benchmark item ID 与 split、精确 prompt 与 tool、model/checkpoint 与 serving-stack version、agent type、few-shot 数量、iteration/reflection/branch limit、带时间戳和 token count 的每次 LLM/tool event、terminal score、GPU utilization/power sample、energy integration rule、concurrency 与 caching 状态、random seed，以及 aggregation script。将逐请求 trace/telemetry 与准确率、能耗、投影功率汇总分开保存，可按其他预算重新聚合并观察 tail behavior；将 projection 与 measurement 分开，则可避免把场景假设误标为观测值。已发布代码可支持重新采集，但论文专属原始记录缺失，因此不能直接把公布数值复用为 trace-and-cost dataset。
