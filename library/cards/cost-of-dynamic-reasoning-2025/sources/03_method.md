The evaluation runs Llama-3.1-8B-Instruct on one A100 40GB GCP a2-highgpu-1g instance and uses eight A100 40GB GPUs on a2-highgpu-8g for Llama-3.1-70B-Instruct, served by vLLM 0.6.6 with PyTorch 2.6, CUDA 12.8, and prefix caching enabled unless stated otherwise. HotpotQA uses Wikipedia APIs, WebShop uses interactive navigation, MATH uses Wolfram Alpha and a Python calculator, and HumanEval executes generated tests; correctness is exact match for HotpotQA/MATH, the benchmark score for WebShop, and pass-all-tests accuracy for HumanEval. The design-space study uses 50 sample questions per point and varies few-shot examples, iteration/reflection limits, and LATS branching; serving traffic is sampled with Poisson arrivals. The public AgentBench repository implements the workflows, bundles benchmark inputs, allows trace saving, and includes one small example trace, but does not expose the paper's complete selected-query manifest, random seeds, per-request timing/energy telemetry, or a sufficiently specified device-power integration procedure.
