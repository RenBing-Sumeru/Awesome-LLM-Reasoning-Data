The paper asks a systems question that capability-centered agent evaluations usually leave implicit: how much latency, GPU work, memory, energy, and serving capacity dynamic reasoning consumes as an agent repeats LLM calls and tool interactions. It compares CoT, ReAct, Reflexion, LATS, and LLMCompiler on HotpotQA, WebShop, MATH, and HumanEval, with ShareGPT as a non-agentic single-turn baseline. For this track, the data object is not a new training corpus but the execution record that would connect each benchmark query and agent configuration to its reasoning/tool trajectory, accuracy or task score, latency, token use, GPU behavior, and energy. The paper publishes aggregate characterizations and projections; the complete per-request record set needed to audit or reuse those measurements is not confirmed as released.
