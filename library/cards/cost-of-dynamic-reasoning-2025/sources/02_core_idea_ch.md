论文的贡献是联合刻画准确率与成本，使 agent 设计和 test-time scaling 选择成为显式实验变量。Sequential scaling 改变 iteration 或 reflection 深度；parallel scaling 改变并发探索的 LATS child node 数量；few-shot 数量、模型规模、prefix caching 和请求并发度构成其他控制变量。反馈契约是各 benchmark 自身的正确性或任务得分，设计空间分析主要以端到端时延表示成本，并在选定的 HotpotQA 配置上加入 GPU 能耗。这是评测与基础设施研究，而不是 RL 训练：它不训练 reward model，也不把轨迹筛选成后训练数据集；benchmark performance 只支持对被测配置的判断，不能证明底层轨迹或测量已构成高质量可复用数据集。
