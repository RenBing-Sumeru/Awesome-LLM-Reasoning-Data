For Rollout, Search, and Test-Time Trace Data, this study identifies the provenance fields needed before agent-cost records can be reused: benchmark item ID and split, exact prompt and tools, model/checkpoint and serving-stack versions, agent type, few-shot count, iteration/reflection/branch limits, every LLM and tool event with timestamps and token counts, terminal score, GPU utilization/power samples, energy-integration rule, concurrency and caching state, random seed, and the aggregation script. Keeping per-request traces and telemetry separate from accuracy, energy, and projected-power summaries would permit re-aggregation under other budgets and reveal tail behavior; keeping projections separate from measurements would prevent scenario assumptions from becoming mislabeled observations. The released code can support recollection, but absent paper-specific raw records prevents direct reuse of the published numbers as a trace-and-cost dataset.
