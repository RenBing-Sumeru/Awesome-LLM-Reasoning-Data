The contribution is a joint accuracy-cost characterization in which agent design and test-time scaling choices become explicit experimental variables. Sequential scaling changes iteration or reflection depth; parallel scaling changes the number of LATS child nodes explored concurrently; few-shot count, model size, prefix caching, and request concurrency provide additional controls. Benchmark-specific correctness or task score is the feedback contract, while end-to-end latency is the primary cost in the design-space analysis and GPU energy is added for selected HotpotQA configurations. This is an evaluation and infrastructure study, not RL training: no reward model is trained, no trajectories are selected into a post-training dataset, and benchmark performance is evidence about the evaluated configurations rather than proof that the underlying traces or measurements form a high-quality reusable dataset.
