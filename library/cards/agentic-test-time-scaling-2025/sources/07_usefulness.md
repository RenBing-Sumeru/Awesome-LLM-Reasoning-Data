Use this paper as an experiment matrix when extending a tool-using agent at inference time. Evaluate whole-trajectory versus step-wise branching separately, log trigger scores before adding reflection, compare list-wise judges against scalar scores under the same candidate set, and measure diversity rather than merely counting rollouts. The official OAgents repository is the implementation starting point. For a new environment, add replayable tool traces, wall-clock and monetary cost, failure recovery, and a no-side-effects sandbox before trusting higher pass rates.
