The study uses a small GAIA validation set and proprietary model and tool stacks whose behavior can drift. Its reported budget is mainly search width and strategy choice, not a fully normalized end-to-end cost including web tools, model calls, and list-wise judges. The framework’s conclusions can depend on PRM quality, tool reliability, prompt construction, and the correlation among sampled agents. BoN’s strong result may not hold for tasks with irreversible actions, hidden state, severe tool-rate limits, or very long horizons, so production use needs environment-specific cost and safety controls.
