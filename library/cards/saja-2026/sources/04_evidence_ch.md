**主张。** 单次 rubric 调用加多维校准，可匹配更昂贵的评委对齐系统。**设置。** 作者在公共评分、偏好和分类任务上比较原始 judge、一维校准、SAJA、LLM-RUBRIC、FELIX 与提示优化。

**结果。** SummEval 的 Spearman rho 从原始/一维校准的 0.60 提升到 SAJA 的 0.74，RMSE 从 1.46 降至 0.42（表 3）。LLM-RUBRIC 上，top-2 rubric 标签为 0.36，完整 logit 分布为 0.37（表 4）。MT-Bench F1 从 0.78 升至 0.86；置信度分流以 99.6% 准确率自动处理 44% 案例。

这些证据支持已测 rubric 和标注预算，不保证自动迁移到专门领域：Paper Reviews 落后于 FELIX，专有数据上的 +5.71% 也无法由公开数据独立复现。成本比较还依赖固定的 API 速率与上下文长度，因而应把它理解为一次调用设计的相对优势，而不是所有服务商上的固定节省比例。
