The prior-work baseline is the earlier Phi strategy of teacher distillation plus synthetic textbook-like data, conventional filtered web/code pretraining, rejection-sampled SFT, and full-response DPO. Phi-4 changes the emphasis by using synthetic data throughout pretraining and post-training, searching the curriculum mixture, and converting oracle-estimated local success changes into token-level preference pairs.

At the construction level, the report's contribution is a portfolio rather than one generator. Seed curation, web rewriting, Q&A extraction, self-revision, instruction reversal, execution-backed code validation, and plurality filtering are assigned to different data families. The report also documents why a synthetic-only ablation loses factual recall, motivating a mixed organic/synthetic recipe rather than claiming synthetic data replaces organic knowledge sources.

Pivotal Token Search is the most specific post-training novelty. Standard DPO on divergent full responses spreads preference signal across many tokens. Pivotal Token Search samples continuations around prefixes, invokes an outcome oracle, recursively isolates token choices with a large success-probability change, and trains on a pair differing at that local choice. This creates automated token-local preference supervision without training a separate process reward model.

What is not new must remain explicit: SFT, DPO, synthetic generation, self-revision, majority voting, code tests, answer checking, curriculum search, and LLM judging all predate this report. Nor does Pivotal Token Search establish step-wise mathematical truth; its signal is the estimated effect of a token on final oracle success under sampled continuations.

For `frontier_reports_data_disclosure_ledger`, the novelty is also the disclosure combination: source classes, aggregate token scales, three post-training objects, pair counts, oracle roles, a released weight artifact, and benchmark caveats appear in one official report. The pipeline is still not open because data, prompts, per-record decisions, and replay assets are absent.
