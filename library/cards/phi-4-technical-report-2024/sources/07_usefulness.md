For `frontier_reports_data_disclosure_ledger`, Phi-4 is useful precisely because it combines strong report detail with a weight-only artifact boundary. Readers can verify the official report, 14B checkpoint, MIT license, six safetensor shards, model card, and later data summary. They cannot inspect the training records. This makes the difference between “documented,” “released,” and “replayable” concrete.

A disclosure ledger should record each layer separately. For pretraining, capture source class, named source, revision, rights, collection date, unique records, tokenization, mixture weight, repetitions, direct-use versus seed-use, synthetic generator, and final run membership. For SFT, add rendered conversation, candidate IDs, generator and evaluator revisions, raw scores, selection threshold, rejection reason, and token count. For DPO, preserve prompt, both responses or token alternatives, oracle/judge inputs and outputs, pair rationale, ordering, score components, and stage membership.

Pivotal Token Search is reusable as a research design when a reliable task oracle and sufficient rollout budget exist. A reproduction should first validate oracle false accepts, estimate success-probability variance, test whether near-monotonicity holds, compare found tokens with exhaustive search on small cases, and publish missed-token and rejected-pair statistics. It should not generalize endpoint verification to domains lacking executable or answer-key checks.

The report also offers useful negative controls. Synthetic-only mixtures underperform on factual recall, strict instruction following remains a weakness, and n-gram decontamination cannot resolve every paraphrase. These observations motivate mixed source portfolios, targeted instruction data, and semantic overlap audits rather than using model scores as a blanket endorsement of the corpus.

Auditors should pin the model revision, verify weight and license files, distinguish the 400B unweighted source pool from the 9.8T training budget, independently sum both DPO tables, and mark every undisclosed generator, threshold, rollout budget, source right, and record count as unknown. The result is a comparable frontier disclosure, not a reconstructed open recipe.
