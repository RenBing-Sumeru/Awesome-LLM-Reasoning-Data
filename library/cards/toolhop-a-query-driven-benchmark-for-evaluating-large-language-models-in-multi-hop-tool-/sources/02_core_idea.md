ToolHop releases 995 user queries and 3,912 associated tools, covering multi-hop problems that require sequential, parallel, or combined calls. Each tool has natural-language documentation, an executable implementation, and structured outputs; queries include canonical answers and detailed feedback. The data object is a query–candidate tool set–calling process–final answer record, primarily for evaluating tool selection, argument generation, result aggregation, and end-to-end success rather than serving as a ready-made agent-trajectory training set.
