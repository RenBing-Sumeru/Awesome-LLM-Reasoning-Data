The paper evaluates 14 models from five model families on the same 995 queries. The strongest model, GPT-4o, reaches only 49.04% final-answer accuracy, and model families exhibit distinct tool-selection and calling strategies. Released local tools, data, and execution scripts permit per-item reproduction, showing both benchmark discrimination and whether failure arises from tool choice, arguments, or result integration. A correct canonical answer, however, does not imply that only one valid call path exists.
