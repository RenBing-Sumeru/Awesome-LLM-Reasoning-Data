HierSVA-DS is built from BaseJump STL and contains 342 modules with hierarchy metadata at depths 0–9. It also includes 28 deep module–bug pairs with natural-language specifications and bug variants. Records contain RTL, hierarchy and parameter metadata, reference SVA, specifications, mutations, and tool outputs. HierSVA-B evaluates assertions along syntax, proof success, vacuity, specification faithfulness, mutation coverage, and formal-core coverage. The dataset follows the Solderpad Hardware License v2.1.
