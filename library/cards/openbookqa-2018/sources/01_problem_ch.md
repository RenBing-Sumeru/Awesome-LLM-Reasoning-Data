OpenBookQA: A New Dataset for Open Book Question Answering 定义了 science-qa, commonsense-reasoning 的评测面：模型输出或智能体轨迹必须满足任务特定的反馈契约。主来源与产物是 paper: https://aclanthology.org/D18-1260/; acl: https://aclanthology.org/D18-1260/; project: https://allenai.org/data/open-book-qa; data: https://allenai.org/data/open-book-qa; doi: https://doi.org/10.18653/v1/D18-1260；本地元数据记录的年份/来源为 2018 / EMNLP 2018。

收录边界是 benchmarks_evaluation_surfaces，来源角色为 benchmark，验证契约为程序化。一个评测实例 里包含：question, choices, correct option, and supporting open-book fact。除非官方产物另有训练数据说明，否则这张卡把它视为评测、审计，不是训练配方。它对 atlas 的价值在于把任务对象、输出和验证器/裁判/奖励/环境谓词 绑定起来，而不是只记录抽象能力结论。
