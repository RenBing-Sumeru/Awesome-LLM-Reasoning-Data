The core mechanism is the pairing of task inputs and model outputs with the following feedback contract: RAF label produced by base-judge agreement or meta-judge consensus, with sampled human validation; no mechanical verifier is provided.

The data object or environment is Rubric-level instruction-following judge evaluation over model responses. The closest comparisons are reward-model, rubric-judge, and preference-evaluation benchmarks. The direction label is benchmarks_evaluation_surfaces with a judgment_required feedback contract. The main thing to preserve is not only the headline score, but the task object, evaluator, split/version, and artifact lineage.
