Prior multimodal critics are often task-specific scorers or post-hoc evaluators. This paper changes the object from a narrow score to a generative verifier that returns a judgment and explanation across visual outcome categories, then reuses it inside sequential generation-and-editing refinement. ViVerBench makes the intended capability explicit across 16 categories. The novelty is not simply using an LLM judge; it is packaging verification, feedback, and test-time refinement around a common visual-verification interface.
