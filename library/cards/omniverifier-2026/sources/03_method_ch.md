1. 定义视觉验证目标。ViVerBench 将视觉结果组织为 16 类任务，记录提示、生成图像或多模态回答及验证目标。

2. 构造验证数据。作者用两条自动化管线建立大规模视觉验证监督；具体规模、许可和每个筛选阈值应以 release 为准，不能从基准页推断。

3. 训练 OmniVerifier-7B。模型对图像—提示输入输出验证结论和解释，使判断可作为反馈，而非只有标量分数。

4. 评测验证能力。将模型回答存为 JSON，再运行发布的规则评测或模型评测；后者使用 GPT-4.1 作为 judge，所选评测器属于测量契约的一部分。

5. 测试时改进。OmniVerifier-TTS 顺序使用 verifier 反馈连接生成与编辑。复现须固定发布的模型／数据版本、提示和图像输入、评测器选择、生成编辑预算；未披露的超参数为未知。
