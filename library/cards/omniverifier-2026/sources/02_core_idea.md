The core object is a generative universal verifier that judges and explains visual outcomes across multimodal reasoning and generation. The work releases ViVerBench, a benchmark covering 16 critical visual-verification categories, and trains OmniVerifier-7B on large-scale visual verification data. The official repository supplies training, inference, and evaluation code; ViVerBench is publicly downloadable on Hugging Face. The paper reports that OmniVerifier improves ViVerBench by 8.3 points and supports a sequential test-time refinement scheme, OmniVerifier-TTS.
