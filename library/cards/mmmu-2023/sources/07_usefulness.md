Use MMMU as a schema for multimodal expert-evaluation records: image assets, text prompt, subject, subfield, answer type, target answer, evaluator rule, split, and model-output normalization.

It is useful for testing whether a model can combine visual evidence with domain knowledge, and for designing audits that separate perception errors, OCR/layout errors, domain reasoning errors, and answer-format errors.

For atlas work, MMMU anchors the multimodal academic-reasoning branch and provides a comparison point for harder variants such as MMMU-Pro or video/multimodal successors.
