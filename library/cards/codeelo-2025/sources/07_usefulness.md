Use CodeElo as a design reference for live external-judge benchmarks. Preserve contest id, problem id, division, rating, tags, language, prompt, model decoding, submission count, verdict, timestamp, and Elo calculation version. It is valuable for leakage-aware coding evaluation because recent official-platform problems reduce reliance on replicated hidden tests. It should not be converted into a training reward stream without platform-policy review and strict rate, provenance, and contamination controls.
