Prior benchmarks often provided offline tests or public examples; CodeElo changes the verifier to the live official Codeforces judge and maps outcomes to human-comparable Elo. The direction signal is external-platform evaluation for difficult code reasoning with hidden tests, special judges, and aligned runtimes. Quality signals include recent contest selection, metadata by division/rating/tag, public code for Elo/ranking logic, and a project leaderboard. What is not new: Codeforces problems and Elo ratings. Reuse checks: platform permission, submission throttling, token access, contest updates, license, and contamination.
