Primary sources: arXiv:2501.01257, the CodeElo project page, QwenLM/CodeElo, and the Qwen/CodeElo dataset page linked by the repository. The problem is that many contest-code benchmarks lack private tests, special-judge support, and environment alignment. CodeElo is in scope as a competition-level coding evaluation surface, not as a training recipe. A task is a recent Codeforces contest problem with title, limits, statement, examples, optional notes, contest division, difficulty rating, tags, and an official-platform submission result.
