Inputs are long natural-language business instructions, input `.xlsx` workbooks, category metadata, and a scaffolded agent environment. Outputs are submitted workbooks, modified-cell records, task-level accuracy, and visualization checklist judgments.

The benchmark has 321 tasks: 100 Financial Modeling, 100 Debugging, 97 Template, and 24 Visualization tasks. The authors build gold-standard spreadsheets from public business and financial materials, including reports, corporate filings, and named data sources such as NYU Stern Damodaran data, Screener.in, Bloomberg, and Bseindia; then they convert complete workbooks into tasks by removing target regions, injecting controlled errors, or specifying visualization goals. Each task is intended to have a unique answer, self-contained instructions, and standard finance/business-domain assumptions. Two independent experts solve tasks for validation and disagreements trigger revision; the paper reports more than 1,500 expert annotation hours.

Evaluation uses an observe-reason-act scaffold based on SWE-agent. The agent can use `bash`, a read-only `view_xlsx` tool, and `submit`, with a Python 3.11 / Debian Bullseye Docker environment, no network, and up to 50 turns. For workbook tasks, Modification measures target-cell computed-value match rate and Accuracy requires all required modified cells to be correct while preserving cells that should not change. Visualization requires Windows Excel/WPS COM export of chart images and a GLM-4.6V checklist judge. Reproduction must pin the dataset release, code revision, spreadsheet engine, VLM judge/API version, scaffold, turn budget, and unavailable raw-source boundary.
