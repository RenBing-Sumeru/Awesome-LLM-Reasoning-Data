Prior terminal benchmarks often emphasize programming, system administration, or narrowly technical shell tasks, while general computer-use benchmarks often use GUIs. TUA-Bench changes the evaluation surface by making the terminal a general computer-use interface for office-like, web, media, and expert scientific workflows.

The quality signal is the combination of manual curation from 394 candidates, deterministic setup scripts, real terminal execution, expert co-designed scientific tasks, public repository, and execution-based scoring. What is not new is CLI use or artifact checking; the novelty is the breadth of non-coding terminal tasks. Before reuse, inspect task licenses, live-web dependencies, installed software versions, scorer code, container image, benchmark release date, and public-task contamination.
