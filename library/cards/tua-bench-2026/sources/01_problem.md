TUA-Bench asks whether terminal-use agents can perform broad computer-use tasks beyond coding and shell-native administration. The primary source is the 2026 arXiv paper https://arxiv.org/abs/2606.28480, with the official project page https://tuabench.ai/ and the facebookresearch repository as artifacts.

The decision boundary is general-purpose terminal-use evaluation. One instance contains a task instruction, deterministic setup script, terminal environment, input files or application state, agent commands, execution feedback, artifacts produced under the environment, and an execution-based scoring protocol. It is not a GUI grounding benchmark, a coding-only benchmark, or a training recipe. It matters because it treats the command line as a text-native environment for everyday digital work and expert scientific workflows, with terminal state and artifact checks as the feedback contract.
