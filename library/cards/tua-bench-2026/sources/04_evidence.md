The strongest evidence is that the benchmark exposes concrete terminal artifacts rather than relying on self-reported completion. The paper reports 120 manually curated real-world tasks across five task families, each with deterministic setup and execution-based scoring.

The reported main result is that the strongest evaluated agent, Claude Code with Claude Opus 4.8 at max reasoning effort, reaches 65.8% overall performance, leaving substantial gaps in long-horizon planning, tool use, execution monitoring, and error recovery. This number is useful only under the paper's task release, scorer scripts, runtime environment, model version, and reasoning-effort setting. Row-level trust comes from task-specific verifiers over produced files or state, not from aggregate success rate alone.
