Multimodal Best-of-N needs a critic that can distinguish reasoning candidates using both the image and the evolving solution. An outcome score collapses a response into one final judgment, while a process reward model scores intermediate steps. The practical bottleneck is therefore not only model architecture: it is a data object that connects an image, a question, a solution prefix, the next step, and an evidence-backed step target.

VisualPRM separates three public objects that should not be conflated. VisualPRM400K is automatically constructed training data; VisualPRM-8B is the learned process reward model; VisualProcessBench is a separate human-annotated test set for step-error detection. The training labels are Monte Carlo estimates converted to binary targets, whereas benchmark labels come from human experts. Performance on VisualProcessBench or downstream Best-of-N tasks does not prove that every VisualPRM400K label is correct.

This work belongs in `rollout_search_test_time_trace_data` because repeated sampling appears twice. During data construction, each solution prefix is expanded with 16 continuations to estimate its future success. During inference, a policy samples N complete candidate responses and VisualPRM selects one by an aggregate step score. The original release publishes the derived training conversations but not the underlying continuation rollouts, rejected candidates, or Best-of-N decision logs, so the selector can be used without the full trace lineage being auditable.
