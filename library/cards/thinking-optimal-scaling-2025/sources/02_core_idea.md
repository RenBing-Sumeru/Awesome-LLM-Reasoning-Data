TOPS defines a thinking-optimal response as the shortest correct System-2-style response the model can produce for a problem. Shorter effort may leave the problem unsolved, while longer effort can introduce unnecessary rounds and mistakes. The goal is therefore a conditional policy over effort levels, not a global preference for concise or long traces.

The method first teaches a tag model to follow explicit low, medium, and high effort labels using a small seed set. It then generates answers for additional problems at each effort and keeps the shortest correct answer across those attempts. Fine-tuning the base model on this selected collection is intended to make the eventual model choose enough thought for difficult examples and stop earlier for easy ones. Correctness, effort label, response length, and selection rule are all essential to the construction.
