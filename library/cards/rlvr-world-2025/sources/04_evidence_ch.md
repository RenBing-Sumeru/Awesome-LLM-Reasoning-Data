已核验的 NeurIPS 记录、arXiv 论文、THUML 仓库/项目页和作者关联的 Hugging Face 集合支持以下事实：论文、代码、项目页、两个派生语言状态转移数据集以及多个模型/tokenizer 检查点确实存在。该集合证明派生工件已发布，但并不证明论文报告的每一条上游轨迹或在线 RLVR rollout 都已公开。

论文记录了文字游戏、网页状态预测和视频/机器人预测中不同的监督对象与奖励定义；还报告了在 Docker 配置的 AWS EC2 上、覆盖 Shopping、CMS、Reddit、GitLab 和 Mapping 的 WebArena 评测，并描述 Web MPC 会采样 20 个动作、保留最常出现的 3 个、再重复 20 次价值评分。这些是论文报告的实验流程，不是部署验证、独立发布的环境镜像，也不证明世界模型预测可安全用于控制。

论文报告了具名的切分比例和数量，但已接受证据未能建立不可变切分文件、来源级记录 ID、被拒绝 rollout 日志、完整环境依赖或端到端运行日志。因此，本 Card 将工件可得性视为已核验，同时将血缘完整性保留为部分披露。
