DeepSeek-V3 post-training starts from a 1.5M-instance instruction corpus. For math, competitive programming, and logic, an internal DeepSeek-R1 model supplies long reasoning responses; domain-specific SFT+RL experts learn to combine R1-style reflection and verification with shorter original responses, then generate traces retained by rejection sampling. DeepSeek-V2.5 generates non-reasoning responses that human annotators check. Two-epoch SFT is followed by GRPO using rule-based and model-based rewards across verifiable and open-ended domains. This is a disclosed construction recipe, but not a released dataset.
