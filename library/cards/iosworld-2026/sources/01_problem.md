The primary sources are arXiv:2606.09764v1, submitted 8 June 2026, the official project, and the official repository inspected at commit `e91f4cb2ef4c9dd48fef83a894477b41fd5e209d`. The verified publication status is an arXiv preprint; an exact ICML 2026 AIWILD workshop forum was not resolved.

iOSWorld addresses a specific evaluation gap: a phone agent may complete an isolated screen-level action yet fail when a task depends on personal state distributed across finance, messaging, travel, food, productivity, and other applications. The benchmark therefore places one fictional persona, Jordan Avery, in 26 connected SwiftUI apps and supplies 133 first-person tasks: 27 single-app, 60 multi-app, and 46 memory/personalization tasks. The released `tasks.json` contains 1,123 rubric criteria, with 4-13 criteria per task and a mean of 8.4.

The canonical released object is a task/rubric and deterministic seeded simulator environment. A runner-generated episode adds screenshot or screenshot-plus-XCUITest observations, actions, optional reasoning/messages, final state and answer, criterion judgments, a rubric fraction, and strict pass/fail. This makes iOSWorld relevant to `environment_agent_trajectory_data`: task state, observation/action interaction, reset, episode capture, and terminal feedback are specified together.

The decision boundary is equally important. The repository releases the 26 apps, seed fixtures, task manifest, runners, evaluator, MCP servers, and AWS EC2 Mac helpers, but not the complete experimental success/failure rollout corpus; the official site shows only 16 curated Opus 4.6 vision+XML trajectories. The paper evaluates agents and reports no SFT, RL, preference, reward-model, or agent training on iOSWorld episodes. These sources support L4-depth bilingual screening content, while accepted workflow metadata correctly remains `L3_summary_ready` and training reuse remains outside the evidenced scope.
