AndroidWorld, AndroidLab, SPA-Bench, B-MoCA, GUI Odyssey, and related mobile-agent benchmarks already provide screenshot/action evaluation, accessibility information, multi-step tasks, or programmatic checking. iOSWorld's concrete change is to make native iOS the substrate and connect 26 apps through one persistent synthetic persona, so multi-app and memory tasks depend on shared personal state rather than only local screen transitions.

The second change is the released evaluation object: a 133-record task manifest with 1,123 criteria is coupled to deterministic app-data reseeding, rich trajectory capture, and a full-episode GPT-5.4 Mini rubric judge. The feedback interface exposes both criterion satisfaction fractions and all-criteria strict pass. It is judgment-based rather than an AndroidWorld-style programmatic end-state contract, which expands semantic coverage but makes judge calibration, API pinning, rubric completeness, and false-positive/false-negative analysis part of the data specification.

The optional MCP layer is another inspectable interface variation. It preserves the benchmark tasks and judge while replacing portions of screen-level action with typed per-app operations. The reported Qwen ablation demonstrates that this interface materially changes outcomes, but MCP, Appium, XCUITest, LLM judging, and simulator reset are established components. Likewise, 26 apps and 133 tasks are scale and integration, not independent evidence of record-level quality.

For reasoning-data research, the direction signal is an executable chain from synthetic state and task provenance through reset, observation/action episode, rubric judgment, and failure analysis. Before reuse, researchers still need an immutable environment/result bundle, complete success and failure trajectories, judge prompt/API snapshot, record-level construction lineage, explicit evaluation split and contamination policy, and complete third-party attribution. Without those checks, the release is a benchmark recipe rather than an open training-trajectory corpus.
