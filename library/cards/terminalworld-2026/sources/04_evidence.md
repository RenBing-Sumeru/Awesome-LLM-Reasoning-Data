The paper evaluates 8 models with 6 agent scaffolds on the manually checked Verified-200 subset. Table 1 reports the best task pass rate as 62.5% for Claude Opus 4.7 with Terminus-2; reported model-agent combinations span approximately 49.0%–62.5%. These are author-reported results under the paper's Harbor, environment, and scaffold settings. They do not measure training value, license clarity, provenance completeness, or test-suite soundness.

The construction counts provide stronger evidence about selectivity than benchmark scores provide about data quality: 80,870 source recordings become 9,492 filtered candidates, 5,035 zero-exit reproduced environments, and 1,530 tasks passing the reference/no-op/partial validator. Verified-200 adds expert manual checking but is deliberately selected for diversity, complexity, length, and nontrivial tools; it is not a random sample. Performance on those 200 tasks should not be treated as an unbiased estimate for all 1,530 tasks (Paper §§3–4).

Paper §4.1 reports 1,280 unique commands and says 91% do not occur in Terminal-Bench. This supports command-vocabulary breadth only; it is not item-level deduplication, downstream benchmark decontamination, or evidence that evaluated models never saw equivalent tasks. Every released instruction also carries a Harbor canary warning against training-corpus inclusion, but a canary enables later detection rather than demonstrating prior decontamination.

Paper §5.4 reports only 21.4% median command-set overlap between human references and successful agent executions. This is evidence that outcome tests permit alternate action paths and that reference solutions should not be treated as the only correct trajectory. It is not evidence that every alternate route is safe or that the tests fully capture semantics.

The failure evidence shows that measured outcomes mix agent capability with infrastructure reliability. Appendix C attributes model-level error rates of about 2.5%–5.5% partly to Harbor/tmux races and container-startup timeouts. About 10% of tasks use end-of-life Ubuntu, CentOS, or Debian images, contributing to third-party-agent installation error rates of 4.5%–21.5%. Resolved rate, ordinary failure, and harness/environment error therefore need separate reporting.

The official release surfaces also provide a negative reproducibility result. The paper reports 18 categories, the stable GitHub README reports 19, and the checked current `full` manifest contains 20 distinct `terminal_domain` values. Because no immutable release maps arXiv v1 to the current Git/HF snapshots, the three counts describe different surfaces rather than a single settled taxonomy.
