The released training source is CodeContests_train, currently 4,529 rows. A record contains the source dataset, problem statement, task identifier, stdio execution method, time limit, public `example_input`/`example_output`, and private `test_input`/`test_output`. The paper describes selecting roughly 4.5K CodeContests tasks of difficulty at most 2. Functional-format tasks in MBPP and parts of LiveBench and LiveCodeBench are converted to stdio for evaluation.

For every sampled task, the policy generates Python solutions and tests in a fixed text format. The tester must emit test input, expected output, and an explanation. With 16 code and 16 test rollouts, the generated cross-execution alone contains 256 outcomes per task. Private gold tests are then appended for code scoring and for the correct/incorrect partition used by the tester reward. A code is treated as correct in that estimator only if it passes all available gold tests; this predicate can be wrong when the test suite is incomplete.

The 7B and 14B runs start from Qwen2.5-7B-Instruct and Qwen2.5-14B-Instruct. Sampling uses temperature 1.0 and top-p 1.0. The paper reports learning rate 1e-6, KL coefficient 0.01, 350 optimization steps, and 8 A100 GPUs. The long-CoT variant starts from Qwen3-4B, uses temperature 0.8, trains for 50 steps, applies the response-length transformation, and truncates training responses beyond 8K tokens.

Updates use a clipped PPO/GRPO-style objective with normalized group rewards and KL regularization. Coder and tester updates are sequential within each iteration rather than separate fixed models. The current repository default configuration exposes sampling, execution, reward, and training modules, but its default `total_steps` is 120; reproducing the paper therefore requires changing defaults and pinning the exact commit/configuration.

Main Best-of-N evaluation samples 16 programs and 16 tests, then ranks programs by generated-test pass count. Final benchmark correctness is measured using gold/private tests, not the generated-test vote itself.
