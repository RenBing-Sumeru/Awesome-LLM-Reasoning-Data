Official ICLR proceedings and the virtual program identify AgentTrek as an ICLR 2025 Spotlight. The paper addresses a concrete data bottleneck: GUI agents require multi-step episodes aligning instructions with changing interface observations, reasoning, grounded actions, and outcomes, but human collection is expensive. Web tutorials are abundant procedural descriptions, yet they do not directly record what an agent observed and executed in a live environment.

AgentTrek asks whether tutorials can become scalable plans for collecting grounded behavior. This is simultaneously a construction and audit problem: tutorial pages may be stale, websites mutate, and a model judge rather than a deterministic site predicate decides which replays count as successful. The work belongs in Data Construction and Open Release Recipes because it specifies a source-to-task-to-replay-to-filter pipeline; it is not primarily a benchmark, a preference dataset, or an RL method.

The paper's data object is a rich multimodal trajectory: structured task metadata, screenshots/video, DOM/HTML and AXTree state, Playwright-native traces, intermediate reasoning, and actions. The current public dataset exposes a narrower object—52,594 dialogue turns in one `messages` column. L4 here means the full paper, appendix, project, code, HF dataset/model surfaces, affiliations, and release boundary support bilingual audit. It does not mean the complete trajectory corpus, failures, construction code, license, or immutable run manifest is available.
