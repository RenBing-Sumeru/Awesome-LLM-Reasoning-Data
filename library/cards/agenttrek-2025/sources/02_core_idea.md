AgentTrek converts tutorial-like web pages into supervised agent behavior through three linked stages: large-scale tutorial discovery and standardization, guided execution on live websites, and VLM-based success filtering. Tutorials provide goals and procedural hints; BrowserGym supplies the interaction substrate; GPT-4o-2024-08-06 performs replay; and a separately prompted GPT-4o evaluator provides the acceptance decision.

The intended object is an environment-grounded episode rather than a free-standing rationale. Each paper-level instance combines a task specification with sequential observations, reasoning, grounded browser actions, and native traces. The feedback contract is mixed: actions execute in a real browser, but acceptance is judgment-required. The evaluator observes the task and reasoning/action history, yet it lacks a deterministic ground-truth website state and its prompt can accept some partial completions.

Successful episodes become text and vision supervision. Qwen2-VL is fine-tuned on 10,000 trajectories, while Qwen2.5 7B/32B text agents use 6,000. The HF surface instead publishes turn-level text examples, so it does not expose the complete episode object, selection boundary, or subset-to-checkpoint lineage.

The closest Atlas comparison is `learn-by-interact-2025`. Both turn tutorial/documentation resources into environment interaction data and use judgment filters. Learn-by-interact backward-constructs instructions for arbitrary contiguous subtrajectories and reports no public corpus; AgentTrek executes standardized tutorials toward their stated expected results and does expose a text-turn dataset and checkpoint, but not the paper's full multimodal trajectories or failed replays.
