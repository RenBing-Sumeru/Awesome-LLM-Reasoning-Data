The paper constructs Feedback Collection with 1,000 fine-grained score rubrics, 20,000 instructions, and 100,000 responses paired with GPT-4 natural-language feedback. Prometheus-13B is trained on inputs containing the instruction, candidate response, reference answer, and rubric and outputs both feedback and a 1–5 score. The model, data, and code are released to provide a reproducible, inexpensive evaluator supporting customized dimensions.
