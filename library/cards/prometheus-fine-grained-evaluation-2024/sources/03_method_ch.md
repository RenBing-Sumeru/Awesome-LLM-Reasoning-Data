1. **设计 rubric：**为开放式 instruction 编写 1–5 分标准，每一级包含可区分的质量描述。
2. **生成回答：**针对 20,000 条指令产生覆盖不同分数等级的 100,000 个候选回答。
3. **生成反馈：**GPT-4 在参考答案和 rubric 条件下，为每个回答输出详细 critique 与最终分数。
4. **质量控制：**检查分数分布、字段完整性和 rubric—回答一致性，形成 Feedback Collection。
5. **训练裁判：**对 13B 基座做监督微调，使其生成反馈后给分，并在未见 rubric、偏好集和多种 benchmark 上测试泛化。
