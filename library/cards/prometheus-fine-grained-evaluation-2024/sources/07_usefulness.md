Feedback Collection can train rubric reward models, generative judges, or critique models and provides a four-field template for domain-specific data. Rubrics should retain level-by-level descriptions rather than only dimension names, and evaluation should report correlation, pairwise accuracy, and calibration. Reference-free variants can be tested when references are unavailable, but the original performance should not be assumed. High-stakes tasks require human or programmatic verifiers to prevent scaling teacher bias.
