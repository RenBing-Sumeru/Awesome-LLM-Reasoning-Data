The contribution is an evaluation audit: instruction-tuned LLMs inspect a question, context, reference answer, and prediction, then decide semantic correctness where EM/F1 only test overlap. The released code and result files cover four QA datasets, 4,193 sampled items, human judgments, prompts, QA predictions, and outputs from Mistral, Llama, and Qwen judges. It is an evaluation artifact, not a training dataset.
