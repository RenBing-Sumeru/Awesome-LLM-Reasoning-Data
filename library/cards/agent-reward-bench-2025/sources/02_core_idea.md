The one-sentence contribution is: AgentRewardBench turns the feedback contract for web-agent evaluation into a benchmark object by pairing full episodes with expert reference labels, task-specific environment rewards, and multiple LLM-judge outputs.

Three layers are coupled. First, source agents execute benchmark goals through AgentLab and BrowserGym, producing trajectories with reasoning, browser actions, accessibility-tree observations, screenshots, errors, and summaries. Second, expert web-agent researchers review the completed episode. Their released record contains binary success, side-effect, and looping judgments, with raw `Unsure` values where applicable, plus four-level optimality: complete failure, suboptimal, somewhat optimal, or completely optimal. Third, automatic evaluators predict labels from different representations. The main paper compares 12 LLM-judge configurations and a functional rule reference; the release additionally includes two GPT-4o-mini input ablations, for 14 LLM configurations plus `functional`.

The reference contract is judgment-based, while the compared automatic signals are mixed. Expert success is a post-hoc semantic judgment of the completed sequence and is not an executable replay predicate. The `functional` evaluator converts stored cumulative environment reward greater than 0.5 into success and emits no side-effect, optimality, or looping labels. Simplified LLM judges receive the goal and action/reasoning history, optionally with the final screenshot and/or accessibility tree, then produce reasoning and four label fields. Model-generated judge reasoning is an evaluator artifact, not expert rationale.

The paper's central distinction is therefore not “human good, automation bad.” It measures which errors each feedback mechanism makes. Environment rules can reject trajectories that experts judge successful, while LLM judges can declare false success after trusting misleading reasoning, missing a task detail, misreading an action's intent, or failing to ground the episode in the browser state. Input representation also changes judge behavior; adding more modalities does not monotonically improve the reported results.

For reasoning-data curation, this makes evaluator output and disagreement part of the data object. A trajectory is not certified merely because it has an environment reward or an LLM judgment. The release supports evaluation and audit of feedback contracts; prospective discussion of RFT, RL, and reward models is not evidence of `reward_modeling` or agent-training use.
