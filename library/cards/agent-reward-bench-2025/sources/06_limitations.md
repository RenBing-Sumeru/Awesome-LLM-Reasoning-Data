- The paper reports six experts, 3,906 binary annotations, and 89.3% success agreement, while the pinned CSV has eight annotator identifiers, 1,408 rows for 1,302 unique keys, 106 double-annotated keys, and a fourth ordinal optimality field. The mapping from raw rows through discussion/adjudication to the reported statistics is unknown.
- The annotation protocol does not disclose recruitment, compensation, per-task assignment, blindedness, independent-label retention, or an immutable adjudication log. Optimality has no reported paper-level agreement statistic, and one raw row is `Unsure`.
- The functional evaluator's `>0.5` cumulative-reward threshold is an environment proxy, not semantic proof of success. Its 55.9% recall shows substantial false negatives against the expert reference. LLM judges remain vulnerable to grounding, instruction-detail, reasoning-trust, and action-intent errors; side-effect positives are too rare for stable conclusions.
- Hugging Face file inventory confirms 1,302 cleaned JSONs, 1,302 screenshot directories, and 15 judgment files per episode. It does not prove that every serialized screenshot path resolves or that every provider response parses successfully. Those exhaustive validation reports are missing.
- The task-level dev/test manifest must be joined manually because the Hugging Face viewer exposes annotations as one `full` configuration. No model-pretraining decontamination, public-task exposure analysis, or future contamination policy is reported. Public benchmark tasks are intentionally reused, and AssistantBench uses its public validation set because the test set is private.
- Offline inspection is supported, but deterministic environment replay is not. Real websites drift; upstream benchmark, AgentLab, and BrowserGym commits are not all pinned; database/site snapshots and containers are absent; `browsergym` is only lower-bounded in requirements; and the runner sets `strict_reproducibility=False`.
- The GitHub repository has no detected code license. The dataset uses bespoke Hugging Face terms rather than a standard open-data license, conditions research use on applicable fair use and third-party terms, and requires derivatives to propagate the terms. Component-level rights for five benchmarks, websites, ServiceNow content, screenshots, and model outputs are not closed.
- AssistantBench episodes and screenshots observe real websites and may contain third-party content. The release provides no PII, privacy, or consent audit. This is a missing review, not evidence that personal information is present.
- Official setup documentation includes a credential-like default example and endpoint templates. This Card intentionally does not reproduce any value. Reusers should remove or rotate defaults and keep credentials out of derived datasets, logs, and documentation.
- Source-agent settings are only partly reconstructable: record-level model arguments, flags, seed, package version, and statistics are available, but a frozen Claude endpoint, all provider behaviors, environment snapshots, and aggregate decoding settings are not. Two persistent timeout attempts are absent, so failed pre-completion attempts are not fully retained.
- The paper evaluates automatic evaluators. It reports no SFT, preference learning, reward-model training, process supervision, RLVR, or agent-policy training experiment with the release. Benchmark results cannot establish that the trajectories or labels are suitable training data.
