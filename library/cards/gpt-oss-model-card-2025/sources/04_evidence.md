The official release states that gpt-oss-120b has 117B total parameters with 5.1B active parameters per token, and gpt-oss-20b has 21B total parameters with 3.6B active parameters per token. It also states that the models, tokenizer, inference implementations, and tool environments are released under Apache 2.0. The official repository provides the reference implementation and the official Hugging Face organization hosts model releases.

The Model Card and release describe evaluations in mathematics, coding, safety, and agentic tool use, including browsing and Python. These are reported evaluation results and capability descriptions, not independent evidence that the stated post-training data, reward contract, or safety procedure can be reproduced. In particular, the release does not provide a training-data package, feedback dataset, reward/verifier artifact, split, decontamination report, or rollout log.
