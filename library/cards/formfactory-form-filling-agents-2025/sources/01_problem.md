FormFactory asks how to evaluate multimodal agents on interactive web form filling with field-level state checks. The primary sources are arXiv:2506.01520, the official project page, and the GitHub repository. It belongs here as an interactive form-filling environment, not as a static screenshot understanding dataset. A task contains a form page, user goal, screenshots or layout information, target field values, agent actions, and backend evaluator output. Its atlas value is the field-level feedback contract for a common web-agent workflow.
