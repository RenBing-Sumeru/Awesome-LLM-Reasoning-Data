The contribution is a form-filling benchmark suite with synthetic/controlled web forms and gold field states. The project reports 20 web forms, 1,250 task instances, and over 13,800 field-value pairs, while the repository later advertises 40+ form templates; these counts should be versioned separately. The mechanism evaluates agents by comparing submitted form state with gold JSON or backend field matches. Closest comparisons are WebArena-style browser tasks, form-filling agents, and GUI grounding benchmarks. The direction label is interactive web form evaluation with structured terminal state.
