对“数据构造与开放发布配方”轨道而言，MathSmith 是区分 source、generator、judge 与 consumer 对象的完整参考。复现者应保留 PlanetMath 页面 ID 与 revision、概念—解释记录、五条采样集合、策略候选、rationale/problem 标签、每个结构/复杂度/一致性分量、全部 K 条教师解答、抽取与归一化答案、拒绝原因、生成器 checkpoint，以及精确下游子集。

HC/Hard 对照可直接用作 verifier 消融：检验一致性是否减少病态或歧义题目，轨迹长度是否能预测独立人工或符号难度，以及两种奖励分别选择了哪些记录。被拒绝候选和未形成多数的教师输出尤其适合作为审计数据，不应被丢弃。

弱点定向流程还给出一种不同于泛化扩量的轨道用途：在留出 Practice Set 上诊断失败，按记录的概念追溯每个失败，生成受控变体，再测量迁移收益是否以简单能力下降为代价。但在直接复用前，使用者仍需固定数据 revision，建立稳定 ID 与哈希，执行语义去污染和重复检查，开展独立数学验证，并审查上游许可。开放产物使这些工作可行，但不能替代它们。
