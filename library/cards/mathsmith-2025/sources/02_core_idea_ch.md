核心设计是直接训练数据生成器。GPT-4o 先生成约 8,000 条冷启动样本，每条由五步构造 rationale 和一个聚焦题目组成；Qwen3-8B 通过 LoRA SFT 学习该格式。随后，GRPO 优化两个版本：MathSmith-HC 同时使用结构、推理复杂度和答案一致性信号；MathSmith-Hard 删除一致性项，更强调推理长度代理。

结构奖励检查所要求的 rationale 与 problem XML 风格区段，并鼓励 rationale 恰有五步，格式与步数权重分别为 0.7 和 0.3。复杂度是 K 条教师推理轨迹的平均长度除以最大长度常量。一致性在同一教师的抽取答案出现严格多数时为 1，否则为 0；推理奖励对复杂度与一致性的权重为 0.7 和 0.3。这些是训练出题器的奖励，不是数学证明。较长轨迹可能来自难度、冗长或困惑，同教师多数也可能重复同一个错误。

概念 provenance 还支撑弱点定向循环：生成 Practice Set，识别目标模型错误，追溯对应概念集合，生成同概念变体，微调并迭代，直到达到预设准确率阈值。
