The novel move is to make evaluation itself budget-aware under test-time scaling. Instead of asking only which model has the highest expected score after repeated sampling, the work asks whether a model ordering is stable at the actual trial budget a user can afford. This shifts the object of study from a scalar benchmark result to the reliability of a decision made from repeated stochastic model behavior.

It also turns a common shortcut—using one greedy decode as an empirical prior—into an explicit bias–variance trade-off that can be checked. By putting many ranking families in one open library and comparing their high- and low-budget behavior, the work provides a concrete reporting standard: a claimed model order should specify its trial count, sampling behavior, ranking rule, and any prior, rather than presenting an apparently context-free leaderboard.
