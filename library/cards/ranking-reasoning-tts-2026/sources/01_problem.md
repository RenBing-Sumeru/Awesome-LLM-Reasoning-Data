When a reasoning model is evaluated with repeated inference-time samples, a leaderboard no longer observes one fixed answer per model and question. It observes a response tensor whose apparent model order can change with the number of trials. A ranking computed from one stochastic response may be noisy, while a ranking at a large sample budget may be too expensive for routine comparison. Standard evaluation reports often hide this dependence behind a single pass-at-k number.

The paper asks how to rank reasoning models reliably in this repeated-sampling regime. It seeks an evaluation procedure that tells researchers which ranking methods converge at high budgets, which remain stable when only a few trials are affordable, and when a deterministic greedy result is a helpful prior rather than a source of systematic bias.
