1. **日志筛选：**从超过一百万条匿名真实聊天记录中去除低质量、敏感和不可评任务，保留高难与多样候选。

2. **任务定稿：**通过聚类、质量检查和人工审核选出 1,024 个代表性用户请求，覆盖多种开放式能力。

3. **标准构造：**为每题编写 task-specific checklist，明确回答必须满足的事实、推理、格式或风格要求。

4. **基线生成：**准备多个固定模型的基线回答，形成稳定的相对比较锚点。

5. **双指标评分：**WB-Reward 进行候选—基线成对判断；WB-Score 逐项检查并聚合，同时校正回答长度带来的偏差。

**可复现信息：**官方公开数据、代码和榜单；真实日志的完整采样分布因隐私原因无法全部复现。
