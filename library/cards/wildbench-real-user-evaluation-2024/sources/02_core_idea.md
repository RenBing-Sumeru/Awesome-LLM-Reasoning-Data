WildBench selects 1,024 challenging tasks from more than one million real-user chat records and creates a task-specific checklist for each item. It provides two complementary metrics: WB-Reward compares candidate responses pairwise against baselines, while WB-Score performs pointwise checklist-based scoring. Multiple reference baselines and length-bias mitigation are also introduced. The data combines real prompts, task requirements, candidate responses, baseline responses, and scoring criteria for open-ended model evaluation, judge calibration, and difficult-instruction mining. Its goal is to preserve the difficulty of live user distributions within a reproducible offline benchmark.
