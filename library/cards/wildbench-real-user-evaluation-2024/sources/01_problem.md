Static academic benchmarks are often researcher-authored, structurally regular, limited in coverage, and potentially leaked into model training. Chatbot Arena captures real human preferences but depends on continuous online traffic and is difficult to reproduce or diagnose finely. WildBench asks whether challenging, diverse, and publicly evaluable user tasks can be selected from large-scale real chat logs and paired with an automatic evaluation protocol that balances open-ended quality, task-specific requirements, and length-bias control. It aims to measure not standardized test knowledge but a model’s ability to answer realistic, ambiguous, long-tail, and complex user requests.
