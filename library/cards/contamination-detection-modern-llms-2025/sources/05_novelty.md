The individual detector families are not all new: Min-K%, Canonical Order, Token Completion Overlap, and Word Perturbation Quiz adapt prior work. The paper's own exploratory contribution is Local Order, which tests memory for dataset adjacency. Its broader novelty is experimental: five heterogeneous probe contracts are implemented side by side across four modern models and eight benchmarks instead of being evaluated in isolated settings.

The controlled instruction-tuning oracle is the more important contribution for data construction. By retaining benchmark questions, replacing answers with generated chain-of-thought, varying known added fractions, and packing consecutive examples, it tests a contamination form that differs from unchanged pretraining text. The before/after design makes detector directionality inspectable even though it cannot certify that the base checkpoint was clean.

For this track, the work is valuable as an audit-failure recipe. It exposes how a benchmark row becomes a perturbation quiz, completion pair, likelihood record, or ordered shard, and it shows which generated or intermediate artifacts would be needed to audit that transformation. The negative result—that ostensibly accepted methods neither track known exposure nor agree with each other—is more informative than a leaderboard-style detector claim.

The novelty boundary must remain narrow. This is not a universal contamination detector, not an instance-level membership ground truth, not a clean benchmark release, and not a complete oracle-training package. Local Order itself has an implementation defect that can duplicate the true successor, and the oracle controls only newly added exposure. The contribution is a comparative stress test and a partially released construction recipe.
