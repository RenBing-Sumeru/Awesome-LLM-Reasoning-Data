For **Data Construction & Open Release Recipes**, the paper is most useful as a template for specifying an audit record before interpreting its score. A practitioner can map each detector to its required input, generated intermediate, judge or statistic, aggregation level, and failure modes. That exercise prevents quiz accuracy, likelihood, overlap, and p-values from being collapsed into a fictitious common label.

The known-added-exposure oracle is a useful design reference for detector evaluation. Its fraction matrix and before/after measurements make false negatives and same-distribution false positives observable. A stronger reuse should add a demonstrably clean or better-characterized base, a token-matched nonbenchmark SFT control, repeated training seeds, exact corpus manifests, and calibrated confusion matrices.

The released 1,500 processed records and 150 completion slices can help reconstruct or unit-test parts of the five probe interfaces. They are insufficient for paper-level reproduction because original-order banks, generated artifacts, oracle data and checkpoint, output logs, and several execution paths are absent. Any reconstruction should pin upstream dataset revisions and repository SHA, fix the Local Order duplicate-option bug, revisit the Canonical Order statistic, and retain all successes, failures, options, draws, and likelihood vectors.

The work can also serve as a release-audit checklist: publish row-level provenance and rights, exact sampling/filtering code, complete generated artifacts, immutable run manifests, model/API versions, seeds, statistical procedures, and a failure ledger. Repository code and processed data should not be redistributed or trained on until their missing license and upstream terms are resolved.

The `sft` training-use label is deliberately narrow. Supervised fine-tuning is used to construct the controlled oracle; the detector scores are not rewards, preferences, correctness labels, or recommended supervision. Appropriate uses are audit, evaluation, detector stress testing, and recipe comparison—not treating the public probe rows as certified reasoning-training data.
