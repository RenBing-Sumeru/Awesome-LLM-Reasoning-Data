D-GARA asks whether Android GUI agents remain robust when real-world anomalies interrupt otherwise routine app tasks. The primary source is the arXiv paper submitted on 20 November 2025 and marked accepted to AAAI 2026, plus the official project and GitHub links recorded by the authors. It is in scope as an agent-environment benchmark because the object is a GUI interaction episode under perturbations. It is not a static screenshot grounding dataset or a pure task-completion benchmark in ideal conditions. A task contains a user instruction, app state, injected anomaly such as a permission dialog, battery warning, or update prompt, agent actions, observations, and a success predicate. The atlas value is its robustness-focused environment feedback contract.
