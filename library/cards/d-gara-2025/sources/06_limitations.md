Correctness is only relative to the app version, device/emulator state, anomaly template, and terminal predicate. A robust response to one permission dialog or update prompt may not transfer to another app, operating-system version, or language locale. Dynamic anomalies make reproducibility harder because UI timing and pop-up behavior can drift. The benchmark should not be read as a complete model of real mobile use or all adversarial GUI conditions. If manual review is used for any predicate or trajectory diagnosis, those rules must be recorded separately from automatic success checks.
