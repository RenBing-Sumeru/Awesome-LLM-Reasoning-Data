The contribution is a dynamic benchmarking framework that embeds real-world GUI anomalies into Android app tasks and measures how much they degrade GUI-agent performance. The core mechanism is anomaly injection: tasks are evaluated under normal and anomaly-rich conditions, so robustness can be separated from baseline task ability. The data object is a GUI episode with instruction, observations, actions, anomaly state, and terminal success check. The feedback contract is mixed environmental evaluation: the app state and task predicate determine success, while the anomaly setting defines the stress condition. Closest comparisons are static GUI benchmarks and idealized mobile-agent task suites. Direction label: dynamic robustness evaluation for GUI agents.
