SpecSearch inserts a draft-evaluate-reject-correct module wherever a search algorithm expands a node. A small model drafts N variable-length thoughts in parallel and an existing thought evaluator, usually a PRM, scores each one. A thought at or above the current step-wise threshold is accepted; a lower-scoring thought is discarded and replaced in full through lossless token-level speculative decoding with the large model. Scores from corrected large-model thoughts, together with accepted small-model thoughts used as approximate upper-bound observations, update the next threshold by an exponential moving average. The feedback contract is therefore mixed: a learned process score gates whole thoughts, while large-model speculative decoding supplies distribution-preserving corrections rather than proof that accepted thoughts are correct.
