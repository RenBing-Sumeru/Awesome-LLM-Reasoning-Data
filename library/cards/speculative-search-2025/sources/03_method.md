The default experiments pair quantized Qwen2.5-72B-Instruct with Qwen2.5-7B-Instruct, use MATH-psa as the PRM, set tree width to 6, maximum depth to 50, beam size to 2, and EMA weight to 0.9; Llama3-70B/8B, MCTS with 4 iterations, Math-Shepherd, and smaller Qwen draft models are additional conditions. At step k, six small-model drafts are scored, drafts below the threshold are replaced by large-model thoughts, all surviving or corrected thoughts are returned to the host search, and their scores update the threshold for step k+1. Main evaluation uses 100 randomly selected MATH problems and 100 GSM8K problems. Decoding temperature, seeds, exact sampled IDs, initial threshold, total thoughts per problem, and a raw trace schema are not disclosed in the paper. The author repository provides inference code and scripts, but no pinned release, standalone trace corpus, or repository license was verified.
