Qwen3Guard 是 Qwen 系列的安全审核发布，包含两种不同的数据/反馈接口。Qwen3Guard-Gen 接收审核指令、安全策略/类别规范、对话上下文和目标内容；它输出风险判断与类别，并在模型回复分类时额外输出拒答判断。Qwen3Guard-Stream 增加 query 与 response 分类头，使回复 token 能在生成过程中被分类。

已披露的 Gen 语料包含超过 119 万条人工标注和合成的正/负提示与回复样本。Gen 用 SFT 训练，Stream 则使用派生的 token 标签与监督分类损失。报告还展示了在 GSPO 安全 RL 实验中用 Gen 充当安全评审器。这一后续奖励演示与过滤/RL 设计相关，但并不是护栏模型自身的已验证训练合约。
