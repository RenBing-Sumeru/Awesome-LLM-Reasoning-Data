The arXiv abstract verifies the main benchmark scale: 73 bugs from seven real-world Python applications and six bugs from example programs. It also states the key feature that each subject has an oracle for functional correctness and supports both system and unit test generation.

The arXiv HTML verifies venue context and author affiliations: FSE 2024, with authors from CISPA Helmholtz Center for Information Security and Humboldt-Universitaet zu Berlin. The paper frames Tests4Py as a benchmark for test generation, debugging, and automatic program repair.

The official GitHub README verifies practical usability. It documents installation through `pip install tests4py`, pyenv requirements, a CLI named `t4p`, commands for checkout/build/test/unit/system testing, and MIT licensing. These are strong signals that the paper is backed by executable tooling rather than only a static paper dataset.
