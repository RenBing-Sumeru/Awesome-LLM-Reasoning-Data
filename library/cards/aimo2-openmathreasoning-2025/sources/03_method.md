1. **Acquire forum discussions.** Collect 620K AoPS discussions, excluding Middle School Math. The exact original scraper and immutable source-post manifest were internal and are not released; current construction docs point to AoPS-Instruct only as a similar public input, explicitly not the original input.
2. **Extract and classify problems.** Qwen2.5-32B-Instruct extracts 580K problems, marks proof/multiple-choice/binary/invalid types, removes unsuitable formats to reach 550K, converts proofs to answer-form questions, and extracts final answers from discussions.
3. **Decontaminate.** Use an LLM prompt to compare normalized problems against popular mathematical benchmarks, yielding the paper-stage 540K count. Candidate pairs, judge outputs, and removal decisions are not published.
4. **Generate CoT.** DeepSeek-R1 and QwQ-32B sample up to 32 candidates per problem at temperature 0.7, top-p 0.95, and maximum 16,384 tokens. A 32-generation Qwen2.5-Math-72B-Instruct pass rate allocates more attempts to hard known-answer problems. Qwen2.5-32B-Instruct filters by equivalence to extracted answers; no-answer and converted-proof items use a majority candidate answer. Of 5.2M candidates—1.0M QwQ and 4.2M R1—3.2M remain, split as 0.5M and 2.7M.
5. **Bootstrap TIR.** LIMO-Qwen-32B generates 1.2M Python-interleaved attempts with the same decoding values; more than eight code executions stop a generation. Require correct final answer, code execution, at most two code blocks, and Qwen2.5-32B-Instruct novelty/significance judgments. This produces the 15K stage-0 set.
6. **Iterate TIR.** Fine-tune QwQ-32B for seven epochs at constant learning rate `5e-6`; 700K attempts yield 260K after wrong/no-code removal. An intermediate 14B model trained successively on CoT and QwQ solutions generates the final 1.7M TIR corpus. Novelty/significance filtering is disabled in later stages because it reduced downstream performance.
7. **Encode tool budgets.** Randomly assign one to eight allowed code executions, expose the remaining allowance in prompts, and discard attempts exceeding the requested limit. Released TIR remains a text string; it does not carry a normalized call/observation ledger or sandbox hash.
8. **Construct GenSelect.** Form eight distinct groups per problem, each with 2-16 candidate summaries and at least one correct and one incorrect solution. QwQ-32B produces 1M comparisons; keep only those selecting a correct-answer candidate, yielding about 565K. Qwen2.5-32B-Instruct cleans long comparison traces, although models trained on summaries lose roughly 1-2 points.
9. **Train and deploy.** Main models receive six epochs of answer-level SFT on about 5.5M CoT/TIR/GenSelect rows with AdamW, weight decay 0.01, cosine schedule, 10% warmup, global batch 1,024, size-specific learning rates, and four-checkpoint averaging. A 2.2M hard subset supports another stage. The winning Kaggle 14B recipe instead uses eight epochs on 2.2M DeepSeek-R1 CoT rows excluding converted proofs, then 400 steps on 15K stage-0 TIR rows at learning rate `1e-5`; it does not use GenSelect.
