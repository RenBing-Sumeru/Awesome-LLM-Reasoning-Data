通用仓库级代码基准主要来自 Web 框架、工具库和应用软件，测试的是常规 issue 修复；科学软件还涉及物理约束、数值稳定性、领域数据格式和实验可重复性，补丁即使通过普通单测，也可能破坏科学含义。现有结果因此无法回答 coding agent 是否能在量子化学、分子动力学或数值相对论等仓库中完成真实维护工作。

AInsteinBench 从科学开源项目的 maintainer pull request 构建可执行任务，覆盖六类科学领域。每题配仓库快照、问题描述、参考修改、测试补丁、Docker 环境和二值评分规则，并经过多阶段过滤与专家审查，用于评测 agent 的科学代码定位、修改和验证能力。
