1. **Scientific coding-agent evaluation:** Run agents with fixed containers and inference budgets, reporting resolution, build-failure, domain, and difficulty scores separately so aggregate means do not hide failure in a scientific field.

2. **Verified training:** Use problems, repositories, and tests as RLVR environments with terminal rewards from test success. Gold patches should remain audit assets and must not be exposed to policy models.

3. **Data-expansion template:** Select maintainer pull requests from additional research projects and reuse the base-fails, gold-passes, expert-semantic-review pipeline. Repositories whose licences, data dependencies, or hardware cannot be packaged should not be forced into public tasks.
