The main contribution is an executable evaluation surface for scientific repositories driven by real maintainer changes. The main maintainer-PR subset contains approximately 244 tasks from quantum chemistry, quantum computing, molecular dynamics, numerical relativity, fluid dynamics, and cheminformatics projects; the release also provides subsets for difficulty and evaluation-type metadata. Records contain question identifiers, task types, descriptions, repository environments, reference answers, tests, and scoring configurations. A patch receives credit only by passing task tests in the specified container, while expert filtering removes instances requiring unavailable services, lacking sufficient descriptions, or having non-discriminative tests.
