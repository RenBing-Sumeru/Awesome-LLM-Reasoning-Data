General repository-level coding benchmarks mainly draw from web frameworks, utilities, and application software, testing conventional issue resolution. Scientific software additionally involves physical constraints, numerical stability, domain-specific data formats, and experimental reproducibility. A patch may pass ordinary unit tests while violating scientific meaning. Existing results therefore do not establish whether coding agents can perform real maintenance in quantum chemistry, molecular dynamics, or numerical-relativity repositories.

AInsteinBench constructs executable tasks from maintainer pull requests in scientific open-source projects across six scientific domains. Each task includes a repository snapshot, problem description, reference change, test patch, Docker environment, and binary scoring rule, with multi-stage filtering and expert review. It evaluates scientific-code localization, modification, and verification by agents.
