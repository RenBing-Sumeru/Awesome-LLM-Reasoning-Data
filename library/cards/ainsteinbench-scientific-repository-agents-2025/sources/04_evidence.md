AInsteinBench’s credibility primarily comes from task provenance and two-layer validation rather than a single model leaderboard. Approximately 244 main tasks trace back to maintainer pull requests in real scientific repositories across six computational-science domains. Base commits, reference patches, and tests are replayed in isolated environments, while experts check whether tasks require domain knowledge and whether tests discriminate correct patches. Evaluations of multiple coding agents show that scientific tasks remain difficult and analyze failures by difficulty and error type. This supports benchmark realism, but the limited set of repositories cannot represent the entire scientific-software ecosystem.
