The verifier receives outcome supervision only. A GSM8K rationale can contain invalid steps yet end at the correct number, while a semantically equivalent answer can be rejected by an undisclosed extractor or formatting rule. MBPP test passing is bounded by available test coverage and can reward brittle or test-specific programs. The code sandbox, timeout, interpreter, dependency, exception, and resource policies are not documented.

Cartesian pairing creates correlated data. One solution may appear in many pairs, and problems with particular positive/negative balances can contribute many more pairs than others. The paper does not report per-iteration class counts, pair counts, deduplication, balancing, subsampling, or malformed-generation handling, so the effective training distribution cannot be reconstructed.

The learned signal is candidate sequence likelihood, not a calibrated probability of correctness. Length, formatting, and generator-specific style can affect that score. The paper does not specify length normalization, score calibration, tie handling, abstention, cross-generator evaluation, adversarial attacks, or a refresh policy. A generator optimized against the verifier could therefore exploit score shortcuts even though the main data-collection loop uses programmatic labels.

Best-of-k improvement is not free capability: the main result samples 128 candidates per problem to estimate Best-of-64, and a scaling analysis uses 1,000 generations. The estimator assumes no tied scores and measures selection within a fixed pool. It does not by itself establish online reliability under a new sampler or deployment budget.

Scope and release are narrow. Evidence covers grade-school mathematics and small Python functions with cheap binary outcomes, 7B/13B LoRA models, and named benchmarks. No open-ended judge task, process supervision, full-parameter training, or robust code environment is tested. No official code, generated data, pair manifest, checkpoint, exact prompt bundle, or full hyperparameter configuration was confirmed.
