One-sentence contribution: WebVoyager: Building an End-to-End Web Agent with Large Multimodal Models makes a user instruction, website context, screenshot/page observation, browser action trace, final response, task date or site condition, and evaluator judgment. reusable by binding it to a concrete feedback contract.

Core mechanism: The authors build an LMM-powered browser agent and test it end-to-end on real websites via Selenium. Feedback contract: A GPT-4V-based automatic evaluator judges success from the task, responses, and recent screenshots, with optional human inspection and reported human-agreement calibration. Closest comparisons are text-only web agents, static web snapshots, and simulator-only web-agent benchmarks. Direction label: verifier-anchored agent evaluation, where the reusable unit is task object plus acceptance rule.
