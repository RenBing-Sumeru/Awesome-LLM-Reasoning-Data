WebVoyager: Building an End-to-End Web Agent with Large Multimodal Models asks how to close this gap: Open-web agents face live websites, screenshots, and changing page states; simulator-only or text-only evaluations miss that multimodal uncertainty. The primary source is https://arxiv.org/abs/2401.13919; public status is ACL 2024 main / arXiv (2024).

Decision boundary: It is collected as a live-web multimodal agent benchmark and evaluation protocol, not as a deterministic programmatic verifier. The evaluation surface is a user instruction, website context, screenshot/page observation, browser action trace, final response, task date or site condition, and evaluator judgment. This makes the paper useful for the atlas because the data object and feedback rule can be audited together.
