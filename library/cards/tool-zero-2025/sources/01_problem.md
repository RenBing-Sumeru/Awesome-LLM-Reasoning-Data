The canonical source is the ACL Anthology version in Findings of EMNLP 2025, pages 9135–9147, DOI `10.18653/v1/2025.findings-emnlp.485`; an earlier ACL ARR/OpenReview version and arXiv:2511.01934 are alternate official records. Tool Zero asks whether a base language model can learn reliable function calling directly with reinforcement learning, without an SFT checkpoint, when exact rule feedback is too sparse early in training. (Paper §1, §4.2–4.3)

The paper formalizes tool use as a trajectory over a query `q` and tool set `T`: each step pairs a natural-language reasoning action and selected tool subset with an observation from tool execution or user feedback. The actual reported RL unit is narrower and offline: a ToolACE or xLAM prompt/dialogue history plus a JSON candidate-tool list is completed with a natural-language thought and one or more Python-like function calls, then compared with a ground-truth call and reference AST. No Tool-Zero-specific live environment or resettable execution service is released.

This distinction places the work in `environment_agent_trajectory_data` because it specifies thought/action/tool/observation fields, and in `training_usage_optimization_objectives` because its main contribution is the whole-completion scalar feedback consumed by GRPO. It is not a released agent-environment dataset, learned reward model, process-supervision corpus, or new benchmark. BFCL-v3, API-Bank, Nexus Raven, Tool-Alpaca, and Seal-Tools are evaluation surfaces.

The Card is written at bilingual L4 content depth from the final paper, appendices, official venue records, checklist, upstream dataset cards, and MindSpeed-RL inspection. Its accepted canonical level remains `L3_summary_ready`: Tool-Zero-specific code, the processed training corpus, checkpoints, evaluation harness, immutable benchmark versions, and reconciliation of reported-number inconsistencies remain unavailable.
