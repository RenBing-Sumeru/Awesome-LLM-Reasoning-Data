LLM-as-a-Judge usually assesses a supplied answer in a fixed context, while existing agent benchmarks often use a terminal metric. Agent-as-a-Judge changes the evaluation object to a requirement, its dependent workspace artifacts, and optionally the trajectory that produced them. DevAI makes that contract concrete through requirement DAGs rather than a single task score. It is not a generally validated process reward model: the evidence-selection workflow and its human-consensus calibration are the paper's proof-of-concept contribution.
