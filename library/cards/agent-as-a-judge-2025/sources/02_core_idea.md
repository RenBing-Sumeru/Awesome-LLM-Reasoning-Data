Agent-as-a-Judge turns evaluation from a one-shot answer verdict into evidence-seeking, requirement-level inspection of an agent workspace. Its main data contribution, DevAI, contains 55 realistic AI-development tasks, 365 hierarchical requirements, and 125 softer preferences; task requirements form dependency DAGs. The judge locates relevant files, reads artifacts, optionally retrieves trajectory evidence, and returns satisfied/unsatisfied decisions. The authors publicly release the DevAI dataset and implementation; the official repository is MIT licensed.
