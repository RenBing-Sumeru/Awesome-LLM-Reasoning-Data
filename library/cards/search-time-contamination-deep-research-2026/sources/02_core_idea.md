The analysis aligns leakage labels with the operation that exposed evidence. Search returns URLs and snippets; BML uses regex patterns over data hosts, exam/question sites, benchmark names, and known source URLs. Visit opens a page; QCL uses normalized longest-common-substring overlap between question and retrieved content, excluding explicit-answer cases. EAL uses DeepSeek V4 Pro with a strict AND rule: extended verbatim question text and an explicitly paired ground-truth answer must both be present.

Question-level analysis first separates BML and non-BML questions, then divides the BML group by QCL/EAL co-occurrence. These groups are post hoc and non-random; the paper assumes comparable difficulty. Turn-level analysis compares predictions immediately before and after an STC event, counts absent intermediate predictions as incorrect, models time to first correct answer with time-varying Cox regression, and studies BML→QCL/EAL escalation with Kaplan–Meier curves.

The only direct access ablation disables web search for Tongyi Deep Research. The study otherwise observes naturally occurring contamination; it does not inject an answer into a randomized treatment group, censor selected pages and rerun identical trajectories, or train with contamination feedback. Proposed controls—isolated knowledge sandboxes, transparent trajectories, and private/dynamic or gated benchmarks—are recommendations rather than implemented interventions.
