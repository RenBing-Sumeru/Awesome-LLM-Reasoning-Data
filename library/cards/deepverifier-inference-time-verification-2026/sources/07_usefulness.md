Use this work when a web or tool-using agent needs a bounded self-correction loop rather than a single final judge. Its operational template is to log compact trace evidence, classify potential failures, turn only high-risk claims into checkable questions, and attach every rejection to an actionable retry instruction. For a production system, keep separate budgets for original execution, evidence verification, and retries; report acceptance accuracy and final task success together so a stricter verifier is not mistaken for a better agent.
