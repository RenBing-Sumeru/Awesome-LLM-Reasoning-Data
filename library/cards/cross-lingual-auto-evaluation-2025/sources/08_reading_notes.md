1. **One-sentence positioning:** It provides a cross-lingual judge using English references and a 500-example human-rated test set.
2. **Data takeaway:** RECON covers six languages, multiple task types, and human judgment scores.
3. **Method takeaway:** Hercule directly aligns an English reference with a non-English response without first machine-translating it.
4. **Core value:** It reduces the cost of building local-language references and supports evaluator meta-evaluation.
5. **Main risk:** The dataset is small, and English references cannot capture all local pragmatic, stylistic, and cultural quality.
