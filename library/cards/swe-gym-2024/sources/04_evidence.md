The arXiv abstract verifies the main counts and claims: 2,438 Python task instances; each has a codebase, executable runtime environment, unit tests, and natural-language task; the authors report up to 19 percentage-point absolute gains in resolve rate on SWE-bench Verified and Lite.

The same abstract reports inference-time scaling with verifiers trained on SWE-Gym trajectories and combined results of 32.0% on SWE-bench Verified and 26.0% on SWE-bench Lite for open-weight SWE agents.

The official GitHub README verifies the author affiliations, ICML-style citation, 2.4K tasks from 11 Python repositories, a Lite split of 234 instances, public data/models on Hugging Face, environment constants in SWE-Bench-Fork, pre-built Docker images, and reproduction docs for OpenHands and MoatlessTools.

Evidence quality is high for artifact existence, task shape, and reported headline results. Exact training-trajectory filtering, model checkpoints, and verifier variants should be checked against the paper and release revisions before reuse.
