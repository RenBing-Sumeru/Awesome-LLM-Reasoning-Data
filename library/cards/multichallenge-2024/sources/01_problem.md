MultiChallenge: A Realistic Multi-Turn Conversation Evaluation Benchmark Challenging to Frontier LLMs defines an evaluation surface in instruction-following, reasoning: whether model outputs or agent trajectories satisfy the task-specific feedback contract. The primary source and artifacts are paper: https://arxiv.org/abs/2501.17399; the local metadata records the source as 2025 / arXiv.

The decision boundary is benchmarks_evaluation_surfaces with roles benchmark and verification contract mixed, judgment_required. One benchmark instance is: task prompt, model answer, judge/checker output, and score. This is not a model-training recipe unless the paper separately releases training data; the card treats it as evaluation, audit. It matters for the atlas because the reusable object is an evaluation/data record with a named scorer, judge, verifier, reward, or environment predicate rather than an abstract capability claim.
