The survey organizes improvement methods with three levers: post-training enhancement, test-time exploration, and data augmentation. Post-training changes what the model learns before deployment; exploration changes what it can try while answering; data augmentation changes the examples from which regularities may be learned. The paper then relates these levers to existing benchmarks and proposes a sandbox-based evaluation view with an observation-coverage metric. That framing is valuable because a claimed gain in induction can otherwise hide very different causes. When comparing papers, ask whether the result comes from changed learned behavior, extra computation during solving, or a different set of observations. Also ask whether the evaluation gives enough and sufficiently varied observations for a proposed generalization to be meaningfully tested, rather than rewarding a short-term fit to the prompt.
