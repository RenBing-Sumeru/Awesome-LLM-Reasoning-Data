最主要的结果来自 DeepSeekMath-7B。名义 30K 样本下，CRPS 在 MATH、GSM8K、CollegeMath、DeepMind Mathematics、OlympiadBench 和 TheoremQA 上的平均准确率为 50.4；590K RFT 为 48.3，590K DART-Math 为 49.4。60K CRPS 达到 52.0。LLaMA3-8B 和 Mistral-7B-v0.1 在 30K 下分别为 39.6 和 36.8，也都高于报告的同规模 SIGMA。这些是作者流程下的下游结果，不能验证每条批评或发布样本。（论文表 1、表 5。）

消融实验把合成、搜索和对比选择拆开。在 DeepSeekMath-7B、30K 设置下，black-box generation 平均为 45.1，Vanilla MCTS 为 47.7，无对比合成为 47.5，随机对比为 48.3，完整 CRPS 为 50.4。移除全局或局部批评后分别降到 48.7 和 49.0；把采样路径多样性从 `K=3` 增加到 `K=15`，分数从 48.1 上升到 50.6。这些比较支持报告设置内的构造选择，但共享的分析模型与终局验证器仍会干扰“增益只来自数据质量”的归因。（表 3。）

泛化分析报告四个域外数学基准平均 40.3，SIGMA 为 38.0；在 200 对扰动 GSM8K 问题上的严格一致性为 64.5，Vanilla MCTS 为 52.1。附录实验使用 Qwen2.5-Coder-7B 在 HumanEval 上报告 57.9 pass@1，使用 LLaMA3-8B 在 StrategyQA 上报告 75.8 精确匹配。这些是有用的迁移信号，但非数学实验的种子数量、构造预算和公开产物没有达到数学发布的披露深度。（表 4、表 6、附录 C-E。）

数据效率主张需要按算术谨慎表述。摘要把 60K CRPS 与 590K 基线比较并称减少 20 倍，但 `590K / 60K` 约为 9.8。接近 20 倍的比较由名义 CRPS-30K 对 590K（约 19.7 倍）以及报告的目标模型 SFT 训练 10 对 192 GPU-hours（19.2 倍）支持。表 7 只覆盖重复发生的目标模型训练；论文承认还存在 MCTS 与分析模型推理开销，却没有公布完整的 API token、金额、探索计算、验证或重试成本账本。

发布核验提供了与基准性能不同的证据。Hugging Face 数据卡报告 27,256 行、9,939 个唯一问题、两个字符串字段、平均 3.3 步和 100% 盒装答案覆盖。官方代码公开了流程模块和配置，但在核验 commit `0d8a807c7783e1e15c24668e17a8450dc028c6a9` 上只有一个 commit，没有 tagged release 或 LICENSE 文件，依赖也仅声明版本下界。面向论文的配置还把名为 `gpt-5-mini` 的模型配置为 `anthropic` backend 和 `ANTHROPIC_*` 环境变量。这些事实降低了可执行复现置信度，尽管代码与最终数据确实公开。
