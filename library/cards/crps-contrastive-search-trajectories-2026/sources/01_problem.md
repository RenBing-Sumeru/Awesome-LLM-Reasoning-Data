Monte Carlo Tree Search can produce a tree of plausible, successful, failed, and inefficient reasoning paths, yet common data pipelines keep only a highest-reward path. Contrastive Reasoning Path Synthesis (CRPS) asks how to convert differences inside that search distribution into compact supervised data instead of treating MCTS only as a filter. The official ACL 2026 paper appeared in the conference proceedings on July 2-7, 2026; its code link is printed on the paper's first page.

Three objects must remain distinct. The **construction substrate** is an MCTS tree with node states, candidate reasoning actions, visits, node values, complete trajectories, and binary terminal outcomes. The **contrastive intermediate** pairs one positive anchor with either a high-visit incorrect hard negative or a longer correct soft negative, then adds analyst-generated global and local critiques. The **released training object** is only a newly synthesized `problem`/`solution` pair retained after final-answer verification. It is static SFT data, not a released search tree, preference pair, process-reward record, or online RL episode.

This places CRPS in `data_construction_open_release_recipes`: the official paper, code repository, and CRPS-30K dataset expose a concrete search-to-SFT recipe and a final data artifact. The decision boundary is narrower than all MCTS or contrastive-learning work: the card covers how search trajectories become released reasoning demonstrations, not test-time search itself or contrastive representation learning.

The release boundary remains incomplete. The public dataset card reports 27,256 examples over 9,939 unique problems despite the 30K name, and rows omit MCTS nodes, selected contrasts, critiques, verifier logs, rejects, and record-level source lineage. The bilingual Card is `L4_chinese_review_ready`, while the release remains `partial`: final SFT rows and code are available, but the intermediate construction trail is not auditable end to end.
