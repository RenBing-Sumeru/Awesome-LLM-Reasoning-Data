Qwen2.5-Math-7B-Instruct explores each seed problem with UCT-based MCTS. Complete paths receive a binary terminal reward from answer correctness. Among correct paths, CRPS chooses the shortest as the positive anchor and breaks length ties with the highest maximum node Q-value. Search statistics are then used to construct two contrast types rather than choosing arbitrary negatives.

A **hard negative** is an incorrect trajectory sampled in proportion to accumulated visit count, so the contrast emphasizes failures that consumed substantial search attention. A **soft negative** is a correct trajectory longer than the positive anchor, intended to contrast strategic efficiency rather than correctness. The paper reports `K=10` contrastive pairs and 10 MCTS rollouts per problem, but it does not state the experiment-level hard/soft mixture or fully reconcile pair availability, reuse, and stage yields. The checked implementation's sampler defaults to a 70%/30% hard/soft target, samples available negatives without replacement, and fills shortages from the other pool; that is code evidence, not an immutable release manifest.

GPT-5-mini receives the problem, positive path, and negative path. It first emits a structured global strategic comparison and a local critique around the first semantic divergence point, after heuristic segmentation into semantic reasoning acts. A second prompt asks the same analyst to synthesize a fresh step-structured solution that follows the success pattern, avoids the identified failure mode, and explains the relevant strategic choice without referring to an external critique.

The feedback contract has several layers but only one deterministic acceptance gate. MCTS terminal reward uses strict ground-truth answer matching; the analyst supplies unverified natural-language global and step-local critiques; post-hoc filtering extracts the synthesized final answer and accepts exact or SymPy-equivalent answers. This check observes terminal-answer equivalence. It cannot establish that every intermediate step is valid, that the identified divergence is causal, or that the synthesized reasoning faithfully implements the critique.

The closest construction contrast is selection-only MCTS or rejection sampling, which retains an existing correct path. CRPS instead turns a selected positive/negative pair into guidance for a newly generated positive demonstration. It differs from local refinement methods such as SIGMA because the analyst regenerates the path rather than patching one failed trajectory.
