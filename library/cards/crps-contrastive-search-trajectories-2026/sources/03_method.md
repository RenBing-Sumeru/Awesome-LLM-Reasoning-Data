1. **Source problems.** The primary math pipeline draws approximately 7.5K problems each from the GSM8K and MATH training splits, for roughly 15K stated seeds. Exact immutable source revisions, seed identifiers, attrition, deduplication, and the mapping to the 9,939 unique problems in the public CRPS-30K artifact are not released.

2. **MCTS exploration.** Use Qwen2.5-Math-7B-Instruct as explorer with UCT. The released configuration sets `c_puct=1.4`, maximum depth 16 semantic reasoning steps, up to 3 actions per node, 10 rollouts per problem, temperature 0.7, a 256-token expansion/action budget, and a 2,048-token simulation budget. A semantic step is segmented by structural boundaries, logic connectors, and explicit enumeration, with a 256-token cap and no split inside mathematical expressions.

3. **Trajectory stratification.** Assign each complete path a binary terminal outcome. Select the shortest correct path as positive anchor, breaking ties by maximum node Q. Treat incorrect paths as hard-negative candidates and correct paths longer than the anchor as soft-negative candidates. Hard negatives are weighted by accumulated visit count; soft negatives have no paper-specified excess-length threshold.

4. **Contrastive pairing.** The paper states 10 contrastive pairs per problem. The checked implementation defaults to a 70%/30% hard/soft target, samples without replacement within each available pool, and fills shortages from the other pool. The paper does not report aggregate hard/soft counts, zero-pair problems, pair-level random seeds, or how 10 rollouts yield 10 usable contrasts for every retained problem.

5. **Dual-granularity analysis.** GPT-5-mini compares a positive/negative pair and returns JSON containing a divergence-step index, local descriptions of each path, a critique of their difference, a global strategic analysis, a success pattern, and a failure mode to avoid. Regex extraction and rule-based repair handle malformed JSON; outputs still unparsable are discarded. The paper reports a parsing-failure rate below 5%, but not exact counts by analyst call, retry policy, or rejected instance.

6. **Fresh synthesis.** Condition GPT-5-mini on the problem and contrastive insights to generate a new step-by-step path rather than editing either original trajectory. The released configuration uses analyst temperature 0.7 with 1,024 tokens and synthesis temperature 0 with 2,048 tokens. The analyst is instructed to weave the contrast into the solution without meta-language and to end with a boxed final answer.

7. **Verification and pool construction.** Extract the final answer and retain only exact or SymPy-equivalent matches to the reference. Uniformly sample verified paths into nominal 15K, 30K, and 60K sets. The checked code samples without replacement if the pool is large enough and with replacement otherwise, but the public release does not expose verified-pool size, replacement flags, duplicates, rejects, or per-row construction lineage.

8. **SFT.** Train the target base model on the problem as prompt and synthesized reasoning path as completion with ordinary causal-LM loss. The paper reports DeepSeekMath-7B-Base, LLaMA3-8B, and Mistral-7B-v0.1; full-parameter AdamW with beta1 0.9 and beta2 0.95, peak learning rate 2e-5, 3% warmup, cosine decay, global batch 128, 3 epochs, DeepSpeed ZeRO-3 offload, and 8 A800 80GB GPUs. Search, analyst, synthesis, verification, and SFT costs must be accounted separately.

9. **Appendix-domain substitutions.** Code experiments use Qwen2.5-Coder-7B with unit tests on HumanEval; commonsense experiments use LLaMA3-8B with exact-answer matching on StrategyQA. GPT-5-mini remains the analyst. The paper does not release matching code or commonsense datasets, seed manifests, or full construction budgets.
