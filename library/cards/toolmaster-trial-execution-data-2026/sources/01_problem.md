Static expert trajectories can teach a tool-use path without teaching an agent how to investigate an unfamiliar API. ToolMaster studies this robustness problem by changing the interaction demonstrations themselves: a query is paired with an exploratory trial phase and an execution phase that can recover from errors. For this atlas, the object of interest is the resulting conversation and its filtering/reward contract, rather than only the trained checkpoint. [Primary paper](https://arxiv.org/abs/2601.12762), Sections 1 and 3.
