Consensus with DeepSeek-V3 is a model-mediated acceptance rule, not independent ground truth. The paper does not report retained-label precision, recall, calibration, or human agreement, and correlated errors may arise because OmegaPRM, the filtering judge, the 32B target writer, and the 14B student share mathematical and model-family priors. System-2 explanations may also be plausible post-hoc rationales rather than faithful accounts of the actual error.

Release lineage is incomplete. The paper's approximately 117,000 traces do not reconcile with the current 156,321-row Hugging Face train split. The public schema exposes only `conversations`; it omits source identifiers, OmegaPRM hypotheses, DeepSeek-V3 decisions, rejected samples, and rebalancing records. The code repository does not provide a complete end-to-end collection, filtering, target-generation, and training pipeline, and has no tagged release or paper-to-commit binding.

Reproducibility and rights remain partial. Exact MCTS constants and limits, generation temperatures, random seeds, teacher prompts and revisions, class ratios, and source allocations are not fully specified. The model card declares MIT, but no license is displayed for the checked data repository or code repository, and inherited source licenses are not consolidated. Excluding PRM800k addresses one leakage route but does not establish semantic decontamination from ProcessBench or the base models' pretraining corpora.

The method has task and decision-boundary limits. Experiments cover mathematics only, first-error stopping discards supervision for downstream steps, and the current repository parser relies on trailing plus/minus symbols. System-2-only has higher F1 on all four reported ProcessBench domains, and one Qwen2.5-14B OmniMATH transfer result declines after mixed training. The adaptive mode should therefore be read as an efficiency compromise whose robustness outside the tested distribution is unknown.
