For a problem prompt, TTA* initializes a tree of candidate derivations. It repeatedly selects a partial solution using an A*-style score, expands it with a proposed next reasoning step, asks the model to critique or refine the result, and inserts the resulting nodes back into the frontier. Search stops under the chosen computation budget and returns a completed solution selected from that explored tree.

The paper evaluates this drop-in decoding wrapper on mathematical reasoning benchmarks and several small-model backbones. It compares the resulting accuracy and robustness with baseline decoding and other test-time methods. Because the primary source provides no code, data, or acceptance record, an implementation should preserve the exact prompt format, priority formula, expansion cap, and stopping condition before attributing any gain to A* rather than to incidental extra tokens.
