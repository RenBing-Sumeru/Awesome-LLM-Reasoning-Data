The paper turns leakage auditing into candidate generation plus human verification: MinHash+LSH finds near-duplicate benchmark/pre-training pairs, annotators label them, and leakage ratios determine which items are removed. The official Hugging Face release contains 6,691 verified pairs with identifiers, both contents, dataset name, language, similarity label, and binary leakage label. It is an evaluation and audit dataset; original-source licenses still apply.
