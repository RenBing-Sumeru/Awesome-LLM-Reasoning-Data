The official MATPO-rollout release contains about 1.487 million planner and worker tool-use rollouts. Records distinguish roles, reasoning steps, tool names and arguments, tool outputs, format rewards, answer-correctness rewards, and composite rewards, supporting multi-agent credit assignment, trajectory-value learning, and robustness to noisy tools. MATPO switches roles through prompts on one shared model rather than deploying two separate models, reducing memory while preserving specialization. The large rollout set also provides multiple role paths and reward components for the same task, enabling analysis of local tool quality versus terminal success.
