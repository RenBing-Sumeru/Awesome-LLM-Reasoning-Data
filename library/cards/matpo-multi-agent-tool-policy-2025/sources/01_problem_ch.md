工具增强推理常用单 Agent 同时规划、执行和整理工具结果，长上下文与噪声响应会使计划被细节淹没。改成 planner/worker 多 Agent 后，又缺少能够分别给两种角色分配信用的 RL 方法：终局答案只能评价整条协作，无法说明计划错还是执行错。 若所有奖励统一回传，planner 可能因 worker 执行错误被惩罚，worker 也可能因优质计划掩盖低质量工具调用而获得正奖励。 统一回传终局奖励会让planner因worker执行错误受罚，也会让低质量worker借助优质计划获得正奖励；这种角色信用混淆使多Agent分工停留在提示层，而非可训练的专业化。

MATPO 在一个 LLM 中用角色提示实现 planner 与 worker，并以角色级 rollout 价值和工具奖励进行联合策略优化。
