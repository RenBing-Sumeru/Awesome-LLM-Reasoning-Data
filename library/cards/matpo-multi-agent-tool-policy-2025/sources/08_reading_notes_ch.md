1. **定位：**MATPO 解决共享模型中 planner 与 worker 工具轨迹的角色级信用分配。
2. **方法抓手：**角色提示分工、双层 rollout、局部工具奖励与全局结果奖励，再联合更新共享权重。
3. **数据抓手：**约 148.7 万条记录，含角色步骤、工具参数、格式/正确性奖励及合成 reward。
4. **证据锚点：**三个知识密集 benchmark 相对单 Agent 基线平均提升 18.38%，且更抗工具噪声。
5. **复用决定：**适合多 Agent RL/value 训练；必须核算工具成本、奖励盲区和角色梯度干扰；还应分别报告 planner 计划成功、worker 工具执行和两者接口错误；最适合多Agent RL、角色价值模型和工具轨迹审计；最大风险是共享权重干扰和工具格式shortcut，复用前必须做角色消融与去重。
