现有多 Agent 系统通常分别部署 planner 和 worker，训练时只优化最终回答，或者固定一个角色只训练另一个。MATPO 将两种角色放在同一模型实例中，并从各自 rollout 计算优势，使 planner 的分解和 worker 的执行都能获得可区分梯度。新意在共享权重下的角色级策略优化与信用合同，而不是多 Agent 架构本身。 这使多 Agent 专业化成为可训练行为，而不只是推理时由提示临时扮演两个角色。 局部优势还允许分别诊断计划分解失败与工具执行失败。 并不新的是planner/worker分工；真正变化是在共享权重中分别估计角色优势，让计划分解和工具执行获得不同梯度，因此专业化由训练形成而非临时角色扮演。
