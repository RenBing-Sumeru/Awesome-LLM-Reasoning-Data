MATPO-rollout can train planner and worker value models or support role-level rewards and shared-weight policy optimization in an existing tool agent. Evaluation should separately measure plan quality, tool-argument correctness, final answers, and noise robustness. Reproduction must fix tool APIs, error handling, and sampling budgets and compare against a single agent with the same total calls. When a task cannot be decomposed into relatively independent subtasks, planner/worker structure may add latency without benefit. Outputs can include a shared-weight multi-role policy, role value models, and stepwise tool-quality audit reports. Success checks should separately report planning success, argument correctness, interface failures, final answers, noise robustness, and total calls against a single agent with equal budget. Non-decomposable tasks are unsuitable.
