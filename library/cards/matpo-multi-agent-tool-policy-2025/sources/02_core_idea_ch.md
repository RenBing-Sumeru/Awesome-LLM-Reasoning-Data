官方 MATPO-rollout 含约 148.7 万条 planner/worker 工具调用 rollout。记录区分角色、推理步骤、工具名称与参数、工具输出、格式奖励、答案正确性奖励及合成 reward，可用于多 Agent 信用分配、轨迹价值学习和噪声工具鲁棒性研究。MATPO 不要求部署两个独立模型，而在同一权重上通过不同提示切换角色，降低显存成本并保留专业分工。 大规模 rollout 还提供同一任务中多个角色路径和奖励组成，便于研究局部工具质量与终局成功之间的关系。 MATPO-rollout约含148.7万条角色化工具轨迹，保存planner/worker步骤、参数、工具返回、格式奖励、答案奖励和合成reward，并提供同题多路径用于分析局部工具质量与终局成功。
