在 GAIA-text、WebWalkerQA 和 FRAMES 上，MATPO 相对单 Agent RL 基线平均获得 18.38% 的相对性能提升，并在向工具结果注入噪声时保持更强鲁棒性。对照显示，共享权重的多角色优化优于仅增加提示中的“planner/worker”描述，说明收益来自角色信用分配而非形式化分工。结论仍依赖所用工具集合、奖励准确性和 rollout 规模，不能直接外推到开放桌面 Agent。 噪声实验尤其检验 worker 返回不可靠信息时 planner 是否会重新规划，而非只测工具调用格式。 分任务结果在检索、网页遍历和多文档整合上均保持同方向提升。 主实验支持角色级优化在相同共享模型上优于单Agent RL并提高工具噪声鲁棒性；它不能把全部18.38%相对增益归于单一模块，也未覆盖开放桌面工具。
