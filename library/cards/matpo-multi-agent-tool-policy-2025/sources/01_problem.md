Tool-augmented reasoning often uses one agent for planning, execution, and synthesis, causing long context and noisy tool responses to overwhelm the plan. Splitting work into planner and worker agents creates another problem: existing RL cannot assign credit separately, because terminal correctness does not show whether planning or execution failed. With uniform reward propagation, a planner may be punished for a worker's execution failure, while a worker may receive positive credit because a strong plan masks poor tool use. Uniform terminal rewards punish planners for worker failures and reward poor workers when strong plans rescue them. Role-credit confusion leaves multi-agent specialization as prompting rather than learned behavior.

MATPO implements planner and worker roles within one LLM through role-specific prompts and jointly optimizes them with role-level rollout values and tool rewards.
