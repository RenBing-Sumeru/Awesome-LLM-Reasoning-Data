1. **分配角色：**planner 将问题拆为子任务和工具需求，worker 接收局部任务并执行检索、计算或网页工具。
2. **收集双层 rollout：**分别保存 planner 决策与 worker 工具轨迹，包括参数、响应、格式合法性和终局答案。
3. **计算角色信用：**工具格式与执行正确性形成局部奖励，任务结果回传为全局奖励，并按角色轨迹估计相对优势。
4. **联合优化：**在共享 LLM 上用角色提示和 MATPO 目标更新两类策略，循环采样约 148.7 万条轨迹；共享模型在更新时仍按角色分别归一化优势，避免 planner 与 worker 的奖励尺度直接混合。
5. **可复现信息：**可复现信息：需固定三个benchmark、共享基础模型、角色提示、工具API、噪声注入、每角色优势归一化与rollout预算；工具版本和部分RL超参数未披露时记为 unknown。
