On GAIA-text, WebWalkerQA, and FRAMES, MATPO achieves an average 18.38% relative improvement over single-agent RL baselines and remains more robust when tool outputs are corrupted with noise. Controls show that shared-weight multi-role optimization outperforms merely adding planner/worker instructions, indicating that gains come from role-specific credit assignment rather than naming roles. Conclusions still depend on the tool set, reward accuracy, and rollout scale and do not directly transfer to open desktop agents. Noise experiments specifically test whether the planner replans when workers return unreliable information rather than only checking tool-call formatting. Task-level results show gains in retrieval, web traversal, and multi-document synthesis. The main experiment supports role-level optimization over single-agent RL on the same shared model and improved tool-noise robustness. It cannot attribute the full 18.38% relative gain to one component or cover open desktop tools.
