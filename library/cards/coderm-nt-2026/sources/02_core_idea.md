CodeRM-NT is a code reward model that learns functional-quality signals without unit tests: MCTS exposes partial and complete programs to an execution-trace LLM judge, and their back-propagated scores supervise scalar and pairwise reward learning. The contribution changes the feedback object from a generated test verdict to an execution-grounded model judgment. The authors release code, training pipelines, and a model, but do not identify a separately downloadable reward-data dataset; the paper reports 196,098 scalar response records and 71,205 pairs constructed from Magicoder-OSS-Instruct-75K.
