The central value is a concrete client-executed agent contract. The model observes `goal + screenshot + recent actions`, proposes a normalized-coordinate or other UI `function_call`, and receives `function_result + URL + screenshot` after external execution. The 13 legacy browser actions include navigation, clicking, typing, scrolling, hovering, key combinations, waiting, and drag-and-drop; coordinate actions use integers normalized to 0-999.

Feedback must be separated by layer. Online-Mind2Web and WebVoyager use three independent human judges of the entire trajectory and majority vote over instruction following, completion, and answer correctness. Deployment uses per-step out-of-model safety gating plus user confirmation for selected high-risk actions. Neither contract is identified as the UI post-training reward, verifier, or terminal predicate; all of those remain unknown.

Compared with `openai-operator-system-card-2025`, this report offers a different proprietary computer-use disclosure with a public legacy function schema, partial Android environment pins, and matched Browserbase comparisons. Its useful direction is to treat the task, state, action, observation, whole-episode judge, safety gate, and live environment as distinct data/feedback objects.
