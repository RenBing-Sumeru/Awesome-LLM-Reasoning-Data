The complete UI-control training contract is unknown: tasks, demonstrations, screenshot/DOM/accessibility inputs, thoughts, success and failure trajectories, reward, verifier, terminal predicate, safety labels, calibration, rollout count, decoding, filtering, optimizer, curriculum, compute, and checkpoint lineage are all undisclosed. Human majority-vote evaluation and the deployment safety service must not be substituted for this missing training evidence.

Web results are version-sensitive. Live pages change; dates and feasibility changed WebVoyager from 643 to 559 tasks; Anchor, Browserbase, browser, Chrome/Playwright, viewport, site snapshot, OS, harness commit, timeout, and retry versions are unpinned. Current API docs and reference code have evolved since October 2025. AndroidWorld pins Pixel 6 and Android 13/API 33 but not the emulator image, apps, locale, reset state, or numerical default step/seed settings.

The report directly identifies prompt injection and adversarial pages, goal or UI misinterpretation, irreversible wrong actions, task failure, data exfiltration, and harmful or sensitive content. Confirmation before purchases, downloads, communications, and similar high-risk actions reduces risk but depends on classification accuracy and user comprehension. The safety service's thresholds, latency, false positives, false negatives, and bypass tests are unknown.

Computer Use-specific safety prompts, transcripts, rater counts, rubrics, results, and error analyses are withheld; much assurance relies on Gemini 2.5 Pro evidence. Exclusion from FSF because tools are restricted to browser/mobile UI controls is a scope decision, not a passed FSF assessment. Benchmark scores cannot establish training-data quality, contamination control, or safety.
