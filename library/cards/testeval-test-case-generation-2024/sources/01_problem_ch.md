一手来源：https://arxiv.org/abs/2406.04531。公开状态是 NAACL 2025 Findings / arXiv，年份为 2024。它要解决的问题，是用 test execution plus coverage measurement for overall, targeted line/branch, and targeted path tasks 这类反馈契约评测 program under test, target coverage objective, generated test inputs or test code, execution result, and coverage metric。

具体数据对象包括：程序、覆盖目标、生成测试用例、执行结果、行/分支/路径覆盖、分数。它是评测面；训练或奖励用途必须单独核验工件和许可。 它对库的价值在于把任务对象、评分器和复现边界钉住，而不是只留下一个总分。
