The arXiv abstract verifies 210 Python programs, three task types, sixteen commercial/open-source LLMs, NAACL 2025 Findings status, and the public GitHub benchmark pipeline.

The row-level evidence is the official task record plus the scorer result: generated tests execute and cover the requested program elements or paths. Aggregate metrics should be read only under the paper's model setup, split, and evaluator implementation; public artifacts can still become contaminated or drift through dependency and packaging changes.
