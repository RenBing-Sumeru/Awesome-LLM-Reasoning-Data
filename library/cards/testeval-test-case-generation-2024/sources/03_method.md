Inputs come from LeetCode-derived Python programs and target coverage tasks. Outputs are program under test, target coverage objective, generated test inputs or test code, execution result, and coverage metric. The substrate is Python test-case generation benchmark with coverage instrumentation.

Pipeline: 1. load or construct the task instance; 2. provide the model with the allowed context and scaffold; 3. collect the generated answer, patch, test suite, span, or trajectory; 4. execute or apply test execution plus coverage measurement for overall, targeted line/branch, and targeted path tasks; 5. report scores only for a pinned split, runtime, artifact revision, and scorer. Reproducibility requires paper=https://arxiv.org/abs/2406.04531, project=null, code=https://github.com/LLM4SoftwareTesting/TestEval, data=https://github.com/LLM4SoftwareTesting/TestEval, plus exact split, dependency/runtime, prompt/scaffold, and scorer version.
