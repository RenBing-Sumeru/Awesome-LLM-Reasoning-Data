The core object is a composite reward, r(x,y)=λrRM(x,y)+Σwi ai(x,y): a base preference score is complemented by verifiable signals only when the instruction requires them. Rather than claiming that one learned scalar represents correctness, the system exposes factuality and hard-constraint checks as separately auditable evidence. The paper additionally builds IFBench (444 multi-constraint instances) to test the missing instruction-following dimension.
