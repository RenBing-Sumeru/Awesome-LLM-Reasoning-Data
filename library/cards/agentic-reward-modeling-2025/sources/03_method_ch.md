1. **路由指令。** LLM 接收指令和检查器说明，选择相关集合 Aₓ，以免无谓调用；但路由仍可能错选或漏选。

2. **核验事实差异。** 对回答对先找冲突事实，再生成定向查询，以 Serper 搜索或参数知识取证，并给每个回答 0/1 事实性分；只核验差异，不逐项核验全部主张。

3. **核验硬约束。** 系统解析长度、关键词、格式等显式约束，LLM 生成 Python 检查代码，执行报错后修正，最后平均二值结果；软语义约束不在此验证器范围内。

4. **合成奖励。** 判决器把 ArmoRM 偏好分与被调用验证器分相加；论文将 λ 和两个权重固定为 1.0，结果用于排序、best-of-n 或构造偏好对。

5. **训练时构造偏好对。** 在 UltraFeedback 或 20,000 条 on-policy 指令各八个样本中取最高分为 chosen、最低分为 rejected，再对 zephyr-7b-sft-full 做 DPO。复现须固定 checkpoint、提示词、Google/Serper、验证代码与基准版本；部分预算和随机种子未知。
