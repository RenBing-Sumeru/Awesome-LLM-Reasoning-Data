Preference-only reward models can favor style, length, or superficial agreement while missing factual errors and instruction violations. Agentic Reward Modeling studies this reliability boundary for post-training: a reward signal should expose which check supports a preference rather than treating one opaque scalar as ground truth. The primary source is ACL 2025. The released object is a reward-agent implementation and its preference-pair construction procedure, not a standalone universal correctness dataset.
