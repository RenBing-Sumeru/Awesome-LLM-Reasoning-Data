Test-time compute improves mathematical reasoning only when a system can distinguish promising solution paths from plausible-looking errors. Process reward models provide step scores, but conventional supervised training does not directly optimize the long-horizon value of a partial utterance, and online Q-learning is difficult because utterance-level actions create an enormous action space.

VerifierQ asks whether a verifier can be trained from fixed reasoning data as an offline critic. The paper targets a process-level record containing a question, partial solution, utterance action, and correctness reward, and seeks a value estimate that lets a generator-verifier system make better use of multiple sampled solutions without requiring new online search during verifier training.
