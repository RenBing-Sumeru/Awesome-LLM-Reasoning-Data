VerifierQ is evaluated with TinyLlama-1.1B and is sensitive to the expectile choice; the paper itself notes dataset-dependent settings and memory/compute cost above a PRM. Offline Q-learning can still overestimate unfamiliar paths when process labels or rollout support are weak. The code is not publicly released in the checked version, and the data lineage spans several external datasets, so reproduction and license review require more work than a self-contained benchmark package.
