The paper represents a state as the problem plus all generated utterances so far, and marks a correct step with reward one and an incorrect step with reward zero. Its modified Bellman target keeps Q-values in the unit interval. A separate value function approximates the large-action-space maximum, while a conservative term and Polyak-averaged target network are intended to reduce offline overestimation and stabilize updates.

Experiments use TinyLlama-1.1B, initialized through MetaMath and process-reward training. The authors evaluate GSM8K and a 500-question MATH subset, comparing VerifierQ with majority voting, PRM, standard Q-learning, and IQL variants. The card records the linked source datasets, but the paper promises implementation release only in the future, so exact training code is not currently an official artifact.
