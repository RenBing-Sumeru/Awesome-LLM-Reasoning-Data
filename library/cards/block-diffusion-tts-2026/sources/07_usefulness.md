Use this paper when the inference stack uses a diffusion or block-diffusion language model and the resource knob is richer than the number of completed samples. It supplies a concrete vocabulary for logging a run: block size, denoising steps, confidence, exploration/refinement phase, token-per-forward, and final accuracy. The official TDAR repository is the practical starting point, but an engineering comparison should hold task, model quality, decoding temperature, and end-to-end latency constant before attributing gains to the scheduling policy.
