The core idea is to align the whole training lifecycle with reasoning. Pretraining improves extraction of mathematics, code, and forum structure; globally deduplicates webpage dumps; applies small-model domain and quality tags; synthesizes reasoning-rich responses; and changes the mixture over three stages. Mathematics and code rise to 70% in Stage 2, while Stage 3 adds 10% synthetic responses and extends context from 8,192 to 32,768 tokens.

Posttraining has two paths. MiMo-7B-RL-Zero applies RL directly to MiMo-7B-Base. MiMo-7B-RL first applies distilled SFT and then RL. The original SFT set contains about 500K filtered responses; a later MiMo-7B-RL-0530 variant reports 6M SFT instances and progressively raises the RL generation budget to 48K.

The RL object is a full solution to one of 100K mathematics or 30K code problems. Mathematics uses Math-Verify. Code uses an online judge and a test-difficulty reward that can grant partial credit by test group. Modified GRPO, dynamic sampling, and a 10% easy-problem pool determine which verified rollouts contribute updates. Model-based curation precedes these programmatic rewards, so the end-to-end construction contract is mixed.
