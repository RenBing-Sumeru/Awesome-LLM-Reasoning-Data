输入是 GSM8K、MATH、MMLU 和 GPQA-Diamond 的评测问题，以及 Llama-3.2-3B、Qwen2.5-MATH-7B 和 Qwen2.5-32B 在 temperature 0.4–1.0 下的生成结果。为控制成本，实验先为每题生成 100 条响应，将得到的经验答案分布视为模拟分布；随后各 SC 变体从该多项分布重采样，而不是重新执行在线推理。分析主要聚焦 aligned questions，即正确答案恰好是该分布众数的问题。

对动态分配而言，每题记录应包含已采样最终答案、唯一答案数 K、前两名计数 n1 与 n2、ASC 置信度、PPR-1v1 置信度、混合排序、排除标记和每一步分配。Blend-ASC 反复为排序最低的问题采样，直到全局预算 T 用尽，再输出经验众数。论文以达到 SC@64 或 SC@128 的 reducible error 所需平均样本数为评价，并报告了 prompt batching 和流式 query 分组变体。

循环中没有可执行环境或正确性奖励；选择器仅是复数投票及 beta/计数置信度。固定分配实验使用对经验间隔具有 oracle 访问的平滑凸近似。完整复现仍需要答案归一化规则、数据集版本、随机种子、aligned-question 精确筛选、100 样本缓存分布和代码；目前均未确认有官方发布。
