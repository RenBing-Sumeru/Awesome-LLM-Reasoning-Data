The core idea is a three-part evaluation frame. “What” names the target capability or risk. “Where” identifies the task, dataset, and benchmark context. “How” specifies prompts, protocol, metric, and grader. Keep all three parts together when reading a score. A reasoning benchmark can be valid for arithmetic correctness yet say little about factual support, tool use, or robustness. The frame turns an impressive number into a bounded claim that another reader can inspect.
