TTT-Discover starts from the open gpt-oss-120b model and uses the Tinker API to run reinforcement learning during solution of a single problem. Candidate programs or solutions are evaluated by the task’s continuous reward, and the policy/search procedure is updated to favor promising regions. This is repeated within the test-time budget until the system returns its best discovered solution.

The evaluation spans Erdos-type mathematics, GPU kernel engineering, past AtCoder competitions, and single-cell denoising. The official project reports results for every attempted problem, provides code and verification links, and states that test-time training costs a few hundred dollars per problem. The method should therefore be evaluated by solution quality and total per-problem optimization cost, not by ordinary fixed-model latency alone.
