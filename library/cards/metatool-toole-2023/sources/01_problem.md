MetaTool Benchmark for Large Language Models: Deciding Whether to Use Tools and Which to Use defines an evaluation surface in tool-use, agent-environments, interactive-evaluation: whether model outputs or agent trajectories satisfy the task-specific feedback contract. The primary source and artifacts are paper: https://arxiv.org/abs/2310.03128; code: https://github.com/HowieHwong/MetaTool; data: https://github.com/HowieHwong/MetaTool; doi: https://doi.org/10.48550/arXiv.2310.03128; the local metadata records the source as 2023 / ICLR 2024 / arXiv.

The decision boundary is environment_agent_trajectory_data with roles benchmark, agent_environment and verification contract environmental, programmatic. One benchmark instance is: Tool-use awareness prompts, single-tool and multi-tool selection examples, and reliability-issue cases. This is not a model-training recipe unless the paper separately releases training data; the card treats it as evaluation, audit. It matters for the atlas because the reusable object is an evaluation/data record with a named scorer, judge, verifier, reward, or environment predicate rather than an abstract capability claim.
