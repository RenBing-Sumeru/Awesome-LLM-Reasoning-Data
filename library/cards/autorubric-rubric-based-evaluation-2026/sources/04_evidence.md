On CHARM-100, binary factual accuracy reaches 87% with Cohen’s kappa of 0.642. Four ordinal criteria achieve 85–93% adjacent-grade accuracy but only 38–58% exact accuracy, showing that near-correct ratings can hide calibration problems. Using the framework for feedback raises a peer-review agent from 0.47 to 0.85, above the 0.82 expert baseline. The protocol is useful, but CHARM-100 is small.
