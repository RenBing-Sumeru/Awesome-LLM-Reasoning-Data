Evidence-backed uses are agent training and evaluation at the framework-interface level. The Card supports comparison of execution-versus-training-trajectory schemas, state/action/reward extraction, optional AIR signals, equal-return credit assignment and task-specific demo rewards. It should not be used to claim access to a common Agent Lightning corpus, a standard reward verifier, a canonical environment, a user trace release or privacy-cleared data. A concrete downstream run requires its own source-rights, consent/privacy, redaction/retention, task/split, reward-calibration, trace lineage and reproducibility evidence.
