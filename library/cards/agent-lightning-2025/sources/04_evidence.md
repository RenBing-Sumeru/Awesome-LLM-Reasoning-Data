The evidence bundle verifies the official arXiv report, Microsoft Research project page, microsoft/agent-lightning repository, MIT license and Responsible AI documentation. Microsoft describes a research-purpose framework and directs users to supply and convert their own datasets to parquet rows containing data ID, input and expected output. The paper demonstrates Spider, MuSiQue/Wikipedia and Calc-X tasks, but the repository links no paper-wide data, trace, reward, model or Hugging Face release. The official artifacts therefore establish code, documentation, examples and a trace interface; they do not establish a canonical frontier corpus, common reward ledger, environment bundle, benchmark-data release or immutable paper-run artifact set.
