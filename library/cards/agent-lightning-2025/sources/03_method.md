The Training-Agent Disaggregation architecture has a server that coordinates user-uploaded task batches, agent clients that execute agents, LightningStore for task/resource/trace synchronization, and a backend that updates resources or models. Environments and rewards may be local to a worker or pooled shared services; no canonical environment bundle is released. LightningRL extracts input-output-reward transitions, assigns episode return across selected LLM calls and delegates token-level optimization to PPO, GRPO or REINFORCE++. The reported implementation assigns every action in an episode the same value as its final return. The three examples use Llama-3.2-3B-Instruct with LangChain, OpenAI Agents SDK or AutoGen. Each task may run multiple times, but a unified corpus sampling protocol, prompt filter, rollout count, retained/rejected transition manifest, seed and checkpoint package are not disclosed.
