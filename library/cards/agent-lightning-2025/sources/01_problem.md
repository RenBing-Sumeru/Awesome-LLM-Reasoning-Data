Agent Lightning is curated for the Frontier Reports and Data Disclosure Ledger as a framework and trace-schema disclosure, not as a canonical training corpus. Its user-supplied tasks and agents can be run through a client that captures executions with OpenTelemetry/AgentOps instrumentation or a basic OpenAI-like API tracer. Executions are represented as component calls with metadata, inputs and outputs; extracted training transitions contain LLM input/context, LLM output/action and scalar reward. State can also carry semantic variables, program counter, values, call stack and resource context. Structured prompts, tool calls and rewards may flow as trace spans to LightningStore, but no paper-wide execution, rollout, trace or span corpus is linked as an official artifact.
