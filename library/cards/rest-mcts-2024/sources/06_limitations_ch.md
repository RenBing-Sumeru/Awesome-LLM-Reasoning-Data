**作者明确的范围限制。** ReST-MCTS* 依赖标准参考标签完成答案筛选。作者把推广到数学与科学之外、尤其是没有精确答案的任务列为未来工作，也指出价值模型规模和数据多样性有限。

**目标依赖策略与搜索预算。** 节点价值来自有限搜索树中实际找到的路径。未发现正确延续并不证明正确延续不存在，观测到的最短距离也未必是全局最短。更换策略、分支数、迭代上限、价值模型或终点验证器都可能改变标签。

**停止与接收是两种不完美且不同的机制。** 学习价值达到 0.9 时，搜索可以在参考答案核验前终止。自我评议由当前推理模型生成，不是独立检查器。之后的终点筛选依赖对格式敏感的字符串匹配，或说明不完整的 GPT-4 判断器。

**终点正确不能验证过程。** 已核验的公开策略数据中，至少有一条直接可见的轨迹最终答案正确，但中间几何论断缺乏依据。这个单例不能量化全库质量，却直接否定了“最终答案接收等于步骤真值”的假设。

**初始化包含标签假设。** 科学数据配方假设参考解可靠且简洁，并把 ChatGLM2 生成的延续视为错误。这些假设可能造成部分解目标的假阳性或假阴性。论文报告的 69.3% 价值模型准确率是对构造目标的一致性，而不是人工步骤有效性审计。

**公开来源信息不完整。** 策略与价值文件都是两字段表，缺少树拓扑、失败或淘汰分支、访问次数、搜索设置、终点判定方法，以及策略轨迹与贡献节点目标的关联。精确来源混合、题目编号、问题级划分语义、去污染和基准重叠分析均未报告。

**许可与复现设置需要核对。** Hugging Face 制品带有 Apache-2.0 或 CC-BY-4.0 标签，但在核验版本上，官方代码仓库没有可见软件许可。上游问题与模型条款仍需审计。附录 E.1 给出的学习率为 `1e-6`，仓库 README 则给出不同的骨干专用设置。

**成本随探索扩大。** 论文报告基础 MCTS* 设置平均每题 108 秒，并展示 token 用量随迭代与分支增长。相同预算下的基准改善只能证明完整推理/训练系统的效用，不能证明发布样本本身天然高质量。
