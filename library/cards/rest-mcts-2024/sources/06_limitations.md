**Author-stated scope.** ReST-MCTS* relies on oracle reference labels for response filtering. The authors identify generalization beyond mathematics and science, especially tasks without exact answers, as future work. They also note limited value-model scale and data diversity.

**Targets depend on policy and search budget.** A node value is derived from routes found in a finite tree. Failure to discover a correct continuation does not show that none exists, and the minimum observed distance need not be globally minimal. Changing the policy, branch factor, iteration cap, value model, or terminal verifier can change the label.

**Stopping and acceptance are imperfect and distinct.** A learned value at least 0.9 can stop search before reference-answer verification. Self-critique is generated by the same inference model, not an independent checker. Terminal filtering then uses formatting-sensitive string matching or an incompletely specified GPT-4 judge.

**Terminal correctness does not validate the process.** The verified public policy release contains at least one readily visible trajectory with the correct final answer but unsupported intermediate geometry. This single audit example does not quantify corpus quality, but it directly contradicts any assumption that final-answer acceptance supplies stepwise truth.

**Initialization embeds label assumptions.** The science recipe assumes supplied solutions are reliable and concise and treats ChatGLM2-generated continuations as incorrect. Those assumptions can create false-positive or false-negative partial-solution targets. The reported 69.3% value-model accuracy is agreement with constructed targets, not a human step-validity audit.

**Release provenance is incomplete.** Public policy and value files are two-column tables. They omit tree topology, failed or rejected branches, visits, search settings, terminal-verdict method, and links between a policy trajectory and its contributing node targets. Exact source mixtures, item IDs, question-level split semantics, decontamination, and benchmark-overlap analysis are not reported.

**Licensing and reproduction need reconciliation.** Hub artifacts carry Apache-2.0 or CC-BY-4.0 tags, but the official code repository has no visible software license at the verified revision. Upstream question and model terms still need audit. Appendix E.1 reports learning rate `1e-6`, while the repository README gives different backbone-specific settings.

**Cost grows with exploration.** The paper reports 108 seconds per question for its basic MCTS* setup and shows token use growing with iteration and branching. Matched-budget benchmark gains are evidence about the complete inference/training system, not proof that released rows are intrinsically high quality.
