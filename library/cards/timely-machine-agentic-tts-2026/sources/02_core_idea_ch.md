Timely Machine 用墙钟时长替代通常以词元长度理解的测试时间。一次任务的成本是模型生成时间与工具执行时间之和，因此同样的交互次数在不同工具下可能对应截然不同的预算。反馈很快时，较小模型可利用速度获得更多轮次；反馈很慢时，轮次被工具限制，较大模型的高质量动作变得更有价值。

该工作通过 Timely-Eval 和 Timely-RL 落实这一思想。Timely-Eval 在文字游戏中改变延迟，评测代码与训练交互，并向普通推理任务提供计时器工具。Timely-RL 先用带时间约束的轨迹冷启动模型，再奖励正确、按时完成和有效的预算利用。因此，它训练的是在物理时间上分配推理与交互的策略，而不是无条件偏好更多词元。
