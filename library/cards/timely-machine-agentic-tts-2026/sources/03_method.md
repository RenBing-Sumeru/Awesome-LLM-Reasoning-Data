Timely-Eval has three task families. It wraps 57 Jericho text games with action, valid-move, score, and termination tools whose delays can be controlled; it adapts four MLEBench-Lite machine-learning tasks where code execution and model training are costly; and it evaluates AIME, MATH, and GPQA Diamond with a timer tool that the model must query. Budgets are set as multiples of measured per-step latency, and an answer that arrives after the deadline is incorrect.

For the cold start, the authors distill one million timed general-reasoning examples from Qwen3-235B-2507-Instruct and timed game traces from DeepSeek-V3.2, limiting game traces to fifty steps. These are combined with DataScience-Instruct-500K. Timely-RL then uses a GRPO-style objective: time beyond the limit earns zero, while correct on-time completion adds a smooth utilization reward. The paper trains with eight rollouts per sample and assesses Qwen3 models from 0.6B to 32B plus TimelyLM-8B.
