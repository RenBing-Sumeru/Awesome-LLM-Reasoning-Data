The prior-work baseline is static QA, offline website imitation, or narrower web benchmarks that do not fully capture offline real-website action traces with HTML snapshots across many sites. What changes here is the release of a more explicit environment, state/action record, or task contract for browser agents.

It is a direction signal because agent evaluation increasingly depends on replayable states, verifiable success predicates, and failure traces. The quality signal is the presence of official source pages, released code/data where available, and a concrete evaluator or benchmark surface.

What is not new: a high leaderboard score alone is not a reusable data contribution. Reuse checks should inspect license, split leakage, task freshness, evaluator brittleness, and whether live web pages drift after release.
