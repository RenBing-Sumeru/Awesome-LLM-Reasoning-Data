一句话贡献：Mind2Web: Towards a Generalist Agent for the Web 把覆盖多个真实网站的离线动作轨迹和 HTML 快照封装成可复用的智能体评测或轨迹表面。核心机制是把任务指令和浏览器状态、页面状态、截图、DOM/HTML、工具或模拟器状态绑定，再用基于记录页面状态的离线动作匹配和元素选择评测给出成功判断。

数据对象是众包网页导航演示、HTML 快照、任务目标和动作目标。反馈契约偏环境化：成功依赖页面状态、答案匹配、任务谓词或评测器，而不是自由文本偏好标签。分类理由：可复用单元是交互环境、Web 行动记录或浏览器任务 harness。

最接近的比较对象是 WebLINX、WebArena、SeeAct 和 Online-Mind2Web。
