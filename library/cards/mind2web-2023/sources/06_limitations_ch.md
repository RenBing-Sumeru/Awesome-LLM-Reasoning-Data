Mind2Web: Towards a Generalist Agent for the Web 的主要局限在于：只有固定 评分面、划分策略、版本和 工件 访问条件后，分数才适合复用。单个 基准 分数可能掩盖提示词/脚手架 选择、依赖漂移、裁判 或 答案抽取器 行为，以及公开数据污染。

划分/版本边界：比较结果前要固定公开/隐藏划分、任务版本、快照日期和评测器版本。

许可证/访问边界：复用前必须检查工件级许可证和再分发条款。

污染边界：公开任务和轨迹可能泄漏到未来训练数据；发布后或 live-web 声明需要带日期的证据。

审核时需要保留的失效模式：真实网站、服务状态或浏览器依赖可能在发布后漂移；提示/脚手架选择、重试、视觉设置和动作抽象会改变分数；公开轨迹或任务配置可能变成训练污染源。
