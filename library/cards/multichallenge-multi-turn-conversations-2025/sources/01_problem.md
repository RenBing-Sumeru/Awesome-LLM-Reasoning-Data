Many dialogue benchmarks either treat each turn independently or only test whether a model remembers explicit facts, allowing frontier systems to approach saturation quickly. Real multi-turn interaction instead requires maintaining constraints, interpreting user revisions, rejecting false premises, and integrating earlier context into later responses. The paper asks whether strong models remain reliable under these more realistic conversational conditions and how to construct a difficult yet consistently scorable multi-turn benchmark. The central issue is not whether a model can answer one hard question, but whether it can remain coherent, correct, and instruction-following as the dialogue state changes.
