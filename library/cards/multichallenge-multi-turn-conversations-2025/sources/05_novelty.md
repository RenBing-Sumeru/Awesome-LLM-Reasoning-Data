Existing evaluations such as MT-Bench often score short conversations using a few fixed dimensions, while some memory benchmarks reduce multi-turn ability to information retrieval. MultiChallenge does not merely add more turns. It deliberately constructs realistic difficulties such as cross-turn constraint conflicts, user corrections, false premises, and state updates, and assigns different acceptance criteria to each instance. By binding a dialogue trajectory to an instance-specific rubric, it forces judges to evaluate the actual conversational state rather than generic fluency. The novelty lies primarily in challenge design and an auditable evaluation protocol, not in a new dialogue model.
