已披露的方法可分为四个边界明确的层次。

1. **数据与过滤。** 模型卡列出四类宽泛预训练来源，并称 xAI 为质量和安全采用去重与分类；但未给出比例、来源清单、提示词溯源、分类器定义、阈值、产出量、拒绝样本策略或基准重叠检查。
2. **后训练。** 模型卡列出监督微调、人类反馈、可验证奖励和模型评分。发布公告称，xAI 使用大规模 RL 提升智能密度，并端到端地训练工具使用 RL；但目标函数、奖励定义、评分器、rollout 策略、采样、日程和数据量均未披露。
3. **安全措施与评估。** 模型卡称部署了注入式安全策略系统提示词和基于模型的输入过滤器，并报告拒答、AgentHarm、AgentDojo、MASK、answer-sycophancy、内部 soft-bias、WMDP、VCT、BioLP-Bench、CyBench 和 MakeMeSay 评估。soft-bias 评估使用 LLM 裁判；CyBench 使用带代码执行能力的智能体 harness 与 Inspect 评估框架。
4. **产品/推理层。** 公告称推理与非推理行为使用相同权重，并由系统提示词引导；它给出 200 万 token 上下文和供 API 用户配置的测试时计算，而不是可复现的训练或评估采样预算。
