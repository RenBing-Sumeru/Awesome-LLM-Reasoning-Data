The canonical source is the ten-author NeurIPS 2025 Main Conference paper and its 64-page final proceedings PDF. The official project page, reproduction-oriented `paper` branch at commit `41ed983cdf541cfcd2f963f33c055d50074f3c90`, released seed files, checkpoints, and linked logs provide the artifact record.

Absolute Zero addresses a specific curriculum-construction problem: can reinforcement learning continuously create its own executable reasoning tasks and rewards instead of consuming a fixed human-curated or teacher-distilled task-answer corpus? One current policy alternates between proposer and solver roles over three Python task types. Deduction asks for an output given `(program, input)`; abduction asks for any input that makes a program produce a target output; induction shows five of ten generated I/O pairs plus a message and asks for a program that passes the five hidden pairs.

An internal online record is therefore more than a Python triplet. It includes task type and sampled buffer context, proposer prompt/completion, generated program and inputs, executor outputs, parse/safety/two-run-determinism checks, eight solver attempts, estimated success rate, proposer learnability reward, solver prompt/completion, task-specific terminal verdict, and format reward. These records enter evolving buffers and Task-Relative REINFORCE++ updates.

“Zero data” has a narrow, supportable meaning: **the AZR RL stage uses no external human-curated or distillation task-answer dataset**. It does not mean zero prior data or zero human design. The policy begins from externally pretrained Qwen2.5 or Llama checkpoints; humans specify prompts, role templates, task taxonomy, an identity-function seed, executor rules, forbidden modules, rewards, optimizer, and evaluation suites. The executor itself supplies privileged program outputs.

This belongs in **Data Construction and Open Release Recipes** because it exposes an online self-play recipe, programmatic verifier, reward calculation, buffer policy, and optimizer scaffold. The repository releases code and model-specific 256-row seed JSONL files, but not the complete paper-run buffers, proposer/solver rollouts, verifier traces, rewards, rejected tasks, or failed executions. The Card is ready for bilingual review at L4, while release completeness and exact-run reproducibility remain partial.
