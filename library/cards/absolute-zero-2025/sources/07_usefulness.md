For the **Data Construction and Open Release Recipes** track, Absolute Zero is most useful as an online-curriculum blueprint, verifier audit target, and disclosure baseline.

1. **Implement a minimal autotelic RLVR loop.** Separate proposer context, proposal, executor validation, task buffer, solver instance, terminal reward, and role-relative optimizer. Begin with the identity triplet and verify that seed generation reproduces the documented 256-row buffers before training.
2. **Compare task families under one verifier.** Hold optimizer and sampling budgets fixed while ablating deduction, abduction, induction, historical references, and proposer updates. Preserve role and creation-step fields so gains can be attributed to curriculum changes.
3. **Audit learnability reward.** Store all eight solver attempts, success-rate calculation, format outcomes, and admission decisions. Compare `1 - success_rate` with confidence-aware or held-out estimates; eight samples are noisy, and zero-success tasks receive no positive learnability signal.
4. **Harden the environment.** Replace raw `exec`/`eval` with a pinned sandbox; disable network access, isolate filesystems and processes, enforce CPU/memory/time limits, and adversarially test denylist escapes, state leakage, and nondeterminism.
5. **Publish a reusable episode ledger.** Release immutable buffers and both successful and failed records with prompts, completions, executor observations, verifier versions, rewards, task lineage, seeds, model checkpoints, and run IDs. This would turn the open recipe into an auditable data release.
6. **Test shortcut and contamination hypotheses.** Stratify by global-variable use, comments/docstrings, program family, and similarity to evaluation tasks; report performance after removing communication channels and matched programs.

Reuse classification is **recipe/audit reference with conditional code reuse**. The released seeds can test parsers and initialization, and the code documents the pipeline, but they are not a training corpus equivalent to the reported online run. Unqualified execution or training reuse is blocked by executor safety, missing trajectory lineage, unclear checkpoint/data licensing, and absent decontamination. The reported models and scores are evaluation evidence, not proof that a complete “zero-data dataset” was released.
