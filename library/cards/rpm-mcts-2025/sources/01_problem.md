RPM-MCTS addresses a test-time code-generation bottleneck: tree search can generate alternative plans, but intermediate algorithmic steps are difficult to score and erroneous steps are often detected only after complete code is produced. The paper’s primary reasoning object is a search trace whose root is a programming problem and whose other nodes are algorithmic steps; associated signals include knowledge-retrieval scores, similarity-based pruning decisions, public-test execution results, LLM judgments, error reflections, and the selected final plan and code. The paper also constructs 2.4K reasoning-step samples for supervised fine-tuning, but no official reusable trace or dataset release is linked, so the described runtime object must be distinguished from a publicly available corpus.
