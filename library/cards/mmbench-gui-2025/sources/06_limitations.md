Correctness is level-specific. A good L1/L2 grounding score does not guarantee task completion, and a successful L3/L4 episode may depend on transient app state, network latency, account configuration, or evaluator assumptions.

The Hugging Face dataset page reports an Apache-2.0 dataset license, but runtime environments, third-party apps, screenshots, and web content can have separate terms. The public repository includes release and TODO-style artifact notes, so users should verify exactly which levels, scripts, and Docker/runtime pieces are available for the chosen revision.
