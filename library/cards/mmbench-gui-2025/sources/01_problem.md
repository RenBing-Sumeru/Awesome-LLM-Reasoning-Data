MMBench-GUI is a 2025 arXiv benchmark from the OpenCompass/OpenGVLab ecosystem for GUI agents. It asks how to evaluate agents across mobile, desktop, and web interfaces when tasks range from screen understanding to multi-step automation.

The evaluation surface is hierarchical: L1 visual/content understanding, L2 element grounding, L3 task automation, and L4 task collaboration over GUI states, instructions, actions, and success/efficiency scores. It belongs in the atlas as both an evaluation surface and an environment/trajectory substrate; it is not just a screenshot QA dataset.
