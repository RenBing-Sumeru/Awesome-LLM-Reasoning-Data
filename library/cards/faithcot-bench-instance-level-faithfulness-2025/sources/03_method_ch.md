1. **采样轨迹：**选择四个领域任务，让四类模型生成答案与完整 CoT，保留模型输出和任务证据。
2. **定义实例标签：**专家依据模型行为和可用证据判断整条 CoT 是否忠实，而非只检查文本正确性。
3. **标注原因与证据：**对不忠实案例记录触发原因、相关步骤及能够支持判断的局部证据，形成 FINE-CoT。
4. **统一比较检测器：**在相同样本上运行反事实干预、logit 分析和 LLM judge，报告检测能力及领域、模型难度变化；标注流程需要把“文本中存在错误”与“文本未反映模型真实计算”分开，否则事实错误会被误当成忠实性真值。
5. **可复现信息：**可复现信息：需固定四个任务域、四种生成模型、原始CoT提示、专家判定协议及各检测方法的模型访问权限；反事实调用次数和部分内部信号设置未披露时记为 unknown。
