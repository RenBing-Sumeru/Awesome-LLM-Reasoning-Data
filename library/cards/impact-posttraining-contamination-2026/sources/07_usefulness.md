An evaluation maintainer with a benchmark, clean starting checkpoints, and a trusted task-training split can reuse the paired-treatment design: inject a documented overlap, retain a clean continuation, apply the intended post-training recipe, and report leaked and counterpart scores. The output is an audit curve showing whether a gain is local leakage or transfer. Check matched compute, prompts, answer parsing, and confidence intervals. Do not use the design to estimate contamination in an opaque model without a clean counterfactual.
