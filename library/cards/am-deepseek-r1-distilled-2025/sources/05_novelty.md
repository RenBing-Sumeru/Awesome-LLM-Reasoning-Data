The closest baseline is the non-public 800K distillation set used by DeepSeek-R1-Distill. The paper changes the reusable object by making chat messages containing a user problem and a distilled long reasoning response explicit and coupling it to reference-answer matching for math, executable tests for code, and reward-model review for other domains. That is a direction signal because another team can train reasoning SFT and distillation from the released records. The inherited backbone, source tasks, autoregressive objective, and public benchmarks are not new.
