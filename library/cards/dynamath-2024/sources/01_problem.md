Primary sources: arXiv:2411.00836, first submitted 2024-10-29 and revised 2025-02-24, plus the official DynaMath project page and GitHub repository. The arXiv record states accepted by ICLR 2025. DynaMath asks whether VLMs can robustly apply the same mathematical reasoning under visual and textual variants of a problem, not merely solve one static benchmark instance.

The data object is a seed visual-math question represented as a Python program, which generates concrete variants with altered numbers, graphs, colors, symbols, geometry, or context. The evaluation surface is model answers over generated visual/textual questions, scored against generated ground-truth answers with average-case and worst-case accuracy. It belongs as a dynamic multimodal math robustness benchmark, not as a static VQA dataset or training corpus.
