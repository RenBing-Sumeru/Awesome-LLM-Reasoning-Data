The prior baseline is static visual-math benchmarks that evaluate one fixed problem instance at a time. DynaMath changes the evaluation object to a programmatic family of variants, allowing robustness checks under controlled visual and textual changes.

The direction signal is dynamic benchmark generation for multimodal mathematical reasoning, with worst-case accuracy exposing failures hidden by average scores. The quality signal is curated seed selection, program-based generation, topic/source statistics, Docker-based generation instructions, and integration into VLMEvalKit. What is not new: visual math QA, answer matching, and accuracy metrics. Reuse checks should inspect seed licensing, program fidelity to the intended math, parser tolerance, random seeds, generated image rendering, and public sample contamination.
