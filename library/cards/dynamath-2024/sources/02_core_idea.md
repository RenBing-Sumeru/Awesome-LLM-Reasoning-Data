DynaMath's contribution is a dynamic visual-math benchmark in which each seed problem is encoded as a Python generator that can instantiate many concrete variants. The core mechanism is program-based question generation: a seed's visual and textual parameters are sampled or changed, producing a new image/question/answer instance while preserving the intended reasoning template.

Compared with MathVista, MATH-V, MMMU-style visual-math evaluation, or static multimodal QA sets, DynaMath changes the object from fixed questions to reproducible variant families. The feedback contract is answer correctness against generated ground truth; robustness is measured by whether a model answers all sampled variants of a seed, not just its mean score. Direction label: dynamic multimodal math robustness benchmark.
