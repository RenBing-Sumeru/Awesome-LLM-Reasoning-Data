The correctness of a computer-use action depends on the current screen, task progress, and later interface changes. Final task completion cannot reveal the local quality of clicks, typing, or waiting, and general multimodal judges may read text descriptions while ignoring interface details.

CUARewardBench preserves screen states and action trajectories across ten software task categories and uses expert labels for single-action validity, progress, and overall trajectory quality to evaluate CUA reward models.
