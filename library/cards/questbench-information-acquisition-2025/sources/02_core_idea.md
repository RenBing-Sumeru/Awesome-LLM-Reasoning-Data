The core contribution is four one-question subsets: Logic-Q hides one proposition, Planning-Q hides part of the initial state, GSM-Q manually removes a key number, and GSME-Q first translates problems into equations before hiding a variable. Each record contains an underspecified problem, candidate clarification questions, hidden state, and correct option. A program checks whether asking a variable is sufficient to uniquely determine the answer and controls difficulty through variable count, ambiguity, and reasoning depth. The feedback contract is whether the question removes all remaining solution ambiguity.
