The principal data object consists of persona constraints, executable subtasks, subtask trajectories, composed long-horizon tasks, difficulty levels, and matching computer-use trajectories. AgentSynth creates more than 6,000 realistic tasks, with an average reported generation cost of about $0.60 per trajectory. A useful record preserves the input, current prefix or environment state, candidate behavior, execution or evidence, feedback label, and provenance instead of only a final outcome.
