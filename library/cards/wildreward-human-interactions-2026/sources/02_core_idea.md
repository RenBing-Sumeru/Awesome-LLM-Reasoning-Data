WildReward uses WildChat conversations to construct WildFB, about 186,000 high-quality interaction instances labeled with five ordered satisfaction levels derived from subsequent user behavior. Instead of converting every record into a pair, the model is trained through ordinal regression directly on the feedback level. The contribution is an implicit-feedback contract grounded in real user continuation behavior, plus a reward model and online-DPO demonstration showing how scalar ordinal signals can replace costly explicit comparisons.
