The arXiv abstract reports a 100-task benchmark built with about 500 person-hours and a study of 11 state-of-the-art LLMs. It reports that all studied LLMs perform much worse on class-level generation than on standalone method-level benchmarks, and that method-level ability does not equivalently reflect class-level ability. The README verifies the benchmark schema, 410 methods, average 33.1 tests per class, official generation strategies, Hugging Face support, and evaluation directory. Row-level evidence is an executed test result for a generated class or method, not a natural-language judgment.
