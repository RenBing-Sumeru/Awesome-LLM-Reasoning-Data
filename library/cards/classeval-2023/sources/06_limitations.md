Correctness is only as strong as the released tests; passing tests does not prove full behavioral equivalence to the reference class. Public tests and solutions can leak into training data. Results depend on generation strategy, sampling budget, Python and package versions, and execution timeout. The benchmark is Python-only and manually sized at 100 classes, so topic and library coverage are limited. Data is released under CC BY-NC 4.0 while the repository code is MIT, so data and code licenses must not be conflated.
