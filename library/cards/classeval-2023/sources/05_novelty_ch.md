先前基线通常是 function-level code generation，一个 prompt 和若干单测围绕一个独立入口。ClassEval 把对象换成面向对象的类，包含 constructor state、fields、method dependencies、imports 和不同生成策略的 prompt。方向信号是代码推理基准应同时暴露依赖元数据，并区分 class-level 与 method-level verdict。质量信号来自手工数据、明确 JSON schema、官方 evaluation code、leaderboard 和 Hugging Face release。它并不发明单测执行或 Pass@k。复用前要查测试覆盖、hidden/public policy、Python/runtime 依赖、data license、答案泄漏和 test exploitation 风险。
