The contribution is a manually crafted benchmark of 100 class-level Python tasks, 100 classes, 410 methods, and an average of 33.1 test cases per class. The core mechanism changes the unit of evaluation from a standalone function to a whole class with method, field, library, and standalone dependency types. The feedback contract is executable correctness under released tests and Pass@k reporting. Closest comparisons are HumanEval and MBPP, which provide simpler standalone prompts. The direction label is executable code benchmark with object-oriented dependency structure and environment/version risk.
