自然语言数学扩充与代码解释器训练过去通常沿两条独立路线发展。前者扩大题目覆盖，却继承模型的算术弱点；后者教授可执行解题，但常建立在相对狭窄的提示集合上。

MuMath-Code 把两者结合起来：从多个角度扩展 GSM8K 与 MATH，让教师生成前置推理、交错的 Python 代码和纠错过程，再让学生分两阶段训练。数据决策是完整的“题目—推理—代码—答案”轨迹是否通过已知答案或伪答案检查并进入 SFT。

L4 事实：主来源为 ACL Anthology 2024.emnlp-main.274 与 arXiv:2405.07551；正式发表于 EMNLP 2024；数据对象为 751K 条 MuMath 自然语言记录和 600K 条工具集成记录；评测表面包括 GSM8K、MATH、GSM-Hard、SVAMP、TabMWP、ASDiv 与 MAWPS；收录说明：已于 2026-07-14 实读两条公开 JSONL 记录。
