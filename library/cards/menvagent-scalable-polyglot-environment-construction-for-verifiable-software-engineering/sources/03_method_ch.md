1. **解析任务资产：** 读取仓库、基础提交、补丁和测试补丁，识别语言、包管理器、构建文件及候选测试入口。

2. **规划并执行环境：** Planning Agent 生成依赖安装和测试方案，Execution Agent 在 Docker 中逐条运行，保存命令、日志和退出状态。

3. **反馈修复：** Verification Agent 判断失败来自依赖、编译、配置还是测试，并把诊断反馈给规划器，迭代修改脚本直至测试可运行或达到预算上限。

4. **复用与发布：** 同仓库任务从历史成功镜像增量修补；最终以预验证测试确认环境，发布 setup/eval 脚本与任务元数据。固定基础镜像、工具链版本和网络策略是复现前提。
