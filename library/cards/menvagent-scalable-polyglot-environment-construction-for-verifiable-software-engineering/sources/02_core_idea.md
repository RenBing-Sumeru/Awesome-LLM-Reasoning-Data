The central contribution is to turn environment construction from one-shot script generation into a feedback-driven and reusable agent workflow. A Planning Agent proposes installation and test plans from repository configurations, an Execution Agent runs commands in isolated containers, and a Verification Agent diagnoses failures from build logs and test outcomes before requesting revisions. For new tasks in the same repository, the system preferentially updates a previously verified environment. The paper also releases 1,000 multilingual tasks in MEnvBench and approximately 3,005 executable environment records in MEnvData-SWE, covering repositories, base commits, problem statements, patches, test patches, setup scripts, evaluation scripts, and image identifiers.
