Repository-level software-engineering training requires container environments that install dependencies, reproduce historical commits, and execute tests. Existing automated builders often fail outside Python because of package versions, system libraries, build tools, or incorrect test commands. Manually repairing every environment is expensive and becomes a bottleneck for collecting verifiable tasks at scale. Without an executable environment, patch correctness must rely on weak labels or LLM judges.

MEnvAgent studies how agents can automatically diagnose and repair polyglot repository environments. Planning, execution, and verification agents iteratively construct Docker environments, while successful historical environments are reused and incrementally patched. The resulting MEnvData-SWE release contains reproducible software-engineering environments across ten languages, together with task patches, test scripts, and container metadata.
