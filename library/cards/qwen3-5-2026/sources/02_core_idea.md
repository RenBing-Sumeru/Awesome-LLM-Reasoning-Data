This Card treats Qwen3.5 as a partial frontier-disclosure ledger, not as an open agent-training recipe. The release connects four facts: a natively multimodal foundation, pre-training and post-training stages, RL scaled over million-agent environments with progressively complex task distributions, and an asynchronous framework intended to support large-scale agent scaffolds and environment orchestration. A Qwen-owned checkpoint makes the resulting post-trained model reusable for inference.

The training data object, however, is disclosed only at report level. No schema is given for task prompts, text-image-video records, observations, actions, tool calls, environment responses, reasoning traces, rewards, termination, or replay. No verifier or reward contract is named. Deployment support for text, image, video, Qwen-Agent, MCP tools, or Qwen Code describes how the released checkpoint can be used; it does not establish what training episodes or feedback produced it.
