For the Frontier Reports and Data Disclosure Ledger track, this Card provides a disciplined way to compare what Qwen3.5 releases with what its training claims would require for audit. It records three different artifact levels: an official report, an Apache-2.0 post-trained checkpoint/configuration release, and an official information repository with citation and deployment material. None is treated as a substitute for the missing agent-training records and feedback contract.

A reusable disclosure package would identify the pretraining source inventory and rights; publish RL task and environment IDs, versions, observation/action/tool schemas, reset and terminal rules; preserve prompts, multimodal inputs, trajectories, rewards, verifier outputs, rejected attempts, replay decisions, and seeds; and map every record through filtering, curriculum assignment, optimizer stage, checkpoint, and evaluation split. Environment containers and deterministic replay metadata would be needed to audit the million-environment claim.

Researchers can use the current sources to study open-weight deployment or to compare frontier disclosure practices. They cannot use them to reproduce agent RL, train a reward model, replay the reported environments, or infer a reliable RLVR contract. Benchmark performance should remain evidence about the released model under evaluation, not evidence that the hidden data or feedback is high quality.
