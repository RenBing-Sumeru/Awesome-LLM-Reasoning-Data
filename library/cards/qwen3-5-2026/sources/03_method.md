The official sources support four bounded layers of disclosure.

1. **Pretraining scope.** Qwen describes early-fusion multimodal training, broader linguistic coverage, and enrichment in Chinese/English, multilingual, STEM, and reasoning material under stricter filtering. It does not publish source inventories, item or token counts attributable to each source, mixture weights, acquisition and rights records, filter thresholds, retention yields, split policy, or decontamination results.
2. **Post-training and agent scope.** The release says RL is scaled over progressively complex task distributions and million-agent environments, including text, multimodal, and multi-turn settings. Environment names, task definitions, observation/action schemas, tools, reset conditions, terminal predicates, curriculum allocation, rollouts, and failure traces are not disclosed.
3. **Systems scaffold.** Qwen describes disaggregated asynchronous training and inference with dynamic load balancing, fault recovery, rollout-router replay, speculative decoding, and locking for multi-turn rollouts. These are infrastructure disclosures. The optimization algorithm, objective terms, reward or verifier, calibration, rollout counts, decoding, optimizer, coefficients, schedules, seeds, and reproducible training implementation remain unknown.
4. **Released artifacts.** `Qwen3.5-397B-A17B` is a post-trained causal language model with a vision encoder, reported as 397B total and 17B activated parameters with a native 262,144-token context. Qwen releases weights and configuration under Apache-2.0 and provides inference and agentic-usage examples. The official QwenLM information repository provides release links and documentation, not the RL training pipeline or training records.

Because no training-record schema is public, trace authorship, sampling, reward attribution, terminal success, and training/evaluation separation are all unknown. Inference recommendations such as temperature, top-p, context extension, tool parsers, or serving frameworks must not be copied into the missing training recipe.
