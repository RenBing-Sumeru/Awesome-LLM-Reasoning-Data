Frontier-model claims about reinforcement learning across multimodal, multi-turn, and agentic settings are useful only if readers can separate released facts from undisclosed training contracts. Qwen3.5 is an especially clear disclosure-boundary case: official sources describe native vision-language modeling, large-scale agent environments, progressively complex task distributions, and asynchronous RL infrastructure, while leaving the underlying post-training records and feedback rules closed.

The official Qwen3.5 release and Qwen-owned `Qwen3.5-397B-A17B` model card disclose high-level pretraining and RL scope and release a post-trained checkpoint. The later official `QwenLM/Qwen3.6` information repository explicitly covers Qwen3.5 and supplies release links, deployment guidance, and an official citation. None of these sources releases the training prompts or tasks, multimodal records, tool trajectories, environment packages, rewards, verifier specifications, accepted or rejected rollouts, or audit logs needed to reconstruct the reported agent-oriented RL.
