1. **Position:**  Distil repeated rubric critiques into persistent, updateable agent guidelines.
2. **Method:**  Feedback collection, rule abstraction, file-memory tools, and continual updating.
3. **Data:**  Rubric Feedback Bench has forty-two scenarios in five groups with prompts, rubrics, and feedback.
4. **Evidence:**  Quality approaches iterative refinement while later inference cost falls; no unified number is claimed.
5. **Reuse:**  Suitable for repetitive workflows; add approval, conflict handling, and rollback.
