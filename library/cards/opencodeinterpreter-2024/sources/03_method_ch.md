1. **建立高难查询池。** 从四个开放代码 instruction 数据集中汇总 287K 条查询，用两个 prompt 让 Qwen-72B-Chat 按 1-5 评分，只保留得分 4 或 5 的 156K 条查询。
2. **打包相关请求。** 用 BERT-base 编码查询，查找四个最近邻，再随机选择两到三个且不重复使用已选 neighbor，从 105K 条单轮样本构造约 16.6K 条多轮记录。
3. **模拟执行交互。** GPT-3.5 先写回答，流程抽取并执行代码，把输出或诊断交给 GPT-4；直到 GPT-4 判断答案正确或达到三轮上限。随后 GPT-4 从十类反馈中选择一类，再写一条类似用户的请求和修订。
4. **加入纠错专用数据。** 让 GPT-4 故意生成错误代码，执行后利用错误消息修正；再把诱导出错的 instruction 替换为普通的正确代码请求，得到约 500 条调试交互。
5. **构造 LeetCode 分支。** 使用经 TACO 清洗的 LeetCode tag 合并相似问题，并合并复杂度或语言不同的同题答案；让 GPT-4 补充文字解释，得到 303 条相似问题记录和 200 条 follow-up 记录。
6. **训练与评测。** 按 2:1 混合 WizardCoder 与 Code-Feedback，以 2e-5 学习率、4,096 cutoff 训练三轮，再使用 EvalPlus 和十条 MT-Bench 编程对话评测单轮及反馈辅助代码生成。
