1. **Build a difficult query pool.** Aggregate 287K queries from four open code-instruction datasets. Ask Qwen-72B-Chat to score complexity from 1-5 under two prompts and retain 156K queries scored 4 or 5.
2. **Pack related requests.** Embed queries with BERT-base, find four nearest neighbors, and randomly pack two or three without reusing a selected neighbor, producing about 16.6K multi-turn records from 105K single-turn instances.
3. **Simulate execution interaction.** Let GPT-3.5 write an initial response, extract and execute code, return output or diagnostics to GPT-4, and repeat until GPT-4 deems the answer correct or three iterations are reached. GPT-4 then chooses among ten feedback categories and writes a further user-like request and refinement.
4. **Add correction-focused data.** Ask GPT-4 to intentionally write faulty code, execute it, and use the resulting error message for correction; replace the adversarial instruction with a normal correct-code request, yielding about 500 debugging interactions.
5. **Construct LeetCode branches.** Use TACO-cleaned LeetCode tags to group similar problems and group solutions that differ in complexity or language; ask GPT-4 to add integrated explanations, creating 303 similar-problem and 200 follow-up records.
6. **Train and evaluate.** Mix WizardCoder and Code-Feedback 2:1, fine-tune for three epochs at learning rate 2e-5 and cutoff 4,096, then evaluate single-turn and feedback-assisted code generation with EvalPlus plus ten MT-Bench coding conversations.
