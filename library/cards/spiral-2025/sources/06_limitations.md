The authors identify four main boundaries: dependence shifts from curated problems to designed games; each run requires substantial compute; evaluation is concentrated on academic benchmarks and zero-shot transfer; and reward hacking remains possible. They report about 25 hours for Qwen3-4B and 28 hours for Qwen3-8B on 8 H100 GPUs and note diminishing returns with longer training. Three small zero-sum games do not establish scalability to open-ended, cooperative, robotics, or very sparse-reward environments. (Appendix B and D.2.)

The environment verifies successful play, not the intermediate explanation. A model can produce a valid action with false or post-hoc reasoning, and the RAE ablation only shows that nonempty output correlates with retained performance. GPT-4.1 pattern classification is not process supervision. Curator inference: any downstream use that treats these traces as faithful demonstrations risks learning game-specific rhetoric or hidden teacher-like policy traits rather than causal reasoning.

The parser and reward implementation enlarge the attack surface. Invalid actions terminate with a special -1.5/0.5 assignment, max-turn truncation gives 0/0, and zero-advantage trajectories may be dropped. Curator inference: a policy can optimize formatting, termination, or environment quirks without learning the intended skill; those branches also complicate the paper's clean zero-sum interpretation. Fixed-opponent exploitation is empirically visible, while self-play exploitation of shared parser or environment artifacts is not stress-tested.

Release completeness limits audit and reproduction. There is no tagged per-experiment bundle containing exact TextArena/Oat/vLLM revisions, prompts, seeds, all valid and invalid turns, rewards, baselines, advantages, optimizer states, and checkpoints. The paper states that no benchmark-related data are used, but no item-level decontamination report is provided. The root repository is MIT licensed while key files carry Apache-2.0 headers, and the static dataset/model licenses and upstream obligations remain unresolved. These gaps block treating the online stream as a ready-to-reuse dataset.
