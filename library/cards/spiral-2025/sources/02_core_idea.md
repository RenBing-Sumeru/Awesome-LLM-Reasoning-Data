SPIRAL's contribution is an online data-and-optimization loop in which one full-parameter LLM plays both roles in turn-based zero-sum language games, so every policy update changes both the data generator and the next opponent. Role-specific top-level instructions distinguish the players; TextArena parses each complete multi-token response into an executable action and advances the state. (Paper §3, Figure 3, Algorithm 1.)

Role-conditioned Advantage Estimation (RAE) maintains a separate EMA return baseline `b[G,p]` for every game `G` and role `p`, then uses `A[G,p] = R[p] - b[G,p]` for the role's full responses. This centers feedback for asymmetries such as first-move or information advantage. RAE does not score individual reasoning sentences. The feedback contract observes valid actions, state transitions, termination, and role outcomes; it does not observe whether the stated chain-of-thought is true, necessary, or causally responsible for the action. (Paper Eq. 2–3.)

The direction is environment-generated online reasoning data with a co-evolving curriculum. The paper contrasts SPIRAL with SPAG's offline single-game updates, fixed-opponent training, single-agent multi-turn systems such as RAGEN, and single-turn self-generated tasks such as Absolute Zero. What changes is the combination of shared-policy two-role self-play, full online updates, multiple multi-turn games, and measured transfer outside the games—not the invention of self-play, REINFORCE, language games, or rule-based terminal rewards. (Paper §2.)
