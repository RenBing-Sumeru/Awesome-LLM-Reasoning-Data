Existing CoT-PRMs rely on many expensive human- or teacher-annotated explanations, whereas ordinary PRMs learn only scores. VRPRM separates the roles of the data: a small expensive set teaches how to analyze, while a larger cheap set calibrates how to score. The novelty is the data recipe and training order rather than visual encoding or the reinforcement-learning algorithm itself.

This assigns different training roles to expensive explanatory data and cheaper step labels.
