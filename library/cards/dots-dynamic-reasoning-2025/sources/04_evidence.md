The paper gives a concrete construction account rather than only reporting aggregate accuracy. Appendix A fixes the reported search at \(K=2\), \(N_{\text{eval}}=4\), \(N_1=8\), \(N_2=3\), and \(T=0.4\). Those settings imply 80 candidate-trajectory executions for a fully searched question before explanation generation and variable Self-Verification retries. The same appendix reports 1,722, 1,624, and 2,140 selected planner examples for the three solvers, or 5,486 total.

The experimental evidence supports solver- and difficulty-conditioned routing, but within the studied models and benchmarks. Table 7 reports different CoT/PoT choices for GPT-4o-mini and Llama-3-70B-Instruct. Figure 3 associates harder MATH levels with longer average trajectories. Table 9 reports 409.1 average output tokens for internalized DOTS, compared with 263.6 for CoT, 436.4 for LTM, and 527.6 for Self-Refine. These observations show that the learned planner changes compute allocation; they do not establish that the selected traces are intrinsically higher-quality or portable to an unseen solver.

Artifact inspection strengthens the data claim. At Hugging Face revision `d6de3b157227150740d38c38e92ffd1803c3d42a`, the dataset repository contains one 4,800,046,236-byte LFS JSON file plus a minimal license-only card. Range inspection of the first 65,536 bytes found the documented `meta info` and `trial result` structure, full role/content dialogues, action trajectories, predicted answers, and both `score: 1` and `score: 0` trials. This verifies that the public artifact contains raw successful and failed rollout evidence, not merely final accepted answers.

The evidence is incomplete at release level. The HF viewer cannot extract features, and neither the card nor a manifest states the exact record count, stable splits, solver partition, checksums, or schema version. The repository README points to a Google Drive location for searched results and final SFT data, but that endpoint returned HTTP 404 when checked on 2026-07-25. The 5,486 paper counts therefore cannot be treated as the row count of the 4.8 GB raw file, and the raw file cannot be treated as a verified final-SFT release.

The results are author-reported; no independent reproduction is recorded in the accepted evidence. Moreover, code and paper settings differ, so benchmark tables cannot validate the checked repository as a parameter-exact implementation. For this Card, the strongest evidence is the paper-defined search contract plus the observed raw-trial schema. Performance claims remain evidence about the reported system, not proof of release completeness, licensing clarity, decontamination, or training-data quality.
