Prior mobile agents often depend on accessibility APIs, app back-end access, scripted environments, or one-off GUI grounding. AppAgent changes the surface by treating the agent as a smartphone user and separating knowledge acquisition from task execution. The direction signal is GUI-only mobile autonomy with reusable app-operation memory. What is not new: multimodal perception, LLM planning, and UI action execution were already active areas. Reuse checks must inspect app permissions, privacy/account state, evaluator criteria, task drift, prompt budget, and whether demonstration traces are redistributable.
