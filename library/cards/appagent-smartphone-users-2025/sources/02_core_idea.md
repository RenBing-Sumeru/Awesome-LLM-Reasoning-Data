AppAgent contributes a multimodal smartphone agent framework that first learns app-specific operation knowledge and then uses it during task execution. The core mechanism is a simplified action space that mimics tapping, swiping, and typing, combined with autonomous exploration or human demonstrations to build an app knowledge base. The closest comparisons are GUI grounding agents, mobile automation systems, and API-based app agents. The feedback contract is environmental: success is judged by whether the visible app state satisfies the requested task, not by a static text answer.
