Algorithm 1 samples (N) candidates independently from πref, queries ŕ for every candidate, and returns the highest-scoring one. Algorithm 2 samples candidates, solves an empirical normalization equation for λ in (O(N\log N)), then accepts a candidate through rejection sampling using the nonnegative χ² weight; if sampling does not terminate within the experimental cap, the implementation defaults to BoN. The empirical study uses GSM8K test prompts, MMLU college-math and college-chemistry prompts, 512 sampled MATH test questions, and 128 sampled AlpacaEval-2.0 prompts. Task-dependent subsets of GEMMA-2-2B, LLAMA-3-3B, Mistral-7B, Phi-3-Mini, and Phi-3-Small generate about 20,000 responses per prompt at temperature 1. OASST, GEMMA-RM, LLAMA-RM, and ARMO-RM provide proxy scores. The authors bootstrap subsets of size (N) from each pool, using 50 replicates except 5 for AlpacaEval-2.0; fixed-budget comparisons use (N=2^{13}=8192), and the same (N) samples estimate the normalizer and support rejection sampling. Correctness is binary for the three answer-based benchmarks, while AlpacaEval-2.0 uses GPT-4o-mini win rate. No policy is trained by the method, and no official code or candidate-trace release was verified.
