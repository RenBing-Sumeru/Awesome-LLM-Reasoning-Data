Algorithm 1 从 πref 独立采样 (N) 个候选，查询每个候选的 ŕ，并返回得分最高者。Algorithm 2 先采样候选，以 (O(N\log N)) 时间求解 λ 的经验归一化方程，再按非负 χ² 权重进行 rejection sampling；若在实验设置的上限内未能接受样本，实现会退回 BoN。实验使用 GSM8K test prompt、MMLU 的 college math 与 college chemistry prompt、从 MATH test split 随机抽取的 512 道题，以及从 AlpacaEval-2.0 抽取的 128 个 prompt。GEMMA-2-2B、LLAMA-3-3B、Mistral-7B、Phi-3-Mini 与 Phi-3-Small 按任务选取子集，并以 temperature 1 为每个 prompt 生成约 20,000 个回答；OASST、GEMMA-RM、LLAMA-RM 与 ARMO-RM 提供 proxy score。作者从候选池 bootstrap 大小为 (N) 的子集；除 AlpacaEval-2.0 仅做 5 次 replicate 外，其余任务做 50 次；固定预算对比采用 (N=2^{13}=8192)，且同一组 (N) 个样本同时用于 normalizer estimation 与 rejection sampling。三个答案型 benchmark 使用二元正确性，AlpacaEval-2.0 使用 GPT-4o-mini win rate。该方法不训练 policy，且未核验到官方代码或候选轨迹发布。
