研究只覆盖数学和代码任务中的一次纠错，并使用二元结果奖励。向需要人工判断的开放任务、更长纠错链、交互环境或非二元过程反馈迁移的效果仍为 unknown。即使中间推理有缺陷，回答也可能获得终局奖励；答案抽取器或不完整单元测试还可能拒绝有效输出或接受错误输出。

MATH 协议把原 test set 中的 4,500 道题移入训练，只在剩余 MATH500 上评估。比较时必须保留这一论文特定划分，不能把分数解读为在未经改动的原始 test set 上的表现。Checkpoint 按训练奖励选择，因此奖励实现细节也是评估 lineage 的一部分。

未确认发布官方可复用代码库、原始在线轨迹语料、训练 checkpoint、精确 split manifest、随机种子列表、运行日志、artifact license 或 decontamination report。论文给出 prompt 和主要超参数，但表中没有披露每题 rollout 数。因此可以按论文实现目标函数，但精确回放和独立的轨迹级审计仍然受阻。
