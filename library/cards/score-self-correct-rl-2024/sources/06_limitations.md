The study is limited to one correction step on math and code with binary outcome rewards. Transfer to open-ended tasks requiring human judgment, longer correction chains, interactive environments, or non-binary process feedback is unknown. An answer can receive terminal credit despite flawed reasoning, while an answer extractor or incomplete unit-test suite can reject valid outputs or accept wrong ones.

The MATH protocol moves 4,500 original test problems into training and evaluates on the remaining MATH500. Comparisons must preserve that paper-specific split and must not read the score as performance on the untouched original test set. Checkpoint selection uses training reward, so reward implementation details are part of the evaluation lineage.

No official reusable code repository, raw online trajectory corpus, trained checkpoint, exact split manifest, seed list, run log, artifact license, or decontamination report was confirmed. The paper provides prompts and major hyperparameters but does not disclose per-prompt rollout count in the table. Therefore reproduction can implement the stated objective, but exact replay and independent trace-level audit remain blocked.
