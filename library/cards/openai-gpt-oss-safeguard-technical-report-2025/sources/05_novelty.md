For this atlas, the main contribution is disclosure value rather than a fully specified training recipe. The official record pairs an open-weight release and a clear policy-and-content classification interface with a technical report that distinguishes intended policy-classification use from end-user chat evaluations.

It also illustrates a useful audit distinction: human-expert judgment is named in the high-level Safety Reasoner lineage, and LLM grading is named for one evaluation, but neither statement supplies a released reward model or verifier. This prevents the common but unsupported inference that an open safety model constitutes an open safety-data or calibrated-verifier release.
