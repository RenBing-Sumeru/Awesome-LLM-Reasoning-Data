MineDojo: Building Open-Ended Embodied Agents with Internet-Scale Knowledge defines an evaluation surface in embodied-agents, minecraft, open-ended-environments: whether model outputs or agent trajectories satisfy the task-specific feedback contract. The primary source and artifacts are paper: https://arxiv.org/abs/2206.08853; openreview: https://openreview.net/forum?id=rc8o_j8I8PX; project: https://minedojo.org/; code: https://github.com/MineDojo/MineDojo; data: https://minedojo.org/knowledge_base; the local metadata records the source as 2022 / NeurIPS 2022 Datasets and Benchmarks Track / arXiv.

The decision boundary is environment_agent_trajectory_data with roles benchmark, agent_environment and verification contract environmental, programmatic. One benchmark instance is: Minecraft tasks, simulator interfaces, knowledge base resources, videos/wiki data, MineCLIP signals, and agent results. This is not a model-training recipe unless the paper separately releases training data; the card treats it as evaluation, audit. It matters for the atlas because the reusable object is an evaluation/data record with a named scorer, judge, verifier, reward, or environment predicate rather than an abstract capability claim.
