ABC-Bench publicly releases 224 practical backend tasks spanning eight programming languages and 19 frameworks. Its dataset page provides JSON records with `task_id`, language and framework tags, categories, and detailed instructions, together with approximately 2.64GB of task archives. Tasks require completing APIs, data access, or business workflows and producing a buildable Dockerfile at the repository root.

The core verifier sends requests from outside the agent container and checks whether the service builds, runs, and returns specified HTTP statuses, payloads, and state changes. Tests are hidden from the agent and score behavior across implementations, reducing direct overfitting to visible assertions. The resource primarily evaluates backend agents and can also collect deployment–test–repair trajectories.
