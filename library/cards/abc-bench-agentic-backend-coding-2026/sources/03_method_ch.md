1. **选择后端仓库：** 从开放项目筛选具有可运行服务骨架、明确路由/业务模块和可容器化依赖的代码库，并覆盖多种语言与 web frameworks。

2. **构造工程任务：** 定位被移除或待补全的 endpoint、数据层或流程逻辑，编写自然语言 instruction，要求 agent 同时恢复实现和 Docker 环境；保存完整任务 archive。

3. **建立外部测试：** 为接口设计端到端 HTTP cases，包括正常输入、边界条件、持久化状态和错误响应。测试从容器外运行，不向 agent 暴露源码。

4. **执行评测：** agent 探索仓库并修改代码，随后构建镜像、启动服务并接受 API tests。只有部署成功且所有规定行为通过才算解决；需固定端口、镜像、依赖网络和 agent 时间预算。
