The benchmark covers 224 tasks, eight languages, and 19 frameworks, substantially broader than a single Python/pytest setting. Public archives, instructions, and external tests make the full deployment chain reproducible. Multiple advanced models and agents are evaluated under a common framework, and even state-of-the-art systems struggle to complete these holistic tasks reliably, showing that the benchmark is unsaturated.

This evidence supports the claim that service deployment and external API verification add realistic difficulty. However, the abstract does not provide one best percentage that can be interpreted independently of agent configuration. Docker generation, dependency downloads, and startup-wait policies also affect failures, which cannot all be attributed to business-logic errors.
