ChartMimic is an arXiv 2024 benchmark paper, revised in 2025 and accepted to ICLR 2025, for evaluating large multimodal models on chart-to-code generation. The gap is that many chart benchmarks ask for QA or description, while visually grounded code generation requires the model to recover chart structure, data encodings, visual style, and executable plotting logic from a figure plus instruction.

The data object is a human-curated triplet: chart figure, textual instruction, and reference code, drawn from scientific-paper chart use cases. The evaluation surface is generated plotting code plus its rendered chart. The decision boundary is multimodal reasoning and executable reconstruction; it is not chart QA, not free-form image captioning, and not a pure code-generation benchmark. Its atlas value is the mixed feedback contract: code execution plus multi-level chart-rendering similarity.
