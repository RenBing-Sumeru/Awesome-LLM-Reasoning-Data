The current arXiv version reports 4,800 human-curated triplets and evaluation of 3 proprietary plus 14 open-weight models. It reports that even strong models remain far from perfect: GPT-4o reaches an average score of 82.2 across Direct Mimic and Customized Mimic tasks, while InternVL2-Llama3-76B reaches 61.6 in the same reported setting.

Instance-level evidence is executable: the generated code either runs or fails, and the rendered output is scored against the chart target. Aggregate scores are credible only with the exact renderer, metric implementation, and task split. The evidence boundary is that visual similarity metrics may miss semantic mismatches in data values, labels, axis scales, legends, and chart-specific conventions; executable code can still generate a misleading chart.
