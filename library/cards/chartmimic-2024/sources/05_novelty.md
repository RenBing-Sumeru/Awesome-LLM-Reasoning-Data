The prior baseline is chart understanding by QA, captioning, table extraction, or synthetic chart-to-text tasks, plus code-generation benchmarks that lack visual chart grounding. ChartMimic changes the target artifact to executable plotting code and makes the rendered chart part of the evaluation evidence.

The direction signal is that multimodal reasoning benchmarks can use executable reconstruction to expose whether models understand visual encodings, not just answer a question about them. The quality signal is the ICLR 2025 acceptance, official project, GitHub code, Hugging Face dataset, scale, chart-type taxonomy, and multi-level metrics. What is not new: chart perception, plotting code generation, and automatic image metrics. Before reuse, inspect license, source chart provenance, code sandbox safety, metric sensitivity, split contamination, rendering determinism, and whether reference code is exposed to models.
