Use ChartMimic as a recipe for executable multimodal evaluation. Preserve sample id, source chart image, instruction, chart type/subcategory, reference code provenance, split, model prompt, generated code, execution log, rendered image, metric components, timeout/error status, and evaluation environment.

For atlas work, it is useful as a benchmark/evaluation-surface card where the data object is not only an answer but an executable artifact. It can guide audit schemas for code-producing multimodal agents by forcing code, render, metric, and provenance fields to stay linked.
