The primary sources are arXiv v2, revised 29 October 2025; the NeurIPS 2025 Datasets and Benchmarks Track Spotlight record; and the official repository inspected at commit `c0fa95e75bafb00ac05d2eb4ac5418b9913475ee`. OS-Harm addresses a gap between measuring whether a computer-use agent completes a desktop task and measuring whether its state-action trajectory causes or attempts harm. The benchmark covers general Ubuntu desktop workflows rather than only simulated tool calls or browser navigation, but it does not study safety training, defenses, adaptive attacks, or natural-world harm prevalence.

The paper reports 150 tasks, 50 in each of three author-defined categories: deliberate user misuse, prompt injection attacks, and model misbehavior. A benchmark instance includes a task ID, Ubuntu snapshot, natural-language instruction, source and VM setup configuration, related applications, optional injection vector and goal, and an OSWorld evaluator record. Running it produces multimodal observations, model reasoning and pyautogui actions, environment logs, screenshots/video, and post-hoc safety and task-completion judgments.

This is an `environment_agent_trajectory_data` object because the auditable unit is a resettable VM episode with state, observation, action, and termination metadata. It is also a `benchmarks_evaluation_surfaces` object because the main labels come from a structured semantic judge rather than a training target. The Card reaches bilingual L4 content depth through verified task, episode, judge, human-label, and release evidence; it remains `partial` and at the accepted metadata level because the Drive license, immutable manifest, retention policy, and prompt-injection count reconciliation are unresolved.
