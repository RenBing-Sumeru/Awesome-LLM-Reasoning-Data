The official source is the 5 June 2025 arXiv v1 preprint, accompanied by the authors' public implementation. LLM-augmented BFS, BestFS, and MCTS impose fixed traversal rules or exploration settings that can behave differently as task difficulty and model capability change. LLM-First Search (LFS) instead asks the runtime LLM to decide whether to stay on the current path or return to an alternative and to value candidate actions. For this atlas, the important object is a search trace containing states, valid actions, model-authored values and exploration decisions, frontier contents, backtracks, token use, and terminal outcomes. This is a direct fit for `rollout_search_test_time_trace_data`; the repository provides code capable of recording such objects but does not include the paper's result traces.
