For `rollout_search_test_time_trace_data`, LFS defines a reusable logging schema: task and instance provenance; model/API revision; system and user prompts; every structured response and retry; state, legal actions, and deterministic transition; scalar child values; explore decision; current path and frontier snapshot; selected or rejected node; token and time cost; backtrack count; stopping reason; and terminal environment reward. These fields support replay, selector calibration, frontier-policy comparison, and compute accounting. The evidence supports test-time compute and evaluation, not SFT, RLVR, or reward-model training. Terminal success and benchmark win rate should stay separate from model-authored intermediate values instead of turning final outcomes into assumed labels for every earlier decision.
