对于 `rollout_search_test_time_trace_data`，LFS 定义了一套可复用日志 schema：任务与实例来源、模型/API revision、system 与 user prompt、每次结构化回复和重试、状态、合法动作与确定性转移、子节点标量价值、explore decision、当前路径与 frontier snapshot、被选或被拒节点、token 与时间成本、回溯次数、停止原因和终局环境 reward。这些字段可支持重放、选择器校准、frontier policy 比较和计算量核算。现有证据只支持 test-time compute 与 evaluation，不支持扩大为 SFT、RLVR 或 reward-model training。终局成功和 benchmark win rate 应与模型生成的中间价值分开保存，不能把最终结果默认当作此前每个决策的标签。
