The paper instantiates LFS on Countdown and Sudoku as deterministic MDPs. Countdown states contain the target, remaining numbers, operation history, and valid arithmetic actions; Sudoku states contain a partial board and valid cell-value assignments. Experiments use GPT-4o and o3-mini through the OpenAI API, run each game five times at temperature 0.0, set per-call `max_tokens` to 16,384 and timeout to 300 seconds, and report o3-mini with low reasoning effort. README reproduction commands use total-token limits of 1,000,000 for Countdown, 100,000 for 4x4 Sudoku, and 500,000 for 6x6 Sudoku. The implementation serializes pickles with the final node, full `Explorer` tree, outcome, token records, elapsed time, backtrack count, and per-step metrics; Sudoku adds solution and board-accuracy fields. These are output capabilities, not a released set of observed paper traces.
