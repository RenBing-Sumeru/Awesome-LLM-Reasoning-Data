LFS maintains the current state-action path and a priority queue of unchosen alternatives. At each nonterminal step, an exploration prompt returns whether the model wants to leave the current path. If it explores, the highest-valued stored frontier node becomes current; otherwise, task-specific evaluation prompts assign scalar values to available children, the highest-valued child is followed, and other children remain available for later backtracking. The feedback contract is mixed: the LLM is both controller and value judge, while deterministic Countdown or Sudoku code enumerates legal actions, applies transitions, and checks terminal success for a binary task reward. Model scores guide selection but are not independently verified correctness labels.
