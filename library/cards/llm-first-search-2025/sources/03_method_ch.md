论文把 Countdown 和 Sudoku 实例化为确定性 MDP。Countdown 状态包含目标值、剩余数字、运算历史和合法算术动作；Sudoku 状态包含部分棋盘和合法的“单元格—数值”赋值。实验通过 OpenAI API 使用 GPT-4o 与 o3-mini，每个游戏在 temperature 0.0 下运行五次，单次调用的 `max_tokens` 为 16,384，timeout 为 300 秒，并称 o3-mini 使用 low reasoning effort。README 的复现命令将总 token 上限设为 Countdown 1,000,000、4x4 Sudoku 100,000、6x6 Sudoku 500,000。实现会把 final node、完整 `Explorer` tree、结果、token 记录、运行时间、回溯次数和逐步 metrics 序列化为 pickle；Sudoku 还包含解答和棋盘准确率字段。这些是代码具备的输出能力，不等于已发布的论文实测轨迹集。
