Use APEX-Agents as a schema reference for professional-work agent evaluation. Preserve world id, job category, prompt, file inventory, tools, expected output type, gold output, rubric criteria, judge model, criterion labels, artifacts changed, action budget, and access/license terms. For atlas work it is especially useful for marking the difference between executable workplace environments, rubric-graded deliverables, and datasets that are publicly visible but explicitly not usable for training.
