APEX-Agents is a 2026 arXiv benchmark from Mercor for long-horizon, cross-application professional work by agents. The problem is that many agent benchmarks test short web or desktop interactions, while banking, consulting, and legal work require coordinated use of files, spreadsheets, documents, email, chat, calendar, PDFs, and domain-specific deliverables. The Card includes it as a professional-work agent evaluation surface, not as a training set. A task object contains a single-turn prompt, world context, files and tools, gold output, metadata, and binary rubric criteria graded against the agent output and artifacts.
