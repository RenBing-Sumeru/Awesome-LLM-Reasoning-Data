The contribution is a benchmark of 480 expert-created professional-service tasks plus the Archipelago execution and evaluation infrastructure. The mechanism is to package tasks into 33 realistic worlds, provide world assets and tool access, execute an agent in that environment, then grade criterion-level rubric statements using the prompt, output, and relevant artifacts or changes. Compared with OSWorld, WorkArena, office-automation benchmarks, and generic tool-use tests, APEX-Agents emphasizes high-value professional deliverables and rubric-graded cross-application workflows.
