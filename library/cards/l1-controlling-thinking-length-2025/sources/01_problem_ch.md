推理模型往往会在困难问题上使用更多 token，但普通长 CoT 模型无法让调用方指定这一预算。输出可能延伸到数万 token，也可能在难题尚未解决时提前结束。测试时的 budget forcing 可能在步骤中间截断解答，或插入续写 token，却没有教会策略重新组织推理。

L1 研究能否把 token 预算变成由强化学习掌握的显式条件变量。LCPO 的训练对象从数学问题和最终答案出发，追加精确长度或最大长度请求，再获得策略在线生成的推理响应。它不需要 gold 中间 rationale；程序化的最终答案正确性与实际 token 数共同提供反馈。

对本图谱而言，关键对象是预算条件化 rollout 及其奖励记录，而不只是发布的模型。可复用记录应连接源条目、请求预算、完整生成响应、抽取答案、实际长度、正确性信号和长度遵守信号。官方发布了代码和模型，但未核验到完整、与论文匹配的训练 rollout 语料。
