Length Controlled Policy Optimization（LCPO）在每条源提示后追加 token 请求，并通过 GRPO 优化策略在线生成的响应。L1-Exact 把二值最终答案正确性与“请求长度和实际长度之差”的惩罚结合起来；论文将精确模式的权衡系数固定为 0.0003，使策略在解题的同时逼近指定 token 数。

L1-Max 从 L1-Exact 继续训练，采用软最大长度目标。正确响应可以在上限内提前结束，超出预算时逐步受罚，而不是被硬截断；模型根据提示同时保留精确模式与最大模式。因此，决定如何压缩或展开推理的是策略本身，而不是外部截断器。

该反馈契约是程序化但范围有限的：`\boxed{}` 答案抽取以及 mathd/SymPy 等价检查判断终局答案，token 计数判断预算遵守。两者都不能证明中间推理链在语义上有效或忠实。
