对 Track 5 而言，L1 是把测试时算力变成可训练轨迹条件、而非事后截断规则的具体案例。图谱记录应把三类对象分开：源问题—答案对、在请求预算下由策略在线生成的推理 rollout，以及正确性/长度奖励记录。

官方脚本和 checkpoint 可支持配方级复现、多个 token 预算下的受控生成、奖励消融以及精确目标与上限语义的比较。由该配方构建的可复用数据集应保存来源版本和条目 ID、提示模板、Exact/Max 模式、请求与实际 token 数、完整响应、抽取答案、检查器结果、各奖励分量、终止原因、GRPO group、随机种子和模型/checkpoint 版本。

审计者可利用这些字段检查填充、重复、验证器错误、按难度分配预算以及训练—评测重叠。在论文对应的 rollout 和奖励记录被发布，或基于固定 commit 重建之前，该工作最适合作为 RLVR/测试时算力配方与模型发布复用，而不是现成的轨迹数据集。
