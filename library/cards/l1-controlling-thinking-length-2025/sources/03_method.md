The training source is DeepScaleR-Preview-Dataset, described as 40K mathematical question-answer pairs drawn from AIME, AMC, Omni-Math, and STILL. The public preprocessing script loads the DeepScaleR training split, adds an instruction to return a boxed answer, samples an exact or maximum token request, and serializes the prompt with its ground-truth answer and requested length. Its default exact-target code samples integer lengths from 100 to 4,000; the paper evaluates 512, 1,024, 2,048, and 3,600-token requests.

The main base is DeepScaleR-1.5B-Preview, itself RL-fine-tuned from DeepSeek-R1-Distill-Qwen-1.5B. LCPO-Exact runs in VeRL for 700 GRPO steps with learning rate 1e-6, batch size 128, and a 4K training context. L1-Max then receives 120 additional RL steps. Evaluation extends the context to 8K; the paper also reports an appendix extension to a 7B model.

The released reward implementation extracts a boxed answer after the reasoning delimiter and applies mathd or SymPy equivalence checks. It separately scores the realized token count, then combines correctness and length according to Exact or Max mode. The official repository includes preprocessing, training, evaluation, replication scripts, model outputs, and an MIT license; the official Hugging Face collection exposes multiple Exact/Max model checkpoints. A paper-complete dataset of all requested budgets, on-policy rollouts, component rewards, failures, and seeds was not verified.
