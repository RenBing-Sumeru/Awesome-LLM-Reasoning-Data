- 区分 L1-Exact 与 L1-Max：前者奖励接近指定 token 数，后者使用软上限并允许提前结束。
- 区分 40K DeepScaleR 源问题—答案池与 LCPO 在线 rollout；LCPO 不需要 gold 中间轨迹。
- 把 boxed 答案等价检查与 token 计数视为两个程序化反馈字段；二者都不验证中间推理。
- 应把数学任务约 3% 的长度偏差与域外任务 20–40% 的偏差并读；预算控制不会均匀迁移。
- 官方发布包含代码、模型、预处理、复现实验脚本和部分 model outputs，但没有核验到完整 GRPO rollout/奖励台账。
- Benchmark 提升衡量的是耦合后的训练系统，不能作为 rollout 数据质量或无污染的证明。
