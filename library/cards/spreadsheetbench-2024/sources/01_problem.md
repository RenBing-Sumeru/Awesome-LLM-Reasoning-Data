SpreadsheetBench asks whether current language-model agents can solve real spreadsheet manipulation requests, not just answer questions about tables. The primary sources are the arXiv paper https://arxiv.org/abs/2406.14991, first posted in 2024-06, the official project page, the NeurIPS 2024 Datasets and Benchmarks spotlight page, the GitHub repository, and the Hugging Face dataset release.

The decision boundary is a benchmark and office-agent evaluation surface: each instance is a natural-language spreadsheet instruction paired with input Excel workbooks, expected answer workbooks, answer positions, and an evaluator that checks the resulting file state. It is not a table-QA benchmark, a generic spreadsheet corpus, or a training recipe. It matters for this atlas because spreadsheet work is a concrete file-state environment where reasoning, code generation, execution feedback, and programmatic scoring meet.
