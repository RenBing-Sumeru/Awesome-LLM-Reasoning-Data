The contribution is to turn real Excel forum problems into a reproducible benchmark for spreadsheet-manipulating agents. Instead of asking models to describe a table, SpreadsheetBench asks them to generate executable solutions that transform input spreadsheets into gold spreadsheet states.

The benchmark contains 912 instructions and 2,729 test cases, with cell-level and sheet-level manipulation tasks covering operations such as finding, extracting, summing, highlighting, modifying, deleting, calculating, and displaying spreadsheet content. The feedback contract is the official evaluator: the same generated solution is run on multiple test spreadsheets for an instruction, then the output workbook is compared with the answer workbook at the specified answer positions. The closest comparisons are table QA benchmarks, Office/desktop agent benchmarks, and code-generation benchmarks, but SpreadsheetBench's direction label is file-state spreadsheet manipulation with programmatic outcome checking.
