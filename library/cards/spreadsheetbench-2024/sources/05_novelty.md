The prior baseline is mostly table QA, synthetic spreadsheet tasks, or office-agent tasks that do not require exact workbook-state transformation across multiple spreadsheet variants. SpreadsheetBench changes the object: the model must manipulate real `.xlsx` files and satisfy an executable file comparison, not merely produce a textual answer.

The quality signal is the combination of real forum-derived tasks, multiple test cases per instruction, answer-position metadata, official evaluator code, and NeurIPS 2024 Datasets and Benchmarks spotlight acceptance. What is not new is spreadsheet use itself, code execution, or exact-match evaluation; the novelty is binding them into a realistic spreadsheet manipulation surface. Before reuse, inspect redistribution rights for forum-derived examples, the CC BY-SA 4.0 license, split policy, evaluator version, formula recalculation workflow, and whether public tasks have leaked into model training.
