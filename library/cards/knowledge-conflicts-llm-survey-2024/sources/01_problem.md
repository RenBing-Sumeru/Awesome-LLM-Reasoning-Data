LLMs may face a prompt that disagrees with what they learned or contains mutually inconsistent statements. This EMNLP 2024 survey defines the problem through context-memory, inter-context, and intra-memory conflicts, and explains why noisy information can harm reliability.

Disagreement is not automatically a model error. A task must state which source should govern the response and whether uncertainty should be exposed. Without that rule, conflicting evidence, outdated information, and an unclear instruction about authority can be mistaken for the same factuality failure.
