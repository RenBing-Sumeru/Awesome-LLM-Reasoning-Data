核心思路是把答案验证变成可训练、可评测的组件，而不是每个数据集单独维护正则或提示。第一阶段由 Qwen2.5-Instruct 裁判和 Math-Verify 移除简单共识案例；随后 DeepSeek-V3 用多个思维链提示和部分数据集专用提示判断争议案例。剩余分歧由领域专家标注、平衡并分配到测试集，中等难度的共识案例则提供基础训练数据。

CompassVerifier 通过错误驱动的对抗合成、复杂公式等价变体，以及提示与长上下文扰动得到增强。推理时，它比较题目、参考答案与候选回答，输出 A、B 或 C。该三分类契约区分“答案错误”和“题目、参考答案或回答无效”，但论文的二分类评测与 GRPO 奖励会把 B 和 C 合并为奖励 0。
