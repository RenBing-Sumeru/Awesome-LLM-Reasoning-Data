The report describes two packed SFT stages: 204,800 samples at 294,912-token packed sequences, then 19,200 samples at 515,000-token sequences with up-to-512K long-context data. Disclosed components include GPT-OSS-120B medium-effort reasoning samples; a retained 45K safety blend with policy-conditioned synthetic responses; search trajectories from a commercially cleared OpenResearcher subset of about 21.7K; about 370K terminal conversations; science data filtered by an LLM judge; and code/tool-call components reported at 1.2M Python, 1.0M C++14, and 1.3M Python tool-call traces. These are component-level disclosures, not a complete item-level mixture manifest.

Unified RLVR covers terminal use, office/productivity, software engineering, search, tool calling, math, code, STEM, safety, chat, instruction following, long-context QA, reasoning, and structured outputs. It uses asynchronous GRPO with batch 8,192, 16 rollouts per sample, and maximum generation length increasing from 48K to 64K. MOPD uses 1,024 prompts per batch, one rollout per prompt, a 192K maximum generation limit, dense signals from corresponding specialist teachers, and two iterations.

Filtering is partly concrete: OpenResearcher is filtered for commercial clearance; safety back-translation uses semantic similarity threshold 0.8 and removes approximately 10–15% per language; the report also names LLM-judge filtering, code rejection sampling, strict code deduplication, and selected benchmark decontamination. Full prompts, teacher routing, source allocations, filter coverage, yields, environment pins, and raw trajectory/reward logs are unknown or only partially released.
