Construction starts from GitHub Python repositories maintained for at least 3 years, with more than 500 stars, dependency/configuration files, tests, and permissive licenses. Filtering leaves 4,923 repositories. Stable-dependency main-branch spans with at least 1,000 modified lines yield 8,311 candidate pairs; automated environment construction and self-repair retain 1,458. Executability and a target-over-base gap of at least 5 tests leave 137 candidates, from which the top 100 are selected. Final tasks average 233 days and 71 commits and contain at least 500 changed source lines excluding tests.

The evaluator uses fresh Docker containers for Architect, Programmer, and pytest stages, copying only the accepted code state forward and archiving timestamped states. Each agent call and pytest run defaults to 3,600 seconds; each agent can be retried 10 times, and evolution stops after 20 epochs or zero remaining gap. The public guidance estimates 48 hours with 16 workers on 32 CPU cores, 64 GB RAM, and about 1 GB/s disk I/O. Local records include main.log, task.log, iteration.jsonl, requirement.xml, code snapshots, test process/JSON reports, and non-passing-test context; exceptions and invalid pytest reports are logged and archived rather than silently relabeled as solved.
