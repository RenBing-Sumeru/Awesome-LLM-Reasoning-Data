DROP's contribution is a crowdsourced reading-comprehension benchmark designed so that many questions require resolving paragraph references and applying operations such as addition, counting, comparison, or sorting. The core mechanism is adversarial question writing over Wikipedia-like passages with answer formats that can be scored by generalized EM/F1 rather than only by span extraction.

Compared with SQuAD-style extractive QA, DROP changes the evaluation object from locating a local answer span to deriving an answer from multiple facts in the passage. The feedback contract is still answer matching, not a proof checker: a prediction succeeds when normalized answer strings or numeric/date components match the gold answer set under the scorer. Direction label: answer-level benchmark for discrete reasoning over text.
