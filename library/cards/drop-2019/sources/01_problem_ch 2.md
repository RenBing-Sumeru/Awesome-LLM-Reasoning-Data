# 问题：这篇论文想回答什么问题？

- 官方来源：https://arxiv.org/abs/1903.00161
- 会议/日期：NAACL 2019 / arXiv（2019）。
- 决策边界：这里把它收为 benchmark / evaluation surface；除非论文明确训练模型，否则不把它当模型训练 recipe。
- 具体问题：DROP tests paragraph-level reading comprehension that requires arithmetic, counting, sorting, and other discrete operations.
- 对 atlas 的价值：它说明 reasoning 系统如何被打分、审计或横向比较。
- 数据对象 / 评测面：passage, question, answer spans or numeric answer, and annotation metadata。
- L4 收录说明：元数据、来源链接、本地中文头、机构和中英文 section 已足够进入人工 review。
