BIG-Bench Hard asks which BIG-bench tasks remain difficult for strong language models and whether chain-of-thought prompting changes that difficulty. The primary sources are the arXiv paper and the official BIG-Bench-Hard GitHub repository. A data object is a JSON task file with examples containing an input/question and a target answer, plus prompts and evaluation scripts for the selected subset. It belongs here as a static hard-reasoning evaluation surface; it is not a new interactive environment or a mechanically verified reasoning corpus.
