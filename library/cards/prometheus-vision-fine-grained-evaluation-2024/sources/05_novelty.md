Prometheus addressed text rubric evaluation, and other VLM benchmarks used GPT-4V scoring. Prometheus-Vision contributes Perception Collection specifically for visual evaluation and trains a locally deployable open VLM judge that accepts custom rubrics. The key contribution is jointly conditioning on evaluation criteria and visual grounding rather than a new visual encoder. It establishes an image-response-rubric-feedback-score record format for later MLLM judge data.
