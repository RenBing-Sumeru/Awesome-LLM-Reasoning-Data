The paper builds Perception Collection with roughly 15K customized visual score rubrics and associated images, instructions, candidate responses, references, and feedback, then trains Prometheus-Vision. It retains Prometheus’s rubric, reference, critique, and score interface while conditioning directly on the image, enabling criteria about object recognition, relations, detail, and instruction following. Data, model, and code are released as a reproducible fine-grained VLM-as-a-judge baseline.
