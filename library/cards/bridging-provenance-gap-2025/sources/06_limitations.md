The audit is dataset-level. A collection or dataset label can conceal records from different creators, platforms, licenses, consent regimes, and transformations. “Derived from” links help trace reuse but do not establish which examples overlap, which license applies to each record, or whether a benchmark item entered training. The resource therefore cannot replace record-level lineage or contamination checks.

Human judgment reliability is under-specified. The paper describes domain experts, legal analysis, full source tracing, and fields such as `License Verified By`, but it does not report field-level coverage, reviewer assignment, training materials, disagreement resolution, or inter-annotator agreement. Public documents can themselves be incomplete, stale, contradictory, or later changed, and the release does not provide a complete timestamped evidence snapshot for every label.

The legal taxonomy is intentionally simplified. Commercial/NC/Unspecified and Model Closed/Source Closed/Unspecified/Unrestricted compress licenses, platform contracts, model-output terms, and jurisdiction-specific questions into comparison categories. Strictest-source aggregation is conservative, yet it neither resolves compatibility among multiple obligations nor constitutes legal advice or clearance.

Coverage is selected, not exhaustive. Popularity, public availability, task tags, surveys, citation/download thresholds, workshop lists, and expert additions privilege visible ecosystems. Private/proprietary training data are absent. Text, speech, and video also use different inclusion rules, schemas, version handling, and size units, so cross-modal totals should not be interpreted as a uniform random sample.

Representation measures have operational limits. “Creator organization” means an affiliation associated with releasing the ML dataset, not an upstream content owner or individual contributor. Headquarters mapping, multi-organization counting, partial identities, missing usage frequency, and unobserved proprietary data constrain geography and Gini conclusions. Higher dataset counts do not measure whose content, labor, or consent is represented.

Versioning is not paper-frozen. The accepted PDF internally gives 3,717 and 3,713 text datasets. The repository's only release, v1.1.0, predates the paper; current main has later modality files, while the README still describes the older 44-collection text audit and cites the 2023 paper. The checked tree contains 110 text JSON files including a template, 95 speech files, and 105 video files, but file counts cannot be equated with paper dataset counts.

Licenses remain layered. Apache-2.0 covers the repository material, not the underlying data, source works, model outputs, or platform access. The official Hugging Face organization contains multiple filtered or normalized artifacts but no single identified repository representing the full 2025 multimodal audit. Reusing a filtered dataset still requires checking every upstream license, term, privacy obligation, and access condition.
