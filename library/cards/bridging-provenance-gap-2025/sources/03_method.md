Selection is modality-specific rather than one uniform crawl.

1. Text focuses on public post-training data used for instruction tuning and preference alignment. The team expands an earlier 44-collection, 1,858-dataset audit to 108 collections by combining recent surveys and tools, monthly popular Hugging Face datasets, SFT/DPO releases associated with open models, multilingual catalogues such as SEACrowd, Masader, AI4Bharat, and Aya, and expert review. The paper discusses recent datasets introduced through April 2024 while also describing monthly popularity review from April through July 2024, so there is no single clean cutoff interpretation.
2. Speech retains datasets where ASR is a primary task. Candidates come from survey repositories, Hugging Face ASR/TTS tags, OpenSLR, and targeted low-resource-language additions. When versions are cumulative, the audit uses the initial release year but recent available metadata; legally or semantically distinct versions can remain separate. Unlabeled hours are excluded, while weakly supervised hours with model-generated transcripts are retained.
3. Video starts from Hugging Face video task tags, Papers with Code categories, a survey repository, relevant workshops, citation/publication criteria, and a 100-download threshold, then uses external expert review. A shared video source used and annotated for different tasks may count as different datasets.

Annotation follows public evidence chains. Domain experts inspect academic papers, websites, GitHub/Hugging Face/Papers with Code pages, and source policies, sometimes traversing several derivations to reach the original source. The paper says relevant licensing and sourcing information is often lost during repackaging and therefore requires a “full trace” through those documents. Text creator organizations are the affiliations associated with the ML dataset release, not the organizations that own or created the upstream content.

The released JSON is heterogeneous by modality. Text records can include identifiers, dataset and collection URLs, languages, task categories, text sources, generating models, format, human annotation, parent datasets, creators, licenses and URLs, license notes/verifier, filter IDs, BibTeX, platform metadata, and text metrics. Speech adds hours, speakers, ISO languages/families, topics, source/process description, creator categories, year, and location. Video adds video hours, availability/takedown status, countries, source platforms, and task categories. Field presence varies; there is no single fully populated schema shared by every record.

The restriction taxonomy has two axes. Dataset license intent is Commercial, NC/Acad, or Unspecified. Each upstream source is classified as Model Closed, Source Closed, Unspecified, or Unrestricted; the strictest source label is used when sources are aggregated. For collection-level text analysis, a collection inherits the most restrictive status of its constituent datasets. This conservative rule is explicit, but field-completion thresholds, annotator assignment, disagreement resolution, and inter-annotator agreement are unknown.

The official repository contains JSON summaries, constants, plots, downloader/preparer/filtering code, and contribution instructions. Its normalization format can represent multi-turn dialogue and response rankings, but that operational feature belongs to retrieval of selected underlying datasets; it does not turn the audit metadata itself into training examples. Reproducible reuse should pin a repository revision and preserve the evidence URL and timestamp behind every human judgment.
