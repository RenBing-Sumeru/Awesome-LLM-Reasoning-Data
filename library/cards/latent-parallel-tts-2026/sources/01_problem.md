Parallel test-time scaling normally samples alternative token chains from a vocabulary distribution and then votes, ranks, or searches over them. Latent reasoning models replace intermediate tokens with continuous hidden vectors, making reasoning more compact but removing both ingredients that make this routine work: there is no categorical distribution from which to sample alternative thoughts, and there are no readable token likelihoods or text traces for a conventional process reward model to score.

The paper asks whether a continuous reasoning model can convert additional inference compute into the same kind of parallel exploration benefit. The problem requires more than adding arbitrary noise, because perturbations can destroy a latent trajectory instead of revealing a useful alternative. It also requires an aggregation signal that distinguishes promising hidden-state paths without pretending that an existing textual verifier understands a sequence of abstract vectors.
