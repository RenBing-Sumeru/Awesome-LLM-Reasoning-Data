Rule-based rewards only cover tasks for which an answer can be normalized and checked; open-ended instruction-following and planning may require different predicates. Qwen-generated thoughts and Llama-generated reflections can share model biases, and a correct final answer does not validate every intermediate node. Relative length buckets may confound task difficulty with verbosity, while preference pairs derived from the shortest common prefix inherit any checker or search error. The verified paper and repository do not fully disclose prompt sources, data volume, split and decontamination procedures, full search settings, row-level tree lineage, or v2 dataset licensing. The public repository also spans multiple Marco-o1 versions, so a model or v1 demonstration link must not be treated as proof that the v2 training trees and DPO pairs are released. Benchmark improvements do not establish data quality.
