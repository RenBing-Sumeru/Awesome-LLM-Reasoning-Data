Each prompt starts at a root and is expanded through a sampled reasoning-flow template represented by a node-transition matrix. MCTS selects nodes with an upper-confidence rule, prompts the model according to the node role, and rolls out until an Answer node. A correct rule-checked answer receives terminal reward and is backpropagated; an incorrect answer can return to an earlier node and invoke Reflection. The paper uses Qwen2.5-72B-Instruct for Thinking-like nodes and Llama3.1-70B-Instruct for Reflection, so generator and critic are separated but both remain model-mediated. The complete prompt-source manifest, per-domain checker implementation, search limit, rollout count, sampling temperature, tree seeds, and full raw tree corpus are not established by the verified public artifacts.

For post-training, valid correct paths are bucketed by relative length per question rather than by a global token threshold. The paper uses long correct paths for SFT and short correct paths for DPO; negative paths are selected from incorrect branches with the shortest common prefix to a positive path. Conservative DPO softens potentially noisy preference labels, mask-based DPO excludes the shared prefix from gradient computation, and the joint objective is L_DPO plus alpha times L_SFT, with the reported later configuration using alpha=1. The experiments start from a Llama-3.1-8B model fine-tuned on the constructed CoT data and also test transfer through Llama and Qwen models. The official GitHub repository points to Marco-o1 model resources, but the checked evidence does not establish a released row-level v2 tree corpus with branch scores, rejected paths, pair identifiers, and checker logs.
