- **Judge identity and decision drift:** Paper v3 Appendix B.1 names GPT-5.5 as the fixed judge, whereas current `docs/REPRODUCE.md` says the paper used Claude Opus 4.7; current setup documentation also describes a GPT-5.5 default. The paper uses PassRate threshold 0.8, but that reproduction document states 0.5. Until authors reconcile both conflicts and pin model, prompt, provider, and code revisions, reported scores cannot be reproduced from one unambiguous contract.
- **Learned-judge fidelity:** The mixed judge may produce false positives or false negatives, inherit semantic and style bias, or change with model aliases and prompt versions. No independent calibration set, error rate, inter-rater reliability, or complete adjudication policy is disclosed. The evaluated agent must remain unable to read hidden anchors; any staging leak would invalidate the contract.
- **Episode and trajectory release:** The public gallery, announced on 2026-07-08 after paper v3, is described as the best trajectory per task. An immutable manifest containing all successful, partial, failed, and hack-flagged episodes, complete downloadable record schema, license, and retention policy was not verified. Failure analysis in the paper does not itself make the failure corpus reusable.
- **Versioned replay:** The paper-canonical Hugging Face revision and VM SHA-256 are pinned, but the checked GitHub documentation is mutable `main`, and no code commit matching the paper tables was disclosed. Current Hugging Face main is newer than the paper pin. Tool aliases, screenshots, application versions, model APIs, task-local services, prompt, threshold, and runtime settings can all change episode behavior or judge output.
- **Task pool and experimental scope:** The suite is English-only, Linux-desktop-only, limited to 114 tasks, and evaluated on a limited backbone-by-harness set. A formal train/dev/test split, model-training overlap analysis, and decontamination protocol are unknown. Public tasks, sources, and graders create leakage and verifier-gaming risk if reused repeatedly.
- **Provenance, rights, and consent:** The paper reports 174 public URLs and says a machine-readable provenance index ships, but the exact released path and record-level completeness were not verified. Code and tasks are stated as MIT, while runtime bundles retain upstream terms. Rights and consent for every user-authored post, request, bundled asset, VM component, and gallery trajectory remain unknown; public availability is not proof of redistribution permission.
- **Interpretation boundary:** The 35.1% and 41.2% top reported PassRates, interface ablations, and reward-hacking analysis characterize the reported evaluation setup. They do not certify task correctness, judge calibration, data quality, training value, or general computer-use capability.
