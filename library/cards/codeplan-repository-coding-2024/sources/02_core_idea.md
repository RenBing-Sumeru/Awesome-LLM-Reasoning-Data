The contribution is a planning loop for repository edits: build and update a dependency graph, ask an LLM for localized changes, classify atomic edits, and expand the plan to impacted code. The evaluation surface is edit similarity and block coverage against target repositories, not hidden unit-test acceptance. Closest comparisons are direct prompting, retrieval/edit baselines, and later SWE-bench-style issue-resolution benchmarks. The feedback contract in the released package is metric computation over source/target/pred repositories, including DiffBLEU, Levenshtein distance, and matched/missed/spurious blocks.
