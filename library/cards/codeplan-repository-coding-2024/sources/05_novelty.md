Prior LLM code-editing work often prompts for a localized change or evaluates generated snippets; CodePlan changes the object to multi-step repository edits guided by dependency analysis. The direction signal is planning over code graphs before and after edits. The quality signal is an official Microsoft replication package with source/target/pred repositories and recomputable metrics. What is not new: static analysis, LLM prompting, textual diff metrics, and repository benchmarks. Reuse checks: MIT license, archived repository status, metric adequacy, language/project scope, dependency graph fidelity, and lack of hidden-test verification.
