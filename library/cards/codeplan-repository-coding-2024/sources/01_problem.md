Primary sources: arXiv:2309.12499, the aka.ms/CodePlan short link, and microsoft/CodePlan. The paper targets repository-level coding, where a change request may affect multiple files, declarations, call sites, and tests. This card is in scope as a planning and repository-edit evaluation surface, not as a live interactive coding-agent benchmark. The released data object is a repository edit package with source repository state, target ground-truth edit, predicted repository states from CodePlan and baselines, block-level diff artifacts, metrics.json files, and evaluation scripts.
