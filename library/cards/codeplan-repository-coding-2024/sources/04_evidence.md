The official repository describes a replication package accepted for FSE 2024. Each edit directory contains source, target, and pred subdirectories; pred contains per-approach repository states, blocks, metrics.json, and diff.html. The evaluation script recomputes text metrics such as DiffBLEU and Levenshtein distance plus block metrics for matched, missing, and spurious edits. Instance-level evidence is the file-wise metric record and diff/block comparison against the target, not a live unit-test verdict. Evidence is bounded by the five released repo ids and metric definitions.
