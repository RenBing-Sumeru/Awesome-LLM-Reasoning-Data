1. **合成 GUI rollout。** 使用强 computer-use agent 在真实网页任务上生成完整交互，保存截图、历史、动作和终局状态。
2. **逐步独立评分。** step grader 对每个动作检查任务相关性、页面一致性和局部合理性，而不是只按整条轨迹成败过滤。
3. **保留局部有效行为。** 删除错误或明显次优步骤，同时允许保留失败轨迹中仍然正确的局部动作。
4. **补充推理信息。** 为通过筛选的动作生成计划或解释，形成 reasoning-rich step，并重组为连贯训练轨迹。
5. **发布双数据对象。** WebSTAR 用于轨迹微调，WebSCORE 保存细粒度评分并用于蒸馏 StepRM。
