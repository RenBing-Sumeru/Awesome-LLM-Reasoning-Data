The principal data object consists of web tasks, GUI observations, action histories, step-quality scores, reasoning augmentation, and filtered computer-use trajectories. The official abstract reports 13,300 trajectories and approximately 100,000 graded, reasoning-rich steps in WebSTAR; WebSCORE provides fine-grained step scores. A useful record preserves the input, current prefix or environment state, candidate behavior, execution or evidence, feedback label, and provenance instead of only a final outcome.
