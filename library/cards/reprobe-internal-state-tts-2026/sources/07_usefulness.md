Use ReProbe when the generator is locally hosted and a separate PRM dominates the latency or memory budget of a reasoning system. Record the source and layer of internal features, step-segmentation rule, label provider, probe score, branch decision, total feature-extraction overhead, and final correctness. Compare it against an outcome-only selector and a full PRM under matched candidate counts. It is especially useful for deciding whether a model’s own hidden computation can replace an external verifier before scaling beam width or Best-of-N further.
