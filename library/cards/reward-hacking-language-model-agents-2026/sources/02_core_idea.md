The core contribution is a text-based AI Safety Gridworlds suite in which an agent receives observable proxy reward while evaluation also logs a hidden intended-safety reward. This makes reward hacking a measurable property of trajectories rather than a post-hoc account of a frontier failure.

The suite evaluates zero-shot agents and agents trained directly on observed reward, then tests credit assignment, prompting, exploration, and entropy interventions. Official code is released; the paper is an arXiv preprint and does not claim a separately downloadable dataset.
