核心新意是匹配前缀的信用分配。PORTool 不在独立采样 episode 之间寻找近似状态，而是在完全相同的查询和已执行历史下构造 sibling 替代动作。这样，无需学习 process reward model 或依赖 canonical 下一工具标签，也能把稀疏结果监督转化为局部比较。

树结构还避免同一共享步骤获得相互矛盾的信用：经过某个前缀节点的全部完整路径共同产生一个重要度。Theorem 3.1 分析均匀轨迹信用如何降低必要步骤的概率；Theorem 3.2 则为按归一化尺度混合分叉级与轨迹级目标提供依据。

这是一项算法与构建贡献，不是数据集发布。SFT 提供初始化，在线 agentic RL 提供主要学习信号。可复用的洞见是奖励/轨迹契约——共享前缀、sibling 动作、后代结果、辅助执行证据与终局标签——前提是未来发布能保留所有分支及其来源链。
