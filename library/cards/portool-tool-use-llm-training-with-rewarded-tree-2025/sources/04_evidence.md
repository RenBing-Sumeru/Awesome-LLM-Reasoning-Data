On the private held-out evaluation, PORTool reports 51.98% accuracy with Qwen-2.5-7B-Instruct, versus 48.23% for the strongest listed baseline. With Qwen-3-1.7B, it reports 46.60% versus 42.76%. The paper also reports ToolBench average pass rate 52.8%, plus TravelPlanner delivery rate 92.8% and pass average 16.7% for the Qwen-2.5-7B-Instruct model.

The terminal evaluator is calibrated on 700 query-answer pairs generated by multiple strong model families and human-labeled using tool outputs as evidence. GPT-4o reaches 94.37% agreement. Each evaluated trajectory receives 5 independent judge calls followed by majority vote. Reported training results average the best 3 checkpoints, which is a selection detail rather than a single final-checkpoint estimate.

Ablations support using both fork- and trajectory-relative advantages and adaptive reward aggregation. Always averaging can dilute rare successful branches; always taking the maximum can emphasize lucky descendants. These results support the optimization mechanism, not public-data quality: the private evaluation items, raw judgments, rollout trees, retries, and checkpoint histories are unavailable for independent error analysis.
