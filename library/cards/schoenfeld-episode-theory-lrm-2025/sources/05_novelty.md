Earlier machine-CoT analyses rely on custom keywords, token statistics, or task-specific step taxonomies without connection to established cognitive theory. This work introduces Schoenfeld episode definitions, guidelines, and human-annotated data to LRM analysis, allowing models to be compared in one functional language. Its novelty is a theory-grounded seven-label process benchmark that provides a foundation for later scalable frameworks such as ThinkARM. The resource converts educational-psychology process concepts into annotatable machine outputs and provides gold data for larger-scale automatic analysis. The seven cognitive stages are not new. The contribution is converting educational-psychology definitions into a reproducible annotation protocol and public gold data for scalable machine-CoT analysis.
