One-sentence contribution: WebMall - A Multi-Shop Benchmark for Evaluating Web Agents makes a shopping instruction, four simulated shops, product offers, task category, observations, cross-shop actions, cart or checkout state, gold offer-URL set, and completion metrics. reusable by binding it to a concrete feedback contract.

Core mechanism: The benchmark builds simulated shops from product offers and defines 91 tasks across 11 categories and five task groups. Feedback contract: Gold offer-URL set matching defines strict completion; product-search, add-to-cart, and checkout tasks also report precision, recall, and F1 for partial completion. Closest comparisons are WebShop, WebArena e-commerce tasks, and live shopping-agent benchmarks. Direction label: verifier-anchored agent evaluation, where the reusable unit is task object plus acceptance rule.
