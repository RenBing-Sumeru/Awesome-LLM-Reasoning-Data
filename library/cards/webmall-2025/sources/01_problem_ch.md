WebMall - A Multi-Shop Benchmark for Evaluating Web Agents 回答的问题是：购物智能体需要跨多个商店做可复现比较购物；单店或实时网页设置让商品覆盖和评分难以比较。主来源是 https://arxiv.org/abs/2508.13024；公开状态为 ACM SIGIR 2026 / arXiv preprint（2025）。

决策边界：它应作为多商店购物基准收录，不是实时电商部署，也不是通用网页购物榜单。评测面是：一个任务包含购物指令、四个模拟商店、商品 offer、任务类别、观察、跨店动作、购物车或 checkout 状态、gold offer-URL set 和完成指标。它对 atlas 的价值在于任务对象和反馈规则可以一起审计。
