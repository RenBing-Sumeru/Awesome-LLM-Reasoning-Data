WebMall - A Multi-Shop Benchmark for Evaluating Web Agents asks how to close this gap: Shopping agents need reproducible comparison-shopping tasks across multiple shops; single-store or live-web setups make offer coverage and scoring hard to compare. The primary source is https://arxiv.org/abs/2508.13024; public status is ACM SIGIR 2026 / arXiv preprint (2025).

Decision boundary: It is collected as a multi-shop shopping benchmark, not as a live commerce deployment or generic web-shopping leaderboard. The evaluation surface is a shopping instruction, four simulated shops, product offers, task category, observations, cross-shop actions, cart or checkout state, gold offer-URL set, and completion metrics. This makes the paper useful for the atlas because the data object and feedback rule can be audited together.
