1. **建立数据源：** 收集 204 道带标准答案的高难数学题，并按 MATH 与两届 AIME 划分子集。

2. **生成或重组反馈：** 从 DeepSeek-R1、Qwen3-32B、QwQ-32B 和两个 R1-Distill 模型为每题采样至少 64 个回答，覆盖正确与错误输出。

3. **验证与筛选：** 用答案规则匹配、强模型复核和人工核验联合标注正确性，删除仅含截断 CoT 的异常记录，并平衡各模型的正负样本。

4. **训练与评测：** 将问题与候选回答组成 pointwise judging 输入；训练 Libra-RM 时再以标签一致性做拒绝采样，并用正确性奖励和长度惩罚进行 RL。
