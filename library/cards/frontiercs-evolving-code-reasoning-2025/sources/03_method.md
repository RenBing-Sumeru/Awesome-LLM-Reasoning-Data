1. **Design open problems:** CS PhDs, elite competitors, and problem setters design tasks without known attainable optima but with measurable quality.

2. **Build executable interfaces:** Each task specifies input, output, validity checks, and resource limits for executable submissions.

3. **Create references and evaluators:** Experts provide strong references, and evaluators check validity before assigning objective partial scores.

4. **Evaluate tracks and budgets:** Models run on algorithmic/research tracks under different reasoning budgets; revision, hardware, time limits, and seeds must be fixed.
