核心思路是把数学文本翻译为交错的“推理—代码”预训练对象。Llama-3.1-70B-Instruct 提取计算所需条件、LaTeX 表达式和预期结果，再编写可独立执行的 Python 代码。执行筛选选择合格块，然后将其压平并加入基础数学语料。

论文中的完整混合包含六个组件。Filtered OpenWebMath 与 filtered CC-En-math 提供网页文本；三个合成集合提供结构化数学/科学文档；StarCoderData 提供导入指定数学包的 Python 与 Jupyter 记录；在线 PDF 提供教材；翻译阶段则新增 2.7287B token 的“数学上下文—代码”配对数据。

反馈对象不是 learned reward，而是执行与输出选择谓词。论文层面的要求是 Python 无错误运行并匹配提取出的预期结果；代码实现却只在两个短字符串都能解析为数值时检查相等，其他无错误输出直接通过。此外，预期结果与程序来自同一次 teacher completion，因此该检查衡量的是内部自洽，而不是独立数学正确性。
