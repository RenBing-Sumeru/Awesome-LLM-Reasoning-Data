The public release is not the full Table 1 corpus. Hugging Face exposes a single train split with partial OpenWebMath, CC-En-math, and translated-code shards, no identifiable textbook directory, and no row-level provenance. Its preview estimate is not a complete document count. Source URLs, upstream revisions, filter scores, teacher fields, execution evidence, and rejected records are absent.

Verification is self-consistency with a weak implementation boundary. Expected result and Python come from one Llama-3.1-70B-Instruct completion. Only two short numeric-parseable strings receive the 0.01 tolerance comparison; other error-free outputs pass. Raw `exec`, a timeout, and two regex blocks are not a secure sandbox for generated code.

The checked pipeline is not end-to-end executable without repair. Execution and conversion scripts import an absent module; one calls an undefined entry point; generation and parsing disagree about a required model field; OpenWebMath filtering references undefined `idx`; and the training resume branch references `new_learning_rate` before assignment. These defects do not show that the authors' original runs failed, but they block transparent replay of the public artifact.

Decontamination is not reproducibly bound to the release. The public script expects an `output` field while hosted rows use `text`, uses substring matching in its exact stage, and emits a tuple-shaped accepted object. Benchmark revisions, candidate matches, decisions, and semantic-overlap review are absent.

Rights and versions remain unresolved. The dataset and checkpoint pages declare Apache-2.0, but the GitHub root has no license. No row-level license ledger covers Common Crawl, OpenWebMath, StarCoderData, synthetic sources, or unlisted textbook PDFs. Code and data revisions predate the ICLR 2025 Spotlight decision, have no named paper release, and are not bound to exact paper-run configurations or checkpoint hashes. The official collection releases four continued-pretrained models but not the downstream CoT/TIR SFT variants.
