MathCode-Pile's basic corpus combines five source classes before translation. Mixtral-8x7B-Instruct labels OpenWebMath documents, retaining mathematical problem/solution and concept/theory material. Common Crawl undergoes two fastText stages with intermediate Mixtral category annotation. Three synthetic collections are filtered for mathematical relevance. StarCoderData Python and Jupyter records are retained when they import packages such as sympy, fractions, cmath, scipy, or statistics; numpy alone is excluded as a filter. About 8K online textbook PDFs, reported exactly as 8,373 documents in Table 1, are selected by title keywords and converted with Nougat.

Released file-preparation code sends selected filtered OpenWebMath and CC-En-math records to Llama-3.1-70B-Instruct. Generation is greedy, truncates source input at 3,072 tokens, allows 3,072 new tokens, and uses 12 local workers. The structured completion contains Conditions Needed, a LaTeX expression, Computation Result, and Python. The paper and deployment script identify Llama-3.1-70B-Instruct as translator; the mathematical-code README's Mixtral-8x7B-Instruct attribution conflicts with them.

Python is run through raw `exec` in worker processes with a ten-second timeout. Regex checks block `input(` and `os.system(`, but do not form a hardened filesystem, network, subprocess, or import sandbox. The intended filter retains code that executes without error and matches the expected result. The released comparator applies an absolute-error threshold of 0.01 only when output and expected result are both shorter than 20 characters and complex-parseable. Otherwise, any error-free execution enters the accepted set.

After filtering, title, conditions, expression, result, and fenced code are concatenated into one `text` document. Generation fields, stdout, exceptions, timeouts, numeric comparisons, and rejection reasons disappear. Exact matching and 13-gram Jaccard similarity above 0.6 are reported for decontamination against nine bundled benchmark test sources, after which four bases undergo three epochs of continued pretraining with a four-million-token global batch.

Table 1 reports six exact components: filtered OpenWebMath 4,826,902,621 tokens; filtered CC-En-math 6,341,745,645; synthetic data 2,193,189,314; math-package code 1,703,226,005; textbooks 1,390,268,773; and translated code 2,728,740,985. The total is 19,487,652 documents and 19,184,073,343 tokens. These are paper-corpus counts, not counts of the current Hugging Face snapshot.

The public dataset has one train split and one text field per row. Its card explicitly says OpenWebMath, CC-En-math, and translated code are only partly released. No textbook-specific directory is identifiable. Public rows omit source URL/license, filter score, teacher/version, execution evidence, and contamination decision. Four continued-pretrained checkpoints are public; the later NuminaMath CoT/TIR SFT checkpoints used in downstream experiments are not in the official collection.
