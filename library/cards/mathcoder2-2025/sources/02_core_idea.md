The core idea is to translate mathematical prose into an interleaved reasoning-and-code pretraining object. Llama-3.1-70B-Instruct extracts the conditions required for a computation, its LaTeX expression and expected result, then writes an individually executable Python snippet. Execution filtering selects blocks before they are flattened and added to the basic mathematical corpus.

The full paper mixture has six components. Filtered OpenWebMath and filtered CC-En-math supply web text; three synthetic collections add structured math/science documents; StarCoderData contributes Python and Jupyter records importing selected mathematical packages; online PDFs provide textbooks; and the translation stage adds 2.7287B tokens of mathematical code paired with context.

The feedback object is not a learned reward. It is an execution-and-output selection predicate. At paper level, Python must run without error and match the extracted expected result. At code level, equality is tested only when both short strings parse numerically; other error-free outputs pass. Moreover, expected result and program originate in the same teacher completion, so the check measures internal consistency rather than independent mathematical correctness.
