FlexiVe-14B is initialized from DeepSeek-R1-Distill-Qwen-14B and trained with GRPO on BIG-Bench Mistake. The reported split contains 1,526 training and 170 test samples. The target is the first error index or −1 for a correct trace. The reward combines exact index correctness with a length penalty, with λ = 0.1, and training activates the Fast Thinking/NoThinking template.

At inference, the paper’s preferred Flex setting uses k = 8 and agreement threshold τ = 0.8. Eight fast outcomes are collected over the whole trace; if consensus is below threshold, the system performs max(1, ceil(k/8)) slow runs. SDV begins with a step-by-step solver trace, segments it using predefined hesitation markers, and probes completion only at those events. If verification finds an error, its textual feedback and the current solution are included in the next attempt; the maximum number of attempts T controls sequential compute.

A reusable SDV record would preserve the problem and solver/model revisions; every generated prefix and trigger; Yes/No log-probabilities; stopping reason; fast outcomes and agreement; escalation decision; slow verification rationale; predicted error index; diagnostic feedback; revised traces; token/FLOP accounting; and final-answer correctness. No official code, model, SDV trajectory dataset, rejected-feedback log, or replay manifest is linked in the accepted metadata, so those release fields remain unknown.
