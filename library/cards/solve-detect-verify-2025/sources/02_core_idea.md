FlexiVe is a holistic generative verifier with three inference modes. Fast Thinking suppresses an explicit rationale and emits a short verification result; Slow Thinking generates a deliberative verification trace; Flex@k first runs k independent fast checks and accepts their majority result when agreement reaches a threshold, otherwise escalating to slow verification. Each verification returns textual analysis F plus the first error index, so the signal can guide correction rather than only rank candidates.

SDV couples this verifier to event-triggered stopping. Hesitation keywords define sparse points at which the solver compares log p(Yes) and log p(No) under a completion prompt; the keyword itself is not treated as proof of completion. A positive log-probability difference stops generation. FlexiVe then accepts the trace or returns feedback for another solve–detect attempt.
