General-purpose agent-trajectory data usually retain only final success or a completed answer, so they cannot reveal which step in planning, retrieval, tool selection, environment execution, or evidence synthesis creates value or introduces an error.

Rather than merely adding complete successful trajectories, this work records instructions, thoughts, actions, observations, environment feedback, and skill- and difficulty-balanced interaction trajectories from 16 tasks, allowing each local behavior to be accepted, rejected, or corrected for an explicit reason.
