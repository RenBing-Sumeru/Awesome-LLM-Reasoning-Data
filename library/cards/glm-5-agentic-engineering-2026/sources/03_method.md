Base training draws from broadly named web, code, and mathematics/science sources. Code processing uses refreshed hosting snapshots, code-containing web pages, Software Heritage repairs, language/quality sampling, and fuzzy deduplication. Mid-training adds natural long documents, synthetic long-range sequences, a small MRCR-like component, and roughly 10 million issue–PR pairs yielding about 160B unique tokens after filtering. Repository identities, commits, retention counts, and rights are not enumerated.

SFT has three families. General Chat uses multilingual and configurable role-play data with automatic and human review. Reasoning uses verifiable logical problems, rejection sampling, and difficulty filtering. Coding & Agent uses trajectories from execution environments; erroneous spans may remain in context while being loss-masked. Maximum disclosed context is 202,752 tokens, but SFT sample and token totals are unknown.

Reasoning RL roughly balances mathematics, science, code, and tool-integrated reasoning. Domain- or source-specific judges/evaluation systems emit binary outcome rewards. The report states on-policy group size 32, batch size 32, beta 2, epsilon-low 0.2, and epsilon-high 0.28, building on GRPO and IcePop without KL. Judge identities, calibration, and per-source reward semantics are not released.

Agentic RL is fully asynchronous. Rollout and learner devices are decoupled; the Multi-Task Rollout Orchestrator routes heterogeneous HTTP task services. TITO records exact token IDs, rollout log probabilities, model-weight versions, and metadata. Only model-generated tokens enter the loss, although environment observations still determine state transitions and rewards. Direct double-sided importance sampling masks out-of-range ratios, while stale, noisy, or environment-collapse trajectories are dropped.

Training environments include over 10K RepoLaunch-built SWE environments across thousands of repositories and nine languages, thousands of Harbor terminal environments from real seeds or web-grounded synthesis, a search pipeline over a Web Knowledge Graph of more than two million deduplicated pages, and an HTML slide-generation environment. These must not be confused with evaluation scaffolds such as OpenHands, Terminus-2, Claude Code, MCP-Atlas, or CC-Bench-V2. Likewise, vLLM, SGLang, Transformers, KTransformers, and xLLM are deployment tools, not data constructors.
