GLM-5 asks how a frontier open-weight language model can move from short-form code generation toward long-horizon agentic engineering: understanding repositories, operating terminals and browsers, using tools, recovering from environment feedback, and completing multi-step software tasks. The central data question is therefore not merely how much text was consumed, but how source records become executable tasks, trajectories, verifier outcomes, and learner updates.

The report is valuable because it spans the full stack: a 28.5T-token base-model pipeline, multi-task supervised fine-tuning, reasoning and agentic reinforcement learning, general reinforcement learning, cross-stage distillation, constructed execution environments, and asynchronous rollout infrastructure. It also exposes a recurring frontier-report limitation: procedural descriptions can be detailed while record-level manifests, exact mixtures, reward artifacts, training budgets, and lineage remain unavailable.

This Card reads GLM-5 as a data and feedback system. It separates training substrates from evaluation harnesses and deployment software, and treats absent disclosures as unknown rather than filling them with assumptions.
