The contribution is a paired benchmark and agent scaffold: CodeAgentBench supplies 101 repository-level function/class tasks from five Python projects, and CodeAgent gives LLMs tool-mediated access to repository artifacts. The mechanism is not a new program verifier; it combines documentation, static dependency extraction, sandbox execution, five programming tools, and four tool-use strategies. The closest comparisons are HumanEval, ClassEval, RepoEval, CodeContests, and SWE-bench. The feedback contract is programmatic: generated code passes only if all task tests pass in the prepared environment.
