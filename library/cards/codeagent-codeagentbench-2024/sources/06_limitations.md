Correctness means passing the authors' tests in the configured sandbox; it does not prove semantic completeness or production readiness. The benchmark covers 101 Python tasks from five projects, so language, framework, and repository diversity are limited. The paper notes remaining memorization risk and simple tool coverage. Public release details, license terms for every source repository, exact environment reconstruction, and test visibility must be checked before score reuse. Commercial-product comparisons are bounded by interaction limits and are not a general product ranking.
