The problem is that standalone code benchmarks do not test whether an LLM can work inside an existing Python repository with documentation, dependencies, runtime state, and tests. CodeAgentBench is in scope as a repo-level coding evaluation surface, not as a generic model-training dataset. A task contains a documentation-defined target, repository context, dependency information, sandbox runtime, canonical solution, and hidden-from-model test suite; success is accepted only through repository tests.
