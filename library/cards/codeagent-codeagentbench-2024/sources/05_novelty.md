Prior code benchmarks often isolate a function, class, contest problem, or GitHub issue; this work changes the data object to repository tasks with documentation, dependencies, runtime environment, tests, and canonical solutions. The direction signal is tool-integrated repo-level evaluation, where action choices and execution feedback matter. The quality signal is manual task construction plus per-task test suites. What is not new: LLM code generation, unit tests, static analysis, and agent prompting. Reuse checks: artifact availability, license, repository drift, hidden-test access, environment image, and contamination.
