- **身份与版本边界：** accepted paper 是 2026 年 6 月 14 日的 arXiv:2606.13608v2。不同标题的 ICML Position Paper 没有被核验为本记录的 venue version。早期官方 SDK 最后停在 2025 年 11 月 17 日的 v1.2.6，已标记 deprecated，且早于论文；当前 tutorial、template、gateway/Amber stack、documentation 与 dashboard 均独立演化。
- **没有 v2 replay bundle：** 没有核验到与 Tables 6–10 绑定的不可变 commit/image manifest、benchmark snapshot、完整 configuration、prompt、model/API version、timeout、result bundle 或逐条 replay archive。CI 与 local execution recipe 只说明配置后的 assessment 可以运行，不能证明历史结果可准确重建。
- **没有发布 trajectory corpus：** Appendix A 汇总成功和失败 run，却没有论文绑定的 archive 暴露逐 instance message、tool log、artifact、score、retry、exclusion 与 failure reason。系统也缺少 universal result schema；当前 tutorial result 可以是 free-form JSON。因此 full-episode 与 state/action descriptor 表示潜在字段，而不是标准化 dataset release。
- **Judge 异构性：** 程序化 test、environment predicate、semantic prompt 与 LLM judge 不共享同一种 error model 或 reward 含义。predicate 可能遗漏要求或接受 shortcut；semantic scoring 可能有 rubric bias、false positive/negative 或 prompt injection。论文建议把 semantic scoring 隔离在 sub-agent 中，但没有对全部 298 个 judge 做对抗审计或校准。
- **Environment 与 observability 风险：** remote agent 可能缺少完整 log 或标准 reset behavior。runtime injection 可能失败或扰动 coding container，因此需要 preflight 与 remote-shell fallback。authentication/control-plane support 能保护访问，但不能证明 state 确定、可可靠 replay 或 observation 完整。
- **Model、harness 与 metric 漂移：** 多个 model 与 production harness 是 proprietary。API、default、reasoning effort、tool 与 provider behavior 可能变化。harness log 的结构不等价，mini-SWE-agent 不提供 token count，而 shell call 可隐藏多个语义 action，限制跨 harness trace comparison。
- **Benchmark exposure 与 fidelity：** 平台没有统一 contamination audit 或 universal split。研究没有复现 Anthropic 的 SWE-Bench Pro memorization screen，也无法使用 Qwen 未发布的 corrected benchmark form。公开 task 与不同 reasoning-effort setting 使 vendor-score matching 和未来 exposure 判断依赖具体 configuration。
- **Selection 与 retention 未知：** 冻结的 298-judge/467-subject inventory、repository exclusion ledger、deduplication key、prompt-scanner snapshot、逐 instance rollout 数、seed、retry 与 failure policy 均未披露。aggregate analysis 包含 failure 并不能证明每条失败 run 都被保留。
- **许可与隐私：** manuscript 采用 CC BY-NC-ND 4.0，但已检查的核心/reference repository 没有核验到统一 license，也没有覆盖 benchmark task、submitted agent、trajectory、log 或 result 的 umbrella grant。remote/hosted mode 可能处理 credential、private service、code 与 execution trace；consent、retention、deletion 与 redistribution policy 不完整。
- **用途边界：** 论文进行 agent evaluation 与 audit，没有用 AgentBeats episode 训练 policy、reward model、process model 或 RL agent。潜在 RL integration 不能支持 training reuse。benchmark performance 也不能证明 data quality、judge validity 或跨 assessment category 的泛化。
