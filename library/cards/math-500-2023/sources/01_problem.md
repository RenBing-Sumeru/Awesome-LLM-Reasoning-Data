Primary source: Lightman et al., "Let's Verify Step by Step," arXiv 2023, plus the official OpenAI PRM800K repository. MATH-500 asks for a lower-cost, fixed evaluation slice of the MATH test set for reporting mathematical reasoning accuracy. The decision boundary is narrow: it is an evaluation subset, not a new problem source and not process-supervision data. The data object is a MATH problem with final answer, solution metadata inherited from MATH, and a final-answer grading contract. Its practical value is a widely reused held-out math evaluation coordinate for verifier and reasoning-model papers.
