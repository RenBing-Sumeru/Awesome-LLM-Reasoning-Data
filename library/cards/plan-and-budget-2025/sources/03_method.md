**Inputs.** The released code loads MATH-500, a local sampled NaturalInstructions JSON, and TravelPlanner validation items; TravelPlanner also carries reference information and requires a separately downloaded database. A preprocessing record can carry `id`, `query`, `reference`, `answer`, `level`, `steps`, and `credits` (official repository: `dataset/*_dataset.py`).

**Construction.** The preprocessing script asks an LLM for two to five ordered sub-questions with hints, explicitly asking it not to reveal an internal chain of thought. It then asks an LLM for JSON difficulty assessments and integer credits that sum to 100 (`dataset/break_down_question.py`). The paper reports LLaMA-3.3-70B-Instruct as the default planner, but the release does not pin the exact endpoint/model that generated each distributed decomposition.

**Allocation and inference.** The planned-local-weighted implementation normalizes credits, multiplies them by constant/linear/polynomial/exponential/cosine schedule weights, floors the resulting shares of the level budget, and assigns any remainder to the largest weighted shares. The level-to-budget table is 1→200, 2→250, 3→350, 4→450, and 5→600. It embeds each sub-question and a requested word limit in one prompt to the target model; this is prompt guidance, not a hard per-subquestion token cap (`inference/_5_planned_local_weighted_model.py`). The repository supports DeepSeek-R1 distills, QwQ-32B, s1.1-32B, Llama-3.3-70B-Instruct, o3-mini, and o4-mini interfaces, while the paper's reported comparison matrix is narrower.

**Evaluation/output.** Each local run emits `prediction`, prompt/completion/total tokens, `score`, and `explanation` per item, then aggregates score and completion tokens (`run/run_inf.py`). MATH uses `math_verify`; NaturalInstructions computes ROUGE-L; TravelPlanner uses secondary-LLM JSON reconstruction followed by its evaluator. The paper reports five-run means and standard deviations, allocation schedules, and an 8,192-token hard cutoff. It does not publish executed result files, full prompt/model configurations, retries, or a selected/rejected rollout ledger.
