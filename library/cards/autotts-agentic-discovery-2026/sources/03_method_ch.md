对每个问题，方法从基础模型预先收集 128 条独立推理轨迹，并以 500 词元为间隔切分，同时收集中间答案探针。控制器状态包含问题、已实例化且活跃的分支、前缀、深度、已揭示探针和剩余预算。其原子动作是 BRANCH、CONTINUE、PROBE、PRUNE 和 ANSWER。终止聚合规则把状态转成答案，目标函数奖励精确准确率，同时惩罚生成和探针成本。

作者使用 AIME24 作为发现集，并保留 AIME25 和 HMMT25 用于测试。Claude Code 在五轮中阅读先前代码、准确率—词元曲线和执行历史后提出控制器实现。每个候选都在存储轨迹的随机子集上重复评估 64 次。最终控制器与 SC@64、自适应及早停自一致性、Parallel-Probe 比较，覆盖 0.6B 到 8B 的 Qwen3 模型；随后又在蒸馏 Llama 模型和 GPQA Diamond 上测试，以检验能否超越搜索设置迁移。
