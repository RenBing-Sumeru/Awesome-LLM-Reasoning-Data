AutoDroid 研究的是 LLM agent 如何在 Android app 中完成自然语言任务，而不依赖每个任务的开发者 workflow 或人工示范。主要来源是 arXiv/MobiCom 2024 论文、官方项目页和 MobileLLM 仓库。数据对象是一条 Android task episode：instruction、由 UI tree 转成的 GUI state、候选 action、app-specific memory、状态转移，以及任务成功或 action accuracy 信号。它应归入 Android environment 与 trajectory/evaluation surface，而不是静态 GUI captioning 数据集或纯模型榜单。价值在于把动态 app 分析、LLM prompting 和 DroidTask 可执行环境连接起来。
