AutoDroid is useful as an agent-environment recipe: preserve instruction, app ID/version, GUI tree, simplified HTML, element IDs, action type/value, prior actions, memory entries retrieved, executor result, risk flag, and terminal success. It informs mobile-agent benchmark design because it exposes both step-level action accuracy and episode-level task success. For atlas reuse, keep exploration memory separate from demonstration trajectories and keep automatic success detectors separate from human labels. The risk checklist should include environment drift, app permissions, privacy-sensitive actions, hidden state changes, and public-trace contamination.
