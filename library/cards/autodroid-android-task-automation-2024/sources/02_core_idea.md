The contribution is an Android task automation system that augments LLM prompting with app-specific knowledge discovered through dynamic exploration. The core mechanism is a simplified HTML representation for GUI states, a UI Transition Graph memory, simulated task tables and UI function tables, and query optimization that reduces action choices and prompt cost. The evaluation surface is DroidTask: 158 manually labeled high-level tasks from 13 open-source apps, with GUI action traces, exploration memory, and a reproducible app environment. The feedback contract is environmental: an action is valid if it matches executable UI constraints, and an episode succeeds when the task-specific completion condition is reached. Closest comparisons include prompt-only LLM mobile agents, demonstration-based mobile automation, MoTiF-trained agents, and LLM-framework baselines. The direction label is memory-augmented mobile agent evaluation.
