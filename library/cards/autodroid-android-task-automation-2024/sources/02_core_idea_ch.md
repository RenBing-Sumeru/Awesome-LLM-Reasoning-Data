核心贡献是一套 Android task automation 系统：通过动态探索获得 app-specific knowledge，再注入 LLM prompt。机制包括 GUI 的简化 HTML 表示、UI Transition Graph memory、simulated task table、UI function table，以及减少 action choice 和 prompt 成本的 query optimization。评测面是 DroidTask：13 个开源 app 上 158 个手工标注 high-level task，包含 GUI action trace、exploration memory 和可复现 app 环境。反馈契约是环境式的：action 必须满足 UI 可执行约束，episode 在任务完成条件达成时成功。接近对比是 prompt-only 移动 agent、示范式自动化、MoTiF 训练 agent 和 LLM-framework baseline。方向标签是“memory-augmented mobile agent evaluation”。
