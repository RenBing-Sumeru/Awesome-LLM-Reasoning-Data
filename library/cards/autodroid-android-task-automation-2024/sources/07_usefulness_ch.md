AutoDroid 可作为 agent-environment 配方：保存 instruction、app ID/版本、GUI tree、简化 HTML、element ID、action type/value、历史动作、检索到的 memory entry、executor result、risk flag 和 terminal success。它对移动 agent benchmark 设计有用，因为同时给出 step-level action accuracy 和 episode-level task success。用于 atlas 时要把 exploration memory 与 demonstration trajectory 分开，也要把自动 success detector 与人工标签分开。风险清单包括环境漂移、app 权限、隐私敏感动作、隐藏状态变化和公开轨迹污染。
