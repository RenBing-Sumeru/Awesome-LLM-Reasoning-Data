已有基线包括开发者 intent、人工示范、任务特定 reward 定义或 prompt-only GUI agent。AutoDroid 的变化是让 agent 通过动态探索建立 app memory，再在每一步用简化 HTML 和检索到的 app-specific guidance 做决策。方向信号是带环境反馈的可执行移动端轨迹数据，而不只是 screenshot 或 instruction。质量信号是 DroidTask 的 release 形态：任务、action trace、exploration memory 和用于复现的 Android VM snapshot。不是新的部分包括 LLM prompting、UI-tree 表示和 Android 自动化工具。复用前要检查 app 许可、VM 可用性、task split、success-detector 代码、风险动作策略、隐私处理，以及公开轨迹是否进入训练。
