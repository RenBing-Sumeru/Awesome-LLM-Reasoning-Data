AutoDroid studies how an LLM agent can complete natural-language tasks in Android apps without per-task developer workflows or demonstrations. The primary source is the arXiv/MobiCom 2024 paper, official project page, and MobileLLM repository. The data object is an Android task episode: instruction, GUI state represented from the UI tree, candidate action, app-specific memory, observation transition, and task success or action-accuracy signal. It belongs in the atlas as an Android environment and trajectory/evaluation surface, not as a static GUI captioning dataset or pure model benchmark. Its value is the explicit bridge between dynamic app analysis, LLM prompting, and DroidTask's executable app environment.
