The pipeline begins with 1,186 WebArena-Lite samples containing instructions, oracle trajectories, and reward functions. SFT initializes the actor; the critic copies that model and adds a randomly initialized value head. At each browser turn, the policy input contains the instruction, action history, and simplified current HTML with element IDs. The textual output is one browser operation such as Click, Type, Search, Scroll, tab control, navigation, or Exit.

Curriculum construction runs for 8 phases and retains 500 new instructions per phase. Failed instructions from prior interaction provide seeds to GPT-4o-2024-05-13. The released generator samples up to 10 seeds per site for 2 turns with random seed 42, temperature 1, and top_p 1. Generated instructions must pass a critic window from 0.05 to 0.75 and a GPT-4o feasibility screen. These code settings are verified, but exact end-to-end run seeds, retry behavior, total generations, and rollout multiplicity are not disclosed.

For feedback, original tasks use WebArena-Lite reward functions; those functions label augmented baseline and WebRL rollouts to train the ORM on 12,200 samples. For a generated task, the ORM compares YES and NO probabilities from the instruction, action history, and final HTML and assigns binary 1/0 reward. Processing code serializes step records with observation, next_observation, task, reward, done, action, and trajectory_reward; it can later add mc_return and rank_score. The current phase trains on both successful and failed labeled rollouts.

Historical replay is narrower. Only successful trajectories enter the buffer. The current actor computes action confidence, and records with probability above 0.5 and at most 0.95 are eligible; replay volume is capped at 2 times the current interaction-data size. Actor and critic then receive off-policy updates with a previous-policy KL constraint, discount factor 0.9, and GAE lambda 0.5. Failed trajectories are not replayed, but their instructions remain curriculum seeds.

Reported WebRL settings use actor and critic learning rates of 1e-6, batch size 128, and 1 epoch for each; ORM training uses learning rate 5e-6, 4 epochs, and cutoff length 16,384. Reproduction must also pin the external VAB-WebArena-Lite/browser/site state, task configurations, reset behavior, model revisions, and processing scripts. The paper does not disclose the maximum episode horizon or total environment compute, and the repository does not provide a turnkey historical run manifest.
