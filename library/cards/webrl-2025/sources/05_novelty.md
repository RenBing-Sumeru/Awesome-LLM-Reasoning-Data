Earlier web-agent training work represented by SFT and Filtered BC relies on fixed demonstrations, while DigiRL brings online reinforcement learning to a fixed task collection. WebRL changes the data interface rather than merely increasing model size: failure instructions become task-generation seeds, task difficulty is filtered into a 0.05-to-0.75 critic window, current-policy browser episodes receive learned terminal feedback, and only successful historical records in the 0.5-to-0.95 actor-confidence band are replayed.

The distinctive object is therefore not a single trajectory but a phase-indexed lineage linking failed instruction, generated instruction, initial site state, actor rollout, ORM label, critic estimate, replay decision, and later policy revision. Running 8 phases with 500 retained tasks each turns construction and selection into policy-dependent processes. This is a useful direction signal for reasoning-data research because task source, judge, optimizer, and retention rule co-evolve; auditing only the final checkpoint or the accepted traces would miss the causal data pipeline.

Individual ingredients are not new in isolation: SFT initialization, GPT-4o generation, binary reward modeling, actor-critic learning, KL regularization, and experience replay all have prior lineages. The contribution is their WebArena-specific closed-loop integration plus empirical analysis of forgetting, confidence filtering, and failed replay. Reuse still requires the missing manifests, exact environment state, ORM audit, and rights information; the released models and code do not by themselves make the underlying curriculum data reproducible.
