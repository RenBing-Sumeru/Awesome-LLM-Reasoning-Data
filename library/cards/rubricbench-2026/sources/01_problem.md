RubricBench: Aligning Model-Generated Rubrics with Human Standards defines an evaluation surface in rubric-reward-modeling, judge-reward-meta-evaluation: whether model outputs or agent trajectories satisfy the task-specific feedback contract. The primary source and artifacts are paper: https://arxiv.org/abs/2603.01562; code: https://github.com/planepig/rubricbench; data: https://huggingface.co/datasets/DonJoey/rubricbench; huggingface: https://huggingface.co/datasets/DonJoey/rubricbench; doi: https://doi.org/10.48550/arXiv.2603.01562; the local metadata records the source as 2026 / arXiv preprint.

The decision boundary is benchmarks_evaluation_surfaces with roles benchmark, verifier_reward and verification contract judgment_required. One benchmark instance is: Each record contains case_id, instruction, response_a, response_b, A/B label, domain, source, and expert atomic rubrics derived from the instruction. This is not a model-training recipe unless the paper separately releases training data; the card treats it as evaluation, audit. It matters for the atlas because the reusable object is an evaluation/data record with a named scorer, judge, verifier, reward, or environment predicate rather than an abstract capability claim.
