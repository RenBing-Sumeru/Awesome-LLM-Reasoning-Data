The contribution is to provide a scale that is not fully pinned in local metadata and must be checked against the official release before quantitative reuse for rubric-reward-modeling, judge-reward-meta-evaluation under a reusable evaluation surface. The core mechanism is the pairing of task inputs and model outputs with the following feedback contract: Official evaluator script compares a submitted A/B prediction with the gold label and reports overall and grouped accuracy.

The data object or environment is Rubric-aware pairwise preference evaluation over text/code/math/safety/chat responses. The closest comparisons are reward-model, rubric-judge, and preference-evaluation benchmarks. The direction label is benchmarks_evaluation_surfaces with a judgment_required feedback contract. The main thing to preserve is not only the headline score, but the task object, evaluator, split/version, and artifact lineage.
