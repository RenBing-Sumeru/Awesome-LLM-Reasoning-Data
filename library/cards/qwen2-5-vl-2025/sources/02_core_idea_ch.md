该报告是一份部分训练披露台账，而不是数据发布。报告给出 4.1T token 的模型配置，并说明预训练数据包括清洗后的 raw web 与合成多模态材料。它还描述了约 200 万条的 SFT 混合数据、两阶段过滤、针对推理任务且由预期答案把关的拒绝采样，以及先 SFT 后 DPO 的后训练。

不同阶段的数据对象包括多模态 QA、带坐标的文档 HTML、grounding 标注、视频字幕与时间戳、agent 截图和动作、偏好样本以及被选中的推理候选。反馈从预期答案匹配到规则过滤、模型过滤和偏好训练不等。报告没有发布统一记录 schema、底层样本、训练后的 reward model 或保留/拒绝集合。
