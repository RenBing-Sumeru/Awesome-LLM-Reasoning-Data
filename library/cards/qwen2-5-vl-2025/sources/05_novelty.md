For this atlas, the notable contribution is the combination of a model report with several concrete data-pipeline interfaces. The report connects multimodal pre-training categories to document, video, grounding, and agent objects; it names construction tools and some counts; and it states filtering and post-training stages rather than only reporting model capabilities.

That disclosure remains partial. Its value is therefore not an open data recipe, nor evidence that an agent capability is itself a released trajectory dataset. It is a comparatively detailed case for mapping what a frontier report says about data and feedback against what remains unavailable for independent audit.
