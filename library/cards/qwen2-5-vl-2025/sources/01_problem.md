Frontier model reports can identify stages, aggregate training scale, or benchmark capability without exposing the data and feedback objects needed to audit or reproduce post-training. For a multimodal visual agent, a model release and an agent benchmark result are not by themselves evidence of released trajectories, executable environments, reward contracts, or data provenance.

Qwen2.5-VL is useful for this disclosure question because the official report gives more than a capability narrative: it describes training data categories, selected construction procedures, filtering, rejection sampling, and SFT/DPO. The same report still withholds the source inventories, record-level data, filter/reward artifacts, and audit evidence that would make those descriptions a reusable recipe.
