The report initializes the language component from Qwen2.5 and trains a redesigned ViT from scratch. Its three pre-training stages list 1.5T, 2T, and 0.6T tokens. The disclosed pre-training categories include image captions, interleaved image-text, OCR, visual knowledge, multimodal academic questions, grounding, document parsing, video, and agent interactions. For interleaved data, it reports standard cleaning followed by four internal scoring dimensions; source identities, score implementation, thresholds, and yields are not given.

The report describes constructed grounding material with public and proprietary data, formats such as XML and JSON, and synthesis using Grounding DINO and SAM. It describes synthetic document HTML that includes layout boxes, OCR data that mixes synthetic, open, and in-house material, one million synthetic chart samples, six million table samples filtered by an offline table-recognition model, and long-video captions synthesized from multiple frames. These are project-level disclosures, not released corpora or complete source manifests.

For agent material, mobile, web, and desktop screenshots receive synthetic captions and UI grounding annotations. Multi-step trajectories from open-source data and an agent framework on virtual environments are reformatted into a shared function-call action space. Human and model annotators write a reasoning explanation for each highlighted ground-truth action from the global query and before/after screenshots; a model filter removes low-quality reasoning. The report does not identify every environment, annotator, record, replay state, or task-success predicate.

Post-training reports approximately two million SFT entries, split evenly by entry count between pure text and multimodal data. Queries come primarily from open-source repositories with curated purchased and online-query additions. Qwen2-VL-Instag categorizes QA pairs into eight domains and 30 subcategories, after which rule-based and Qwen2.5-VL reward-model filters score examples. For rejection sampling, an intermediate Qwen2.5-VL candidate is retained only when its output matches a ground-truth expected answer, then receives additional rule/model checks. SFT is followed by DPO on image-text and pure-text preference data with the ViT frozen; preference sources and criteria are unknown.
