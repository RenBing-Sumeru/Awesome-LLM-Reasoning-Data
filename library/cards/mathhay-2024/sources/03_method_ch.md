1. 输入：2024 年 1 月到 8 月的搜索引擎文档，按数值丰富度、上下文信息量和实体丰富度筛选。
2. 生成问题：构造 SSSD、MSSD、SSMD、MSMD 四类任务，覆盖单/多相关文档与单/多步计算。
3. 质量控制：先执行 LLM 生成的 Python 解法，再把问题和相关文档重新交给 LLM 生成另一份 Python 解法并执行；答案一致才保留。
4. 构造 haystack：把相关文档与无关文档混合，控制 32K 到 128K token 的上下文长度，并设置相关文档位置。
5. 输出：论文报告 10 个 topic、40 个 subtopic、673 道问题，其中包含 126 道 verified 子集。
6. 复现边界：需要 pin 文档收集时间、生成模型、prompt、Python 环境、数值答案规范化、上下文长度、文档位置策略，以及使用 verified 还是 unverified 样本。
