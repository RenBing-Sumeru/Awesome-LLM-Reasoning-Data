Use MathHay as a design pattern for long-context math evaluation: separate relevant-document retrieval, numerical grounding, computation steps, and placement robustness.

Preserve topic, subtopic, source document date, relevant document ids, irrelevant document ids, context length, placement depth, task type, question, Python solution, final numeric answer, model output, and verified/unverified status.

For atlas use, it is a useful bridge between benchmark cards and environment-like retrieval tasks. It can inform long-context audit checklists, but any training or reward use needs a stronger artifact, license, and semantic-validation audit.
