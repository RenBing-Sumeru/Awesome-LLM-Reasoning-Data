- SetUpAgent generation code, the reference-command database, full prompts-as-code, system messages, seeds, API retries, and token/cost budgets were not found in the inspected official artifacts. The public SWEBench fork contains evaluator adaptations, not the benchmark-generation implementation.
- Historical reproducibility is incomplete: the exact `uv` version, package-index snapshot, Ubuntu base-image digest, full package manifest, and per-task immutable Docker digests are unknown. Mutable tags can change replay behavior.
- A 95% test-pass threshold is not equivalent to a fully correct setup. The SWA manual audit found 22 fully correct setups among 30 sampled instances, leaving false-positive setup acceptance as a demonstrated risk.
- The terminal predicate is test-relative. Incomplete, flaky, over-specific, leaked, or misparsed tests can produce false positives or false negatives; parser handling of XFAIL/XPASS and missing names is a concrete sensitivity in the inspected branch.
- Current official releases expose 450 SWA and 798 SWEE rows rather than the paper's 535 and 885, without an instance-removal manifest or changelog. Scores and samples can drift depending on the revision used.
- Both Hub releases contain only a public `test` split. The paper reports no complete instance-level overlap audit against other SWE benchmarks and no direct model-training-corpus decontamination check.
- The source repositories were filtered for permissive licenses, but neither dataset release declares a dataset license. Rights and attribution for issue text, PR text, patches, tests, dependencies, and contributor content remain unresolved.
- Failed setups, rejected PRs, parser failures, no-F2P cases, and complete execution logs are not released. This prevents analysis of failure distributions and may hide systematic environment-selection bias.
- The paper's agent evaluation is cost-limited: SWEE and SWE-Full are uniformly subsampled to 535 instances for the main comparison, while some final-version rows use 100-instance subsets. Reported relative gaps should not be interpreted as full-dataset constants.
- Privacy, contributor consent, and governance treatment for public GitHub text and code are unknown. Public availability does not by itself establish permission for benchmark redistribution or downstream training.
