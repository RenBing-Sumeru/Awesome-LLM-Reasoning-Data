已有基线主要是 prompt-only 或启发式 RAG 评测，如 RAGAS、few-shot 闭源 LLM judge，以及更耗标注的抽样人工评测。ARES 的变化是：用合成数据把 judge 做成目标域适配，再用 PPI 给模型预测包上统计置信区间。方向信号在于它把 RAG 组件准则和统计不确定性分开，使配置比较更可审计。质量信号来自 KILT、SuperGLUE、AIS 和真实 RAG 系统上的排序/打分结果。不是新的部分包括二分类相关性/忠实性准则、合成 QA、分类器微调。复用前要检查验证标签质量、领域迁移、语言、合成模型、judge checkpoint、未标注样本构造和代码/数据许可。
