The contribution is an automated RAG evaluation framework that trains lightweight, domain-adapted judges from synthetic data and rectifies their aggregate scores with a small labeled validation set. The core mechanism is: generate synthetic query-answer examples from in-domain passages, train separate DeBERTa-v3-Large binary judges for the three RAG criteria, then use PPI over labeled and unlabeled triples to report scores and confidence intervals. The feedback contract is not free-form preference alone: each triple is accepted or rejected for a named criterion, and PPI estimates the judge error from human labels. The closest comparisons are RAGAS, prompted GPT-3.5 judges, sampled annotation baselines, and EXAM-style RAG metrics. The direction label is statistically calibrated evaluator construction for RAG.
