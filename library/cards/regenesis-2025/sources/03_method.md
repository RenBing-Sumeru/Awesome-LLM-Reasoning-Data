**Inputs.** Start with a model `M`, a training split of instruction/reference-answer pairs `(q_i, a_i)`, and 25 fixed general reasoning guidelines listed in Appendix A.4.1. The main model is Mistral-7B-Instruct-v0.3. Five datasets are processed separately: GSM8K and NumGLUE for mathematics, ReClor for logic, and ARC-Challenge plus StrategyQA for commonsense. GSM8K contributes numerical answers but not its human rationales. Exact dataset revisions and item identifiers are not disclosed. (Paper §3, §4.1.1)

**Generation.** For every instruction and every seed guideline, the same model first writes a task-adapted guideline. It then writes one detailed reasoning structure that should not solve the task, and finally expands that structure into a complete reasoning path and predicted answer. Main generation uses temperature 0.85, producing 25 candidates per instruction. This is a fixed-width sampling scaffold rather than search over a tree. (Paper §3.1, §4.1.2)

**Terminal selection.** Main experiments extract each predicted answer and apply exact match to the reference answer. Paths that fail are discarded. If an instruction has no passing path, the pipeline retries after supplying the reference answer only during guideline adaptation and structure generation; the final path-generation prompt does not contain the answer. This design reduces direct answer exposure compared with STaR, but the intermediate objects may still encode answer-specific information. Table 1 reports that the retry raises mean instruction coverage from 96.2% to 99.4% across the five training sets. From the passing pool, the recipe randomly keeps at most `p=5` paths per instruction. (Paper §3.2, Table 1; Appendix A.1)

**Alternative selector.** For datasets without reference answers, the paper studies self-consistency: sampled answers vote and paths supporting the majority answer are selected. This experiment covers GSM8K and StrategyQA, despite both having references, and therefore demonstrates an alternative mechanism rather than validating truly unlabeled deployment. Majority agreement is not an independent correctness judgment. (Paper §5.2, Table 5)

**Output and training.** The disclosed SFT tuple is `(q_i, r_path_i,j, a_i)`. Main Mistral training uses learning rate `1e-6`, 3 epochs, batch size 16, weight decay 0.1, cosine scheduling, warmup ratio 0.03, and an 8-A100 node with 40 GB per GPU. Appendix A.5.4 gives the same optimizer settings. The Llama analysis uses vLLM for data creation and LoRA SFT with learning rate `1e-4`, 3 epochs, batch size 8, weight decay 0.1, cosine scheduling, and warmup ratio 0.1. (Paper §4.1.2; Appendix Tables 21–22)

**Evaluation.** Fine-tuned models are tested on the corresponding in-domain test split and six OOD datasets: ASDiv, SVAMP, AQuA, BBH, ANLI, and OpenBookQA. Exact-match accuracy is used throughout. Inference CoT uses temperature 0.8; self-consistency draws 15 responses at temperature 0.8 and majority-votes the final answer. Appendix A.2 holds total mixed-training size at 7,000 while combining two, three, or four training datasets, with three random seeds per combination. (Paper §4.1.4, §4.3; Appendix A.2, A.6.1)

**Reproduction boundary.** A faithful reconstruction must pin source-dataset versions and split IDs, the exact 25 prompts and system templates, answer extractors, retry flags, generation seeds, maximum lengths, random-retention seeds, model revisions, and SFT implementation. The paper supplies prompt text and optimizer hyperparameters, but not immutable source snapshots, per-item construction records, total token/compute budgets, retry counts, or released scripts. No official implementation or generated dataset was verified.
