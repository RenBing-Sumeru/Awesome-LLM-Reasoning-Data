The contribution in one sentence is: use the target model to move from 25 task-agnostic reasoning guidelines to task-specific guidelines, then to non-solving structures, and finally to answer-selected complete paths that supervise the same model.

The construction object has four representational layers. A human-written seed guideline names a broad strategy such as decomposition or systems thinking. The model adapts that guideline to the current instruction, expands it into a structure that should organize but not solve the task, and then instantiates the structure as a step-by-step path plus predicted answer. The same target model produces all three generated layers. The selected training record is the complete path, not a separately labeled sequence of valid steps. (Figure 1; Paper §3.1)

The main feedback contract is terminal and programmatic: extract the predicted answer and compare it with the dataset reference answer. A passing answer makes the path eligible; up to five eligible paths are retained at random. The verifier observes final-answer agreement but cannot observe whether intermediate statements are valid, necessary, faithful to the model's computation, or free of answer-conditioned rationalization. The majority-vote alternative observes agreement among sampled answers, not correctness. (Paper §3.2, §5.2)

The closest self-training comparisons are LMSI and STaR. LMSI uses few-shot CoT examples and majority vote, with a ground-truth-filtered variant added by the authors; STaR directly samples chains of thought, filters by answers, and exposes hints during path generation for failed items. ReGenesis changes the pre-path representation and moves its retry hint upstream: only guideline adaptation and structure generation receive the answer, while final path generation does not. Self-Discover is a closer representation-level precursor because it composes reasoning structures, but ReGenesis turns the abstract-to-concrete chain into selected post-training data for the same model. The novelty is this construction interface and hint placement, not the individual ideas of CoT, answer filtering, self-consistency, or SFT.
