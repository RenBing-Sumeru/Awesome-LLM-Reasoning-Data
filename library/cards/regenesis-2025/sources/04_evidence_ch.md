最强证据是在明确模型与推理 prompt 下进行的一组受控准确率比较。以下均为作者报告结果；目前未核实独立复现或公开语料审计。

- **域内效用。** 使用 Mistral-7B-Instruct-v0.3 与 self-consistency 推理时，未微调模型在 GSM8K、NumGLUE、ARC-Challenge、ReClor、StrategyQA 上分别为 60.0、38.2、80.6、56.2、80.8；ReGenesis 为 76.6、74.7、85.4、70.6、91.3，平均绝对提升 16.56 个百分点。相同评测列下，STaR 为 66.0、64.5、84.1、63.8、85.9。（Table 2）
- **OOD 效用。** 模型分别在五个源数据集上微调，再到 ASDiv、SVAMP、AQuA、BBH、ANLI 与 OpenBookQA 评测；作者汇总 ReGenesis 相对未微调模型约提升 6.1 个百分点，而对照方法平均约下降 4.6 个百分点。并非每个单元格都提升：NumGLUE 训练的 ReGenesis 在 ASDiv 上从 77.2 降到 76.9，ReClor 训练时从 77.2 降到 76.4，但大多数报告单元格改善。（论文 §4.3、Table 3）
- **组件消融。** 在 GSM8K 训练后，完整 adaptation + structure + path 流程域内得分 76.6，六个 OOD 得分为 81.2/83.9/48.8/69.3/49.5/81.4。移除 structure 时为 66.2 与 76.1/80.3/47.6/53.4/42.1/75.6；移除 adaptation 时为 70.0 与 77.5/80.1/47.2/57.9/43.0/76.4。（Table 4）
- **无参考答案筛选。** majority-filter ReGenesis 在 GSM8K 与 StrategyQA 上为 62.8、83.1，LMSI 为 62.3、79.0，未微调模型为 56.3、80.8。这说明脚手架可以配合一致性筛选，但只覆盖两个任务，且低于主 ground-truth 筛选的 76.6、91.3。（Tables 2、5）
- **模型迁移。** 使用 10,000 条 NumGLUE 样本时，Meta-Llama-3-8B-Instruct 域内从 58.9 升至 79.2，STaR 为 75.6；作者报告六个 OOD 任务平均提升 6.46 个百分点。（论文 §5.3、Table 6）
- **Hint 位置。** 当全部 GSM8K 训练样本都获得 hint 时，仅在 adaptation 与 structure 阶段提供答案的域内得分为 75.7，并在六个 OOD 中五项优于三个阶段都提供答案；两组 OOD 向量分别为 79.3/79.7/50.0/67.3/41.9/77.4 与 78.8/78.4/44.1/69.0/41.3/77.0。这支持最终路径生成不见答案，但没有隔离主流程中只对失败项重试的效果。（Appendix Table 7）

这些实验说明该配方在给定数据集与预算下具有下游效用；它们不能证明每条筛选路径都逐步有效，也不能单独把迁移归因于 25 条准则，更不能替代对未发布生成语料的 lineage 审计。
