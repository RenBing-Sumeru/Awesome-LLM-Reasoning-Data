The central contribution is to turn open-ended website generation into an executable benchmark: natural-language website instructions are paired with operation-level browser tests, and generated websites are scored by running those tests in a UI-agent environment. The core mechanism is a two-part pipeline: curate diverse website instructions from author-created project descriptions, then create and human-refine test cases that cover the instruction requirements while leaving implementation choices open.

The data object is a website-building request together with test cases that specify what to do in the browser and what result should be observed. The feedback contract is YES/NO/PARTIAL from a WebVoyager-style UI agent powered by Qwen2.5-VL-32B-Instruct; weighted accuracy counts YES as 1 and PARTIAL as 0.5. Appearance quality is a separate 1-5 judge signal, not the same as functional test success.

The closest comparisons are repository repair and coding benchmarks such as SWE-Bench, SWE-Bench Multimodal, SWE-Lancer, and code-generation tests, plus automated website usability testing such as UXAgent. The change is the blank-codebase, user-facing website setting with executable browser operations. Direction label: browser-executed evaluation for website-generation agents.
