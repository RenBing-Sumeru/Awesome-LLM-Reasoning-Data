已有基线多是在代码题、仓库补全、问题修复或已有项目的功能补丁上评测代码智能体。WebGen-Bench 改变的是任务对象：智能体接收非专业用户风格的网站需求，必须从空目录生成可运行的多文件 Web 应用。它也改变了反馈契约：不只看单元测试或问题是否解决，而是用浏览器里的用户操作验收功能，再用独立视觉评分信号评价外观。

方向信号在于把开放生成和可执行行为测试结合起来。这个评测同时触及规划、文件组织、界面实现、动态行为和视觉约束。质量信号来自人工修订的测试用例、公开的界面智能体评测路径、自动标签与人工测试的对齐实验，以及公开代码、数据、模型和生成输出。

不新的部分也要承认：浏览器自动化、界面智能体、提示生成测试、监督微调和网站生成器都不是首次出现。可复用的新意是把这些组件组织成一个有版本数据、可执行测试、公开产物的网站生成评测面。复用前必须检查许可、划分、647/667 数量差异、原始数据字段、外部模型 API 依赖、框架分叉、浏览器和运行时版本、评测提示、超时策略，以及公开测试样本是否进入后续模型训练。
