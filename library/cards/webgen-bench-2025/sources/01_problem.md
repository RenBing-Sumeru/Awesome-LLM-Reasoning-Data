WebGen-Bench asks whether language-model code agents can build an interactive, functional, multi-file website from a natural-language request when no starter code is given. The primary source is the arXiv paper "WebGen-Bench: Evaluating LLMs on Generating Interactive and Functional Websites from Scratch", submitted on 2025-05-06 and revised on 2025-08-11 as arXiv:2505.03733; the official repository and Hugging Face dataset are linked by the authors.

The concrete gap is evaluation: prior repository-level software-engineering benchmarks mostly ask agents to modify or repair existing codebases, while user-facing website builders must choose a stack, create files, implement UI behavior, and satisfy functional and visual requirements from a non-expert instruction. The evaluation surface is a benchmark instance containing one website-generation instruction plus several atomic browser test cases, each with an operation and expected result. Success is not judged by a static answer string; it is decided by a browser-navigation UI agent that executes the test operation on the generated site and returns YES, NO, or PARTIAL, with a separate appearance score for visual quality.

The boundary is important. This work is an evaluation and data-release surface for from-scratch website generation, plus an optional instruction/trajectory resource for supervised fine-tuning. It is not a general theorem prover, not a full-stack production certification suite, and not evidence that a generated website is secure, accessible, legally compliant, or deployment-ready.
