Correctness is relative to the specified browser operation and expected result. A YES label means the UI agent observed behavior matching one test case under the configured environment; it does not certify backend robustness, security, accessibility, cross-browser compatibility, data privacy, or maintainability. PARTIAL labels are especially sensitive to the UI agent's interpretation.

The authors state two explicit limitations: the generated websites are primarily TypeScript, JavaScript, CSS, and HTML, excluding languages such as Python, Java, and Go because of integration complexity; and the training experiment uses supervised fine-tuning rather than reinforcement learning or direct preference optimization. Additional practical limitations include dependency drift, framework forks, generated-site startup failures, browser state, model API changes, screenshots used for appearance grading, and public-test contamination.

The dataset is synthetic and manually curated, which reduces direct copying risk but does not eliminate realism gaps. The MIT license is stated by the paper and HF dataset page, but code and data reuse should still pin the repository commit and dataset revision.
