The paper reports that WebGen-Bench contains 101 website-generation instructions and 647 test cases, while WebGen-Instruct contains 6,667 training instructions. The strongest non-finetuned result in the main table is Bolt.diy with DeepSeek-R1 at 27.8% weighted accuracy; the supervised WebGen-LM-32B model reaches 38.2% after training on 600 filtered trajectories. These numbers support the claim that current agents are far from saturating the benchmark, but they are specific to the tested frameworks, models, prompts, and runtime setup.

Instance-level evidence comes from executed browser test cases: each operation is run on a generated website and the UI agent emits YES, NO, or PARTIAL. The authors compare UI-agent labels with human testing on three Bolt.diy result sets and report alignment rates of 90.3% for Claude-3.5-Sonnet, 86.1% for DeepSeek-R1, and 94.4% for DeepSeek-V3. Appearance scores are cross-checked in the appendix with additional multimodal graders and human scores; the ranking among the three inspected systems remains stable.

The evidence boundary is substantial. Functional correctness is only as reliable as the UI agent, browser environment, generated-site startup, and test-case specification. Appearance score is a judge signal, not a proof of usability. The appendix table for test-case categories sums to 667 while the abstract, method section, and HF dataset card report 647, so any downstream count-sensitive analysis should pin the exact dataset revision and recompute counts.
