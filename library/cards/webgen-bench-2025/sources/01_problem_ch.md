WebGen-Bench 想回答的问题很具体：语言模型驱动的代码智能体在没有起始代码的情况下，能不能根据自然语言需求生成可交互、可运行、多文件的网站。主要证据来自 arXiv 论文 "WebGen-Bench: Evaluating LLMs on Generating Interactive and Functional Websites from Scratch"，初稿提交于 2025-05-06，v2 修订于 2025-08-11；作者同时提供官方 GitHub 仓库和 Hugging Face 数据集。

它补的是评测缺口。SWE-Bench 等仓库级任务主要考察修改或修复既有代码，而网站生成需要智能体自己选择技术栈、组织文件、实现界面行为，并满足非专业用户提出的功能和视觉要求。一个评测实例由网站生成指令和若干浏览器测试用例组成；每个测试用例包含一个用户操作和期望结果。验收不是静态字符串匹配，而是让 WebVoyager 风格的界面智能体在浏览器里执行操作，并输出 YES、NO 或 PARTIAL；视觉质量另由多模态评分器给 1 到 5 分。

边界也要分清：这是一套从零生成网站的可执行评测面，并附带可用于监督微调的数据资源；它不是通用软件认证、不是安全/无障碍/合规测试，也不能证明生成的网站达到生产部署标准。
