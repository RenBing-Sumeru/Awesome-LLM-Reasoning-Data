BigCodeArena turns code execution into part of the human preference-collection interface: users compare anonymized model responses after seeing and interacting with their runtime behavior. A record ties the task, multi-turn dialogue, two candidate programs, sandbox environment and outputs, optional interaction traces, and a four-way vote; execution is behavioral evidence while humans still decide overall preference. The closest comparison is text-only Chatbot Arena-style voting; this work changes the observation surface from static code to executable artifacts. It is a Track 02 resource because the released object is human preference data, later consumed by BigCodeReward for reward-model evaluation.

Open data: BigCodeArena preference subset — https://huggingface.co/datasets/bigcode/bigcodearena-preference-5k. The official BigCode collection also releases the 14K raw sessions and the BigCodeReward derivative; code is at https://github.com/bigcode-project/bigcodearena.
