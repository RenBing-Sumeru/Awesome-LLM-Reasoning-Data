The closest baseline is Chatbot Arena-style pairwise voting, where people judge static text responses. BigCodeArena changes the decision surface by letting users execute, inspect, edit, and interact with candidate code before choosing, while logging the environment and multi-turn context. This is a direction signal because code reward models can be audited against preferences informed by observable behavior rather than source text alone. Its quality signal is the deployed public platform and 4,731 execution-bearing votes retained for ranking. Pairwise voting and code sandboxes are not new independently; their integration into an open multi-turn preference release is the changed object. Reusers must retain execution context instead of flattening records into code-only pairs.
