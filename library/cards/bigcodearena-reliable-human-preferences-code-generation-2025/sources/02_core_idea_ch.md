BigCodeArena 把代码执行纳入人工偏好收集界面：用户在查看并交互运行行为后比较匿名模型回答。一条记录连接任务、多轮对话、两个候选程序、沙箱环境和输出、可选交互轨迹及四类投票；执行提供行为证据，而总体偏好仍由人作出。最接近的对照是 Chatbot Arena 式纯文本投票；该工作把观察表面从静态代码改为可执行产物。它属于 Track 02，因为发布对象是人类偏好数据，随后被 BigCodeReward 用于奖励模型评测。

公开数据：BigCodeArena 偏好子集 — https://huggingface.co/datasets/bigcode/bigcodearena-preference-5k。官方 BigCode 集合还发布 14K 原始会话和 BigCodeReward 派生产物；代码位于 https://github.com/bigcode-project/bigcodearena。
