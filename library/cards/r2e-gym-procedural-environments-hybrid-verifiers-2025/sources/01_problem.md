R2E-Gym: Procedural Environments and Hybrid Verifiers for Scaling Open-Weights SWE Agents defines an evaluation surface in swe-agents, procedural-environments, hybrid-verifiers: whether model outputs or agent trajectories satisfy the task-specific feedback contract. The primary source and artifacts are paper: https://arxiv.org/abs/2504.07164; project: https://r2e-gym.github.io/; code: https://github.com/R2E-Gym/R2E-Gym; data: https://huggingface.co/R2E-Gym; huggingface: https://huggingface.co/R2E-Gym; doi: https://doi.org/10.48550/arXiv.2504.07164; the local metadata records the source as 2025 / COLM 2025 / arXiv preprint.

The decision boundary is environment_agent_trajectory_data with roles benchmark, agent_environment and verification contract environmental, programmatic. One benchmark instance is: repository-level SWE tasks with natural-language task descriptions, executable environments, unit tests, ground-truth patches or commits, agent trajectories, output patches, reward signals, and final SWE-Bench-style outcomes. This is not a model-training recipe unless the paper separately releases training data; the card treats it as evaluation, audit. It matters for the atlas because the reusable object is an evaluation/data record with a named scorer, judge, verifier, reward, or environment predicate rather than an abstract capability claim.
