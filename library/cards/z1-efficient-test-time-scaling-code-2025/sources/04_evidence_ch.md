以下证据是作者报告的模型与预算证据，不是对发布数据行正确性的验证。

- **主评测。** 表 1 报告 Z1-7B 在 MATH500、GPQA Diamond、LiveCodeBench 和 BigCodeBench-Hard 上分别为 76.4、47.5、35.3 和 22.3，四项平均为 45.4。作者称其性能可与 R1-Distill-Qwen-7B 比较，而平均 thinking token 约为后者的 30%。评测对每个问题使用一个温度为 0 的贪婪样本；这并没有披露 teacher 生成温度。
- **预算曲线。** 附录表 8 在不同最大预算下报告：GPQA 为 47.5，实际平均 2,470 thinking token；LiveCodeBench 为 35.3，平均 866；MATH500 为 76.4，平均 1,185。这些点支持预算—性能分析，但不能识别哪些公开训练行导致了该行为。
- **轨迹长度消融。** 在 74M-token 训练预算下，longest-greedy 子集包含 33K 样本，平均轨迹长度 2,216，三任务平均 50.8；shortest-greedy 子集包含 90K 样本，平均长度 807，平均 49.1。完整 107K 设置报告平均 53.1、平均 thinking token 1,507；随机 64K 为 50.1/1,390，随机 16K 为 48.5/1,236。这显示的是该配方内经测量的长度与数量权衡，而不是长轨迹普遍更优。
