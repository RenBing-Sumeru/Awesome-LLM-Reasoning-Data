**Unknown feedback quality.** No execution checker, unit-test result, answer-equivalence rule, judge score, reward, or acceptance label is documented or released. A fluent QwQ-32B-Preview response may contain incorrect code or reasoning. Treating the approximately 3% repetition filter as a quality verifier would be a false positive in the audit; it observes repetition, not task correctness.

**Incomplete construction and selection lineage.** The exact Code Evol-Instruct revision, per-row source IDs, complexity labels, teacher sampling parameters, candidate multiplicity, repetition detector, and rejected generations are absent. Fewer than 1% of retained traces are reported as truncated, but rows carry no truncation flag. Curator inference: without discarded candidates and filtering code, one cannot measure false removals, residual repetition, hidden teacher traits, or selection bias.

**Governance gaps.** The release has only a train split. Dataset and top-level repository licenses are unknown; the ACL paper's CC BY 4.0 license does not transfer to code or data. No training-release decontamination or duplicate-prompt control is documented, and LiveCodeBench's contamination-resistant design is not a substitute for checking overlap between Code Evol-Instruct-derived training prompts and evaluation tasks.

**Budget and generalization limits.** STW can convert a length overrun into a direct-answer continuation, but the 2,048-token failure shows that it can remove reasoning needed for a complex item. Cut-off rates vary substantially by benchmark, so one fixed cap is not uniformly safe. The training mixture is code-related and does not cover many science and mathematics topics; cross-domain benchmark results should not be read as disclosure of a broad training-source mixture.

**Reproducibility and reporting.** Training, evaluation, STW, and ablation selection are public, but teacher generation and repetition filtering are not. Reported benchmark scores have not been independently reproduced in this Card, and LiveCodeBench is reported as 35.4 in Table 3 but 35.3 in Tables 1 and 8.
