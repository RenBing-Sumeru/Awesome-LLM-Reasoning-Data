Z1 addresses a coupled data-and-inference problem: long reasoning trajectories can transfer stronger problem solving through supervised fine-tuning, but indiscriminately long outputs increase test-time cost and may waste tokens on simpler prompts. The paper therefore studies whether a code-focused mixture of shorter and longer teacher responses can train a compact model whose reasoning length is subsequently controlled by an explicit inference budget.

The released object is concrete. The official `Z1-Code-Reasoning-107K` dataset has one `train` split with 107,173 rows in one Parquet shard. Each row contains `id`, `question`, `response`, and `token_num_qwen`; `response` is an unsegmented reasoning-and-answer target rather than separate thinking and final-answer fields. The paper associates simpler prompts with shorter trajectories and more complex prompts with longer ones, but the release contains no simple/complex or short/long label.

This belongs to **Rollout, Search, and Test-Time Trace Data** because trajectory length and the runtime thinking budget are the variables under study. It does not release multiple candidates, rejected generations, search trees, verifier scores, or per-row budget logs. The EMNLP 2025 Industry Track paper, appendices, ACL and arXiv records, official GitHub repository, and official Hugging Face data/model artifacts support an L4 Card; they do not establish correctness, licensing, decontamination, or full construction reproducibility.
