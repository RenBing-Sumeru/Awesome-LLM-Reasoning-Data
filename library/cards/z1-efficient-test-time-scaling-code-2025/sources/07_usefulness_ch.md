对 **Rollout, Search, and Test-Time Trace Data** 而言，Z1 适合作为研究训练轨迹长度如何与推理时思考预算交互的受控基线。研究者可以按 `token_num_qwen` 对 107,173 行发布数据分层，在固定训练 token 预算下复现 longest、shortest 和 random 子集比较，并扫描 `max_tokens_for_thinking`，同时记录自然结束、STW 截断、续写长度、最终正确性和墙钟成本。

它也是区分“响应语料”和“经过验证的 rollout 语料”的实用审计案例。更强的衍生发布应增加上游来源 ID、复杂度与 short/long 标签、截断标志、generator 设置、全部过滤前候选、重复过滤判决、适用时的可执行正确性结果，以及精确的代码和数据 revision。这些字段可使 selector 错误与长度预算归因被检查。

合适的复用类别是：**配方和审计参考；在许可证、来源、重叠与正确性审查完成前，阻止直接训练复用**。公开训练代码原则上允许复现 SFT，但可下载性和基准表现都不能解决权利或逐行质量问题。STW 可作为推理基线，在不同基准上扫描预算；它不应被描述成 verifier，也不能保证强制续写出的答案仍然正确。
