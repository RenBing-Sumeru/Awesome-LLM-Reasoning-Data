**Inputs and generation.** Problems come from Code Evol-Instruct, described as having prompts evolved in depth and breadth. QwQ-32B-Preview generates one released `response` trajectory per row. The exact upstream revision, per-row source identifier, prompt-complexity label, teacher decoding temperature, seed, candidate multiplicity, and raw generation log are unknown.

**Length handling and filtering.** Teacher trajectories are capped at 8,192 tokens. The paper reports removing approximately 3% of samples with repetitive reasoning and says fewer than 1% of retained data are truncated. It does not release the repetition detector, threshold, implementation, discarded-row manifest, or truncation flag. This operation must not be recast as correctness filtering or as a verified deduplication procedure.

**Released output.** The official Hugging Face revision exposes 107,173 rows in one train-only Parquet shard with `id: string`, `question: string`, `response: string`, and `token_num_qwen: int64`. There is no source, difficulty, short/long, truncation, final-answer, verifier, reward, or correctness field. The repository preprocessing uses `question` as the user message, masks its tokens from loss, and supervises the full `response` plus the end marker; the paper deliberately does not split trajectories with paired `think` delimiters.

**SFT and runtime scaffold.** Qwen2.5-Coder-7B-Instruct is fine-tuned for 2 epochs with learning rate 1e-5, 100 warmup steps, cosine decay, bfloat16, global batch 128, FSDP, 836 total steps, and 8 A100-80G GPUs. STW then caps the initial reasoning generation; natural termination proceeds normally, while length termination triggers the fixed direct-answer hint and a continuation. Main evaluations use a maximum of about 4,096 thinking tokens, although exact caps vary by experiment and observed average lengths are lower.

**Reproduction boundary.** Training, evaluation, STW, and length-sorted ablation-selection code are public. Reproduction still requires pinning the checked GitHub commit and dataset revision, reconstructing the absent teacher-generation and repetition-filtering stages, and supplying decontamination and rights checks. No dataset correctness terminal predicate is documented.
