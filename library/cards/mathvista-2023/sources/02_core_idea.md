The contribution is a consolidated and extended benchmark for mathematical reasoning in visual contexts. The core mechanism reuses and normalizes examples from prior multimodal datasets, adds newly collected visual math tasks, and annotates each item along task type, visual context, answer type, and reasoning skill.

The data object is an image plus question, answer, answer type, source dataset, and taxonomy labels. The feedback contract is answer-level scoring through official evaluation scripts, using exact or normalized matching and LLM-assisted answer extraction for some free-form model outputs.

Closest comparisons are VQA-style datasets, chart/table/math diagram datasets, and text-only math benchmarks such as GSM8K or MATH. The direction label is multimodal mathematical evaluation surface.
