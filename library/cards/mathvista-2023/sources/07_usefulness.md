Use MathVista as a schema for multimodal math benchmarks and as an audit checklist for visual reasoning claims. It is useful when a model card needs to separate text-only math ability from diagram, chart, table, and scientific-figure reasoning.

Preserve source dataset, image id/file, question, answer, answer type, task type, visual context type, reasoning-skill label, split, prompt, OCR/caption inputs, raw model output, extracted answer, and evaluator verdict.

For atlas use, MathVista is evaluation-only evidence. It can guide benchmark selection and multimodal evaluator design, but row-level reuse requires image provenance and license checks.
