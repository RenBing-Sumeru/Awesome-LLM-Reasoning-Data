Prior baselines either stress visual recognition without deep math or math reasoning without visual context. MathVista changes the evaluation object by unifying diverse visual math tasks and adding a taxonomy that supports fine-grained failure analysis.

The direction signal is multimodal reasoning evaluation where the model must read the visual scene and compute or infer a mathematical answer. The quality signal is the scale, official data release, GitHub evaluator, Hugging Face dataset, leaderboard, and ICLR oral venue status.

What is not new: individual source datasets, answer matching, and VQA-style evaluation are not new. Before reuse, inspect source-dataset licenses, image provenance, split policy, answer normalization, LLM-assisted extraction behavior, and possible benchmark contamination.
