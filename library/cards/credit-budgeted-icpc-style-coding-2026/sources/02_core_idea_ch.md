USACOArena 的贡献是一个带严格 credit economy 的 ACM-ICPC 风格交互 arena。核心机制是统一记账：生成、测试和 wall-clock time 都消耗预算，agent 必须在探索、调试和最终提交之间权衡。官方 README 说明使用 Hydro-based judging 与 problem-management workflow，并公开 paper configs、competitor configs、problem lists、benchmark CLI 和 reproduction scripts。反馈契约是程序式的：Hydro/题目测试和 USACOArena API 报告决定 judged outcomes，credit accounting 给出分数上下文。最近对比对象是不对每个决策收费的竞赛编程 benchmark。
