The prior baseline is executable coding evaluation that rewards final accepted solutions while treating tokens, testing, retries, and elapsed time as external bookkeeping. USACOArena moves those decisions inside the benchmark via a unified credit budget. The direction signal is resource-aware coding-agent evaluation for large agent swarms and deployment cost. The quality signal is an open Hydro integration, public configs, problem lists, logs/report tooling, and reproduction documentation. ICPC-style judging and token accounting are not new separately. Reuse requires checking problem-content rights, dataset/corpus rights, MIT code scope, Hydro version, hidden/public tests, budget parameters, and whether local tests leak solution strategy.
