Primary source: arXiv:2604.10182, submitted 2026-04-11, with arXiv comments marking ICLR 2026 acceptance; official companion repository is USACOArena. The paper asks how to evaluate autonomous coding agents when every generated token, local test, and elapsed second consumes a limited credit budget. The evaluation surface is an ICPC/USACO-style competition episode with problem statements, submissions, local tests, judge results, time, token/cost accounting, and final reports. It belongs in the atlas as a cost-aware executable coding benchmark, not as a static accuracy-only code dataset. Evidence is bounded by the Hydro-backed judging setup, released artifacts, public configs, and problem-content licensing.
