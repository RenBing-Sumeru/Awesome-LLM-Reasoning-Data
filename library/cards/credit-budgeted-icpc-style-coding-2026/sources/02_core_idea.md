USACOArena contributes an interactive ACM-ICPC-style arena with a strict credit economy. The core mechanism is unified accounting: generation, testing, and wall-clock time all deplete budget, so agents must trade off exploration, debugging, and final submission. The official README reports a Hydro-based judging and problem-management workflow, public paper configs, competitor configs, problem lists, benchmark CLI, and reproduction scripts. The feedback contract is programmatic: Hydro/problem tests and USACOArena API reports determine judged outcomes, while credit accounting shapes the score context. Closest comparisons are competitive-programming benchmarks that measure pass rate without charging each decision.
