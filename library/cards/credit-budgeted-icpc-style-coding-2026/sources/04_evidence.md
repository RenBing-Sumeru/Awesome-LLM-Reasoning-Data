The repository supports this claim operationally by exposing paper-aligned competition configs, competitor configs, problem lists, benchmark scripts, report export, and metric timeline export. Instance-level evidence is a judged submission trace plus credit ledger, not final solved/unsolved status alone. Evidence is bounded by Hydro setup, public problemset release, USACO/third-party content availability, exact budget rules, API model versions, and scaffold decisions.
