Use USACOArena as a schema for cost-aware executable coding episodes. Preserve problem id, public/hidden test policy, judge result, local-test calls, generated token count, elapsed time, credit ledger, model/provider, scaffold, config files, Hydro/problemset version, and final report. It is useful for comparing agent strategies that have similar pass rates but different exploration and spending profiles. For atlas work, keep evaluation reward, training reward, and budget audit as separate fields.
