1. **One-sentence positioning:** A rubric-based benchmark for realistic multi-turn spoken interaction rather than ordinary ASR.
2. **Method takeaway:** Agents generate task blueprints, humans record conversations, annotators review them, and instance-level rubrics grade responses.
3. **Data takeaway:** It contains 452 conversations, 47 speakers, and 1,712 rubrics across four capability axes.
4. **Evidence anchor:** The strongest tested model achieves about 54.65%, with spoken repairs and acoustic-cue memory being hardest.
5. **Reuse decision:** It is suitable for diagnosing voice agents, but judge use of audio evidence must be audited.
