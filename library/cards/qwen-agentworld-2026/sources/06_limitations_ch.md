训练数据披露停留在总规模和来源类别。官方材料没有给出轨迹清单、各来源计数、混合权重、采集日期、任务查询清单、来源许可账本、样本级谱系，也没有公开 CPT/SFT/RL 记录。模型卡中“未使用外部 API 服务输出”的声明只排除了一条采集路径，仍不能确认每条记录的生成者和权利。阶段池互斥与 AgentWorldBench 分布外的说法，也没有公开成员表或完整污染审计支撑。

反馈层同样不完整。SFT 生成器和独立裁判均未具名，其版本、提示、采样设置、阈值和误差行为都是 unknown。RL 的大部分奖励权重来自 LLM 裁判，但裁判身份、校准与聚合行为没有发布。可执行规则只覆盖一个子集，且没有覆盖表或完整验证器代码。论文虽然报告了“自我吹捧”式奖励黑客，并以规则锚定、内容类型分类和严格标签提取缓解，但尚无独立稳健性审计。

已核查的官方产物仅开放 Qwen-AgentWorld-35B-A3B；397B 检查点及其起始谱系仍不可得。Apache-2.0 适用于官方仓库、已发布权重和 AgentWorldBench，不必然覆盖底层训练轨迹与上游语料。论文中的性能结果也不能证明这些未发布记录准确、有代表性、无污染或可合法复用。
