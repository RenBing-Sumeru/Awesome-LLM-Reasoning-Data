Qwen-AgentWorld treats environment simulation as conditional next-observation generation. A system-level instruction specifies the task, action space, optional initial state, demonstrations, and optional simulation instruction. The context then alternates agent actions in user turns with environment observations in assistant turns; given the history and current action, the model predicts one next observation. The unified text schema covers MCP, Search, Terminal, SWE, Android, Web, and OS. Android, Web, and OS states are represented by accessibility trees or UI view hierarchies rather than screenshots.

Training follows “CPT injects, SFT activates, RL sharpens.” CPT learns state-transition dynamics and specialized world knowledge, SFT adds explicit next-state reasoning traces, and GSPO RL optimizes simulation fidelity. SFT draws three candidates per query from an unnamed general-purpose reasoning model and uses an independent judge for best-of-three rejection sampling. RL combines a five-dimension LLM-judge rubric—Format, Factuality, Consistency, Realism, and Quality—with a binary executable verifier on a subset, weighted 9:1 in favor of the rubric.

This mixed feedback contract is partly executable but mostly judge-based. It supports classification as SFT, agent training, and partially verifiable RL; it does not support a claim that the training corpus, judge, verifier, or replayable environments are open.
