The paper treats an LLM-judge verdict as a statistical outcome jointly shaped by the compared answers, judge identity, and bias covariates such as verbosity or self-preference. Bayesian generalized linear models estimate the target comparison separately from systematic bias and return uncertainty rather than a single point correction. The fitted model also supports counterfactual simulations: a user can estimate what verdicts would look like with a selected bias removed, without rerunning an expensive judge. The contribution is an analysis and mitigation framework with an accompanying software package, not a new judge dataset.
