长 context window 并不保证模型能汇总散布在多份文档中的证据并完成可靠多跳分析。已有长上下文 QA 往往既缺少真实的非结构化上下文，也缺少确定正确答案的可执行路径。

π² 从 Wikipedia 表格出发，生成 SQL 与 Python 独立执行结果一致的分析问题，再用真实网页文档替代原表格，并根据上下文和已验证答案反向生成逐步推理。这样得到的数据由结构确定 ground truth，但学生模型必须在普通长文本中完成推理。
