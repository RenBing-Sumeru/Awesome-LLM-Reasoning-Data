FactRBench can compare long-form models along two dimensions—making fewer false claims and providing sufficient coverage—and can evaluate whether factuality judges correctly detect omissions. The VeriFact pipeline is suitable for RAG, report generation, and research QA systems: extract and refine facts, retrieve evidence for each claim, and then calculate precision and reference coverage. Error types such as missing relations, dropped qualifiers, and unclear referents can be converted into training feedback. For open tasks without stable reference answers, recall should be interpreted as coverage relative to the available reference set rather than absolute completeness.
