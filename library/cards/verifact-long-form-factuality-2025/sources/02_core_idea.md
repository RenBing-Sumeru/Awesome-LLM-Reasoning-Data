The paper introduces VeriFact, which identifies incomplete facts, restores necessary context, and recovers relational facts missed by ordinary decomposers, thereby improving the completeness of verification units. The accompanying FactRBench dataset provides reference fact sets for long-form answers, derived from responses by advanced LLMs and human-written answers, enabling factual precision and recall rather than only hallucination-rate measurement. The released records include questions, model responses, extracted facts, reference facts, and related annotations. The contribution is therefore a factuality-evaluation dataset plus an improved extraction pipeline, not a new factual knowledge base.
