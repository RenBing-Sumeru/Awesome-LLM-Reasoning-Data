LNE-Blocking is an inference-time audit procedure that turns a possibly leaked benchmark prompt into a contamination-adjusted evaluation record: the record contains a greedy response, an LNE-derived contamination signal, a selected number of blocking operations, a disrupted response, and its task score. It replaces repeated sampling in contamination mitigation with a single adaptive decoding path, aiming to expose performance less dependent on memorized reference text. The intervention changes generation only for the audit pass, not the model's weights or the benchmark labels. The authors release code, but do not claim to release a new benchmark dataset.
