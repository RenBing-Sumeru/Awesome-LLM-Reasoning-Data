1. **One-sentence position:** SWE-PolyBench provides 2,110 four-language repository tasks and combines test resolution with file and CST localization metrics.

4. **Evidence anchor:** Agent results vary strongly by language and complexity, while localization recall does not guarantee passing tests, revealing multiple independent bottlenecks.
