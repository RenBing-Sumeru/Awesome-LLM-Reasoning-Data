1. **一句话定位：** SWE-PolyBench 提供 2,110 个四语言仓库任务，并把测试解决率与文件/CST 定位指标放在同一评测中。

2. **方法抓手：** 真实 PR、容器构建、F2P/P2P 重放、gold patch 结构解析和 PB500 分层抽样构成数据流程。

3. **数据抓手：** Java 165、JS 1,017、TS 729、Python 199，覆盖 bug、feature、refactoring；每条带环境与结构元数据。

4. **证据锚点：** agent 表现随语言和复杂度显著变化，且定位召回并不保证最终测试通过，说明有多个独立瓶颈。

5. **复用决定：** 适合跨语言评测和 retrieval 诊断；最大风险是分布不均和 gold patch 非唯一，必须分层报告并以执行为主。
