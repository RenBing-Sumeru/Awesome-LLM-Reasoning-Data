Repository-level coding-agent evaluation remains centered on Python bug fixes, with limited Java, JavaScript, and TypeScript coverage and little separation among feature addition, refactoring, and repair. A final test-pass score also cannot reveal whether an agent failed to locate files, missed syntax nodes, or generated an incorrect patch, limiting diagnosis of multilingual systems.

SWE-PolyBench builds 2,110 executable tasks from 21 real repositories across four languages and three change categories and releases a task- and repository-stratified PB500 subset. In addition to Docker-based test outcomes, it computes retrieval precision and recall over files, functions, classes, and concrete-syntax-tree nodes from gold patches, evaluating both terminal resolution and code localization.
