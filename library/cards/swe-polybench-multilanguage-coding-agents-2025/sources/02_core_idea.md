The main contribution is a repository benchmark combining multiple languages, change types, and structured localization metrics. Its 2,110 instances comprise 165 Java, 1,017 JavaScript, 729 TypeScript, and 199 Python tasks categorized as bug fixes, features, or refactorings. Each record includes issue and pull-request information, base commit, gold and test patches, Dockerfile, test commands, F2P and P2P sets, and syntax-node metadata. A task is included only when the gold patch makes at least one failing test pass without breaking preserved tests. SWE-PolyBench500 uses stratified sampling to reduce evaluation cost, and the harness automatically applies agent patches, executes tests, and reports resolve and localization metrics.
