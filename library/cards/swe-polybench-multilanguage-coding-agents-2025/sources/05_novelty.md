Multi-SWE-bench expands language coverage but mainly asks whether an issue is resolved, and standard SWE-bench reporting emphasizes resolve rate. SWE-PolyBench changes both task coverage and diagnostic surface: it includes features and refactorings in addition to bugs and derives file, function, class, and CST-node targets from gold patches to measure localization. It does not change the basic contract of tests as the terminal oracle. Instead, it adds PB500 for cost control and localization metrics so that where an agent fails becomes an explicit benchmark output.
