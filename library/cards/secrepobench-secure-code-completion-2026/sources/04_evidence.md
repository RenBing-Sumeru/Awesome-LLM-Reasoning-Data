The paper evaluates about 28 standalone LLMs and 13 code agents across three agent frameworks on 318 tasks. Code agents substantially outperform models that see only local prompts, yet strong agents still often pass functional tests while failing security checks, or vice versa. SecRepoBench is also markedly harder than prior snippet-level security benchmarks. This supports the importance of repository context and execution feedback, but the tasks focus on C/C++ and selected CWE classes and do not represent all vulnerabilities.
