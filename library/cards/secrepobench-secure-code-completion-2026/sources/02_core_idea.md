SecRepoBench contains 318 tasks from 27 real C/C++ repositories covering 15 CWE categories. Each instance records the repository revision, completion location, context, reference implementation, build and test commands, and security-validation assets. Tasks are extracted from real security fixes or security-sensitive code, verified so that removing the target implementation breaks the baseline and the reference completion compiles, passes developer tests, and survives OSS-Fuzz-style validation. The reward contract is functional correctness plus specified security behavior, not textual similarity.
