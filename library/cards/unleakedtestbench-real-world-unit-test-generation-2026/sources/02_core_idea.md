The main contribution is 3,909 real function-level test-generation tasks plus a paired leaked control benchmark. Functions are extracted from open-source projects and filtered for executability, recoverable dependencies, and cyclomatic complexity, while original developer tests serve as independent oracles. Evaluation includes test accuracy, statement and branch coverage, and mutation score, so the verifier measures not only whether tests run but whether they expose faulty implementations. Pairing ULT with PLT helps separate memorization from genuine generalization.
