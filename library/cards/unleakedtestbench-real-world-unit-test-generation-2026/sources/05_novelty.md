Earlier benchmarks such as TestEval and HumanEval-derived sets mainly ask whether generated tests cover short functions, without treating code complexity and training leakage as central variables. ULT’s novelty is to place unseen real-world functions and paired leaked versions in one design and select more engineering-like code using cyclomatic complexity. It does not introduce a new generator; it changes the evaluation data and causal control so researchers can distinguish reproducing seen tests from understanding semantics and designing new tests.
