Existing unit-test-generation benchmarks often contain structurally simple functions and tests that may appear in model pretraining data, so high scores can reflect memorization and may not transfer to real code. The paper builds UnLeakedTestBench (ULT) from more complex real-world Python functions with release-time or leakage controls and pairs it with PreLeakedTestBench (PLT) for controlled comparison. The task is to generate executable tests for a provided function, not to generate the function itself.
