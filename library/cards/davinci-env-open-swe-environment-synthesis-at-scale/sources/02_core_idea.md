The core data contribution of daVinci-Env/OpenSWE is 45,320 executable Python software-engineering environments covering more than 12.8K repositories. Each environment binds a code revision and task/change to container-build information, tests, and an evaluation script. The authors further collect approximately 13K agent trajectories from about 9K high-quality environments.

The verifier first determines whether images build and tests run, then checks whether the gold modification passes target tests and filters tasks that are too easy, unsolvable, or produce unstable feedback. The data object is therefore not only an issue–patch pair but a launchable environment, terminal test result, and tool-interaction trajectory, supporting SWE-agent SFT, RL, and environment-generation research.
