Reasoning models often improve by producing more thought tokens, but a fixed long budget wastes compute on easy instances and a fixed short budget can cut off a difficult solution. Simple length limits do not distinguish productive revision from repetition, so they can reduce accuracy sharply. The useful decision is not how many tokens a model can produce in general, but whether the current partial reasoning is still adding information that can change the answer.

This paper asks when a running thought trace can be stopped with controlled risk. It treats the growing trace as a nested reasoning tree: each generated segment may add a new branch, revisit one, or backtrack. The decision record contains a prompt, current thought prefix, hidden representations, probe outputs, candidate stopping threshold, token count, final answer, and task result. The aim is to stop only once novel reasoning has plateaued, rather than applying an identical cap to every problem.
