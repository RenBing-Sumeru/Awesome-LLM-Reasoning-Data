The authors monitor a model’s hidden representations as it generates a reasoning trace and train lightweight probes to characterize whether the implied reasoning tree is still changing. At generation steps, these features are converted into an online stop decision. Unlike post-hoc confidence filtering, the rule can actively terminate decoding before the full default thought budget is used. Learn-then-Test calibrates thresholds on a calibration set and supplies finite-sample, distribution-free risk control for the stated decision setting.

The paper considers DeepSeek-R1-distilled Qwen 32B and Llama 70B models plus QwQ 32B. It first uses held-out s1K-1.1 data for in-distribution calibration, then studies transfer to AIME24, GPQA Diamond, and MATH500. A faithful run must record the base-model revision and hidden-state layer, probe features and training split, allowable risk, calibrated threshold, token trace, stop point, answer extraction, benchmark correctness, and latency. It should compare against both full generation and naïve token caps at matched accuracy targets.
