论文以 pass@1 报告 AIME2024、GPQA-Diamond 和 LiveCodeBench。第一阶段 Qwen2.5-72B 分别达到 79.2、65.7 和 63.8，32B 模型达到 75.8、66.3 和 64.2。32B 经过退火后变为 77.9、66.9 和 61.7：数学与科学上升，代码下降。72B 的学习率消融显示，把 8e-5 降到 8e-6 后，AIME2024 从 79.2 降到 72.5，LiveCodeBench 从 63.8 降到 60.2。这些结果支持论文所用配方，但不能证明每条记录或每个难度标签都正确。

官方 Hugging Face 仓库公开了字段模式和 60 个按类别、教师、采样轮次组织的 JSONL 文件，并把数据集标为 CC-BY-NC-4.0。其数据卡同时提醒：每个唯一问题会重复 12 次，部分 `ground_truth` 可能不准确，而且受限于条件只能开源完整数据的一个子集。因此，论文中“已发布全部数据与方法”的宽泛表述不能作为完整性保证。链接的 GitHub 项目树只有论文 PDF 与资源文件，没有端到端 DeepDistill 实现。
