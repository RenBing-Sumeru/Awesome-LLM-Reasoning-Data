Use LIMA as a baseline for a small, auditable SFT pilot: define the desired response style, curate a provenance-preserving instruction-answer set, train one capable backbone, and compare it with a larger uncurated set under the same judge. The output should be a quality-versus-scale curve plus error categories, not a claim that 1,000 is universally sufficient.
