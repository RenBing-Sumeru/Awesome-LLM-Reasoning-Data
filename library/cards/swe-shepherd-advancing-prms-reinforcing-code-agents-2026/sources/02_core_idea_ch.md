SWE-PRM Collection 以 issue、仓库状态摘要、动作历史、当前工具调用或补丁、测试/静态检查证据和步骤奖励为核心。数据从多种代码代理运行中采集，正确与错误动作通过可执行测试、补丁适用性、任务进展和 judge 组合标注。其重点是可重放的软件工程轨迹，而不是普通代码问答。

关键是单条记录能够还原输入、过程状态、反馈依据和接受结果。该工作围绕issue、仓库状态、工具动作、补丁、测试证据和步骤奖励组织数据，使研究者可以追踪标签由何种 verifier、judge、环境或执行工具产生，并将其用于SWE-Bench 轨迹选择与代码代理强化。许可、人工核验、格式和去污染若未披露，应继续标为待核验。
