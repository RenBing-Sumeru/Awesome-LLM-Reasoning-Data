Post-training disclosures often name a model and a safety goal without identifying how prompts, answers, reasoning traces, feedback, and rights connect. For a release that addresses previously blocked topics, the audit questions include how requests are constructed, which models write answers and chain-of-thought, what safety data is selected, and whether any reward or acceptance process is specified.

Microsoft's MAI-DS-R1 release provides a concrete but bounded answer. It identifies a 350K internally developed multilingual construction path and a 110K named Tulu3 safety/non-compliance component, but does not expose records, internal teachers, selection rules, training feedback, splits, or source-level rights.
