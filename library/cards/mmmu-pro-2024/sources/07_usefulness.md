Use MMMU-Pro as a benchmark-audit recipe for multimodal academic reasoning. Preserve fields for question id, subject, visual asset, prompt variant, answer options or target answer, split/revision, evaluator version, and whether the item is standard or vision-only.

It is useful for comparing models under reduced shortcut conditions, testing prompt scaffolds, and checking whether a system's claimed visual reasoning survives a harder evaluation surface.

For atlas reuse, keep model output, score, prompt policy, dataset revision, answer-fix date, and any refusal/invalid-output handling separate from the benchmark metadata.
