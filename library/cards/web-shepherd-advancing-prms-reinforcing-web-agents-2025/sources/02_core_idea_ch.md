训练数据围绕任务、页面状态、动作历史、候选动作、检查表判断与步骤偏好组织。轨迹由网页代理执行产生，同一状态下的动作通过后续页面变化和任务进展比较。训练集合与 WebRewardBench 必须严格分离：前者用于 PRM 和 RL，后者只用于评测，不能作为新的训练候选数据。

关键是单条记录能够还原输入、过程状态、反馈依据和接受结果。该工作围绕页面观测、同状态动作、检查表、过程偏好和终局结果组织数据，使研究者可以追踪标签由何种 verifier、judge、环境或执行工具产生，并将其用于WebRewardBench 与网页代理 RL。许可、人工核验、格式和去污染若未披露，应继续标为待核验。
