Program-of-Thought supervision can delegate arithmetic to Python, but a program written around one set of numbers may silently change its logic when the numbers are perturbed. Existing synthesis also spends another teacher call for each new question, so the decision boundary is whether one checked example can become a reusable, number-independent training object without losing its mathematical semantics.

InfinityMath masks numerical constants, asks a teacher for a generic question and function-style solution, executes the instantiated program, and keeps the record only after answer agreement. This is atlas-relevant because the released object links a source problem, a reusable template, executable reasoning, variable constraints, and answers; its evaluation surface includes ordinary math tests plus GSM8K+ and MATH+ numeric perturbations.
