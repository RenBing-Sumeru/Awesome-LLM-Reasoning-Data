Earlier CoT and PoT corpora usually serialize a solution for one concrete problem, while question-rewrite methods spend more teacher calls to create each variant. InfinityMath changes the supervision object by separating numeric placeholders from a documented function program and retaining the variable constraints needed for deterministic expansion. This is a direction signal because scaling can occur through checked program transformations rather than unconstrained teacher generation, and GSM8K+/MATH+ make numeric consistency an explicit quality surface. Program execution, docstrings, and numeric substitution are not individually new; the novelty is their released, auditable composition, and a single-instance answer check still does not certify the template globally.
