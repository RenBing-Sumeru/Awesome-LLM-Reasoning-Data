- **定位。** WebDevJudge 检验自动 judge 能否复现专家对可部署网页实现的偏好。
- **方法抓手。** 它将 10,501 个来源 query 过滤为 654 个标注对，并以覆盖意图、静态和动态质量的 query 条件化二元 rubric tree 判断。
- **数据抓手。** 代码和数据已公开；WebDevJudge-Unit 新增 502 个用于代码与交互核验的可行性案例。
- **证据锚点。** GPT-4.1 成对一致率为 70.34%，人工一致率为 84.56%；单答案评分为 60.86%。
- **复用决定。** 适合已部署网页的 judge 审计；先固定环境并测量功能等价性和可行性错误。
