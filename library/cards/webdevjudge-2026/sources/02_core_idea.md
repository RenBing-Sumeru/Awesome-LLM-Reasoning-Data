WebDevJudge converts an open-ended web task into a pairwise human-preference record with a query-grounded rubric tree: intention, static quality, and dynamic behavior are decomposed into binary checks. The released code/data benchmark has 654 labelled pairs, plus WebDevJudge-Unit with 502 feasibility tests. It tests LLMs, MLLMs, and planner--executor--summarizer workflows, showing that a plausible critique is not sufficient evidence of executable web quality.
