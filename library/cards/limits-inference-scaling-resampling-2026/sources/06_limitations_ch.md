实证结果只覆盖 HumanEval+/MBPP+ 代码生成和人工编写的单元测试。理论虽可能不依赖领域，但论文并未验证其能迁移到数学推理、LLM 生成测试、学习型 judge、工具调用智能体或交互环境。提示词敏感性、训练污染、候选间依赖、修复循环、多样性选择和 verifier 改进也未被评估。

EvalPlus 扩展测试被当作更强的正确性 oracle，但作者同时识别并排除了疑似 oracle 不匹配。残留的假阴性或假阳性都会改变上限估计。效用实验改变的是假设性的假阳性成本，并未估计真实部署成本，也没有给出普适的安全精度阈值。

复现条件仅部分完备。仓库发布了代码和三份样本包，却没有记录精确 API 模型快照、请求日期、随机种子、完整的任务—模型—尝试 manifest 以及压缩包校验和。MIT 与 Apache-2.0 声明覆盖仓库代码和继承组件，但所有新生成输出的许可证仍未知。检查时也未看到带标签的不可变 release。
