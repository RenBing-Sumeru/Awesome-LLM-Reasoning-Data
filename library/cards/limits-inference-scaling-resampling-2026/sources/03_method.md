For HumanEval+, the authors analyze at least 200 samples per task and model for most models and 1,000 for Command Light; MBPP+ uses 50 samples per task and model. Sampling temperature is 0.8 with EvalPlus defaults otherwise. The pool combines previously released EvalPlus samples for several open models with newly collected samples for Llama 3.1, Phi-3, GPT-4o, and Cohere Command-family models.

Within a budget K, candidates are traversed in order until the first one passes the original tests. The extended suite then classifies that accepted program as a true or false positive. For each K up to 200, the finite-budget study randomly permutes the same stored candidates 1,000 times and evaluates utilities at false-positive cost-benefit ratios 0, 1, 2, 4, and 8. The theoretical appendix models easy and hard task mixtures to explain why conditioning on prior rejection changes the remaining task distribution.

A separate RACE-based branch samples 50 solutions per task, model, and instruction at temperature 0.8 and checks camelCase, snake_case, line-length, and line-comment requirements. The official repository provides analysis notebooks and three linked sample archives for HumanEval+, MBPP+, and code quality. It exposes no tagged release or consolidated manifest; exact API snapshots, seeds, dates, and comprehensive checksums are unknown.
