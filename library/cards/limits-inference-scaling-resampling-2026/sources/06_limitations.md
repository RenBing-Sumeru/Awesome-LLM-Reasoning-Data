The empirical results cover code generation on HumanEval+/MBPP+ with human-authored unit tests. The theory may be domain-agnostic, but transfer to mathematical reasoning, LLM-generated tests, learned judges, tool-using agents, or interactive environments is not demonstrated. Prompt sensitivity, training contamination, candidate dependence, repair loops, diversity selection, and verifier refinement are not evaluated.

Extended EvalPlus tests are treated as the stronger correctness oracle, yet the authors also identify and remove suspected oracle mismatches. Remaining false negatives or false positives would alter the estimated ceiling. The utility study varies hypothetical false-positive costs; it does not estimate real deployment costs or define a universally safe precision threshold.

Reproducibility is partial. The repository releases code and three sample bundles, but exact API model snapshots, request dates, random seeds, a complete task/model/attempt manifest, and archive checksums are not documented. MIT and Apache-2.0 notices cover repository code and inherited components, but the license for all newly generated outputs is unknown. No tagged immutable release was visible when checked.
