The local training object has four fields: a mathematical problem, the correct reasoning steps before the error, a chosen next step, and a rejected next step. Given the same problem and valid prefix, the policy should prefer the corrected continuation to the first erroneous continuation. This changes DPO from answer-level comparison to step-level conditional comparison. It also creates a stricter data requirement: the step boundary and prefix correctness must be trustworthy, otherwise the pair can teach the wrong local transition.
