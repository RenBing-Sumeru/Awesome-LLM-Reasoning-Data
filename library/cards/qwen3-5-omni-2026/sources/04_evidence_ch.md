官方 arXiv v2 报告支持三段预训练、聚合 token/小时数、领域教师构造、paired-query OPD、交互目标、人工偏好训练、规则奖励 GSPO 与 Talker 各阶段。报告还说明模型可通过 API 使用。已核查的卡片产物没有链接到官方下载训练集、偏好集、教师输出集合、交互轨迹集、奖励日志、来源清单或阶段 manifest。

报告包含文本、视觉、音频、音视频、语音、长上下文、推理与智能体任务上的大量评测。它们是特定评测协议下模型行为的证据，不会验证每条训练记录，也不揭示来源权利、语音材料同意程序，或证明后训练反馈栈可复现。API 可用性只能证明服务存在，不能证明训练流水线可获得。
