这项工作包含两个相互关联、但不能混为一谈的数据对象。公开对象是 StructuredOR：共 124 个 JSON 记录，其中 `train/` 下 86 个文件，`test/` 下 38 个文件。每条记录包含 `question`、嵌套的 `label` 和 `objective_value`。`label` 用 `set`、`parameter`、`variable`、`objective`、`constraint` 五个列表组织最终数学模型；其中按对象类型记录名称、描述、数据或定义域、变量类型与可选边界、目标方向与函数，以及约束函数。不同记录之间存在可选键差异。

运行时对象则是一棵未公开的搜索树。BPP-Search 把数学建模压缩为四层：问题；集合与参数；变量；目标与约束。一个基于 Qwen2.5-Math-1.5B 的过程奖励模型为中间候选打分，供贪心或 beam 保留；另一个独立微调的 Qwen2.5-Math-1.5B 成对分类器负责排序完整候选。公开 JSON 保留最终端点和参考目标值，但不包含节点文本、拓扑、被拒分支、PRM 分数、成对比较、检查器输出或搜索预算。
