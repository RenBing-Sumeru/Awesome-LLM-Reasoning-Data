运筹优化建模要求模型把自然语言问题转成数学规划，并保持集合、参数、变量、目标函数和约束相互一致。本文所用的既有公开资源往往只给出问题与目标值，中间建模决策无法用于监督或诊断。论文一方面以 StructuredOR 补充结构化标注，另一方面用 BPP-Search 研究如何在中间建模决策上进行搜索。

对“Rollout / Search / Test-Time Trace Data”方向而言，这同时也是一个发布边界问题。BPP-Search 在 Q -> SP -> V -> OC 的分支树上推理，对中间节点打分、剪枝，并对最终候选队列排序。仅保留最终答案无法说明搜索过哪些替代方案、某个分支为何被淘汰、验证器是否失败，或选中模型消耗了多少推理预算。因此，官方发布应被理解为最终结构化样例，而不是公开的 BPP-Search 轨迹语料。
