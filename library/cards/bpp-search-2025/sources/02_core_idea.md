The work has two linked but distinct data objects. The released object is StructuredOR: 124 JSON records, split into 86 files under `train/` and 38 under `test/`. Each record contains a `question`, a nested `label`, and an `objective_value`. The `label` organizes the final mathematical model into lists named `set`, `parameter`, `variable`, `objective`, and `constraint`; entries carry names, descriptions, data or domains where applicable, variable types and optional bounds, objective sense and function, and constraint functions. Optional-key variation exists across records.

The runtime object is a search tree that is not in the release. BPP-Search compresses mathematical modeling into four layers—question; sets plus parameters; variables; objective plus constraints. A Qwen2.5-Math-1.5B process reward model scores intermediate candidates for greedy or beam retention, and a separately fine-tuned Qwen2.5-Math-1.5B pairwise classifier ranks completed candidates. The public JSON keeps the selected endpoint and reference objective value, but not node text, topology, rejected branches, PRM scores, pairwise comparisons, checker outputs, or search budgets.
