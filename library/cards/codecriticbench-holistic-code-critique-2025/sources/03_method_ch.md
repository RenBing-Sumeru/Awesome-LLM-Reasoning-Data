1. **准备任务与输入：**从与代码批评相关的公开任务、真实模型输出或人工问题中收集样本，并保留参考答案、检索证据、测试用例或评价标准。

2. **生成候选与反馈：**围绕同一输入构造正确、错误或质量接近的响应，通过执行测试、参考比对与人工维度标注形成可比较的候选和初始标签。

3. **核验与筛选：**对边界案例进行规则、执行器、模型或人工复核，删除标签含混、格式异常和可能泄露答案的记录，整理为万级代码生成与代码问答批评案例。

4. **组织使用协议：**按任务、错误类型或能力维度划分数据，并将其用于评测代码critic的定位、解释和修复能力；模型训练仅作为数据有效性验证，不替代构建流程。
