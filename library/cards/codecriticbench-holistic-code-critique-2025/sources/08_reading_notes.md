1. Positioning: CodeCriticBench uses execution tests, reference comparison, and human multidimensional annotation to create specialized feedback for failures that general code critique evaluation misses.

2. Method handle: collect tasks and candidates, generate feedback, verify boundary cases, and organize by capability; label review is the decisive quality control.

3. Data handle: more than ten thousand code-generation and code-QA critique cases, with records centered on inputs, candidates, evaluation evidence, and feedback labels.

4. Evidence anchor: strong models often identify that code is wrong but fail to localize, explain, and repair it completely, with conclusions bounded by model, candidate, and judge configurations.

5. Reuse decision: best suited to evaluating code critics on localization, explanation, and repair; contamination, false positives, and distributional stability must be checked.
