Execution tests show whether code passes, but not whether a critique localizes the defect, explains its cause, and proposes a valid repair. Existing code critics may merely state that a bug exists, miss the decisive fault, or suggest a change that breaks other behavior.

CodeCriticBench collects code-generation and code-QA cases and combines execution tests, reference comparison, and human multidimensional annotation to evaluate localization, explanation, and repair separately.
