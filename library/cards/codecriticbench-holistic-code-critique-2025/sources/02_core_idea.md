The central artifact is CodeCriticBench, containing more than ten thousand code-generation and code-QA critique cases. Each record organizes a task input, candidate response, reference evidence or evaluation condition, and a feedback label, together with fields needed to trace provenance and labeling. The authors use execution tests, reference comparison, and human multidimensional annotation for quality control, making the resource a feedback dataset for training, evaluation, or auditing rather than a generic question-answer collection. Its primary use is evaluating code critics on localization, explanation, and repair.
