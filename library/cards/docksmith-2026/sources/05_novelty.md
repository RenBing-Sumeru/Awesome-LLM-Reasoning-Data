The relevant prior-work baseline is a software-agent pipeline in which repository environments are infrastructure around issue solving and the reusable data object is primarily the task, patch, or general SWE trajectory. DockSmith instead makes environment construction the supervised behavior: specialized agents browse a repository, edit Docker and evaluation artifacts, execute them, observe failures, and repair them. The resulting object exposes how an executable substrate is produced rather than assuming that substrate already exists.

Two mechanisms shape that behavior before training. The loop detector reacts to repeated non-improving agent combinations by forcing diversification, and success memory retrieves validated Dockerfile/evaluation-script pairs from other tasks. After execution success, redundancy filters, per-language token limits, a Dockerfile-derived complexity score, and a 1:2:2 curriculum determine which successful traces contribute to SFT. This links environment interaction, terminal verification, and training selection more explicitly than a release containing only final Dockerfiles or issue-patch pairs.

The contribution is not a new proof of program correctness, a new scalar reward, or a complete replay format. Docker, repository tests, multi-agent orchestration, retrieval of prior examples, supervised fine-tuning, and success filtering are existing components. The concrete change is their organization around an environment-building trajectory and the release of per-agent SFT fragments at nontrivial scale. Scale and engineering integration are part of the result, but they should not be promoted into an unsupported claim of universal novelty.

For reasoning-data research, the direction signal is that the environment can be both the source of observations and the verifier that selects data. Reuse still requires checking whether fragments reconstruct full episodes, whether test success has false positives or false negatives, whether dropped failures are needed, and whether the pinned release carries sufficient environment, lineage, licensing, and security metadata.
