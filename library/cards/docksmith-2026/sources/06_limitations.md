Success-only retention creates a direct selection bias. Failed terminal rollouts are not documented as SFT examples, so the released training view omits unsuccessful endpoints, unresolved repositories, and many recovery paths. A build/test success signal can also be wrong when the evaluation script, activation procedure, patch protocol, exit-code handling, or test coverage is defective. The paper documents several such protocol error classes, but does not report the global false-positive or false-negative rate of the terminal verifier.

The public object is not replay-complete. Its 39,719 rows are per-agent chat fragments tied to 2,876 instances, not 39,719 complete episodes. No deterministic episode assembler, immutable row-to-repository/task manifest, container image digests, dependency locks, repository/evaluator/test-patch hashes, host architecture, network/cache policy, timeout/reset policy, or full terminal-predicate manifest is released. Repository drift and mutable dependencies can therefore change outcomes even when the text fragment is unchanged. The Hugging Face Dataset Viewer also fails with `DatasetGenerationCastError` because conversation and index shards present incompatible schemas, complicating standard loading and automated inspection.

Rights and security remain layered. The dataset card declares Apache-2.0, but upstream repository, PR, test-patch, dependency, and generated-artifact rights are not enumerated. The model page has neither a model card nor a license tag, so the dataset license must not be transferred to the model. No secret/credential scan, malicious-repository isolation, network-egress rule, privacy/consent analysis, or supply-chain threat model is disclosed, even though building arbitrary repositories executes third-party code and package-installation paths.

The reported decontamination operates at repository level. Benchmark snapshots, timestamps, hashes, matching code, and semantic overlap for PRs, issues, tests, or patches are unknown. GPT-5.1 error labels may introduce judge bias, correlated event counts, or rubric mistakes; no human agreement result is reported. Experimentally, Context Retrieval errors rise by 10.9%, shell/environment resolution worsens, and excessive Docker mixing degrades several SWE metrics, limiting any broad claim of uniform improvement.

Version boundaries require explicit handling. The ICML final has 11 authors, whereas arXiv v2 has 13, changes `Luck Ma` to `Lu Ma`, adds Yanhao Li and Yingwei Ma in the final, and drops four arXiv-v2 names. The dataset content commit, current dataset revision, and model revision are separate identifiers. The exact full-episode count, token count, released-model data mixture, generator configuration, optimizer/scheduler, and seeds remain unknown.
