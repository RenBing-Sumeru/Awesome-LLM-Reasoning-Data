数据披露停留在领域标签层面。官方没有给出样本清单、各来源数量、来源许可账本、合成数据占比、采集日期、提示/参考答案格式、推理轨迹保留策略、阶段产率、划分清单或接受/拒绝记录。去污染与基准重叠程序也是 unknown，因此已报告分数不能排除泄漏。

反馈合同不可复现。“ground-truth 真实反馈”没有识别验证器或终止规则。早期 T1-preview 评价器和 reward model 均未版本化或发布，其提示、rubric、权重、聚合、阈值、校准与失败行为缺失。数据回放和策略重置也没有缓冲区语义、周期或消融；所谓稳定性提升没有公开指标定义与基线。

官方 GitHub 仓库承载的是发布页材料而非训练实现，官方 Hugging Face 产物则是演示 Space，而非可下载权重或实质性模型卡。T1 的确切参数量、基座快照、最大上下文、训练算力、模型许可、安全数据和部署时推理预算仍是 unknown。后续 TurboS 报告只能作为相关背景，不能证明这些 T1 特定事实。
