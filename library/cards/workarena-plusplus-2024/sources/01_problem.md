WorkArena++: Towards Compositional Planning and Reasoning-based Common Knowledge Work Tasks asks how to close this gap: Agents can pass atomic workplace tasks while still failing compositional planning, reasoning, memorization, and multi-step enterprise workflows. The primary source is https://arxiv.org/abs/2407.05291; public status is arXiv; official WorkArena GitHub labels NeurIPS 2024 (2024).

Decision boundary: It is collected as a compositional enterprise web-agent benchmark and trace-generation direction, not as proof that generated traces alone verify success. The evaluation surface is a composed workplace goal, ServiceNow state, browser observations, intermediate action/observation trace, generated ground-truth trace when available, and terminal success predicate. This makes the paper useful for the atlas because the data object and feedback rule can be audited together.
