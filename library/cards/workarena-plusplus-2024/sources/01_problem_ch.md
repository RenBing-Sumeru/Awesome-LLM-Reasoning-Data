WorkArena++: Towards Compositional Planning and Reasoning-based Common Knowledge Work Tasks 回答的问题是：智能体可能通过原子办公任务，但仍无法完成组合规划、推理、记忆和多步企业 workflow。主来源是 https://arxiv.org/abs/2407.05291；公开状态为 arXiv; official WorkArena GitHub labels NeurIPS 2024（2024）。

决策边界：它应作为组合式企业网页智能体基准和轨迹生成方向收录，不证明生成轨迹本身就能验证成功。评测面是：一个任务包含组合式工作目标、ServiceNow 状态、浏览器观察、中间动作/观察轨迹、可用时的生成 ground-truth trace，以及终止成功谓词。它对 atlas 的价值在于任务对象和反馈规则可以一起审计。
