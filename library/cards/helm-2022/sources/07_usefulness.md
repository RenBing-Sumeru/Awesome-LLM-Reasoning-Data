Use HELM as a schema and engineering reference for benchmark suites that need provenance-rich, multi-metric evaluation. Preserve scenario ID, split/version, prompt template, adapter settings, model identifier, decoding parameters, raw output, metric code version, score, and run timestamp.

For the atlas, HELM is useful for distinguishing evaluation-only evidence from feedback that could train a model. Its design also provides a checklist for reporting non-accuracy dimensions when comparing reasoning systems.
