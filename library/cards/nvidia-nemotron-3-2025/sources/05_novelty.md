Nemotron 3 is notable not merely for releasing model weights, but for exposing several layers that are often collapsed in frontier reports: a family-level multi-environment RL design, open post-training software, documented data classes, selected released training data, and an explicit redistribution-rights boundary. The Nano documentation makes private, gated, and publicly accessible material visible as different release states instead of implying that all named data is equally open.

For this atlas, the important contribution is an auditable disclosure pattern. The public reference recipes and data catalogue are useful artifacts, but the repository explicitly distinguishes them from reported runs that included additional proprietary data. This makes the work a strong example of why an open recipe can be evidence about method while still not being evidence of full-report reproducibility.
