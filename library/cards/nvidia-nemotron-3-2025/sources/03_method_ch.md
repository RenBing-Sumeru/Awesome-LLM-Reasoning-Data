家族 RL 环境覆盖数学和科学推理、竞赛编程、指令遵循、软件工程、搜索、聊天、通用智能体工具使用和长上下文任务。报告称所有这些任务族被同时训练。它描述了训练与推理解耦的异步 RL，利用模型吞吐量生成 rollout，并采用 GRPO 与 masked importance sampling 来处理 rollout policy 差异。

对 Nano，官方模型文档描述了公开、爬取、合成、私有第三方和 NVIDIA 内部来源的混合。它称合成后训练记录可包括由强教师模型和 agent 系统蒸馏的轨迹、解答和翻译。文档描述了移除畸形样本和重复推理的质量控制、自动编译器/数值/语言检查，以及定向内容过滤。精确 prompt、逐来源混合权重、教师路由、产出比例、拒绝记录以及分配到 Nano、Super 或 Ultra 的关系仍为 unknown。

公开发布边界具有实质影响。Nano 权重和选定的最终预训练、后训练数据被发布；模型卡说明样本无需门控，而剩余的代码、数学和多语言数据需要门控与批准。NVIDIA 开发者 recipe 是开源数据 reference implementation，NVIDIA 说明其结果会不同于使用额外专有数据的技术报告 benchmark。Nano 文档列出了私有第三方和 NVIDIA 内部数据，但它们未向公众开放。
