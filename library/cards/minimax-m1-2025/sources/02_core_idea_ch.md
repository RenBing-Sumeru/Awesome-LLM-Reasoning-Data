训练路径被明确分成多个阶段。MiniMax-Text-01 先继续训练 7.5T 非合成 token，其中 STEM、代码、书籍和推理相关内容提高到 70%，上下文从 32K 逐步扩到 1M。随后，Long-CoT SFT 在数学、代码、STEM、写作、问答和多轮对话上注入反思式推理；数学与代码约占该混合的 60%，但总规模、具体来源和回答作者均为 unknown。

RL 先使用能够通过规则或执行检查最终结果的任务。数学采用答案抽取与校验，SynLogic 为 41 类逻辑任务提供生成器与验证器，竞赛编程依赖测试，软件工程则在容器中执行模型提出的修改并运行相关测试。之后再加入 25K 条通用提示，由 Generative Reward Model 或规则与模型的组合反馈评分。

CISPO 是把这些反馈机制连接起来的优化框架。它裁剪重要性采样权重而非 token 更新，采用组相对优势、动态采样、长度塑形且不使用 KL 项。课程从规则可验证推理开始，逐步混入模型评分的通用任务。进入 80K 阶段后，40K 模型用于过滤简单提示，更困难的数学与代码提高权重，容易重复的合成推理数据则被降采样。

这种组合比只发布权重提供了更多信息，但仍停留在报告层。官方制品包含 40K/80K 权重、模型代码与部署指南，却不包含训练记录、奖励模型、rollout 历史、执行环境包或精确训练实现。
