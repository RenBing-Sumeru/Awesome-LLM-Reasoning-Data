The data-recipe contribution is the disclosed combination of feedback regimes at long output lengths. MiniMax-M1 places final-answer rules, task-specific logic verifiers, programming tests, containerized software execution, five-grade Generative Reward Model judgments, pairwise reference comparisons, and constraint checks inside one progressively mixed RL curriculum. Reports often name an optimizer while leaving this feedback composition vague; here the categories and approximate counts are visible.

CISPO changes the optimization interface by clipping importance-sampling weights rather than dropping token updates. This matters for long traces because low-probability reflective tokens can otherwise lose gradient contribution during repeated off-policy updates. Hybrid Lightning Attention simultaneously lowers rollout cost, while staged 40K-to-80K expansion and data reweighting make output budget a curriculum decision rather than only an inference option.

The software-engineering component also broadens the target data object from answer-only questions to environment-backed interventions. Public GitHub issues and pull requests become containerized tasks with faulty code and tests, and runtime outcomes provide feedback. The report thereby exposes a concrete bridge between RLVR and agent training, although the actual environments are not released.

None of the ingredients alone is new: long reasoning SFT, GRPO-style relative advantage, rule rewards, execution tests, reward models, difficulty filtering, and curriculum learning all have precedents. The distinctive contribution is their large-scale disclosed composition with open 40K/80K weights. It should not be described as an open training recipe because data, verifiers, environments, reward artifacts, and training implementation remain incomplete.
