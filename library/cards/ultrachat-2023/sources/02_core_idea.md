UltraChat's main contribution is to scale synthetic conversation construction by separating user demand into **Questions about the World**, **Creation and Writing**, and **Assistance on Existing Materials**, then generating contextual exchanges for each sector. Unlike evolved single instructions such as WizardLM, its supervised object is a complete multi-turn conversation in which both sides are model-written. The teacher supplies targets rather than independent correctness feedback, so quality rests on construction controls, corpus analysis, and downstream evaluation.

Open dataset: yes. **UltraChat**, https://github.com/thunlp/UltraChat, contains 1,468,352 English dialogues averaging 3.8 turns and 1467.4 tokens per dialogue. Records are multi-turn user/assistant message sequences grouped by sector and distributed as downloadable JSON files for chat SFT; the paper does not establish factual labels or a per-record verifier, and users must check the repository's current release terms before redistribution.
