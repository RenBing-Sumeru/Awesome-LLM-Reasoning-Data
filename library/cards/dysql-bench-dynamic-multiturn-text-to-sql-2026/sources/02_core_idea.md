DySQL-Bench contains 1,072 tasks across 13 domains from BIRD and Spider 2 databases. The pipeline first converts schemas and table content into hierarchical logic trees, then uses an LLM to synthesize multi-turn user–database interactions. Automated verify-and-refine executes every SQL statement and checks state differences and semantics, followed by expert confirmation; the paper reports 100% data correctness. Records include databases, initial states, turn intents, SQL, execution results, and terminal oracles for multi-turn agent evaluation and execution rewards.
