Static Text-to-SQL assumes a complete one-turn question and usually generates only SELECT queries, whereas real analysis iteratively changes filters, aggregations, and even performs INSERT, UPDATE, or DELETE based on intermediate results. Existing benchmarks therefore cannot test whether database agents preserve state and modify data correctly across turns. The paper introduces DySQL-Bench and a three-party environment where a simulated user changes intent, the model executes SQL each turn, and a real database verifies results and state.
