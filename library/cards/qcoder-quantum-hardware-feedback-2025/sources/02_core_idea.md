QCoder Benchmark releases real contest-based quantum-programming tasks, natural-language problem statements, human code submissions, and a public evaluation API. Candidate code is executed not only in Python but also in a quantum simulator that checks output correctness, supported operations, and hardware constraints while recording circuit depth, execution time, and error category. Human submissions provide a realistic comparison baseline and enable analysis of whether models solve tasks with shorter circuits or better hardware mappings. The core data object is task–code–simulated execution trace–domain metrics.
