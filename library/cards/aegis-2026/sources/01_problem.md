Aegis is published as an ICLR 2026 conference paper; this Card uses the ICLR/OpenReview record, arXiv:2509.14295v6 (27 April 2026), the full paper and appendices, the author project and GitHub repository, and the official Hugging Face dataset as primary sources. The accepted metadata remains `L3_summary_ready`: the bilingual sources provide review-ready depth without upgrading the curation level or pre-populating a human Review decision.

The concrete problem is error attribution in a multi-agent system (MAS). A terminal task failure does not say which agent introduced the fault or which failure mode occurred, while naturally occurring failures rarely come with controlled ground truth. Aegis constructs such supervision by starting from a successful MAS trajectory, deliberately perturbing selected agents, retaining the resulting episode only if the task evaluator changes the outcome to failure, and using the injection plan as the attribution target (Paper §§4–5).

One released object is a failed full episode, not one injected error. The public JSONL viewer exposes top-level `id`, `metadata`, `input`, `output`, and `ground_truth`: visible records include the task/query, serialized conversation history, framework/benchmark/model/agent-count metadata, `output.faulty_agents` entries with agent name, error type, and injection strategy, plus the correct answer and injected-agent provenance. The corpus contains **9,533 faulty trajectories** and **24,843 individual injected-error instances** across 14 MAST-derived modes—about 2.6 injections per trajectory. Treating 24,843 as a trajectory count would misstate the data object.

This belongs in `environment_agent_trajectory_data` because the supervision attaches to a complete interaction trace produced by one of six MAS frameworks—LLM Debate, MacNet, AgentVerse, DyLAN, SmolAgents, and Magentic-One—operating on MATH, GSM8K, HumanEval, SciBench, MMLU-Pro/MMLU, or GAIA. The environment/evaluator determines whether the intervention changes the terminal outcome, while the trace supplies the evidence from which a model predicts faulty agents and error modes.

The decision boundary is narrower than “replayable agent environment.” The verified release is primarily an offline JSONL corpus plus construction and evaluation code; exact GPT-4o-mini snapshots, evaluator versions, reset state, baseline-to-variant links, and a cross-artifact manifest are not pinned. Aegis supports the paper's SFT, GRPO/RLVR, contrastive, and evaluation studies, but it does not establish generic agent training, process supervision, preference learning, or immutable end-to-end replay.
