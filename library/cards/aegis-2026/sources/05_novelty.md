Prior multi-agent diagnosis can evaluate terminal success or ask a model to identify a faulty participant, and Aegis inherits its 14-mode taxonomy from MAST. Prompt injection, response corruption, SFT, GRPO, contrastive objectives, and the six source benchmarks or MAS frameworks are not individually new. The relevant baseline is therefore sparse or naturally observed attribution data, not the absence of any earlier multi-agent evaluation.

Aegis changes the data object by pairing a complete failed MAS episode with a controlled intervention record: selected agents, error modes, injection strategy, correct answer, and planned provenance. It changes selection by requiring a paired successful baseline and retaining only perturbations that reverse the task evaluator's outcome. This connects a trace, a terminal predicate, and an attribution target in one post-training object rather than treating failure as an unlabeled transcript.

The feedback interface has two layers. Construction uses heterogeneous task evaluators to decide whether an intervention enters the corpus; GRPO converts structured agent/error agreement into a normalized scalar reward with partial credit and penalties for malformed, duplicate, false-positive, or excessive outputs. DCL adds turn attention and agent/error prototypes to reuse the same episode-level labels. The important direction signal is this alignment of intervention, retention, structured target, and downstream reward—not any one optimizer.

The main engineering contribution is breadth: 9,533 failures, 24,843 injections, six task families, six MAS frameworks, and 14 modes. Scale does not resolve the epistemic boundary. Because the label equals the planned intervention, the release knows what was changed, but it does not prove which change was necessary when several agents are perturbed or capture unexpected emergent failures outside the taxonomy.

Before reuse, researchers should verify the complete nested JSONL schema, whether successful baselines used as DCL anchors are public, the discarded-attempt ledger, grouped split isolation, DyLAN refinement, exact evaluator and GAIA judge versions, model snapshots, upstream rights, and a manifest binding paper/code/HF revisions and hashes. Those checks determine whether the novelty is usable as training data, an attribution benchmark, or only a construction/audit reference.
