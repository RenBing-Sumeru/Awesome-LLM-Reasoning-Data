The contribution in one sentence is: Aegis turns deterministic successful MAS runs into evaluator-confirmed failed episodes whose planned agent/error interventions become episode-level attribution labels, then exposes those labels through SFT, structured GRPO reward, contrastive learning, and benchmark evaluation.

The mechanism separates intervention from verification. An adaptive LLM manipulator reads the task and agent roles, chooses prompt injection or response corruption, and creates a unique plan of target-agent/error-mode pairs drawn from 14 MAST-derived modes in three families: specification issues, inter-agent misalignment, and task-verification failures. The perturbed MAS executes normally; the planned labels enter the corpus only when a task-specific evaluator observes that the previously successful task now fails. DyLAN receives an additional post-hoc label-refinement step whose procedure is not disclosed in enough detail for independent audit.

The feedback contract is **mixed**. Math uses normalized numeric/LaTeX comparison, HumanEval executes tests with a timeout, SciBench applies unit-aware numeric tolerances, and MMLU-Pro extracts choices A–J. GAIA first extracts an answer and then uses GPT-4o-mini for semantic judgment. These checks observe terminal answer behavior under benchmark-specific rules; they do not directly verify every intermediate turn, prove that each injected error was necessary, or rule out evaluator false positives and false negatives.

For GRPO, feedback shifts from construction-time terminal failure to an output-level scalar reward. Predicted and gold JSON are parsed into agent/error pairs: exact pairs receive full credit; a correct agent or correct error can receive non-repeatable partial credit; malformed JSON, duplicates, false positives, and excess outputs are penalized; the score is normalized before optimization (Paper §5.2; Appendix C.2). This reward checks structured attribution, not whether the model reconstructs the causal chain turn by turn.

The nearest evaluation contrast inside the paper is Who&When, used as an out-of-distribution attribution benchmark. Aegis-Bench is sampled from the same six source task families as training and validation, whereas Who&When tests transfer to naturally presented failures. The key difference is that Aegis labels are generated by controlled intervention and retained terminal failure; this yields scalable labels but does not establish counterfactual causal ground truth for emergent or multi-cause failures.
