The contribution is to provide a scale that is not fully pinned in local metadata and must be checked against the official release before quantitative reuse for os-agents, personal-computer-use, linux-desktop under a reusable evaluation surface. The core mechanism is the pairing of task inputs and model outputs with the following feedback contract: MyPCBench rubrics, judge/scorer, and environment checks.

The data object or environment is personal digital-life Linux desktop with simulated logged-in web apps. The closest comparisons are agent-environment, tool-use, and benchmark-harness papers in the same atlas category. The direction label is environment_agent_trajectory_data with a environmental, mixed feedback contract. The main thing to preserve is not only the headline score, but the task object, evaluator, split/version, and artifact lineage.
