MyPCBench: A Benchmark for Personally Intelligent Computer-Use Agents defines an evaluation surface in os-agents, personal-computer-use, linux-desktop: whether model outputs or agent trajectories satisfy the task-specific feedback contract. The primary source and artifacts are paper: https://arxiv.org/abs/2606.16748; project: https://mypcbench.com/; code: https://github.com/ljang0/MyPCBench; data: https://huggingface.co/datasets/ljang0/MyPCBench; huggingface: https://huggingface.co/datasets/ljang0/MyPCBench; doi: https://doi.org/10.48550/arXiv.2606.16748; the local metadata records the source as 2026 / arXiv preprint.

The decision boundary is environment_agent_trajectory_data with roles benchmark, agent_environment and verification contract environmental, mixed. One benchmark instance is: personal computer-use tasks, app/web states, Docker/QEMU environment, actions, rubrics, and dataset records. This is not a model-training recipe unless the paper separately releases training data; the card treats it as evaluation, audit. It matters for the atlas because the reusable object is an evaluation/data record with a named scorer, judge, verifier, reward, or environment predicate rather than an abstract capability claim.
