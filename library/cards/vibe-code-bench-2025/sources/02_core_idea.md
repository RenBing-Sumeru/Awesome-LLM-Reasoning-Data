One-sentence contribution: Vibe Code Bench evaluates whether models can build functioning web applications in a full development environment, scored through point-and-click functional tests and review criteria. The core mechanism is to turn a realistic task substrate into an observable input-output-scoring contract rather than only reporting model impressions.

Inputs come from Web application/product-style task prompts curated by Vals AI.; outputs are Generated application files plus rendered behavior under browser-based checks.; feedback is Point-and-click tests, edge-case workflow checks, and engineer-verified criteria. It belongs under benchmark/evaluation surfaces because the central artifact is the measurement contract. Closest comparisons are other benchmark surfaces in the same domain, but this card should be read at the level of the released task object and scorer rather than as a broad model capability claim.
