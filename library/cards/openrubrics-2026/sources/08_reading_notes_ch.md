1. **一句话定位。** OpenRubrics 用生成的硬规则与原则，使偏好判决可解释。
2. **方法抓手。** CRG 输入 prompt 和排序回答；阈值为 0.5 的偏好一致性决定每条 rubric 记录是否保留。
3. **数据抓手。** 论文报告 35.7K 个指令，并在 Hugging Face OpenRubrics 发布数据和权重；仍须核对当前许可和源数据子集。
4. **证据锚点。** RUBRIC-RM-8B 平均为 70.1，直接 Qwen-3-8B 为 57.7；voting@5 达 73.0。
5. **复用决定。** 适合标签可信的成对奖励建模；先审计文化偏差、标签噪声，以及任务是否需要绝对分数而非成对判决。
