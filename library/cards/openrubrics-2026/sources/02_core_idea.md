OpenRubrics is a 35.7K-instruction collection of prompt-rubric and rubric-conditioned preference records. Contrastive Rubric Generation (CRG) compares chosen and rejected responses to produce two complementary criteria: hard rules for explicit requirements and principles for implicit qualities. A generated rubric survives only if it helps recover the known preference label, turning preference consistency into the acceptance gate. The public Hugging Face release provides datasets and model weights. This changes reward modeling from a direct opaque comparison into a two-stage decision: formulate criteria from the prompt, then judge a response pair against them.
