The official NVIDIA Hugging Face dataset card is the primary source for this release; the linked arXiv report, *NVIDIA Nemotron Nano 2: An Accurate and Efficient Hybrid Mamba-Transformer Reasoning Model* (20 August 2025), supplies the surrounding post-training pipeline. Version 2.0 is dated 20 August 2025, and downloading its files requires agreeing to share contact information.

The concrete problem is not only how to assemble a large mixture across mathematics, code, STEM, chat, and languages, but how to make each retained supervision record auditable: where its prompt came from, which model generated the response, which check accepted it, what rights apply, and which training stage consumed it. Nemotron-Post-Training-Dataset-v2 exposes a large SFT-style record while leaving important source, decision, and run lineage at release level.

A visible row contains `uuid`, `license`, `generator`, `version`, `category`, `reasoning`, and a role/content `messages` sequence. The nine release splits total 6,341,414 rows. This belongs in **Data Construction & Open Release Recipes** because it exposes a concrete packaged data object and top-level construction account. It is not a replayable RL corpus: row-level rewards, rejected candidates, verifier outputs, rollout groups, and SFT/RL/DPO/RLHF stage identifiers are not in the published schema.

The Card reaches L4 through the official dataset page, official citation, full report and appendix, and an official NVIDIA data catalogue. Raw Parquet verification, immutable file manifests, row-level provenance, and decontamination evidence remain unresolved.
