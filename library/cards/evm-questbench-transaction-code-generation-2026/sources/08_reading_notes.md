1. **One-sentence position:** EVM-QuestBench verifies real state outcomes of natural-language transaction code on 107 dynamically instantiated fork-chain tasks.
2. **Method takeaway:** Template sampling, fork snapshots, script execution, state validators, and step decay.
3. **Data takeaway:** Sixty-two atomic and forty-five composite tasks require both code and validators.
4. **Evidence anchor:** Twenty models over five rounds show a persistent gap between atomic precision and composite completion.
5. **Reuse decision:** It fits sandboxed transaction agents and must never be treated as a guarantee of mainnet safety.
