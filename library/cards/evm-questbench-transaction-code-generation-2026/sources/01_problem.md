A single wrong parameter, approval, or call order in a natural-language-generated on-chain transaction script can cause irreversible loss. Existing code benchmarks often use static matching or mock APIs and cannot verify actual EVM state changes. EVM-QuestBench executes model scripts on forked-chain snapshots, dynamically samples addresses and numeric parameters, and uses task-specific validators to inspect balances, approvals, positions, and contract state for both atomic transactions and multi-step workflows.
