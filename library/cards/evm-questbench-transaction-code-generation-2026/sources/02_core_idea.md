EVM-QuestBench contains 107 tasks: 62 atomic scenarios and 45 composite workflows. Template pools define tasks, while evaluation dynamically instantiates numeric values and on-chain objects to reduce hard-coding and memorization. The runner creates an EVM fork snapshot for each run, executes generated scripts, and invokes validators on target state. Composite tasks also apply efficiency decay based on actual actions relative to optimal steps. The release provides templates, runners, and validators for benchmarking and execution-grounded rewards.
