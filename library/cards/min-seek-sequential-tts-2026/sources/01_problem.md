Sequential test-time scaling asks a reasoning model to continue reconsidering a problem through additional reconstruction cycles. A few extra thoughts can improve an answer, but pushing the sequence further often produces repetition, unstable attention, and declining accuracy. The deployment problem is therefore not merely how to make a model think longer; it is how to prevent earlier, flawed self-revisions from overwhelming the useful context as more inference compute is spent.

The paper asks whether a training-free memory policy can stabilize this process over a much wider range of reasoning lengths. It also addresses a systems constraint: retaining every past thought makes the KV cache grow with the sequence and eventually hits the context limit. The desired procedure should preserve enough useful history for another revision while avoiding both attention degradation and the quadratic cost associated with an ever-growing cache.
