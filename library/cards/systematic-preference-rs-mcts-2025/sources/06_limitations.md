The verifier covers structural, lexical, capitalization, formatting, and ordering constraints that can be checked by code. It does not establish factual accuracy, safety, usefulness, coherence, or human preference. MCTS partly compensates during search with policy self-evaluation of content conditions, but that signal comes from the same 8B policy, uses an undisclosed self-consistency count L, and has no reported calibration or independent error analysis. Final pair eligibility deliberately ignores it.

The prompt pipeline is only partly reproducible. The paper does not enumerate every seed dataset or source count, publish few-shot prompts, identify generator revisions, report the all-mpnet-base-v2 revision or similarity threshold, preserve duplicate rejects, or provide item-level source lineage. Training and evaluation use distinct constraint ontologies—the generated training constraints versus IFEval constraints—but the evaluation prompts are generated by the same pipeline and no broader contamination audit or immutable split manifest is supplied.

The sampling contract is incomplete. RS reports N=64 and temperature 1.0, but "non-overlapping" is ambiguous and stage-wise yields are not tabulated as reusable records. MCTS reports depth 5, K=4, M=4, c_puct=1.0, and lambda=0.2, yet omits tree iterations, self-evaluation L, action token limit, terminal rules, total tokens, latency, hardware, and failed-tree handling. Search cost and data yield therefore cannot be compared end to end.

The training dataset size and number of unique prompts are fixed within comparisons but their numeric values are not disclosed. DPO beta, batch size, full optimizer details, hardware, seeds, and checkpoint selection are also missing. Experiments use only Llama-3.1-8B-Instruct and code-verifiable instruction-following, limiting transfer to larger models and open-ended preferences.

Open access to the paper is not an open data release. The official ACL page provides the CC BY 4.0 paper, DOI, and BibTeX, but no official code repository, generated-prompt dataset, preference pairs, verifier implementation, search trees or logs, rejected candidates, checkpoints, or release license was confirmed. The reported 48K is a rounded experimental prompt count; the exact table total is 47,198, not a published dataset size.
