RefactorBench provides 100 manually designed refactoring tasks in real repositories. Each task is tied to a fixed repository snapshot, three natural-language instructions with different specificity, and AST-level validation tests. The three instructions are independent and can be combined within the same repository to create longer tasks, controlling instruction detail and compositional depth. It is not a large training dataset, but a state-reasoning benchmark for coding agents with a state-aware SWE-agent baseline that explicitly represents completed actions.
