Benchmarks such as SWE-bench focus on issue repair and final test success. Their repository state is complex, but instruction specificity and compositional length are difficult to control systematically. RefactorBench changes the evaluation axes by providing three instruction variants for the same real refactoring, composing non-conflicting tasks, and using AST assertions to locate missing structural changes. The novelty is not repositories or agents themselves, but making preservation of past actions a controlled variable for comparing state-aware and state-agnostic agents on the same tasks.
