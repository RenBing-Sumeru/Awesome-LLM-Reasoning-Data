Under base instructions, the baseline coding agent fully solves only 22% of tasks, whereas a human developer limited to five minutes per task solves 87%, indicating that the benchmark is not a collection of trivial syntax edits. Success rises from 12% with lazy instructions to 27% with descriptive instructions, showing that missing information matters. Adding explicit state representations to SWE-agent yields a 43.9% average relative improvement across instruction settings. These results support state forgetting as an important failure source, but human time limits, agent budgets, and model capabilities differ, so the entire gap cannot be attributed only to state modeling.
