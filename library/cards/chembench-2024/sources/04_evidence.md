The arXiv abstract reports more than 2,700 curated question-answer pairs, evaluations of leading open and closed LLMs, and the finding that the best models outperformed the best human chemists in the study on average. The same source also reports failures on some basic tasks and overconfident predictions, which is the key audit signal. The official GitHub README verifies the reusable package path: `ChemBenchmark.from_huggingface`, model-specific `PrompterBuilder`, `benchmark.bench`, and `save_topic_reports`. Row-level evidence is a scored answer under the released metric, not the aggregate claim that a model is "superhuman."
