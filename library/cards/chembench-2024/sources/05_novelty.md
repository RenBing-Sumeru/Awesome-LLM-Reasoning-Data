The prior baseline is broad academic QA or isolated chemistry prompts that do not provide a maintained chemistry evaluation harness. ChemBench changes the object to a domain-specific suite with curated QA, topic reports, package-level runners, and chemist baselines. The direction signal is that expert-domain reasoning benchmarks need calibration and confidence auditing, not only accuracy. The quality signal is the public Python package, arXiv paper, and Zenodo/Hugging Face-style artifact path recorded by the project. What is not new: automatic QA scoring and prompt-based model evaluation. Reuse checks should cover task provenance, answer-key exposure, topic balance, package version, dependency constraints, license, and whether the questions are already in model pretraining data.
