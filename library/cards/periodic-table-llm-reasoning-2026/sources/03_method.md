The input is the surveyed research literature. The method organizes papers by reasoning paradigm, then synthesizes trends in prompting, architectures, training objectives, reward modeling, and benchmarks, and finally groups recurrent limitations. The output is a structured reference, not a dataset, benchmark harness, or executable method.

No new verifier, reward, judge, environment, code, or data artifact is released. When applying the taxonomy to a concrete system, write down the serialized object first—prompt, trace, answer, tool action, or episode—then identify who generated it and how it is evaluated. Check the cited primary artifact for split policy, hidden tests, model and sampling budget, license, data lineage, and contamination controls; none can be inferred merely from the survey's category.
