The method estimates the chance that a model succeeds under each discrete reasoning level and applies conformal calibration to those estimates. Given a new prompt and a target error tolerance, it selects an appropriate effort level while enforcing the risk-control rule. The result is an inference-time controller; it does not claim to alter the base model's weights or to create new reasoning data.

Evaluation tests whether the controller can choose levels automatically while preserving the requested reliability boundary and using lower effort on easy instances. The official paper is a CAO Workshop at ICLR 2026 oral. No code or data repository is linked in the checked primary record, so a reproduction must recover the calibration split, effort-level interface, and risk metric from the paper before treating the guarantee as portable.
