The contribution is a public, evolving function-calling benchmark that separates syntactic call formation, relevance selection, executable correctness, and multi-turn/agentic tool use. The core mechanism is to run model outputs through category-specific evaluators: AST-style matching for structured calls, executable checks where ground-truth behavior can be run, and scenario-level checks for later BFCL versions. Closest comparisons are API-Bank, ToolBench, Gorilla APIBench, and model-provider tool-call demos. The direction label is tool/API benchmark with an environmental feedback contract.
