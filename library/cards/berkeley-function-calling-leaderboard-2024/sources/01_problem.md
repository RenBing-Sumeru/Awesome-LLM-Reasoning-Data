BFCL asks whether LLMs can produce valid function/tool calls rather than only fluent chat answers. The primary sources are the Berkeley/Gorilla leaderboard page, official BFCL blog posts, the Gorilla GitHub implementation, and the Hugging Face dataset/space. A benchmark instance contains a user prompt, available function schemas or APIs, optional multi-turn context, and an expected call or executable outcome. It belongs here because it exposes tool-use behavior through AST, executable, and agentic checks; it is not merely a preference leaderboard or free-form instruction-following test.
