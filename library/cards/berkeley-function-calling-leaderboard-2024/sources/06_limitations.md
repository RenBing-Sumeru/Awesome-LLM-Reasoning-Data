Correctness is correctness relative to BFCL's schemas and evaluator categories, not proof that an agent can safely use arbitrary external tools. AST matching can miss semantic near-equivalence, while executable checks can depend on package versions, sandbox state, or live API behavior. Hosted-model outputs may change without a model-name change, and leaderboard categories evolve over time. Public examples create contamination risk, while hidden or live components make exact reproducibility harder without the official harness snapshot.
