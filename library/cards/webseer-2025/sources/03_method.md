The input is a multi-hop QA item with one or more ground-truth answers; the paper does not disclose the exact training-source mixture. The environment exposes Google search, a webpage reader that fetches HTML and asks the same language model to answer a page-specific question, a controlled Python executor, and `submit_answer`. During paper training, retrieval is restricted to Wikipedia through Google Site Search and the official Wikipedia API. Paper evaluation instead uses Google Web Search and Jina, while the public repository's inference instructions use Serper. These are related but non-identical environments.

Cold-start construction alternates a reasoner path with a verifier path. A verifier result contains `CORRECT` or `INCORRECT` plus its tool-augmented evidence path. The result is accepted only when that judgment matches ground-truth equality; otherwise the verifier is sampled again up to (K). Accepted failure feedback is appended to the history so the reasoner can try again. A finalized SFT sequence may therefore contain earlier failures and repairs, but instances that never succeed by (n_{max}) are absent. Observation tokens are excluded from the autoregressive SFT loss. The paper does not report (K), (n_{max}), the trajectory-generator identity, decoding temperature, or the underlying prompt mixture.

For SRRL, the reported 14B run starts from Qwen2.5-14B and uses verl. Each step samples 12 prompts with 8 candidate trajectories and at most 30 interaction turns; training runs for 100 reported steps and 60 A800 GPU hours. Figure 2 depicts up to 20 answer submissions, but the numerical score threshold is undisclosed. GRPO with DAPO clip-higher optimizes a trajectory reward combining a safe-zone/hard-limit length penalty with (r\alpha^T), where (r) is a task score and (T) is the number of submissions; (\alpha), length thresholds, seeds, and several optimizer settings are not reported.

The official release currently separates an SFT Parquet repository (`WebSeer-sft-dataset`) from an RL train/test Parquet repository (`WebSeer-dataset`) and provides `WebSeer-14b`. This release layout is distinct from the benchmark sets used to score the method.
