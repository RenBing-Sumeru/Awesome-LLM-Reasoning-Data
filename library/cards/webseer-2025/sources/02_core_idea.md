WebSeer unifies two stages around the same answer-feedback-reflection loop. For the SFT cold start, a reasoner produces a tool-augmented path and an independent verifier uses the same tools to return both a binary judgment and an evidence path. The verifier can be re-queried up to an undisclosed budget (K); its judgment is checked against the known answer, and only episodes that eventually reach a correct answer with a consistent judgment are retained. Fully exhausted or unverifiable instances are discarded.

Self-Reflective Reinforcement Learning (SRRL) then permits multiple answer submissions inside one rollout. Each submission receives task-specific scalar feedback, exemplified by F1, rendered back into the dialogue as text. A below-threshold score allows the policy to continue reasoning. SFT supervises the agent's own reasoning and actions while masking observation tokens; RL attaches feedback to the full episode through answer score, output-length penalty, and an exponential discount based on submission count. This repeated-rollout object is why the work belongs in `rollout_search_test_time_trace_data`.
