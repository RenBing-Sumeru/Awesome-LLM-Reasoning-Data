Search agents trained only from a terminal answer reward can stop after shallow retrieval, and an early query or extraction error can compound across later tool calls. WebSeer studies multi-hop open-domain question answering in which an agent can search the web, query a webpage reader, execute Python, and explicitly submit an answer. Its objective is to make failed submissions recoverable: the agent receives feedback, keeps the same dialogue context, searches again, and revises the answer.

For this atlas, WebSeer is a construction and agent-training recipe rather than a new benchmark. The relevant data object is a multi-turn episode containing model reasoning, tool calls, observations, one or more answer submissions, feedback, reflection, and a termination record. The QA benchmarks used in the paper are evaluation surfaces; they are not evidence that every released trajectory is correct or replayable.
