Keep three boundaries separate while reading: CheckPoint coverage is not final task success; GPT-4 PassRate is not a deterministic environment verifier; API/UI hybrid execution is an evaluation design, not proof that an agent understands a phone like a human user.

Read the dataset and environment sections before the result tables. The important object is the benchmark row and its CheckPoints, not only the aggregate model ranking. For downstream use, keep SAST, SAMT, and MAMT separate because multi-app tasks have different failure modes, especially app switching and long action-history management.

Any comparison should pin the app set, device state, step budgets, and evaluator revision. Aggregate scores are not row-level certificates.
