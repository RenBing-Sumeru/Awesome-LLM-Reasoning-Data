The core contribution is a hybrid API/UI mobile-agent benchmark with process-level CheckPoints, so agents are evaluated on app choice and intermediate execution rather than only on a final natural-language claim. The mechanism changes the old UI-only recipe by letting an action be either click, scroll, input, or an ADB-style API call, and by starting tasks from the phone home screen.

The data object is a mobile task over 29 applications and 103 usable APIs, grouped as SAST, SAMT, and MAMT. The official paper reports 832 data entries: 332 single-app single-task queries, 300 single-app multi-task queries, and 200 multi-app multi-task queries. Real voice-assistant queries seed SAST, while GPT-4 augments complex SAMT/MAMT tasks that are manually reviewed.

The feedback contract is the main direction signal. CheckPoint-l1 checks whether the correct application packages appear; CheckPoint-l2 checks packages, key phrases, and API commands against action history. PassRate is a separate GPT-4-based completion metric. Closest comparisons include AndroidEnv, Mobile-Env, WebShop, ToolLLM-style API evaluation, and Android in the Wild; Mobile-Bench is distinct because it combines real apps, real/augmented user queries, multi-app tasks, and hybrid API/UI execution.
