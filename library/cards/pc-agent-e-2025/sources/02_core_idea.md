The contribution is a trajectory-to-SFT recipe: retain a small human-executed main trunk, ask Claude 3.7 Sonnet to supply missing rationales and nine single-step alternatives at every human state, and train a native screenshot-based agent on the union of human and synthetic thought-action targets.

The core data object has two levels. At episode level, a human task is represented by a task description and a sequence of screenshots and executed keyboard or mouse actions. At training level, each human or synthetic node becomes an independent sample whose input is the current 1280x720 screenshot, task description, and textual history of prior human-trunk thoughts and actions, and whose target is one ReAct-style thought plus one normalized action. Synthetic nodes share the human state and history but do not create a new environment transition; previous screenshots are also excluded from context.

The feedback contract is mixed but must be split by stage. For released and training traces, `finish` and `fail` are terminal action tokens; failed-ending records are removed, and the cleaning code can rewrite the final surviving action to `finish`. This records a construction decision, not independent proof that the Windows task succeeded. Ordinary Claude alternatives receive only syntax and placeholder filtering and are never executed. During evaluation, WindowsAgentArena-V2 separately restores virtual-machine snapshots and applies task-specific evaluators to the resulting application state, with some LLM-based initialization checks and limited human evaluation. The agent's `finish` stops interaction, whereas the benchmark evaluator decides success.

The closest internal comparison is direct distillation from Claude: ten executed end-to-end Claude trajectories per task, 3,120 trajectories total, trained with the same procedure. PC Agent-E instead samples alternatives only at human-visited states, avoiding synthetic branch continuation and its accumulated errors. Human-only thought completion is another baseline. Relative to broad computer-use datasets that collect or simulate full episodes, this work changes the supervision interface to multiple positive action targets per trusted human state; it does not make those targets environment-verified. That distinction is the main direction signal for the assigned track.
