**Inputs and human collection.** A manually composed set of tasks spanning Windows applications is enlarged by undisclosed LLMs. Two annotators execute tasks on their own Windows computers while PC Tracker records screen observations and keyboard or mouse actions. Annotators may discard unsatisfactory runs or revise task descriptions. The retained set has 312 complete trajectories: 74 with 2–5 steps, 139 with 6–10, 73 with 11–15, and 26 with 16–30. Rule cleaning removes failed-ending and null-action records plus redundant or meaningless actions, resizes coordinates and screenshots to 1280×720, and ensures the last surviving step is `finish`.

**Contamination filtering.** Each retained task must have zero 13-gram overlap, 3-gram overlap below 0.7, and cosine semantic similarity below 0.85 against every WindowsAgentArena-V2 test task. The thresholds are disclosed, but the semantic encoder, task-expansion model and prompts, and decontamination implementation are unknown.

**Thought completion and Trajectory Boost.** The released code uses `claude-3-7-sonnet-20250219`. Given the task, current screenshot, current human action, and up to 30 prior human-trunk thought/action entries, Claude reconstructs the thought for the human action. It then samples nine separate alternative thought-action responses per human step with `max_tokens=1000` and 18 concurrent workers. Temperature and top-p are not set in the code and remain unknown. Alternatives are not executed. Filtering removes null or unparseable responses and literal `(x, y)` placeholders; on a human `finish` node, a synthetic response must also contain `finish`. No ordinary synthetic action is checked by an environment transition, reward, or semantic correctness verifier.

**Flattening and outputs.** `prepare.py` converts every human and retained synthetic node into a separate LLaMA-Factory sample. The input contains one current screenshot, the task, and prior human-trunk textual history; the target is a thought plus one action from the unified vocabulary: click, right click, double click, drag, scroll, press key, hotkey, type text, wait, finish, or fail. The result is about 27K action-level samples derived from 312 augmented episodes. The public 1.57 GB `data.zip` is the episode package—312 JSONL files, 312 companion task files, and 4,503 PNG screenshots—not a ready-made 27K JSON and not a replay bundle with VM snapshots, post-action observations, rewards, or evaluator outputs.

**Training and evaluation.** Qwen2.5-VL-72B-Instruct is full-parameter fine-tuned in LLaMA-Factory with the visual tower frozen, 8192-token cutoff, batch size 128, learning rate 2e-6, cosine schedule, warmup ratio 0.05, two epochs, and 32 GPUs; the paper reports about five hours, while GPU model and a pinned container are unknown. Evaluation uses a screenshot-only PC Agent-E scaffold at 1280×720. WindowsAgentArena-V2 has 141 feasible tasks across 11 Windows applications, restores VM snapshots, and judges success using task-specific evaluators after interaction; agents terminate by `finish`, `fail`, or a default 30-step cap. OSWorld supplies a separate Linux transfer evaluation.
