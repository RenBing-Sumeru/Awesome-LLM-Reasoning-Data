MoB requires a finite set of comparable discrete final answers. Answer extraction and normalization can split semantically equivalent answers or merge distinct ones, directly changing the mode. Its main assumption can also fail: when the mode of the reward-ranked Best-of-m distribution is wrong, MoB chooses that wrong answer more deterministically, whereas a stochastic Best-of-m draw can still be correct by chance. Reward misranking, reward hacking, calibration differences, and ties therefore remain central risks. Conventional m=N bootstrap is inconsistent for a maximum statistic; the theory instead requires m-out-of-N conditions that are asymptotic and include reward-tail assumptions. Generation still costs N model calls per question, and the paper estimates a few thousand H100 GPU-hours for the pools without tracking exact compute. The release provides prompts, completions, extracted answers, correctness, and reward scores, but no decontamination report or random question-selection seed. Its top-level MIT license does not separately resolve upstream benchmark rights, model-output terms, or reward-annotation rights.
