Given N generated outputs and their scalar rewards, MoB considers Best-of-m on bootstrap samples of size m<N drawn with replacement from the same pool. Each bootstrap sample contributes the final-answer value of its highest-reward output; MoB returns the most frequent such answer, approximating the mode of the Best-of-m output distribution. The released implementation does not materialize thousands of bootstrap subsets. After sorting outputs by reward, it computes in closed form the probability that each output would be the maximum in an m-sample, sums those probabilities by extracted final answer, and chooses the answer with the largest mass in O(N log N). The feedback contract is therefore learned scalar judgment plus exact grouping by final-answer string; the reward model ranks whole completions, while majority aggregation operates on extracted answers.
