LLM judges can prefer a longer, more concrete, or more familiar answer even when it is wrong or fails the instruction. OffsetBias studies this evaluator failure: select the genuinely good response rather than a response whose style exploits a judge's superficial cue.

The decision surface is an instruction and a good/bad response pair. It targets six identified content-and-style biases, while position bias is measured separately because it is not tied to a particular text pair.
