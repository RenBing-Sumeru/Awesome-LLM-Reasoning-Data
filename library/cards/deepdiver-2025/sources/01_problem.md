Existing iterative-RAG systems are commonly prompted with fixed search rules or trained and evaluated against relatively clean Wikipedia-style corpora. DeepDiver asks whether a model can instead learn when to search, what to query, and how much additional evidence to gather in a live web environment containing noise, stale pages, and conflicting claims. Its primary data object is an episode: a WebPuzzle question, alternating reasoning and search actions, search queries, retrieved documents, a final answer, and episode-level reward. WebPuzzle supplies 23,684 training questions and a 275-question expert-curated test set across Cross-Page QA, Open Riddle, and Wiki Riddle. This belongs in the rollout/search/test-time trace track because the number and depth of search interactions—and the decision to stop searching—are part of the learned trajectory rather than fixed preprocessing.
