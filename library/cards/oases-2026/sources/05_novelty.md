Outcome-only search RL, heuristic process rewards, separate state evaluators, PPO, and answer-level EM/F1 are established components. OASES's distinctive integration converts changes in state-conditioned answerability into telescoping process rewards and co-trains the same policy on search and evaluation rollouts sampled from its current state distribution. At inference, only the search role runs, so evaluation trajectories are a training-time scaffold. The direction signal is the explicit relationship among prefix state, evaluation answer, state score, reward delta, search action, and terminal outcome—not a new human process-label dataset or a proof that EM/F1 is a complete verifier.
