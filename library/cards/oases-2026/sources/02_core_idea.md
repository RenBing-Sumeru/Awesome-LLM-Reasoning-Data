A single policy performs two roles under different instructions. As searcher, it alternates reasoning, search actions, retrieved-result observations, and a final answer. As state evaluator, it answers the original question using only the information accumulated at one prefix state. The same exact-match/token-F1 scorer grades every state answer and the final answer. The difference between consecutive state scores becomes a process reward for the search action that produced the new evidence; the final answer retains the outcome reward. Search and evaluation rollouts share a PPO/GAE training buffer, keeping the evaluator on the current policy's state distribution.
