核心做法是后向构造：先生成行为，再从连续子轨迹中推导描述实际行为的指令。它反转了通常的“先有指令”假设，不再要求一条轨迹只有完成种子任务时才有价值。

其数据与反馈契约可概括如下：

| 要素 | 观察或生成的对象 |
|---|---|
| 种子资源 | 文档、教程、FAQ 或 SWE-bench-Lite 中不重复的 Python 文件 |
| 初始任务 | Claude-3.5-Sonnet 针对每份源文档采样的三条指令之一 |
| 环境行为 | Claude-3.5-Sonnet 的动作及其产生的观察，直到停止或达到环境步数上限 |
| 候选记录 | 连续观察—动作子轨迹，以及概括步骤或抽象目的的新指令 |
| 机械筛选 | 删除与无动作或环境错误有关的连续重复动作—观察状态 |
| 模型筛选 | Claude-3.5-Sonnet 和 Gemini-1.5-Pro 都认为样本连贯、自然、合理且与指令一致 |
| 下游对象 | 检索得到的上下文示例，或用于下一动作预测的 SFT 样本 |

反馈契约是**混合型**：环境执行提供状态转移，基准评测器随后衡量任务完成；数据构造阶段则把重复状态规则与双模型语义委员会组合起来。委员会不会实际执行重构后的指令，也不验证终态成功，只判断给定指令与行为是否在语义上合理。逐条投票、理由、置信度、拒绝原因和精确模型修订版均未发布。

枚举所有连续片段会使候选数随轨迹长度呈二次增长。ICLR 终稿显示，85,905 条原始轨迹扩展为 1,456,808 个候选，最终 440,008 条通过筛选。它提高了昂贵交互的产出率，也产生了大量来自同一回合、彼此高度重叠的记录；审计和切分时应保留共同的回合来源。

同一批接受样本支持两种用途：训练外适配时，每一步通过智能体检索选取演示；训练式适配时，记录被转换为下一动作预测的监督微调样本。证据只支持 `sft` 和 `agent_training`，不支持把它扩展为偏好优化、奖励模型训练或策略梯度强化学习。
