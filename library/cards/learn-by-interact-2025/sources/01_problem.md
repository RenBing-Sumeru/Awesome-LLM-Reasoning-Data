Agent adaptation in realistic software, web, desktop, and data-engineering environments is constrained by the scarcity of action-level supervision. Human annotators must understand both the task and a stateful interface, execute long action sequences, and diagnose environment-specific failures. Learn-by-interact asks whether commonly available documentation and autonomous interaction can replace manual trajectory labeling.

The paper's concrete data object is an environment-specific instruction-subtrajectory pair. A trajectory alternates observations and actions, and a retained record has a newly constructed instruction \(I'\) plus a contiguous segment \(T'=(o_i,a_{i+1},o_{i+1},\ldots,a_j,o_j)\). The instruction may summarize the executed steps or abstract their apparent purpose. It is not necessarily the task that originally caused the agent to act.

This distinction is central. The generating agent can fail, detour, or execute only part of its initial task. Rather than discard every such episode, backward construction asks what the observed segment actually accomplished and relabels it accordingly. That can recover useful local behavior, but instruction-behavior alignment after relabeling is not evidence that the original task succeeded, that the path was efficient, or that the behavior was safe.

The ICLR final reports a four-stage accounting chain: 28,635 source documents produce 85,905 raw trajectories, all contiguous segments yield 1,456,808 candidate instruction-subtrajectory pairs, and filtering retains 440,008 examples. The pools are constructed separately for SWE-bench-Lite, WebArena, OSWorld, and Spider2-V.

This Card belongs in **Data Construction & Open Release Recipes** because the contribution is a concrete recipe for turning source resources and environment interaction into agent-training examples. “Open release” remains an audit dimension, not a property established by publication: no official code repository, generated dataset, project page, model checkpoint, dataset card, or immutable release was found.
