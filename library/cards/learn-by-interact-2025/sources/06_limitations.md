- **No reusable release was found.** The official paper, proceedings page, OpenReview record, arXiv record, and author page do not provide confirmed code, generated data, project site, model checkpoint, dataset card, or immutable release. The reported corpus must not be described as open.
- **Backward relabeling changes the success claim.** A failed or accidental path can become an apparently aligned record after its goal is rewritten. Alignment to the new instruction does not prove original-task completion, optimality, necessity, or safety.
- **The semantic verifier is not an executor.** Claude-3.5-Sonnet and Gemini-1.5-Pro judge coherence, naturalness, reasonableness, and alignment, but no calibration set, exact API revision, per-item vote, rationale, confidence, disagreement analysis, or independently labeled accuracy is released.
- **Candidates are strongly correlated.** Exhaustive spans from one episode overlap and can differ by only one boundary step. No raw-episode group identifier, group-aware split, near-duplicate audit, or trajectory-family leakage analysis is reported.
- **Provenance is aggregate.** Live documentation and benchmark environments are not snapshot-pinned. Per-record URLs, document versions, crawl dates, environment/container revisions, action-space versions, transformations, and source licenses are absent.
- **Benchmark overlap is unresolved.** Synthesis deliberately uses resources tied to the evaluated environment families. The paper reports no task-, instruction-, code-, or semantic-overlap study against evaluation instances.
- **Substitution can shift the target domain.** When target documentation is unavailable, related-domain resources may be used—for example, Amazon documentation for a WebArena shopping environment. The fidelity of this substitution is not separately measured.
- **Rights do not transfer automatically.** CC BY 4.0 covers the paper, not necessarily the unreleased generated corpus, third-party documentation snapshots, environment observations, or model outputs. Artifact licensing and rights lineage are unknown.
- **Reproduction inputs are incomplete.** Exact prompts as executable files, model revisions, seeds, retries, maximum steps, LoRA rank, GPU count, runtime, token consumption, cost, dependency lockfiles, raw candidates, and rejection ledger are unavailable.
- **Version drift matters.** arXiv v1 and the ICLR final contain different counts and headline results. Mixing versions can produce an internally inconsistent reconstruction; this Card uses the final proceedings paper.
- **Evaluation is not a sample audit.** Reported benchmark gains do not establish correctness, diversity, safety, provenance, decontamination, licensing, or independent reproducibility of the 440,008 retained records.
