Read the coverage metric, the confidence analysis, and the deployment budget as one argument. The most important comparison is not DCO versus cross-entropy at an arbitrary N, but whether the training coverage parameter and test-time N are matched. Then separate direct-answer experiments from theorem-proof search, where the parameter also changes effective tree shape. The MATH table is especially instructive: pass@1 improves while high-N coverage worsens. It is a warning to evaluate an inference-scaling system with the actual decision rule it will use, rather than with a convenient one-sample proxy.
