The central claim is that pass@N is a coverage objective, not merely an accuracy objective repeated N times. At a large budget, a useful model must allocate enough probability mass to multiple plausible answers so that a correct one can be reached by sampling. Cross-entropy optimized for pass@1 instead rewards making the observed completion increasingly dominant. When the model is uncertain and that dominant completion is wrong, this creates overconfidence and removes the exploration needed for coverage.

Direct Coverage Optimization, or DCO, optimizes the probability that a reference completion appears at least once in a specified number of samples. Its gradient is the ordinary cross-entropy gradient multiplied by an overconfidence-dependent attenuation factor, so examples the model already treats as very likely contribute less. The training coverage parameter becomes a control for the later sampling regime: small values favor concentrated exploitation, while larger values encourage broader exploration. The record therefore joins the training parameter with the deployment pass@N budget.
