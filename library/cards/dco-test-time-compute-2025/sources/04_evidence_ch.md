论文首先用一个四轮 Llama-3-8B 的 MATH 实验展示问题。交叉熵将 pass@1 从 4.4% 提高到 7.4%，但报告的 pass@256 从 65.2% 降至 44.5%，pass@4k 从 82.5% 降至 63.0%。这是直接证据，表明更好的一样本准确率能够与更差的大预算覆盖率并存。作者报告，当 DCO 的训练覆盖参数接近测试时采样数时，多个 DCO 变体形成更强的性能前沿。

对于证明搜索，报告的 pass@4k 交叉熵基线在 Mathlib 上为 55.6%，在 MiniF2F 上为 37.4%。逐步 DCO 模型的集成达到 62.2% 和 43.6%，而使用五倍计算的交叉熵基线为 57.0% 和 39.5%。这些发现支持让训练置信度匹配搜索机制，但仍只是对所测试模型、数据、判定器和采样预算的证据；论文本身表明，若为部署 N 选择的 DCO 设置过大或过小，性能会落在前沿之下。
