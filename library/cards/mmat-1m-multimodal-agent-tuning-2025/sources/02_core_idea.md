The principal data object consists of multimodal questions and answers, detailed rationales, dynamic API or RAG information, multi-turn reflections, corrections, and compressed one-turn ORR records. MMAT-1M is a million-scale dataset with both multi-turn Rationale-and-Reflection records and One-turn Rationale-and-Reflection records. A useful record preserves the input, current prefix or environment state, candidate behavior, execution or evidence, feedback label, and provenance instead of only a final outcome.
