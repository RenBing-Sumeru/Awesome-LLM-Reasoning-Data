Million-scale multimodal-agent data usually retain only final success or a completed answer, so they cannot reveal which step in planning, retrieval, tool selection, environment execution, or evidence synthesis creates value or introduces an error.

Rather than merely adding complete successful trajectories, this work records multimodal questions and answers, detailed rationales, dynamic API/RAG information, multi-turn reflection, corrected results, and compressed one-turn ORR records, allowing each local behavior to be accepted, rejected, or corrected for an explicit reason.
