1. **整理公开多模态 QA。** 清洗图像—问题—答案数据，去除缺失图像、重复和答案不可核验样本。
2. **生成详细 rationale。** 教师模型为原始 QA 扩展多步解释，并依据任务动态插入 API 调用或 RAG 信息。
3. **构造多轮反思。** 把初始回答扩展为包含工具结果、推理更新和自我检查的多轮 Rationale and Reflection。
4. **利用反思修正。** 根据后续反思修复逻辑冲突、证据遗漏或错误结论，并保存修改前后内容。
5. **生成两种格式。** 保留完整 RR 多轮数据，同时压缩为 One-turn Rationale and Reflection，以降低训练长度。
