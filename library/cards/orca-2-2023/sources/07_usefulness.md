Use Orca 2 when building teacher demonstrations for a smaller model whose best strategy varies by task. Define task groups, choose candidate strategies, elicit several teacher answers, verify them, erase the strategy instruction, and compare against both a generic-explanation dataset and an explicit-strategy-label dataset. The output is a task-answer SFT set plus an auditable hidden mapping. Do not use Prompt Erasing where operators must inspect or control the strategy at inference time, or where teacher answers lack independent correctness checks.
