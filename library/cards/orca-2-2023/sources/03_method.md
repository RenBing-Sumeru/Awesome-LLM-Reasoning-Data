1. **Group tasks and inspect failures.** Input FLAN/Orca task families and earlier Orca behavior; identify where a small model needs direct answering, step-by-step reasoning, recall, extraction, or another strategy. Output a task-to-strategy mapping chosen for the student's capacity.
2. **Write teacher prompts.** For each task group, create detailed system instructions that elicit the selected behavior from GPT-4; multiple calls or specialized prompts may be used. Output task, strategy prompt, and teacher answer triplets.
3. **Erase the strategy.** Replace the detailed generation prompt with a generic system message before student training, leaving the user task and GPT-4 answer trace visible. The student therefore cannot simply condition on an explicit “use strategy X” label.
4. **Train progressively.** Starting from LLaMA-2-7B or 13B, train one epoch on FLAN-v2, three epochs on 5M GPT-3.5 teacher records from Orca 1, then four epochs on about 1M GPT-4 Orca 1 records plus 817K Orca 2 records. Output the Orca-2-7B and 13B checkpoints.
5. **Evaluate the learned choice.** Run zero-shot evaluations over 15 benchmarks, about 100 tasks, and more than 36K prompts, using exact-match or task-specific metrics plus open-ended judges where needed. The results test model behavior; without released records they do not independently verify the hidden data-selection decisions.
