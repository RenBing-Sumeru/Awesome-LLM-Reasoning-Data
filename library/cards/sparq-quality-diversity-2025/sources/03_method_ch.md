working set 由 7.5K 条 MATH 训练题解对初始化。学生模型是先在这些种子上训练三个 epoch 的预训练 Gemma-2-9B。除角色消融外，Gemma-2-27B-it 生成子题解对，Gemma-2-9B-it 标注技能。附录 F 给出提示模板：把父题和解答传给变异模型，要求输出带预期数值答案的新题与新解；分类器最多返回三个相关技能。

每个变异步骤抽取 64 个父样本。生成器写出子题，分类器分配技能单元，学生为每个子题生成 16 条解答。提取的最终数值答案与预期答案是否一致，形成二元验证标签；solve rate 对其求平均；质量在闭区间 [0.1, 0.9] 内等于 (1-)solve-rate，区间外为零。所有子题都写入 archive。不同变体会保持 working set 不变、保留全局最高质量样本，或在各技能单元内维持有容量上限的高质量成员。

每种主要方法最多运行 5,000 个变异步骤，得到 320K 个子题解对和约 500 万条学生验证解。由于多数子题的 solve rate 为零，作者报告每种方法平均约保留 80K 道唯一题目和 500K 个题目/成功解元组。同题的多个成功解会让较容易的保留题贡献更多元组。消融实验删除 solve rate 至少 0.5 的题目中 75% 的成功轨迹，把一组 500K 元组缩减为 350K，下游效果并不一致。

固定预算分析使用 300K 条静态均匀 archive，删除零质量题解对，每题仅保留一条成功学生解，再在 (2^{12}) 到 (2^{15}) 的预算下比较 quality、diversity、联合 QD 和 random 抽样。下游训练一个 epoch，批量大小 16，学习率从 2e-6 余弦衰减到 2e-7，运行在 8x8 TPUv4 slice 上。初始 SFT 除三个 epoch 外的设置、生成硬件、temperature、seed、parser 规则和答案归一化细节均未知。
