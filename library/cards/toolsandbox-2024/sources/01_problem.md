Primary source: https://arxiv.org/abs/2408.04682. Public status: arXiv preprint, 2024. Prior tool-use evaluations often use stateless REST APIs, single-turn prompts, or off-policy trajectories. ToolSandbox asks how to test tool use when state changes across conversation and tools.

The evaluation object is conversation turns, tool calls, tool state changes, user-simulator responses, intermediate milestones, final milestones, and score. The feedback contract is dynamic evaluation strategy over intermediate and final milestones along an arbitrary trajectory. This belongs in the collection as an auditable benchmark or environment surface; it is not by itself proof of deployable reliability, and training use should be inferred only where the paper explicitly releases data for that purpose.
