One-sentence contribution: ToolSandbox evaluates tool-use models in stateful conversations with simulated users, implicit tool-state dependencies, and milestone-based checks. The core contribution is a stateful, conversational, interactive environment with implicit tool dependencies, a built-in user simulator, and milestone checks.

The data object contains user instruction, tool schema, conversation turn, tool call, tool response, environment state, milestone check, final score. Success is decided by conversation and tool state satisfy the required intermediate and final milestones. Closest comparisons are static web benchmarks, tool-use datasets, or code benchmarks in the same domain, but the direction label here is the concrete evaluation surface and its verifier rather than a general capability claim.
