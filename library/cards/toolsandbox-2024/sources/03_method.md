Inputs are stateful tool-use scenarios with user instructions and simulated follow-up conversation. Outputs are conversation turns, tool calls, tool state changes, user-simulator responses, intermediate milestones, final milestones, and score. The substrate is stateful tool sandbox with implicit dependencies among tools and a user simulator.

Pipeline: 1. construct or load the task instance; 2. run the model or system under the official harness; 3. collect actions, observations, answers, or predicted structures; 4. apply dynamic evaluation strategy over intermediate and final milestones along an arbitrary trajectory; 5. aggregate scores only under a pinned version of the benchmark. Reproducibility requires pinning paper=https://arxiv.org/abs/2408.04682, project=https://github.com/apple/ToolSandbox, code=https://github.com/apple/ToolSandbox, data=https://github.com/apple/ToolSandbox, plus the exact split, runtime, scorer, prompt/scaffold, and release revision.
