The current benchmark contains 328 Python completion tasks covering 26 widely used libraries. Each item binds an explicit library version, code context, completion location, and unit tests. The official Hugging Face data and evaluation harness are released separately; submissions use `example_id` and `answer`, and evaluation runs in pinned environments. The data object is a versioned problem–candidate code–execution result record, primarily for evaluation and error analysis rather than large-scale training.
