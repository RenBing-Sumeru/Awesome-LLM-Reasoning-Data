The paper-time pipeline can be reconstructed at the module level as follows.

1. **Seed and validate.** Rank textual Hugging Face post-training datasets using downloads, community engagement, and reported downstream performance; choose 83 seeds across General, Math, Code, and Science. Deduplicate the pending queue, verify each candidate through the Hugging Face API, and set its effective date to the earlier of the Hugging Face timestamp and associated-paper date. Candidates before the modern post-2020 scope terminate recursion.
2. **Retrieve and clean evidence.** A GPT-5.1 sourcing agent finds repositories, blogs, and papers from the dataset README. Gemini-2.5-Flash extracting agents fetch web content and arXiv material and remove metadata headers, code blocks, HTML, and irrelevant paper sections before building a shared evidence context.
3. **Extract source claims.** Parallel GPT-5.1 tracing agents distinguish construction sources from evaluation benchmarks, baselines, and incidental citations. Each candidate edge is serialized as source, one of five relation types, confidence, and evidence.
4. **Aggregate, resolve, and expand.** A Gemini-2.5-Pro aggregation agent deduplicates claims and uses online retrieval plus API checks to resolve aliases to `org/name` IDs. Temporal validation rejects a source newer than its target; unsupported low-confidence edges are pruned and other low-confidence cases are described as sent to experts. Accepted sources return to the queue, and DFS continues until no ancestor is found or the date cutoff applies.
5. **Audit literal overlap.** Exact `(instruction, input, output)` hashes quantify intersections between source paths. Exact `(instruction, input)` matches measure leakage from Omni-MATH, TheoremQA, LiveCodeBench, TruthfulQA, and SciBench into downstream training datasets.
6. **Construct the diversity pool.** From 212 unique leaves, rank by out-degree, remove leaves with no downstream use, exclude niche and non-QA sources, and keep 31 datasets. Normalize about 8.7M rows to Alpaca format, remove non-English and length-outlier records, perform exact-Q deduplication, then MinHash with 128 permutations, threshold 0.7, and 8-grams to report 570K instructions.
7. **Evaluate, not train.** Embed instructions with Qwen3-Embedding-8B at dimension 4096 and compare Vendi Score and Centroid Distance with eight public baselines. The paper does not report SFT or other downstream training with the 570K corpus.

Reproduction requires a paper-time code revision, model endpoints, prompts, API responses, confidence and expert-routing thresholds, agent budgets, random seeds, the 83-seed manifest, all 430 nodes and 971 accepted edges, the 31-source row manifest, deduplication logs, and licenses. The current repository does not pin that complete run: its CLI defaults to `gpt-5.4`, while Appendix A assigns GPT-5.1, Gemini-2.5-Flash, and Gemini-2.5-Pro by agent role.
