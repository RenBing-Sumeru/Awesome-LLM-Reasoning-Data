The contribution is a documentation-grounded, multi-agent pipeline that converts dispersed provenance statements into a recursive dataset lineage graph and then uses graph topology to choose less-derived source data.

For each candidate, a sourcing agent locates evidence, extracting agents summarize Hugging Face READMEs, web pages, and papers, tracing agents identify actual construction sources, and an aggregation agent merges duplicate claims and resolves aliases to canonical Hugging Face IDs. The edge relation is one of Semantic Evolution, CoT Distillation, Synthetic Generation, Structured Fusion, or Direct Inclusion/Subset. DFS expands newly discovered sources until the pipeline finds no ancestor or reaches the pre-2020 cutoff. Starting from 83 selected seeds, this process yields the reported 430-node, 971-edge graph. Leaf nodes with downstream reuse are then ranked by out-degree; 31 QA-oriented sources survive domain/format filtering and supply the diversity-oriented corpus.

The feedback contract is mixed rather than a correctness reward. Hugging Face availability, canonical-ID resolution, release-time consistency, agent confidence, supporting text, and low-confidence expert review decide whether a dataset-level edge is retained. Exact triplet matching measures source intersection; exact instruction/input matching checks five benchmarks; exact-Q and MinHash remove corpus duplicates. These checks can observe documented ancestry and literal overlap, but not concealed sources, paraphrased contamination, or whether an instruction has a correct and useful answer.

Relative to cataloguing provenance fields for isolated releases or scanning samples pairwise, the paper's direction signal is the use of graph ancestry as a reusable construction and audit layer. The closest conceptual comparison in this atlas is `bridging-provenance-gap-2025`, which audits source and rights metadata across releases; this paper instead infers directed derivation paths and applies them to source selection. Neither provides verified per-record ancestry for the resulting training rows.
