GLM-4.5 is a frontier ARC (agentic, reasoning, and coding) model report whose training narrative spans web-scale pre-training, code and reasoning continuation, expert-model iteration, mixed reinforcement learning, tool use, and agent environments. For an auditable reasoning-data atlas, the question is not whether the released model is capable: it is which data objects, feedback contracts, environments, and audits can actually be inspected or reused.

The report provides unusually broad high-level disclosure, but the official release boundary is critical. Official weights, inference integrations, and model documentation do not constitute a release of the original corpus, post-training data, reward model, LLM Judge, agent environment, source-rights evidence, or evaluation-leakage audit. This Card records both the disclosed pipeline and those missing artifacts.
