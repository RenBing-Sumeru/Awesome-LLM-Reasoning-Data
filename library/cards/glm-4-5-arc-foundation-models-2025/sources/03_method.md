For pre-training, the report names crawled Chinese and English web pages, social media, books, papers, and code repositories. It describes quality bucketing, upsampling, MinHash and semantic deduplication, language- and domain-specific quality models, and code-aware processing. Its figure reports nominal components of 15T general-pretraining tokens, 7T code/reasoning continual-pretraining tokens, 500B repository code tokens, 500B synthetic-reasoning tokens, and 100B long-context/agent tokens; the text summarizes the total as about 23T tokens.

Post-training starts from small cold-start SFT and grows to millions of expert-generated reasoning, chat, agent, and long-context samples. Rejection filters remove malformed or short reasoning, check objective answers, apply reward models to subjective responses, and retain tool trajectories that obey protocol and reach expected terminal states. Agent SFT uses real API/MCP tools alongside constructed or simulated tools, generated tasks, existing tool-call trajectories, user simulation, and judge-agent success filtering.

Reasoning RL uses a GRPO-style approach without a KL term. Agentic RL uses web QA and software-engineering tasks with environment feedback; general RL mixes rules, human preference feedback, and model feedback. Exact prompts, datasets, reward aggregation, rollout configurations, and production schedules are not released.
