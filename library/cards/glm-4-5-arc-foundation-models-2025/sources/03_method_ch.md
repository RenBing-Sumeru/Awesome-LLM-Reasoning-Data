预训练部分列举了中英文爬取网页、社交媒体、书籍、论文和代码仓库，并描述质量分桶与上采样、MinHash 与语义去重、语言/领域质量模型及面向代码的处理。图中给出名义规模：15T 通用预训练 token、7T 代码/推理续训 token、500B 仓库代码 token、500B 合成推理 token 和 100B 长上下文/agent token；正文将总规模概括为约 23T token。

后训练先从小型冷启动 SFT 开始，再扩展到数百万级专家生成的推理、对话、agent 和长上下文样本。拒绝筛选会移除格式错误或过短的推理，核验客观答案，用奖励模型筛选主观回答，并保留协议合规且达到预期终态的工具轨迹。Agent SFT 同时使用真实 API/MCP 工具与构造/模拟工具、生成任务、既有工具调用轨迹、用户模拟和裁判 agent 的成功筛选。

推理 RL 使用不含 KL 项的 GRPO 式方法；agentic RL 使用带环境反馈的网页问答和软件工程任务；通用 RL 混合规则、人工偏好和模型反馈。具体提示词、数据集、奖励聚合、rollout 配置和生产调度均未发布。
