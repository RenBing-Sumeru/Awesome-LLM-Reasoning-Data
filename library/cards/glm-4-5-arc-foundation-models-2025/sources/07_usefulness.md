Use this Card to compare frontier reports by disclosure quality: which source categories are named, which feedback signals are executable, where model or judge feedback enters, and which artifacts are required to reproduce or audit an agent-training claim.

It is especially useful for separating a model release from a data release. Researchers can cite the report for its high-level construction account, but should not claim access to the original training corpus, post-training data, reward/judge contract, agent environment, or contamination evidence without a later official release.
