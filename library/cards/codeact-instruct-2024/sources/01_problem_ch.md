LLM 智能体通常输出文本或格式固定的 JSON tool call；这两种形式都难以组合多个工具、复用中间变量，也需要额外解析逻辑才能根据执行错误调整行动。CodeAct 要回答两个问题：可执行 Python 能否成为统一 action 语言，以及这些交互能否从一次性的在线 episode 变成可复用监督。

本文在 Track 01 中的核心对象是 CodeActInstruct：7,139 条静态多轮对话，逐轮保存任务指令、模型思考、可执行代码、环境反馈、纠错过程与最终答案。teacher 负责生成轨迹，原任务指标和环境结果筛选成功 episode，Llama-2 与 Mistral 再通过 SFT 消费这些记录。

**L4 事实：**主要来源为 arXiv 2402.01030，已被 ICML 2024 接收；开放数据 `xingyaoww/code-act` 包含 7,139 条轨迹和 10,581,681 个 Llama-2 token；构造、筛选、任务混合、训练消费者、实验与执行风险均已核对，但官方论文页面未披露作者机构。
