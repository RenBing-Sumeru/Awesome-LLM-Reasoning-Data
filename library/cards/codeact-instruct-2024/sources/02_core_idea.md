CodeActInstruct converts hard examples from five existing task suites into executable multi-turn demonstrations. GPT-3.5, Claude, and GPT-4 act through Python, observe search results, table outputs, simulator states, or tracebacks, and revise their plans; the pipeline retains successful, parseable episodes and deliberately favors trajectories that recover from an earlier error. The released records are SFT targets, which is why this Card belongs to instruction/demonstration/rationale data even though the substrate is an agent environment; work that releases only an online environment or benchmark is the closest excluded neighbor.

Open dataset: yes. Dataset name: CodeActInstruct. Official URL: https://huggingface.co/datasets/xingyaoww/code-act. Scale: 7,139 CodeAct trajectories and 10,581,681 Llama-2 tokens. Record form: instruction, thought, executable Python action, environment observation/error, revisions, terminal solution, and success outcome. File/storage format: one CodeAct Parquet shard plus a separate general-conversation Parquet shard. Domains/languages: English information seeking, mathematics, code, table reasoning, and robot planning. Construction and filtering: GPT-3.5/Claude/GPT-4 interact with executable tasks; original metrics verify success and heuristics retain parseable, useful, self-correcting episodes. License/access constraints: public Apache-2.0 dataset; upstream source terms still require review. Intended use: SFT and agent training.
