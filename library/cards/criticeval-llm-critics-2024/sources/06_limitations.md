1. **Judge circularity:** Using LLMs to score LLM critiques can introduce shared preferences, only partly mitigated by human validation.
2. **Scenario breadth:** Nine task types are broad but shallow within each domain, with limited professional code review or long-document editing.
3. **Non-unique references:** One error can support many valid critiques, so a single reference may undervalue differently phrased correct feedback.
4. **Versioning and contamination:** Public tests may enter later training corpora, requiring hidden or refreshed evaluation sets.
