Self-play reasoning systems turn model-generated questions and solutions into the next round of training data. In the R-Zero-style Challenger-Solver loop studied here, the Challenger is rewarded for posing questions near the Solver's uncertainty boundary, while a within-iteration repetition term is intended to keep the curriculum varied. The paper argues that local lexical novelty is insufficient: later rounds can recycle earlier modes, and differently worded questions can exercise nearly identical procedures. It calls these failures Local Diversity Illusion and Surface Diversity Illusion. (Paper §1 and §3.)

The constructed object is not a static benchmark. It is an evolving stream of generated competition-math questions, Solver reasoning rollouts and extracted answers, equivalence groups, consistency scores, majority pseudo-labels, canonical Python representations, embeddings, memory decisions, and replayed historical question-answer pairs. The policy, pseudo-label source, novelty representation, and historical pool all change during training. No immutable copy of this stream is released.

This is a data-construction paper because MAP and SAM alter which questions are rewarded, admitted to memory, and replayed. It is not a ground-truth dataset release: its principal correctness signal remains Solver agreement, while the official repository currently exposes a project description and figures rather than executable code or generated records.
