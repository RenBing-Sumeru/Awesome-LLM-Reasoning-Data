- **Verifier scope is narrower than reasoning quality.** Ordered key-action coverage plus a correct final state does not test whether thoughts are grounded, intermediate actions are rational, or the trajectory is minimal. Because non-key exploration is allowed, a successful but inefficient episode can pass. Because the key path is synthesized, another valid action ordering can also be rejected or mislabeled during first-error localization.
- **Candidate accounting is missing.** The paper reports 6,246 accepted Stage-2 episodes but not total rollouts, rejected counts, per-task pass rates, failure categories, retry policy, or the complete failed pool. Stage-3 source proportions, anomaly sampling, and first-error-label accuracy are also unknown.
- **Generation and training settings are incomplete.** The GPT-4o snapshot/prompts, Stage-2 temperature and top-p, rollout budget, maximum steps/tokens, seeds, stage-specific optimizer settings, hardware, batch schedule, epochs, and paper-checkpoint mapping are unknown. Generic repository launchers are not a paper-matching manifest.
- **Replay is partial.** The release includes scene/object IDs, image paths, actions, key actions, and an AI2-THOR dependency version, but not immutable Unity/build hashes, initial-state and randomization seeds, or complete action/transition logs. Exact episode replay and re-verification are therefore not guaranteed.
- **The current release needs a loader audit.** The Hugging Face page reports 157 GB, but the Dataset Viewer fails at revision `e498d661e45b1ccf5694e4e8bfd825eee58e0051`: `test_809.json` has a 15-field evaluation schema while dialogue records use `id`, `messages`, and `images`. Separate configurations or a tested loader are not provided on the page.
- **Evaluation does not certify the corpus.** The 809 simulator cases are author-curated and scene-disjoint by report, but template, instruction, object-combination, and teacher-output overlap are not audited. Search Efficiency is key-action count divided by predicted-action count, while Task Completeness measures the proportion of predicted actions that are key actions; neither metric proves that every record is correct or that all necessary exploration is represented fairly.
- **Rights and release scope remain incomplete.** Code is MulanPSL-2.0 and the dataset card declares Apache-2.0, but no asset-level provenance/NOTICE mapping is published for the simulator renders. GPT-4o output terms, Qwen2-VL derivative obligations, and any model-weight license require separate checks; an official author-owned model-weight repository was not verified. The release also lacks an explicit privacy statement distinguishing simulator images from the human-mediated real-world evaluation media.
