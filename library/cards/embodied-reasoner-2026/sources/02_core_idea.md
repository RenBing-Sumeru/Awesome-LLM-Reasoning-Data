The released training object contains 9,390 trajectories: 1,128 Stage-1 synthetic imitation episodes with 4,636 images, 6,246 Stage-2 accepted self-exploration episodes with about 45.8K images, and 2,016 Stage-3 reflection/correction episodes with about 13.8K images. The paper separately reports about 64K images, 8M thought tokens, and roughly 90K occurrences of five thought patterns—situation analysis, task planning, spatial reasoning, self-reflection, and double verification. The 90K figure is not a count of independent examples.

Each example is a multi-turn Observation-Thought-Action episode. User turns provide an egocentric image and interaction feedback; assistant turns provide reasoning and a discrete high-level action. The origin-format records also expose task family/subtask, scene, instruction template and variants, ordered key actions, object identifiers and types, per-action rewards, total reward, trajectory strings, and image paths. The dialogue file converts the same 9,390 trajectories into training messages, so these are two representations of the corpus rather than two additive sets.

The environment is AI2-THOR: training spans 107 scenes, about 2,100 objects, and about 2,600 containers. The action vocabulary includes observation, motion/navigation, pickup, placement, opening/closing, toggling, and termination. This state-action context makes the records richer than free-form chain-of-thought transcripts, while missing seeds and build hashes still prevent guaranteed deterministic replay.
