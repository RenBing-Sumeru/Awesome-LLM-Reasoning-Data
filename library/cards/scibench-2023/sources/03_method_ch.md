输入是数学、化学、物理中来自教材和课程式来源的大学水平问题。公开 Hugging Face 查看器显示字段包括 `problem_text`、`solution`、`answer_latex`、`answer_number`、`problemid`、`unit` 和 `source`；GitHub README 说明 JSON 文件位于 `dataset/original`，每个文件对应一本教材，多模态样例位于 `dataset/img`。

流程如下：

1. 选择需要大学水平概念、复杂计算、详细解答的题目，其中一部分还包含视觉语境。
2. 按教材或来源把题目转换成 JSON 记录，并通过 GitHub 和 Hugging Face 发布。
3. 在仓库说明的多种设置下评测模型，包括零样本、思维链、少样本、Python 和 Wolfram 风格工具设置。
4. 用仓库评测代码把模型答案与参考答案或参考解比较，得到答案级分数。
5. 对错误答案运行分析协议：人工标注者比较模型解答和参考解，把错误原因归纳成十类科学问题求解技能，再用大模型验证器自动归因失败。

输出包括基准记录、模型答案、答案级分数、提示设置对比和错误画像。复现时需要固定 arXiv 版本、Git 提交或分支、Hugging Face 数据版本、提示设置、模型快照、工具设置、评测脚本、数值容差，以及是否包含图像题。GitHub README 明确提到数据有小幅更新并保留 `old` 分支，因此旧版和当前版分数不能在没有版本元数据时混用。
