Read the paper and artifacts in this order: arXiv abstract for scope, dates, ICML status, and the 43.22% paper result; project page for authors, institutions, current result presentation, criteria, examples, and BibTeX; GitHub README for artifact layout, dataset update warning, evaluation settings, and error-analysis protocol; Hugging Face for current row count and visible schema fields.

Keep four labels separate. The dataset is the textbook-derived problem set. The evaluator is the answer-matching/scoring script. The prompt or tool setting is the experimental scaffold. The error category is diagnostic metadata produced after a wrong answer, not the same thing as a ground-truth solution step label.

When comparing SciBench results across model reports, first ask which dataset revision and evaluator were used. The 43.22% arXiv number and the 48.96% current project-page number should be read as version-specific claims.
