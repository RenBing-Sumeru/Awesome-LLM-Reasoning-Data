SciBench 适合作为一个小型、公开、大学水平科学推理基准，且答案级评分可以被检查。它最适合比较提示策略、工具辅助解题、不同模型家族，以及同一题面上的数值/科学推理行为。

可复用的数据结构应保留题目编号、来源/教材、学科、题面、参考解、参考数值或 LaTeX 答案、单位、可选图像链接、提示设置、工具设置、模型输出、解析后答案、评测器结果、评分容差，以及如果生成了错误归因标签，也要单独保留。不要把正确性分数和诊断错误标签合并成一个字段。

报告评测分数时，每个分数都应绑定 Git 提交或分支、Hugging Face 数据版本、模型快照日期、评测脚本版本、提示模板和工具策略。做训练数据时，SciBench 更适合作为保留审计集；如果训练使用公开实例，必须披露并与后续评测结论分开。
