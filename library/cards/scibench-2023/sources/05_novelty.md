The prior-work baseline is science and math evaluation built from high-school science, multiple-choice QA, or short algebraic word problems. Those settings are useful but can understate failures that arise in college-level scientific calculation, equation selection, unit handling, and domain-specific theorem or formula retrieval.

SciBench changes the object and the audit surface. The object is a curated set of open-ended college textbook problems spanning mathematics, chemistry, and physics. The audit surface includes reference answers/solutions, prompt/tool settings, answer-level scoring, public artifacts, and a diagnostic error taxonomy. The direction signal is that scientific reasoning benchmarks should expose domain-specific computation and versioned evaluator details, not just aggregate QA accuracy.

Quality signals are the ICML 2024 record, public project page, GitHub repository, Hugging Face dataset, MIT repository/data metadata, visible data fields, and documented version caveat. What is not new: prompting strategies, chain-of-thought, Python/Wolfram assistance, automatic grading, and post-hoc error analysis all predate SciBench. The reusable novelty is the assembled college-level science benchmark and its failure-analysis protocol.

Before reuse, inspect source-textbook redistribution constraints, dataset revision, record count, prompt templates, score tolerance, evaluator implementation, tool-call settings, image handling, and public contamination. Keep answer correctness separate from verifier-generated error categories when using results downstream.
