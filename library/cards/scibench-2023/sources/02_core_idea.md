The central contribution is a public benchmark for college-level scientific problem solving, paired with prompt-setting comparisons and a diagnostic error-analysis protocol. The core mechanism is simple but useful: curate difficult textbook problems, normalize them into machine-readable records, evaluate LLM answers under several prompting/tool settings, and inspect failures through a ten-skill scientific problem-solving taxonomy.

An instance is not a dialogue or a chain-of-thought label. It is a free-response scientific problem, source/textbook metadata, a reference answer or solution, optional unit or visual context, and evaluation outputs. The main feedback contract is whether the model answer matches the reference answer or solution under the official evaluator. The diagnostic layer uses human analysis plus an LLM verifier to attribute wrong answers to skill deficits; those labels should be treated as audit metadata because they depend on the verifier model and prompt.

Closest comparisons include GSM8K and MATH for quantitative reasoning, AI2 ARC and other science QA sets for domain knowledge, and ScienceWorld or ScienceAgentBench for science-agent evaluation. SciBench differs by focusing on static, open-ended, college-level textbook problems across math, chemistry, and physics rather than multiple-choice QA, short arithmetic word problems, or interactive lab workflows.
