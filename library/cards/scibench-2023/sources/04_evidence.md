The paper-level evidence is that SciBench evaluates representative open-source and proprietary LLMs across multiple prompting strategies and reports poor overall performance on college-level scientific problem solving. The arXiv abstract reports a best overall score of 43.22%, while the current project page reports a best overall score of 48.96% for the updated dataset/results presentation; this discrepancy is a versioning signal, not a reason to treat the numbers as interchangeable.

Artifact evidence is strong. The arXiv record gives title, authors, submission dates, DOI, and ICML 2024 status. The project page lists authors, institutions, paper/code/dataset links, dataset criteria, examples, and the official BibTeX. The GitHub repository exposes `dataset`, `eval`, a MIT license, a note about minor dataset changes, and an `old` branch. Hugging Face exposes a JSON-format text dataset with 692 rows in the current viewer and fields for problem text, solution, answer, unit, problem id, and source.

Instance-level evidence is answer matching: a model produces a free-response answer, the evaluator compares it against the reference answer or solution, and the result contributes to subject/setting scores. Error-type evidence is weaker and should be read separately because it depends on human interpretation and an LLM-verifier-assisted attribution protocol.
