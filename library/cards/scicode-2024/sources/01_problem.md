SciCode: A Research Coding Benchmark Curated by Scientists defines an evaluation surface in scientific-coding, code-generation: whether model outputs or agent trajectories satisfy the task-specific feedback contract. The primary source and artifacts are paper: https://arxiv.org/abs/2407.13168; the local metadata records the source as 2024 / arXiv.

The decision boundary is benchmarks_evaluation_surfaces with roles benchmark and verification contract programmatic. One benchmark instance is: scientific problem, required function/code, generated solution, tests, and pass/fail score. This is not a model-training recipe unless the paper separately releases training data; the card treats it as evaluation, audit. It matters for the atlas because the reusable object is an evaluation/data record with a named scorer, judge, verifier, reward, or environment predicate rather than an abstract capability claim.
