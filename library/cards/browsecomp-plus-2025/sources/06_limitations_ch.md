- **问题边界与 contamination。** benchmark release 包含 830 个 filtered query，不是 BrowseComp 原始的 1,266 条。由于 parent question 与 answer 已公开且可逆解码，未来模型可能吸收这些内容。论文报告 o3 与 GPT-5 的 parametric-only accuracy 约为 20% 与 26%，这只能视为可能的 exposure signal，不是 contamination measurement。
- **可逆 canary。** query payload 使用公开 canary，以及由公开 SHA-256 key 派生的 base64/XOR transform。key 与 decryptor 都公开，因此只能阻止意外摄入，既不提供保密性，也不能对 model weight 去污染。
- **不完整 qrels。** 人类 evidence 与 gold label 覆盖构建出的候选池，并非全世界或扩展 corpus 中的所有相关文档。新增的相关文档可能被计为 false negative；o3 生成的 candidate URL 也会影响哪些 evidence 进入 pool。因此 retrieval/citation metric 必须理解为相对于 incomplete qrels 的 judgment。
- **Citation predicate。** citation scorer 只把 numeric document ID 与 evidence qrels 匹配；它不检查引用 passage 是否蕴含对应 claim、citation placement 是否正确，或 final explanation 是否完整。
- **Judge 漂移。** 正式论文以 GPT-4.1 判断 semantic equivalence，而当前公开代码默认使用 Qwen/Qwen3-32B。Appendix G 在同一个 GPT-5 plus Qwen3-retriever condition 上，给出 substring、GPT-4.1 与 Qwen3 grading 分别为 65.18%、70.12% 与 71.69%。未注明 judge snapshot、prompt 与 configuration 的分数不能视为准确复现。
- **失败保留。** 当前 producer code 可以序列化带 non-completed status 的返回 response；evaluator 把 non-completed 或 missing-output run 视为 failure 或 parse error。但 query-level exception 可能在写入任何记录前终止。construction reject 只公开 aggregate count，四个 public run file 也尚未被穷尽核验其 row count 或 completed/incomplete/error 分布。
- **部分 trajectory release。** 可见 archive 只有 BM25+GPT-5、BM25+o3、Qwen3-Embedding-8B+GPT-5 与 Qwen3-Embedding-8B+o3。其他被评测 agent 或 retriever 没有已核验的公开 trajectory；每个可见文件是否覆盖全部 830 条也为 unknown。
- **提取与任务范围。** Selenium/Trafilatura 文本提取会遗漏或损伤 interactive page、dynamic layout、multimedia 与部分 PDF content。明确移除的条目包括 42 个 map/distance task 与 13 个 ambiguous 或 non-unique-answer task。保留的 benchmark 评测短答案与 document citation，不是完整 deep-research report。
- **版本与准确 replay。** code 与 Hugging Face artifact 各有独立 history，repository 没有 release tag，corpus revision 为 unknown，也没有 immutable manifest 绑定 query、corpus、index、trajectory、prompt、dependency、agent 与 grader。proprietary API snapshot、seed、retry state、部分 service version 与 rollout count 未披露；因此即使 controlled rerun 比 live web 更可行，准确历史 replay 仍为 false。
- **License 与隐私。** code 以及 query/corpus/index repository card 显示 MIT metadata，arXiv v1 为 CC BY 4.0，archival-paper license 记录为 unknown，trajectory repository 则没有已核验 license。repository-level MIT metadata 不能证明第三方 scraped page 可被重新许可。PII scan、robots/terms review、takedown procedure、annotator compensation 与 consent 均为 unknown。
- **用途边界。** 证据只支持 evaluation。论文没有建立 SFT、distillation、preference learning、reward modeling、process supervision、RLVR 或 agent-training use；benchmark performance 也不能证明 data quality 或 training utility。
