The central contribution is a fixed-corpus derivative of BrowseComp that separates three questions: whether the environment retrieved human-labeled evidence, whether the agent cited those evidence document IDs, and whether a semantic judge accepted the final answer. Freezing the search substrate removes live-web drift from the retrieval comparison, but it does not remove model-weight contamination or make the labels exhaustive.

The benchmark record combines four data objects. First are 830 test queries with answers. Second is a 100,195-document web corpus. Third are human evidence qrels, gold-document labels, and mined hard negatives: evidence supports one or more clues, a gold document semantically contains the final answer, and a hard negative is a scraped result not retained as positive after labeling and deduplication. Fourth is a partial set of full agent episodes. The public run inventory contains only BM25+GPT-5, BM25+o3, Qwen3-Embedding-8B+GPT-5, and Qwen3-Embedding-8B+o3; coverage of all 830 queries and success/failure distributions has not been exhaustively verified.

The feedback contract is mixed. Terminal validity is programmatic: `status` must be `completed` and a final answer must exist. Retrieval uses Recall@k and nDCG@k against human qrels. Citation recall matches numeric cited document IDs to evidence qrels, but does not test sentence-level entailment. Final-answer accuracy requires an LLM semantic-equivalence judge: the archival results use GPT-4.1, while current public code defaults to Qwen/Qwen3-32B. No pairwise preference, process reward, learned reward model, or optimizer is part of the evidenced release.

Relative to BrowseComp, the change is not a new set of 1,266 questions or a replacement scoring card. It is the controlled environment, document supervision, construction ledger, and partial episode observability around a retained 830-query subset. This distinction supports the category choice and the `related: [browsecomp-2025]` link while keeping `training_use` limited to `evaluation`.
