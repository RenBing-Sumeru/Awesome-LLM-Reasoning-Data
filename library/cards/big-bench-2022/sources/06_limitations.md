Correctness is only task-local correctness under the task scorer. Because tasks are heterogeneous, aggregate scores mix very different skills, data sources, and scoring functions. Public repository tasks can be memorized; some tasks may have ambiguous labels, brittle regex scorers, or domain assumptions not captured in metadata. The benchmark should not be read as a single measure of reasoning ability or as a stable live leaderboard unless the repository commit, task subset, prompt policy, and model versions are fixed.
