The prior baseline was smaller, narrower, or institutionally curated benchmark suites. BIG-bench changed the object by inviting broad community task contribution and by shipping tasks with executable scoring definitions in one repository. The direction signal is a benchmark-as-platform pattern: heterogeneous task definitions plus a common harness for scaling studies. What is not new: prompt-based evaluation, multiple-choice grading, exact-match metrics, and many individual task ideas. Before reuse, audit task licenses, author-provided data lineage, task duplicates, scorer correctness, task weighting, and public-data contamination.
