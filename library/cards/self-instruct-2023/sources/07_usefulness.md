Use Self-Instruct to bootstrap instruction SFT when human effort can supply a small, diverse seed set but not a full corpus. Generate candidate tasks, apply lexical and semantic deduplication, create task-aware instances, validate answers independently, and compare a model trained on accepted data with the same base model and a human-data baseline. The output is a versioned instruction-instance dataset plus rejection logs. Do not use the loop without stronger verification in high-stakes factual domains or where generated-data redistribution rights are unclear.
