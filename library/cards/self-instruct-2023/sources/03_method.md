1. **Seed the task pool.** Input 175 human-written tasks, each with an instruction and example instances. These provide initial task forms and become in-context demonstrations for the generator.
2. **Generate new instructions.** Sample eight accepted tasks into a prompt and ask GPT-3 to propose additional instructions. Output candidate task descriptions; later iterations mix machine-generated tasks back into the prompt so the pool expands beyond the seeds.
3. **Filter instructions.** Remove malformed candidates and compute ROUGE-L similarity against every accepted instruction. Reject a candidate when its maximum similarity exceeds 0.7; otherwise add it to the task pool. This is a lexical diversity rule, not proof of semantic novelty.
4. **Generate and filter instances.** Classify whether each instruction is a classification task. Generate input then output for general tasks, and use output-first generation for classification tasks to avoid collapsing to one label; remove repeated instructions, empty fields, and heuristic invalid outputs. Output instruction-input-output records.
5. **Train and evaluate.** Fine-tune vanilla GPT-3 on the 82,439 retained instances and evaluate on SUPER-NATURALINSTRUCTIONS plus expert-written novel tasks. The student consumes one target output per instance; human audit, not a universal verifier, measures record validity.
