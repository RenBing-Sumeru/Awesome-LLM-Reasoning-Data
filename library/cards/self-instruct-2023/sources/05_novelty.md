Earlier instruction tuning relies on a fixed set of human-authored tasks, even when model-generated answers are used. Self-Instruct changes the generated object to the instruction distribution itself: the model invents tasks, creates instances, filters them, and feeds accepted tasks back into the next generation prompt. The novelty is this closed synthetic-data bootstrap with explicit task and instance filters, not SFT or in-context prompting alone. It establishes the reusable lineage later expanded by instruction-evolution and response-generation pipelines.
