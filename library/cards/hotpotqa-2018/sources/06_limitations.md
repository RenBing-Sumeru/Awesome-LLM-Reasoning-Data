Correctness is defined by string and supporting-fact overlap, not by a full proof of reasoning. A model can exploit annotation artifacts, retrieve shortcuts, or answer from memorized public examples.

Full-wiki results depend on the retrieval index and Wikipedia snapshot; distractor results hide the retrieval problem. Supporting-fact labels are sentence-level and may omit alternative valid evidence. Public release creates contamination risk for modern LLM evaluation, so post-release claims need version and training-cutoff evidence.
