Use HotpotQA as a reusable schema for evidence-grounded QA: question, answer, supporting article titles, supporting sentence IDs, distractor context, split, and evaluator output. It is useful for testing retrieval, reading, evidence selection, and joint answer-evidence scoring.

For atlas work, preserve whether a data point is used for supervised training, retrieval training, reranking, or final evaluation. The same supporting-fact label has different audit meaning in each role.
