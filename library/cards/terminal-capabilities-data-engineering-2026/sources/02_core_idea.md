The paper combines two task-sourcing strategies in Terminal-Task-Gen. Dataset adaptation wraps existing math, code, and software-engineering prompts in the Terminus 2 terminal interface. Synthetic generation either transforms structured seeds into adjacent terminal tasks or combines typically three to five primitive skills to target terminal-specific capabilities. DeepSeek-V3.2 generates the synthetic tasks and all SFT trajectories; Qwen3-8B, Qwen3-14B, and Qwen3-32B are the student bases.

The reusable data object is a full terminal episode serialized as `conversations` role/content cells plus coarse `agent`, `model`, `model_provider`, `date`, `task`, `episode`, `run_id`, `trial_name`, and `enable_thinking` metadata. Adapter configurations also expose `source`. Assistant content includes analysis or plan text and a Terminus 2 action object whose `commands` contain literal `keystrokes` and wait `duration`; user turns carry the current screen or `New Terminal Output`. The final artifact is task-dependent environment state, files, code, patches, or reports rather than a uniform answer string.

The public Nemotron-Terminal-Corpus contains exactly 366,154 train-only rows: 226,313 adapter rows and 139,841 skill-based rows, the latter split into 44,809 easy, 89,343 medium, and 5,689 mixed rows. Paper Table 5 instead totals 490,520 trajectories by adding 124,366 seed-based trajectories. No confirmed public artifact contains that seed-based stream. The release is therefore a substantial but incomplete projection of the paper's studied mixture, not a downloadable copy of all 490,520 trajectories.
