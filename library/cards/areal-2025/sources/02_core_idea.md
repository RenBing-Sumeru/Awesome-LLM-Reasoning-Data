The feedback contract is programmatic and outcome-only. The reward service gives plus five for a correct final answer and minus five otherwise; nonzero reward appears only at the final action. Math uses rule-based string matching. Coding extracts code and executes unit tests. Completion or configured generation limits stop a rollout, while interruption for a weight load is not a task-success predicate. This identifies feedback categories but not a unified verifier artifact: exact math parser and matching rules, code-extraction behavior, unit-test suite and sandbox versions, edge cases, raw decisions and per-record terminal reasons are not published as one audit ledger.
