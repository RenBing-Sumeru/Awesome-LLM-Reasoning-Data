The final paper evaluates 12 models on 13 tasks with 4 runs per model-task pair and analyzes all 624 trajectories for failure behavior. Under its aggregate AUP comparison, Gemini-2.5-Pro ranks highest. Every model except o1-preview, Gemini-1.5-Pro, and Gemini-2.0-Flash fails to produce a valid submission on at least 1 task. These are author-reported benchmark results, not independently reproduced findings.

The failure evidence is richer than a leaderboard score. The paper distinguishes failure—no valid intermediate test-set score—from incompletion—termination after at least 1 valid score—and records evaluation, runtime, cost, format, context, permission, and other termination errors. The current public tree also preserves invalid runs: for example, GPT-4o Breakout run 0 has an empty `agent` result array while its trajectory file remains present. This supports a failure-retention claim, not an assertion that every possible error type is exhaustively released.

The public release has drifted beyond the paper experiment. At audited commit `9d40c1b5035202018cd7091fb4e83a9c68b377c0`, the repository contains 676 `.traj` files and 676 paired `results.json` files, representing 13 model-directory names × 13 tasks × 4 runs. The additional `gemini-20-pro` grid is absent from the final 12-model paper analysis; no result from that grid is evidence for the paper's tables or conclusions.

The episode schema is directly inspectable in released files, including action, observation, response, state, thought, execution time, message history, cost/token statistics, exit status, submission, and intermediate/final scores. Task configs and evaluator code are also public. This supports analysis of behavior and feedback use, while the lack of a paper-bound 624-file manifest prevents exact record-to-table reconciliation.

The evidence does not validate training use. No policy optimizer, nonzero Gym reward adapter, trained checkpoint, or agent-training result is reported. Benchmark performance also cannot establish held-out validity because repeated `validate` exposes test-set scores, nor can it establish deterministic replay, uniform licensing, decontamination, privacy review, or scientific novelty.
