The canonical paper source is the final COLM 2025 paper, not arXiv v1 or the mutable repository alone. It introduces MLGym as a Gymnasium-style shell environment and MLGym-Bench as 13 open-ended Level-1 baseline-improvement tasks spanning data science, game theory, computer vision, NLP, and reinforcement learning. The final author list has 18 authors, including Mikhail Plekhanov, who is absent from arXiv v1.

The concrete problem is how to evaluate AI-research agents that must inspect data, modify code, train models, and submit heterogeneous artifacts under resource limits. A universal answer string is insufficient: task outputs may be CSV predictions, model weights or policies, Python strategy code, or optimized training/heuristic code. Each task therefore binds a natural-language description, datasets, optional starter code, dependencies, evaluator, baseline score, timeout, and expected artifact to a containerized workspace.

For the atlas, the central object is an executed environment episode. A released `.traj` record contains `environment`, `trajectory`, `history`, and `info`. Steps include `action`, `observation`, `response`, `state`, `thought`, and `execution_time`; `info` carries cost/token/API statistics, exit status, submission, score history, and summarizer data. The object connects prompt, shell/tool behavior, observable feedback, workspace state, flexible output, verifier scores, termination, and provenance, placing it directly in `environment_agent_trajectory_data`.

The final paper's failure analysis covers 13 tasks × 12 models × 4 seeds = 624 trajectories. At the audited repository commit, current public main contains 676 `.traj` files and 676 paired `results.json` files across 13 model-directory names × 13 tasks × 4 runs. The extra `gemini-20-pro` grid postdates the final-paper comparison and is repository-release evidence only; it must not be attributed to the paper's results.

The inclusion boundary is evaluation, audit, environment design, and trajectory-release analysis. The paper presents the environment as future training infrastructure but does not demonstrate an agent-policy training run. Current `MLGymEnv.step` returns native Gym reward 0 while task metrics live in `info.score`, so the release is not evidence of an off-the-shelf RL reward contract.
