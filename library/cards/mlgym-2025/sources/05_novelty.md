Prior benchmarks already combine language models with code execution, datasets, and automated metrics. MLE-Bench, MLAgentBench, RE-Bench, ScienceAgentBench, and SWE-Agent are the paper's relevant comparison surface. MLGym does not originate shell agents, public ML datasets, task-specific evaluators, or Gymnasium interfaces.

Its concrete change is to package 13 heterogeneous Level-1 research tasks behind one task-YAML, container, command, evaluator, and trajectory contract. The submitted artifact can vary by task, yet each run exposes a comparable lineage from prompt and environment state through thought/action/observation steps to validation history, submission, exit status, task metrics, and cross-task AUP.

The release adds content depth beyond final scores: full current-grid trajectories, both valid and invalid runs, evaluator/starter artifacts, and a replay helper are inspectable. This makes failure, cost, formatting, context exhaustion, evaluator interaction, and intermediate score-seeking behavior auditable. The later expansion from the paper's 624 analyzed runs to 676 public file pairs is release evolution, not paper novelty or extra experimental evidence.

The feedback design is directionally important but also the main caveat. Repeated `validate` turns the test metric into an interactive optimization signal. The environment therefore measures how well an agent can adapt to an exposed evaluator surface under budget, not performance under a once-only hidden final test. Likewise, a Gymnasium-compatible API does not imply an RL-ready reward because native reward is 0 and metrics live in `info.score`.

For reasoning-data research, the reusable idea is the explicit binding of task configuration, environment actions, observations, workspace state, flexible artifacts, evaluator histories, failures, and replay. Before treating the files as training data, one still needs a stable version, a non-leaky split protocol, a reward adapter and demonstrated objective, exact paper/current manifests, deterministic environment pins, and reconciled rights.
