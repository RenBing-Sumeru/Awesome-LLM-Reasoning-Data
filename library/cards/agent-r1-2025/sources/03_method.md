V1 uses Qwen2.5-3B-Instruct with native function calling. The Multi-hop QA environment is NousToolEnv with one wikisearch tool over a KILT Wikipedia corpus described as 36 million passages, using bge-large-en-v1.5 embeddings and returning top five documents. Tool is an atomic executor; ToolEnv orchestrates RL state, reward and next state. V1 evaluates PPO, GRPO, REINFORCE++, REINFORCE++Baseline and RLOO, using action/loss masks and PPO advantage masks so policy updates select agent-generated rather than environment tokens. The report gives no sampling seed, record IDs, prompt templates, rollout count, inference settings, top-five retrieval logs, retained/rejected trace ledger or run-time context snapshot. Current documentation may describe append/truncate/summarize/rewrite/augment context operations, but those are later framework capabilities and are not attributed to the v1 run.
