For this atlas, the distinctive contribution is an explicit tool-environment transition and masking contract for multi-turn agent RL. V1 separates atomic tool execution from ToolEnv state/reward/next-state management, and makes action/loss and advantage masks central to credit assignment. It therefore enables comparison of agent-generated versus environment token boundaries alongside final-answer feedback. The card also captures a critical disclosure lesson: framework evolution must be version-bound. Current GSPO/StepPO, GAE/token-GAE, GiGPO, Qwen3-4B, ALFWorld, WebShop, Paper Search and step-level AgentEnv claims are later repository facts, not v1 evidence.
