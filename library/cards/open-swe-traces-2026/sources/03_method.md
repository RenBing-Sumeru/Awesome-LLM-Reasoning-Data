Construction begins with SWE-rebench-V2. The authors select 20,000 unique pull-request tasks in Python, Go, TypeScript, JavaScript, Rust, Java, PHP, C, and C++, retaining repositories labeled MIT, Apache-2.0, BSD-2-Clause, or BSD-3-Clause. MiniMax-M2.5 and Qwen3.5-122B-A10B then operate in containerized repository tasks through OpenHands and SWE-agent interfaces, exploring files, invoking tools, and iteratively producing patches.

Raw framework logs are aggregated into a common representation. Runtime validation removes environment-corrupted traces. Behavioral pruning removes maximum-iteration and premature terminations, empty patches, edits to `test_patch`, malformed or illegal concurrent tool interactions, and repeated tool errors. An AST-based `TrajectoryScanner` inspects Bash commands and rejects prohibited git-history access, including risky uses of reflog, blame, log, or diff under the scanner's context rules. The survivors are normalized into Parquet with role/content/tool-call fields and, where available, `reasoning_content`.

Repository tests supply the terminal outcome, but the release does not include per-row test commands, logs, checksums, or a cause code for `resolved=-1`. The current HF release has `openhands` and `sweagent` configurations, each with `minimax_m25` and `qwen35_122b` splits; these four source modes total 49,948, 55,488, 57,268, and 44,785 rows. The Viewer reports ten top-level fields. `reference_patch` and `model_patch` are nested inside `metadata`, together with patch-size statistics; they are not top-level columns.

For validation, the paper performs SFT on Qwen3-30B-A3B Thinking, Instruct, and Coder variants. Reported SFT settings are learning rate 1e-5, batch size 32, maximum context 131,072, warmup ratio 0.1, weight decay 0.01, cosine schedule, and three epochs. Evaluation uses up to 250 turns and 256K context with separate `/think` and `/no_think` decoding settings. Teacher-generation temperature, seeds, retry policy, raw rejection counts, exact harness/container commits, optimizer name, and public-row-to-ablation manifests are unknown.

Public verification artifacts are the arXiv paper and appendix, the NVIDIA collection, the 18.3 GB Parquet dataset, and two tool-definition JSON files. At the verified date, the official collection exposes the paper and dataset but no construction code repository or `OPEN-SWE-AGENT` checkpoint.
