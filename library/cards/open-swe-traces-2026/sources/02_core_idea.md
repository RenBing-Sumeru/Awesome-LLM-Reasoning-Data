The contribution is a released 207,489-episode corpus built by crossing two teacher modes with two agent-harness families over 20,000 unique SWE-rebench-V2 pull-request tasks. MiniMax-M2.5 supplies explicit thinking trajectories; Qwen3.5-122B-A10B supplies non-thinking trajectories. Each teacher is used with OpenHands- and SWE-agent-family interfaces, yielding four public configurations across nine programming languages.

The data unit preserves state–action evidence rather than only a terminal answer. A record carries `instance_id`, repository, repository-license label, language, `trajectory_id`, the structured `trajectory`, serialized tool definitions, `resolved`, nested patch/category metadata, and `hf_dataset_name`. Conversation turns distinguish system, user, assistant, and tool roles; MiniMax records can retain `reasoning_content`. The feedback contract is environmental and outcome-level: repository tests label a patch solved (`1`), unresolved (`0`), or unavailable (`-1`). It is not stepwise correctness supervision.

The release intentionally retains non-success episodes: 65,244 are resolved, 95,487 unresolved, and 46,758 have unavailable outcome information. Relative to a resolved-only subset, this exposes failed searches, partial progress, and harness interaction patterns that can be sampled under explicit objectives. Relative to SWE-rebench-V2 itself, the novelty lies in materializing teacher–environment interaction episodes from the task substrate; the underlying pull requests, agent frameworks, and executable-test idea are reused rather than newly introduced.
