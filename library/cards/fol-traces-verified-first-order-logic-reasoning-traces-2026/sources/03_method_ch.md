1. **生成逻辑问题。** 程序化控制谓词、变量、量词嵌套和结构，生成前提集合与查询。
2. **运行确定性求解器。** 执行证明或反例搜索，保存每个搜索状态、规则调用和中间结论。
3. **计算复杂度。** 依据公式长度、量词深度、搜索节点、分支和求解时间生成多维难度元信息。
4. **验证与清理。** 删除超时、解析失败、重复或不同求解器结论冲突样本，并保证答案可重放。
5. **形成 FOL-Traces。** 保存问题—答案—算法轨迹—复杂度；模型预训练仅是数据的下游用途。

整套构建流程需要固定原始数据版本、轨迹生成模型、提示词、标签器或执行工具、筛选阈值和 split。最终记录应保留公式、答案、求解器状态、推导操作和复杂度元信息及来源；未披露的预算、随机性和人工抽检比例应写为未知。
