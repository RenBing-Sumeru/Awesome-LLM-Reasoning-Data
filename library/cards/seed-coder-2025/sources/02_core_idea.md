The central mechanism is a cascade of learned and executable filters. DeepSeek-V2-Chat scores 222,066 files from 21 languages on a 0-10 quality scale. A pretrained 1.3B Llama-2-structured regressor is fine-tuned for one epoch to imitate those labels and removes the relative bottom approximately 10% before filtering an 89-language corpus. This is teacher imitation, not independent code correctness.

For web recall, 10M candidates are split 70/30 for fastText seeding/validation; the reported recall is 99% and precision 45%, yielding roughly 3% of Common Crawl as code-related candidates before later LLM scoring. Continued-pretraining positives start from about 100K seeds plus random/hard negatives and expand for 2-3 fastText rounds. These stages increase coverage but can propagate teacher and false-positive bias.

Post-training changes the feedback object. SFT combines LLM generation, model correctness/difficulty judgments, syntax checks, and generated-test self-correction. DPO turns on-policy candidates into about 20K preference pairs using generated-code/generated-test execution. LongCoT GRPO uses executable correctness and format signals. The exact reward formula, sandbox, compiler/runtime matrix, tests, parser, weights, normalization, and exploit controls remain unknown.

The closest comparison is DeepSeek-R1-style execution-verifiable reasoning, but Seed-Coder adds an end-to-end corpus construction and synthetic instruction pipeline. Its direction value is showing how a chain of model scorers and generated tests becomes an implicit training objective.
