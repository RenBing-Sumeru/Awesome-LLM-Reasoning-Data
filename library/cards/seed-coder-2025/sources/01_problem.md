*Seed-Coder: Let the Code Model Curate Data for Itself* is a 2025 arXiv report from ByteDance Seed with official code, project, and Base/Instruct/Reasoning weights. It asks how to scale code-model training data with less hand-written filtering, then follows the lifecycle from GitHub and web acquisition through learned quality scoring, continued pretraining, synthetic SFT, DPO, LongCoT warmup, and GRPO.

The title requires a boundary: initial code-quality ground truth comes from DeepSeek-V2-Chat; unspecified external LLMs synthesize and judge SFT data and tests; DeepSeek-R1/open traces supply reasoning warmup. Only later DPO candidates and GRPO rollouts are explicitly generated by Seed-Coder policies. “Self-curation” therefore means model-centric construction, not a target model independently creating and verifying every record.

The data objects include files, repository sequences, 74M commits from 140K filtered repositories, web code documents, FIM sequences, instruction-response pairs, generated solution/test/revision traces, chosen/rejected pairs, and long-CoT coding trajectories. The release contains weights and recipe descriptions but not data, the 1.3B scorer, generator prompts, tests, sandbox, preference records, reward code, or record lineage.

This Card belongs in the frontier disclosure ledger because the paper gives unusually concrete counts and training settings while retaining material uncertainty about feedback validity, provenance, licenses, and reproducibility.
