- **Object boundary:** Released records are offline one-step transitions. They cannot evaluate action execution, multi-step planning, recovery, environment drift, reset reliability, or terminal task success, and must not be described as complete episodes or an executable environment.
- **Judge dependence:** Generation scoring relies on a proprietary VLM and prompt parsing, with risks from verbosity, hallucination, rubric drift, API drift, and nondeterminism. The paper uses `gpt-4o-2024-08-06`, while the script defaults to `gpt-4o-mini`; unpinned use changes the feedback contract.
- **Benchmark completeness:** One of 250 generation rows lacks both required images in the official snapshot, leaving only 249 image-complete rows. QA labels are imbalanced at 1,162 Yes versus 625 No, so aggregate accuracy can conceal answer-prior behavior unless per-class metrics are reported.
- **Split and contamination:** The paper states training-source versus held-out/test-source separation, but QA rows omit source/split fields and no immutable transition IDs, screenshot/text hashes, deduplication report, evaluated-model exposure audit, or post-release contamination policy is released. Public references make leakage straightforward.
- **Failure retention:** Annotation prompts allow failed actions or no observed change, but their prevalence, balance, candidate rejection, and kept/discarded decisions are undisclosed. There are no episode-success labels or released complete source trajectories, so failure retention cannot be inferred from row counts.
- **Synthetic annotation quality:** 90% of MobileWorld uses Qwen3-VL-8B annotations and 10% Qwen3-VL-235B-A22B; training descriptions/QA are VLM-filtered without human filtering. Correlated annotator errors, judge preferences, and Qwen-family priors can survive selection.
- **Release transparency:** The 184 MB training tar contains three Parquet members without a dataset card, exact row manifest, complete schemas, source IDs, or candidate/filter lineage. Rounded components 543k + 942k equal about 1.485M, so the “1.4M” headline is not an exact release count.
- **Replay and reproduction:** No emulator/device snapshot, app fixture, executable action trace, reset routine, or deterministic replay contract exists. Exact learning rate, annotation decoding, token budget, seeds, checkpoint selection, judge retries, and API snapshot are unknown.
- **License and privacy:** Only the paper's CC BY 4.0 license is verified. Code, datasets, screenshots, annotations, and model weights have no confirmed artifact license; source mobile screenshots also lack MobileWorld-specific consent, PII/account-content filtering, takedown, and redistribution-rights disclosures.
