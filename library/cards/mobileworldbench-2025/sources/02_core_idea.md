MobileWorldBench's core idea is to isolate semantic world modeling from full agent control. Given a static current screenshot and a natural-language rendering of one human action, a model either generates the expected state change or answers a binary question about the next state. The source next screenshot is used to construct references and, for generation scoring, is visible to the judge; the evaluated model does not interact with the app or receive a multi-step history.

The feedback contract is mixed. For Next-State-Generation, a GPT-4o judge compares the prediction with the ground-truth next screenshot and reference change description, assigning 1–5 scores for **accuracy, completeness, and relevance**, with an overall total out of 15. For Next-State-QA, programmatic evaluation computes exact Yes/No answer accuracy. Human pairwise comparisons over 3,000 sampled model-output matches are additional analysis, not the primary released metric.

This feedback can observe semantic agreement with a reference transition and binary factual correctness. It cannot verify an executed environment outcome, long-horizon recovery, safety, or terminal task completion. There is no episode terminal predicate: each independent row ends after one predicted description or Yes/No answer. AndroidWorld appears only in a separate downstream planning experiment and must not be projected onto the benchmark's released feedback contract.

Relative to complete mobile-agent trajectories, the contribution is a compact transition-level prediction target that can be scaled into SFT data and evaluated offline. Relative to image-only future-frame prediction, it makes action-conditioned semantic text the target. The closest internal comparison is between MobileWorldBench evaluation rows and MobileWorld training annotations: they share the one-step object but differ in source portions, filtering, scale, and human review. Missing record-level split IDs prevent independently verifying zero overlap.
