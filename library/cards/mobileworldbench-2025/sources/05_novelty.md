The closest baseline object is a full mobile demonstration trajectory: screenshots and human actions unfold over an episode toward task completion. MobileWorldBench deliberately changes the object to independent one-step transitions and asks for semantic future-state prediction. This makes state/action supervision easier to serialize and evaluate offline, while removing the environment, history, recovery behavior, and terminal success that characterize full agent trajectories.

A second change is the paired evaluation interface. Free-form Next-State-Generation uses three-dimensional GPT-4o rubric feedback, while Next-State-QA uses exact Yes/No accuracy. The benchmark therefore exposes how a learned semantic judge and a programmatic binary check behave on two views of the same transition-prediction problem. Neither channel is an environmental verifier, and the learned side inherits model/prompt/version dependence.

MobileWorld extends the same one-step object into a large SFT construction recipe: Qwen3-VL annotators generate multiple candidate descriptions and QA pairs with access to before/action/after evidence, then VLM filters select outputs; benchmark QA adds Mechanical Turk filtering. The useful direction signal is the explicit separation among human source demonstrations, synthetic semantic annotations, offline benchmark targets, and downstream AndroidWorld planning.

The work does not newly introduce screenshots, action descriptions, VLM annotation, SFT, Yes/No QA, or LLM-as-judge evaluation. The 1.4M headline and benchmark improvements are scale/result claims, not record-quality certificates. Before reuse, one must audit the missing generation images, exact Parquet counts/schema, source/split IDs, decontamination hashes, failed/no-change retention, judge configuration, artifact licenses, privacy/consent, and third-party screenshot rights.
