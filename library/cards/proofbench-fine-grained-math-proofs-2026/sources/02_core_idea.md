The core benchmark contains 145 proof problems from USAMO, IMO, Putnam, EGMO, APMO, and TST, with 435 proofs generated by o3, Gemini-2.5-Pro, and DeepSeek-R1. Experts assign 0–7 scores using references and marking schemes. The current Hugging Face release also has 464 best-of-N rows, for 899 total; the 435 human-scored core must be distinguished from extensions.
