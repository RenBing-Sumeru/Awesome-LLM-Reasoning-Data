The main contribution is the largest cross-language vericoding collection at the time: 12,504 formal specifications, including 3,029 Dafny, 2,334 Verus or Rust, and 7,141 Lean tasks, of which the authors describe 6,174 as new unseen problems. Sources include DafnyBench, APPS, FVAPPS, VerifiedCogen, Clever, HumanEval, and NumPy documentation. Records normalize the preamble, specification, code hole, postamble, source ID, and quality metadata; `specs` stores original files, `jsonl` provides programmatic access, and `issues` preserves non-compiling translations for specification repair. Language-specific compilers or kernels are terminal verifiers, and the MIT repository releases data, construction scripts, and 55,397 experiment outcomes.
