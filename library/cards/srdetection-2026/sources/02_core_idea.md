SrDetection is a threshold-free, self-referential membership detector: a leaked code item should be easier than its functionality-preserving rewrites. The evaluation surface is one original program plus generated variants; gray-box detection compares perplexities, while black-box detection compares completion-to-reference n-gram overlap. The within-set extremum rule is the verifier. No separately downloadable benchmark dataset is identified; the repository releases code and data for the method.

The method therefore avoids inferring a universal likelihood cutoff from an unrelated corpus.
It instead asks a matched counterfactual question for every audited item.
