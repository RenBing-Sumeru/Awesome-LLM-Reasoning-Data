Logics-STEM couples two data decisions: build a broad, decontaminated long-CoT base distribution, then reshape the second-stage prompt distribution toward questions the current model fails. Retrieved documents supply knowledge for new failure-adjacent questions, while verified final answers support either continued SFT or RLVR. The reusable contribution is this explicit curation and feedback contract, not only the released model scores.
