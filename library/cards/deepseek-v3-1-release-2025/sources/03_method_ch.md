唯一明确披露的训练血缘是 V3 Base 到 V3.1-Base，再到 V3.1。V3.1-Base 沿用早期的两阶段上下文扩展方法，但加入来源未说明的额外长文档，并把 32K 与 128K 阶段分别延长到 630B 和 209B token。发布版本对权重和激活采用 UE8M0 FP8 缩放格式。此后，官方只说明 V3.1 在 V3.1-Base 上完成后训练，并未列出训练阶段、教师、过滤、奖励、采样或环境。

推理时，首轮与多轮前缀控制思考模式。多轮上下文会移除前一轮的思考内容，但保留结束标记。非思考工具调用采用严格格式，要求工具名精确匹配且参数是符合 schema 的 JSON。思考模式的搜索代理则使用独立的多轮模板，调用用户提供的搜索与 Python 工具。这些格式定义了可观察记录和运行时契约，但不能证明训练时使用了相同模板、工具或成功条件。
