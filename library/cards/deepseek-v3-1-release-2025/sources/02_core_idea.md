DeepSeek-V3.1 is an official 671B-total/37B-activated, 128K-context release that exposes two behaviors through the chat template: a think prefix enables thinking mode, whereas a closing think marker selects non-thinking mode. Its base checkpoint extends the original V3 base with additional long documents over 630B tokens at 32K and 209B tokens at 128K. The release also specifies non-thinking tool calls and thinking-mode search-agent trajectories. It states that post-training optimization improved tool and agent performance, but discloses no corresponding prompts, traces, rewards, or optimizer.
