The only disclosed training lineage is V3 Base to V3.1-Base to V3.1. V3.1-Base follows the earlier two-phase context-extension method, but expands the data with unspecified additional long documents and lengthens the 32K and 128K phases to 630B and 209B tokens. The release uses UE8M0 FP8 scaling for weights and activations. It then says V3.1 is post-trained on V3.1-Base, without naming stages, teachers, filters, rewards, sampling, or environments.

At inference, first-turn and multi-turn prefixes control thinking mode. Previous-turn thinking content is dropped from multi-turn context while the closing think marker remains. Non-thinking tool calls use a strict schema containing exact tool names and JSON arguments. Thinking-mode search agents use separate multi-turn templates for user-provided search and Python tools. These formats define observable records and runtime contracts; they are not evidence that the same templates, tools, or success predicates were used during training.
