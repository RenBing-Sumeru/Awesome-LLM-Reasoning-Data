The main evidence is difficulty under a mechanical verifier. The arXiv page identifies the accepted NeurIPS 2024 Datasets and Benchmarks version and reports that existing neural and symbolic theorem provers solve only a handful of problems. The project page makes this operational: aggregating all tried methods still proves under 1% of theorems, and few-shot GPT-4o solves only one problem in each language when given 10 attempts.

Instance-level evidence is not an aggregate accuracy number. For a row, the decisive artifact is an accepted proof script or proof term for the exact theorem statement, language version, and library state. The evidence boundary is therefore strict: scores are comparable only under the same repository revision, language subset, prompt/scaffold, attempt budget, timeout, and checker version. The official pages also show ongoing maintenance, so leaderboard claims need a date and artifact revision.
