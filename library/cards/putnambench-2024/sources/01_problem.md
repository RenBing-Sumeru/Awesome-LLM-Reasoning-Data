PutnamBench asks whether neural theorem provers can solve undergraduate competition mathematics when the target object is a machine-checked theorem, not a natural-language answer. The primary sources are arXiv:2407.11214, accepted to the NeurIPS 2024 Datasets and Benchmarks Track, plus the official TrishulLab project and GitHub repository. The arXiv v2 abstract reports 1692 hand-constructed formalizations of 640 Putnam theorems; the current project/repository report 1724 language-level formalizations across Lean 4, Isabelle, and Coq, so count-sensitive reuse must pin the source revision.

The evaluation surface is a theorem statement in a proof assistant. A system succeeds only if it produces a formal proof accepted by the relevant checker. This belongs in the atlas as a code-executable formal-math benchmark and contamination audit surface. It is not a proof-quality rubric, an informal MATH/GSM8K-style answer benchmark, or a process-supervision dataset unless proof attempts and checker traces are separately collected.
