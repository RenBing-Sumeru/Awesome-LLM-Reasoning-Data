The contribution is to turn Putnam competition problems into a multilingual formal-theorem-proving benchmark whose feedback contract is supplied by proof-assistant acceptance. The core mechanism is manual formalization of Putnam statements in Lean 4 and Isabelle for all 640 problems in the arXiv v2 framing, with a substantial Coq subset and ongoing repository maintenance. The project page also exposes factored-solution tasks for problems where the original problem asks for a closed-form object plus a proof.

Closest comparisons are informal competition-math benchmarks such as MATH/GSM8K and earlier formal-theorem-proving benchmarks that focus on one proof assistant or easier theorem distributions. PutnamBench changes the object and the verifier: the model must emit a proof term/script that the language accepts. The direction label is verifier-backed formal-math evaluation, with a reuse warning that benchmark statements are public and proof publication is discouraged to limit direct contamination.
