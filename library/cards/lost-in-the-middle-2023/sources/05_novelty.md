Prior long-context evaluations often asked whether a model could answer from a long prompt; this work changes the controlled variable to where the decisive evidence sits. The direction signal is useful because it turns an aggregate long-context score into an audit over context position. The quality signal is the paired construction: same answer target, varied placement, answer-level scoring. What is not new is retrieval QA, synthetic key-value lookup, or exact-answer scoring. Reuse should inspect prompt formatting, distractor source, generated splits, scorer behavior, license, and contamination from public examples.
