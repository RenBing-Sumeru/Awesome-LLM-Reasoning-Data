BEARCUBS is a COLM 2025 benchmark for information-seeking agents that must use the live public web, including videos, maps, games, virtual tours, interactive databases, and multilingual sites. Its motivating gap is that conventional search QA can often be solved from indexed text, whereas computer-using agents must perceive rendered pages, manipulate interfaces, and recover evidence through changing websites. The benchmark therefore asks whether a system can complete difficult text-based and multimodal web tasks, not merely whether it can reproduce a memorized fact.

The paper’s benchmark object is richer than the downloadable object. Internally, an item joins a question to one concise gold answer, a text-based or multimodal category, a viable human browsing trajectory, and visited websites. An evaluated run adds the agent answer, elapsed time, a recorded trajectory, and an answer-level outcome. By contrast, the public BearCubs_20250310.json.zip contains 111 question-only records. It does not expose gold answers, category labels, URLs, human or agent trajectories, model outputs, timing, outcomes, provenance, or a split manifest.

That distinction controls this Card’s scope. BEARCUBS belongs in environment_agent_trajectory_data as an evaluation and audit surface because the paper studies interaction paths, runtime, source quality, and terminal outcomes. It is not a verified public trajectory corpus, replay environment, or training dataset. The accepted status remains partial and L3_summary_ready; this bilingual Card adds reading depth without upgrading the curation decision.
