The core design is a small, manually validated set of 111 live-web questions whose answers are concise and uniquely gradable but deliberately resistant to ordinary Google Search. The retained set contains 56 text-based and 55 multimodal questions across 108 distinct top-level URLs. Human viable paths average 6.1 steps, ranging from 3 to 14, and 3.4 webpages, ranging from 1 to 8. These statistics describe the authors’ internal benchmark and validated paths; they are not fields in the public JSON.

The intended data object has three layers. The task layer contains the question, gold answer, modality/category, viable path, and visited sites. The episode layer contains live-web observations, page visits, pixel-mediated mouse and keyboard actions for computer-use systems, critical interactions, the final answer or abstention, elapsed time, and trajectory. The feedback layer assigns one of four answer labels—correct, wrong, no_answer, or no_direct_answer—and can reduce them to binary accuracy. No training reward or dense process reward is defined.

Published correctness is based on manual judgment that the returned answer directly and unambiguously entails the gold answer. The optional released autorater sends question, gold_answer, and model_answer to GPT-4o-2024-11-20 at temperature 0 and produces the same four-way label. Neither manual nor automatic answer judgment verifies that the agent used the intended source, modality, or interaction path. Trajectories and source attribution are analyzed after the fact rather than used as the primary correctness verifier.

The public release exposes only question IDs and question strings. Gold answers are gated case by case for non-commercial research, and the project policy prohibits redistribution or open-sourcing them. The project page links only three example trajectories for one displayed question. Consequently, the public package cannot reconstruct the task layer, score a model with the autorater by itself, reproduce the 56/55 category split, or replay complete successful and failed episodes.
