The contribution is to provide a scale that is not fully pinned in local metadata and must be checked against the official release before quantitative reuse for mcp-tool-use, multi-tool-agents under a reusable evaluation surface. The core mechanism is the pairing of task inputs and model outputs with the following feedback contract: official harness scoring; exact per-task mix of deterministic checks, execution checks, and judge logic should be pinned from the repository revision.

The data object or environment is Model Context Protocol servers and their exposed tools. The closest comparisons are agent-environment, tool-use, and benchmark-harness papers in the same atlas category. The direction label is benchmarks_evaluation_surfaces with a environmental, mixed feedback contract. The main thing to preserve is not only the headline score, but the task object, evaluator, split/version, and artifact lineage.
