MCP-Atlas: An Agentic Benchmark for Evaluating Tool Use in Large Language Models defines an evaluation surface in mcp-tool-use, multi-tool-agents: whether model outputs or agent trajectories satisfy the task-specific feedback contract. The primary source and artifacts are paper: https://arxiv.org/abs/2602.00933; code: https://github.com/lastmile-ai/mcp-atlas; the local metadata records the source as 2026 / arXiv preprint.

The decision boundary is benchmarks_evaluation_surfaces with roles benchmark, agent_environment and verification contract environmental, mixed. One benchmark instance is: natural-language user goal, available MCP servers and tools, model tool-selection or tool-execution trajectory, final answer, and benchmark score. This is not a model-training recipe unless the paper separately releases training data; the card treats it as evaluation, audit. It matters for the atlas because the reusable object is an evaluation/data record with a named scorer, judge, verifier, reward, or environment predicate rather than an abstract capability claim.
