公开边界使完整重放与 provenance audit 无法实现：两个 SFT JSONL 文件没有提供原始 live trajectory、rejected rollout、逐 iteration/query 映射、timestamp、捕获的 browser state、model checkpoint，或逐 row 的 real-versus-synthetic manifest。Llama-3.3-70B 在没有报告 calibration 或 human agreement 的情况下判断自身训练轨迹是否成功，因此 false acceptance 与 false rejection 可能通过后续 SFT 被放大。语言模型 world model 会产生虚构网页状态，论文的 intrinsic score 在深度超过二以后低于 0.50；作者认为噪声可能增加训练多样性，但并未证明条目级正确性。真实网站会变化，实验因访问问题排除了 48 个 Mind2Web 网站和五个 WebVoyager 网站，重复实验也只是尽量安排在相近时间窗口。Dataset 与 code 声明 MIT，但 message text 所含第三方网页内容的权利或同意、decontamination、duplicate control 与 evaluation-query overlap 均为 unknown。GPT-4o evaluation 与 WMLA scoring 还引入了一个不同于自我改进循环的外部 judge。
