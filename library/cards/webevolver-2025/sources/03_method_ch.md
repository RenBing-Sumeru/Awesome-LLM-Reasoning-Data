训练从 1,516 个 query 开始，其来源是 Mind2Web training set，以及面向 WebVoyager 和 Mind2Web 所含网站的 self-instructed queries。Cognitive Kernel 通过 Playwright 操作真实网站，以 accessibility tree 为 observation，动作空间包括 `click`、`type`、`scroll`、`goback`、`restart` 和 `stop`；交互在任务完成或达到 step limit 时终止。Llama-3.3-70B 既采样轨迹，也为 rejection sampling 提供二元完成度判断。成功样本在论文报告的三轮 self-improvement 中累积，并用常规 SFT 优化，而不是 end-to-end RL。真实轨迹还被转换为 world-model example，transition rationale 由原始 Llama-3.3-70B 提供。合成阶段让 iteration-2 world model 与 iteration-1 policy 交替生成，最多七步，并再次筛选结果。推理阶段的 WMLA 最多采样三个候选动作：第一个使用 temperature 0，其他动作使用 0.7 并附加差异化指令；随后模拟一至三层深度，由 GPT-4o 最高分决定执行动作。官方仓库提供采样与转换脚本，但逐 query rollout 数、接收数量、训练采样温度、完整 fine-tuning 设置和 checkpoint 仍为 unknown。
