WebEvolver 并未分别发明 iterative SFT、rejection sampling、web-agent world model 或 look-ahead scoring。相较于 OpenWebVoyager 风格的自我改进，它的具体变化是：在同一交互循环中共同演化一个预测 transition 的 LLM，并让该模型同时承担额外 policy-training trajectory 的生成器和推理时候选动作模拟器。相较于 WebDreamer 与 WMA，论文强调其 world model 会参与训练数据构造，并生成最长七步的 synthetic rollout，而不只是静态的一步或短视野 prompting 组件。对本 Track 而言，真正有用的新意是把 real rollout、judged acceptance、world-model SFT、synthetic rollout、第二次 acceptance 与 policy SFT 串成同一 lineage。论文描述了这条 lineage，代码也实现了其中一部分，但公开 SFT 文件没有提供可逐 row 审计各阶段的 manifest。
