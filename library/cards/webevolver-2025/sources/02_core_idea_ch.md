该方法共同训练一个 Llama-3.3-70B policy 和一个 Llama-3.3-70B world model。通过完成度筛选的真实浏览器轨迹既监督 policy，也会被转换为 transition example：world model 根据最近的 observation/action 历史及由 base model 生成的 transition rationale，预测下一棵 accessibility tree。随后，iteration-2 world model 充当虚拟 web server，与 iteration-1 policy 的动作交替生成最长七步的 synthetic trajectory，目标是处理真实自我改进阶段未完成的 query；通过完成度筛选的合成轨迹再加入 policy SFT。WMLA 是另一条独立的推理时分支，它用 world model 模拟候选动作，并由 GPT-4o 评价预测进展。因此，训练数据接收依赖 Llama-3.3-70B 的二元判断，真实执行提供 environmental feedback，WMLA 使用 GPT-4o scalar judge；三者都不是程序化正确性证明。
