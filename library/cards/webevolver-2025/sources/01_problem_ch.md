WebEvolver 发表于 EMNLP 2025，所处理的问题是：Web agent 反复用自身在真实网页上完成的成功轨迹进行训练时，可能因探索不足、未充分利用 LLM 预训练阶段获得的网页知识而停止改进。论文层面的数据对象包括 query、accessibility-tree observation、chain-of-thought/action 决策、完成度判断，以及 world model 生成的下一步 observation；但公开对象更窄，Hugging Face 只提供 agent policy 与 world model 的两个 JSONL SFT 文件，并以聊天 `messages` 表示，而不是原始真实/合成轨迹、被拒绝尝试或可重放浏览器状态。正是这一边界使它与 `rollout_search_test_time_trace_data` 相关：多条真实与想象 rollout 影响训练和 WMLA 动作选择，但官方数据发布中可复用的只有其 SFT 序列化结果。
