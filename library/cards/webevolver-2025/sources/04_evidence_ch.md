ACL Anthology 核验了 EMNLP 2025 论文、作者、页码 8959-8975 和 DOI，arXiv 则链接到 Tencent 官方仓库。官方 Hugging Face 发布声明 MIT，展示一个约 13.5k 行、只有 `messages` feature 的 train split，并包含 `webevolver_policy_sft.jsonl`（23.9 MB）与 `webevolver_world_model_sft.jsonl`（76.2 MB）；已接受元数据记录两者合计 13,465 条 SFT row。论文中，WebEvolver 在含 473 个 query 的 text-only WebVoyager 上得到 42.49，而 zero-shot Llama-3.3-70B agent 为 32.98；depth two 的 WMLA 达到 51.37。论文还在过滤后的 53-query Mind2Web-Live、GAIA-web 和 SimpleQA 上报告实验。World-model evaluation 显示，深度超过二以后，structure、similarity 和 overall score 均下降。这些结果只支持该配方在所测试模型、过滤网站、judge 和时间窗口下的表现，不能证明每条公开 SFT row、synthetic state 或 self-judgment 都正确；benchmark performance 也不是数据质量证据。
