HarnessFix is a 2026 arXiv paper and official GitHub release about a narrow agent-evaluation problem: many low scores in LLM-agent benchmarks can be caused by flaws in the harness rather than by the agent alone. The paper studies failed trajectories from four benchmarks, SWE-Bench Verified, AppWorld, Terminal-Bench 2.0, and GAIA, and asks how to diagnose whether the benchmark setup, environment, evaluator, or task specification caused the failure.

The data object is not a new training trace corpus; it is a harness-defect record derived from failed agent trajectories, with the failed run, expected benchmark feedback, a flaw diagnosis, and a repair. The feedback contract is benchmark-specific execution plus a repaired-harness validation check. The atlas value is that it turns agent-evaluation infrastructure itself into an auditable object: score reuse must distinguish agent mistakes from harness-induced failures.
