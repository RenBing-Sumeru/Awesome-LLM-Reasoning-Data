**Data and training.** The card names four pretraining source classes, standard de-duplication/classification, targeted mid-training, and SFT/RL on human feedback, verifiable rewards, and model-based graders (card §3.1). It does not identify a prompt source, model checkpoint, dataset count, mixture, teacher, sampling protocol, optimizer, reward mix, or split.

**Safety-training path.** xAI says it trains demonstrations of appropriate responses to benign and harmful queries. Its input filter rejects classes such as bioweapon, chemical-weapon, self-harm, and CSAM requests; filters are trained with mixed synthetic and production data and Grok-generated adversarial attacks (card §2.1.1). This is evidence for filter training, not evidence that production data enter the base model or general post-training set.

**Evaluation path.** An internal multilingual refusal set is separately model graded; AgentHarm assesses malicious agentic tasks and AgentDojo assesses prompt injection. Input-filter tests use an internal restricted chem/bio set; jailbreak tests use internal templates. Thinking and Non-Thinking use a production system-message instruction. Dual-use capability tests remove safeguards (card §2). None publishes prompts, labels, grader version, tool setup, instance IDs, system-message instruction text, filter version, or logs.

**Announcement path.** xAI reports the same large-scale RL infrastructure as Grok 4, agentic reasoning reward models for non-verifiable signals, and a November 1–14 silent rollout with continuous blind pairwise live-traffic evaluations. It also evaluates hallucination on a stratified sample of production information-seeking queries. The sources do not say these traffic records trained Grok 4.1 or disclose consent, retention, data separation, or aggregation.
