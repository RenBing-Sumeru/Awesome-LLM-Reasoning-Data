The study is limited to Python, 27 repositories, one offline training iteration, and a simplified Agentless scaffold, so cross-language, cross-scaffold, and online-RL behavior remain unknown. Repository-level non-overlap with the SWE-Bench test repositories is asserted, but the authors acknowledge possible pretraining contamination; item-level decontamination is not reported. Guidance generation is privileged: the appendix prompt exposes the reference patch and, for environment-feedback guidance, the previous trajectory and stack trace, so reuse must preserve whether a hint contains answer or localization leakage. The source counts are internally inconsistent (593 + 219 does not equal 817), and six evaluation environments did not compile. Unit tests may be incomplete and a passing patch is only a terminal predicate, not validation of every intermediate action. No official dataset, code, trajectories, model, exact task list, collection seeds, collection temperature, license, or full reproducibility package was found; benchmark improvements cannot substitute for those missing audit artifacts.
