与只从独立成功 rollout 进行普通 RLVR 相比，Agent-RLVR 在失败与策略更新之间加入 teacher 辅助的再次尝试，利用环境信息让新的成功轨迹更容易被采到，同时继续以单元测试执行作为终局 verifier。与 rejection-sampling SFT 相比，它为同一任务构造 winning/losing 的完整轨迹对并进行 offline DPO；与普通测试时采样相比，它又复用已收集的 patch 数据训练 pairwise reward model 进行选择。对本图谱而言，方向性信号在于环境状态、失败轨迹、特权 guidance、再次尝试、测试奖励和下游 preference pair 之间的显式连接。Guidance、offline DPO、单元测试评分和 Agentless 风格的 localization/repair 各自都不是新方法；贡献在于它们被组合成适用于稀疏奖励软件 agent 训练的特定构建闭环。
