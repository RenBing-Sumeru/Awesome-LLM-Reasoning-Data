RLVR is straightforward when a short answer can be checked, but software-engineering agents must navigate repositories, interact with execution environments, and make multi-step edits before receiving a sparse terminal signal. Agent-RLVR addresses this setting with records built around a GitHub issue, a Python repository snapshot, a Docker environment, tests, a full agent trajectory and patch, the test outcome, optional guidance, and a guided reattempt. The paper reports 817 training environments across 27 repositories and 8,186 collected trajectories, but does not release those records. For the rollout/search/test-time trace track, the relevant object is therefore not the reported SWE-Bench score; it is the environment-grounded lineage connecting an attempted trajectory, executable feedback, teacher guidance, a new trajectory, and a terminal reward.
