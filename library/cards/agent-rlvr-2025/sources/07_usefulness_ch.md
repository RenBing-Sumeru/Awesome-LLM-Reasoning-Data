对 rollout、搜索与测试时轨迹这一分类，Agent-RLVR 可作为记录“反馈如何改变探索过程”的 schema。可复用记录应保留 issue 与仓库 revision、Docker image、scaffold 与 tool call、初始轨迹、生成或为空的 patch、精确测试执行、二值结果、teacher 身份与 prompt 输入、各类 guidance、带 guidance 的再次尝试、同任务 winning/losing pair、SFT/DPO 归属以及 reward-model score。它也说明了三种判定必须分开保存：通过环境测试、在 offline training 中被偏好，以及被学习型 reward model 选中。研究者可以据此比较 guidance 辅助的 rollout 构建、环境奖励、偏好转换和测试时 patch 选择，但论文本身并未授权复用未发布的环境或轨迹。
