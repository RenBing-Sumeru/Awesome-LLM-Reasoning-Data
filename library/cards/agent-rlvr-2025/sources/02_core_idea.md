The core mechanism is guidance-assisted exploration without replacing the verifiable terminal predicate. An agent first attempts a task without guidance; its patch is run against the environment tests. For a failure or missing patch, an external teacher produces three possible information channels: a plan, environment-feedback guidance based on the failed attempt and stack trace, and environment-interaction guidance pointing to relevant code locations. The agent reattempts during training, and correct versus incorrect trajectories for the same task become preference pairs for offline DPO. Positive non-guided traces also supply SFT data, while problem-statement/patch pairs are reused to train a pairwise reward model that ranks 32 patches at test time. Thus the feedback contract combines a binary environment reward, full-episode trajectories, and derived pairwise preferences; guidance is a search aid, not the correctness judge.
