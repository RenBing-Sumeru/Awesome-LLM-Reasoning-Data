数据集包含 issue description、完整仓库快照、Docker 环境、回归测试与定向测试、guidance 和 agent 轨迹。论文称其中 593 个问题来自 SWE-Gym，另有 219 个问题通过类似的抓取与标注流程自行收集，但两者相加为 812，与报告的 817 个环境不一致。引导与无引导采集阶段均对每个问题采样 16 条轨迹，最终得到 8,186 条轨迹，其中 4,093 条为 positive；on-policy 轨迹来自 Qwen-2.5-72B-Instruct，off-policy 轨迹来自 guidance 模型 claude-3-7-sonnet-20250219。系统使用只保留 localization 和 repair 的简化 Agentless scaffold。20% 的正确无 guidance 轨迹用于 SFT，训练 5 个 epoch，learning rate 为 1e-5、sequence length 为 8k；完整 preference data 用于 1 个 epoch 的 DPO，learning rate 为 1e-6。每条 winning trajectory 必须通过全部任务测试，再与同一任务的错误轨迹配对。独立的 Qwen-2.5-Coder-32B reward model 以 pairwise loss 训练 500 steps，learning rate 为 1e-5、warmup ratio 为 0.05，随后对 k=32 个 patch 排序。论文未披露采集温度、seed、精确任务清单，也未解释每题采样数如何与最终轨迹总数对应。
