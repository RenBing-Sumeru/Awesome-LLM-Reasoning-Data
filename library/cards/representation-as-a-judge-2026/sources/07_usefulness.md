If you have prompt–response reasoning records and a calibrated teacher judge, use INSPECTOR's representation-plus-probe pattern to rank or filter them before SFT. The required inputs are a fixed base LM, judge-scored examples, and a held-out calibration set; the output is an aspect score/filter decision. Verify correlation with independent labels and downstream data-ablation gains. Do not use it when no trustworthy teacher/reference is available or when prompt/model drift has not been audited.
