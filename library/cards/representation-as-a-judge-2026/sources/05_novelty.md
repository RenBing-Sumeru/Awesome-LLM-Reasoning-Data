Prompt-based LLM judges obtain a verdict by generating text, while earlier small-model baselines treat weak generation as weak evaluation. This work moves the decision object from decoded output to internal representations and trains probes to imitate aspect-level judge scores. The new element is this representation-as-a-judge framing and probing route, not the use of an LLM teacher or data filtering itself. Before reuse, compare teacher-label fidelity with independent human calibration and test layer/model transfer.
