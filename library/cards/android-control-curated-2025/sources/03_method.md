Construction begins from AndroidControl human demonstrations; the upstream official publication reports 15,283 demonstrations, 14,548 unique tasks, and 833 apps. The exact AndroidControl revision consumed by this release is not disclosed.

The purification pipeline is:

1. Convert exact-point grounding into intent-aligned box scoring: a predicted point is accepted when it falls within the bounding box of the UI element containing the annotated ground-truth point (Paper §2.1.1, Eq. 4–5, p. 3).
2. Run Qwen3-VL-235B, InfiGUI-R1, and GUI-R1 on tasks and send consensus failures to the correction stage (Paper §2.1.2, Eq. 6, p. 3). Run counts, prompts, and decoding settings are unknown.
3. Ask an undisclosed LLM reviewer for a deficiency category, task revision, ground-truth revision, and rationale; have human experts verify proposed corrections before applying accepted changes (Paper Eq. 7, pp. 3–4; Algorithm 1, p. 5). Panel size, sampled fraction, agreement, and acceptance thresholds are unknown.
4. Release high/low point and box views plus `android_control_high_task-improved.json`. The latter may retain `revised_task`, `revised_memory`, `candidate_predictions`, `candidate_actions`, `candidate_review_result`, `org_gt_action`, and `gpt_corrected` beside the static screenshot, history, and action target (official dataset JSON).

For evaluation, model text is parsed from the `answer` and `action` XML-style tags; action names are normalized, click/long-press predictions are scored by predicted-box-center containment or a point-distance threshold, input text is accepted by substring/token-F1 at 0.5, and improved tasks can match any retained candidate action. The evaluation script uses vLLM with temperature 0.0, top-p 0.001, repetition penalty 1.05, and 512 maximum tokens; these are evaluation settings, not established GRPO rollout settings (`src/eval/utils.py`; `src/inference/vllm_inference_Qwen2_5_VL_7B_SFT_batch.py`).

For Magma-R1 post-training, the authors select 2,400 curated samples, use GRPO with a PPO-style clipped ratio and within-group reward normalization, assign a continuous Gaussian grounding reward from predicted-box-center distance to the ground-truth point, and stratify action sampling to increase rare type/scroll actions (Paper §2.2, Eq. 1–3, p. 4; Algorithm 1, p. 5; §3.1, p. 5). Group size, Gaussian sigma, clip epsilon, optimizer, learning rate, epochs, target action proportions, random seeds, and the 2.4K IDs are unknown; no GRPO trainer/config was found in the official repository.

Reproduction must pin the five JSON hashes and screenshot archives, GitHub commit, dataset revision, scorer and prompt code, model revision, and exact checkpoint. It must also supply the Easy/Hard mapping, train/evaluation overlap audit, and live environment if terminal success is claimed. The README evaluation command/path and the released entry point do not constitute a complete Tables 1–2 reproduction workflow, and the current model repository mixes a paper-era 3B root configuration with later 4B material.
