Earlier autoformalization datasets usually start from existing natural-language problems and ask models or experts to write Lean translations, so scale is constrained by the problem pool and human validation. ATLAS changes the starting point: it extracts seeds from Mathlib concepts and proof structures, synthesizes corresponding natural language, and returns to formal language for verification. Teacher-student distillation and LoRA are not new. The novelty lies in Data Lifting and formal-structure augmentation, which turn Mathlib itself into a renewable data source controlled by a compilation–back-translation–NLI validation chain.
