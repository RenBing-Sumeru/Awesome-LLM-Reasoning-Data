CLAIR starts from an instruction and an existing response, obtains feedback about its weaknesses, and generates a targeted revision that changes only the necessary content. The original and revised responses form a contrastive preference pair after quality checking. The authors train Llama-3-8B-Instruct on comparable 32K datasets using DPO-like objectives and several APO variants. APO anchors likelihood changes relative to the reference policy, distinguishing settings where the chosen answer should be raised, the rejected answer lowered, or both. Evaluation uses MixEval-Hard and supporting alignment benchmarks.
