The paper introduces CLAIR, which asks an AI reviser to minimally improve a response so that chosen and rejected answers are highly contrastive, and Anchored Preference Optimization (APO), which lets training explicitly control the desired movement of each response likelihood. It releases UltraFeedback-CLAIR-32K and code. The data contribution is a 32K set of minimally revised preference pairs whose differences are more attributable to quality, while APO supplies a family of objectives matched to the expected quality of the starting policy.
