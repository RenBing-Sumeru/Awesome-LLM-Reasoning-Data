1. **构建混合数据。** 输入是公开指令数据集和任务集合。作者修订 Tulu V1，移除效果较弱的来源，并加入对话、代码、CoT、Orca、WizardLM、LIMA 和科学类记录，产出 326,154 条 SFT 样本。检查时应保留每条数据的来源标识、许可证和精确版本。

2. **监督微调。** 输入是 Tulu V2 混合数据，以及 7B、13B、70B 的 Llama 2 或 Code Llama 基座。按照论文配方用目标回答进行全参数微调，产出 Tulu 2 和 Code Tulu 2 checkpoint。复现时需固定基座 checkpoint、序列长度、混合权重和优化器设置。

3. **加入偏好优化。** 输入是 Tulu 2 checkpoint 和 UltraFeedback 偏好对。以 `5e-7` 学习率运行三轮 DPO；70B 模型使用 512 核 TPUv3，训练约七天，产出 Tulu 2 + DPO checkpoint。检查稳定性、回答冗长度、多语言退化以及训练数据与评测集重叠。

4. **评测并发布。** 输入是仅经过 SFT 和进一步经过 DPO 的 checkpoint。用统一工具评测能力、安全、代码和开放式生成，输出逐任务分数、汇总比较、代码、数据与模型。只有提示和解码规则相同时才能比较，也不能把整套配方的收益只归因于数据。
