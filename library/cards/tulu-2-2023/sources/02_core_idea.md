Tulu 2's contribution is an openly documented adaptation package in which instruction-response records supervise SFT, preference pairs supervise DPO, and a common harness evaluates the resulting checkpoints. Compared with Tulu V1 and one-shot data releases such as LiMA, it makes the mixture revision, later preference stage, model scaling, and evaluation outputs inspectable as separate objects. This belongs in a data primer because it exposes how heterogeneous post-training data and feedback are assembled and consumed.

Open dataset: yes. **Tulu V2 SFT Mixture**, https://huggingface.co/datasets/allenai/tulu-v2-sft-mixture, contains 326,154 instruction-response examples drawn from FLAN V2 CoT, Open Assistant, ShareGPT, GPT-4-Alpaca, Code-Alpaca, LIMA, WizardLM, Open-Orca, hard-coded prompts, and a 7,544-example science mixture. It is distributed through Hugging Face with source/configuration fields and conversation or instruction-response records for supervised fine-tuning; formats and licenses remain source-dependent. Code and checkpoints are at https://github.com/allenai/open-instruct and https://huggingface.co/collections/allenai/tulu-v2-suite-6551b56e743e6349aab45101.
