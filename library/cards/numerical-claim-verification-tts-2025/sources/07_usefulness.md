Use this paper when a fact-checking service must reserve costly multi-path reasoning for claims likely to need it. Log the retrieved evidence, predicted complexity, routing choice, sampled paths, verifier scores, verdict, token cost, and latency. Compare uniform Best-of-N, single-pass verification, and complexity-routed scaling with the same retrieval corpus. It is particularly useful for designing an escalation policy: a simple claim should not receive the same inference budget as a claim that requires reconciling dates, units, quantities, and multiple evidence sources.
