The distinctive contribution is not only using a verifier for Best-of-N. It makes the decision to invoke Best-of-N itself conditional on an instance-level estimate of complexity. This creates a routing policy between a cheap one-path consumer and an expensive multi-path, verifier-selected consumer, so compute is part of the fact-checking decision rather than a fixed global setting.

The paper also frames reasoning drift as a failure that can occur despite relevant evidence and despite long reasoning. Multiple candidate paths are therefore not treated as a generic way to “think more,” but as alternatives from which a verifier can recover an evidence interpretation that one drifting path abandoned. This is a useful pattern for settings where correctness is evidence-grounded but not reducible to a simple executable test.
