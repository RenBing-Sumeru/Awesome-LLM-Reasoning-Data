The pipeline retrieves evidence with BM25 and reranking, then samples multiple claim-verification paths from an LLM. VERIFIERFC is trained on claim, path, and predicted verdict triples, using both paths whose verdict matches expert labels and paths whose verdict does not. At inference, the verifier scores the paths and the highest-scored path supplies the selected verdict.

For adaptive scaling, the system estimates claim complexity from layer-wise latent representations using a semi-supervised decomposition signal. Rather than applying Best-of-N uniformly, it allocates the more expensive verifier-guided search to claims predicted to require it. This ties the stored objects—claim, evidence, paths, scores, complexity, and verdict—to a direct budget decision for every test instance.
