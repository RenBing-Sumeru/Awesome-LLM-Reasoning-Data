AgentPack asks whether public code changes co-authored by software engineering agents and humans can serve as higher-quality code-editing data than older human-only commit corpora. The primary source is arXiv:2509.21891v2, dated 27 March 2026, and the official Hugging Face dataset page. The current paper reports 1.8M code edits from Claude Code, OpenAI Codex, and Cursor Agent across public GitHub projects from April to October 7, 2025; the Hugging Face card still describes an earlier 1.3M-commit snapshot through mid-August 2025.

The data object is not a full agent interaction trace. It is a mined code-change record: agent attribution metadata, repository/commit or pull-request identifiers, natural-language change description, git patch, affected file snippets or hunks, and derived labels/statistics. The atlas boundary is software-engineering agent data and code-editing supervision, not an executable environment benchmark. Feedback is implicit: the change appeared in public GitHub activity and often passed through human maintainer acceptance, while training value is tested later on code-editing benchmarks.
