Correctness is not mechanically certified for every edit. The dataset lacks the original prompts and full human-agent conversations, the exact model behind Cursor Agent is uncertain, and many changes may have been refined by humans before merging. Failed or discarded agent attempts are mostly missing, so AgentPack reflects successful visible collaborations rather than total agent capability.

The corpus is restricted to public GitHub activity and to attribution patterns that leave detectable signatures. GitHub API changes after October 7, 2025 affect comparable future collection. Reuse also carries license, privacy, secret leakage, repository deletion, duplication, benchmark contamination, and security-risk concerns. The Hugging Face page requires accepting access conditions, and its current card describes an earlier snapshot than the arXiv v2 paper.
