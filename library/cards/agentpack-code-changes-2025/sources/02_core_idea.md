The one-sentence contribution is a large corpus of real-world code edits co-authored by three named coding agents and humans, with an extraction pipeline and evidence that fine-tuning on the corpus improves code-editing benchmarks. The core mechanism scans GH Archive public events, identifies agent-authored activity through signatures or PR links, fetches repositories and patches, filters misattributed dependency code such as node_modules, and formats edits for training.

Closest comparisons are CommitPackFT, CanItEdit, HumanEvalFix-style editing benchmarks, and synthetic code-instruction corpora. AgentPack changes the data source: instead of short human commit messages or synthetic prompts, it uses agent-written rationales and multi-file edits that were integrated into public repositories. The feedback contract is weaker than a unit-test verifier per item but stronger than unfiltered web code because public project acceptance and downstream pass@1 evaluations provide external evidence.
