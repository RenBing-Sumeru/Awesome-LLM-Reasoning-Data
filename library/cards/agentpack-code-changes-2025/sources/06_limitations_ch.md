并非每条 edit 都有机械化正确性证书。数据缺少原始 prompt 和完整人机对话；Cursor Agent 背后的具体模型不确定；许多变更可能在 merge 前被人类进一步修改。失败或被丢弃的 agent 尝试大多不可见，因此 AgentPack 反映的是可见的成功协作，而不是完整 agent 能力。

语料限于公开 GitHub 活动和会留下可检测签名的归因模式。2025 年 10 月 7 日之后 GitHub API 字段变化会影响未来同类收集。复用还涉及 license、隐私、secret 泄漏、仓库删除、重复代码、benchmark contamination 和安全风险。Hugging Face 页需要接受访问条件，且当前卡片描述的是早于 arXiv v2 的数据快照。
