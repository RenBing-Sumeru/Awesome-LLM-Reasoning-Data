The prior baseline was mining human commits, pull requests, or synthetic code-instruction data. AgentPack changes the source to human-agent collaborative code changes from public GitHub activity shortly after the deployment of coding agents. The direction signal is that real agent use can become code-editing supervision, but only if attribution, provenance, and human acceptance are auditable.

Quality signals include the systematic GH Archive pipeline, named agent attribution rules, node_modules filtering, large scale, multilingual code coverage, task-type analysis, Apache-2.0 dataset license on Hugging Face, and fine-tuning improvements over prior editing data for several model/benchmark pairs. What is not new is the code-editing objective or the use of commit diffs as supervision. Reuse must inspect access conditions, license compatibility of source repositories, exact snapshot date, PII/secrets risk, duplicated code, attribution errors, and whether downstream benchmarks overlap with mined repositories.
