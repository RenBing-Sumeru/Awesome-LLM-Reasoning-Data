此前的开放推理数据已经使用教师蒸馏、答案过滤、多候选、LLM judge 和长 CoT SFT；OmniThought 并非首次提出这些组件。它更具体的变化，是为每个问题保留多条答案有效候选，把推理有效性与答案接收分开，并为每条保留轨迹记录教师身份及两个用于学生模型适配选择的整轨描述量。

Reasoning Verbosity 不等于简单长度：论文把 QwQ-32B 对“推理量是否适合该问题”的判断与对数归一化 token 长度结合。Cognitive Difficulty 也不只是题目难度：它估计理解并复现所选推理方法所需的能力。下游选择规则再使用目标能力 `mu_CD` 和 CD-RV 间距为特定学生采样轨迹。这样，模型能力、轨迹方法与冗长度成为显式构造变量，而不只是事后观察。

该工作还把同一个发布对象连接到三种训练接口。SFT 从 RV-CD 空间采样；DPO 构造同题冗长度偏好对；GRPO 学习标量 RV/CD 预测器，并把其输出加入格式奖励与准确性奖励。价值在于共享的元数据底座和受控比较，而不是声称三种目标语义相同。特别是，DPO 的 chosen/rejected 关系针对期望冗长度，GRPO 的 RV/CD 项则是学习得到的奖励。

这一方向信号具有条件性，不是普适规律。报告中的最优值从 7B 学生的 `mu_CD=5` 移到 32B 学生的 7；论文从 100K 到 1.1M 的扩展表也显示边际收益递减。因此，复用时应在目标模型和领域上重新验证选择规则。由于生成设置、逐行来源 lineage、验证器资产、精确训练子集和冻结的端到端构造配置均不可用，这项贡献仍属于部分披露。
