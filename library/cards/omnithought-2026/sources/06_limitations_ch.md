- **来源 lineage：** 发布 schema 没有题源或领域字段。虽然来源族和总体领域已知，但仅凭公开行无法把具体问题映射回上游 revision 或许可。
- **生成披露：** 每条被接收轨迹保留教师身份，但教师比例、每题请求数、采样 temperature/top-p、最大输出、随机种子、重试、原始候选数和被拒生成均不可用。
- **保留语义：** 论文验证器把推理有效性与解答有效性分开，但只有解答错误才强制移除。因此，答案正确但局部推理无效的轨迹可以保留；`thought_correctness_verify` 是整体判断，不能定位首个错误。
- **验证器重放：** 代码测试、runner 版本、sandbox、超时、数学/科学归一化规则、LLM judge 设置和逐候选证据未发布；假接收与假拒绝率未知。
- **RV 构造：** 最终 RV 混合模型判断与 token 长度。发布没有提供原始 judge 分量、归一化长度分量、tokenizer、`L_min` 或 `L_max`，因此不能仅凭行内容精确重算显示分数。
- **CD/RV 校准：** QwQ-32B 既是核心数据标注器，也是报告审计的参照对象。平均绝对差低于 2 不等于精确一致，也未提供逐级混淆、领域校准、不确定性或相同范围适配无关学生模型的证据。
- **选择偏差：** 随机移除部分少于 3,000 token 的轨迹，可能压低简洁或简单样本的占比；移除比例、随机种子、来源分布及其与教师风格的交互未披露。
- **发布计数：** 固定 revision 的 README 声明 708,009 个问题行，论文报告 CoT 超过两百万条。datasets-server 只完成部分处理，其 552,229 估算并非权威总数。精确嵌套数量、重复项与每题轨迹数仍需完整快照审计。
- **去污染：** 论文列出归一化 Indel 和 10-gram 方法，但没有阈值、移除样本、归一化细节、生成输出筛查或残余重叠测量。
- **偏好含义：** DPO 把 RV 3–5 设为 chosen，把最大 RV 设为 rejected。这操作化的是冗长度偏好，而非人类偏好、事实性或正确性；两侧都可能答案有效。
- **RL 可复现性：** GRPO 目标列出格式、准确性、RV 和 CD 项，但奖励权重、reward model 训练数据细节、rollout 数、解码、advantage 设置和可执行验证代码均未完整报告。
- **实验归因：** 10K 实验控制了问题集合，但主模型比较同时改变模型家族、所选轨迹、能力目标、训练预算，可能还改变快照。benchmark 提升不能证明数据质量。
- **权利与伦理：** Apache-2.0 仓库元数据不能替代逐来源条款。论文还指出教师偏差传播与高风险部署中生成误导性推理的风险；隐私、来源同意和下游安全需单独审查。
- **代码完整性：** EasyDistill 是官方代码，提供 ThoughtX 指南、过滤脚本和示例配置；但核验到的示例只是 1.5B/4K scaffold，没有冻结完整构造过程或所报告的 7B/32B 运行。
- **版本边界：** arXiv v1 描述两位教师与 Qwen2.5 实验，ACL 正式版加入 DeepSeek-R1-0528 和 Qwen3 内容。应以 ACL 正式发表版作为主要配方记录；OmniThought-0528 仍是独立发布。
