1. **一句话定位：** Defects4C 发布 248 个普通缺陷与 102 个漏洞的可执行 C/C++ 修复 benchmark。
2. **方法抓手：** 从 900 万候选提交挖掘、定位函数、恢复 Docker、验证 gold patch 与复现测试。
3. **数据抓手：** 每例含 buggy code、上下文、补丁、构建与测试资产，最终由编译和回归执行判分。
4. **证据锚点：** 24 个 LLM 在统一 harness 下评测，但测试通过仅代表当前 oracle。
5. **复用决定：** 适合补足非 Python 修复数据；使用前应增加 sanitizer、fuzzing 与隐藏安全测试。
