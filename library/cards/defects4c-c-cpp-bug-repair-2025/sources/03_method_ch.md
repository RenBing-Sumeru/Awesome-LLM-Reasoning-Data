1. **挖掘提交：** 在大规模 C/C++ 仓库历史中检索 bug-fix 与 vulnerability-related commits，利用提交消息、diff 和安全元数据得到候选修复对。

2. **定位与筛选：** 比较修复前后版本，保留可映射到具体函数、修改范围清晰且项目可构建的实例；普通 bug 与安全漏洞分别整理。

3. **恢复复现资产：** 为缺陷版本建立 Docker 环境和构建命令，编写或整理能触发问题的测试，并确认 gold patch 能消除失败且不破坏原有行为。

4. **生成 benchmark：** 发布 buggy code、上下文、gold patch、测试和执行模板。候选补丁先编译，再运行缺陷测试与回归测试；任何编译错误、超时或未修复失败均判为不通过。
