VaPR starts from high-quality SFT ground-truth responses and asks a text LLM to modify only task-relevant spans, injecting targeted visual or reasoning errors while preserving length and style to create hard-negative preference pairs. The official VaPR-30K release has about 29.9K records under Apache-2.0, derived from a filtered LLaVA-665K subset. Each item includes an image path, one of ten task types, chosen conversations, and rejected_conversations. GPT-4o creates the main set, while Qwen3-32B produces VaPR-OS to test an open-source editor.
