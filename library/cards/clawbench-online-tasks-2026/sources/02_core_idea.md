The core contribution is a benchmark of 153 everyday online tasks across 144 live platforms and 15 categories. Tasks include workflows such as purchases, appointments, and job applications.

The closest comparison is static web-agent evaluation in sandboxed or mirrored sites. ClawBench changes the substrate by using production websites and a lightweight interception layer that captures and blocks only the final submission request.

The feedback contract is environmental: an agent must navigate multi-step workflows and reach a successful final submission state without causing real-world side effects.
