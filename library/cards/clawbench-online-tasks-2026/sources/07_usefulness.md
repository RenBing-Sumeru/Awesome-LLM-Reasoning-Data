Use ClawBench as a reference for live-web agent evaluation design. It is especially useful when a project needs to test document use, multi-step form filling, and production-site navigation.

Reusable records should keep task id, platform, category, account state, user documents, browser trace, final intercepted request, success status, action budget, runtime date, and safety policy.

For audits, separate capability failure from environmental drift and from safety-blocking behavior.
