The official sources support four bounded layers of disclosure.

1. **Browsing tasks and learned behavior.** OpenAI says new browsing datasets were created for research use cases and that the model learns searching, clicking, scrolling, file interpretation, sandboxed Python use, and synthesis across many websites. Task sources, prompts, web snapshots, browser states, action schemas, tool versions, and retained trajectories are unknown.
2. **Training feedback.** The card says datasets span objective auto-gradable tasks with ground-truth answers and open-ended tasks with grading rubrics. During RL on browsing tasks, a chain-of-thought model grades responses against the ground truth or rubric. Reward scalarization, aggregation, model checkpoint and prompt, calibration, thresholds, error rates, and reward-hacking analysis are not disclosed.
3. **Safety additions and mitigations.** The report names o1 safety datasets reused in training and new browsing-specific safety datasets. It also describes new prompt-injection safety training, system constraints on arbitrary URLs, refreshed personal-data policies, new safety data/evaluations, and a system blocklist. The records, policies, mixing, optimization use, and implementation are unknown.
4. **Environment and evaluation boundary.** Deep Research can inspect web text, images, PDFs, user files, and run Python for calculations, analysis, and plotting. The Python tool has no internet access and runs in the GPT-4o sandbox. These deployment and evaluation facts do not establish a released browser/Python training environment, replayable container, or training-tool contract.
