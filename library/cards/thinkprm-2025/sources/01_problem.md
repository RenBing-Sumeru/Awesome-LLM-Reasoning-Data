The arXiv v5 paper, official author repository and project page, public Hugging Face dataset and model releases, and the official OpenReview TMLR submissions listing are the primary sources for this Card. OpenReview lists the eight-author work as accepted by Transactions on Machine Learning Research in March 2026; arXiv records the original 2025 release.

Process reward models score partial solutions so that Best-of-N or search can favor promising reasoning paths. Conventional discriminative PRMs map a prefix directly to a score and commonly require hundreds of thousands of step labels. General-purpose LLM-as-a-Judge verifiers can instead generate explanations, but the paper finds frequent invalid labels, looping, overthinking, and weak error detection when reasoning models are used without verifier-specific training.

ThinkPRM asks whether a small, filtered synthetic dataset can turn an existing reasoning model into a generative process verifier. The released data object is a six-field training row: a PRM800K/MATH problem, a model-generated solution prefix, a QwQ-32B-Preview verification CoT, parsed prefix steps, human ground-truth step labels, and an overall prefix label. At inference the verifier produces a new verification trace and a scalar correctness score used to rank or expand candidate paths.

The work belongs in `rollout_search_test_time_trace_data` because verifier traces are generated inside Best-of-N and beam-search workflows, and parallel or sequential re-verification changes which candidate solutions are retained without changing the solution generator. The Card remains L3/partial because the dataset repository's MIT notice has an unfilled copyright placeholder and unclear upstream coverage, while code licensing, decontamination, rejected generations, exact upstream row IDs, the 65K expansion, and several reconstruction settings remain unavailable or unverified.
