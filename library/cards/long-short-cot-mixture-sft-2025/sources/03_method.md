**Inputs → rewriting.** Start with the 1,000 s1K-1.1 long trace-and-answer instances reported as DeepSeek-R1-distilled. For each usable question and thought process, Qwen2.5-72B-Instruct receives the Appendix A.1 constraint prompt and writes a shortened thought process. The paper reports that 16 inputs exceed the rewriter context limit; 984 short examples remain. Rewriter revision, decoding parameters, retries, seeds, and raw outputs are unknown.

**Mixture → SFT response.** Completely randomly merge the 1,000 original long examples and 984 short examples. The public dataset's one train split exposes `system`, `instruction`, `input`, and `output`; the output serializes a think-delimited trace and an answer. Detailed-thinking instructions are used with long examples and brief-thinking instructions with short examples. No immutable map identifies a released short row's long parent. (Paper §§2.2-2.3, 3.1; Appendix B; official dataset viewer)

**Training → inference.** Fine-tune Qwen2.5-32B-Instruct with LlamaFactory on 16 A800 GPUs. Reported settings are cutoff length 4,096, learning rate 1e-5, cosine schedule, warmup ratio 0.05, bf16, AdamW, and weight decay 1e-4; unspecified settings use framework defaults. Epoch count is adjusted so the mixture and s1.1 baseline see equal training-example quantity, but the exact count is not reported. At inference, replace detailed/brief wording with the Appendix A.4 balanced-thinking instruction. This is SFT plus prompting, not RL, search, or a verifier-guided selection loop. (Paper §3.1; Appendix C)

**Required replay artifacts.** A faithful reconstruction needs the upstream s1K-1.1 revision and prompt provenance; the exact rewriter checkpoint and executed prompt; decoding and retry settings; source-to-short pairs and excluded IDs; merge order/seed; complete SFT configuration; evaluation prompts, answer extraction, and decoding settings. These are not released with the paper. The linked GitHub repository is currently a project-page template marked under development, so it is not sufficient implementation evidence.
