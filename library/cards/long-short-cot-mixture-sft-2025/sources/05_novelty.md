Before this paper, a practitioner could directly SFT on long LRM-distilled CoTs, or compress them freely. The paper's explicit comparison includes direct compression, a ThinkTwice-inspired short-trace construction, and long-only/short-only/mixture SFT. The upstream task questions and long-trace source are not new here. (Paper §§3.1, 4)

The concrete change is a constrained rewriting interface plus a mixed training set. Its Appendix A.1 makes the desired preservation criteria visible, while the data release contains both detailed- and brief-thinking response examples. This is a useful direction signal for rationale-data research because it separates trace length and instruction mode as design variables, rather than treating a teacher trace as an indivisible label.

What is not new or established: neither LLM rewriting, SFT on CoT, nor prompt-controlled output length originates here; the constraint prompt is not a verifier; and the release does not demonstrate a generally safe compression rule. Tables 2-4 provide a within-paper quality signal but no per-pair correctness evidence, mixture-ratio sweep, model-scale transfer, or independent replication. Reuse should first test pair integrity, answer preservation, source licensing, and overlap with target evaluations.
