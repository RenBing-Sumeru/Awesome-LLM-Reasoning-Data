For SFT, the paper forms a Mixture-of-Thoughts pool spanning Math, Code, and STEM from OpenR1-Math, Open-Math-Reasoning, Codeforces-CoT, and the Llama-Nemotron STEM subset. Appendix E says approximately 100,000 examples are randomly sampled from source collections for each domain, but it does not publish the sampled identifiers or immutable source revisions. Qwen3-8B-Base is the main SFT model; a Qwen3-0.6B proxy is also tested for scoring data later used to train the 8B model. Offline HES scoring requires a forward pass over each stored response to obtain token distributions.

For RFT, DeepSeek-R1-Distill-Qwen-7B generates 32 candidate responses for every DeepScaleR query. Candidates are checked for final-answer correctness before HES ranking. Per-query selection takes up to k highest-HES correct responses for k = 2, 4, or 8; if fewer than k are correct, all correct responses are retained. Global selection pools all correct responses and retains the highest-HES N, with N matched to the corresponding per-query data volume. The exact candidate decoding settings and the correctness checker, normalization, tolerance, and failure policy are not disclosed.

For RL, DeepSeek-R1-Distill-Qwen-1.5B runs GRPO using verl. The reported configuration uses a maximum generation length of 8,192, temperature 0.6, 32 rollouts per query, 3 epochs, and 628 steps. A reduced update batch contains half the rollout data, split between positive and negative pools. The main strategy takes highest-HES successful rollouts and random failed rollouts. Entropy is computed from logits already produced during generation; this avoids an additional model forward pass, although it still requires vocabulary-wide entropy operations and logit handling.

SFT and RFT use AdamW with learning rate 4e-5, cosine decay, 0.1 warm-up, global batch size 64, and 3 epochs. Evaluation covers AIME24/25, HMMT23/24/25, Olym-MATH, GPQA-Diamond, and LiveCodeBench; the paper reports evaluation temperature 0.6 and maximum generation length 32,768. Appendix F reports all experiments used one node with 8 NVIDIA A100 80GB GPUs and about 500 GPU hours in total.

The only verified paper-specific artifacts are the arXiv paper, its official BibTeX endpoint, and the OpenReview submission record. No official code repository, selected-data files, HES score tables, rollout dump, model checkpoint, project page, or Hugging Face release was found. The paper names open-r1 and verl as implementation substrates and lists upstream dataset/model licenses, but those upstream resources are not a release of this paper's transformed records.
