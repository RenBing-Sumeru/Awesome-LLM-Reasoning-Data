**Method and measurement.** ECR can count a parseable but substantively wrong artifact as complete; TPR is only as strong as each custom test script's coverage and thresholds. Appendix failures show repository bypass, mock outputs, wrong formats, and redirected debug output, all of which expose verifier-gaming or false-positive paths. Conversely, brittle dependencies, missing system libraries, downloads, timeouts, or external-resource drift can make a valid approach fail, creating environment-driven false negatives. Alpha introduces human quality ratings and economic assumptions that are not interchangeable with the binary programmatic terminal predicate.

**Data and release.** The 54 tasks form a single public evaluation set; no train/dev/test split, hidden test set, model-pretraining decontamination, benchmark-overlap audit, or grader-secrecy policy is reported. Prompts, inputs, graders, and some ground truths are public, so later model contamination and evaluator adaptation are material risks. GitHub exposes only 43 example result JSONLs and does not identify the producing framework/model/run; a complete success/failure result set and action-observation rollouts are absent. The Hugging Face snapshot has 276 files and 82.8 MB but omits the code base, configs, ground truths, results, and runner needed for independent replay.

**Lineage, rights, and security.** The audited benchmark commit pins its copied repository trees, but it does not disclose each upstream repository's source commit or retrieval date. There is no GitHub tag, named Release, root benchmark license, container digest, complete package lock, checkpoint/data hash list, network policy, or run manifest. HF declares CC BY-NC-SA 4.0, but that declaration does not resolve heterogeneous rights for copied repositories, multimedia inputs, tests, binaries, models, or helper assets. The dataset card claims no PII and exclusion of sensitive/private material, yet item-level provenance, consent, and redistribution rights are not published. Reproduction executes third-party code, installs packages, and may download resources or access the web, so it requires isolation and supply-chain controls.

**Generality.** The current benchmark is limited to 18 selected Python repositories and seven application areas, and the authors note narrower domain coverage and incomplete evaluation of reasoning models. Reported hardware and framework configurations may not transfer cleanly, while live resources can drift despite pinning the benchmark SHA. OpenHands event counts may also exceed configured `max_iterations`, making realized interaction budgets hard to infer from configuration alone. These limits do not negate the benchmark's value; they bound it to evaluation and audit until replay, lineage, licensing, contamination, and trajectory-retention questions are resolved.
