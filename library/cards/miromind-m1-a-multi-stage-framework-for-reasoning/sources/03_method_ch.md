1. **构建 SFT 语料：** 汇集数学问题并生成多条长推理，使用答案验证、质量规则和去重保留 719K 问题—CoT—答案记录。

2. **筛选 RL 提示：** 从候选题中选择 62K 较难且答案可规范化的问题，避免过易题在训练早期全部通过而失去梯度。

3. **长度渐进优化：** 先在较短上下文和预算下训练，再逐阶段增加允许的推理长度，使 policy 逐步适应长链而非直接承担最大上下文成本。

4. **抑制重复并评测：** 依据重复片段施加自适应惩罚，同时以答案规则给 correctness reward；在 AIME、MATH 等固定基准上比较 SFT 与各 RL 阶段。
