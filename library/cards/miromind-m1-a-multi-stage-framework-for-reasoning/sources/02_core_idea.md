The data contribution consists of MiroMind-M1-SFT-719K and MiroMind-M1-RL-62K. SFT records contain mathematical prompts, verified long CoT trajectories, and final answers; the RL set contains difficult prompts, gold answers, and metadata required for rule rewards. Both are released together with Qwen2.5-based models, training configurations, and evaluation scripts. The key contribution is not one new source but an explicit connection among large-scale cold-start trajectories, verifiable RL prompts, and context-length curricula so that researchers can reproduce or replace individual stages.
