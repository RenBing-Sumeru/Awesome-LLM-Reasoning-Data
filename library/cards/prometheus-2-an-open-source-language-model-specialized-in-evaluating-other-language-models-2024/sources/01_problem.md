Prometheus 2 is motivated by an evaluation dependency problem. In many open-model studies, GPT-4 or another closed model is asked to score answers, yet the evaluator’s rubric, calibration, cost, version, and failure modes are not reproducible. The paper specializes an open language model for evaluation so that the criterion can be supplied by the user and the evaluator itself can be inspected, rerun, and compared. Its target is not “a better chatbot”; it is the decision function that stands between a candidate output and a score or preference label.
