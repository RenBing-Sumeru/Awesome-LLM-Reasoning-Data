The model accepts an instruction, one response or a pair of responses, and a custom evaluation criterion. It must map this context into either a direct assessment score or a pairwise decision. These modes impose distinct contracts: a direct score needs an interpretable scale and calibration across examples, whereas a pairwise decision needs answer-order invariance and a tie policy. Prometheus 2’s use of a user-defined rubric is useful only if that rubric is recorded verbatim; changing “correct” to “helpful and concise” changes the task.
