The authors train an evaluator model and test it on four direct-assessment benchmarks and four pairwise-ranking benchmarks. The public prometheus-eval release packages models, code, and data references. A reproduction should preserve the checkpoint, chat template, rubric text, response ordering, generation parameters, parsing rule, score range, and aggregation metric. When a benchmark already contains a criterion, state whether it was passed through unchanged or rewritten, because rubric paraphrases can alter a judge’s decision.
