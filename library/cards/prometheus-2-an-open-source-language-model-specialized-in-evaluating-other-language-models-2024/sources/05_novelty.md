A key result is that direct evaluation and pairwise ranking need not be separate proprietary services. An open evaluator can serve both when trained to follow a criterion. This makes it possible to audit the full evaluation prompt and model weights, and to use the same judge in a controlled ablation. The contribution is not the invention of LLM-as-a-judge prompting; it is an open, criterion-conditioned judge intended to close the gap with stronger evaluators across both common interfaces.
