已披露流程如下：

1. **预训练数据：** 经过过滤、重加权和去污染的网页、代码、数学、多语文本与图像。1B/4B/12B/27B 分别使用 2T/4T/12T/14T 个词元训练；大模型在训练后期把序列长度从 32K 扩展至 128K。
2. **稀疏教师监督：** 每个词元按概率采样 256 个教师 logits，其余置零并重新归一化，再使用交叉熵。教师身份、检查点、温度、缓存/在线模式与查询次数未知。
3. **指令微调：** 先从未披露的大型 IT 教师模型蒸馏，再使用改进的 BOND/WARM/WARP 式 RL。权重平均的人类反馈 RM、代码执行与数学标准答案提供奖励；安全训练使用 SFT/RLHF。具体修改、阶段顺序、采样展开策略/次数、优化器、KL、系数、批大小、LR 与选择/合并规则均未知。
4. **QAT：** 数据适配 PT/IT 分布，通常训练 5,000 步，以非量化检查点的概率分布作为教师目标；发布按通道/按块 int4 与 switched-fp8。
5. **审计/发布：** 完成能力、安全与记忆评测后，发布 PT/IT 原始/量化权重以及推理/微调库。

代码执行与数学校验虽被命名，但沙箱、语言、依赖、测试、超时、等价性解析器、部分得分与奖励聚合均未披露。公开的 PyTorch/JAX 库不是内部训练技术栈。
