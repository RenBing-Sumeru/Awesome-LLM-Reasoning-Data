1. **Prepare algorithm tasks:** One hundred twenty-one algorithms are selected from textbooks, papers, and common ML libraries. Specifications describe inputs, outputs, formulas, components, and training requirements, with executable references and test data.

2. **Construct practical tasks:** Ninety-seven Kaggle-style problems are selected. Human approaches are compressed into solution sketches that do not reveal complete code, while data splits, submission formats, and resource constraints are provided.

3. **Build execution environments:** Dependencies, datasets, and hardware budgets are fixed, and generated code is executed. Compilation or runtime failure, malformed outputs, and timeouts are recorded separately rather than merged into prediction errors.

4. **Score comprehensively:** Task completion is checked first, then predictive performance is normalized against references and runtime is measured. Reproduction requires fixed seeds, data versions, libraries, hardware, and permitted training time.
