1. **一句话定位：** MLAlgo-Bench 用 121 个算法和 97 个实战任务测试模型能否把复杂 ML 说明转成可运行且性能合理的代码。
2. **方法抓手：** 编写算法/方案描述、准备数据与参考实现、隔离执行、同时评估完成率、相对性能和时间。
3. **数据抓手：** 两类任务均包含可执行环境，不是普通静态 prompt—code benchmark。
4. **证据锚点：** 最佳模型算法任务完成 48.8%，实战任务仅 21.6%，端到端集成明显更难。
5. **复用决定：** 适合 ML agent 评测；最大风险是随机性和资源不可比，必须固定环境并多种子运行。
