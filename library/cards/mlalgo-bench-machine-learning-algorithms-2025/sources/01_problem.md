Function-level code benchmarks mainly test whether short programs pass unit tests. They do not measure implementation of complete machine-learning algorithms, configuration of training procedures, reproduction of paper details, or execution of Kaggle solution plans. ML code also depends on numerical performance, runtime, random seeds, and data processing, so mere executability can incorrectly accept weak or degenerate implementations.

MLAlgo-Bench asks whether models can translate complex human algorithm descriptions and solution sketches into executable ML implementations with reasonable performance. It separates algorithm implementation from practical competition-solution implementation and evaluates execution, relative predictive performance, and time overhead automatically.
