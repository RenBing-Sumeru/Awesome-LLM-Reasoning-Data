MLAlgo-Bench contains two parts: 121 implementation tasks spanning traditional and deep-learning algorithms, and 97 practical tasks based on Kaggle-style scenarios. Algorithm tasks require implementation of models or optimization procedures from complex descriptions. Practical tasks provide a human solution sketch, data, and an execution environment and require complete training, inference, and submission code.

Each task includes a reference implementation, data interface, execution scripts, and performance baselines. Metrics include task pass rate, relative performance, and time overhead. The data object is therefore not a simple prompt–code pair but a task or solution sketch linked to an executable environment, model submission, and measured performance, supporting evaluation of long instruction understanding and multi-stage ML programming.
