1. **One-sentence position:** MLAlgo-Bench uses 121 algorithms and 97 practical tasks to test whether complex ML descriptions can become executable, competitive code.
2. **Method takeaway:** Write algorithm and solution specifications, prepare data and references, execute in isolation, and jointly measure completion, relative performance, and runtime.
3. **Data takeaway:** Both tracks include executable environments rather than static prompt–code pairs.
4. **Evidence anchor:** The best model completes 48.8% of algorithm tasks but only 21.6% of practical tasks, showing that end-to-end integration is much harder.
5. **Reuse decision:** It is suitable for ML-agent evaluation; randomness and resource comparability are the main risks, requiring fixed environments and repeated seeds.
