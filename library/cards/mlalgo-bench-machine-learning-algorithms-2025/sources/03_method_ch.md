1. **整理算法任务：** 从教材、论文和常用 ML 库选择 121 个算法，编写包含输入输出、公式、模块和训练要求的说明，并准备可运行参考代码与测试数据。

2. **构造实战任务：** 从 Kaggle 类问题选择 97 个任务，将人类方案压缩为不直接泄漏完整代码的 solution sketch，提供数据划分、提交格式和资源限制。

3. **建立执行环境：** 为任务安装依赖、固定数据和硬件预算，运行模型生成代码；编译/运行失败、输出格式错误或超时分别记录，而不是统一当成预测错误。

4. **综合评分：** 先判断任务是否完成，再将模型指标与参考性能归一化，并统计运行时间。复现需要固定随机种子、数据版本、库、GPU/CPU 和容许训练时长。
