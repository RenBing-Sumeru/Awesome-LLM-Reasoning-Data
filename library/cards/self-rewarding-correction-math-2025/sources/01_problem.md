The primary sources for this Card are arXiv:2502.19613, the official RLHFlow repository, and the RLHFlow Hugging Face releases linked by that repository. arXiv records six authors and a 26 February 2025 submission; no accepted conference or journal venue is verified.

The concrete problem is inference-time self-correction without an external reward model. A model must produce a mathematical solution, judge its own most recent answer, revise only when the judgment says it is wrong, and terminate when the judgment says it is correct. Untuned models often revise correct answers or fail to repair wrong ones, while a separately deployed reward model adds another model and a separate feedback contract.

The paper addresses this with training-time external supervision. A ToRA checker backed by SymPy determines answer correctness while sequential rejection sampling constructs long-CoT demonstrations containing an initial answer, a generative evaluation label, an optional revision, and a stopping decision. This distinction is central: the deployed loop is self-rewarding, but the data construction and PPO/DPO stages use ground-truth correctness.

The final public IFT object is narrower than the whole paper pipeline. `RLHFlow/self_rewarding_ift_example` contains 31,990 train rows with `gt` and a three-message `conversations` list. Official companion repositories expose a 40K SFT-prompt set, a 16.3K-row raw example, an RL-prompt repository, and turn-level examples, but no manifest joins them into one versioned lineage. The work fits `data_construction_open_release_recipes` because it exposes rejection-sampling code and data checkpoints while leaving candidate, rejection, partition, license, and contamination records incomplete; the Card therefore remains L3.
