Training uses DS-1.5B, Qwen3-4B, and DS-7B with Polaris-53K prompts on the VeRL codebase and DAPO. Shared settings are batch size 256, learning rate 1e-6, no warm-up, no KL or entropy loss, temperature 1, top-p 1, top-k -1, and eight rollouts per problem. Direct RLVR uses maximum output lengths of 16K for the 1.5B/7B models and 32K for Qwen3-4B. TFPI instead stages 2K to 4K to 8K for DS-1.5B/DS-7B and 4K to 8K to 16K for Qwen3-4B; the paper reports step and H20-hour budgets for each stage.

At collection time, each original query x is transformed into x' = ThinkingFree(x). The policy samples eight y values conditioned on x'; the same rule-based outcome reward used for x labels each response, and DAPO computes group-relative advantages and clipped token-level updates. A subsequent TFPI+RL condition restores the ordinary thinking template and longer response limit. Evaluation separates math (AIME24/25, BeyondAIME), multi-task reasoning (GPQA-Diamond), code (LiveCodeBench), and instruction following (IFEval), with documented sampling counts and decoding parameters.

The official repository includes training/evaluation scripts, a script that downloads Polaris-53K, TFPI-EVA, and released intermediate and direct-RL checkpoints. Reproduction still requires pinning commits and dataset revisions. The repository does not establish that all online rollout text, rejected samples, reward outcomes, dynamic-sampling decisions, or WandB logs are released.
