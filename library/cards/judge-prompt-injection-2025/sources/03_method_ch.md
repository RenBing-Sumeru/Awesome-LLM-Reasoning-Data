1. 确定目标。输入为目标问题和攻击者控制的回答；攻击者知道开源裁判及其首尾模板，却不知道其他回答、候选数和目标位置。输出检查是是否生成指定选项字符串。

2. 构造影子上下文。攻击者把目标对与 3 个抽样影子候选组合，并放到不同索引处，以近似不可见的真实评测集合。

3. 优化后缀。离散梯度式 GCG 搜索同时最小化目标对齐生成损失、选项索引 token 的目标增强损失和对抗困惑度损失。默认使用 20 个 token、3 个影子候选、600 次迭代、温度 0、alpha 为 1、beta 为 0.1。

4. 提交并计分。后缀附到目标回答后，与干净回答在各位置共同接受裁判；ASR 是被操纵胜出的比例，ASR-B 是无后缀时胜出率。代码公开，但论文未发布攻击数据集或通用后缀。
