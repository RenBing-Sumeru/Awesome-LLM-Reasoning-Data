For the Rollout, Search, and Test-Time Trace Data track, CMCTS is a blueprint for tree-structured process data with multiple feedback channels. A reusable example should contain node text, action family and exact prompt, parent, depth, visits, UCT value, PRM positive/negative logits, Q/V reward, rule mask, tool call and output, terminal status, vote group, selected path, and ground-truth outcome. Rule satisfaction, PRM preference, execution success, and final correctness should remain separate labels.

Such records could train or evaluate process reward models, compare constrained and open action spaces, study branch diversity, replay alternative pruning policies, and audit whether tool actions or learned rewards drive gains. The paper-linked repository may support reimplementation, but without pinned releases and complete generated trees it is not yet a documented trace dataset. Users should treat the work as a search recipe and schema source unless artifact completeness is verified.
