Prior tree-of-thought and MCTS approaches search over model-generated actions or states and use model scores, value functions, or process rewards to guide expansion. CMCTS changes the search substrate by defining a small semantic action vocabulary, enforcing human-inspired order constraints, and combining those constraints with PRM-derived Q and V signals. The coding action also makes tool-assisted verification an explicit branch type rather than an incidental prompt behavior.

The direction signal for data curation is the separation between action, generated state, rule eligibility, process score, and terminal vote. This provides a richer trace schema than a linear long-CoT record and enables audits of why a branch was explored or rejected. The rule-only and PRM-only variants make feedback-source attribution inspectable in principle.

MCTS, UCT, PRMs, self-consistency voting, SymPy use, and prompt-based action types are not new separately. The novelty is their constrained composition and the claim that predefined action diversity improves search. Benchmark superiority over a larger model is not evidence that the intermediate tree is correct or reusable; tree release, PRM lineage, and rule coverage must be evaluated independently.
