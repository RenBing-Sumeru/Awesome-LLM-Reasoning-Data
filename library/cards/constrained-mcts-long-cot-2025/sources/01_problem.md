CMCTS: A Constrained Monte Carlo Tree Search Framework for Mathematical Reasoning in Large Language Model (arXiv:2502.11169) addresses long-chain mathematical search with a base LLM whose unconstrained MCTS expansions can be redundant or poorly ordered. Native MCTS lets the model propose actions from a broad space and may also rely on the model itself for evaluation. The paper instead asks whether a predefined action vocabulary, partial-order rules, and a process reward model can improve state diversity and guide search without updating the policy model.

The data object is a mathematical search tree, not merely a final chain of thought: problem, state text, selected action and action type, parent-child edge, visit count, Q and V estimates, partial-order eligibility, expansion and simulation path, terminal event, back-propagated reward, candidate trajectories, vote count, and reward-based tie break. The current official arXiv v2 describes four action subsets—understanding, reflection, coding, and summary. The paper and repository expose an implementation recipe, but a versioned release of complete trees, PRM scores, rejected states, and experiment lineage is not established.
