An LLM-as-a-Judge owner can use RobustJudge before deployment: select attacks that match the task, run clean and attacked evaluations, then compare defenses by both attack reduction and clean-score cost. The output is a versioned risk report identifying fragile templates and judge configurations. Start from the released code and data, but add domain prompts, operational permissions, and target-model versions. Do not use it as a security certificate when the production task cannot be represented by its attack harness; log every configuration and rerun after model updates.
