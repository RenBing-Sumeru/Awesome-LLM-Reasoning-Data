RobustJudge is an automated robustness benchmark for LLM judges: it applies adversarial manipulations, measures verdict changes, and tests defenses under the same evaluation setting. Its central contribution is to connect 15 attacks, 7 defenses, 12 judge models, prompt-template variation, and a deployment test in one comparable protocol, so the output is a conditional security profile rather than a clean-score leaderboard. The official repository releases the framework and accompanying data. It is intended for evaluation and audit, not for training an evaluator.
