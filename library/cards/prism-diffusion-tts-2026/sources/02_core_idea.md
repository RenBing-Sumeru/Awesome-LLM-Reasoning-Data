Prism treats a partially denoised sequence as a search state rather than as a failed or unfinished answer. Its Hierarchical Trajectory Search explores broadly during an early-to-middle denoising window, scores intermediate completions, prunes weak states, and shifts subsequent function evaluations toward states that look more promising. This turns a fixed repeated-sampling budget into an adaptive allocation decision.

The framework combines that allocation with two mechanisms tailored to diffusion generation. Self-Verified Feedback asks the same model to evaluate intermediate completions, avoiding a separately trained external verifier. Local branching then partially remasks uncertain content while preserving high-confidence tokens, so candidates can differ where exploration is useful without discarding a promising global draft. The resulting record links state, score, branch, remasking action, and computation cost.
