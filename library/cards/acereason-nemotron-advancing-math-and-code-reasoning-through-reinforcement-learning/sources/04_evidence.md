Math-only RL improves AIME25 by 14.6 and 17.2 points for the 7B and 14B models and also raises LiveCodeBench by 6.8 and 5.8 points. The final 14B model reaches 78.6%/67.4% on AIME24/25, while the 7B model reaches 69.0%/53.6%. These results support transfer from mathematical RL to coding and the sequential recipe, but base model, sampling budget, and code data also affect final scores, so gains cannot be attributed only to the 49K math prompts.
