The reusable artifact is AceReason-Math, roughly 49K mathematical prompts and reference answers drawn from NuminaMath and DeepScaler-Preview under CC BY 4.0. The authors remove multi-part, multiple-choice, true/false, proof, figure-dependent, and overly long or complex-answer problems so that rule-based rewards remain stable. The code stage uses executable tests and is a separate data object. The contribution centers on this verifiable prompt pool and a sequential math-to-code RL recipe.
