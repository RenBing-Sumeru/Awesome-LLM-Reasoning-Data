UnitCoder releases more than 500K executable Python code samples covering over 370 unique API calls. Instead of first rewriting code into new instructions, it extracts functions from pretraining corpora with AST parsing and uses generated tests as direct quality supervision. Failed samples are repaired by a bug-fix agent using execution traces, and passing samples are refined for readability. Records include original functions, generated tests, execution results, and repaired or refined code for code SFT and complex API-composition training.
