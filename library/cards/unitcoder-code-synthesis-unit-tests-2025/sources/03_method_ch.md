1. **抽取函数：**AST 解析预训练语料，保留语法完整、可独立封装的 Python 代码及 API 信息。  
2. **生成测试：**用人工 Python 测试微调 unit-test generator，为正常、边界和复杂包调用生成用例。  
3. **执行分类：**在沙箱运行函数与测试；通过项进入优化，失败项保留错误堆栈。  
4. **迭代修复：**bug-fix agent 依据失败轨迹修改代码，重复执行直至通过或达到轮数上限。  
5. **风格优化：**refine agent 改善可读性并重新测试，只有功能保持者发布。实验代理使用 Llama3-70B、Qwen2.5-72B；完整计算预算未披露。
