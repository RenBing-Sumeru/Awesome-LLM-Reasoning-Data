With the same base models, adding UnitCoder data raises Llama3.1-8B from 31.0% to 40.4% on BigCodeBench and from 5.4% to 14.2% on BigCodeBench-Hard. InternLM2.5-7B improves from 27.9% to 39.3%, and from 10.1% to 17.6% on the Hard split. In a controlled ablation, general code data scores 29.4%, adding verified data raises it to 35.2%, and the full verified-and-refined data reaches 39.3%. This supports contributions from both test verification and refinement, although training mixtures and source-corpus differences still affect attribution.
