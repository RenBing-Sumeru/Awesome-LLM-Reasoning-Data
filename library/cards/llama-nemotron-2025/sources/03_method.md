The report's synthetic-data table totals 33,011,757 examples: 22,066,397 math, 10,108,883 code, 708,920 science, 39,792 chat, 56,339 instruction-following, and 31,426 safety. Math contains 2,225,427 reasoning-on and 19,840,970 reasoning-off examples; code contains 991,706 on and 9,117,177 off; science is 708,920 on; chat has 8,574 on and 31,218 off. These are report-level counts, not a presently reconciled inventory of raw release rows.

For math, the pipeline extracts problems from Art of Problem Solving forums, excluding Middle School Math. Qwen2.5-32B-Instruct extracts and classifies problems; proof, multiple-choice, binary, and invalid problems are removed. It extracts a final answer, and an LLM comparison method removes benchmark-similar questions. DeepSeek-R1 produces 16 reasoning solutions per problem and Qwen2.5-Math-7B-Instruct produces 64 direct solutions. Qwen2.5-32B-Instruct judges predicted-answer equivalence; if no final answer can be extracted, the modal candidate answer becomes the ground truth.

For code, 28,904 unique questions are aggregated from TACO, APPS, CodeContests, and CodeForces after exact-match deduplication. Cosine similarity and LLM judges check overlap with named coding benchmarks, and a manual check reports less than 0.3 percent overlap. DeepSeek-R1 generation uses temperature 0.6 and top-p 0.95. Post-processing requires reasoning traces, extracts code, removes samples with code inside reasoning tags, and checks syntax with Tree Sitter, yielding approximately 488K Python samples. The report does not say that every released code response is executed against tests.

Science uses StackOverflow question-answer pairs plus synthetic multiple-choice questions. Nemotron-4-340B-Instruct defines topics and subtopics; Qwen2.5 generates and varies questions at multiple difficulty levels. The full set is checked against GPQA, MMLU, and MMLU-Pro. DeepSeek-R1 generates multiple reasoning traces, with majority voting when ground truth is absent. General prompts are synthetic or from permissive public datasets; DeepSeek-R1 generates multiple responses and Llama-3.1-Nemotron-70B-Reward selects them. Reasoning-off pairs use Llama-3.1-Nemotron-70B-Instruct for general prompts and Llama-3.3-70B-Instruct for other domains, followed by ground-truth or reward-model filtering.

SFT uses Adam and token-level cross-entropy with model-specific mixtures and schedules. LN-Nano uses three stages, beginning with reasoning data and ending with chat, instruction following, and tool calling. LN-Super trains one epoch on the full SFT set with learning rate 5e-6, 16k sequences, and global batch 256. LN-Ultra uses packed 24k sequences and batch 256 with warmup and cosine decay, including a restart after optimizer instability.

LN-Ultra reasoning RL uses GRPO with 72 prompts per rollout, 16 responses per prompt, temperature 1, top-p 1, global batch 576, and two gradient updates per rollout. Llama-3.3-70B-Instruct judges answer agreement; format rewards enforce the presence or absence of paired think tags. Eight LN-Super responses estimate prompt pass rate, prompts at or above 0.75 are discarded, and a pass-rate curriculum moves from easier to harder batches. The paper reports about 140k H100 hours. Instruction following uses RLOO for fewer than 120 steps with a constraint verifier; preference alignment uses HelpSteer2 prompts and Llama-3.1-Nemotron-70B-Reward with family-specific RPO or GRPO.
