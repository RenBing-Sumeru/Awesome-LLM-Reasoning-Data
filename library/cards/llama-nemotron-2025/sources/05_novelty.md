For data disclosure, the notable contribution is not simply that synthetic reasoning data exists. The report connects domain-specific source selection, multiple open-model generators, heterogeneous verification, a visible reasoning-mode control field, model-specific SFT mixtures, and several RL contracts to an official dataset and three released weight families. This is a substantially richer disclosure surface than a frontier report that publishes only weights and benchmark tables.

The paired `detailed thinking on/off` design makes inference behavior a data-level control problem. Reasoning traces and direct answers are conditioned by an explicit system instruction, and row metadata records the intended mode. That provides an auditable link between a product-facing reasoning toggle and its supervision, although not every prompt has both modes and exact pairing coverage is not reported.

The RL recipe is also unusually concrete at report level. LN-Ultra uses judged answer accuracy, tag-format rewards, LN-Super pass-rate filtering, and a progressive difficulty curriculum with specified rollout and batch parameters. Separate instruction-following and preference stages use a constraint verifier and a released reward-model family. The novelty is this disclosed composition, not GRPO, RLOO, reward-model rejection sampling, or SFT individually.

The Card therefore treats Llama-Nemotron as a frontier disclosure ledger, not as proof of a perfectly reproducible open pipeline. The release establishes more than a narrative, but the unresolved count ledger, exact code revisions, stage-to-row membership, rejected candidates, and verifier calibration still prevent full replay.
