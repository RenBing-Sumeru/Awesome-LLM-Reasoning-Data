Use this paper when you need to choose or explain an intermediate structure in an LLM system. Start with the node taxonomy to find methods that use a compatible representation, then use the task taxonomy to see how that representation has been applied. It is especially helpful for avoiding superficial comparisons based only on names such as “chain,” “thought,” or “agent.” For a literature review, make a small table with one row per candidate method: node type, transition mechanism, task, output, and evidence available. For system design, use the same table to decide whether an intermediate structure is needed for control, tool interaction, decomposition, or communication. The survey helps formulate the choice, but primary experiments are still needed to choose a method.
