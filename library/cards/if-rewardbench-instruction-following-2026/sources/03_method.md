1. **Cover instructions:** Single-turn, multi-turn, and system-prompt steerability settings are collected, spanning formatting, content, conditional, and interaction constraints.
2. **Write checklists:** Each instruction is decomposed into independently verifiable checklist items with constraint-type labels.
3. **Generate responses:** Multiple models are sampled to retain a quality gradient from full compliance to partial or clear violation.
4. **Build preference graphs:** All response pairs are labeled using checklist satisfaction and holistic quality, forming a consistent preference graph.
5. **Meta-evaluate:** Judges perform constraint and overall assessment, and listwise capability is measured by graph-ranking agreement. Code and data are released in the official repository.
