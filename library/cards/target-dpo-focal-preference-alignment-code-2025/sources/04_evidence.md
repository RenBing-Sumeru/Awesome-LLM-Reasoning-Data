Across several code models and HumanEval, MBPP, and BigCodeBench-style tasks, the paper reports consistent gains and fewer local defects. The key controlled comparison uses the same CodeFlow data and shows that focusing the objective on modified tokens outperforms whole-block DPO. Gains vary by base model and benchmark, so they should not be attributed solely to the 59K scale. These results support the central claim only under the released data, model scales, candidate budgets, and evaluation protocols; cross-domain use requires new validation.
