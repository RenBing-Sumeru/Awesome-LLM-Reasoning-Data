**Method and credit assignment。**positive-only episode filtering 不为中间 actions 提供 process labels。成功 episode 可能包含冗余搜索、偶然恢复，或在页面状态略有变化时就会失败的动作，但其中每个保留 action 都会成为正向 BC target。相反，包含有用局部进展的失败 episodes 不进入 loss。curriculum 改变了可达到的行为，却没有解决这种 terminal-credit ambiguity。

**Verifier and judge risk。**WebVoyager 的 prompted judge 可能产生 false positives 与 false negatives；已报告的 88.9% aggregate accuracy 没有揭示 calibration、class balance 或 attack robustness。公开发布没有固定论文中的 Gemma 3 27B evaluator，而只提供 12B config，以及复用 policy `agent.get_action` 路径的代码。WebArena 的 programmatic evaluators 更直接，但仍绑定 task specifications 和 environment state；两种反馈路径都不能建立 step correctness。论文还观察到：repeated checking 可能损害原本正确的答案，agent 可能过度依赖 Bing resets，final-step self-verification 也可能遗漏“仓库年份必须满足要求”之类约束。

**Split and lineage risk。**在固定 commit 的公开发布中，全部 733 个 WebArena train IDs/questions 都出现在 812-row test file 中，虽然 endpoint fields 不同。这证明默认公开文件没有编码干净的 train/test task separation，但不能证明论文原始运行使用了完全相同的文件状态。WebVoyager 的 128,072 条 train rows 包含 104,756 个 unique `(web_name, question)` pairs，却只有 3,184 个 unique IDs。与 test 共享的 337 个 IDs 属于 lineage-key collisions，并非直接 task contamination，因为没有 exact `(web_name, question)` pair 重叠。paper-run split IDs、random seeds、generator lineage、deduplication rules 和 rejection statistics 仍为 unknown。

**Release and replay risk。**仓库公开 tasks、code、configs 和两个 checkpoints，但没有 `train_trajectories.pt`、`evaluate_trajectories.pt`、screenshots、successful/failed rollout manifests 或 immutable browser/environment snapshot。live WebVoyager sites 会随内容、cookies、layout、availability 或 browser behavior 变化；WebArena 同样需要固定 images 与 database state。缺少 raw 与 rejected episodes，导致外部无法独立审计 reward errors、domain weighting、replay age 和 dropped failures。

**Configuration and rights risk。**论文与 scripts 在关键设置上不一致：WebVoyager 在论文中是 12 iterations/六张 GPUs，在公开 script 中则是 15 iterations/四个 devices；WebArena 论文报告四张 GPUs，但 script 只列出两个 devices。GitHub 仓库没有 root LICENSE、tag 或 release。Hugging Face checkpoint metadata 声明 MIT，但这不能解决 upstream Gemma terms，也不能覆盖 task text、website content 或 screenshots 的权利。privacy/consent 和 redaction procedures 均为 unknown。实验只覆盖 web agents；robotics 与 open-world computer use 仍是 future work，Table 3/Table 4 也未针对本 Card 被独立复现。
