The prior-work baseline is agent-environment, tool-use, and benchmark-harness papers in the same atlas category. The change introduced by ScaleWoB: Guiding GUI Agents with Coding Agents via Large-Scale Environmental Synthesis is the particular task object and feedback contract: generated environments, UI tasks, code artifacts, agent trajectories, and success predicates scored by environment-specific web/GUI task checks and generated test predicates. That combination is the direction signal, not a generic claim that models are better or worse.

The quality signal is the presence of official artifacts (paper: https://arxiv.org/abs/2605.25160; project: https://scalewob.github.io; code: https://github.com/ScaleWoB/ScaleWoB; data: https://github.com/ScaleWoB/ScaleWoB; doi: https://doi.org/10.48550/arXiv.2605.25160), source metadata, and explicit audit fields for split, license, lineage, and failure modes. What is not new is the general idea of benchmarking or judging model outputs. Before reuse, inspect artifact version, license, split, evaluator/judge implementation, data lineage, prompt/scaffold settings, and contamination risk.
