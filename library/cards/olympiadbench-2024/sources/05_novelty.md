The prior baseline is a mix of math, science, exam, and multimodal benchmarks: GSM8K/MATH-style math sets, GaoKao/AGIEval-style exam suites, SciBench-like scientific problem solving, and multimodal sets such as ScienceQA, MMMU, CMMMU, and MathVista. OlympiadBench changes the object by focusing on olympiad-level math and physics, including bilingual records, many image-bearing problems, expert solution annotations, and progressive physics contexts.

The new direction signal is the combination of contest-level difficulty and an explicit answer-type-aware evaluator for free-form scientific answers. Its quality signal is not that every item is automatically verifiable; rather, it clearly separates automatically scoreable open-ended answers from proof/text cases that require manual treatment.

What is not new: OCR, benchmark curation, answer-format prompting, numeric tolerance, and symbolic equivalence checking are existing techniques. Before reuse, inspect the exact data version, source-rights chain for contest problems, Hugging Face dataset license, GitHub code license, evaluator tolerance settings, OCR/image fidelity, and whether scores are being compared on the same multimodal/text-only slice.
