输入包括官方竞赛 PDF 或考试材料、图片资源、OCR 后文本，以及标准解或参考答案。构造流程是：

1. 从国际奥赛、中国奥赛和高考难题部分收集数学、物理题。
2. 用 Mathpix 解析 PDF，再人工检查、清洗、修订，并用基于向量相似度的 LLM 辅助去重。
3. 标注题型、子领域、答案类型；物理渐进题还把共同材料和前序答案组织进上下文字段。
4. 将数据打包成分类文件，文件名编码开放式/证明题、多模态/纯文本、学科、语言、竞赛或高考来源。
5. 用固定 prompt 模板进行模型推理，模板暴露答案类型和最终答案格式，但不额外提供知识点提示。
6. 对可自动评分的开放式题调用官方 evaluator；证明题只做抽样人工分析，不给全量自动判定。

输出是 benchmark 记录、模型回答、答案级分数和错误分析。verifier 对数值用浮点容差，对表达式/方程用符号计算判等，对区间和元组做元素级比较。复现时需要固定数据版本、prompt 模板、模型访问日期、评测代码版本、容差策略，以及多模态图片是否真正输入给模型。
