The canonical record is the 2025 arXiv preprint *InSTA: Towards Internet-Scale Training For Agents*, revised on 22 May 2025. An OpenReview page says “Submitted to ICLR 2026”; it contains no acceptance, Poster, Spotlight, or Oral decision, so this Card does not treat the submission as a venue publication. The paper asks how web-agent training data can cover the long tail of live websites without hand-writing tasks and demonstrations for a small set of familiar sites.

InSTA belongs in open release and construction recipes because it defines a complete conceptual funnel: rank one million Common Crawl hosts, use an LLM to reject unsafe or unsuitable domains and propose tasks, ground harder tasks through one live Playwright exploration loop, run agents, judge their trajectories, filter successes, and fine-tune an agent. Its public object is narrower than this pipeline. V2 publishes a website task row with `domain` and `task`; v3 publishes `website`, `instruction`, `steps`, and `criteria`. Neither release is a public trajectory corpus.

The internal paper-level episode is much richer: current URLs, compact HTML-derived Markdown, raw HTML, screenshots, DOM metadata, model reasoning, parsed Playwright function calls, task-proposer traces, and an LLM-judge rationale with success, efficiency, and self-correction scores. The feedback attaches primarily to a full episode through a learned terminal judge, not to a programmatic answer key.

The Atlas value is the boundary between scalable generation and auditable release. The paper and project describe approximately 150K live-site rollouts, 2.2M screenshots, 2.2M action/reasoning traces, and 150K judge traces, while the current official HF organization exposes only task datasets and no public models. The released recipe is therefore useful for reconstruction and audit, but the claimed paper-run trajectory corpus cannot be independently inspected or reused.

This L4 Card is evidence-complete for paper identity, submission-only venue state, construction logic, exact task counts, code and task releases, affiliations, and documented safeguards. It remains `partial` for trajectory and checkpoint release, failed rollouts, judge rationales, immutable lineage, privacy, third-party rights, decontamination, and independent reproduction.
