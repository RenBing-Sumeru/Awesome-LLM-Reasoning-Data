Use this paper to decide whether a project needs causal evaluation of an LLM or LLM assistance for a causal task. It is especially useful for converting broad goals such as fairness or explainability into an explicit causal question. It should be paired with the relevant primary methods before drawing empirical conclusions.

Use the paper to write a short causal problem statement before choosing a method. Name the intervention or relationship of interest, the target quantity, the data available, the assumptions needed for interpretation, and the role the language model will play. This forces an important distinction between an LLM that is itself the object of causal evaluation and an LLM used as an assistant within a causal workflow. The two cases can use similar words while requiring different outputs and evidence. The survey helps identify appropriate primary studies, but it does not supply the assumptions or measurements needed to identify a particular effect in a new setting.
