1. **Select real databases:** Eighty public databases are standardised by schema, table relationships, and executable environment across domains and scales.


2. **Generate and filter claims:** Claims requiring aggregation, comparison, joins, or temporal reasoning are created from database content, while trivial lookups are removed.


3. **Execute deterministic labels:** Reference queries or programs produce evidence that is mapped to entailment, contradiction, or insufficient evidence, with checks that query semantics match the natural-language claim.


4. **Build evaluation:** Models generate executable programs or direct labels, which are run in a common sandbox and scored for three-way accuracy and abstention. Reproduction requires fixed database snapshots and SQL engines.
