TOUCAN is an arXiv preprint submitted on 2025-10-01. The official evidence used here is arXiv v1, the official Agent Ark repository, and the official `Agent-Ark/Toucan-1.5M` release. It addresses a concrete agent-data bottleneck: large tool-use corpora often use simulated outputs or narrow APIs, while collecting episodes against diverse live services is difficult to scale, filter, and audit.

The work belongs in **Environment and Agent Trajectory Data** because its reusable object is an interactive episode, not merely a prompt-answer pair. A full-release row carries a UUID and subset label; the synthetic question; available and target tool declarations; a serialized multi-message history containing system/tool schemas, user turns, assistant tool calls and arguments, remote tool/function responses, and a final assistant response; task- and response-quality assessments; and MCP metadata. The SFT configuration is a reduced six-column view and omits assessment and metadata columns.

The decision boundary is important. TOUCAN records real responses from live MCP services, but it does not release a normalized environment state, state delta, scalar reward, or task-general predicate proving that the user's end goal was correct. Its mixed feedback contract can establish format compliance, tool-use behavior, target-tool coverage/order, and judge-rated plausibility/completeness; it cannot turn every retained episode into a verified successful trajectory.

The card reaches bilingual screening depth because the paper, appendix, code, release schemas, counts, declared licenses, and principal filters were checked. It remains `L3_summary_ready` in canonical metadata, and high-assurance reuse is still blocked by unresolved release binding, per-row lineage, exact replay, upstream rights, PII auditing, decontamination, and rejected-sample accounting.
