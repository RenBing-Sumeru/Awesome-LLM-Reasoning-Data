One-sentence contribution: SWT-Bench: Testing and Validating Real-World Bug-Fixes with Code Agents makes a real bug-fix issue, repository state, generated test patch or reproduction script, original and patched code states, fail/pass transition labels, and coverage or success metrics. reusable by binding it to a concrete feedback contract.

Core mechanism: The benchmark turns real bug fixes into tasks where agents generate tests that validate the bug and the repair. Feedback contract: In unit-test mode, generated tests must fail on the original code and pass after the fix, with no failing tests after the fix; metrics include success rate and changed-line coverage. Closest comparisons are SWE-bench patch repair tasks and test-generation datasets without real bug-fix validation. Direction label: verifier-anchored software-agent evaluation.
