SWT-Bench: Testing and Validating Real-World Bug-Fixes with Code Agents asks how to close this gap: Bug-fix benchmarks usually evaluate patches, but software agents also need to generate tests that reproduce and validate real-world fixes. The primary source is https://arxiv.org/abs/2406.12952; public status is NeurIPS 2024 / arXiv v3 / OpenReview (2024).

Decision boundary: It is collected as a test-generation and validation benchmark for code agents, not as a standard patch-generation benchmark. The reusable object is a real bug-fix issue, repository state, generated test patch or reproduction script, original and patched code states, fail/pass transition labels, and coverage or success metrics. This matters for the atlas because the object and feedback contract are inspectable together.
