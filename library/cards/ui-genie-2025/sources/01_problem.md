Mobile GUI agents need supervision for both local action correctness and whole-task completion, yet dynamic execution is expensive and reference trajectories admit only a narrow set of valid behaviors. Static imitation data alone does not say whether an alternative click is harmless, whether a later state completes the instruction, or whether an apparently successful action caused an unwanted side effect. UI-Genie asks whether a learned multimodal verifier can turn existing demonstrations and new device exploration into additional reward-model and agent-training data.

The relevant data objects are not just “trajectories.” They include binary step/task reward examples built from screenshots, action history, candidate actions, rule labels, controlled corruptions, and mined hard negatives, plus successful exploration steps formatted for agent SFT. Auditing therefore requires separating source demonstrations, synthetic negatives, explored trajectories, verifier decisions, and the final released row/trajectory units.
