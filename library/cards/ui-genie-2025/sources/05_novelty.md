The main contribution is a data engine that joins a GUI-specific binary step/outcome verifier with iterative collection. It uses cheap structural checks to seed reward data, adds controlled task-level corruption and RM-targeted hard negatives, and then reuses the verifier for beam-search control, outcome filtering, and continuation-based step relabeling. Agent data and reward data are therefore co-produced instead of being prepared once in isolation.

The useful novelty is the explicit connection among corruption operators, verifier training, exploration, and accepted SFT records. It is not evidence that the verifier is ground truth, that synthetic negatives cover natural agent failures, or that the loop is self-correcting. The same RM influences search, acceptance, and later labels, so systematic errors can be amplified across generations.
