本文的主要贡献是一套把 GUI 专用二元步级/结果级验证器与迭代式数据采集连接起来的数据引擎。它先用低成本结构规则初始化奖励数据，再加入受控的任务级破坏和针对 RM 的困难负例，随后把验证器同时用于 beam-search 控制、结果筛选和基于续跑的步骤重标注。这样，agent 数据与奖励数据在同一闭环中共同产生，而不是分别一次性制备。

真正有用的新意，是把破坏算子、验证器训练、探索与最终接受的 SFT 记录明确串联起来。这并不意味着验证器就是真值，也不意味着合成负例覆盖了自然发生的 agent 失败，更不能说明闭环一定会自我纠错。同一个 RM 同时影响搜索、接纳与后续标签，因此系统性错误可能跨代放大。
