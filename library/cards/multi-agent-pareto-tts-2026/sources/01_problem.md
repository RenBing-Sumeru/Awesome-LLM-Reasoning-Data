Inference-time methods are often reported with different, unmatched budgets. A debate system may look stronger than self-consistency only because it spends far more generations, while a FLOP-only accounting can miss memory-transfer costs that shape real accelerator latency. Practitioners therefore lack an answer to a basic deployment question: under the same budget, should they buy more independent samples, more refinement rounds, more agents, or a larger model?

This paper asks how the structure of a reasoning pipeline changes the accuracy-time frontier. It compares self-consistency, self-refinement, multi-agent debate, and mixture-of-agents rather than treating each as an isolated algorithm. The target is not maximum accuracy at unlimited cost, but Pareto-efficient configurations that either improve accuracy for a given runtime or reach a target score with less computation.
