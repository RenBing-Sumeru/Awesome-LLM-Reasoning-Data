The study treats pipeline choice, pipeline parameters, and model size as three separate levers for test-time compute. Parallel scaling means more sampled chains, debate agents, or proposer models; sequential scaling means more refinement iterations, debate rounds, or mixture layers. It then places every configuration on an accuracy-versus-estimated-runtime plot and keeps only points that are not dominated by a cheaper and more accurate alternative.

This framing exposes a practical distinction between debate and mixture-of-agents. Debate retains previous exchanges, so extra rounds enlarge the context carried by each agent and can weaken the benefit of sequential scaling. Mixture-of-agents aggregates across layers without the same accumulated dialogue history. The paper's rule of thumb is that mixture-of-agents is often Pareto efficient when the number of parallel proposer models exceeds the number of sequential layers by one.
