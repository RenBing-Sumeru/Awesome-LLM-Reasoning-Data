The novelty is the matched-cost comparison rather than the invention of a new agent architecture. Previous reports often compare a multi-agent design with only a single chain-of-thought baseline or count FLOPs without representing memory transfer. By putting four established pipelines and their parameter sweeps on one Pareto analysis, the work turns “multi-agent is better” into testable allocation claims.

It also separates parallel and sequential scaling inside each architecture. This matters because a larger nominal budget can have opposite effects depending on whether it adds independent evidence or lengthens a shared context. The rule that mixture-of-agents tends to work best with one more proposer than layers is empirical rather than universal, but it is a concrete design signal that connects an agent topology to the test-time accuracy-cost frontier.
