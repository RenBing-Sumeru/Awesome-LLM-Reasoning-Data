SCALE 将自生成的结构作为分配信号：它采样八个分解，让模型选择其一，在已有上下文条件下为每个子问题给出 [0,1] 分数，并与阈值比较。高于阈值的步骤用 System 2，其余步骤用 System 1；后续步骤获得前序问题和解答作为上下文。

反馈是混合的：大纲质量与难度来自模型自评，终端过滤来自与 LIMOPro 最终答案的一致性，benchmark 评测使用答案准确率和 token 派生指标。分数不是经验证的过程标签，最终答案一致也不能验证全部中间推理。

相对 CoT、InftyThink 与 majority voting，关键变化是题内路由，而不是统一推理深度或整题答案采样。发布物提供了检查选中轨迹的字段，但没有提供审计大纲为何被选中或每条 route 成本所需的全部证据。
