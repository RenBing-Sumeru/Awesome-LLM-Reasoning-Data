SCALE 处理的是比整题 token 上限更细的测试时扩展问题：一道数学题内部，哪些子问题应获得审慎推理，哪些应使用快速模式？AAAI 2026 论文把该选择实现为四阶段提示流程：分解、难度评分、阈值化模式选择和顺序上下文传播。

发布的数据对象将数学题与选中的分解、步骤分数、详细及简洁的步骤解、最终答案和答案匹配标志关联。它因此适用于 Rollout, Search, and Test-Time Trace Data 与 SFT；但它不是完整的分配日志：发布物没有给出被拒绝的大纲、实际 route decisions、生成 token、延迟或生成一行数据的确切模型请求。

L4 证据覆盖最终 arXiv 论文、作者代码及作者链接的 Hugging Face 数据卡；它不证明上游问题无污染、步骤标签正确，或公开的 3,112 条发布物等同于论文的 800 对 SFT 子集。
