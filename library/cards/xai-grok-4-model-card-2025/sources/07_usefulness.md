Use this Card to audit the boundary between an official frontier disclosure and a reusable post-training artifact. It provides verified anchors for four questions: which source classes are named; which high-level feedback families are named; which evaluation/mitigation mechanisms are reported; and which data, verifier, filter, and reproducibility details are still unknown.

It can support comparisons across Track 12 model reports without treating their shared vocabulary—such as “verifiable rewards,” “model grading,” or “tool-use RL”—as evidence that their data objects or reward contracts are comparable. It is suitable for disclosure analysis and safety/evaluation interpretation, not for direct training-data reuse or recipe replication.
