The experiments use MATH-500, 90 AIME problems from 2022–2024, and MATH-250, a validation sample with 50 problems at each MATH difficulty level. Proposers are Qwen2.5-Math-7B, Qwen2.5-Math-1.5B, and Llama-3.2-3B-Instruct. Skywork-o1-Open-PRM-Qwen-2.5-1.5B and 7B serve as discriminative verifiers. A double newline defines the smallest reasoning step, and selection uses the PRM’s final score.

The study varies g, generation count n, beam width, branch factor, model pairing, difficulty, and budget. Its analytical cost model separates proposer compute for extending and branching from verifier compute for scoring candidates. CM-g and AM-g estimate a policy on validation data, then reuse that precomputed g for a model/task/budget configuration; the paper recommends recomputation when a core component changes.

A reusable record should preserve prompt and benchmark identity; proposer, verifier, prompt template, and revisions; step delimiter; g, B1, B2, n, and budget; all candidate prefixes and parent links; PRM scores; selected and rejected branches; generation/verification FLOPs and latency; validation policy and difficulty bucket; random seed; final answer; and ground-truth correctness. The official VG-Search repository exposes code and recipes under Apache-2.0, but the accepted metadata does not verify a standalone trace corpus, exact run manifest, or licenses for all models and source benchmarks.
