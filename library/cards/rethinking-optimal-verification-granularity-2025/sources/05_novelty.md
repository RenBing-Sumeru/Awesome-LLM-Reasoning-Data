VG-Search’s main contribution is to elevate verification cadence from an implicit implementation choice to an explicit search variable with accuracy and compute consequences. The same scaffold spans the endpoints of step-wise beam search and answer-level Best-of-N, enabling controlled comparisons without changing the basic proposer–verifier contract. CM-g and AM-g then turn those measurements into reusable per-configuration cadence policies.

The work does not introduce PRMs, beam search, Best-of-N, or a new labeled reasoning dataset. It also does not adapt g inside an individual solution. For this track, the direction signal is the trace schema: verifier call timing, skipped checks, branch pruning, and compute allocation must be logged alongside scores if search trajectories are to be audited or reused.
