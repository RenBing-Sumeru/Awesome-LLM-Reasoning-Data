# 证据

**主张 1：**Mulberry-260K 在不改变消费模型架构的情况下提升同一模型。**受控设置：**表 1 在相同八个基准上比较 LLaVA-NeXT-8B 与使用已发布搜索数据做 SFT 后的 Mulberry-LLaVA-8B。**结果：**报告的平均分从 39.7 升至 50.7，绝对提升 11.0 点；MathVista 从 37.5 升至 56.3。**边界：**这支持完整数据加 SFT 配方的效用，但没有把搜索作用与额外训练计算分离，也不能证明每一步推理都正确。

**主张 2：**相较只用 GPT-4o，集体搜索提高了找到正确路径的成功率。**受控设置：**表 2 使用 1,000 条 Geo3K/GeoQA-Plus 样本，在相同 CoMCTS 流程中依次加入 Qwen2-VL-7B、Llama-3.2-11B-Vision-Instruct 和 Qwen2-VL-72B。**结果：**GPT-4o 直接预测成功率为 58.2%，仅用 GPT-4o 的 CoMCTS 为 63.8%，四模型集体为 80.2%。**边界：**生成与评审使用重叠的模型家族，因此更高的搜索成功率并不等于独立的步骤验证准确率。
