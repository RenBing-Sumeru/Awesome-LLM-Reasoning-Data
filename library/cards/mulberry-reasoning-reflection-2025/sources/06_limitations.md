# Limitations

- **Curator audit risk:** node validity is an average judgment from the same four model families that generate candidates; correlated visual or logical mistakes can survive. Reuse should manually audit step-level false accepts against an independent expert or executable checker.
- **Curator audit risk:** a reflective target inserts a lower-UCB sibling plus a fixed rethink sentence, but lower UCB does not prove that node is the true causal error. Audit whether the correction actually addresses the inserted mistake before treating these records as faithful reflection supervision.
- **Curator audit risk:** the 260K seeds reuse many benchmark-like visual sources and the paper reports no semantic decontamination counts. Compare training questions and images against every downstream evaluation split before attributing gains to reasoning quality.
