The final ICML version of MathConstruct contains 127 difficult construction problems; early arXiv and workshop versions reported 126, so the snapshot should be specified. Problems come from several mathematics competitions and cover permutations, graphs, sets, sequences, geometric constructions, and related objects. Each includes an informal specification, output format, reference solution, and programmatic verifier.

The checker validates not only formatting but also feasibility, constraints, and required optimality or size conditions. Parameterized problems can generate new variants checked by the same verifier, testing whether a model has learned a construction strategy rather than memorized an instance. The primary contribution is an answer-verifiable benchmark, not a large reasoning-trace release.
