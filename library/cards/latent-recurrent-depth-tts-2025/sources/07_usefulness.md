Use this paper when the system owner controls model architecture and wants a test-time budget that is not forced through longer textual rationales. A production evaluation should log prompt class, recurrent iterations per token, total recurrent operations, generated tokens, cache reuse, speculative-decoding behavior, latency, memory, energy if available, and task result. Compare models at matched wall-clock and quality targets, because a parameter-equivalent compute statement does not replace deployment measurements.
