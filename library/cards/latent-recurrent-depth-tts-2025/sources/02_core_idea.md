The model inserts a recurrent block into a transformer-style language architecture and repeatedly applies it to the hidden representation. At test time, this block can be unrolled to different depths, so the same model receives different amounts of internal processing without first producing an extended chain of thought. The recurrence makes compute a continuous architectural control rather than a count of displayed reasoning tokens.

The paper argues that latent iterations can represent operations that are hard or wasteful to verbalize. Its reported architecture also supports zero-shot per-token adaptive compute, KV-cache sharing, and speculative decoding, which connect recurrent depth to serving cost as well as accuracy. The central record is therefore not a curated trace but an inference execution: prompt, chosen recurrent depth, hidden-state evolution, generated output, and task outcome.
