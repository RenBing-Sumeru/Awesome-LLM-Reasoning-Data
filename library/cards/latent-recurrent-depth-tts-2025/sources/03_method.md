The authors train a depth-recurrent language model from scratch. A recurrent block iteratively updates the latent state, and inference can allocate more or fewer iterations before a token is emitted. This differs from prompting an unchanged autoregressive model: the architecture and training recipe must teach the recurrent dynamics to remain stable and useful over variable unroll lengths. The paper reports a proof-of-concept model with 3.5B parameters trained on 800B tokens.

At evaluation, the number of latent iterations is varied as the test-time budget. The study measures reasoning and coding tasks as well as language-model behavior, and compares performance at different internal compute levels; the abstract reports loads equivalent to as much as 50B parameters. The official repository provides pretraining and inference code, and links a Hugging Face model. Reproduction should record recurrent-depth schedule, per-token depth, cache behavior, tokens, latency, memory, output, and benchmark score, because visible output length cannot reveal how much latent computation was used.
