Most test-time reasoning methods buy additional computation by asking a model to emit more visible tokens. This makes every intermediate operation occupy context, requires long-chain behavior to be learned from specialized data, and couples the reasoning budget to a verbal trace that may be redundant or unable to express the useful internal computation. It also makes a longer answer an imperfect proxy for a deeper computation.

This work asks whether a language model can spend additional inference compute internally, before producing the next word. The decision object is the number of recurrent latent iterations applied to a hidden state for a prompt and token position. Instead of selecting a longer chain or more candidates, the system selects recurrent depth. The paper studies whether such depth can improve reasoning and coding performance while retaining small context windows and standard language-model training data.
