作者从头训练深度循环语言模型。循环模块迭代更新潜变量状态，推理可在输出一个 token 前分配更多或更少迭代。这不同于给不变的自回归模型追加提示：架构与训练配方必须让循环动力学在不同展开长度下保持稳定和有用。论文报告一个 3.5B 参数、在 800B token 上训练的概念验证模型。

评估时，潜变量迭代数作为测试时预算变化。研究测量推理、代码和语言模型行为，并在不同内部计算等级比较性能；摘要报告最高达到相当于 50B 参数的计算负载。官方仓库提供预训练和推理代码，并链接 Hugging Face 模型。复现应记录循环深度日程、逐 token 深度、缓存行为、token、延迟、内存、输出和基准分数，因为可见输出长度无法揭示实际使用了多少潜变量计算。
