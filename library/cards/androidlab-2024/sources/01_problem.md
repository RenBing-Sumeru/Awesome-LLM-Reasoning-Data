AndroidLab is an ACL 2025 Long Papers / arXiv paper and official THUDM release for training and systematically benchmarking Android autonomous agents. The gap is that prior mobile-agent work often used static screenshots, narrow interactive tasks, or closed-model-only prompting, which made open-source model training and fair modality comparisons hard to audit. The Card includes it as a mobile agent environment, benchmark, and trajectory-data source, not as a general GUI perception dataset. Its evaluation object is an Android task on a predefined virtual device, with XML or screenshot/SoM observation, an agent action sequence, and task/sub-goal checks over UI state; its training object is an Android Instruct record containing task, screen state, XML information, and operation.
