Use AndroidLab as a recipe for mobile-agent environment cards that connect executable evaluation with trajectory data. Preserve task id, app name, device/image version, observation mode, action vocabulary, per-step observation, emitted action, sub-goal state, terminal predicate, metric names, prompt scaffold, and model budget. It is especially useful for comparing text-only and multimodal agents under one action contract and for auditing whether instruction tuning improves grounded mobile control rather than only formatting.
