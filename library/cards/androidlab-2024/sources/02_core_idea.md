The contribution is a unified Android-agent suite that aligns text-only LLMs and multimodal LMMs to the same action space, then uses the same environment both for benchmark scoring and instruction-data collection. The mechanism is XML mode for text observations, SoM mode for marked screenshots, shared actions such as tap, swipe, type, long press, home, back, and finish, and task evaluation through decomposed required page states. Compared with AndroidWorld, AndroidEnv, AppAgent, AITW, and static mobile UI datasets, AndroidLab is more explicitly tied to training-data construction for open-source models while retaining an executable benchmark surface.
