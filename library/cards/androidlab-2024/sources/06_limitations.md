Correctness is only relative to AndroidLab's encoded task checks and required page states. A passing trajectory can still be brittle under a different Android image, app version, language setting, screen layout, or permission state, and a failing trajectory may reflect evaluator narrowness rather than impossible task completion. Public tasks, demos, and instruction traces can leak into later model training. The repository is MIT-licensed, but data, app assets, screenshots, and downstream redistribution should still be checked at artifact level before reuse.
