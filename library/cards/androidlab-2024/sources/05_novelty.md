The prior baseline is a mixture of static mobile UI datasets, interactive Android environments, and prompt-only closed-model evaluations. AndroidLab changes the setup by aligning XML and visual observations to one action vocabulary, evaluating task progress through sub-goal page states, and collecting aligned text/multimodal operation traces for instruction tuning. The direction signal is a benchmark-as-training-surface release for mobile agents. The action vocabulary, ReAct/SeeAct prompting, Android emulation, and SoM marking are not themselves new; reuse should inspect whether the benchmark tasks overlap with training traces, whether app data are frozen, and whether the evaluator permits alternative valid paths.
