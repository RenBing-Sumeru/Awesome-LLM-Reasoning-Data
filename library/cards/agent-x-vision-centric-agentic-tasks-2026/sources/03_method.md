1. **Build tasks:** Collect image, multi-image, video, and text inputs and design tasks that require tool use.

2. **Execute trajectories:** Have agents plan, select tools, and record observations, actions, and intermediate results at each step.

3. **Human review:** Review tool calls, reasoning chains, and final answers, labeling failure locations and causes.

4. **Layered evaluation:** Compute step-, chain-, and outcome-level metrics separately; reproduction must fix tool versions, environments, and scoring rules.
