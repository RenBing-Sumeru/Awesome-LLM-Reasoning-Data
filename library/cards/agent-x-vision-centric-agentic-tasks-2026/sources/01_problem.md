A visual agent must not only interpret single images, multiple images, or video, but also plan information needs, invoke tools, and integrate returned evidence. A wrong final answer cannot reveal whether perception, tool choice, or long-horizon reasoning failed, and traditional VQA benchmarks lack replayable tool traces.

Agent-X builds 828 real multimodal agent tasks, records observations, plans, tool calls, and intermediate results, and evaluates single-step tool use, complete reasoning chains, and final outcomes separately.
