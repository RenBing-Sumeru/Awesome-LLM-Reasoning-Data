The main artifact is MR²Bench, containing roughly 94K crowdsourced preferences for image response ranking and video QA. Each record organizes a task input, visual or environmental state, candidate response or trajectory, evaluation evidence, and a preference, score, success, or critique label, together with task provenance and capability categories. Quality control relies on sampling multiple responses for the same visual input and obtaining set-level rankings with pairwise verification, making the release suitable for training, evaluation, or auditing rather than ordinary question answering.
