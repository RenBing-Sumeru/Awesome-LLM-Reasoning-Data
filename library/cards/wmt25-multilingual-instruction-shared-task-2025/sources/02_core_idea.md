MIST releases nearly 20K multilingual prompts across 30 languages and five problem types: machine translation, linguistic reasoning, open-ended generation, cross-lingual summarization, and LLM-as-a-judge. The shared task has two rounds: the first collects system outputs for four generation tasks, and the second asks participating systems to evaluate outputs from other models. Official resources preserve raw submissions, automatic metrics, per-item human evaluations, and aggregated scores. Open-ended generation and summarization receive multidimensional seven-point Likert ratings, supporting both model benchmarking and evaluator meta-evaluation.
