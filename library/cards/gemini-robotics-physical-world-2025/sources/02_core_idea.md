The central contribution is a Gemini-derived vision-language-action pipeline whose record interface is current-scene images plus a natural-language instruction, followed by predicted action chunks executed by the robot. Gemini Robotics-ER, built on Gemini 2.0, is distilled into a cloud VLA backbone; an onboard local decoder turns its representation into continuous low-level controls.

The reasoning-enhanced specialization changes the intermediate data object. A re-labelled action dataset supervises predicted left- and right-arm trajectories for approximately the next one second, after which the decoder produces actions. This adds an interpretable trajectory-understanding/generation interface, but the relabeller, coordinate schema, coverage, validation, and whether labels are human-, model-, or geometry-produced are unknown.

Robot evaluation observes task-specific physical completion. Full success is binary, while progress is a scalar from 0 to 1 representing the completed fraction. ERQA uses a multiple-choice answer key. These are evaluation contracts: the paper does not state that success or progress is used as an RL reward, and it does not release an executable terminal checker or scorer audit.

Compared with vision-language models that stop at language answers, the report connects multimodal reasoning to state-action supervision and real robot episodes. Compared with a released answer-level benchmark such as ERQA, the proprietary action corpus contains temporally extended demonstrations and control labels. The key distinction is therefore not merely model capability but which record and feedback layers are actually open.
