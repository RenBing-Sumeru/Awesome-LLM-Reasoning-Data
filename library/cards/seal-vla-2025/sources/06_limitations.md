Selection is bounded by the base policy: if no viable action sequence is sampled, verification cannot recover one. GPT-4o can misjudge fine-grained gripper interactions, wrist-camera views, or occluded scenes, and plan alignment is not equivalent to whole-task success or safety. Simulation or world-model error can change the candidate ranking; sampling and verification add latency and external-model cost.

For the released data, exact episode counts, source-license inheritance, annotation prompts/revisions, reviewer identities, rejection records, inter-reviewer checks, and a record-level provenance ledger are not fully documented on the dataset page. OOD environment versions and immutable replay fixtures also need pinning. Pretrained checkpoint availability remains unknown from the current repository README.
