LIBERO-R is directly useful for studying segment-level embodied reasoning because it links task instructions, robot episodes, timestep intervals, progress summaries, and next-subgoal text. SEAL additionally provides a schema for logging runtime steering: candidate action sequences, simulator/world-model revision, predicted terminal images, verifier prompt and model revision, binary judgments, latency, selected sequence, executed outcome, and task terminal state. Keeping these fields separate prevents semantic alignment from being mistaken for success or safety.
