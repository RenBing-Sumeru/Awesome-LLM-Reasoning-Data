1. **调研工作负载：** 作者通过六个行业的形成性研究归纳企业数据 agent 的常见目标与失败点。

2. **构建多库数据：** 为每个领域准备多个数据库与表，故意保留跨库引用差异、文本字段和异构 DBMS。

3. **编写真实问题：** 问题要求 agent 发现数据源、生成查询或代码、进行连接与转换，而非只输出一条 SQL。

4. **建立验证器：** 每题保存 ground truth 和 `validate.py`，对结构化答案、数值或集合进行自动比较，避免由 LLM judge 决定。

5. **统一执行：** agent 在容器中访问数据库，日志记录查询、代码和中间产物，最终以 pass@1 和错误类型汇总。
