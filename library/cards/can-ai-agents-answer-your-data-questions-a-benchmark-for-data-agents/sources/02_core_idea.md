DAB contains 54 questions across 12 datasets, nine domains, and four database-management systems, including combinations of SQLite, PostgreSQL, DuckDB, and MongoDB. Tasks stress multi-database integration, ill-formatted key joins, unstructured-text transformation, and domain knowledge. Each item provides database environments, a question, ground truth, and validation scripts. The data object is a multi-source state–agent queries/code–answer artifact–programmatic result record, forming a small but realistic benchmark.
