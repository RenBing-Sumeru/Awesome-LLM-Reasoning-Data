The prior baseline is short-context NLP benchmarks or isolated long-context diagnostics. LongBench changes the evaluation surface by combining bilingual, multitask, long-input records under one public harness and by reporting results across task families rather than one retrieval toy. The direction signal is that long-context capability must be audited by data object fields: context length, source task, language, answer type, and metric. The quality signal is the ACL publication plus official code and Hugging Face release. What is not new: QA metrics, ROUGE, summarization, and code completion tasks. Before reuse, inspect source dataset licenses, duplicate leakage, split provenance, truncation policy, and metric suitability.
