The contribution is a bilingual multitask suite for evaluating whether long-context models can use extended input across realistic task families. The core mechanism is to collect or adapt datasets into a unified long-context format covering single-document QA, multi-document QA, summarization, few-shot learning, synthetic tasks, and code completion. The data object is a context-question-answer record rather than an interaction trace. The feedback contract is mixed automatic scoring: exact or F1-style QA metrics, ROUGE-like summarization metrics, classification accuracy, or code metrics depending on task. Closest comparisons include short-context QA suites and narrower long-context tests; LongBench changes breadth, bilinguality, and context-length coverage.
