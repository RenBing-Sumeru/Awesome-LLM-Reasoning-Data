LongBench asks how to evaluate long-context understanding beyond short QA or synthetic needle retrieval. The primary sources are the 2023 arXiv paper, the ACL 2024 long-paper record, the THUDM GitHub repository, and the Hugging Face dataset. Its decision boundary is long-context evaluation, not a training corpus and not a verifier for arbitrary long-form reasoning. A benchmark instance is a bilingual long-context record containing a long input context, task prompt or question, reference answer or label, task/dataset metadata, and an automatic metric. The atlas value is that it makes context length, task type, language, and scoring metric explicit fields for long-context benchmark reuse.
