Correctness is limited to automatic metrics over reference answers. Long contexts can be truncated or reformatted differently across model harnesses, making scores hard to compare without exact prompt and context-window metadata. Some tasks measure retrieval from long input more than reasoning, while summarization metrics may reward overlap rather than factual consistency. Public source datasets may already appear in pretraining corpora, and the public release can contaminate later models. LongBench should not be read as evidence that a model can maintain coherent long-horizon agent state or verify long-form claims without separate evaluation.
