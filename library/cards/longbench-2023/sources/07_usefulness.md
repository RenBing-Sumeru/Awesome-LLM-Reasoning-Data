Use LongBench as a schema for long-context benchmark records: preserve context, question or task prompt, answer, task family, original dataset, language, input length, truncation rule, prompt template, metric, and subset. It is useful for comparing long-context model harnesses and for designing audits that separate context retrieval, aggregation, summarization, and code completion. For atlas use, it is a baseline evaluation surface where feedback is automatic but heterogeneous; the metric field is as important as the answer field.
