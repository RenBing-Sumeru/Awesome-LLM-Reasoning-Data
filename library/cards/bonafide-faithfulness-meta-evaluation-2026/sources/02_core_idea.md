The paper constructs BonaFide with 3,066 CoTs carrying step- and trace-level ground-truth labels across 13 tasks and 10 models. Each task contains a recoverable computational bottleneck so the output reveals which intermediate information the model actually used. The official BonaFide-Extended release contains 19,459 additional records for training faithfulness classifiers, calibrating metrics, and testing transfer across tasks, models, and CoT lengths. The Extended version broadens model-task combinations, supporting supervised detectors and tests of whether a metric works only for the bottleneck pattern used to create it. Records retain tasks, models, steps, and trace labels for length and cross-setting stratification. BonaFide contains 3,066 CoTs across 13 tasks and 10 models with step- and trace-level truth.
