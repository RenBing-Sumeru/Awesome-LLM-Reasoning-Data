STaR repeatedly converts a model's answer-correct rationales into its next SFT set, and uses answer-conditioned rationalization to create training signal for questions the current model cannot solve unaided. The data object is a question, gold answer, generated rationale/final answer, normal-versus-rationalized trace type, acceptance result, and iteration; exact task matching is the feedback contract, so intermediate steps remain unverified. Compared with static self-training, the changed decision is to preserve successful reasoning traces, not just pseudo-label answers.
