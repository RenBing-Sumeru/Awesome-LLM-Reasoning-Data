1. **Discover real tasks:** Identify discovery tasks in scientific repositories whose documentation, scripts, and data define inputs, target artifacts, and runnable references.

2. **Recover environments and data:** Freeze commits, install dependencies, package Docker images, and preserve input data, artifact previews, and reference code.

3. **Synthesize evaluators:** Analyze reference artifacts and domain logic, generate checks for shapes, values, statistics, or files, and repair them through repeated execution.

4. **Validate quality and collect trajectories:** Experts create gold verdicts for the automatic evaluators, inconsistent tasks are removed, and agents generate successful and failed training trajectories.
