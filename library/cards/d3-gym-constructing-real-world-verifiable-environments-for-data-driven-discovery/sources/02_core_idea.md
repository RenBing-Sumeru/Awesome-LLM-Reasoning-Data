D3-Gym contains 565 tasks from 239 real scientific repositories across four disciplines. Each task includes a natural-language instruction, an executable environment with dependencies, input data and artifact previews, reference code, and an automatically synthesized evaluator. About 6.37K trajectories are also released. The Hugging Face table stores metadata for 565 tasks while images reside in Docker repositories. Thirty-nine source repositories have no stated licence, so downstream use requires separate audit.
