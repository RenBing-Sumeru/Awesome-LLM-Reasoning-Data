The prior baseline is mobile GUI evaluation in simulated, open-source, or demonstration-only settings, where internal states, scripted environments, or logged actions can define success. AndroidDaily changes the evaluation surface by using closed-source real applications and an external guideline judge over visual trajectories. The direction signal is an audit path for opaque environments: task success can be approximated through process-aware, observable obligations and constraints. What is not new: visual trajectory collection, LLM-as-judge evaluation, and mobile-agent task execution. Before reuse, inspect guideline authorship, evaluator calibration, app version drift, account and privacy requirements, region-specific UI differences, hidden manual interventions, and whether public tasks leak into agent training.
