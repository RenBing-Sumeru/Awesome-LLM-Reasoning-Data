AndroidDaily asks how to evaluate mobile GUI agents on realistic closed-source Android applications where internal app state is unavailable. The primary source is the arXiv paper, whose HTML metadata lists ACM Multimedia 2026 conference status. The decision boundary is verifiable evaluation over observable visual trajectories in real apps, not dataset training traces or an open-source app simulator. A benchmark item is a daily-use task in a closed-source app, with the agent's screen-action trajectory judged against external guidelines. Its atlas value is that it targets the hard case where success cannot be checked through app internals and must be inferred from visible behavior and task-specific criteria.
