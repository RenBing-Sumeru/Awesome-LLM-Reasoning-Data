The primary text for this Card is the archival NeurIPS 2025 Datasets and Benchmarks paper; the arXiv record establishes that the work first appeared on 2024-12-18, which is why the stable id and metadata year remain 2024. The official project, benchmark repository, release 1.0.0, environment-backup repository, and experiments repository provide the executable and record-level evidence. This date distinction matters because the paper and baselines changed between arXiv v1 and the archival version.

TheAgentCompany asks whether a general computer-using agent can complete consequential, multi-step workplace tasks whose state is distributed across code, files, terminal processes, web applications, and social interaction. Static question-answer or single-turn tool benchmarks do not expose this whole feedback boundary. Here, the agent works inside a Dockerized Linux workspace and a self-hosted intranet containing GitLab, ownCloud, Plane, and RocketChat; 41 tasks additionally involve Sotopia-based simulated colleagues.

The benchmark release contains 175 manually curated tasks. A task record includes an English intent in `task.md`, weighted checkpoints in `checkpoints.md`, a task-specific evaluator, initialization/finalization logic, dependencies, and container configuration. An evaluated episode binds the task id to ordered observations, actions, environment transitions and communication events, screenshots, evaluator/checkpoint outcomes, and a terminal result. Official experiment runs publish per-task result JSON, per-step screenshots, and compressed trajectory JSON. These trajectories were produced by evaluated models and harnesses; they are not human demonstrations or an authored training-trace corpus.

This makes the work directly relevant to `environment_agent_trajectory_data`: the environment is part of the verifier, feedback attaches to checkpoints and the full episode, and official successful, partial, and zero-score logs make failure behavior inspectable. The Card does not treat the public logs as training data, does not infer a train/dev/test split, and does not generalize benchmark scores into claims about workplace automation. L4-depth coverage is supported for the task object, environment, evaluation contract, construction process, released run shape, and versioned evidence; experiment-log rights, immutable run/image manifests, decontamination, task-level lineage, judge calibration, and privacy/consent remain unresolved.
