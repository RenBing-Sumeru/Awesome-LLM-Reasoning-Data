The contribution is a fine-grained evaluation framework with 1,740 instances, 12 skills, and 4 broader abilities. The mechanism assigns skill-specific rubrics to model outputs and uses LLM or human-style judgment to score each skill on a scalar scale. The feedback contract is judgment-required scalar scoring. Closest comparisons are HELM, MT-Bench, AlpacaEval, and reward-model evaluation sets. The direction label is rubric decomposition for instruction-alignment evaluation.
