MUIAnno is a May 2026 arXiv paper on mobile UI understanding. The concrete gap is that many mobile-UI datasets are either automatically derived from view hierarchies, focused on navigation/video traces, or scoped to screen summaries rather than expert-checked element-level grounding. The paper addresses whether real iOS screens can be turned into a dense benchmark where a multimodal model must recover every visible UI element as structured output.

The data object is a mobile screen record: an iOS screenshot, element bounding boxes, element class labels from a 36-class taxonomy, and JSON-style annotation output. The evaluation surface asks a model to take a screenshot plus a fixed instruction prompt and emit JSON elements with categories and boxes. The feedback contract is not task completion in a live phone; it is one-to-one matching against expert labels, with IoU >= 0.5 and class agreement required for a true positive, summarized by precision, recall, and F1.

This belongs in the atlas as an environment/trajectory-adjacent observation grounding surface for mobile agents. It is not an agent benchmark for multi-step app control, not a reward-learning recipe, and not evidence that a model can safely operate phones. Its L4 value is the explicit screen-level object, expert-label contract, public dataset/tool claims, and clear audit risk around API model drift, label schema, dataset license, and App Store screenshot provenance.
