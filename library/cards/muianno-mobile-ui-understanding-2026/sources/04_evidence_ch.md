最强证据是数据集本身的可数对象：1,000 张真实 iOS 截图、36 个元素类别、27,367 个标注元素、论文报告的 14% correction rate，以及公开数据集和标注工具的可用性声明。这些证据说明它不是单纯概念框架，而是一个可落到样本级的评测面。

论文报告了 5 个多模态模型在同一 UI element extraction 协议下的结果：GPT-5.4 为 precision 0.65、recall 0.75、F1 0.70；Claude Opus 4.6 为 0.65/0.69/0.67；Gemini 3.1 Pro Preview 为 0.53/0.58/0.55；Llama-4-Scout 为 0.435/0.456/0.445；Gemma-4-31B-IT 为 0.411/0.420/0.416。

真正的样本级证据不是总分，而是某个预测 JSON 元素是否同时满足专家框匹配和类别匹配。证据边界很窄：结果绑定作者的 prompt、schema、全量截图设置、API 端点和论文报告的模型版本。它不能外推为真实手机任务完成能力、多步 UI 控制能力或跨设备鲁棒性。
