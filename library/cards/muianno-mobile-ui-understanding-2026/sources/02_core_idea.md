The contribution is an expert-annotated iOS UI dataset plus a prompt-based benchmark for measuring whether multimodal models can localize and type visible UI elements. The mechanism is deliberately simple: collect real app screens, annotate every visible component with a controlled taxonomy, export the labels as structured JSON, and compare model-generated JSON to the expert record.

The core object is not a natural-language answer but a set of UI elements with coordinates and semantic categories. The feedback contract combines spatial overlap and semantic label agreement; malformed JSON, duplicate predictions, missed components, wrong labels, and loose boxes all lower the score. The benchmark is evaluation-only in the paper: no task-specific training or fine-tuning is reported for the evaluated models.

Closest comparisons are Rico, MobileViews, MUD, MONDAY, GUIOdyssey, and UICrit. MUIAnno differs by emphasizing expert element-level extraction on real iOS screens, while navigation-oriented datasets emphasize action sequences and large automatic datasets emphasize scale. The direction label is expert-labeled mobile GUI grounding for agent perception, with reuse risk concentrated in annotation fidelity, public-data contamination, and model/API versioning.
