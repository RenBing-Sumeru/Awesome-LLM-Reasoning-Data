WikiSQL was designed for early pointer networks and contains case inconsistencies, type errors, SQL syntax problems, unanswered questions, and token-selection labels. When modern LLMs generate complete SQL, these defects confound dataset errors with model errors. LLMSQL systematically classifies, cleans, and re-annotates WikiSQL, converts questions and full SQL into plain text, and provides a unified execution-evaluation package so the legacy corpus can serve modern generators.
