LLMSQL is a cleaned WikiSQL benchmark of about 80.3K records, not a newly collected database corpus. It detects case-sensitivity issues, column-type mismatches, value errors, invalid SQL, and questions without executable answers, automatically repairing deterministic defects and removing or re-annotating unreliable cases. Each LLM-oriented record provides a natural-language question, schema/table, and full SQL text, while the official Python package standardizes Transformers/vLLM inference and execution accuracy.
