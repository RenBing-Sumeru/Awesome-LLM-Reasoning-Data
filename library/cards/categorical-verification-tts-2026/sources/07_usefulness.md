Use this paper when an agent or symbolic reasoner has expensive step verification and a machine-readable action interface. Start by logging every candidate state and verifier outcome, implement only high-precision deterministic gates, train a within-state ranker, and compare call-efficiency against verifying all survivors and a fixed-width search. The key reporting unit is not just pass rate: retain per-state candidates, gate decisions, selected top-k, verifier calls, and failures so that a lower call count can be audited rather than attributed to a hidden reduction in search coverage.
