Mid-training begins from Qwen2.5-72B-Base. Natural-diff records pair issue or PR text with Python-centered SEARCH/REPLACE patches; records with additions/deletions, more than three Python files, or more than five edit blocks are filtered. PR commit packs preserve multi-step change context while removing signatures and GitHub identifiers.

For exact localization, Qwen2.5-72B-Instruct is lightly tuned on 2,000 DeepSeek-R1 trajectories and generates reasoning retained only when the modified-file set matches exactly. A second synthetic component runs file tools without a shell against simulated observations. Partial localization must include at least one correct file; false-positive files may still be opened, and reflection is injected. These are synthetic interaction traces, not repository executions.

The reported pre-upsampling mixture is about 50B natural-diff tokens, 20B PR commit-pack tokens, 10B localization-reasoning tokens, and 10B synthetic-interaction tokens. Upsampling the two synthetic components fourfold yields about 150B token exposures. Training uses next-token prediction, batch 256, maximum length 32K, learning rate 2e-5 with about 3B warmup tokens, then cosine decay to 2e-6.

Cold-start SFT uses DeepSeek-R1 20250120 BugFixer and TestWriter traces from SWE-Gym and SWE-bench-extra. Main Agentless RL uses a 64K context and Kimi k1.5's REINFORCE-like objective with a multi-rollout average-reward baseline. It starts from 1,200 tasks solvable at pass@16; every 100 steps it resamples 500 zero-pass tasks and reintroduces newly solvable ones.

Each reported RL iteration contains five training steps, samples 1,024 problems, and produces 10 rollouts per problem, or 10,240 rollouts. The prompt pool is adjusted every 20 iterations and recent positive examples are replayed late in training. A separate adaptation study shuffles nested subsets of a reported 5,016 public SWE-smith Claude 3.7 Sonnet trajectories to train the same priors for SWE-Agent use.
