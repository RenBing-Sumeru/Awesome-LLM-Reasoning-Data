Best-of-N improves the chance that an LLM produces a useful response, but it still needs a selector. Learned outcome or process reward models add training and inference cost and may shift across models or tasks; majority-based self-consistency only applies when outputs collapse to comparable final answers, and Universal Self-Consistency spends another model call and context window on judging. Self-Certainty instead scores each candidate from probability distributions the generator already produces. The auditable record is a prompt, N sampled responses, every next-token distribution, a scalar self-certainty score and rank per response, answer extraction state, optional Borda votes grouped by answer, and the selected output. The paper evaluates this record shape on mathematics, code reasoning, and code generation, but does not release its candidates, logits, or score manifests.
