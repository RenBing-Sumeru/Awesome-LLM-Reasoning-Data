Self-certainty 衡量分布集中度，而不是真实性。置信度异常高的错误可能胜出，对 token 得分取平均也可能掩盖局部但决定性的错误。答案趋同时，纯 self-certainty 可能弱于多数投票；此时 Borda 又依赖答案抽取规则、答案频率和指数 p。推荐的 p 会随 N、模型和任务改变，并在验证查询上调整，因此结果需要记录调参来源，并审计潜在泄漏。该方法要求每个生成 token 的完整词表分布，许多封闭 API 无法提供，而且原始轨迹的存储成本远高于只保存文本。经验参考分布实验暴露了分布偏移敏感性，USC 对比也因上下文溢出而不完整。论文未完全披露精确的基准版本、生成长度上限、候选清单、每次运行的随机种子，以及除 LiveBench-Math 时间关系外的污染控制。仓库提供实现代码，但没有正式 release、原始 rollout/logit 数据、固定环境或明确 license。基准增益不能证明分数校准良好，也不能证明数据质量。
