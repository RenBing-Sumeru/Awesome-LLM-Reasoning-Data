The core idea is an open pipeline from real human desktop behavior to multimodal supervised trajectories. AgentNetTool captures synchronized screen video, mouse and keyboard events, and accessibility trees on annotators' own machines. After manual upload and review, Action Reduction compresses redundant low-level events, while State-Action Matching chooses a visually distinct frame before mouse pre-movement so the screenshot does not leak the future cursor location. A terminal success or failure action is appended to the episode.

OpenCUA then adds three levels of supervision. L1 is the executable action, L2 is reflective reasoning, and L3 is a description of the observation. A reflector judges the preceding action using before/after screenshots and action code; a generator produces observation-thought-action text with task history, reflections, target action code, a red coordinate marker, and a zoomed crop; a summarizer refines the task and scores completion, alignment, efficiency, and difficulty. The disclosed teacher for all three roles is `claude-3-7-sonnet-20250219`.

This makes the feedback boundary explicit: humans author actions, a frontier model authors and judges reflective text, offline AgentNetBench matches predicted actions against curated valid actions, and online OSWorld-Verified uses environment-specific task checks. Training itself is supervised fine-tuning and distillation from human and model-authored traces, not reinforcement learning from an environment reward.
