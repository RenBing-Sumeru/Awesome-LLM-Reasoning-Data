论文明确指出，人类采集成本高且难以扩展，演示者可能缺乏应用专业知识或最优捷径，而同意参与机制会引入选择偏差。即使语料覆盖广，也仍可能低估专业企业工作流、无障碍交互模式、英语之外的语言，或标注者不愿录制的任务。

reflective CoT 是事后监督。generator 能看到目标动作代码，reflector 能看到动作前后的截图。因此，文本可能编码已经观察到的结果，或为低效动作作出合理化解释，而不是恢复人类的真实推理。公开材料没有给出 Claude reflector 相对于逐步专家标签的校准误差，也没有验证生成 thought 的忠实性。

隐私控制具体但尚不足以完成审计。记录在人工上传之前保留于本地；标注者复核视频、动作和 accessibility tree；私密任务会被拒绝；内部人员与 GPT-4o 执行两阶段筛查，并由人确认模型标记。逐记录同意与脱敏日志、隐私 prompt、detector 错误率和删除流程并未公开。模型、数据、工具和代码的 MIT 声明也不能解决截图中第三方网站或应用 UI、字体、图标或用户材料的权利问题。

复现仍然不完整。仓库发布了 CoT 生成和离线评测代码，但仍将训练流水线列为未完成。AgentNet 没有捆绑不可变的 OS image、应用版本、网站状态、credential、locale、resolution 或 reset script。当前 HF viewer 因轨迹 JSONL 与 metadata JSONL schema 不同而失败，README 中若干路径也已与 live tree 漂移。静态 Step SR 可能拒绝其他有效动作，在线成功率则会随网络、CAPTCHA、屏幕状态和应用更新而变化。
