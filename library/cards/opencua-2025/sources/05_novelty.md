OpenCUA's contribution is the combination of real cross-platform desktop demonstrations, reduction of dense input streams, cursor-leakage-aware screenshot alignment, multi-level reflective supervision, open models, and both offline and online evaluation hooks. The data object is richer than static grounding: it links task, visual state history, executable action, model-generated reflection, trajectory scores, and explicit termination.

Individual ingredients have precedents. Aguvis develops unified pure-vision GUI agents and reasoning-oriented supervision; AgentTrek releases human web trajectories; OSWorld provides an interactive desktop evaluation environment; grounding datasets supply screenshot-to-coordinate labels. OpenCUA's difference is the integrated foundation stack and the breadth of human Windows, macOS, and Ubuntu workflows, not the invention of every component.

The most technically specific data innovation is State-Action Matching: it aligns an action with the frame before mouse pre-movement rather than one that already reveals the future coordinate. The reflective pipeline is also unusually inspectable because the released schema separates action code, observation, thought, correctness, redundancy, and reflection. That transparency makes post-hoc rationale risk auditable rather than making the rationale automatically trustworthy.
