For the Data Construction and Open Release Recipes track, OpenCUA is a high-value reference because it exposes most of the transformation chain: consented human recording, raw-event reduction, state-action alignment, privacy and quality review, reflective trace synthesis, step filtering, source mixing, SFT formatting, static action evaluation, and interactive task evaluation. It is useful for comparing where provenance or verifier errors can enter a multimodal agent dataset.

Researchers can reuse AgentNet for screenshot-conditioned action SFT, reflective-trace distillation, action grounding, offline policy comparison, trajectory analysis, or studying human mistakes and recovery. The released CoT generator is also a concrete starting point for alternative reflectors, rationale-faithfulness checks, and ablations that separate L1 actions, L2 reflections, and L3 observations.

Safe reuse requires narrower claims than the headline model scores. Pin the dataset and model revisions, parse trajectory and metadata JSONL separately, inspect rights and privacy for the intended domain, and retain the distinction between human actions and Claude-authored reasoning. For evaluation, treat AgentNetBench as first-choice step agreement and use a replayable environment for whole-task claims. Reproducing the paper's model training still requires unreleased launcher/configuration details and external source snapshots.
