MindLoom represents difficulty as a chain of atomic knowledge-reasoning transformations. A learned retriever proposes modes compatible with the current question, while similarity and scarcity scoring balance semantic fit against overusing common patterns; rollout judging supplies both difficulty labels and correct SFT responses. The mode chain and source ID keep the generation path inspectable.
