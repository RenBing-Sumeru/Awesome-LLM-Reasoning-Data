1. **Build a verified reference pool.** Input: 58,526 problems from 16 STEM/reasoning datasets with answers and solutions. Operation: run forward inference and retain partial-success cases that have at least one correct trace but are not trivially solved. Output: eligible hard references. Check: all-correct items are too easy and all-wrong items lack a verified trace for reverse analysis.
2. **Reverse-engineer thought modes.** Input: an eligible question and verified solution. Operation: DeepSeek V3.2 decomposes the solution into atomic knowledge-reasoning transformations and ordered chains. Output: 8,322 records containing 32,269 mode steps. Check: deduplicate by source ID/question and preserve provenance.
3. **Learn mode retrieval.** Input: problem states paired with extracted modes. Operation: fine-tune Qwen3-Embedding-0.6B so a current state retrieves compatible transformations. Output: a thought-mode bank and retriever. Check: compare learned top-20 candidates with random retrieval.
4. **Compose new problems.** Input: a seed and retrieved candidates. Operation: choose compatible modes using similarity plus scarcity scoring, then apply up to three evolution steps; stop when a later mode makes the problem incoherent or unsolvable. Output: 7,515 synthesized questions. Check: track selected mode tuple, scores, and source lineage.
5. **Roll out, judge, and filter.** Input: each synthesized question. Operation: DeepSeek V3.2 generates three solutions and a strict judge labels correctness; remove records derived from held-out HLE, SciBench, AIME 2025, and excluded MATH-500 questions. Output: 10,854 provenance-safe rollouts and 9,230 final SFT records. Check: keep only questions with at least one judged-correct response.
6. **Run controlled SFT.** Input: exactly 9,230 chat-formatted records. Operation: full-parameter SFT for three epochs on Qwen3/Qwen3.5 targets. Output: reasoning models. Check: match data count, hyperparameters, and evaluation protocol for distillation and external-data baselines.
