**受控 SFT 主张，表 1。** 所有微调 baseline 都使用恰好 9,230 条记录和相同超参数。在 Qwen3.5-9B 上，MindLoom 把 MedQA pass@1 从 base model 的 78.71 提高到 86.80，并在论文报告的 9 个 benchmark 中几乎都取得最佳 pass@1。该结果支持最终数据流程，但与 base 的比较包含所有构造阶段。

**过滤主张，表 2。** 在相同 Qwen3.5-9B 设置下，删除基于 rollout 的过滤会使 MedQA pass@1 从 86.80 降至 70.38；完整流程在大多数指标上也优于随机检索和不做逆向工程。这个明显下降说明只增加生成问题数量并不够，选择 judge 判定正确的回答是核心质量关卡。
