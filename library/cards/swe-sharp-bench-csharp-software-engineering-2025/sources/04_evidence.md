The authors compare Python SWE-bench Verified and C# SWE-Sharp-Bench using identical model–agent configurations. The resolved rate is about 70% on Python but only about 40% on C#, a thirty-point gap. Holding models, scaffolds, and evaluation procedures constant strongly indicates that language ecosystems and toolchain transfer remain bottlenecks. Automated replay of 150 tasks from 17 repositories also supports reproducibility. However, the two benchmarks are not strictly matched for task difficulty, repository count, or issue distribution, so the gap cannot be attributed entirely to C# syntax, and with only 150 tasks individual repositories can strongly affect aggregate scores.
