Multi-SWE-bench covers several non-Python languages but does not systematically address C# solutions and projects, NuGet, or MSBuild. Replacing a test command with `dotnet test` is insufficient for replaying historical commits. SWE-Sharp-Bench builds an end-to-end .NET curation pipeline and quantifies ecosystem transfer with an identical Python comparison. It does not change the SWE-bench contract of issue, patch, and tests; it adds an important enterprise language and releases the full path from mining and building to test selection and evaluation.
