The main contribution is the first reproducible SWE-bench-style benchmark dedicated to C# and .NET. Its 150 records are released through CSV and Hugging Face, with fields centered on repositories, base commits, issues or problem statements, patches, tests, and environments; the code repository contains mining, solution-building, and evaluation scripts. Tasks come from 17 active C# projects and are replayed with `dotnet`, MSBuild, and native project test frameworks. A patch is resolved only when target and regression tests pass. The CDLA-Permissive-2.0 release supports cross-language coding-agent evaluation, .NET environment adaptation, and C# repository retrieval and is primarily a test benchmark rather than training data.
