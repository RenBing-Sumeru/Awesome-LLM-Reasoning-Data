AGIEval is a 2023 arXiv benchmark paper with an official GitHub release. It asks whether foundation models can handle questions designed for human admission, qualification, and competition exams rather than synthetic NLP tasks. The data object is an exam item with task metadata, prompt text, optional answer choices, a gold answer, and a scoring script surface. The feedback contract is answer-level correctness under the released evaluator, with prompt settings such as zero-shot, few-shot, and chain-of-thought affecting comparability. It belongs in the atlas as a public standardized-exam evaluation surface, not as a training dataset or process-supervision signal.
