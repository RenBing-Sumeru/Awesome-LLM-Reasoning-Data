Each candidate is represented by token-level uncertainty proxies and a predicted verification cost. The proxies summarize average negative log probability, the worst token logit margin, and margin dispersion; a policy combines them into a score and verifies a candidate only if that score exceeds a budget-sensitive cost threshold. The actual budget is based on realized output-length-normalized verification cost, while an input-length-normalized estimate is available before the decision. The evaluation reports error hit rate under fixed budget fractions.

The intervention hierarchy compares four policies. Threshold is a static global baseline. MP-Adapt is a globally shared mirror-prox learner that updates a scoring vector and a dual budget multiplier online. MP-Strat gives cost strata separate dual variables and stabilizes decisions with a teacher-student exponential moving average. CST uses no online learning at all, but assigns independent running quantiles within four predicted-cost strata. A local theoretical model further bounds global allocation distortion by the dispersion of stratum-level discriminability.
