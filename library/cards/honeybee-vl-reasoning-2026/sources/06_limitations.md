The answer filters are terminal and teacher-dependent. A known ViRL answer can reject a correct alternative form if extraction or normalization fails, while four samples from one Llama-4 Scout instance are not independent voters. Three agreeing traces can share the same visual hallucination, algebraic mistake, or answer-parser artifact. Conversely, a valid minority answer can be discarded. No released per-step labels establish that the caption is grounded or the intermediate reasoning causes the final answer.

The public release is only partly self-contained. Dataset Viewer examples show rows in which `question` or `image_path` is null, because `q_source` and `q_id` point to OpenThoughts3 or ViRL. Reuse therefore depends on independently obtaining compatible upstream revisions, joining identifiers correctly, and observing upstream licenses and deletion requests. The release does not provide a record-level source revision, checksum, license, verification decision, teacher request, or rejected candidates.

Decontamination is narrow. The paper removes evaluation images that exactly match source images under pHash; it does not report exhaustive checks for crops, rotations, screenshots, derived diagrams, semantically equivalent questions, answer leakage, or text-only benchmark overlap. Five benchmarks guide recipe hill-climbing, so their scores are validation evidence rather than untouched final-test evidence; five additional evaluation sets are introduced after the final construction, but a complete overlap audit is still unknown.

Counts and versions require care. The paper table says 2,480,000 records, while the current partial Hub conversion estimates 2,463,128 and materializes 1,360,000. The official dataset revision and GitHub commit can be pinned, but no release manifest explains the difference or binds paper rows, source pointers, generation code, and model revisions. The GitHub repository is archived, has two commits, and publishes no trained HoneyBee checkpoint.

Licensing is layered rather than settled by the `cc-by-nc-4.0` dataset tag. The repository license says the data are CC-BY-NC, Llama-4 outputs remain subject to the Llama 4 license—including its model-naming condition—and third-party content remains governed by its own terms. The exact rights for every upstream image/question pair and the effect of pointer reconstruction require separate review.

Finally, the paper's own faithfulness check is limited: GPT-5.1-mini judges 80% of HoneyBee-8B MathVista CoTs faithful. This is neither a human corpus audit nor proof about the released teacher traces. A Dataset Viewer spot check also found a trace that says no interval satisfies an inequality but then boxes an interval. That single observation demonstrates a possible failure mode only; it must not be extrapolated into a prevalence estimate.
