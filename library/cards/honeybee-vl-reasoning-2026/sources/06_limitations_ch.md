答案过滤只检查终局结果，而且依赖教师。对带金标的 ViRL 问题，如果答案抽取或归一化失败，正确的等价表达也可能被拒绝；对新问题，同一个 Llama-4 Scout 生成的四个样本并不是独立投票者。三条一致轨迹可能共享同一视觉幻觉、代数错误或解析器伪影；相反，有效的少数答案可能被删除。公开数据没有逐步标签来证明图像描述确实有视觉依据，或中间推理真正导致最终答案。

公开版本只在部分意义上自包含。Dataset Viewer 示例中可见 `question` 或 `image_path` 为空的记录，因为 `q_source` 与 `q_id` 只指向 OpenThoughts3 或 ViRL。使用者必须自行取得兼容的上游修订、正确连接标识符，并遵守上游许可和删除请求。发布物没有为每条记录提供来源修订、校验和、许可、验证决定、教师请求或被拒候选。

去污染范围较窄。论文使用 pHash 删除与评测图像完全相同的来源图像，但没有报告对裁剪、旋转、截图、派生图表、语义等价问题、答案泄漏或纯文本基准重叠的穷尽检查。五个基准用于配方爬山搜索，因此它们的分数属于验证证据，而不是完全未接触的最终测试；最终构造后又加入五个评测集，但完整重叠审计仍未知。

计数和版本需要谨慎处理。论文表格给出 2,480,000 条，而当前 Hub 的部分转换估算为 2,463,128 条，实际物化 1,360,000 条。官方数据修订和 GitHub 提交可以固定，但没有发行清单解释差值，也没有把论文行、来源指针、生成代码和模型修订绑定在一起。GitHub 仓库已归档，只有两个提交，也没有发布训练后的 HoneyBee 检查点。

许可是分层的，不能由数据页上的 `cc-by-nc-4.0` 标签一笔带过。仓库许可声明数据采用 CC-BY-NC，Llama-4 输出仍受 Llama 4 许可约束，其中包括模型命名条件；第三方内容继续受各自条款约束。每个上游图像—问题对的具体权利，以及通过指针重建后产生的义务，都需要另行核查。

最后，论文自己的忠实性检查也有限：GPT-5.1-mini 将 HoneyBee-8B 在 MathVista 上 80% 的 CoT 判为忠实。这既不是人类对全语料的审计，也不能直接证明公开教师轨迹的质量。Dataset Viewer 抽查还发现一条轨迹，正文先说没有任何区间满足不等式，随后却框出一个区间。这个单例只能说明故障模式可能存在，不能外推为发生率。
