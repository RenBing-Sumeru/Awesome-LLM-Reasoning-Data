- Read the programming model first: typed tasks, intent/outcome effects, coupled scopes, and the persistent commit graph define the data object. The three consumers are runtime supervision, Counterfactual Replay Optimization, and Meta-Agent-Guided Tree-RL.
- Read the limitations as part of the method contract: the applications are proofs of existence, a strong meta-agent adds cost, broadly coupled edits erase replay savings, and reversibility is tiered rather than universal.
- Do not equate the framework repository with the paper run. The actively maintained `shepherd-agents/shepherd` repository is early alpha; `shepherd-agents/shepherd-experiments` freezes the paper substrate and contains `framework-perf`, `live-intervention`, `cbo`, `mcts-rl`, and `trajprune`, but has no GitHub Release or claimed trajectory/checkpoint release.
- The auditable training chain is: 2,492 Endless Terminals tasks; eight base-policy screening rollouts; 442 Qwen3.5 or 530 Nemotron-3 retained tasks; batches of 16 prompts and eight root samples; 8-turn, 1,024-output-token-per-turn, 16,384-input-token caps; a Claude Opus 4.7 fork selector; outcome rewards; two-level advantages; 1,120 optimization steps; held-out Endless Terminals validation and Terminal-Bench 2.0 OOD testing. Exact task IDs, seeds, branch factor, trajectories, rewards, and checkpoints remain unavailable.
