Shepherd 将四个智能体运行时概念映射到函数式编程抽象。`Task` 是带类型的函数，使智能体可替换；`Effect` 是带类型的动作记录，并把意图与结果分开；`Scope` 是拥有绑定和所发 effects 的区域作用域处理器；`Trace` 是持久化 Git 式图，其中 effect 对应提交、fork 对应分支、被接受的子分支可 merge、被拒绝的子分支可 discard。

意图与结果分离构成反馈边界。监督智能体可以在外部世界响应之前查看意图，并在破坏性调用产生结果之前拒绝它。执行后的 effect 具有三类回滚契约：文件系统与沙箱状态等可逆 effect 可由底座原生回滚；某些数据库写入等可补偿 effect 依赖用户提供的补偿处理器；模型调用和电子邮件等不可逆 effect 只能保留为审计记录。因此，“可逆执行”并不意味着所有外部后果都能撤销。

Tree-GRPO 把轨迹图当作数据构造原语。它保留根轨迹前缀，让更强的元智能体选择 fork 回合并提出一个 bash 动作，恢复到该回合之前的耦合智能体—环境状态，再采样相互隔离的 sibling 后缀。终局结果奖励被转换为两类信用信号：共享前缀动作使用跨根 GRPO advantage，fork 后动作使用树内 sibling advantage；系统不使用学习得到的 value function 或过程奖励模型。
