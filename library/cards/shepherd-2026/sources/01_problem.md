Long-horizon agents do not only emit text. They call models and tools, mutate files and processes, and leave an environment whose state influences every later decision. Flat transcripts omit this coupled state, while coarse container snapshots do not expose which action caused a change. This makes it hard for a higher-order agent to observe a worker without perturbing it, stop a risky action before it materializes, branch at the point of failure, or reuse an unaffected prefix.

Shepherd treats execution itself as the object. A task is a typed agent definition; each action becomes an intent effect followed by an outcome effect; a scope binds the worker to model providers, tools, processes, filesystem state, and an effect cursor; and a persistent commit graph records the resulting history. The resulting record is not just a chat log: it joins action semantics, environment state, branch lineage, and task feedback.

For this atlas, the most important case is Meta-Agent-Guided Tree-RL. The authors start from a 2,492-task Endless Terminals pool, screen it with eight base-policy rollouts per task, and train on model-specific subsets after removing tasks passed by all eight rollouts: 442 tasks for Qwen3.5-35B-A3B and 530 for Nemotron-3-Super-120B-A12B. Terminal-Bench 2.0 is held out as an out-of-distribution test set. No generated trajectory dataset or record-level task manifest is released, so Shepherd is primarily an environment/trace substrate and construction recipe rather than a downloadable training corpus.
