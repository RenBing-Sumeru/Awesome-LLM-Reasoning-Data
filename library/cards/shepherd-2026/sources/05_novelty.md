The contribution is not merely storing tool-call logs. Shepherd makes agent execution a manipulable value with a typed state-transition contract. Intent and outcome are distinct records, agent state and environment state fork together, and divergent continuations share a content-addressed prefix. This lets a meta-agent intervene at runtime or replay a suffix without reconstructing state from a flat transcript.

For reasoning-data construction, the key novelty is the alignment between storage and credit assignment. The branch graph retains which actions belong to the common prefix and which occur after the counterfactual choice. Tree-GRPO can therefore attach an inter-root outcome advantage to the prefix and an intra-tree sibling advantage to the suffix without training a separate value model or process-reward model. The environment trace supplies the grouping needed for localized outcome supervision.

The paper also makes rollback scope explicit. Reversible, compensable, and irreversible effects have different contracts. This prevents a common audit mistake: treating a replayable transcript as proof that the external world was restored. Shepherd is strongest when state lives inside a captured filesystem or sandboxed process tree; applications with broadly coupled or irreversible effects need additional handlers and governance.
