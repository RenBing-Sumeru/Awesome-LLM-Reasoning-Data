The paper frames all three applications as proofs of existence. It does not establish an optimal meta-agent policy, broad robustness across models and benchmarks, or that the same gains cannot be obtained with another substrate. Tree-GRPO specifically depends on a stronger Claude Opus 4.7 meta-agent for fork selection, adding token cost and a teacher-policy dependency.

Release completeness is the main data limitation. The official experiment repository contains code and a frozen framework snapshot, but no generated root/sibling trajectories, terminal rewards, exact task-ID split, random seeds, filtered-trajectory counts, trained checkpoints, or checkpoint-to-run manifest. Successful and failed siblings must coexist during advantage computation, while all-pass tasks and overlong trajectories are filtered, yet the durable retention policy and record counts are undisclosed.

Reset guarantees are tiered. Captured filesystem and sandbox state can be restored; compensable effects require correct user handlers; model calls, emails, and other irreversible effects are audit-only. Counterfactual replay also loses its efficiency advantage when an edit affects most later behavior. Overlay checkpoint chains require compaction after roughly 60 layers, and event-stream storage grows linearly.

The split prevents direct Endless Terminals training on Terminal-Bench 2.0 test tasks, but no pretraining-contamination, near-duplicate, or cross-benchmark overlap audit is reported. There is no consolidated license for source tasks, model outputs, or generated traces, and no disclosed PII/secret redaction, consent, access-control, or retention policy. These gaps block treating the experiment as an auditable public training dataset.
