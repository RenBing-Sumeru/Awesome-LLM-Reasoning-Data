BiGGen Bench contains 765 open-generation instances organized into nine capabilities and 77 tasks. Each instance includes a system message, input prompt, reference answer, and instance-specific scoring rubric, averaging about ten examples per task. Five evaluator LLMs are used to assess 103 frontier language models, and the release includes data, model responses, human scores, and judge scores. Its contribution is not raw scale but principled coverage and instance-specific criteria, allowing each score to be traced to concrete requirements.
