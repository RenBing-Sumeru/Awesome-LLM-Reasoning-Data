Open-ended generation benchmarks often ask LLM judges to assign holistic scores using broad criteria such as helpfulness or harmlessness, even though the important requirements differ by task. Code explanation requires logical correctness, creative writing emphasizes style and novelty, and information seeking requires coverage and factuality. Abstract rubrics create coverage bias and opaque judgments. The paper therefore studies how to define multiple generation capabilities systematically, provide task- and instance-specific evaluation criteria, and test whether multiple LLM judges can reliably evaluate a large set of frontier models.
