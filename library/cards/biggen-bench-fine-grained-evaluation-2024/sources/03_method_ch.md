1. **能力 taxonomy：**先定义九类生成能力，再在其下组织 77 个差异化任务，降低只测 instruction following 的覆盖偏差。
2. **实例编写：**为每个任务制作开放提示和参考答案，保留不同领域、风格及推理要求。
3. **专属 rubric：**针对每条实例编写细粒度 criteria，明确必须包含、应避免和质量等级，而非使用统一总体标准。
4. **响应收集：**从 103 个前沿模型生成答案，形成大规模模型—任务响应矩阵。
5. **多 judge 验证：**由五个 evaluator LLM 评分，并与人工结果比较，分析 evaluator、任务和模型排名稳定性。
