DynScaling requires a query batch, so its inter-query allocator does not directly fit single-query, streaming, or strict-latency use. Variation ratio measures disagreement rather than epistemic correctness: confidently wrong answers may receive little extra budget, while semantically equivalent answers can appear different after imperfect parsing. Majority voting can preserve a shared error. Algorithm 2 returns initial plus conditioned responses, but the implementation discussion says an eight-sample unit yields four predicted answers for majority voting, leaving the counted response set unclear. Token cost varies with response length, and displayed curves are moving-average smoothed. Evidence is limited to two Gemini models and GPQA/AIME; other tasks and models are untested. Code, prompts, model outputs, allocation logs, seeds, API revisions, decontamination, and a reusable artifact license remain unknown or unreleased.
