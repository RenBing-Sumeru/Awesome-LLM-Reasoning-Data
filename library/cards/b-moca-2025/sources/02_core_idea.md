The contribution is B-MoCA, a benchmark with 131 daily Android tasks and 45 randomized environments split into 35 training and 10 testing configurations. The core mechanism is to formulate device control as sequential decision-making: the agent receives a task instruction and observation, emits a continuous/discrete/text action, and receives a success signal from detectors built on ADB/Appium-accessible app state and UI attributes. The feedback contract is environmental, with +1 success when the detector condition is satisfied and 0 otherwise. Closest comparisons include Android emulator benchmarks, OS/mobile control agents, and demonstration-trained policies. The direction label is configuration-robust mobile control evaluation.
