B-MoCA is useful as a mobile-agent benchmark schema: preserve task ID, instruction, app target, environment ID, randomized configuration fields, observation modality, action representation, detector rule, terminal status, run seed, and agent prompt/checkpoint. It is a good audit surface for generalization because the same task can be evaluated under multiple device configurations. For atlas use, keep training environments, test environments, human demonstrations, and detector outcomes separate. The reuse checklist should include versioned task list, removed stochastic tasks, detector source, emulator image, model API date, and app/network dependencies.
