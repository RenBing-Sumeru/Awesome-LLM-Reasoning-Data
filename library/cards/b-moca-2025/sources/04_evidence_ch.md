CoLLAs 2025 论文说明 B-MoCA 定义 131 个日常任务，并创建 45 个独立环境，其中 35 个训练环境、10 个测试环境。官方项目页记录了版本历史：首次公开 release 有 70 个任务，后续增加任务，ver.2 因高随机性删除 7 个任务后为 131 个任务，ver.3 更新 action parsing。benchmark 比较 GPT-4o、Gemini-1.5-pro、Llama-3、MLLM agent 和 imitation-learning custom agent。报告结论是 foundation-model agent 能处理简单任务，但在长程或随机化设置下降明显；custom agent 能模仿 demonstration，但对未见配置泛化不足。行级证据是 emulator 内 detector success；聚合 success rate 只有在固定环境 ID 和 release 版本时才可比。
