The prior baseline is narrow legal NLP datasets or professional-exam-style evaluation. LegalBench changes the construction model by making a collaborative task bank where lawyers, law professors, computational legal practitioners, and legal impact labs contribute tasks they consider interesting or useful.

The direction signal is open, community-curated domain evaluation with task-level provenance. The quality signal is the public repository, Hugging Face release, task descriptions, split convention, and explicit license guidance that asks users to follow each dataset creator's license.

What is not new: many component tasks draw on existing datasets or familiar NLP formats. Before reuse, inspect which tasks were transformed from prior corpora, which are newly created, what each license permits, how labels were normalized, and whether a selected subset overweights easy binary tasks.
