Correctness is task-local. A LegalBench answer can be correct under a label file while still being incomplete legal advice, outdated law, or an answer that a practitioner would qualify in a real matter.

The benchmark is English-only and mixes legal areas, task formats, and source lineages. Aggregate scores can hide large differences between contracts, statutes, judicial opinions, privacy policies, and synthetic legal hypotheticals.

Licensing must be audited at task level. Hugging Face lists cc-by-4.0 for the dataset page, while the official GitHub repository states that LegalBench mixes created and transformed datasets and asks users to follow the dataset creator's license. Public release also creates contamination risk.
