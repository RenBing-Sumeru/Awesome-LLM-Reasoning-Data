Primary source: the arXiv paper "Mobile-Agent-v3: Fundamental Agents for GUI Automation" (2025) and the official X-PLUG/MobileAgent repository. The problem is how to build GUI agents that can generalize beyond a single mobile benchmark by combining a GUI foundation model, cloud virtual environments, and a trajectory-production loop.

This card treats the work as an agent-environment and trajectory surface, not as a single leaderboard entry or a fully disclosed training corpus. A data object can be a GUI task, screenshot/state observation, model action, execution result, self-evolution trace, or benchmark outcome.

The feedback contract is mixed: environment task success, benchmark scores on AndroidWorld and OSWorld-Verified, and trajectory filtering or judgment inside the self-evolving framework. Its atlas value is the explicit connection between GUI evaluation, feedback collection, and future post-training data.
