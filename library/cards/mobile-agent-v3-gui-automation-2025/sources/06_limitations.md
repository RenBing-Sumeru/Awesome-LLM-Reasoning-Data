Correctness is relative to benchmark environments and internal trajectory judges. A passed task verifies the final GUI outcome under a particular state, not semantic optimality, privacy safety, or robustness to UI redesign.

The framework is sensitive to cloud environment drift, app/OS/browser versions, action grammar, step budget, checkpoint release, prompt/scaffold design, and unavailable private data-generation infrastructure. Public repository access does not imply full reproducibility of training data or cloud execution.

Reuse risks include contamination from public benchmark tasks, undisclosed trajectory filtering, overfitting to environment predicates, and licensing boundaries for screenshots, app content, and model weights.
