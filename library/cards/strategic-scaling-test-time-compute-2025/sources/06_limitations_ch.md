理论对比假设回答正确性相互独立，并假设 oracle 阈值能精确或近似识别正确性；学习型 PRM 和 LLM judge 可能违反该假设。过早的 false positive 淘汰会固定错误答案，false negative 则会浪费预算。不同任务的 oracle 分数量纲不可直接比较，最佳阈值 gamma 还可能依赖专家知识或 held-out 调参。

论文主要按生成次数计费，但回答长度和 oracle 成本并不相同；token 预算实验缩小了问题，却不能完全消除口径差异。MATH-500-Hard 根据特定模型在给定预算内的失败构造，不能视为内在难度标签。论文没有发布逐题分配、原始分数、拒绝回答、版本化提示包、seed 或可执行环境。Card 元数据也未确认数据集许可证、去污染控制和提示重叠审计。benchmark 提升不能替代这些缺失的审计记录。
