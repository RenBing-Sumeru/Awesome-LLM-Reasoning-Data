对 **Rollout / Search / Test-Time Trace Data** 轨道而言，MM-PRM 的价值在于它展示了从搜索轨迹到选择器的完整概念转换：多模态种子 -> rollout 树 -> 终局判定 -> 节点价值 -> 采样过程路径 -> 学习式步骤评分器 -> Best-of-N 排序。这是研究“如何将测试时搜索产物变成过程监督数据”的可复用 schema。

公开代码可用于受控重建研究。研究者可替换终局裁判器，调整 rollout 预算与搜索优先级，比较软/硬目标，保留而不平衡失败分支，或检验聚合函数引起的长度偏差。公开检查点可作为跨模型迁移实验的可部署评分器，MM-K12 则提供公开种子接口。

复用时应把各契约保存为分离的字段或产物：原始图像/问题/参考答案，精确的策略和裁判模型修订版，所有 rollout 与裁判响应，树拓扑与搜索统计，被采样/过滤的路径，逐步 MC 标签，PRM 分数，聚合规则和选中的终局答案。没有这份台账，下游用户就无法区分收益究竟来自更好的生成、更多的搜索、答案裁判行为、标签选择、PRM 泛化还是聚合。

因此，当前公开包最适合被视为“配方 + 种子集 + 检查点”，而不是开放的 747k 过程标签数据集。只有重建缺失的标注层，才能审计数据组成、标签质量、失败覆盖与复现性声称。
