Multimodal mathematical reasoning can fail in the middle of an otherwise plausible chain. Final-answer supervision records only whether the completed response matches a reference and cannot identify which intermediate transition made the path unrecoverable. MM-PRM studies whether such outcome feedback can be expanded into scalable process supervision without human step annotation.

The work must be read as three different data layers. First, MM-K12 supplies 10,000 image-question-answer seed problems. Second, an offline multimodal MCTS pipeline generates reasoning trees and assigns Monte Carlo values to partial paths. Third, those soft values train an 8B process reward model whose scores rank candidate paths at inference time. The seed rows, tree nodes, learned PRM outputs, and benchmark answers are not interchangeable objects.

The release boundary is narrower than the paper's data-generation claim. The official Hugging Face dataset exposes the 10,000-row MM-K12 seed set, the model hub exposes the MM-PRM checkpoint, and GitHub exposes construction and evaluation code. The reported approximately 747,000 step annotations, tree topology, and sampled PRM training records are not downloadable from the checked official locations.
