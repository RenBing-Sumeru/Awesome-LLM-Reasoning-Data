- **Verifier 的 false positive 与 false negative。** unvalidated Completion 可能把失败 build 留下的 intermediate binary，或成功 build 的 submodule/vendored package 计为完成。Strict/Flexible Success 虽然提高 target awareness，却只匹配 filename，不检查 function、runtime behavior、semantic fidelity、provenance 或 security。带预期名称的 stale/incorrect artifact 可能成为 false positive，名称不同但正确的 executable 可能成为 false negative。online `Success(f_k)` 的实现与 `K` 数值均为 unknown。
- **Source mutation 改变了被评判对象。** scaffold 允许修改 source，论文也展示了 OpenCV API patch。作者没有披露 allowed-change policy、patch diff 要求、semantic-equivalence test，也没有区分“build original source”和“repair then build”。因此 filename predicate 成功可能只说明修改后的程序生成了目标名称，其 intended behavior 从未被检查。
- **Environment 与 replay 规格不足。** “全新 Ubuntu 22.04 container”没有固定 Dockerfile/image digest、预装 package、compiler/dependency version、package-index snapshot、submodule policy、network allowlist、retrieved-page snapshot、cache state、wall-clock timeout、`K` 数值、model/API snapshot、seed 或 replay command。live web page 与可变 dependency service 会同时改变 observation 与 outcome。没有核验到公开且与论文关联的 OSS-Build-Agent 或 evaluator implementation。
- **Release 不是 rollout corpus。** 当前 test data 保留 148 个 positive 与 237 个 negative repository label，但只有 126 个 negative 含 failure reason。完整 successful/failed command-observation trajectory、stdout/stderr、patch、artifact、retry history 与逐 run terminal outcome 均缺失。130-record retrieval file 与“Build Trajectory”列包含 URL chain，而非 shell command 或 environment observation。
- **Paper-time 到 current schema 的 drift 没有映射。** paper-time test label commit `d0a2dfa8a309897f7bb299eb4fff067a58442d06` 只有 6 个字段且没有 source commit。当前 test revision `3c3fcb66ddd525219857a40c91d94a8b32c59e14` 新增 failure metadata、`commit_hash` 与 `retrieval_labels.json`；没有与论文关联的 tag 或 changelog 解释迁移。validation revision `971b6834230b5cbc4695d42bddc5ff51cf1267c8` 仍缺 source commit hash。
- **Overlap 与 contamination 仍未解决。** 去除 fork 不能发现 copied、vendored、renamed 或 code-clone overlap。论文没有报告与 CompileAgentBench 或其他 repository-agent benchmark 的 instance-level deduplication，也没有审计 evaluated model 的 pretraining 是否包含这些 repository、README、documentation、fix 或 target name。2024 source cutoff 与 star/keyword filter 不是 decontamination evidence。
- **License 分层且不完整。** 两个 Hugging Face dataset card 都声明 CC BY 4.0，但这不能覆盖 linked repository、dependency、documentation、generated patch 或 binary 的权利。在固定 revision 中，385 个 test license cell 有 92 个空白、60 个为 `NOASSERTION`；70 个 validation license 有 18 个为 `NOASSERTION`。没有 end-to-end attribution/rights manifest。
- **Execution 存在严重 security 边界。** 论文披露的 agent 以 root 运行不可信 repository 与 build script，安装 package、访问 external URL，并可能修改 source。论文没有报告 threat model、egress restriction、sandbox-hardening profile、secret policy、supply-chain isolation 或 artifact malware scan。根据这一 execution surface，curator inference 是：不能在 privileged 或普通 networked host 上直接复用。
- **范围与用途有限。** benchmark 只覆盖满足 filter 的 GitHub C/C++ repository，并以 filename predicate 评测 compilation；不能据此证明一般 software-engineering capability、runtime correctness、portability、maintainability 或 security。benchmark gain 不是 data quality 或 training utility 的证据，论文只支持 `evaluation` 与 `audit`。
