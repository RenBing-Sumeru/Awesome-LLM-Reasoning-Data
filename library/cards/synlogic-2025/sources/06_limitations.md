- Easy and Hard are not interchangeable difficulty labels over the same task set. Easy removes eight tasks and exposes 27 `data_source` values; Hard exposes all 35. Dataset statistics, verifier coverage, and model claims must name the configuration.
- The public object is prompt-plus-verifier state. It does not release the 16 online policy responses per prompt, accepted/rejected sets, format scores, correctness scores, advantages, or training-step linkage, so the paper's RL experience data cannot be replayed exactly.
- `reward_model.answer`, `reward_model.solution`, and `reward_model.style` are public schema fields but can be empty. Official guidance uses `extra_info.game_data_str`; task answers may live in different nested locations, and a generic loader can silently score against the wrong field.
- The paper's format description is less strict than the repository reward reference. The code requires exact start/end placement and exactly one copy of every tag. A formatting difference can therefore zero the reward before logical correctness is checked.
- Programmatic does not mean infallible. Each task has its own answer extraction and verification logic, but no released task-level error rates, adversarial suites, ambiguity labels, or human adjudication set calibrates false positives and false negatives.
- The authors report no identical generated samples in benchmark test sets, but near-duplicate, semantic, template, and adopted-resource overlap are unknown. No released match/removal ledger covers KOR-Bench, BBH, BBEH, ARC-AGI, Zebra Puzzle, or the mathematics/code evaluations.
- Difficulty calibration is only partially specified. DeepSeek R1 and OpenAI-o3-mini are named, but exact versions/endpoints, calibration prompts, seeds, and decoding settings are unknown; lower-bound chat models are not named.
- The current GitHub repository has no tagged release. Hugging Face history records duplicate and Boolean Expressions repairs, and GitHub issue 6 reports a missing Cipher question generator. Reusing mutable `main` without hashes can change rows or executable behavior.
- The pinned Hard release has an observed text-integrity defect: 48 of the first 100 Dataset Server rows, all from Campsite, contain mojibaked Chinese in both the prompt and `game_data_str`. The affected share across tasks/configurations and whether parsing or reward behavior changes are unknown.
- Repository and dataset metadata state MIT, and OpenReview states CC BY 4.0 for the paper, but record-level upstream source identity, attribution, and license compatibility for adopted and benchmark-inspired tasks are incomplete.
- The 7B and 32B studies use different data configurations, response limits, batches, and model capacities. Mixed-domain studies also change task mixture. Benchmark differences cannot be attributed to data quality alone.
- The paper reports answer-level binary rewards, not process labels. Verifier success does not establish that intermediate reasoning is faithful, concise, safe, or pedagogically useful.
- Reproducibility remains partial because sampling temperature, complete software/dependency versions, infrastructure details, random seeds, and the exact rollout corpus are unknown.
