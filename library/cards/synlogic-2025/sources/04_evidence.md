The release evidence first establishes what exists. The current Hugging Face API reports two configurations and four files: Easy and Hard train/validation Parquet files. Dataset statistics show 27 `data_source` values in Easy train and 35 in Hard train, with 15,837 and 32,840 rows respectively. The validation sizes, 270 and 350, agree with 10 records per included task. The public schema exposes `data_source`, `prompt`, `ability`, `reward_model`, and `extra_info`; sampled rows confirm that `reward_model` fields can be empty while `game_data_str` carries task state. At pinned revision `bb4297b82b9c28ef39249f48386cefd5e856618a`, 48 of the first 100 Hard train rows returned by the official Dataset Server contain visibly mojibaked Chinese in both prompt content and serialized verifier state; all 100 sampled rows are Campsite, so this is direct evidence of an encoding defect in that slice, not an estimate for the whole release.

For logic-only RL, Table 2 reports SynLogic-7B at 44.4 on SynLogic-Easy validation, 48.1 on KOR-Bench, 66.5 on BBH, and 8.0 on BBEH. SynLogic-32B reports 52.9 on SynLogic-Hard validation, 62.2 on KOR-Bench, 85.8 on BBH, and 25.5 on BBEH. The 32B score exceeds the table's R1-Distill-Qwen-32B BBEH value of 19.2, while remaining below that model on KOR-Bench and BBH. These are trained-model benchmark outcomes, not direct measurements of dataset correctness or verifier error.

The same table reports cross-domain mathematics changes relative to base models. SynLogic-7B moves from 0.3 to 10.0 on AIME 2024, from 64.6 to 71.8 on MATH 500, and from 30.0 to 55.0 on AMC 2023. SynLogic-32B moves from 4.5 to 19.6, 68.6 to 82.0, and 45.0 to 57.5 on those benchmarks. Comparisons to instruction-tuned and distilled models are mixed, so the evidence supports transfer from the studied RL setup rather than universal superiority.

The mixed-data evidence separates the SynLogic contribution from a math-plus-code control. Table 3 reports Zero-Mix-3 at 28.6 BBEH, 65.0 KOR-Bench, 40.7 LiveCodeBench, 35.8 AIME 2024, and 57.5 GPQA-Diamond, versus Zero-Mix-2 at 18.5, 58.6, 39.5, 34.5, and 55.2. Both configurations run for the same number of training steps, but the mixtures contain different data. The result motivates studying logical prompts in cross-domain RL; it does not isolate every possible data-volume, sampling, or optimizer confounder.

Artifact history provides separate audit evidence. GitHub commit `d2e6cf93042a2713fdd833f5e5e071ac3d8ab901` fixes a Boolean Expressions repetition bug. Hugging Face commits remove duplicate Easy prompts and duplicate ARC-AGI prompts and later fix Boolean Expressions. An open GitHub issue reports that the Cipher question generator is missing. These records demonstrate that the executable dataset changed after release and that exact revision identity matters.

None of these results calibrates all 35 verifiers, proves the absence of semantic contamination, validates upstream license compatibility, or certifies unreleased rollouts. Benchmark performance is evidence that the training recipe affected studied models; it is not evidence that every public row is correct or that the released object is a complete account of training data.
