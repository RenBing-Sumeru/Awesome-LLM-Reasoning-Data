步骤 1 — 汇集源医学问答。
输入：来自七个医学来源的训练记录，其中包括常见医学考试集 MedQA、MedMCQA、PubMedQA 和 MMLU，以及高难数据 MedXpert、HuatuoGPT-o1 与医学 HLE。
操作：选择源训练样本，保留问题、可用选项和标准答案；其余 MedXpert 与 HLE 样本留作评测。
输出与流转：55,071 条候选问答记录进入实体抽取。
检查或停止规则：不使用源测试样本生成数据，并保留来源标识以便审计混合比例。

步骤 2 — 把问题与答案实体映射到 PrimeKG。
输入：一条问题—答案、GPT-4o 和 PrimeKG 节点。
操作：抽取医学实体，搜索精确匹配和语义候选节点，再让教师根据上下文选择相关映射。
输出与流转：问题端和答案端的映射节点集合进入图搜索。
检查或停止规则：任一侧没有可用映射实体时删除该问答；候选因此从 55,071 条减少到 45,725 条可生成样本。

步骤 3 — 检索并筛选思考路径。
输入：已映射的问题与答案节点，以及 PrimeKG 图。
操作：为每对节点寻找最短路径，再让 GPT-4o 保留与当前问题最相关的最多三条路径。
输出与流转：精简后的问题到答案医学关系集合用于引导推理写作。
检查或停止规则：优先最短连接以减少过度思考；此阶段的路径相关性由教师判断，尚未逐条经过独立临床医生验证。

步骤 4 — 生成并筛选推理过程。
输入：问题、原始答案、已选知识路径、GPT-4o-0806 和论文公开的生成与评测消息。
操作：生成详细医学解释，再让教师只根据该解释回答问题，并将结果与源答案比较。
输出与流转：接收记录把来源元数据、问题、选项、答案、路径、推理过程和结论序列化到公开 JSONL 文件。
检查或停止规则：只保留答案匹配的推理；45,725 条生成记录中有 32,682 条通过。

步骤 5 — 训练并评测消费者。
输入：MedReason 记录和 7B-8B 指令或推理模型。
操作：以学习率 5e-6、batch size 128 和 ZeRO-3 运行三轮 SFT，再评测常见与高难医学问答；临床医生另行把抽样推理与 HuatuoGPT-o1 比较。
输出与流转：微调模型、准确率和专家偏好证据用于估计数据效用与解释质量。
检查或停止规则：使用固定 benchmark split 和对应模型基线；最终答案准确率及小规模临床样本不能证明每个中间步骤都有效。

复现要求：固定七个源数据版本及条款、PrimeKG 快照、实体检索向量、GPT-4o-0806 与 2024-12-01-preview 接口版本、全部生成和评测消息、答案归一化器、JSONL 版本、SFT 基础 checkpoint 与评测 split。论文报告约 3,600 美元 API 使用和八卡 SFT，但未披露准确 token 总量、生成随机种子或完整的跨来源去重。
