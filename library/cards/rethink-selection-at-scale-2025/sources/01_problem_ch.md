ACL Anthology 官方记录显示，本文发表于 Findings of the Association for Computational Linguistics: EMNLP 2025，出版时间为 2025 年 11 月。论文追问：在 10K–300K 单一来源池上看似有效的 self-scoring SFT data selector，当 candidate pool 扩大到真实 instruction mixture 的规模时，是否仍优于 random sampling？它研究的是 supervised fine-tuning 的 subset construction，而不是 response generation、preference learning、RL 或新的 correctness verifier。

一条输入 record 是来自 OpenHermes2.5 或 English-filtered WildChat pool 的现有 instruction-response 或 multi-turn conversation。Selection 可以附加 model-derived quality score、embedding/cluster 或 compression state 以及 token count，再保留 10K 或 50K records 做 answer-level SFT。因此，审计所需 data object 不只是 selected text，还包括 upstream revision/ID、selector implementation、score/feature、selected/rejected decision、random seed、SFT run 与 downstream metrics。

本文属于 Data Construction and Open Release Recipes，因为它检验 selection rule 及其 scaling/release behavior。其价值主要是 negative result：在测试条件下，复杂 selector 很少相对五次 random control 获得统计显著收益，而且 implementation 与 compute constraint 实质性地改变了多个 baseline。这里的 L4 表示 paper、appendix、venue record、code tree 与公开 source-pool surface 足以支持完整双语审计；不表示论文专用 selected subset、checkpoint、contamination audit、license 或 preferred end-to-end selector 已发布。
