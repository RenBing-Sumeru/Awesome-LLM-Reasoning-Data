APPS correctness is only as strong as its tests and execution harness. Passing tests does not prove semantic equivalence for all inputs, and failing tests can reflect environment mismatch rather than reasoning failure. Public problem statements, solutions, and released tests are contamination risks for later models. The benchmark is evaluation-only unless a separate training-data audit is done. It should not be treated as measuring software engineering workflows, repository modification, or interactive debugging; it measures standalone program synthesis under the chosen prompt and runtime policy.
