Primary source: arXiv 2105.09938 and the official Hendrycks APPS repository; the paper appeared at NeurIPS 2021 Datasets and Benchmarks. The problem is rigorous evaluation of code generation beyond small function-completion tasks. APPS belongs here as an executable code benchmark, not as a reasoning trace dataset or a training recipe. The data object is a programming problem with natural-language specification, constraints, examples, candidate Python solution, and input/output tests. Its atlas value is the programmatic feedback contract: generated code is judged by running tests.
