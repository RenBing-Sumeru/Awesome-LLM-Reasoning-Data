Chronos changes the scoring object from an unordered bag of token-confidence values to a directed temporal process. This permits the selection rule to react differently to a local late-stage failure and to a broadly uncertain trace, rather than assigning them similar average confidence. The contribution is therefore not merely another voting weight; it provides a learned representation of how confidence evolves within a reasoning trajectory.

It also couples this representation to a concrete test-time consumer: filtering and weighted majority voting. The scorer is deliberately much smaller than a language-model verifier and is trained from terminal correctness rather than step-level human annotations. This creates a middle path between uniform self-consistency and a large process reward model, where model-internal probability signals drive the allocation of influence among sampled traces.
