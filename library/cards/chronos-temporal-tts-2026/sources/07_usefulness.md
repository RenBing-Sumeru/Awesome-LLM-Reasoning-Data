Use Chronos when a locally hosted reasoner can expose token probabilities and a system already pays for many parallel trajectories. Log each trajectory’s answer, token-probability series, score, retained-or-discarded status, vote weight, token count, and final correctness. Compare uniform majority voting, a confidence heuristic, and Chronos at the same sample count and retention ratio. It is especially useful when correct paths are not the most frequent answer and a team needs a low-overhead alternative to deploying a separate billion-parameter verifier.
