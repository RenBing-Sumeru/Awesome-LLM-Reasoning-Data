The source questions come from Bespoke-Stratos-17k, described as 17,000 question, long-reasoning, and answer examples. The paper uses DeepSeek-R1 as the long-reasoning teacher and Qwen2.5-Math-7B-Instruct as the short teacher. Rejection sizes 0, 4, and 8 are studied, with k=8 used as the default paper setting; the repository README describes generating four or eight short attempts. Correct candidates are ranked by token length, and duplicate question-answer pairs carrying both long and easy routing annotations are deduplicated in favor of the easy-marked pair. Exact tie handling, answer parser, failed-generation policy, and final pair count are not disclosed clearly enough to reconstruct the corpus from the paper alone.

SFT trains Llama-3.2-3B-Instruct and Qwen2.5-7B-Instruct bases on the constructed sequences. The repository reports full-parameter training, batch size 32, three epochs, and learning rate 1e-5; the paper specifies AdamW, temperature 0.7, four A100 80GB GPUs for 7B and two for 3B. The post-training stage samples automatically routed long/short rollouts and optimizes binary correctness with the clipped objective. Evaluation covers MATH500, GPQA-Diamond, GSM8K, OlympiadBench-Math, AIME, and MMLU-Pro, using output accuracy and generated-token length.

The official GitHub repository provides data-curation scripts, SFT, post-training, inference, and evaluation code, but its visible root has no dataset release or explicit license file. The official Hugging Face model page releases AutoL2S-7B weights, configuration, and inference examples under Apache-2.0 and notes that the paper's EASY token is implemented as specialLong. For reproducibility, a pinned code/model revision, raw long/short pairs, all rejected attempts, prompt templates, exact split, seeds, teacher revisions, correctness logs, and the mapping between paper notation and implementation token names still need verification.
