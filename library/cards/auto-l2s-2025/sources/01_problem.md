Distilling long reasoning traces can improve a smaller or non-reasoning model, but it can also teach the student to produce long chains for inputs that do not need them. Simply truncating outputs or adding a universal length penalty risks removing necessary intermediate reasoning on harder questions. AutoL2S asks how to construct supervision that teaches both concise and extended solutions and lets the model select between them per instance.

The paper's data object is a paired long-short reasoning record. Starting from a Bespoke-Stratos-17k question and reference answer, a strong teacher supplies a correct long chain, a short teacher generates several candidate short chains, answer correctness filters them, and the shortest correct candidate is retained. The record also contains a routing annotation indicating that a short path exists, trigger tokens delimiting the long and short modes, and the final answer. Questions without a verified short path keep only the long trace.

This object is used first for supervised distillation and then to induce long/short online rollouts for a GRPO-style refinement stage. The official code repository includes curation and training scripts, and the official Hugging Face repository releases an Apache-2.0 Qwen2.5-7B-based model. A fully versioned paired raw-trace dataset, rejected candidates, correctness evidence, teacher generations, and split manifest were not confirmed as released, so the model checkpoint is not a substitute for data lineage.
