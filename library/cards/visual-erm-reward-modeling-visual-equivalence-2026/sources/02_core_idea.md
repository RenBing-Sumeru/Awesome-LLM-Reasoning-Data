Visual-ERM trains a generative reward model that directly compares a target image with a candidate rendering and outputs discrepancy category, location, severity, and explanation. It also releases VC-RewardBench to test visual-equivalence judging with fine-grained discrepancy annotations. The main VC-RewardBench reported in the paper contains 1,335 carefully constructed chart, table, and SVG cases. Each includes a target image, a correct or corrupted candidate rendering, and feedback such as discrepancy type, location, severity, and description. The current Hugging Face viewer may total roughly 2.67K rows across configurations, which should not be equated with 1,335 independent benchmark cases; the licence is Apache-2.0.
