For the Data Construction & Open Release Recipes track, ReasonMed is a concrete template for budgeted domain-data synthesis: enumerate source splits, sample complementary teachers, use answer-key-conditioned error logs, estimate difficulty from pass counts, escalate repair selectively, and materialize alternative SFT views. Its code modules make individual stages inspectable even though the exact paper run is not turnkey reproducible.

CoTMed can support long-rationale SFT and error analysis; ResponseMed supports concise answer-explanation SFT; ReasonMed supports models that emit hidden-style reasoning followed by a user-facing summary. The unequal counts and absent IDs mean these should be treated as separate files, not assumed paired counterfactual views. The release is also useful for studying whether summary supervision captures similar benchmark utility with fewer output tokens.

High-risk reuse requires a stronger data contract. Add source dataset and original-question IDs, answer/version provenance, teacher and sampling metadata, verifier/refiner outputs, difficulty, rejected paths, and cross-view IDs. Revalidate source questions and all clinical claims with independent references and qualified reviewers; measure inter-reviewer agreement; preserve abstention when options are invalid; build source-level license and decontamination manifests; and keep a held-out question-family split.

ReasonMed is suitable for research on SFT recipes, judge auditing, provenance recovery, and medical-data failure analysis. It is not clinical advice, a patient-facing corpus, or evidence that long chain-of-thought is medically faithful merely because downstream accuracy improves.
