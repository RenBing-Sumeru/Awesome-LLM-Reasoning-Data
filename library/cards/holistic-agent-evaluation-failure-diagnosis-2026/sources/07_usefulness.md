Use this paper as a design reference for agent trace diagnosis schemas. Preserve trace ID, span ID, parent/child structure, span kind, input/output, tool feedback, local metric score, rationale, mapped category, severity, aggregation rule, judge model, and mapper version.

For the atlas, it is useful because it separates terminal success from localized failure evidence. It can inform verifier design for agent trajectories, but its outputs should be stored as judge-derived diagnostic labels rather than ground-truth environment outcomes.
