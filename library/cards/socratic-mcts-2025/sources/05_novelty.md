The method's main change is the semantic search unit. Rather than branching over tokens or fixed reasoning steps, it branches over dynamically generated questions, then answers each new question with a decoupled policy call to reduce propagation of the current path's mistakes. Node evaluation composes the path back into a final-answer context and uses several wrap-up-conditioned completions, while confidence gating and direct-exit nodes avoid spending the full budget on every item.

MCTS, UCT, self-consistency, question decomposition, and early exit are established components. Socratic-MCTS combines them into a multimodal test-time trajectory whose nodes have interpretable question–answer content. For this atlas, the direction signal is that visual search data should preserve both semantic actions and the internal-agreement machinery. Benchmark accuracy is the end-to-end quality signal; it does not validate individual subquestions, answers, weights, or tree branches.
