The input is an image plus a multiple-choice question. InternVL2.5-78B first provides an initial answer and confidence estimate; the reported search gate skips MCTS when confidence exceeds 0.9. Otherwise, the subquestion policy and isolated-answer policy run at temperature 0.6. The first tree level expands up to six subquestions and later levels up to three. A node terminates when the model produces no answer or degenerates into repetitive output. UCT uses exploration constant 1.4.

Each value estimate composes the partial path, appends one of eight wrap-up phrases, and obtains eight answer completions. The method parses each completion to a canonical choice and assigns a normalized heuristic weight; reaching maximum length without a valid answer receives weight zero. Weighted answer agreement is backpropagated through the tree. Direct-exit nodes omit the exploration term to reduce their special-node bias. The final answer is selected through the search and internal-agreement statistics rather than a benchmark label.

Experiments use a frozen model with single runs: 40 MCTS iterations for MMMU-PRO and 20 for MMStar and the English multiple-choice subset of MathVista test-mini. The paper also compares Direct Answer, greedy CoT, and a depth-3 multimodal Least-To-Most baseline. There is no model training. Exact prompt packages, transition lists, per-node seeds, tree logs, parser implementation, and executable code were not confirmed as official releases.
