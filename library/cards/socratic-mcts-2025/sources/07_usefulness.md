Socratic-MCTS broadens the Rollout, Search, and Test-Time Trace Data track beyond text-only math and code. It supplies a concrete schema in which an action is a subquestion, a state includes a subanswer, the value comes from weighted internal agreement, and the budget is measured in MCTS iterations and rollouts. It is useful for comparing semantic tree search with flat best-of-N or prompt-only decomposition.

A reusable visual-search record should include the image identifier and license, benchmark item and split, model/version, root answer and confidence, confidence estimator, search-gate decision, parent node, subquestion candidates, isolated subanswers, transition phrase, terminal reason, UCT components, eight rollout completions, parsed choices, heuristic weights, agreement value, backpropagated statistics, direct-exit status, iteration count, final answer, and ground-truth evaluation. The ground-truth label should remain separate from the internal value signal. Without released logs, the paper is an evaluation recipe rather than a trace-data source.
