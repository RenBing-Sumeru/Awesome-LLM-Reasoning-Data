Socratic-MCTS defines an action as a generated subquestion and a node state as that subquestion paired with an answer. A question policy proposes the next actions from the current trajectory, while an answer policy answers each subquestion in isolation from the image; the experiments use the same InternVL2.5-78B model for both roles. UCT balances the accumulated node value against exploration.

To estimate a node, the method appends diverse wrap-up transitions and samples eight short completions. A parser extracts canonical multiple-choice answers, a heuristic downweights verbose or degenerate outputs, and weighted majority agreement supplies the rollout value. Direct-exit nodes allow an answer to terminate a path, while an initial-confidence threshold can skip search entirely. Compared with Least-To-Most prompting, the decomposition is searched and value-guided; compared with ordinary MCTS, actions are semantic subquestions. Internal agreement remains a judgment-required proxy and can be confidently wrong.
