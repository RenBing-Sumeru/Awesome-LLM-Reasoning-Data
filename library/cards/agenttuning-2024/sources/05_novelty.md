Earlier agent fine-tuning usually targeted one environment or treated an agent framework as the main intervention, leaving cross-task transfer and general-language retention unresolved. AgentTuning changes the training object to a small six-task mixture of complete, reward-filtered ReAct conversations and jointly samples general dialogue during SFT. This makes trajectory diversity and mixture ratio auditable decisions rather than incidental logs. ReAct, GPT teachers, task rewards, and next-token SFT are not themselves new.
