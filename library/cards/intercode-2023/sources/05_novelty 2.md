The prior baseline is usually static QA, single-file editing, or hard-to-reproduce demonstration scripts. The change here is packaging Docker Bash, SQL, Python, CTF, and SWE interactive coding environments as an executable environment, task set, trajectory surface, or automatic evaluation harness.

It is a direction signal because post-training agents need actions, state, tool feedback, test results, and verifiable outcomes.

What is not new is a leaderboard score by itself. Reuse must check artifact version, license, contamination, task leakage, and evaluator stability.
