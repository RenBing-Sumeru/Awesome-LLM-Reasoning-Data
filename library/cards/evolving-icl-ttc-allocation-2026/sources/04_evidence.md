The paper’s main evidence is a set of coverage-versus-output-token curves across five benchmarks and four API model configurations. On MATH-500, the similarity-conditioned adaptive version is above uniform sampling, elimination, and its own random-demonstration variant over the shown token ranges for Gemini with and without thinking, GPT-4.1 Mini, and GPT-5 Nano. The same qualitative ordering is reported on LiveCodeBench, MinervaMath, GPQA-Diamond, and the hard Reasoning Gym evaluation, with GPT-5 Nano on Reasoning Gym noted as an exception where prompt conditioning is less sensitive.

The ablations isolate the proposed distribution change. Neighbor prompting exceeds the fixed prompt on MATH-500, while random demonstrations are less stable and can underperform on reasoning-intensive benchmarks. The paper also substitutes temperature scheduling for evolving demonstrations, evaluates a self-consistency version that stops at 75% consensus, and tests reward-model and 5%-noisy-reward variants. These checks support the narrower claim that structured, similarity-based conditioning improves allocation efficiency beyond merely eliminating solved questions.
