The algorithm initializes an answer pool and active set for all test queries. During the one-round warm-up, it generates K responses per query using a zero-shot chain-of-thought prompt. Ground-truth correctness is the main reward oracle and a question is removed when any response is correct. The method embeds all questions, fixes a semantic neighborhood for each query, and records successful responses as the evolving test-time demonstration set.

During adaptive rounds, each active query receives an in-context prompt composed of the most recent successful responses from its top-P neighbors; the paper uses four total rounds and P equals three by default. It evaluates MATH-500, LiveCodeBench, MinervaMath, GPQA-Diamond, and a 400-question hard Reasoning Gym set using Gemini-2.5-flash-lite with and without thinking, GPT-4.1 Mini, and GPT-5 Nano. Comparisons include uniform best-of-N, adaptive elimination with a fixed generation distribution, and random rather than similarity-selected demonstrations; coverage and output-token curves are reported over four runs.
