Use this paper to design a batched inference service in which successfully verified requests can help related unresolved requests during the same run. The reusable recipe is to define a verifier contract, run a low-cost warm-up, exclude solved items, retrieve only semantically close and verified demonstrations, and plot both quality and total input-plus-output cost against a no-sharing baseline. It is not a drop-in evaluation protocol for benchmarks requiring item independence. Any adoption should freeze the allowed information flow, log demonstration provenance per answer, test false-positive propagation, and report how results change when test-set reuse is disabled.
