论文的主要证据是一组跨五个基准和四种 API 模型配置的覆盖率—输出 token 曲线。在 MATH-500 上，基于相似度条件化的自适应版本在展示的 token 范围内高于统一采样、淘汰策略和自身的随机示例变体，涉及启用与未启用思考的 Gemini、GPT-4.1 Mini 和 GPT-5 Nano。LiveCodeBench、MinervaMath、GPQA-Diamond 与困难 Reasoning Gym 上也报告了同样的定性排序；但论文指出 GPT-5 Nano 在 Reasoning Gym 上是例外，因为它对提示条件化不那么敏感。

消融实验隔离了所提出的分布变化。邻居提示在 MATH-500 上超过固定提示，而随机示例更不稳定，且在推理密集基准上可能表现更差。论文还用温度调度替代演化示例，评估在 75% 共识时停止的自一致性版本，并测试奖励模型和 5% 噪声奖励变体。这些检查支持较窄的结论：结构化、基于相似度的条件化能在只淘汰已解决问题之外进一步提高分配效率。
