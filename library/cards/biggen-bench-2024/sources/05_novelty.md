The prior baseline is broad open-generation or preference evaluation with shared criteria. BiGGen changes the data object by making every instance carry a tailored rubric, reference answer, and capability label. The quality signal is the public CC-BY-SA-4.0 HF dataset, GitHub evaluation scripts, task documentation, and leaderboard. What is not new: LLM-as-judge scoring and Likert rubrics. Before reuse, inspect evaluator-model choice, rubric leakage, score calibration, license inheritance, prompt sensitivity, and whether scores are used only for evaluation rather than reward training.
