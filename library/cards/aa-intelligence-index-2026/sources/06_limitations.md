The index is text-only and English-only, while image, speech, and multilingual performance are evaluated separately. A strong aggregate score can hide weak component performance.

Several components rely on judge models, equality checkers, official servers, or internally maintained benchmark copies. Those dependencies make the score sensitive to methodology version, API behavior, and access policy.

Do not use the aggregate number as row-level evidence or as a reward signal without separately auditing each component's verifier contract.
