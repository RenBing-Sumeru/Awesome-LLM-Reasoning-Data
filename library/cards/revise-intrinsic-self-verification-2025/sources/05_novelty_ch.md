贡献是把验证与纠错序列化到同一模型 token 空间。显式控制动作让“停止”和“修正”成为可训练 continuation，第二阶段则把 gold correction 条件化在模型自身失败前缀之后。验证与修复因此由具体序列 schema 连接，而不只是一次 retry 指令。

训练顺序经过刻意设计：先学习何时停止，再学习检测失败后如何继续。pair schema 同时随结果正确性和 curriculum 阶段变化。这不同于普通 retry prompting——后者没有学习错误条件 gate；也不同于外部 verifier search loop——后者把 gate 交给另一个系统。

内在设计减少了推理期依赖，却没有消除验证风险，而是把决定移入生成原路径的同一模型。评估重点应是校准与“正确改错”退化，而不能假设自信度等于正确性。
