口头置信度存在系统性过度自信，其排序能力也可能随模型、语言、领域、提示格式、工具或网页状态变化。在 SailorFog-QA 上选择的阈值未必能迁移到 BrowseComp 或真实流量。高置信可能让错误答案提前终止，低置信也可能丢弃正确答案；预算耗尽后选择最高置信答案依赖的是相对排序，而不是绝对校准。

摘要可能遗漏或扭曲证据，并使后续尝试产生锚定；负约束也可能压制其实正确的先前答案。多次实时网页尝试并不独立，token/尝试次数还没有覆盖全部工具、摘要模型、延迟与 API 成本。评测按基准惯例使用 LLM-as-a-judge。本卡未确认公开代码、完整尝试、查询、网页快照、摘要、被拒输出、逐模型阈值、许可证、去污染和重放清单，这些字段仍为 unknown。
