Fixed-budget test-time scaling gives every web query the same number of costly agent attempts, even when the first answer is likely sufficient. BrowseConf asks whether an agent's verbalized confidence after a long sequence of search, visit, reasoning, and observation steps can route additional attempts. The relevant record is an attempt-level trace containing the query, actions and observations, final answer, self-reported confidence, attempt index, carried-over context, stop decision, and evaluation outcome. Confidence is a model-produced control signal, not a correctness label or calibrated probability by default.
