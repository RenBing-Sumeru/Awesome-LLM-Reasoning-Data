Use LongVideoBench as a schema for long multimodal evaluation records: preserve video id or reference, duration, frame sampling policy, subtitle/transcript availability, question, options, gold answer, referred context, split, model input policy, and score. It is useful for audits that separate retrieval of the relevant time span from answer selection. For atlas use, it shows how a benchmark can combine human-authored questions with objective multiple-choice scoring while still needing evidence-grounding checks.
