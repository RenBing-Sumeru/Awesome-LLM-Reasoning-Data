- **success-only SFT：** 公开3,085个turn row全部来自412条成功完成trajectory，reward均为1。failed demonstration与recovery behavior缺失；独立使用row还可能掩盖trajectory boundary并重复history context。
- **online rollout发布缺口：** 主要policy约54K条trajectory未确认公开。identical-reward group被丢弃，judge/infrastructure failure可被loss-mask，也没有不可变ledger把生成episode连接到reward、mask、optimizer step或checkpoint。完整success/failure/abort retention为unknown。
- **task membership漂移：** 公开RL JSONL含2,198个task，默认代码使用2,102-task parquet。需要paper-bound manifest才能确定哪些task、filter、evaluator reference与validation row产生报告模型。
- **judge有效性：** VLM judge可能被gaming，且以GPT-4.1 label而非独立human truth训练。format gating、parsing、仅最近三张screenshot、action/history截断、API漂移与failure masking可能产生false positive/negative。Judge-13K class balance与完整indexed count为unknown。
- **live-web replay：** website content、availability、locale、region、time、cookie、personalization、login state、CAPTCHA/anti-bot behavior、redirect与付费Browser-Use服务行为都会改变observation和outcome。Kubernetes isolation减少跨rollout污染，但不提供deterministic site snapshot或replay capsule。
- **decontamination与lineage：** 论文报告evaluation-overlap filtering和embedding deduplication，但未发布不可变task-level overlap hash、rejection ledger、精确benchmark snapshot或base-model pretraining exposure audit。从292K source task到15,601个SFT candidate、412条trace、2,198/2,102个RL task与online rollout的完整链仍不完整。
- **许可：** code、SFT Trajectories与RL Tasks声明Apache-2.0。Judge-13K及各policy/SFT/judge model API没有已确认license/model-card metadata。website content、screenshot、upstream benchmark与third-party service可能适用单独权利，不能假设继承Apache-2.0。
- **隐私与安全：** SFT记录包含来自live site的screenshot、URL、history与response。dataset card称无意包含private data，但未记录系统化PII/copyright scan、redaction、consent、data-subject或takedown audit。风险包括scraping、绕过bot detection、inauthentic engagement、purchase/form错误及对第三方施加流量。
- **系统与metric：** official scoring依赖付费Stealth Browser服务与推荐judge。排除aborted infrastructure failure的success是不同metric。精确code/container/browser/model/API固定、seed、dependency、reward constant及规范化90-iteration/30-step-stage launch manifest均不可用。
