The strongest novelty is the combination of broad, maintained live-site tasks with a visual, trajectory-aware outcome judge. Earlier web benchmarks already supplied web tasks, demonstrations, live interaction, or model-based scoring separately. Online-Mind2Web makes task decay and website drift first-class evaluation concerns, and WebJudge separates key-point extraction, evidence-frame selection, and terminal judgment.

For data curation, the useful conceptual advance is the explicit distinction among an action trace, action-effect status, and episode success. A click can execute successfully while the task fails; an episode can be not executable because the site changed; and a judge can fail because the decisive screenshot was filtered out. This decomposition is reusable for reward and verifier datasets beyond web browsing.

The later v2 submission schema is valuable release engineering, but it should not be retroactively read as proof that all paper runs were captured under that schema. Likewise, WebJudge-7B is evidence of reusable reward-model supervision for screenshot relevance, not evidence that the full evaluator or all benchmark trajectories form a complete policy-training dataset.
