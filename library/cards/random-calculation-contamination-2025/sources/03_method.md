The generator recursively builds expression trees with 1-20 binary operations. The paper describes bounded integer, fraction, square, and cube leaves and the four basic arithmetic operators. The implementation converts each LaTeX expression through latex2sympy2, evaluates it numerically with SymPy, rejects non-real or non-finite values, applies a nominal 0.001 float-conversion check, shuffles, and keeps up to 1,000 items for each level. Because both operands in that check are converted to `float`, it is not a comparison against a retained high-precision reference. The checked-in data has no duplicate prompts, but the generator does not implement explicit deduplication.

The checked-in JSON records expose `id`, `prompt`, and `answer`. Files `01_op_list.json` through `20_op_list.json` each contain 1,000 rows for the paper's 20 levels; the directory also contains a 1,000-row `00_op_list.json` of base expressions. Operation level is represented by file organization rather than a released per-record derivation tree. IDs reflect enumeration before filtering and therefore have gaps in several files. A seed is not fixed, so regeneration is a recipe reproduction rather than an exact reconstruction of the checked-in files.

For RLVR, the paper selects the 5- and 10-operation subsets and reports a 700/300 train/validation division for each. Exact split membership is not released. The main model is Qwen2.5-Math-7B, with Llama3.1-8B-Instruct used as a comparison. Reported training uses GRPO in a TTRL-style setup, learning rate 5e-7, batch size 128, temperature 1.0, and 16 sampled responses per prompt. The Avg@16 evaluation reference instead uses temperature 0.7, top-p 0.8, and top-k 20; these decoding settings should not be conflated with training.

The correct reward is continuous in [0,1] and uses absolute and relative numeric error, avoiding an almost-everywhere-zero exact-match signal. Controls replace it with random, inverted, or majority-voted-incorrect feedback. Because the contract observes the final numeric answer, it does not validate the semantic correctness of an intermediate rationale.
