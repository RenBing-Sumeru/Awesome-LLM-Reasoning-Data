The contribution is to turn a dynamic, multi-step browser episode into a collection of single-step reasoning problems whose answers can be scored without executing every candidate in WorkArena.

The data object has two layers. The upstream layer is a successful oracle-like trajectory `(a0,o0,…,aT,oT)` produced by BrowserGym/Playwright for one WorkArena configuration. The downstream training layer is a state/action record: task goal, current webpage content, action history, action definitions, and oracle next action. Standard SFT uses o3-mini-annotated trajectories; the SFT-L ablation uses `DeepSeek-R1-Distill-Llama-70B`; GRPO samples a group of reasoning/action candidates from the policy.

The feedback contract is programmatic. It can observe whether the answer respects the `&lt;think&gt;`/`&lt;action&gt;` structure, whether the proposed operation is valid, whether its function name equals the oracle function, whether its parameters match, and whether extra tokens follow the closing action tag. The paper assigns 0.1 for format, 1 for exact action and parameters, 0.1 for action type alone, and −0.9 for post-termination tokens. It cannot observe whether the reasoning is faithful, whether a different action would also succeed, or whether the candidate completes the task. WorkArena terminal success is measured only during evaluation.

The nearest substrates are WorkArena, which defines the workplace tasks and environment success checks, and BrowserGym, which supplies standardized observations/actions and heuristic `cheat()` programs. The optimization scaffold comes from GRPO, veRL, and TinyZero. Relative to a conventional SFT trajectory pipeline, WorkForceAgent-R1 changes the unit of optimization and installs an explicit next-action reward; it does not introduce the environment, Playwright oracle mechanism, or GRPO itself, and it does not release a new corpus.

The resulting research direction is rule-verified agent training under expensive interaction: use environment programs to generate references, then learn from state-local decisions. The central audit question is whether the cheap proxy preserves the alternatives and long-horizon consequences that live interaction would reveal.
