The canonical record is the March 2026 Findings of EACL paper, ACL Anthology ID `2026.findings-eacl.3`; the 2025 suffix in this Card ID reflects the earlier arXiv submission, not the formal publication year. The paper addresses a specific training problem: supervised web agents can memorize demonstrated paths, yet workplace pages change after every action and expose long HTML or accessibility-tree observations. End-to-end multi-step RL would repeatedly execute a costly remote environment, so the authors seek a cheaper signal for learning the next action with explicit reasoning.

The construction starts from WorkArena's 33 ServiceNow task types. Ten training configurations per task yield **330 reported training configurations**. BrowserGym `cheat()` functions execute Playwright scripts to create oracle-like sequences of actions and observations. Invalid-action or unsuccessful trajectories are removed, and each retained sequence is split into independent decision records. A record combines the natural-language goal, current HTML/AXTree observation, previous actions, available operations, and the oracle next action; SFT may also attach teacher-generated reasoning, while GRPO attaches sampled `&lt;think&gt;...&lt;/think&gt;&lt;action&gt;...&lt;/action&gt;` completions and rule rewards.

This belongs in `environment_agent_trajectory_data` because its central object is derived from interaction trajectories and its supervision is tied to environment state and action, even though the RL verifier is an offline oracle-action matcher rather than live terminal feedback. It is not a released trajectory dataset, a general web benchmark, or proof of end-to-end planning: the repository contains recipe code with external data/model placeholders, but no accepted trajectories, rejected failures, checkpoints, or replay manifest.

The Card is therefore useful as an auditable construction and feedback recipe. Its L3 boundary is deliberate: the paper and code are inspectable, but data reuse, exact replay, failure-distribution analysis, and model reuse remain blocked by missing artifacts.
