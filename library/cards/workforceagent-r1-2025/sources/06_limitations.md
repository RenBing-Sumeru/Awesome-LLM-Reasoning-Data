- **Proxy false negatives.** Exact oracle-action matching can score a different but valid navigation action as wrong. Because sampled candidates are not executed, the verifier cannot detect equivalent paths or recovery strategies. This is a curator inference from the stated surrogate contract.
- **Reasoning is unverified.** Tags and actions are checked, but the content inside `&lt;think&gt;` is not compared with state transitions or causal evidence. Higher action reward therefore does not prove faithful reasoning.
- **Dropped failures.** The construction removes invalid-action and unsuccessful trajectories before training. No rejection count, IDs, raw failed records, or per-task acceptance rates are released, so selection bias and failure coverage cannot be measured.
- **Release gap.** The repository ships code with unresolved external data-path and model-path fields, not the 330 configurations, accepted trajectories, derived records, teacher annotations, GRPO samples, evaluation episodes, or trained checkpoints. Complete successful and failed trajectories are both unavailable.
- **Paper/code drift.** At commit `1ee2619b…`, `webagent.py` relaxes several tag checks, uses scores on a different scale from `Rf+Rs+Rp`, and contains a postfix-length branch inconsistent with its labels/comments. The preprocessor also derives train and test with separate `train_test_split` calls. No run manifest binds the reported experiments to corrected code.
- **Reward hacking.** The paper directly observes dense-reward variants collapsing toward a frequent click or generating excessive post-termination actions. The sparse design is more stable, but the authors still list superficial reward hacking as a limitation.
- **Benchmark overlap.** Training and testing configurations are reported separate, yet both use the same 33 WorkArena task types and ServiceNow substrate. No broader browser-domain evaluation or model-training contamination audit is reported.
- **Hidden teacher traits.** o3-mini perturbs configs and annotates SFT reasoning; DeepSeek-R1-Distill-Llama-70B supplies SFT-L reasoning. Exact versions, prompts, outputs, sampling controls, costs, and filtering are unknown.
- **Replay and versioning.** WorkArena is remote-hosted; ServiceNow state, BrowserGym/Playwright versions, container/database snapshots, configuration IDs, split seed, and checkpoint hashes are not pinned. The repository has no tag or GitHub Release.
- **Rights boundary.** The ACL paper is CC BY 4.0, but no root LICENSE covers the code repository, and unavailable training data/checkpoints have unknown terms. Apache headers on inherited files cannot be generalized to the entire release.
- **Author-stated scope.** The paper notes a gap to stronger commercial models, limited generalization beyond workplace browsing, and residual reward-hacking risk. Benchmark scores should not be treated as proof of data quality or safe deployment.
