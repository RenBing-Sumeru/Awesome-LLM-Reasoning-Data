The release boundary is the main audit limitation. Each of the 523,776 stored predictions is an extracted string or option letter, not a raw completion. There are no released reasoning traces, token logprobs, seeds, per-attempt token counts or latency, rollout rewards, advantages, or stable per-rollout identifiers. Incorrect final answers are observable, but the failed reasoning that produced them is not; reward hacking, unsupported reasoning, and answer-extraction errors therefore cannot be inspected.

`pass_rate` is a Qwen3-VL-8B-Instruct measurement at temperature 1.0, quantized in increments of 1/16. It can change with the policy, prompt, extraction rule, seed, or unreported sampling controls, so it is not an intrinsic difficulty property. Sorting higher pass rate first also encodes a particular easy-to-hard choice rather than proving that the order is optimal for every backbone.

The verifier grants most credit to final-answer equivalence and a smaller amount to output format. It does not check intermediate reasoning, image grounding, or whether the answer follows from the cited visual evidence. The same MathRuler-based reward is used across all three released Qwen3 stage launchers, including perception tasks; syntactically compliant or fortuitously correct answers can receive reward.

Lineage is incomplete in several ways. The paper lists DocVQA in Stage 3, whereas the hosted 16,195-row dataset lists only Math PUMA, GeoQA170K, CLEVR-Math, and ArxivQA. Stage-1 rows omit the DOCCI captions used to generate them. The hosted artifacts expose only `train` splits; a deterministic 85/5/10 formatter in the Stage-1 utility is a local construction option, not evidence of released validation and test manifests. No decontamination procedure is disclosed.

Licensing must be audited below the top-level labels. The paper is CC BY 4.0, the code repository is Apache-2.0, and the dataset cards declare Apache-2.0. Yet Stage 1 derives from DOCCI and notes its caption license, Stage 2 redistributes ORZ-Math-13k, and Stage 3 says each image source retains its upstream license. Those source-specific obligations are not replaced by the collection-level license.

Other interpretation risks include correlated errors from using Qwen2.5-72B to generate Stage-1 questions and two Qwen2.5-VL models to filter them, and an inconsistency between broad main-text wording about the vision encoder and the appendix/scripts' open-frozen-open schedule. Benchmark improvements demonstrate outcomes in the reported settings, not completeness or quality of the data release.
