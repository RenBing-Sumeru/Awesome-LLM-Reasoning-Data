VLM-CapCurriculum separates two curriculum axes. The capability curriculum runs visual perception, then textual reasoning, then visual reasoning. The difficulty curriculum samples every released problem 16 times with Qwen3-VL-8B-Instruct at temperature 1.0, extracts the final answer from each attempt, grades it against the target, and stores the mean correctness as `pass_rate`; the combined curriculum sorts examples from higher to lower pass rate inside each capability stage.

The reusable object is an eight-field row: `index`, `problem`, `answer`, `images`, `source`, 16 `predictions`, 16 `correctness` flags, and `pass_rate`. Across 32,736 rows, the vectors contain 523,776 extracted answer-level attempts and the same number of correctness labels. Incorrect extracted answers remain in those vectors. The corresponding full completions, reasoning text, and rejected chains of thought do not.

Images are retained only where the task is multimodal: Stage 1 perception and Stage 3 visual reasoning reference downloadable image archives, while Stage 2 text reasoning uses an empty image list. The object is therefore suitable for auditing answer-level repeated sampling and curriculum order, but not for inspecting the reasoning that led to each answer.
