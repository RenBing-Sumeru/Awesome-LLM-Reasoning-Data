Use this card when selecting a reasoning-token cap, comparing test-time search policies, or deciding whether a new scaling method should report more than pass rate. Its measurements can be added to an internal serving evaluation: plot per-budget marginal gain, count answer regressions, segment by difficulty, and choose a stopping rule under an explicit cost sensitivity. It is a measurement paper, not a plug-in early-exit method, so a production policy still requires validation on the intended model and workload.
