The contribution is a large demonstration dataset for Android control, released with conversion and evaluation code. Instead of asking models only to identify a UI element in a screenshot, AITW records full device-control episodes and asks policies to predict the next action under a normalized Android action space. The feedback contract is offline: predicted action type and touch/text parameters are compared with the recorded human action under evaluator rules, and task success is inferred only through the labeled trace. Closest comparisons include MiniWoB/PixelHelp-style web or UI tasks and later mobile datasets such as AndroidControl and AMEX. The direction label is real-device trajectory data with action-level supervision.
