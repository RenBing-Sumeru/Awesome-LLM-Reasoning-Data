AITW correctness is relative to recorded demonstrations and evaluator rules. A predicted action can match the logged next action while still failing if replayed in a different app version, account state, locale, or screen size. Human traces may contain multiple valid alternatives, so next-action matching can penalize valid behavior that diverges from the demonstrator. The release is large and bucket-dependent; missing files, changed repository code, or undocumented filtering can affect reproduction. Public demonstrations are also a contamination risk for later mobile-agent training corpora.
