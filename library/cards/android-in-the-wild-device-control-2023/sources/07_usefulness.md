AITW is useful as a base dataset for mobile imitation learning, offline agent evaluation, and action-space design. Reusable records should preserve task text, subset name, episode id, step id, screenshot or observation reference, action type, action parameters, text payload, previous and next states, device metadata if available, and evaluator version. For atlas purposes, it supplies an early large-scale mobile trajectory benchmark whose audit focus is the gap between demonstration-label agreement and live-environment success.
