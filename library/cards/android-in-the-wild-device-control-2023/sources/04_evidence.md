The official abstract and repository describe about 715K human demonstrations over roughly 30K unique instructions. The repository exposes the Android in the Wild code entry and downloader/evaluation utilities, which is the primary reproducibility evidence. The paper reports baseline agents on the offline benchmark, but the row-level evidence is the stored action trace and evaluator agreement with the human next action, not a fresh execution certificate. Evidence is bounded by whether the public bucket remains accessible, the exact split and action-normalization code used, and the gap between action imitation metrics and real task completion in a drifting Android ecosystem.
