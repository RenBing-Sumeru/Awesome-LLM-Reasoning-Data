The central intervention is Echo-CoT hard-negative construction. Standard CoT prompts ask for step-by-step reasoning and a boxed A/B/C answer. Echo prompts instead state one of A/True, B/False, or C/Uncertain as an assumption and request reasoning that supports it. When the asserted answer differs from the benchmark label, the generation can become a fluent negative whose reasoning is aligned with the wrong conclusion rather than a random malformed response.

The feedback contract has three layers that should not be conflated. First, a programmatic checker parses the boxed label and assigns reward 1 for exact equality with the gold label and 0 otherwise. Second, a GPT-4o judgment prompt examines wrong Echo rationales; errors the judge recognizes are discarded, while wrong traces the judge fails to flag are retained as harder negatives. Third, a Qwen2.5-7B-Instruct ORM is trained over the complete trace to predict the probability of a final `+` rather than `-` token. At inference, this learned scalar—not the gold checker or Echo judge—ranks independently sampled solutions.

The released FOLIO files expose the result of this construction but not its full provenance. The ordinary file contains 10,009 CoT rows. The combined Echo-CoT file contains all of those rows plus exactly 9,096 additional Echo rows, every one with reward 0, for 19,105 rows in total. Because the combined schema has no CoT/Echo origin flag, candidate ID, judge verdict, or filter-decision field, the augmentation can be recovered by comparing the two files but cannot be audited as a native per-record lineage.

Relative to ordinary outcome labeling, the contribution is a targeted way to enrich the negative class with answer-conditioned rationales and then connect that data to Best-of-N test-time selection. It is not step-level process supervision: intermediate statements receive no correctness labels, and a trace with invalid reasoning can still be positive if its final A/B/C answer matches gold.
