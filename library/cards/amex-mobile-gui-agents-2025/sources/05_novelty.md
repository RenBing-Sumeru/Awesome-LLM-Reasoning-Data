The prior baseline is mobile GUI data that mainly records screenshots, UI features, and actions, with weaker element-function semantics or less third-party app coverage. AMEX changes the data object by aligning visible interactive boxes, functionality descriptions, and long instruction-action chains on the same Android screens. The direction signal is a reusable schema for training/evaluating agents that need to reason over screen layout and element affordances. What is not new: Android emulators, screenshot trajectories, human demonstrations, GPT-assisted annotation, and action matching are established components. Before reuse, inspect license, HF split integrity, zip reconstruction, author/version mismatch across official pages, app distribution, evaluator assumptions, and contamination risk from public screenshots.
