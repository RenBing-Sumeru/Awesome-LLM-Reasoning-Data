AMEX is useful as a recipe for multi-layer mobile GUI supervision and as a benchmark surface for grounding, screen understanding, and action-chain modeling. A reusable record should preserve app identity, screenshot id, element boxes, element type or affordance, screen description, element functionality, instruction, step index, action, action target, split, annotator/GPT provenance where available, and evaluator version. For atlas work, it is a strong example of environment-agent trajectory data with human/GPT annotation contracts, but downstream comparisons should keep L1/L2/L3 tasks separate.
