The contribution is a multi-level Android GUI dataset for generalist mobile agents. AMEX changes the usual AITW-style trajectory object by adding three annotation levels: interactive element grounding, screen and element functionality descriptions, and complex instructions with stepwise GUI-action chains averaging about 13 steps. The feedback contract is mixed: human filtering and checking validate boxes and descriptions, while released evaluation tools and downstream action/grounding tasks provide model-comparison scores. The closest comparisons are AITW, AitZ, MoTIF, UGIF, and PixelHelp; AMEX is a direction signal for richer mobile trajectory data, not a proof that an agent can safely execute arbitrary real-app tasks.
