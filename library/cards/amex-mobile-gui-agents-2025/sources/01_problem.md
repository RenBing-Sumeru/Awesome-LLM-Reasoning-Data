AMEX asks how to give mobile GUI agents a training and evaluation surface that contains more than action coordinates. The primary sources are the ACL Anthology Findings 2025 paper, the arXiv record, the project page, the codebase, and the Hugging Face dataset. The collection target is Android GUI-control on popular third-party apps, not API-tool use or a live reinforcement-learning environment. A data item may include a screenshot, interactive-element boxes, screen and element function descriptions, a natural-language instruction, and a stepwise GUI-action chain. Its atlas value is that success can be studied through visible GUI grounding and action-chain supervision instead of only final task completion.
