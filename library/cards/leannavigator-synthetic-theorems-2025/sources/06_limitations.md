- **The graph is not released.** Public rows omit seed theorem and file IDs, graph IDs, predecessor states, accepted alternative edges, rejected tactics, failures, distances, and verification transcripts. The graph cannot be reconstructed from `[state, proof]`.
- **The exact count is not release-bound.** The official notebook loads 4,702,639 examples, but its local filename is not checksum-linked to the Zenodo archive. Zenodo publishes a file checksum but no row-count manifest; the full MD5 and row count were not independently recomputed.
- **The environment pin is incomplete.** Notebooks expose Mathlib4 commit `27c6744e1c0e25d676be5eb252cd4b6d30c6acc7` and Lean 4.9.0-rc2, but the dataset record does not bind those values, a LeanDojo revision, Python dependencies, or the code commit to the archive.
- **Random row splitting risks graph-family leakage.** The training notebook shuffles and makes an unseeded 90/10 split after graph identifiers have been removed. States derived from the same theorem or graph may cross train and validation.
- **Decontamination is not reproducible.** The authors state that Mathlib4-derived training did not include MIL or MiniF2F content, but no seed manifest, exact/semantic overlap report, ancestor grouping, or base-model pretraining audit is released.
- **The proof horizon is biased.** Retaining only nodes within eight tactics of `ProofFinished` excludes longer-horizon proofs, while shortest-path selection suppresses valid alternative strategies and favors terse tactic strings.
- **Template retrieval constrains diversity.** Templates and positive tactics come from Mathlib4's existing proof ecology. Coverage, duplicate, tactic-frequency, theorem-family, and semantic-diversity analyses are absent.
- **Failed search data disappear.** Invalid tactics and unsuccessful branches could support verifier, preference, process, or search-policy research, but only successful flat targets are published.
- **Training code does not match the paper exactly.** The notebook configures `google/byt5-base`, whereas the paper reports flan-t5-base and flan-t5-small. It also truncates multiline proof targets to the first tactic and lacks a fixed split seed or run-to-table manifest.
- **Licensing is uneven.** Zenodo labels the dataset CC BY 4.0, but the GitHub repository has no root license and the release lacks item-level upstream/derivative-rights analysis.
- **Versioning is weak.** The October 2024 dataset predates the February 2025 paper; the inspected code commit is from April 2025. No tagged, paper-aligned bundle fixes data, code, environment, schema, count, and checksums together.
- **Model performance is not a data audit.** Reported MIL and MiniF2F results do not prove row independence, semantic novelty, contamination control, rights, replayability, or current-version Lean compatibility.
