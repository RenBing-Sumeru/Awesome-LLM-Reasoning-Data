The paper turns contamination mitigation from an accuracy-level claim into a per-question matching problem. For a clean model, an updated benchmark should reproduce the original correct/incorrect vector (fidelity); after fine-tuning the model on the original benchmark, that vector on the update should stay unchanged (resistance). The contribution is an audit protocol and two metrics, not a new universal dataset. Official code provides mitigation, contamination, evaluation, and metric scripts; it does not claim a separately packaged general-purpose dataset release.
