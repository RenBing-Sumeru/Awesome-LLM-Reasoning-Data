1. **生成依赖任务。** 输入：运算数量、随机算术运算符、实体名称与干扰项参数。操作：构建模 23 的顺序依赖链，并确定性计算每个中间状态。输出：问题图与精确最终整数。检查：删除训练评测精确重复，并通过执行验证答案。
2. **渲染轨迹粒度。** 输入：同一条已求解依赖链和一种 CoT 类型。操作：Explicit CoT 输出每个运算，Composed CoT 把每 g 个运算合成一组，Implicit CoT 省略这些运算的中间过程。输出：任务语义相同的不同 target。检查：所有版本必须得到同一个已验证答案。
3. **构建受控划分。** 输入：渲染后的样本。操作：在运算数为 8、16、24 的训练题间保持平衡，构建从 6K 到 768K 的数据预算，并把 32 至 104 个运算的更长链留作分布外评测。输出：匹配的 SFT 与长度泛化数据。检查：每次只改变规模、粒度、顺序或多样性中的一个变量。
4. **执行 SFT 与重复实验。** 输入：Qwen2.5 或 Llama 目标模型和一种轨迹数据。操作：使用 LLaMA-Factory 训练，比较 384K 条不同记录训练 1 个 epoch、同 6K 条记录重复 64 个 epoch，以及 6K 条记录训练 1 个 epoch。输出：样本暴露量或数据多样性匹配的 checkpoint。检查：按未见链长度统计 pass@1，以区分学习与记忆。
5. **在压缩 SFT 后执行 RLVR。** 输入：分别在 24K 条 Explicit、Composed-g=2 或 Implicit-g=2 记录上完成 SFT 的 checkpoint。操作：在未见过的奇数或偶数短运算长度上，用 8 次 rollout 和精确最终答案奖励执行 GRPO。输出：可能把压缩运算重新拆成小步骤的策略。检查：在更长链上比较训练前后 pass@1、回答长度与实际输出运算粒度。

复现信息：官方仓库提供生成器和训练评测脚本，而不是固定数据集。需要固定随机种子、模运算任务语法、运算划分、干扰项、CoT 模板、模型 checkpoint、token 预算、LLaMA-Factory 与 verl 版本及 GRPO 设置；仓库许可仍未确认。
