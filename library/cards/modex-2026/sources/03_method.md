For each prompt, the target model independently generates N paths. ModeX computes an N-by-N adjacency matrix whose entries sum set-based Jaccard overlap for one-, two-, and three-grams. It builds the unnormalized graph Laplacian, thresholds the Fiedler vector at zero to obtain two clusters, and computes cut conductance. A cut with conductance below the reported tau of 0.8 is accepted; the larger cluster survives, with total edge weight breaking equal-size ties. The process recursively rebuilds the induced graph until no acceptable cut remains, then returns the maximum-degree node. The main experiments use N=4, 8, and 16. Generation temperature, top-p, exact per-task token limits, and random seeds are not reported in the paper.

ModeX-Lite starts with N parallel decodes and, every T generated tokens (100 by default in the paper and official code), constructs a graph over current prefixes and performs one non-recursive spectral partition. It keeps the representative subset and continues only those paths until all remaining paths emit EOS; a centroid is then selected. The main setup evaluates the first 300 CNN/DailyMail v3.0.0 test items, all 164 HumanEval test items, and the first 300 Math-500 test items with Qwen2.5-7B-Instruct and Llama3.1-8B-Instruct, replacing Llama with CodeLlama-7B-Instruct for code. The official MIT-licensed repository includes algorithm code, model and dataset wrappers, prompts, evaluation utilities, scripts, and logging hooks, but no reusable candidate/graph/pruning trace corpus was verified.
