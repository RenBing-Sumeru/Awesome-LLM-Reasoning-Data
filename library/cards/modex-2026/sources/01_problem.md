Best-of-N generation can improve the chance of obtaining a useful response, but open-ended outputs cannot be aggregated by exact-answer majority voting. External reward models or LLM judges add cost and their own biases, while perplexity need not correspond to answer quality. ModeX asks whether the sampled responses themselves contain enough structure to select a representative output. Its trace object is an inference-time candidate set plus a deterministic selection record: complete or partial response paths, pairwise n-gram similarities, a weighted graph, Fiedler-vector partitions, conductance tests, retained clusters, pruning events, and the final centroid candidate. This belongs in the rollout/search/test-time trace track because both standard ModeX and ModeX-Lite allocate compute across multiple paths and make explicit decisions about which trajectory survives, without training a selector or generating a replacement answer.
