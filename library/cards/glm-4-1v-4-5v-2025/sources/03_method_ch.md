1. **预训练来源池。** 报告从超过 100 亿图像—文本对开始，来源包括 LAION、DataComp、DFN、Wukong 和 Web 搜索；还列出 MINT、MMC4、OmniCorpus、超过 1 亿本数字化书籍、学术论文、合成与自然 OCR、grounding、GUI、视频和文本来源。这些是来源或初始池规模，不是已发布的最终记录清单。

2. **按来源构造与过滤。** 图像描述数据经过分辨率、纯色、描述长度、图像去重规则，CLIP 分数阈值高于 0.3，再做概念均衡重采样和事实中心 recaption。图文交错 Web 数据删除无关图片、广告、二维码和低信息布局。学术 PDF 被解析，OCR 页面与表格被渲染，GLIPv2 生成自然图像框，Playwright 捕获 GUI 截图和可见 DOM 元素，视频则经过完整性检查、embedding 去重和 human-in-the-loop 标注。

3. **报告的预训练产物。** 报告列出 2.2 亿 OCR 图像、4,000 万自然图像 grounding 标注、超过 1.4 亿 GUI 问答和 5,000 万 instruction-tuning 混合样本；视频和图文交错语料没有完整最终数量。报告称对开源 instruction 数据进行人工与自动污染检查，但没有发布最终唯一记录数、各来源权重、来源版本、许可证、过滤产出率或训练—评测重叠账本。

4. **预训练日程。** GLM-4.1V-Thinking 与 GLM-4.5V 使用共享的 AIMv2-Huge 视觉架构，并分别接入 GLM-4-9B-0414 和 GLM-4.5-Air。多模态预训练在序列长度 8,192、全局 batch 1,536 下运行 120,000 步；长上下文继续训练加入视频和超过 8K 的序列，在长度 32,768 和同一 batch 下运行 10,000 步。报告还描述打包和各模型对应的 tensor/expert/pipeline/context 并行。

5. **长 CoT SFT。** 在可验证与不可验证领域整理以中文、英文为主的推理样本，用预训练模型过滤过易或过难的提示。回答使用 think 区和 answer 区；可验证答案必须只有一个由 `begin_of_box` 和 `end_of_box` 特殊 token 标记的区域；GLM-4.5V 去掉显式 answer 标签。流程删除格式错误、不一致或噪声推理、语言混杂和冗余思考，并把后续 RL 检查点中的选中样本回流。全参数 SFT 使用长度 32,768、全局 batch 32；记录数量与生成器谱系未知。

6. **RL 任务准备。** 在每个领域识别可验证子任务，过滤或合成问答，把唯一答案选择题改成填空，验证正确性，再把多模型 pass@k 与专家标签结合为离线难度。各领域先运行 pilot RL，确认数据与奖励是否能产生可学习增益。数量、来源快照、试验结果和保留清单均未发布。

7. **奖励构造。** RLVR 抽取盒装答案后执行领域化规则、符号、几何、功能或语义检查；RLHF 任务使用 reward model。共享格式/风格检查会惩罚错误盒标记、语言混杂、重复、流畅度不足或不遵循指令。官方仓库公开了可配置 VLM 奖励系统包，包含符号、多模态和 agent 验证器及 LLM-judge fallback，但未开放 reward-model 检查点或完整生产奖励日志。

8. **RLCS 与 GRPO。** 以预设但未披露的比例混合领域数据，用 GRPO 优化。离线难度层级与在线 rollout pass@k、子类表现结合，每个 iteration 重加权。ratio-EMA 扩展采样以弥补全对/全错组。其他报告选择包括更大 batch、截断后强制回答、移除 KL 和 entropy loss、提高上 clip、top-p 设为 1、per-sample loss、负载均衡、打包和梯度累积。准确 rollout 数、温度、batch、学习率、clip、步数、tokens 与计算量仍未知。
