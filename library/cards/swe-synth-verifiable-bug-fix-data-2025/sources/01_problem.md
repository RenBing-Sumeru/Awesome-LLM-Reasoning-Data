Repository-level repair models need complete trajectories for localization, test-log reading, code editing, and patch verification, but real issues are limited and successful agent traces are even scarcer. A bug–fix diff alone does not supervise intermediate tool use. Random code mutation scales easily but often creates non-compiling, untested, or trivial defects.

SWE-Synth asks an LLM to reimplement functions in real repositories to create executable bugs, then lets a software-engineering agent iteratively repair them using failing logs and local code. Construction retains buggy repositories, failing and passing tests, candidate patches, and structured repair trajectories. Only agent outputs verified by tests enter the training set, yielding repository-level, process-aware, and executable data.
