Traditional mutation datasets store before–after code and test outcomes, while SWE-bench-style real data stores issues and gold patches but few successful interaction traces. SWE-Synth has an LLM rewrite complete functions to create contextually plausible but behaviorally wrong implementations, then immediately asks an agent to repair them using real test logs. Synthetic defect, tool process, and terminal verification are bound into one record. It is not the first use of tests for patch filtering or the first bug generator; the change is making process-aware trajectories the main training object and verifying both defect and repair in one repository test loop.
