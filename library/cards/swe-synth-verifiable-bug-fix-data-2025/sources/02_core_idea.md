The main contribution is a single executable loop for both defect synthesis and repair-trajectory synthesis. Across multiple commits from seven Python repositories, the authors select test-covered functions and ask Qwen2.5-Coder-32B to reimplement them after removing their bodies. Versions that compile but make at least one test fail become bugs. The paper reports 9,459 buggy variants and 3,018 test-passing repair patches produced by agents; the visible Hugging Face snapshot may be smaller, so users should pin revisions. Training records can include repository states, test logs, tool interactions, patches, and verifier results for SWE-agent SFT, process distillation, and test-based rewards.
