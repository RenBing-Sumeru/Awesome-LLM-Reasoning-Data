仓库级自动修复模型需要能定位故障、读取测试日志、编辑代码并验证补丁的完整轨迹，但真实 issue 数据数量有限，成功 agent 轨迹更少；仅有 bug–fix diff 又无法监督中间工具使用。直接随机变异代码虽然易扩展，却可能产生无法编译、没有测试触发或过于简单的缺陷。

SWE-Synth 用 LLM 重新实现真实仓库中的函数来制造可执行 bug，再让软件工程 agent 在失败日志和局部仓库中迭代修复。构建过程同时保存 buggy repository、失败/通过测试、候选补丁和结构化 repair trajectory；只有测试验证成功的 agent 输出进入训练集，从而产生仓库级、过程感知且可验证的数据。
