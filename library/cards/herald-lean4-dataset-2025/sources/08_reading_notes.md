- **Use the accepted publication identity.** The ICLR 2025 proceedings record confirms the title, authors, venue, and accepted-paper results. ArXiv `2410.10878v2` is useful for version history, but its abstract retains older scores, so it should not silently replace the proceedings version when reporting performance.

- **Keep release and training counts separate.** There are exactly **579,883** public statement rows and **44,553** public proof rows, each in one `train` split. Using the same 579,883 pairs in NL-to-FL and FL-to-NL directions yields **1.16 million** directional training examples, not 1.16 million distinct released pairs. Rounded paper figures such as 291K originals, 580K statements, and 44K or 45K proofs explain the recipe but do not override the release schemas. The reported 1:2:1 original:tactic:informal mixture is not recoverable row by row because no component label is present.

- **Interpret validation by layer.** Lean compilation is strong evidence for formal elaboration in an environment and, for complete proofs, proof checking; it is not an NL-FL equivalence test. A statement ending in `:= sorry` can compile without a proof. Back-translation plus DeepSeek-V2.5 NLI is a judgment-dependent semantic proxy, so any claim that the combined pipeline verifies meaning should include the Table 4 audit: 151 Herald outputs passed, but only 101 were fully correct.

- **Read repositories by scope and pin.** `herald_translator` contains translator inference, the Lean REPL check, back-translation, NLI, and evaluation data/configuration; it is not the corpus builder. The paper-linked Lean-Jixia URL was unavailable when checked. Verified revisions are statements `d8d849682ecfba92dda26026a97e10a662187f4c`, proofs `2d31b459df74d730bff85682de237d894b4eecfa`, model `c819f8707ef7486befcac64b7ce907afa7fb7dd4`, code `f03f6c40e57baae4ed084f29e0511364f41a2370`, and Lean environment `25a1d0527272e24bc88f0aec08db74e69b5db4b3`. No manifest binds them to one named release. The test environment pins Lean 4.11.0, Mathlib `20c73142afa995ac9c8fb80a9bb585a55ca38308`, and REPL `adbbfcb9d4e61c12db96c45d227de92f21cc17dd`; these are runtime pins, not proven per-row construction provenance.

- **Preserve unknowns.** The most consequential missing information is the exact Mathlib revision and declaration manifest; generator and checkpoint; embedding model and index; complete prompts and decoding; construction code; row lineage; random seeds; candidate and reject ledgers; semantic audit labels; split logic; and decontamination results. These are unknown, not negative findings to be filled with assumptions.
