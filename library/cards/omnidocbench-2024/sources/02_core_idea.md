The contribution is to provide a scale that is not fully pinned in local metadata and must be checked against the official release before quantitative reuse for document-ai, multimodal-reasoning-benchmark under a reusable evaluation surface. The core mechanism is the pairing of task inputs and model outputs with the following feedback contract: the official evaluator, answer key, judge, hidden test, metric, or environment predicate determines success.

The data object or environment is PDF parsing, layout, OCR, table, and formula recognition. The closest comparisons are document, chart, multimodal QA, and visual evaluation benchmarks. The direction label is benchmarks_evaluation_surfaces with a mixed feedback contract. The main thing to preserve is not only the headline score, but the task object, evaluator, split/version, and artifact lineage.
