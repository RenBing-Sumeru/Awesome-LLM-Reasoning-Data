数据收集通过 BrowserGym 运行在五个 WebArena 克隆环境上：Shopping Admin、Shopping、Reddit、GitLab 和 Map，每个域探索 20 个 URL。NavExplorer 使用 Claude-3.7-Sonnet，最多交互 15 步；PageExplorer 分别使用 GPT-4o（最多 20 步）和 Claude-3.7-Sonnet（最多 10 步）。每个候选任务最多进行三次、每次不超过 10 步的 Claude 可行性尝试，由 GPT-4o VLM-as-a-judge 判断成功与否，每个 URL 最多保留 30 个可行任务。对每个可行任务，GPT-4o-mini 和 Qwen-2.5-7B-Instruct Solvers 共生成两条从当前页面开始的轨迹和两条从网站根页面开始的轨迹；最大 horizon 均为 10，temperature 为 0.7。raw exporter 保留图、节点、轨迹、逐步 action/thought/observation 元数据和 PNG 截图；processed exporter 将轨迹转换为由 `next_step_idx` 连接的逐步 prompt/completion 记录，并保留 reward、长度和 step number。论文仅用成功轨迹对 Qwen-2.5-7B-Instruct 做 SFT，并在 temperature 0 下用 WebArena task-specific reward function 评估。复现还需要可运行的 BrowserGym/WebArena、模型或 API 权限、补齐仓库中的路径与凭据占位符，并固定数据集和代码 revision；README 提供命令，但没有可直接复放的不可变运行清单。
