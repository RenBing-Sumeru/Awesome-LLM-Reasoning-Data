ICLR 2026 官方论文和 arXiv v2 处理的是数据收集问题，而不是提出新的浏览器 benchmark：Web 智能体需要与目标环境相关的示范，但人工轨迹成本高，彼此独立的无监督探索 episode 又会反复访问容易到达的页面。Go-Browse 因此把网站表示为逐步发现的 URL 图，在复用已发现页面路径的同时收集任务和 ReAct 浏览器 episode。Go-Browse-WA 的数据对象不只是成功答案列表：论文报告从五个自托管 WebArena 克隆域的 100 个 URL 中得到 3,422 个任务、26,749 条轨迹和 196,462 个交互步骤，包含成功与失败 episode、thought、浏览器 action、observation、reward、图与页面元数据；原始发布还含截图、HTML 派生数据和完整 accessibility tree。它同时适合“Rollout, Search, and Test-Time Trace Data”与“Environment and Agent Trajectory Data”分类；L4 审核应关注实际发布字段、反馈契约、权利与复现边界，而不能只看 benchmark 成绩。
