最接近的数据收集基线可分为两类：NNetNav 等 interaction-first 方法的探索 episode 不共享状态；instruction-first 方法则先从有限观察提出任务，再尝试求解。Go-Browse 的变化在于把已发现 URL 与最短轨迹前缀保存在图中，把探索重置到前沿页面，并将全局导航发现与局部任务执行拆开。它还把任务提出本身变成智能体交互行为，并在 VLM 可行性筛选后显式收集带前缀和从根页面开始的 solver rollout。对本图谱而言，方向信号来自 search state、候选任务、judge、环境 action 与下游训练的联结记录，而不是“图搜索天然保证高质量数据”这一说法。重置到已知页面与 Go-Explore 相近，VLM 筛选也不是全新技术；可复用的新意在于它们被组合为一条 Web 数据流水线。复用审计仍需核对准确 prompt 版本、图与前缀字段、负轨迹、Hub revision、数据权利，以及 closed-model 判断能否重现。
