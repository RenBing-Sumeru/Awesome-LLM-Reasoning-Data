JudgeLM addresses how to evaluate open-ended LLM outputs at scale when exact-match metrics and fixed benchmarks do not cover answer quality. The primary sources are the 2023 arXiv paper, the official BAAI/HUST repository, the JudgeLM-100K dataset, and the OpenReview-linked ICLR 2025 Spotlight record referenced by the repository. The data object is a judging example built from a task seed, one or more LLM-generated answers, optional reference support, and a GPT-4-generated judgment used as supervision or evaluation target. The atlas boundary is judge/reward infrastructure: this is not an objective correctness benchmark like JudgeBench and not a general human-preference dataset. It matters because it exposes a scalable teacher-judge feedback contract, including known judge biases, for later evaluation and reward-model pipelines.
