The supervision is only as reliable as the GPT-4 teacher judgments and prompts. Bias mitigations reduce measured artifacts but do not remove all position, reference, or format dependence. Model release and training depend on LLaMA/Vicuna licensing and exact base weights, so redistribution and commercial reuse need separate checks. Multimodal, multi-answer, and multi-turn extensions are supported by the platform but should not be assumed to have the same evidence strength as the main answer-pair judge setting. Using JudgeLM as a reward model in RL or data filtering changes the risk profile and requires audits for reward hacking and domain mismatch.
