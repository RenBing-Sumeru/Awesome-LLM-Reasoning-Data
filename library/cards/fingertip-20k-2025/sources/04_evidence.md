The main training evidence is a controlled Qwen-2.5-VL-7B LoRA comparison on the authors' two tasks. With the full 16,000-episode training set and rank 64, proactive suggestion changes from `SR1` 3.1% and `Sim1` 0.25 before fine-tuning to 26.0% and 0.55 after fine-tuning. Personalized execution changes from `SR2` 1.5%, `Sim2` 0.95, and step ratio 2.16 to 15.5%, 1.42, and 1.13 (Paper §5.4, Table 5). These are author-reported results; the release has no training script or checkpoint for independent reconstruction.

The benchmark also exposes a large remaining gap. With zero initial screenshots, the best tested generalist proactive system reaches `SR1` 12.8%, while the human reference reported by the authors is 30.3%. For execution, UI-TARS-1.5-7B reaches `SR2` 38.5%; most un-fine-tuned `Sim2` values remain near 1, meaning their action sequences are not substantially more similar to the current user's behavior than to a different user type (Paper §5.2, Tables 3–4). These results define the tested benchmark surface, not general mobile-agent reliability.

The execution fine-tuning result is especially important to interpret conservatively: 15.5% `SR2` remains low even after the reported increase, and `SR2` was manually judged from the final phone state. The 2.5× action-length cutoff can fail a valid but longer path, whereas `Sim2` can reward action-string resemblance without proving functional completion. The public execution script does not reproduce the manual label and writes `success=0`, so its output alone cannot recover the paper's `SR2` (Paper §5.1; official `personalized_execution.py`).

Artifact inspection supplies independent audit evidence about release shape, not independent reproduction of model results. At the pinned GitHub commit, `total.csv` has 20,000 rows, 83 users, and 482 app identifiers; `test_suggestion.csv` has 1,000 rows but 996 unique episode keys, and it overlaps execution on 172 unique keys. Kaggle version 2 declares CC BY 4.0 for the dataset, while the repository has no code license or tagged release. These checks show that paper counts, released rows, and unique evaluation units must be reported separately.

The evidence supports a narrower conclusion than benchmark promotion language might suggest: longitudinal human episodes can train and evaluate personalized mobile behaviors under this setup, and full-data SFT improves the reported metrics. It does not establish that the released subset is representative of the full paper corpus, that trajectories are intrinsically high quality, that scores are contamination-free, or that a live phone state can be reset and replayed.
