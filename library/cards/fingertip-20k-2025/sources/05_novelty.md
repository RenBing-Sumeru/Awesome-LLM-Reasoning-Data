The prior-work baseline in the paper is general mobile-agent evaluation centered on a supplied task and current UI state. Tested systems include UI-TARS-1.5-7B for execution. FingerTip 20K changes the problem formulation by making behavior longitudinal and user-conditioned: proactive suggestion must infer an intent before it is given, while execution can use profile data and retrieved earlier behavior from the same user (Paper §§3 and 5).

The new data object is the link among a self-recorded real-life intent, profile, timestamp/scenario, screenshot/XML state sequence, and human actions over one month of use. The new feedback interface is not a single automatic environment reward; it combines semantic similarity and a DeepSeek-V3 judgment for suggestion with manual terminal inspection, a path-length cutoff, and action-sequence similarity for execution. This combination makes user-specific context and mixed verification first-class audit objects.

Several components are established rather than new: Android GUI actions, screenshot and accessibility-tree observations, human demonstration collection, similarity metrics, learned judging, retrieval of examples, LoRA, Qwen-2.5-VL-7B, and live ADB execution. The title's “20K” is a rounded dataset name, not evidence of 20,000 unique tasks, and the paper's 21,437 collected episodes do not resolve to the public 20,000-row index. Scale and downstream scores are not record-level quality guarantees.

For reasoning-data research, the direction signal is that agent episodes can encode persistent user context and can be consumed both as demonstration targets and as evaluation references. Reuse must still verify which user/profile fields are necessary, whether personalization gains survive privacy-preserving ablations, how final success is adjudicated, and whether alternate valid paths are penalized. Builders must also reconcile the count/split discrepancies, obtain the missing training implementation, and pin the changing Android/app substrate before treating the release as reproducible.
