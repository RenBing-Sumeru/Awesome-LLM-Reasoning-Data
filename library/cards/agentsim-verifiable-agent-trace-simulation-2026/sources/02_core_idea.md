The principal data object consists of questions, retrieval queries, document evidence, stepwise reasoning, validator outputs, model disagreement, and human review decisions. The Agent-Trace Corpus contains more than 103,000 verifiable reasoning steps across three established information-retrieval benchmarks, with a reported 100% grounding rate for substantive answers. A useful record preserves the input, current prefix or environment state, candidate behavior, execution or evidence, feedback label, and provenance instead of only a final outcome.
