The prior baseline is text-only BrowseComp or multimodal search benchmarks with shallow hops, non-searchable evidence, or final-answer-only metrics. BrowseComp-V3 changes the object by requiring public-searchable cross-modal evidence, multi-level visual reasoning, annotated trajectories, and process scores. The quality signal is the detailed arXiv specification and reported human/model process metrics. What is not new: web search tools, short-answer success rate, and agent scaffolding. Before reuse, inspect the Hugging Face dataset revision, license, image rights, URL stability, search API dependence, trajectory fidelity, and sub-goal scoring rules.
