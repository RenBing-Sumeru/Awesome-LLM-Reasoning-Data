BrowseComp-V3 was submitted to arXiv in February 2026. It asks whether multimodal browsing agents can solve deep-search tasks whose evidence is interleaved across text and images on publicly searchable web pages. The data object is a multimodal question with images, answer, metadata, sub-goals, and annotated interaction trajectories as described in the paper. The feedback contract combines final-answer success rate with process score over expert-validated sub-goals. The dataset is recorded at https://huggingface.co/datasets/Halcyon-Zhang/BrowseComp-V3; code, evaluator revision, license, and split details still need artifact-level audit before reuse.
