U-MATH targets a gap between saturated school-level math benchmarks and the harder but narrower competition or quiz-style evaluations often used for LLM reasoning. The primary source is the arXiv paper "U-MATH: A University-Level Benchmark for Evaluating Mathematical Skills in Large Language Models" (arXiv:2412.03205, 2024), with official evaluation code and released benchmark artifacts linked from https://github.com/toloka/u-math.

The decision boundary is evaluation, not post-training data construction. The paper contributes a static benchmark surface: 1,100 unpublished open-ended university-level math problems from current US curricula, balanced across six core university subjects, with about 20% visual problems. It also introduces mu-MATH, a meta-evaluation set of 1,084 tasks derived from U-MATH problems and model solutions to test whether LLM judges can correctly grade free-form math answers.

The concrete data object is a problem record with a text or visual prompt, reference answer, model solution surface, subject metadata, and an answer-level correctness decision produced through the official judge prompt or checked in the meta-evaluation setting. Its screening relevance comes from exposing a verifier-facing benchmark for advanced math where the verifier is not a simple exact-match normalizer but an auditable LLM-judge contract.
