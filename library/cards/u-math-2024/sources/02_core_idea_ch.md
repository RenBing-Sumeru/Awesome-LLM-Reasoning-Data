一句话贡献：U-MATH 用未公开的大学课程数学开放题建立评测集，并配套 LLM judge 评分流程；mu-MATH 再反过来评估这个评分流程本身是否可靠。

核心机制分两层。第一层是提升题目分布：题目来自大学课程，答案是开放式的，并包含一部分视觉题，因此不是 GSM8K 式短文本算术，也不是纯选择题。第二层是把“判题”单独做成评估对象：mu-MATH 从 U-MATH 题目中抽样，附上多个模型生成解答，并给出人工或来源侧确认的正确性标签，用来测试 judge 模型的 F1、偏置、保守或宽松倾向、推理判据和一致性。

反馈契约是答案级正确性，但由公开的 judge prompt 执行。它应归到 benchmark / evaluation surface；验证契约是混合型：参考答案约束正确性，开放式解答的最终评分依赖 LLM judge，因此必须审计 judge 的稳定性。最接近的参照包括 MATH、GSM8K、MathVista、MATH-V，以及那些不默认模型裁判可靠、而是专门测量裁判可靠性的 meta-evaluation 工作。
