Inputs are university-level math tasks, optional visual materials, reference answers, model-generated solutions, and judge prompts. The main U-MATH pipeline curates 1,100 unpublished open-ended problems from current US curricula, balances them across six core subjects, marks text-only versus visual tasks, and releases evaluation code for running models and grading solutions.

The mu-MATH pipeline selects about one quarter of U-MATH problems, generates four candidate solutions per problem using top-performing language models, and attaches correctness labels to form 1,084 judge-evaluation tasks. The output is therefore not only a benchmark score for solvers but also a benchmark score for graders. U-MATH reports problem-solving accuracy by modality and subject; mu-MATH reports judge quality, including F1 and analyses of inconclusive judgments, conservatism, leniency, reasoning, and coherence.

The verifier is an LLM-judge protocol grounded by reference answers and meta-evaluation labels. For reproducibility, a user needs the repository revision, exact data files, prompt templates, model sampling settings, judge model version, answer extraction conventions, and whether a run uses the visual subset. The artifacts to verify are the arXiv paper, the GitHub repository, released benchmark files, prompt appendix, and any license file attached to the repository.
