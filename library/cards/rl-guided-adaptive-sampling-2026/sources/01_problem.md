Fixed-budget self-consistency spends the same amount of inference computation on an easy problem and a hard one. Adaptive baselines reduce some waste, but commonly stop with a hand-written threshold or a distributional assumption. Those rules can either keep sampling after the answer distribution has already settled or stop while a useful correction is still likely, and sequential decisions can add latency even when many candidates can be produced in parallel.

This paper asks whether the allocation itself can be learned as a sequential control problem. The target is a small controller that sees only the final answers already sampled from a fixed reasoning model, decides whether to stop or request more parallel answers, and explicitly trades final-answer quality against both the number of candidates and the number of sampling rounds.
