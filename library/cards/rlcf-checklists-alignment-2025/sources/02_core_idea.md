The paper proposes Reinforcement Learning from Checklist Feedback (RLCF). It first generates an instruction-specific checklist, evaluates candidate responses against each item, and aggregates the item-level judgments into a training reward. The authors also release WildChecklists with 51,071 records containing real-user prompts, instruction-level criteria, model responses, and labeled preference relations. The work changes the feedback object from a holistic response score to traceable atomic requirements. This supervision can support both online reinforcement learning and offline preference-based alignment, while the released prompt–checklist–response–item-feedback structure is itself a reusable data contribution.
