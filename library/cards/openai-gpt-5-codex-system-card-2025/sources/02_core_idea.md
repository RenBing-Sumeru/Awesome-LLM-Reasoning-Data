The Card's one-sentence contribution is: GPT-5-Codex makes the GPT-5 coding specialization legible through real-world SWE task families, explicit RL, code-review specialization, inherited malware safety data, and new prompt-injection data, while leaving the actual reward and records unknown.

The main layer is agent training. The report says RL targets code resembling human style and PR preferences, instruction adherence, and iterative testing (PDF p.1). The launch page says code review navigates the codebase, reasons over dependencies, and runs code and tests. These statements identify desired behavior and an episode surface, not a complete feedback contract: PR preferences do not prove pairwise records or a preference model, and running tests does not prove that tests supply all or any training reward.

The second layer is evaluation. Recent commits from popular open-source repositories are reviewed by GPT-5-Codex, and experienced software engineers judge comments for correctness and importance. Other evaluations use all 500 SWE-bench Verified tasks, established-repository refactors, human mobile-web preferences, a policy-expert malware golden set, prompt-injection attacks, Production Benchmarks, StrongReject, CTFs, and Cyber Range. These human, test, policy, and environment predicates are evidence about evaluated behavior; none is established as the training verifier.

The third layer is deployment. Cloud and local sandboxes, default network denial, workspace restrictions, approvals, configurable allowlists or denylists, citations, terminal logs, screenshots, and test reports constrain or expose product behavior. They do not identify the RL environment, training examples, or reward.

The disclosure delta is version-specific. Base GPT-5 supplies broad source classes, router signals, and safe-completion context, not this Codex task ledger. The o3/o4-mini Codex addendum already disclosed real-world coding RL and the inherited malware pipeline, plus an unexpected-state false-completion reward that this GPT-5-Codex addendum does not repeat. GPT-5-Codex adds a clearer complex-task taxonomy and code-review training plus experienced-engineer review evaluation. GPT-5.1/5.2-Codex later disclose a conflicting-edit user model, preservation reward, compaction, and internal PR hidden tests; none may be backported here.
