The filter is a proxy rather than a correctness certificate. A rationale can raise the likelihood of an observed continuation by repeating cues, summarizing earlier text, or rationalizing a known continuation after the fact. Appendix H is especially important: the authors' manual review says most retained Pile rationales describe the preceding context rather than guide future reasoning. The Pile threshold is zero and is not calibrated on labeled rationale validity.

Several published details conflict. The paper's definition of the loss difference and its retention inequality do not agree with the prose that a rationale should reduce loss; the released code instead compares conditioned and baseline token log-probabilities. The Pile length cap is described as 2,000 words, 2,000 tokens, and implemented as 2,000 characters. ECQA is 75.2 in Table 2 and the official model card but 76.2 in Table 5. These should be treated as unresolved reporting issues, not silently harmonized.

Release completeness is also unresolved. The linked HF dataset has 15,178 rows with `preceeding`, `rationale`, and `following`, no dataset card, and no license. That size does not match the reported 79K mixture and does not obviously match Table 1's implied retained GSM8K count. It lacks source IDs, filter scores, thresholds, and a manifest. The inspected GitHub revision has no LICENSE, references absent filtering/parsing scripts, and contains cluster-specific paths. The HF model's Apache-2.0 declaration does not license the dataset or code.

No broad decontamination analysis was identified, although GSM8K and ECQA training sets feed construction and their test/validation sets feed evaluation. Preventing the answer from appearing inside a generated rationale reduces one leakage channel but is not a benchmark-overlap audit. Exact reported-run hyperparameters and package revisions remain unknown.

The paper itself notes limited task and comparison coverage, limited study of data-mixture choices, no DPO experiment, and compute constraints that prevented scaling to stronger models or a corpus such as OpenWebMath. Benchmark gains therefore establish neither generality nor rationale quality.
