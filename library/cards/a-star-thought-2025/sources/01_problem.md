Long chain-of-thought can improve reasoning accuracy, but it also raises inference latency, memory use, and deployment cost. Simply prompting a model to be brief, truncating its output, or deleting locally redundant tokens can remove steps that are necessary for reaching the answer. A*-Thought therefore treats efficient reasoning as a trace-construction problem: given an existing long reasoning trajectory and its target solution, select a shorter sequence of informative spans that can still supervise a model under restricted output budgets.
