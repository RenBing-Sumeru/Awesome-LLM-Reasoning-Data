The main contribution is a solution-aware, span-level construction procedure rather than another instruction to “think less.” BIS uses both the question and target solution to identify candidate steps, while A* evaluates combinations of locally coherent spans instead of pruning each token or sentence independently. The search explicitly separates present-path quality from estimated remaining cost and records the selected path as reusable SFT data. This differs from prompt-only brevity methods and from fixed-rate compression because the retained amount is determined by a validator-guided search trajectory rather than a uniform deletion budget.
