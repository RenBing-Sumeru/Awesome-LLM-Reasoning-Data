The prior baseline is usually static screenshot QA, single-platform demos, or hard-to-reproduce GUI/OS task scripts. The change here is that Windows VM tasks, applications, browser, and scalable OS-agent evaluation becomes an explicit dataset, environment, trajectory surface, or evaluation harness.

It is a direction signal because post-training agents need state, action, observation, tool invocation, and verifiable outcomes rather than final answers alone.

What is not new is a model score by itself. Reuse must check artifact version, license, environment drift, task leakage, and evaluator stability.
