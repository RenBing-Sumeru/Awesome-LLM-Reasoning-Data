The authors evaluate frontier models on four stages. The strongest GPT-5.5 reaches about 48.31% for specification generation, 92.18% for executable code from natural language, only 13.95% for Verus proof generation given a specification, and 5.29% for end-to-end verified code. The gap shows that ordinary code correctness does not represent formal-proof ability and that proof synthesis is the dominant bottleneck. For data quality, positive tests achieve about 99.66% average line coverage, and Post2Exe identifies and leads to fixes for 60 incomplete specifications. The benchmark clearly separates stages, but results depend on the supported Verus subset, online judges, and recent proprietary models; high test coverage still does not prove complete specifications.
