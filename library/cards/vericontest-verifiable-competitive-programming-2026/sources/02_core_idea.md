The main contribution is to unify functionality, efficiency, and formal proof for competitive programming in one benchmark. It contains 690 LeetCode and 256 Codeforces problems. Each record includes a Rust/Verus specification, executable program, proof, online-judge information, positive tests, and mutation-derived negative tests. The Verus compiler and proof kernel determine formal correctness, original online judges check algorithms and complexity, and Post2Exe translates postconditions into executable checks to detect incomplete specifications. The roughly 50 GB release provides hundreds of positive cases per problem on average and about ten times as many negative cases, supporting vericoding, specification generation, proof generation, and verifier-guided RL.
