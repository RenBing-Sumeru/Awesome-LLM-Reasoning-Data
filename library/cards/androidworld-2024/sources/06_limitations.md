A success label is only as broad as the task-specific checker. Some phone tasks have multiple valid human paths, and a strict final-state predicate can miss semantic success or accept shallow state manipulation. App updates, emulator images, permissions, locale, network access, and account state can change the task. Public task descriptions and validators are contamination risks for later agents. The repository is an official Google Research artifact, but score reuse still requires version pinning because AndroidWorld is a living software environment.
