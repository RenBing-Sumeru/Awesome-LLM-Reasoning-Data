Prior work had mobile screenshots, web mini-environments, human phone-use traces, and Android wrappers, but fewer public benchmarks with dynamic app state and programmatic task validation. AndroidWorld changes the object of evaluation from a static UI label or demonstration to a runnable task instance whose parameters and state can vary. The quality signal is the official task list plus executable validators. It does not make Android emulation, accessibility trees, or multimodal prompting new; reuse should inspect whether task validators overfit a narrow UI path, whether alternate valid completions are accepted, and whether public tasks have entered model training.
