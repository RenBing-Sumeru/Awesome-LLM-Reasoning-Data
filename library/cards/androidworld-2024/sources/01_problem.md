AndroidWorld is an ICLR 2025 / arXiv v5 Google Research and Google DeepMind environment for evaluating autonomous agents on Android devices. It addresses the gap between static mobile UI benchmarks and open-ended phone use: agents need to operate apps, update device state, and satisfy task-specific predicates rather than answer a screenshot question. This Card includes it as an executable mobile-agent benchmark and environment surface, not as a training corpus. A task instance contains a natural-language instruction, an Android emulator state, one or more app states, agent actions, observations, and a programmatic success or failure condition.
