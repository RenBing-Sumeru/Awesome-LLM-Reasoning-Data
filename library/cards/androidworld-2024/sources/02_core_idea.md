The core contribution is a dynamic Android benchmark with programmatically defined setup, success, and teardown logic for tasks spanning everyday phone apps. The mechanism is to instantiate a task, let the agent interact through accessibility/UI observations and Android actions, and grade the final device or app state with task-specific validators. Compared with AITW, MiniWoB-style web tasks, static GUI grounding datasets, and narrower Android harnesses, AndroidWorld's direction label is executable real-device-style evaluation with changing task parameters and stateful app interactions.
