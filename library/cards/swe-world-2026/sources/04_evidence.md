On SWE-bench Verified, Table 2 reports resolve rates of 25.6 for the 4B SFT policy, 30.0 for 4B RL, 52.0 for 32B SFT, 55.0 for 32B RL, and 68.2 for 32B RL + TTS@8. The 32B RL number is internally inconsistent: Section 6.2 prose says 54.8, whereas the abstract, Table 2, and official repository README say 55.0. This Card preserves both values and treats 55.0 only as the table value pending reconciliation. All final benchmark correctness judgments use the SWE-bench Verified Docker harness, not SWR. (Paper Table 2; §6.2; Appendix E.)

Simulator diagnostics show material residual error. SWR-72B reports accuracy 0.770, precision 0.780, recall 0.807, and F1 0.794 against Docker-derived labels. With SWT-72B transitions, the agent resolves 60.2% versus 68.4% with Docker ground-truth transitions. On equal 5.7K SFT trajectories, Docker data yields 51.4 and SWE-World data 52.2; mixing 9.3K trajectories yields 53.8. These are author-reported results without independent replication, and the mixed-data comparison also changes data quantity. (Paper Tables 3–5.)

The paper supplies a negative result rather than only aggregate gains. On a 4K evaluation, CoT raises SWR reward accuracy from 0.578 to 0.712. Figure 2 and §7.2 show that a non-CoT SWR can reward short invalid solutions, after which optimized trajectory length collapses: direct evidence of reward hacking, not just a hypothetical risk. The result supports the value of reward reasoning and auditing, but does not prove that the simulated reward is calibrated under new repositories or adversarial policies. (Paper Table 7; Figure 2; §§7.1–7.2.)

The reported 16,550 task instances include 310,544 edited lines, 25,703 edited files, 32,819 F2P tests, and 696,895 P2P tests. Those counts document the claimed construction scale; because the task rows, 26K/21K world-model examples, and 5.7K SFT trajectories were not found as complete releases, neither benchmark scores nor model weights are evidence that the underlying corpora are independently auditable or training-ready.
