SWE-World replaces the Docker dependency inside an agent episode with a hybrid environment: deterministic filesystem navigation/editing plus a learned Software World Transition model (SWT) for execution feedback and a learned Software World Reward model (SWR) for terminal test reports and rewards. Docker is not eliminated from the evidence chain; it supplies the targets used to train SWT/SWR and the final SWE-bench Verified correctness judgments. (Paper Figure 1; §§4.1–4.2 and 6.1.)

The feedback contract is mixed. `str_replace_editor`-style navigation and edits change the sandbox deterministically. For an `execute_bash`-type action, SWT observes the task context, initial analysis, hidden gold patch, current agent patch, command, and relevant code, then predicts `stdout`, `stderr`, and `exit_code`. On submit, SWR also observes F2P/P2P tests and the final patch, generates a test report, and outputs reward 1 only when all required tests are predicted to pass. SWT can imitate likely command output but cannot observe real execution at inference; SWR can estimate terminal success but is not the benchmark oracle. Real Docker tests remain the collection labeler and final evaluator.

The construction loop also uses reverse-reasoning distillation: Qwen3-235B-A22B-Thinking writes CoT while conditioned on the context and Docker ground-truth output, and an undisclosed LLM-as-a-judge filters invalid or output-leaking rationales. This creates a second feedback boundary: the CoT may improve prediction, but it is a post-hoc teacher artifact conditioned on the answer signal rather than a faithful record of how Docker executed the command.

Relative to R2E-Gym, SWE-Gym, SWE-rebench, and Docker-backed SWE-agent training, the directional change is to learn the transition and terminal-feedback interfaces and use them for trajectory generation, SFT, RL, and test-time selection. The closest atlas comparisons are `swe-dev-2025` and `swe-mirror-2025`; SWE-World is distinguished by the explicit SWT/SWR split and by evidence that its learned reward can be hacked.
