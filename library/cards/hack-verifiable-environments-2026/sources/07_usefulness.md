An agent evaluator can wrap an executable task with a small, documented shortcut and a deterministic detector, then report both reward hacking and hack-free success under fixed prompts and budgets. The required inputs are a resettable environment, a specified exploit, and an action-level monitor; the output is an auditable failure-rate report. Use the TextArena release to benchmark prompt or model changes. Do not use it when the real failure cannot be operationalized as a detectable action, or when planted weaknesses would distort the task beyond its deployment setting.
