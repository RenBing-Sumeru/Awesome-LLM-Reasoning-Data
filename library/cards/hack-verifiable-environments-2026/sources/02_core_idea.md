The core object is a wrapped environment whose designer defines a hack set H and a deterministic predicate for each shortcut. The wrapper exposes discoverable files or actions but monitors every interaction, so exploitation is measurable rather than inferred from a trajectory. Hack-Verifiable TextArena applies this to 34 text-game environments with hidden-solution, logical-bug, prompt-reading, and prompt-editing hacks. The feedback contract records hack rate and hack-free win rate; the code is open, while the paper does not claim a separately downloadable dataset.
