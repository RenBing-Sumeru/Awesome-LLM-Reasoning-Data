RULER: What's the Real Context Size of Your Long-Context Language Models? defines an evaluation surface in long-context-diagnostics, long-context-grounding: whether model outputs or agent trajectories satisfy the task-specific feedback contract. The primary source and artifacts are paper: https://arxiv.org/abs/2404.06654; venue: https://openreview.net/forum?id=kIoBbc76Sy; openreview: https://openreview.net/forum?id=kIoBbc76Sy; code: https://github.com/NVIDIA/RULER; data: https://github.com/NVIDIA/RULER; doi: https://doi.org/10.48550/arXiv.2404.06654; the local metadata records the source as 2024 / COLM 2024 / arXiv.

The decision boundary is benchmarks_evaluation_surfaces with roles benchmark and verification contract mixed. One benchmark instance is: official records expose configurable long-context retrieval, tracing, and aggregation tasks, prompt/task metadata, a model output surface, and a score or success target. This is not a model-training recipe unless the paper separately releases training data; the card treats it as evaluation, audit. It matters for the atlas because the reusable object is an evaluation/data record with a named scorer, judge, verifier, reward, or environment predicate rather than an abstract capability claim.
