The authoritative publication is the 21-page Findings of ACL 2025 paper, pages 23938–23958, DOI `10.18653/v1/2025.findings-acl.1227`; its appendix contains the principal agent prompts, resource notes, comparison examples, and derivation-evaluation rubric. This Card also audits the official repository at commit `1d3f0743717ccec23472692eb4e13d56f833bb2d`, checked on 21 July 2026. Author names follow the PDF, which gives `Jierui Zhang` and `Kun Xie`; the ACL HTML renders those two differently.

STORM-BORN targets long natural-language mathematical derivations and proofs drawn from technical documents. The intended gap lies between short numerical word problems, whose terminal answer is easy to check but whose reasoning may be shallow, and formal theorem-proving corpora, whose proofs are machine-checkable but expressed in a proof language. The proposed object instead preserves formulas, approximations, dependencies, heuristic cues, and multi-step prose, so correctness requires source reading and mathematical judgment rather than answer-string comparison.

The final public object is much smaller and more concrete than the 2,000-pair construction pool described in the paper. `data/storm-born.jsonl` contains exactly 100 unique rows from 28 distinct source identifiers. Each row has `paper`, `question`, and `whole_label`: a coarse source name or arXiv ID, a self-contained derivation/proof question, and a long natural-language/LaTeX derivation. No row contains the original formula record, page/equation evidence, agent outputs, human decision, revision history, or quality score.

The repository also releases a random 73-row train split and 27-row test split that exactly partition the 100 questions with no question overlap. Four-option files expose `paper`, `question`, `A`–`D`, and `ground-truth`: one file covers all 100 questions and two byte-identical files cover the 27-question test subset. The advertised blank-format artifact currently contains only `[]`. The train and test files are not source-document-disjoint: 17 of the test set's 18 source identifiers also appear in train.

This is a direct `data_construction_open_release_recipes` case because the paper specifies a document filter, six specialized agents, source-answer retrieval, context enrichment, expert selection, derived evaluation formats, and downstream SFT studies. Its canonical `L3_summary_ready`/`partial` state must remain. The 2,000 generated pool, top-500/fullset ablation data, rejected items, paper-selection manifest, exact human protocol, per-row evidence, and valid release licensing are absent, so the current artifact supports bounded reuse rather than a fully auditable reproduction.
