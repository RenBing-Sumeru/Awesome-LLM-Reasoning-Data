WebSailor’s central idea is to teach difficult web navigation in two stages: first reconstruct compact reasoning around successful expert actions, then use online agentic RL to move beyond imitation. SailorFog-QA raises task uncertainty by sampling non-linear subgraphs from web-grounded random-walk graphs and obscuring exact names, dates, and quantities. The trace pipeline then separates the expert’s useful behavior from its stylistic reasoning: actions and observations are retained, while a second LLM writes a short justification for each chosen action (Paper §3).

The data object is a full ReAct episode: question and answer, alternating `think`, `tool_call`, and `tool_response` segments, and a terminal `answer`. Search returns ten titles, snippets, and URLs per query. Visit retrieves pages through Jina and asks Qwen-2.5-72B to summarize information relevant to a goal. Observation tokens are visible in context but masked from both the supervised and policy losses (Paper §§2, 4; Appendix A.1–A.3).

The feedback contract is mixed. DUPO assigns `0.1 * R_format + 0.9 * R_answer`: the format component checks tags and ReAct ordering programmatically, while an undisclosed LLM judge decides answer correctness. This contract can observe serialization compliance and terminal equivalence, but it cannot directly establish that intermediate web claims are supported, that the search path is minimal, or that reconstructed thoughts faithfully explain the expert’s causal decision process.

Relative to WebDancer’s trajectory-centric RFT/RL recipe, WebSailor changes the task source toward deliberately high-uncertainty graphs, reconstructs concise thoughts from successful action–observation traces, and replaces slower batch refilling with DUPO’s in-batch duplication of nonzero-variance groups. Relative to WebSailor-V2, this paper is the first-stage pipeline: later work should not be used to backfill undisclosed WebSailor-v1 data or reward details.
