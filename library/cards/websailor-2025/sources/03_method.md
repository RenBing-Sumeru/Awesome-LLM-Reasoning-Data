The reconstructable pipeline is:

1. **Task source.** Query Wikidata’s SPARQL service for rare entities, use Search and Visit to collect features and related entities, and expand a graph by a probabilistic random walk until a predefined edge count. The generator and graph-size settings are undisclosed (Appendix A.2).
2. **QA synthesis.** Sample subgraphs, formulate a question and reference answer, then obfuscate precise facts into vague periods, partial names, or qualitative quantities. No total QA count, split, deduplication rule, or decontamination test is reported (Paper §3.1).
3. **Expert rollout.** An undisclosed open-source LRM produces a complete ReAct solution. QwQ-32B is mentioned as an example, but the exact teacher revision, prompt, temperature, rollout count, and success yield are unknown (Paper §3.2).
4. **Thought reconstruction.** Discard the expert’s native thoughts but keep each successful action–observation pair. A separate undisclosed instruction-following LLM receives prior history, the chosen action, and following observation and writes a concise thought for that step.
5. **RFT filtering.** Keep only trajectories with a correct final answer, fewer than 32k tokens, and more than five tool calls. Observation tokens are masked from the loss. The paper describes just over 2,000 retained examples, not an exact manifest (Paper §4.1).
6. **DUPO rollout and reward.** Sample eight rollouts per QA. Remove all-eight-correct cases before training; during training remove zero-standard-deviation groups and duplicate eligible cases from the same batch. Use group-relative advantages, token-level policy gradients, asymmetric clipping, and the mixed `0.1 format + 0.9 answer` reward (Paper §4.2).
7. **Training outputs.** RFT and RL are run on Qwen-2.5 3B, 7B, 32B, and 72B. Megatron handles SFT; verl handles RL. Appendix A.4 reports the main optimizer settings, but base checkpoints, seeds, dependency commits, judge configuration, and service versions are not pinned.

Reproduction also requires freezing the live environment: Qwen-Agent code, Google Search behavior, Jina retrieval, Qwen-2.5-72B summarization, tool schemas, API keys, retry policy, page snapshots, and the 30-tool-call cap. The public repository supplies inference/evaluation code and models at 3B/7B/32B, but not synthesis code, the 2k+ RFT records, complete DUPO rollouts, or a 72B checkpoint.
