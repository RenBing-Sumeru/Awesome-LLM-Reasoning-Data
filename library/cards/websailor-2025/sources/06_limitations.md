- **Success-only supervision.** RFT discards incorrect answers, trajectories over 32k tokens, and trajectories with at most five tool calls. This creates survivor, length, and complexity bias and removes precisely the failures, recoveries, and near misses needed for error analysis.
- **Reconstructed-thought faithfulness.** A second LLM writes thoughts after seeing the expert action and its following observation. Those rationales may be plausible post-hoc explanations rather than the reason the expert chose the action. The reconstruction model, prompt, decoding settings, and human checks are unknown.
- **Judge uncertainty.** The answer judge is undisclosed. SailorFog-QA can have non-unique answers according to §5.3, so a single reference and learned equivalence judgment can create false negatives or false positives. The 0.9 answer weight also dominates the programmatic format term.
- **Environment drift.** Google results, web pages, Jina retrieval, and Qwen-2.5-72B summaries can change or fail. The release has no timestamped page corpus, response cache, API version, retry log, or deterministic replay fixture; historical trajectories therefore cannot be regenerated exactly.
- **Reward blind spots.** Terminal correctness does not verify citation support, intermediate factuality, efficient exploration, or causal faithfulness of thoughts. An agent may obtain reward from a correct answer despite unsupported intermediate claims, and the format checker can be gamed by syntactically valid but low-quality ReAct structure.
- **Sampling blind spots.** DUPO removes all-correct and all-incorrect groups. This improves variance for optimization but supplies no gradient for uniformly failed tasks and changes the effective task distribution toward intermediate difficulty.
- **Reported method limits.** The authors explicitly identify the 32k filter, context-limit failures, over-thinking on simple questions, and a 50-step synchronous RL limit as constraints (Paper §5.4).
- **Release gap.** The official repository exposes only 20 QA examples, not the 2k+ successful RFT traces, any failed/rejected traces, synthesis code, per-record lineage, split, or reward logs. The README still promises trajectory release; planned availability must not be treated as actual availability.
- **Rights and privacy.** The paper is CC0, repository MIT, and released model pages Apache-2.0, but the QA sample has no separate dataset card/license. Web-derived provenance, redistribution rights, personal-data filtering, consent, and takedown procedures are undisclosed.
- **Generalization and evidence.** Evaluation covers four information-seeking benchmarks under one tool framework. No multi-seed training variance, judge calibration, contamination audit, robust web perturbation, or independent reproduction establishes that the recipe transfers to other environments.
