**Inputs.** The released command starts from \`datasets/math14k.jsonl\` and \`deepseek-ai/DeepSeek-R1-Distill-Qwen-7B\`; reported students are 7B and 1.5B DeepSeek-R1-Distill-Qwen. Each input has an instruction and ground-truth answer. The template separates the \`think\` and \`answer\` fields (Appendix A.1; repository Step 1).

**Pipeline.** (1) Sample 64 completions at temperature 0.9, default 8,192 new tokens; extract answer, run \`merged_verify\`, and store equality/text/token length. (2) Sort correct traces; with \`q=alpha*(1-p)\`, alpha=.2, select leading correct traces and pair each with a longer incorrect trace, up to M=64. (3) For each chosen step, sample 64 rewrites at temperature 1.0; estimate local KL using a one-trajectory 512-token window and retain the shortest below .005. (4) substitute eligible rewrites into pairs (paper §3, Appendices A.1/B; repository Steps 1-5).

**Training.** README filenames are \`step1_response.jsonl\`, \`dpo_pair.jsonl\`, \`rewrite.jsonl\`, \`rewrite_kl.jsonl\`, and a rewritten-pair file; they are named outputs, not verified releases. Full-parameter LLaMA-Factory DPO uses \`sigmoid_l2s_log\`, .5 DPO-L/.5 SFT, lambda=1, Adam, lr 5e-6, batch 128, 9,000-token context, and 8 Tesla A100 GPUs (paper §3.3, §4.1, Appendix A.2; README Step 6).

**Reproduction boundary.** Pin checkpoint, tokenizer/template, commit, SGLang/Ray and LLaMA-Factory versions, comparator, KL computation, source rows and samples. No paper-matched generated pairs, seed/retry logs, retention count, split manifest, lineage ledger, or construction decontamination report was verified.
