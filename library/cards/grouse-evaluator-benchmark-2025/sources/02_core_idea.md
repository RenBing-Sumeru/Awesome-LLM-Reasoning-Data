GroUSE is a 144-unit-test benchmark built from 16 grounded-QA situations and seven generator failure modes. A test supplies a question, documents, an answer, and expected score or acceptance behavior, so the judge’s output can be checked against a precise oracle. The authors also propose a GPT-4 evaluation pipeline spanning the relevant criteria and distil GPT-4 reasoning traces into Llama-3. The benchmark is an evaluation dataset and audit contract, not a model-training corpus; code and materials are released through the official repository.
