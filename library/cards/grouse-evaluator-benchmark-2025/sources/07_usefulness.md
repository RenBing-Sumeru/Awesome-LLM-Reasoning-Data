A RAG-team evaluator can run a candidate judge on GroUSE before using it for automated acceptance, then inspect per-criterion failures rather than only an aggregate correlation. The required inputs are a judge prompt and the benchmark examples; the output is a calibrated failure-detection report and a shortlist of rubric gaps. A model developer can adapt the unit-test pattern to its own documents and abstention policy. Do not use the benchmark as a substitute for task-specific human audits when the knowledge base or safety policy differs substantially.
