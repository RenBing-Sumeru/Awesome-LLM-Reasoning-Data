MedQA 要回答的问题是：模型能否解医学考试中的开放域医学问答，尤其是需要医学知识和临床推理的选择题。主要论文是 arXiv:2009.13081，提交于 2020 年 9 月；官方代码与数据入口是 GitHub 的 jind11/MedQA。

收录边界是 benchmark/evaluation surface，不是临床决策系统，也不是可直接用于病人诊疗的标签源。一个样本是医学考试题、多个选项和官方答案；部分 release 文件还包含解释或教材/上下文资源。反馈契约是与答案 key 的精确选择题 accuracy；复用时要固定语言子集、split 文件、prompt 格式、scorer 和污染时间点。
