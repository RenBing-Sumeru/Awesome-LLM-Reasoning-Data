The reconstructable pipeline is:

1. **Graph collection.** Begin with seed entities, use web tools to find related entities and facts, deliberately connect existing nodes to make components denser and cyclic, and internally preserve discovery queries, source URLs, and entity statistics. Seed lists, crawl dates, source manifests, and generator models are undisclosed (Paper §3.1).
2. **Subgraph and QA synthesis.** Run random walks to extract connected subgraphs, use Weisfeiler-Leman to check non-isomorphism, balance focus across orbit-node roles, then generate questions with semantic ambiguity, distractors, or structural constraints. The final paper reports more than 30,000 instruction-tuning pairs; exact count, schema, split, duplicates, and record-level provenance are unknown (§§3.2–3.4).
3. **SFT trajectory collection.** Unspecified high-performing open-source models solve generated tasks. Rejection sampling keeps successful trajectories, but candidate count, acceptance rule, retry budget, decoding, and failure retention are not reported. Qwen3-30B-A3B-Thinking-2507 receives the cold-start SFT (§4.1).
4. **Dual environments.** Adapt the generator to an offline Wikipedia corpus for simulation train/test tasks and rapid algorithm iteration. For final live-web training, route multiple search providers, page parsers, and Python through a scheduling layer with QPS limits, caching, retries, degradation, and backups (§4.2).
5. **On-policy RL.** Generate current-policy episode groups and optimize a tailored GRPO objective with token-level policy gradients and leave-one-out advantages. Selectively omit some negative trajectories, including overlength runs without Final Answer; do not use dynamic sampling. `R_i`, group size, clipping values, and the complete exclusion rule are unknown (§4.2).
6. **Training configuration.** Megatron SFT uses batch 64, learning rate 5e-6 to 1e-10, cosine decay, and weight decay 0.1. rLLM RL uses batch 128, learning rate 1e-6, temperature 1.0, and top-p 1.0. Inference allows 128k context and up to 100 ReAct rounds (Appendix B; §5.4).

Reproduction additionally requires the exact SailorFog-QA/V2/IterBench stage mixture, graph and prompt lineage, reward implementation, Wikipedia snapshot, live provider and parser versions, cache and retry records, sandbox image, dependency commits, seeds, and all retained/excluded rollouts. None are released by the V2 project directory.
