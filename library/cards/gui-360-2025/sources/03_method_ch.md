可重建的管线如下：

1. **来源与任务实例化。** 从 application help/tutorial、online forum、Q&A/community site 与 search query 中收集 Word、Excel、PowerPoint 的 prototypical query。使用未披露的 LLM，把每条 query 匹配到 66 个手工实例化 Office template 之一，再改写为具体可执行 request。Table 2 给出 Word 27,903、Excel 28,552、PowerPoint 21,698 条 raw query，合计 78,153；但 §3.1 写的是 79,075 个 candidate，因此输入计数尚未对齐。
2. **过滤任务可执行性。** 未披露的 LLM 把 task 标为 `NORMAL`、`NONEXEC`、`CROSSAPP`、`VERCTRL`、`TPLMISS` 或 `INVALID`，只保留 `NORMAL`。论文称最终保留 59,553 个 candidate，但 prompt、模型版本、threshold、人工 adjudication、deduplication 与逐阶段记录均未发布。
3. **执行 episode。** 在 15 台 Windows 11 VM 上运行任务，每台分配 4 个 CPU core。TrajAgent 分解 request、调度 execution agent、捕获 screenshot 与 UI Automation/accessibility state，选择 mouse/keyboard GUI action 或通过 MCP 暴露的 Word/Excel/PowerPoint API，并记录 observation、thought、action argument/coordinate 和 status，直至结束。GPT-4o 执行第一轮，GPT-4.1 重试失败任务；二者报告的 temperature 均为 0.0。
4. **判断与清洗。** GPT-4.1 驱动的 EvaAgent 检查完整 episode 和 final application state，给出 reason、evidence、sub-score 与 completion decision。只有满足全部未披露 criteria 的成功且可执行 trajectory 才进入主 corpus；缺少已执行 action、screenshot 或 essential metadata 的 step 会被删除。失败尝试独立保存在 HF `fail/` tree，但 failure taxonomy、timeout/abort policy、attempt-to-task mapping 与 sanitizer drop log 均为 unknown。
5. **切分与转换。** 成功轨迹按 trajectory 做 80/20 切分：train 为 13,750 条 trajectory、105,368 个 step；GUI-360-Bench/test 为 3,439 条 trajectory、26,284 个 step。三类 benchmark task 共用该 partition。随后把日志转换成四个 SFT-ready directory：grounding、screen parsing、action prediction，以及带 accessibility context 的 action prediction。
6. **训练与评测。** 论文以 Qwen2.5-VL-7B 为主要 SFT/action-prediction 实验模型，也报告 UI-TARS-1.5-7B 的 SFT grounding variant。processed record 分别提供 coordinate、structured control 和 structured next-action target。静态 evaluator 计算 point-in-box grounding、IoU/text parsing metric 与 function/argument/status matching；它们不 replay action，也不提供 executable terminal reward。

论文报告 SFT 及其所称 RL 实验均使用 4 张 NVIDIA A100 40GB、FP16、gradient accumulation、checkpointing，并在 `1e-5`、`5e-6`、`1e-6` 中搜索 learning rate。optimizer、batch size、epoch、scheduler、seed、每次运行选定的 learning rate、checkpoint mapping，以及所有 RL algorithm/reward/rollout 细节均为 unknown。复现时必须固定 arXiv version、GitHub commit 与 HF file；而 Windows/Office/MCP 版本、VM image、locale/display、reset rule、TrajAgent/EvaAgent implementation 与 prompt、terminal checker、task/split ID 和 timeout/retry manifest 仍未发布。
