The official project page reports 120 tasks across Ubuntu and Android and describes cross-environment support, graph evaluators, and task generation. The arXiv v4 abstract reports the best single-agent GPT-4o completion ratio as 38.01% on the benchmark. The repository exposes `crab-benchmark-v0`, documentation, examples, and install instructions. Instance-level evidence is the graph evaluator's node outcomes over an episode trace, not the leaderboard number alone. Evidence is bounded by benchmark-v0, evaluator graph semantics, communication setting, model version, GUI/device state, and dependency versions.
