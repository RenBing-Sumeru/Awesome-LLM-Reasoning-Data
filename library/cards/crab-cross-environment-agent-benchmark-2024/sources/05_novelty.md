The prior baseline is single-environment GUI, web, desktop, or mobile evaluation, often with coarse final success. CRAB changes the evaluation object to cross-environment workflows and introduces graph evaluators as reusable structured predicates. The direction signal is multi-device, multimodal agent benchmarking with finer-grained success decomposition. The quality signal is public code, task dataset, docs, demos, and a benchmark framework rather than a closed leaderboard. Python action decorators, GUI automation, and completion ratio are not new by themselves. Reuse requires auditing task licenses, `licenses/LICENSE`, benchmark-v0 version, evaluator graph fidelity, device state, and public-trace contamination.
