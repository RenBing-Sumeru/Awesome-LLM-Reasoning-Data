CRAB contributes a Python-centric framework for building multi-environment agent benchmarks, plus CRAB Benchmark-v0. The official page states Benchmark-v0 has 120 tasks across Ubuntu and Android, tested with multiple MLMs and communication settings; the arXiv v4 abstract reports four advanced MLMs and a best single-agent GPT-4o completion ratio of 38.01%. The core mechanism is graph-based fine-grained evaluation: task success is decomposed into evaluator nodes rather than only a final textual answer. Closest comparisons are single-environment GUI/OS/mobile benchmarks. The direction label is cross-environment agent evaluation with structured predicates.
