Primary sources: arXiv:2407.01511, first submitted 2024-07-01 and revised to v4 on 2025-07-20, plus the CRAB project page and CAMEL-AI repository. CRAB asks how to evaluate multimodal agents that must act across more than one GUI environment instead of a single website, desktop, or phone task. The evaluation surface is an instruction-driven episode over environment state, screenshots/observations, actions, and graph-evaluator predicates. It belongs in the atlas as a cross-environment agent benchmark and framework, not as a reward-model dataset. Evidence is bounded by CRAB Benchmark-v0, runtime setup, task/evaluator graph version, and agent communication setting.
