Success is only as faithful as the graph evaluator and configured environment state. GUI tasks can drift with app versions, OS settings, emulator images, network state, screen resolution, and API provider behavior. A graph node can certify observable progress without proving the user's broader intent. Public tasks and traces can contaminate future agent training. The repository has a `licenses/` directory rather than a root license file; downstream users should verify code, docs, benchmark data, and any third-party app assets separately.
