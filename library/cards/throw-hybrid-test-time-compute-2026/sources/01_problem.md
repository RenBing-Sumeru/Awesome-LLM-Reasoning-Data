Best-of-N sampling is highly parallel but completes every trajectory, including ones that already look unpromising. Process-reward-guided beam search can focus on stronger partial chains, but repeatedly invoking a reward model creates sequential overhead and poor batch-1 latency. Applying either method uniformly ignores that some prompts need little deliberation while others need selective refinement.

The paper asks how a test-time system can decide early whether to stop wasting branches or invest more search in a difficult question. The decision must be made from incomplete traces, not from an oracle difficulty label, and it must account for both policy-model decoding and process-reward scoring. The desired procedure should retain sampling diversity where it helps, but reserve expensive stepwise expansion for cases where short initial reasoning provides evidence that it is justified.
