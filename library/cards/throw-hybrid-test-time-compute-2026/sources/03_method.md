Stage I generates partial traces of 350 tokens, scores each branch with Qwen2.5-Math-PRM-7B, and calculates the fraction that fall below a threshold. A second threshold classifies the query as easy or hard. For easy cases, only the top K branches survive. For hard cases, top branches are expanded by a configured multiplier. The authors give a compute analysis showing savings whenever the total second-stage branches remain below the original sample count, with further savings from fewer repeated PRM calls than beam search.

The main experiments use Qwen2.5 1.5B and 3B instruction models on one A100 GPU, with maximum output length 2,048 and temperature 0.7. MATH500, AMC23, and AIME24 are evaluated against Best-of-N and PRM beam search at 8, 16, and 32 candidates. Substituting a Llama PRM and a Llama policy model tests whether the result depends on the particular Qwen model pair, while ablations measure the difficulty indicator and random rather than informed branch selection.
