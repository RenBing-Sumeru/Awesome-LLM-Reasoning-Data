# 问题

大学层级的科学题库常有最终答案，却没有可复用的推导，而逐题编写专家过程又代价很高。SciInstruct 汇集科学、数学和 Lean 证明问题，通过答案感知生成、反思与质量过滤，为缺少过程的问题补充分步解答。

论文的判断边界是科学推理记录的生成与筛选，而不是科学预训练或只发布模型：序列化的问题、分步回答和学科标签直接进入 SFT，已知答案、GPT-4 结果判断与学习分类器提供反馈。
