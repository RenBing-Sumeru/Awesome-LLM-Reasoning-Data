# 方法

1. **汇集带答案的问题。**输入来自教材、教学材料、公开问答、习题集和 LeanDojo。处理过程规范物理、化学、数学与定理证明条目，并在有利于求解时把部分中文题译成英文。输出是 257,143 个原始问题或已有证明指令。检查/停止规则要求每条都有问题、答案/解答目标和学科；论文没有公开逐条来源标识。
2. **生成并反思缺失过程。**输入是问题、参考答案和 GPT-4-0613。处理过程先采样分步解答并判断结果，再让同一模型定位并修复错误；若第二阶段仍失败，第三阶段把真实答案加入提示。输出是答案一致的分步轨迹。检查/停止规则只保留判断正确的结果；图示的 42,497 个问题依次获得 19,824、5,458 和 7,687 条正确解答，共 32,969 条。
3. **过滤低质量指令。**输入是已接受/源解答和模型生成候选。处理过程把源正例与 ChatGLM2、GPT-3.5、GPT-4 的负例或判断样本合并，抽取 ChatGLM3-6B-Base 特征，训练输出 -1 到 1 分数的分类器。输出是排序后的指令及最终 254,051 条 SciInstruct 混合。检查/停止规则在过滤消融中剔除最低十分之一；最终答案正确仍不能证明每一步正确。
4. **训练并测试消费模型。**输入是聊天格式的 SciInstruct，以及 ChatGLM3 6B/32B、Llama3-8B-Instruct 或 Mistral-7B MetaMath。处理过程使用 Transformers 与 DeepSpeed 做两轮 SFT，ChatGLM 学习率为 3e-6。输出涵盖科学、数学、通用语言、混合、规模和 pass@k 结果。检查/停止规则以任务准确率或代码 pass@1 判定，并用逐域删除与数据比例实验追踪数据作用。

**复现要点：**应核验 NeurIPS 论文与数据说明、三个 CC BY 4.0 文件、逐行 `content/summary/subject` 结构、提示、反思数量、分类器组成和训练脚本。复建还需固定源快照、OCR、翻译、GPT 版本、采样和判断提示、分类阈值及基准切分；论文没有披露温度、大多数采样次数、随机种子、完整 token 成本和逐条来源。
