DSBench's contribution is a realistic benchmark for data-science agents that combines long contexts, multimodal task backgrounds, large files, multi-table structures, and end-to-end modeling tasks. The core mechanism is to expose agents to full task instructions and data artifacts, collect their produced answers or submissions, and score them with task-specific evaluators.

Compared with DS-1000-style code completion or small tabular QA, DSBench changes the evaluation surface to agentic analysis and modeling over external files. The feedback contract is mixed: data-analysis evaluation uses scripts that call an answer-computation/judging step, while data-modeling evaluation computes competition metrics such as accuracy for each competition. Direction label: realistic data-science agent benchmark.
