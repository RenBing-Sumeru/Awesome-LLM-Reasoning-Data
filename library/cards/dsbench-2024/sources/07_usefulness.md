Use DSBench as a schema for data-science-agent evaluation: preserve task source, task type, instruction, multimodal/table background, data-file manifest, agent scaffold, generated files, answer/submission, runtime, cost, judge version, metric script, and final score.

For atlas work, DSBench is useful for separating executable workflow benchmarks from smaller code-completion tests. It also provides a concrete example where evaluation combines human-style answer judging and competition-style programmatic metrics.
