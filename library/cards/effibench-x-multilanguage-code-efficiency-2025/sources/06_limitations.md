1. **Machine dependence:** Runtime and memory depend on CPU, OS, compiler, and JIT, so numbers from different machines are not directly comparable.

2. **Contest bias:** Tasks emphasize algorithmic complexity and omit repository optimization, services, GPUs, and maintainability.
