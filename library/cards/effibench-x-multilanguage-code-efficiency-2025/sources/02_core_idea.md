EffiBench-X contains 623 competitive-programming problems with 100 tests each across Python, C++, Java, JavaScript, Ruby, and Go, retaining human expert implementations as normalized baselines. The executor first compiles or runs candidates in a sandbox and checks every output. Only functionally correct programs enter repeated performance measurement, producing relative time and memory efficiency. Records include problems, tests, language templates, expert solutions, and execution assets for optimization benchmarks, best-of-N, and efficiency rewards.
