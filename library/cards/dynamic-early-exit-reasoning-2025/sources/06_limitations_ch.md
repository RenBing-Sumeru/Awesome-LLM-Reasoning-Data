核心假设是试答 token 概率能够反映答案正确性。该假设可能在分布迁移、持续低置信或过度自信的模型，以及长结构化代码答案上失效。Qwen3 需要实现特定修改，直接说明同一聚合方法与退出判定不能原样迁移。DEER-PRo 能降低 prompt 离散，但不会产生独立 ground truth。

Marker 监视依赖英语与模型，其他语言必须重新寻找等价转折 token。熵峰表示模型对下一 token 不确定，不一定对应语义推理边界。自信但错误的前缀可能过早退出，正确但低置信的前缀则可能浪费算力。截断还可能使可见 rationale 不完整，或与返回答案不忠实。

试答分支会增加计算、延迟与 KV-cache 开销，代码任务尤其明显。Branch-parallel acceleration 改变调度和显存行为，但官方尚未发布其代码。主要实验通常使用 greedy decoding 与 16k 上限；对随机采样、其他 token 预算、闭源模型、工具使用或开放式输出的行为仍未充分建立。

目前没有版本化决策轨迹数据集。原始前缀、全部候选事件、被拒试答、token 概率、阈值、分支时序、失败、seed、精确运行清单与逐样本退出日志都没有稳定发布；代码也没有 tagged release。Benchmark 准确率和压缩率不能替代校准、回放、污染或轨迹忠实性审计。
