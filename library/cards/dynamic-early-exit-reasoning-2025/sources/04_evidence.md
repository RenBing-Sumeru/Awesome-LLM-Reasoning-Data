Across the paper's evaluated model-task combinations, DEER changes both generated-token count and final-answer accuracy. The final ICLR version reports aggregate length reductions of 19.1%-80.1% and accuracy changes of +0.3 to +5.0 points; main-table comparisons also show that DEER-PRo can trade a small amount of extra generation for more robust accuracy on some smaller models. Threshold ablations show that a low threshold can produce premature incorrect exits, while an overly high threshold exits late. Latency experiments distinguish token reduction from wall-clock gains and report additional benefit from the paper's branch-parallel design.

These results support studying confidence-gated early exit under the reported models, prompts, and evaluators. They do not show that the confidence is calibrated on each domain, that the chosen prefix contains faithful reasoning, or that raw decision traces are reusable data. The released repository is narrower than the paper: mathematical Hugging Face/vLLM code is available under MIT, while the README still marks code-generation and branch-parallel code as forthcoming and provides no rollout release. Benchmark gains therefore cannot be used as proof of trace quality or artifact completeness.
