在论文评估的模型—任务组合中，DEER 同时改变生成 token 数与最终答案准确率。ICLR 最终版本报告总体长度降低 19.1%-80.1%，准确率变化为 +0.3 到 +5.0 个百分点；主表还显示，在部分小模型上，DEER-PRo 会用少量额外生成换取更稳健的准确率。阈值消融表明，过低阈值会产生错误早退，过高阈值则退出过晚。延迟实验区分 token 减少与实际 wall-clock 收益，并报告论文所述 branch-parallel 设计带来的额外收益。

这些结果支持在所报告模型、prompt 与 evaluator 下研究置信门控早退，但不能证明置信度在每个领域都已校准，也不能证明所选前缀包含忠实推理或原始决策轨迹可作为数据复用。公开仓库的范围小于论文：数学任务的 Hugging Face/vLLM 代码采用 MIT 发布，而 README 仍把代码生成与 branch-parallel 代码标为待发布，也没有 rollout release。因此，benchmark 提升不能作为轨迹质量或 artifact 完整性的证据。
