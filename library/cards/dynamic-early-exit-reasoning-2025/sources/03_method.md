At generation time, marker-based DEER watches action-transition tokens. Entropy-based DEER instead treats blank-line-delimited reasoning steps as units, measures the entropy of the next step's initial token, and uses values above the reported 0.672 threshold as candidates. At each candidate, the current prefix is forked. The inducing branch uses a final-answer cue and extracts a boxed answer, while the original branch is retained so decoding can continue after a low-confidence trial. The reported default confidence threshold is 0.95; the paper studies 0.9-0.97, but also notes that some models with systematically low confidence require a lower threshold.

The paper evaluates 11 reasoning models across GSM8K, MATH-500, AMC 2023, AIME 2024, AIME 2025, OlympiadBench, GPQA Diamond, HumanEval, BigCodeBench, and LiveCodeBench. Main correctness runs use zero-shot CoT, greedy decoding, one sample, rule-based answer checks or Pass@1, and a 16,384-token maximum. AMC/AIME results use repeated rounds because of small sample counts. Supplementary Qwen3 experiments also test the recommended 32,768-token, top-p 0.95, temperature 0.6 configuration. These are evaluation settings, not a released trace schema.

The official MIT repository provides Hugging Face Transformers and vLLM implementations for mathematical reasoning and rule-based evaluation on seven benchmarks. Its Qwen3 path changes confidence aggregation and additionally requires the trial branch to generate the closing think tag before exit. The repository states that code-generation support and Branch-Parallel Decoding Acceleration are still coming soon, has no tagged release, and does not publish a versioned corpus of CoTs, candidate transitions, trial branches, confidence sequences, or exit decisions.
