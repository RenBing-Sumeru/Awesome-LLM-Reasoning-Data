Long-chain reasoning can continue after a model has accumulated enough information to answer. The additional tokens increase latency and memory use, and later reasoning may overturn a correct intermediate result. Static token budgets cannot place the cutoff per example: easy and difficult problems, or even different reasoning paths for the same problem, can reach a sufficient prefix at different points.

Dynamic Early Exit in Reasoning Models asks whether the model can identify such a point online without extra training. For this atlas, the relevant object is not a new training dataset. It is an inference-time decision trace containing the original prompt, current CoT prefix, detected transition event, induced trial-answer branch, token probabilities, aggregated self-confidence, exit-or-continue action, final answer, and external benchmark outcome. The benchmark outcome evaluates the controller; it is not a quality label for every prefix.
