CodeUltraFeedback releases 10,000 coding instructions, each paired with four responses drawn from a pool of fourteen LLMs. GPT-3.5 judges every response against one of five coding preferences and produces both a rating and textual feedback. A record therefore preserves an instruction, the preference being judged, candidate-model identities, four responses, and four annotations.

Its feedback contract is LLM-as-a-judge, not direct human preference. The resource supports learning relative coding preferences, reward modeling, and audit of judge rationales. A rating is meaningful only with the instruction and the named preference; it is not a general score for code. This explicit multi-preference object distinguishes the dataset from a collection of solutions with a single correctness label.
