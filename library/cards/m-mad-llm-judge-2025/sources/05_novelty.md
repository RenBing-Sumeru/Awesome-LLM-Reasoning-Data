Earlier LLM judging typically uses one prompt and one model decision. M-MAD changes the decision granularity: MQM criteria are split before agents debate, then a separate agent synthesizes them. Multi-agent debate alone is not new; the contribution is its dimension-conditioned integration for MT evaluation.
Relative to GEMBA-MQM and EAPrompt, which also use MQM prompting, it does not merely place more labels into one generation. It decouples dimensions first, preserves conflicting stances in debate, and only then converts evidence into a weighted score; the changed object is where evidence is aggregated.
