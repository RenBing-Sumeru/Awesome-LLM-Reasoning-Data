M-MAD decomposes MQM-inspired criteria into dimensions, lets judge agents debate within each dimension, and asks a final agent to synthesize the verdict. The released repository contains prompts, WMT-23 inputs, annotated outputs, and meta-evaluation materials.
Its evaluation object is a source, translation, dimension-level error spans and severities, debate viewpoints, and final score—not preference-training data. The repository uses WMT-23 Metrics Shared Task inputs and preserves stage prompts and outputs, enabling a reader to trace why a total score was produced.
It does not train a new reward model: each stage calls an existing LLM and uses MQM error category and severity as an explicit contract. It is therefore an evaluation recipe, not general supervision data inferred from the reported correlations.
