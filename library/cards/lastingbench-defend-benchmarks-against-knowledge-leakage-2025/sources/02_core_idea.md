LastingBench turns benchmark contamination from a detection-only problem into a repair problem. It treats a QA item as leaked when a model can answer without its context, fails after an equivalent rephrasing, or persists with the old answer after a contradictory question. For a leaked item, a strong reasoner first answers a paraphrased question and exposes a reasoning trace; that trace, question, and answer form a retrieval query for the smallest context passages sufficient to justify the answer. The method then generates several plausible counterfactual rewrites of only those critical passages, changing the relevant fact while preserving the original question’s reasoning structure. It selects the rewrite that most reduces reliance on the model’s prior answer, measured by conditional perplexity, and merges it back into the long context with the new gold answer. The result is a defended version of the same task: success should require reading the altered evidence rather than recalling the old benchmark fact, so an established QA benchmark can remain useful after leakage is discovered.
