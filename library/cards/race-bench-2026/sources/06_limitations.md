No official code, data, project, container image, evaluator, judge prompt, or trajectory URL was verified. The paper describes a rich instance object and Docker workflow, but independent users cannot currently inspect the record schema, source lineage, FTP/PTP commands, OCI digests, dependencies, agent revisions, evaluator outputs, or correction history. Methodological reset to a base commit is not equivalent to public deterministic replay.

There is no train/dev/test split or decontamination protocol. Lite is an outcome-matched subset selected using results from three agents on the full 528 instances, not an independent holdout. Tasks originate from public GitHub issues/PRs in the same 12 repository families as SWE-bench; no temporal cutoff, pretraining-exposure audit, or issue/commit/patch/test overlap analysis is reported.

Reasoning assessment has equifinality risk. One gold implementation and one constructed reasoning reference cannot enumerate all correct solutions. Exact alignment may penalize alternative files or decompositions, while LLM semantic matching may vary with prompt and model revision. Trace summarization and patch back-inference also mix contemporaneous reasoning with post-hoc reconstruction.

Successful and failed runs are analyzed only in aggregate. Without a public record-level corpus, it is unknown whether all patches, traces, test logs, judge outputs, timeouts, crashes, and apply failures were retained. Single-attempt, temperature-zero evaluation does not estimate environment or API variance.

License, privacy, and security remain unknown for a released benchmark object. The paper's arXiv license does not license GitHub issue/PR text, upstream code, patches/tests, synthetic annotations, traces, or containers. No PII/consent/takedown policy is reported. Docker isolation is described, but network access, secrets, Linux capabilities, dependency pinning, malicious setup scripts, resource limits, supply-chain defense, and host-escape protection are not specified.
