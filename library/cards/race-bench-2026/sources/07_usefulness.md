For `environment_agent_trajectory_data`, RACE-bench is a useful specification for evaluating code-agent episodes at both terminal and intermediate levels. It links an issue-derived task, base-commit container, tool-mediated observations/actions, final patch, FTP/PTP feedback, and normalized reasoning fields. This supports evaluation of localization, planning, over-prediction, executable success, and failure diagnosis.

The demonstrated `training_use` is restricted to evaluation and audit. No SFT, preference-learning, reward-model, RLVR, or agent-training release is shown. The five reference modules and judge scores should not be reused as rewards until official instances, prompts, calibration labels, alternative-solution handling, and evaluator code are available.

If artifacts are later released, a safe audit should pin source commits and OCI digests, retain every success and failure, separate expressed trace content from patch-inferred content, run independent judge calibration, and test alternative correct patches. Benchmark users should keep Full and Lite roles explicit, establish temporal/contamination policy, verify upstream licenses, scan public discussion text for personal data, and sandbox untrusted repository setup and tests.
