RACE-bench pairs terminal executable verification with five structured reasoning modules: concept explanations, goal expectation, file localization, specific implementation tasks, and ordered task-step decomposition. References include entities, locations, change types, purposes, necessity, and a closed taxonomy of step types. They are structured annotations, not raw human chain-of-thought.

Terminal success is programmatic. A generated patch must apply cleanly and every FTP and PTP test must pass in the instance environment. FTP tests encode behavior that fails before the gold patch and should pass after it; PTP tests protect previously passing behavior. Apply-success/test-fail remains a distinct failure group rather than being merged with patch-application failure.

Reasoning evaluation is mixed. Exact or structured matching covers some file/entity/location fields, while LLM semantic judgments score concept and goal understanding and align newly proposed tasks/steps. DeepSeek V3.2 summarizes agent traces into the reference schema; patch-driven back-inference can supplement fields after the run. Consequently, the score measures alignment between normalized behavior and one constructed reference, not direct access to the agent's internal reasoning.
