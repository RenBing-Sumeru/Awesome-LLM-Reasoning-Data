1. **选择可执行项目：** 从真实 GitHub 仓库筛选具有稳定单元测试和可构建环境的项目，固定 commit、依赖与测试命令。

2. **构建 RDG：** 对测试进行动态 instrumentation，记录测试触达的函数及调用边，根据依赖关系确定哪些组件必须先实现，并生成无循环的开发顺序。

3. **合成阶段任务：** 沿 schedule 逐步隐藏或回退目标实现，保留当前可见代码、相关测试与预期修改；每个阶段输出 partial repository—tests—patch 三元组。

4. **执行筛选与训练：** 在 Docker 中确认补丁前目标测试失败、应用 gold 修改后通过，并删除不稳定任务。用训练实例 SFT 开源模型，再在 2,020 题 SWE-Flow-Eval 上执行验证。复现需固定 tracing、测试选择和容器镜像。
