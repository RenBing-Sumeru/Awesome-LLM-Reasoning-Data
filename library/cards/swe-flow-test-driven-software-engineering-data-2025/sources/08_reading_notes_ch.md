1. **一句话定位：** SWE-Flow 从 unit tests 与运行时依赖反推 18K+ 可验证 TDD 阶段任务，而非依赖人写 issue。
2. **方法抓手：** 固定项目、动态 tracing 建 RDG、生成开发顺序、回退部分实现、执行测试筛选。
3. **数据抓手：** 16,061 条训练、2,020 条测试，包含 partial codebase、tests、修改和 Docker 环境。
4. **证据锚点：** 同模型微调实验表明 RDG/TDD 数据显著提升阶段式开发能力，但测试覆盖仍限定结论。
5. **复用决定：** 适合过程监督和 agent 训练；最大风险是 unit tests 未覆盖真实需求与依赖。
