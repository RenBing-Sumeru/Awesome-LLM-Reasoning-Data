1. **One-sentence position:** SWE-Flow infers more than 18K verifiable TDD stage tasks from unit tests and runtime dependencies instead of relying on human-written issues.
2. **Method takeaway:** Fix projects, build RDGs through dynamic tracing, create development orders, revert partial implementations, and filter by test execution.
3. **Data takeaway:** It contains 16,061 training and 2,020 test instances with partial codebases, tests, modifications, and Docker environments.
4. **Evidence anchor:** Same-model fine-tuning experiments show substantial gains from RDG/TDD data, although test coverage limits the conclusion.
5. **Reuse decision:** It is suitable for process supervision and agent training; missing requirements and dependencies outside unit-test coverage are the largest risk.
