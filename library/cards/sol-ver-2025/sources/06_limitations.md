- The full-pass gate is circular. A weak or incorrect generated suite can accept wrong code, and a wrong code/test pair can become positive SFT data for both roles. Passing all sampled tests does not establish conformance to the natural-language specification.
- Solver and Verifier share Llama 3.1 8B weights and upstream data, so their errors are correlated. Iteration agreement of 75.14%/72.38% is not independence and can reflect stable shared blind spots.
- Verifier DPO negatives are alternative expected outputs from the model's sampling space. If the assumed chosen output is wrong, preference direction is reversed; the same issue affects failing-code negatives for Solver DPO.
- Branch coverage is measured on a candidate solution, not on the unknown intended program behavior. Output diversification blocks one simple shortcut but does not guarantee boundary coverage, oracle correctness, exception handling, or adversarial robustness.
- Only 45% of Iter 1 examples yield an agreed full-pass pair. The default rule discards the rest, while the paper's relaxed-threshold ablation shows that more selected data can hurt. This exposes sensitivity to the scoring function and candidate pool.
- The 103,280 deduplicated prompts are described but not released. Exact snippet revisions, template mixture, deduplication, generated-record counts by round, accepted/rejected ratios, split construction, and provenance joins are unavailable.
- Main-generation candidate counts, temperature, top-p, random seeds, SFT/DPO hyperparameters, compute budget, timeout, dependency policy, process isolation, and sandbox security are unknown. The disclosed temperature 0.6/top-p 0.9 applies only to evaluation negative-example generation.
- Decontamination and overlap controls are unknown. Training prompts draw on OSS-Instruct snippets and benchmark training templates; evaluation uses MBPP and LiveCodeBench. Embedding-distribution similarity is not an overlap audit.
- No author-linked code, generated corpus, model checkpoints, or license for those unavailable artifacts was verified. The paper recipe cannot be replayed or inspected at record level.
- Evidence is limited to Python function-level tasks and one 8B model. Generalization to other languages, repository context, interactive debugging, larger models, or production test environments is unknown.
