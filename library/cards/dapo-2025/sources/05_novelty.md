The prior-work baseline is GRPO: one prompt produces a response group, final rewards are normalized within the group, and each response's token loss is averaged before responses are averaged. DAPO keeps group-relative outcome supervision but changes four interfaces around it. Dynamic Sampling makes group eligibility part of the data pipeline; Token-Level Policy Gradient Loss changes token weighting; Soft Overlong Punishment changes the scalar reward surface; and Clip-Higher changes the optimization constraint (Paper §§2-3).

For reasoning-data research, the concrete novelty is not simply a new optimizer name. The paper makes the effective online dataset policy-dependent: easy all-correct and hard all-wrong groups are generated but excluded, while variable-reward groups are replenished to a fixed count. It also treats response length as feedback and publishes an integer-answer prompt construction recipe plus implementation artifacts. These changes expose how selection and aggregation can be as consequential as the original prompt file.

Several components are not new in isolation: GRPO, rule-based outcome reward, PPO-style clipping, web/competition problem collection, and answer-format normalization have precedents. The 17K scale and Qwen2.5-32B run are engineering scale, not independent methodological novelty. Before reuse, verify the intended deduplicated data revision, exact reward parser, transformation fidelity, source rights, benchmark overlap, and whether the current recipe matches the paper run.
