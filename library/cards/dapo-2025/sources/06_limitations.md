- **Method boundary:** DAPO supplies only answer-level outcome supervision. A rollout with a matching integer can contain invalid intermediate reasoning, while an equivalent answer can be rejected by extraction or normalization. The paper names `is_equivalent` but does not disclose the exact paper-run training implementation, calibration set, or false-accept/false-reject rate.
- **Transformation risk:** an undisclosed LLM rewrites non-integer answers into integer-target tasks. Appendix A shows one successful example and says most outputs were satisfactory, but gives no generator version, acceptance threshold, yield, double-check protocol, or measured semantic-error rate. This can change the task or target before RL begins.
- **Selection and reward risk:** Dynamic Sampling drops all-correct and all-wrong groups from updates. As a curator inference, this improves gradient availability but creates a policy-dependent curriculum and removes precisely the easiest successes and hardest failures from the optimized batch. Soft Overlong Punishment also makes response length part of reward, which can discourage valid long solutions.
- **Release risk:** the paper says 17K prompts, whereas Hub revision `6587709` exposes 1,791,700 rows in one train split with repeated blocks. There is no official deduplicated manifest, source URL per row, original problem, transformation trace, rejected rewrite, or online rollout release. The release-level Apache-2.0 tag does not resolve rights for the underlying web and competition content.
- **Evaluation and contamination risk:** the main result is confined to AIME 2024. No disclosed decontamination, source-overlap analysis, alternative benchmark, seed variance, or record-level audit separates data effects from benchmark overlap, optimizer interaction, and run variance.
- **Reproducibility risk:** the paper, current DAPO repository, current verl-recipe, reproduction commit, and W&B runs are separate versioned surfaces. The DAPO README currently links a removed training-code branch, and the later official reproduction uses settings and hardware not fully bound to the paper run. Version drift can change sampling, reward, loss aggregation, and results.
