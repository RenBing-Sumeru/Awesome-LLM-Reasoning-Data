该发布描述的是面向编码的后训练栈，而非公开指定的数据集。Qwen2.5-Coder 清理并改写噪声预训练数据。对 Code RL，多样编码任务通过自动扩展的测试用例获得执行反馈。对 Agent RL，多轮智能体动作从一个据称可并行运行 20,000 个独立环境的 Qwen 自建云系统获得反馈。

已披露的监督对象可包含代码编辑或解答、工具调用、多轮智能体状态、环境反馈以及执行或测试结果。报告中的终止条件是代码执行成功或环境完成，但没有给出通过阈值、超时、部分完成策略或完整 reward 公式。

从披露账本看，该发布提供了部分接口图：数据清理、执行反馈、可扩展环境和长程智能体学习均被点名。它并非对任务、测试、轨迹、云 provisioner 或 reward 实现的公开发布。
