An open-weight coding model can be accompanied by high-level claims about data scale, execution feedback, and large agent-RL infrastructure without releasing the task records, tests, environments, reward rules, or audit artifacts that determine what the training signal actually was. In long-horizon coding, the task, environment, tools, test suite, and terminal condition jointly define the data object; model weights alone do not disclose them.

The Qwen3-Coder release reports 7.5T pretraining tokens with 70 percent code, Qwen2.5-Coder data cleaning, execution-driven Code RL, and 20,000 parallel cloud environments for Agent RL. Yet it does not publish the prompts, task manifests, repository revisions, test cases, trajectories, environment images, or reward implementation needed to independently inspect or recreate this post-training substrate.
