Earlier surveys commonly organize LLM training by architecture or optimization stage. This work changes the entry point to data operations across post-training and foregrounds the distinction between selecting existing data, improving it, generating it, compressing it, and letting it evolve. Those operations are not new individually; the direction signal is their common audit-oriented taxonomy. Before reuse, check whether a claimed data gain is separable from changes to the base model, teacher, inference budget, or evaluation set.
