This is a literature survey, not a construction pipeline. It classifies representative post-training approaches according to the five categories in the official abstract and links an author-maintained paper list. For each primary method reused from this map, inspect the original paper or release for prompts, response/trace authorship, filters, teacher identity, sample budget, split policy, license, and contamination controls. The official ACL page and DOI are the citation artifacts; the linked GitHub repository is a paper list, not evidence that one common codebase or dataset reproduces every surveyed result.
