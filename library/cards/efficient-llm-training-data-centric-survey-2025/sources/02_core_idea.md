The paper's contribution is a data-centric taxonomy with five categories: data selection, data quality enhancement, synthetic data generation, data distillation and compression, and self-evolving data ecosystems. The core idea is that “efficient training data” is not one object: a selected subset, an improved label, a teacher-written example, and a compressed corpus make different provenance and audit claims. The feedback contract is intentionally not unified because the surveyed methods may use humans, teacher models, preferences, rewards, or task verifiers. In this atlas, compare it with post-training surveys for pipeline placement and with primary releases for concrete data evidence.
