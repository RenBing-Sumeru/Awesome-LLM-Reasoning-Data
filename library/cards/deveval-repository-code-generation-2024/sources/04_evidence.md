The arXiv abstract reports 1,874 testing samples from 117 repositories across 10 domains, annotated by 13 developers, and a highest reported GPT-4-turbo Pass@1 of 53.04% in the paper's setting. The official GitHub README describes a released artifact with 1,825 samples from 115 repositories, so aggregate scale should be cited with the source and version.

The decisive instance-level evidence is executable: a completion replaces the target body and passes or fails the relevant tests. This is stronger than string matching but weaker than a full semantic proof, because the tests, dependency data, and original repositories define the boundary of correctness. Reported scores are constrained by the repository snapshot, environment, prompt condition, model version, and decoding budget.
