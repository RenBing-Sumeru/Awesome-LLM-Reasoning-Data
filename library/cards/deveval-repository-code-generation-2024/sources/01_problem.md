Primary source: arXiv:2405.19856, submitted 2024-05-30 and marked by arXiv as accepted to ACL 2024, plus the official seketeam/DevEval repository. DevEval asks how to evaluate LLM code generation under real repository context rather than isolated function puzzles. The card belongs in the atlas as a repository-level executable benchmark and agent-environment surface, not as a training recipe or a general SWE issue-fixing benchmark.

The data object is a repository-aligned code-generation sample: namespace, target function or method, source file position, requirement text, reference implementation, dependency annotations, tests, and repository/topic metadata. The evaluation surface is code replacement inside the original project followed by test execution, with Pass@k and dependency-recall style measurements. Its L4 value is the explicit coupling among task requirement, repository context, dependency graph, and executable feedback.
