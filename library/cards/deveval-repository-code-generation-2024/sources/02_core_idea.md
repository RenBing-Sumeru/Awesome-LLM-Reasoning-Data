DevEval's contribution is a manually annotated benchmark where code-generation prompts are grounded in real repositories and checked by repository tests. The core mechanism is to locate target functions or methods, record requirements and dependencies, expose several context settings, and evaluate generated code by inserting it back into the project.

Compared with HumanEval, MBPP, APPS, or contest-style benchmarks, the changed object is not just a Python function signature but a project-local completion with dependency and file-context constraints. The feedback contract is executable: generated code must satisfy the provided tests in the pinned repository environment; dependency recall is a secondary diagnostic rather than a correctness proof. Direction label: repository-context executable benchmark for code agents.
