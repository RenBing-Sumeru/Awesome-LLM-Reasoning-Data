The pipeline has three phases. In task collection, Qwen3-32B reads each target repository README and emits five search keywords. GitHub search retrieves the top 20 repositories ranked by stars and issue counts. Candidate pull requests must have linked issues, be merged and closed, and edit code. An LM prompt then screens for substantive bug fixes or features that are both high-quality and mirrorable into the target repository. GPT-4o-2024-0513 distills repository-specific names, paths, and traces into a portable abstract description.

In task mirroring, GPT-4.1 backs Agentless-style localization and Search/Replace patch generation. The Test Agent localizes source and test files and creates `test.patch`; it is required to add nontrivial tests that pass on the current target code. The Mirror Agent receives the abstraction and test-derived structural hints, modifies only non-test source code, and produces `mirror.patch` that breaks those tests. Comments are removed, the patch is reversed into `fix.patch`, and a final LM prompt uses the original issue, `test.patch`, `fix.patch`, and Gym examples to write `problem_statement`.

Verification first checks that `mirror.patch` applies to `base_commit`, and that `test.patch` and `fix.patch` apply after it. The full suite is then run as `Run.log` after the mirror patch, `Test.log` after adding tests, and `Fix.log` after all three patches. Accepted transitions preserve existing results, introduce at least one `ANY -> FAILED -> PASSED` test, forbid listed pass/skip-to-failure regressions, and discard flaky or abnormal cases. Deduplication requires different fail-to-pass tests and different `fix.patch` content. Seed Gyms come from SWE-Gym, SWE-rebench, and Multi-SWE-RL; Gym selection uses a five-minute full-suite limit, 1 GB memory limit, and a manual basic functional check.

For post-training data, Claude 3.7 Sonnet and Claude 4 Sonnet are used as expert generators on a 15,000-task subset; each task receives three trials at temperature 1.0 and at most 100 rounds. A trajectory is successful only if it issues `finish` and its final patch passes a superset of the tests repaired by `fix.patch`. The process yields 6,431 successful SWE-Mirror episodes, combined with 6,025 SWE-rebench episodes. Qwen2.5-Coder-Instruct-7B and 32B are fine-tuned for at most three epochs with AdamW, weight decay 0.01, warmup ratio 0.1, peak learning rate 5e-5, and 32,768-token context. Error Masking keeps erroneous actions in context but removes their response loss; it does not retain wholly failed episodes as positive demonstrations.

Exact task splits, the 15,000-task membership list, container images, repository commit manifest, dependency locks, harness/parser revisions, prompt code, random seeds, and model endpoint versions are not available through a verified public artifact. These must be fixed before exact construction or trajectory replay.
