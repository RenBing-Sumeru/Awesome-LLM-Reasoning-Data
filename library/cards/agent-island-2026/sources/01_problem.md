The authoritative paper record is arXiv:2605.04312v1, submitted on 2026-05-05. The artifacts describe a NeurIPS 2026 submission, but no acceptance was verified, so the venue remains **arXiv preprint**. The paper asks how to evaluate frontier language models after fixed capability benchmarks become exposed, contaminated, or saturated. Agent Island replaces a reusable item bank with a low-stakes social-strategy environment in which each evaluated model faces adaptive model opponents.

One benchmark instance is a complete seven-player game episode. Seven distinct model identifiers receive anonymized player labels. Across five elimination rounds, active players privately confer, pitch publicly, submit private votes and rationales against another active player, eliminate one player, and consolidate memory. In round six, the two survivors pitch and the five eliminated players privately vote, with rationales, for the winner. A released JSON log preserves game configuration/status, the player-to-model mapping, parser and usage statistics, round state, vote tallies, and ordered private/public events with prompts, content, visibility, provider-exposed reasoning, metadata, and timestamps.

This is an environment_agent_trajectory_data object because state, action, visibility, environmental aggregation, and the terminal winner are serialized together. It is not evidence for policy training: the paper reports no explicit reward delivered to players and uses the episodes only for evaluation and behavioral audit. Nor does adaptive play prove decontamination; the fixed public rules, engine, APIs, and released logs remain exposed.

Two scales must stay separate. The arXiv v1 analysis and frozen version-1.0.0 manifest contain exactly **999 games involving 49 unique models**. The independently mutable live source retrieved on 2026-07-20 reported **1,270 games and 62 ranking rows**; the official site's `games_played >= 10` rule left **59 displayed models**, and the source timestamp was 2026-07-02 15:26:25.976235+00:00. Those live values are not paper results, and earlier live snapshots are stale. Evidence is sufficient for a detailed bilingual Card, but the accepted metadata remains `partial` and `L3_summary_ready` because generator/model bindings, failed-run accounting, compute details, decontamination, and the replication-ZIP license remain unknown.
