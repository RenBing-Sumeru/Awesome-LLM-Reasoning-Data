The contribution is a vision-centric mobile-device agent that decomposes user instructions, reads screenshots through multimodal perception, and issues concrete touch/text/navigation operations. The core mechanism combines GPT-4V-style visual reasoning with OCR and icon detection so the agent can localize actionable UI elements.

The evaluation surface is Mobile-Eval: mobile tasks grouped by difficulty and evaluated through the executed operation sequence. The feedback contract reports whether the task is completed and how efficient the trajectory is relative to a reference path.

Closest comparisons are app-specific automation, XML-access Android agents, and later mobile/OS benchmarks such as AndroidWorld or OSWorld. The direction label is smartphone GUI trajectory evaluation under visual-only observation.
