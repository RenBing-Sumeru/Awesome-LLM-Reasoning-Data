Use this paper as a recipe for visual mobile-agent evaluation. Preserve task text, app name/version, screenshot, detected text/icon candidates, chosen operation, coordinates or text input, previous actions, terminal state, and Mobile-Eval metric fields.

It is useful for designing smartphone GUI trajectory schemas, comparing visual observation against XML-based control, and auditing whether a claimed agent can ground actions in screenshots.

For atlas use, keep success, progress, efficiency, and completion labels separate; store the environment setup and model/prompt version with every trajectory.
