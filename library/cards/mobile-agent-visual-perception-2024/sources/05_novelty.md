Prior mobile automation often depended on structured UI trees, app APIs, or narrow scripted flows. Mobile-Agent changes the object by using screenshots as the primary observation and by evaluating full mobile task trajectories.

The direction signal is that mobile GUI agents need perception-grounded state, action coordinates, execution history, and task-level feedback rather than final text answers. The quality signal is the official paper plus a maintained series repository that keeps Mobile-Agent variants and Mobile-Eval artifacts together.

What is not new: OCR, icon detection, and LLM-based step planning are existing components. Before reuse, inspect app/task licenses, repository revision, device setup, model backend, prompt, step budget, and whether Mobile-Eval labels are sufficient for the target audit.
