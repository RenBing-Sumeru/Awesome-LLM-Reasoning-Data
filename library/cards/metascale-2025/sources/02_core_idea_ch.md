MetaScale 包含三个阶段。初始化阶段先要求 target LLM 自行生成面向当前任务的 meta-thought，再从 WildChat 检索 embedding 相似度最高的 8 个任务，要求模型抽象并适配其中的策略。选择阶段把每个 meta-thought 视为 multi-armed bandit 的一个 arm，并选择 UCB 最大者；UCB 将该 arm 的 Skywork reward 经验均值与依赖总尝试次数和被选次数的 exploration bonus 结合。被选 meta-thought 用于条件化生成新回答，其标量 reward 再更新该 arm。每到 evolution interval (k)，系统选择高 UCB meta-thought 作为 parent，由 target LLM 生成经过改进的 child；论文没有直接执行字面层面的 crossover 或 mutation。完成 (T) 次尝试后，系统返回 reward-model score 最高的回答。反馈契约是 mixed：learned outcome reward 驱动搜索；GSM8K 用精确答案检查；MMLU-Pro 用答案抽取与匹配；Arena-Hard 用 LLM judge 评测。
