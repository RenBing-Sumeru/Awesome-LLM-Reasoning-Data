对 Rollout, Search, and Test-Time Trace Data 轨道而言，MetaScale 提示了一套 strategy-level trace schema：benchmark item 与 retrieval query；检索到的 WildChat ID 与 similarity score；初始 cognitive mindset 和 problem-solving strategy；arm selection count、empirical mean、UCB value 与 β；每次被选 meta-thought、生成回答与标量 reward；evolution interval、parent set、child strategy 与 lineage；attempt budget；最终 argmax response；以及与 search reward 分开保存的 evaluation result。这类记录可支持 exploration/exploitation、retrieval influence、strategy diversity、reward hacking 与 scaling efficiency 研究。论文证据支持测试时构造和评测用途，不支持 SFT、preference training 或 RL 复用。由于没有发布轨迹集和相应许可，这仍是从方法推导出的 schema，而不是已经可用的数据集。
