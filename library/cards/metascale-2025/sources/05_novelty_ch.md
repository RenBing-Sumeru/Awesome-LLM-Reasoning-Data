既有 test-time 方法通常在同一 prompt 下采样答案、修订回答，或借助 verifier 搜索。MetaScale 改变的是搜索变量：每个 arm 是文本策略而不是答案，并且策略池本身会在推理期间变化。其初始化把模型自行生成的策略与从 WildChat 检索样例中抽象的策略结合；selector 使用累积 arm reward，而不只是独立地给候选打分；LLM-mediated evolution 又从高 UCB parent 生成新的策略 arm。Genetic algorithm、UCB、retrieval、persona、meta-reasoning 与 reward-model selection 各自都不是新概念；贡献在于把它们按 query 集成为固定预算的 strategy-search trajectory。对本图谱而言，这条轨迹才是新意信号：若方法未来以数据形式发布，应保留 retrieved example、parent/child strategy、arm statistic、candidate response 与 final selection 之间的 lineage。
