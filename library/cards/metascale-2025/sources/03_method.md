Algorithm 1 takes a query, target LLM, reward model, instruction-tuning dataset, attempt budget (T), and evolution interval (k). For each attempt it selects a meta-thought with UCB, generates a response, obtains a score from Skywork-Reward-Llama-3.1-8B-v0.2, updates the arm statistics, and periodically expands the pool from high-UCB parents. The main matched evaluation randomly samples 64 instances from each of GSM8K, MMLU-Pro, and Arena-Hard and applies the same subsets across methods in a zero-shot setting. GPT-4o (gpt-4o-0806) and Llama-3.1-8B-Instruct are the target models. Main fixed-budget comparisons use 128 attempts, while scaling analyses range from 1 to 128. The paper explicitly sets greedy one-pass and CoT baselines to temperature 0 and Best-of-N variants to temperature 0.6, but does not separately disclose MetaScale's decoding temperature. GSM8K uses numeric exact match. MMLU-Pro uses two regular-expression extractors and selects a random option if both fail. Arena-Hard uses GPT-4-Turbo to judge against GPT-4-0314 and reports win-rate confidence intervals; additional tables use the full Arena-Hard set with and without style control. UCB β, (k), exact initial-pool size, seeds, and sampled item IDs remain unknown.
