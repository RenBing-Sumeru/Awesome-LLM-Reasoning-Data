For this atlas, the distinctive contribution is not merely an agentic GRPO recipe: it makes two feedback layers inspectable at once. Released static SFT/RL material, code and checkpoints support examination of an end-to-end pipeline; persistent and online evolving rubrics expose why an open release can still have a dynamic-feedback provenance gap. The source roles are construction recipe, data release, verifier/reward and agent environment. The relevant declared uses are SFT, agent training and evaluation. Comparisons should therefore separate released rows and checkpoints from the unexposed online rubric history, judge calls, search observations and selection decisions.
