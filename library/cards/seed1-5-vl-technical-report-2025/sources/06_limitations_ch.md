3T 规模语料没有配套逐条来源清单、不可变混合表、最终领域计数、去重日志、来源版本、许可映射或公开训练/验证切分。“来自 Web”“公开”“内部”“抓取”和“开源”等描述不足以支持权利或溯源审计。论文列出许多生成器和公开数据集，但具体版本、提示、随机种子、阈值、筛选产率及来源到样本映射大多为 unknown。约 5 万条 SFT 汇总不包含未披露的内部纯文本和 LongCoT 数量；偏好集规模、RL 提示数、候选 K、episode 总数和轨迹清单同样未知。

反馈覆盖范围有限。最终表达式与 SymPy 匹配时，视觉推理仍可能是伪相关；IoU 与点位奖励依赖参考几何；正则和字符串检查可能被投机；reward model 会继承标注者、模型和任务分布偏差。同时评估两种回答顺序只能缓解位置偏差，不能解决校准或更广泛的 judge 偏差。推理轨迹未被评分，因此流水线不能证明 LongCoT 忠实。

报告说明合成视觉 puzzle 会针对 PuzzleVQA 等 benchmark 去污染，但没有提供覆盖预训练、SFT、偏好、RL 提示及大量公开和内部评测的全语料重叠审计。内部 benchmark 和精选定性案例无法独立复现。论文自身也把 3D 空间想象、幻觉和组合搜索列为仍存在的模型失败。

最后，API 可用和 Apache-2.0 示例代码不等于模型或数据开放。已核验的官方工件提供 API 与 cookbook，而非模型权重、训练代码、reward-model 检查点、verifier 或数据集，因此无法据此端到端复现。
