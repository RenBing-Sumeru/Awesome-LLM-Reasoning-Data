No record-level source manifest, immutable mixture table, final per-domain counts, deduplication log, source revision, license map, or released train/validation split accompanies the 3T-scale corpus. Descriptions such as web-sourced, public, internal, crawled, and open-source are not sufficient for rights or provenance audits. The paper names many generators and public datasets, but exact versions, prompts, seeds, thresholds, filtering yields, and source-to-example mappings are mostly unknown. The 50k SFT aggregate excludes undisclosed internal text-only and LongCoT counts; preference-set size, RL prompt count, candidate K, total episodes, and trace manifests are also unknown.

Feedback has bounded coverage. A final expression can match under SymPy while the visual reasoning is spurious; IoU and point rewards depend on reference geometry; regex and string checks can be gamed; a reward model can inherit annotator, model, and task-distribution bias. Evaluating both response orders addresses positional bias but not calibration or broader judge bias. Because the reasoning trace is not scored, the pipeline does not establish LongCoT faithfulness.

The report states that synthetic puzzles were decontaminated against benchmarks such as PuzzleVQA, but it does not provide a corpus-wide overlap audit for pre-training, SFT, preferences, RL prompts, or the many public and internal evaluations. Internal benchmarks and selected qualitative examples are not independently reproducible. The paper itself identifies 3D spatial imagination, hallucination, and combinatorial search as remaining model failures.

Finally, API availability and Apache-2.0 sample code do not make the model or data open. The checked official artifacts expose an API and cookbook rather than model weights, training code, reward-model checkpoints, verifiers, or datasets, so end-to-end reproduction is not possible from the release.
