Seed1.5-VL 把多模态能力视为分阶段的数据问题。532M 参数的 SeedViT 与约 20B 激活参数的内部 MoE 语言模型通过 adapter 连接，随后依次进行 adapter 对齐、3T-token 多模态预训练和 240B-token 的均衡长上下文阶段。按能力划分的数据覆盖图文知识、OCR、grounding 与 counting、3D 感知、视频、STEM 和 GUI 交互。

后训练在精选 SFT 与在线强化学习之间迭代。通用提示由学习式 VLM 偏好模型评分，可验证提示则接收符号、几何、约束、字符串或环境奖励。监督只作用于最终生成结果。回答正确的 RL 轨迹会回流到下一轮 LongCoT SFT，报告称当前模型经历了四轮此类迭代。
