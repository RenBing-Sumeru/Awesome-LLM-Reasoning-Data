论文在 Best-First、Beam、Tree Search 与 MCTS 上报告答案准确率和平均生成 token 成本。状态合并通常降低 token 使用，例如 GSM8K 的 Best-First 设置在论文归一化 token 指标上由 2.47 降至 0.88。TD(λ) 训练和 verifier 集成改善了多项准确率结果；消融还比较预训练与后训练 SimCSE、不同聚类方法及方差降低组件，并以人工评价检查嵌入相似度与判断的一致性。

这些属于搜索系统层面的检查，不能证明每个合并状态对都逻辑等价、每个价值目标都校准良好，也不能证明每条保留轨迹适合训练。部分 MATH 配置会增加计算，集成也需要多个 verifier。基准准确率与 token 节省说明构造配方值得审计，但不是未公开 rollout 语料的数据质量证明。
