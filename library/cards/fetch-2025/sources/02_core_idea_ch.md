FETCH 向 Best-First、Beam、Tree Search 或 MCTS 加入两个正交组件。节点扩展后，微调过的 SimCSE 编码新推理状态，凝聚层次聚类把邻近状态合并为超节点；超节点分数由成员节点的 verifier 分数聚合，后续扩展再按分数顺序选择成员。另一部分在训练时用有界的调整后 TD(λ) return 替代纯 Monte Carlo 目标，在推理时可平均多个 verifier 的预测。因此，其反馈契约由结果诱导的标量价值估计与学习得到的语义等价判断共同构成。二者都不是 oracle 式过程标签：聚类可能合并逻辑不同的状态，较低方差的价值估计也仍可能存在系统性错误。
