嵌入模型可由两类状态对监督进行后训练。提示式路线让通用 LLM 判断两个推理状态是否等价；一致性路线交换状态，比较它们对后续采样动作的影响，再用阈值生成相同/不同标签，最后用交叉熵使余弦相似度拟合这些标签。GSM8K 与 GSM-Plus 设置中，policy 和 value network 从 Llama-3-8B 出发并在 GSM8K 上微调；value network 每题仅从初始状态以温度 1.0 采样 16 条 rollout。MATH 设置则采用既有的 Mistral-7B policy 与 PRM。

推理时，每次扩展产生子状态、嵌入和 verifier 分数；聚类建立超节点，搜索在超节点之间选择，再按 verifier 分数顺序扩展成员状态。论文在 GSM8K、每个原题随机抽取一个变体的 GSM-Plus，以及 MATH500 上评估四种搜索算法。可复现的导出记录至少应保留源划分、提示、完整状态文本、父子边、嵌入模型版本、状态对标签或聚类距离、阈值、成员列表、原始与聚合 verifier 分数、TD 目标来源、扩展预算、解码设置和最终答案。官方仓库提供代码与示例 JSONL，但完整搜索树、被拒状态、状态对训练记录、verifier 目标和逐次运行种子均未被证实已发布。
