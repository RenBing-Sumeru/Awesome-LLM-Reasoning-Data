Personalized RewardBench supplies an explicit user-specific rubric for each example and constructs two generally high-quality responses that respectively follow or violate it, making the preference distinction depend primarily on the individual requirement. The official release contains roughly 2.83K personalized-preference instances. Core fields include the request, user rubric, chosen and rejected responses, and labels. Construction controls correctness, relevance, and helpfulness so that adherence to the personal preference is the main difference, and human review checks this isolation condition.
