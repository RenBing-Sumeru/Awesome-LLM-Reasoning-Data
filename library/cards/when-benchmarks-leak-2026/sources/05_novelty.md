Detect-then-filter methods change the evaluated set and are limited by detection error; earlier black-box approaches calibrate outputs or rewrite prompts, while white-box approaches edit activations or bypass attention. DeconIEP instead learns a per-instance perturbation at the input embedding, leaving text, weights, and benchmark membership unchanged. Its reference-guided KL objective turns a relatively less-contaminated checkpoint into a behavioral anchor, rather than locating a fixed set of shortcut neurons. The novelty is a controllable inference-time mechanism for the residual-contamination versus clean-utility trade-off, not a method for proving data provenance or removing training exposure. The bounded budget also exposes a measurable control variable: stronger perturbation can lower residual contamination but raises benign utility loss, so the method reports a trade-off rather than a single unrestricted correction.
