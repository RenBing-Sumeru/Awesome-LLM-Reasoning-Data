DeconIEP learns an instance-adaptive, bounded perturbation in input-embedding space. A lightweight generator uses the embedding of each item to produce a perturbation, then drives the contaminated model's output distribution toward that of a same-architecture reference model that is relatively less contaminated. The discrete prompt and model parameters remain unchanged; the ℓ∞ budget constrains the intervention. This targets memorization-driven shortcut pathways without filtering benchmark items or relying on a perfectly clean reference. The official ACL page exposes the paper only: no official code or standalone dataset release is linked. The method is a mitigation layer for a specified evaluation setting, so its output should be read alongside the reference choice, perturbation budget, and clean-utility test.
