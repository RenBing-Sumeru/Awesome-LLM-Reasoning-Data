Use this Card when deciding whether an open PRM checkpoint is enough to support process-supervision or verifier claims. It provides a disciplined separation: the model interface can be tested on segmented reasoning text, but the data and labeling process behind the interface cannot yet be independently audited.

It is also useful for evaluating step-reward deployment. A user can document input formatting and per-step scores, but should not infer calibrated correctness probabilities, released ground-truth traces, or an RLVR training recipe from the model release alone.
