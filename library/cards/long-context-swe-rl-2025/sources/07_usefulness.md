For the environment-agent-trajectory track, the paper is most useful as a schema and training-contract reference. A comparable record should bind task identity and repository commits to the initial issue, ordered reasoning/actions, stdout/stderr/exit-code observations, submitted patch, terminal test result, length statistic, final reward, group membership, policy/checkpoint version, and environment image digest. Recording reset and abnormal-termination events would close gaps left by this paper.

The RFT/RL contrast is a concrete ablation template for data-selection research. One can compare success-only full episodes, success plus masked malformed turns, mixed-success on-policy groups, and retained hard failures while holding tasks, environment, and inference runtime fixed. Outcome counts and zero-advantage exclusions must be reported; otherwise performance differences cannot be attributed to the retention policy.

The verifier design is a useful baseline for RLVR and agent training: executable tests supply a terminal signal and a soft turn penalty discourages loops without deleting every long failure. A stronger replication should add held-out tests, mutation or adversarial test checks, per-step diagnostics, patch-scope constraints, unsafe-action logging, and abstention evaluation. These additions address test incompleteness and sparse credit without pretending the original paper implemented them.

The release also provides an audit checklist for infrastructure-sensitive on-policy data: pin sampler versions and all decoding flags, task and container manifests, repository/test commits, dependency locks, seeds, network policy, reset semantics, and rollout/checkpoint lineage. The reported vLLM incident makes this checklist empirically motivated.

Reuse class: the public SWE-rebench tasks, runner fork, and containers may support environment reconstruction subject to their own licenses and version checks. The paper-specific 7,249/2,028 selections, 6,548 RFT episodes, RL rollouts, rewards, model, and trainer are blocked pending release. Accordingly, this Card is safe as a reading, recipe, evaluation-design, and audit reference; it is not a downloadable training dataset or independently reproduced baseline.
