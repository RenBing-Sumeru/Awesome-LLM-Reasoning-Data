The audited source is arXiv:2508.03501v2, revised 10 October 2025, together with the official OpenReview forum. The venue record says only “Submitted to ICLR 2026”; no acceptance or proceedings publication has been verified. The paper asks how to train a 72B software-engineering agent over repository interactions that can last tens of turns and up to 131k context tokens, where feedback arrives mainly after a patch is submitted.

The relevant object for the atlas is not merely a task prompt or final patch. A training episode begins with a GitHub issue and a sandboxed repository snapshot, then records a sequence of model reasoning/command actions and environment observations (stdout, stderr, and exit codes), ending with a submitted repository state, validation outcome, length penalty, and scalar reward. The hidden state includes files, source code, and running processes. This makes the work a direct instance of `environment_agent_trajectory_data`: state, action, observation, environment feedback, terminal predicate, failure retention, and replay metadata determine what can be learned from the record.

The public substrate is SWE-rebench: 21,336 tasks from approximately 3,400 Python repositories, with issue text, repository/setup commits, gold and test patches, test lists, installation metadata, quality metadata, and per-repository license names. The paper applies correctness, complexity, LLM-quality, and 50-run determinism filters to obtain 7,249 training tasks, but does not publish the selected instance manifest or filter decisions. An upstream SWE-bench execution fork and a registry announced as containing 7,500 pre-built task containers are public; neither is the paper-specific trajectory corpus.

The decision boundary is therefore construction-recipe and training-report inclusion, not reusable-data-release inclusion. The authors describe 6,548 successful RFT trajectories and online RL rollout groups, yet the task manifests, RFT and RL trajectories, failed RFT attempts, rewards, submitted patches, checkpoint, internal JAX training code, and immutable replay bundle are unavailable. This Card reaches L4 content depth by auditing the paper, appendices, OpenReview status, pinned upstream dataset revisions, execution fork, and container announcement; it does not upgrade the accepted metadata beyond `L3_summary_ready`.
