Evol-Instruct makes instruction difficulty and breadth explicit construction variables: every accepted record links a seed, an evolution operator, an evolved instruction, and a teacher response. Compared with Self-Instruct, it targets controlled complexity rather than more samples of similar difficulty; compared with UltraChat, it produces single instruction-response pairs rather than contextual conversations. The OpenAI model authors both the evolved request and its answer, while rule checks filter malformed evolutions; no independent verifier establishes answer or reasoning correctness.

Open dataset: yes. **Evol-Instruct / WizardLM instruction data**, https://github.com/nlpxucan/WizardLM, includes paper-related JSON instruction-response releases for SFT. The paper creates a 250K evolved pool from 52K Alpaca instructions and uses a random 70K subset in the matched LLaMA-13B experiment; records contain an evolved instruction and teacher output, with seed/operator lineage needed for a full audit. The repository has received later dataset revisions, so users must pin the exact file, count, format, and license before training or redistribution.
