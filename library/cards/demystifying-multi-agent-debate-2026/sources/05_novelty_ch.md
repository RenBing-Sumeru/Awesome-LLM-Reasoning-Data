有价值的数据贡献是显式辩论契约，使交互前覆盖与交互中影响可以分开观察。记录可区分 10 个采样候选、5 个入选的不同答案、每轮可见上下文、表达置信度、修订、奖励分量和终局投票。

论文形式化的 diversity 目标统计 unique answers，并未规定 embedding distance；官方仓库 README 则描述了基于 embedding 的实现，二者不能静默混用。置信诱导、self-consistency、GRPO 和多数投票均有先例；方向信号是把多样性控制的初始化与经过训练的置信表达/使用结合，并暴露 reward hacking 压力。该工作仍是协议/配方，而非已发布辩论数据集。
