Existing research-agent benchmarks often evaluate literature question answering, hypothesis generation, or local code completion and do not show whether a system can complete a real experiment. AI research experiments require understanding a question, formulating a testable hypothesis, modifying multiple code modules, configuring data and hyperparameters, running training, and interpreting results. Failure at any stage can make the experiment non-executable. Manually constructing such tasks from papers and repositories is also too expensive for scalable, reproducible evaluation.

EXP-Bench introduces a semi-automated construction pipeline that organizes 461 research tasks from 51 top AI papers and their open-source code. Each task provides a research question and incomplete starter code and asks an agent to design, implement, execute, and analyze an experiment, with code execution and stage-level scoring checking the complete research process.
