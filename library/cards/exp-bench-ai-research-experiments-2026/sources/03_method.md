1. **Select papers and repositories:** Influential AI papers are filtered for open-source implementations, installable dependencies, and experiments that can be rerun within controlled budgets.

2. **Extract experimental structure:** A model identifies research questions, hypotheses, variables, data, models, metrics, and expected conclusions from papers and maps them to repository code and configuration files.

3. **Generate task assets:** Key experimental components are removed or rewritten to create incomplete starter code, explicit goals, and execution instructions, with dependencies, paths, and base scripts automatically checked.

4. **Validate and score:** Humans review fidelity and trial-run tasks. Agent outputs receive separate scores for design, implementation, executability, and analysis, while complete success requires every stage to pass.
