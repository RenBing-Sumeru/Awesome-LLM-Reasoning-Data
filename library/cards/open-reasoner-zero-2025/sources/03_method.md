The final paper and pinned repository state support the following reconstruction.

1. **Collect prompt/reference pairs.** The original pool draws from AIME through 2023, MATH, Numina-Math, and Tulu3 MATH. The extended file is mainly cleaned from OpenR1-Math-220k. The paper also names AoPS and programmatically synthesized general-reasoning tasks. Released rows do not preserve source IDs or mixture proportions.
2. **Curate for rule verification.** Exclude proof-oriented and other tasks that the checker cannot reliably score. Apply an LLM-based difficulty filter to remove samples with zero or very high pass rates. The filtering model, prompt, thresholds, candidate counts, and row-level decisions are undisclosed.
3. **Initialize without SFT.** Main ORZ policies and critics use Qwen2.5 Base at 0.5B, 1.5B, 7B, and 32B. Policy and critic are separate; the critic's value head is randomly initialized. “Zero” refers to skipping SFT/distillation before the RL stage.
4. **Sample online behavior.** Each generation iteration samples 128 unique prompts and 64 responses per prompt, producing 8,192 trajectories before packing or filtering. Temperature and top-p are both 1.0. Released configs allow 2,048 prompt tokens, 8,000 generated tokens, and 8,192 model tokens.
5. **Assign terminal rewards.** Parse the named `answer` section; code further requires `\boxed{...}`. Normalize the candidate and reference and test mathematical equivalence. Correct receives 1, otherwise 0; intermediate rewards and separate format rewards are absent.
6. **Estimate values and optimize.** A separate critic predicts token values. PPO uses GAE with \(\gamma=1\), \(\lambda=1\), clipping \(\epsilon=0.2\), batch-level advantage normalization, one strictly on-policy policy update, and 12 critic minibatch updates. Policy/critic AdamW learning rates are \(10^{-6}\)/\(5\times10^{-6}\), betas are [0.9, 0.95], weight decay is zero, and warm-up is 50 optimizer steps. KL and entropy contributions are effectively zero.
7. **Mine hard prompts.** During the first 1,100 ORZ-32B steps, retain prompts with fewer than four correct responses among 64 attempts. The resulting public hard file contains 13,451 rows. The paper then describes 100 annealing steps with learning rate decayed to \(3\times10^{-7}\).
8. **Release selected surfaces.** Publish code, Dockerfile, configs, three prompt files, evaluation files, policy weights, and critic weights. Do not publish the exact paper-run rollouts, incorrect responses, 64-way mining attempts, rewards, values, advantages, GRPO failure trajectories, immutable logs, or checkpoint-to-data manifests.

Reproduction remains incomplete. All released PPO configs point to the original 57k file, while the paper describes a roughly 129k mixture and hard-data annealing. Mixed-domain data/configs are also absent. The README's 16-node statement for 32B conflicts with a config declaring 32 training nodes per group, and the repository has neither a tag nor a GitHub Release.
