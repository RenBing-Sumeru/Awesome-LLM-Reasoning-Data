Primary source: arXiv:2310.16253, submitted 2023-10-25, plus the official ConDefects repository. The paper addresses leakage in LLM-era fault-localization and program-repair benchmarks whose code may predate and overlap with model training data. The data object is an AtCoder-derived faulty program paired with fault location, repaired code version, test cases, date metadata, and difficulty metadata. It belongs in the atlas as an executable repair/localization evaluation surface with contamination controls, not as an agent trajectory benchmark by itself. The evidence boundary is versioned dataset construction and test execution; later README updates extend the dataset beyond the original paper window.
