The baseline is established repair/localization datasets whose instances may have been public long before contemporary LLM training cutoffs. ConDefects changes the construction by sourcing recent contest programs, pairing real faults with repairs and locations, and exposing time-window and difficulty filters. The direction signal is benchmark hygiene for executable code tasks under leakage pressure. The quality signal is executable tests plus metadata and toolkit commands. AtCoder contests, unit tests, and coverage-based localization are not new. Reuse requires checking dataset version, AtCoder redistribution terms, CC BY-SA data terms, MIT code terms, downloaded tests, runtime, and whether public tasks have leaked into later models.
