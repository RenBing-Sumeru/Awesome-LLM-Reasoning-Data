ConDefects contributes a post-2021 AtCoder fault dataset for evaluating localization and repair methods under lower leakage risk. The original arXiv abstract reports 1,254 Java faulty programs and 1,625 Python faulty programs produced between 2021-10 and 2023-09; the repository later reports a 2024/6 update with 810 Java tasks, 985 Python tasks, 2,045 Java files, and 2,864 Python files. The feedback contract is programmatic: run tests, collect pass/fail and coverage outputs, and compare repairs/locations to released records. Closest comparisons are Defects4J-style and pre-LLM repair datasets; the direction label is leakage-aware executable code benchmark.
