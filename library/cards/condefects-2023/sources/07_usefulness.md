Use ConDefects as a contamination-aware executable code benchmark schema. Preserve task id, language, date, difficulty, faulty code, repaired code, fault location, test list, pass/fail vector, coverage matrix, subset filter, and dataset update. It is useful for evaluating repair agents, localization methods, and post-cutoff split design. For atlas reuse, separate training use, evaluation use, and audit use; the same tests can be a verifier for evaluation but should not be silently reused as reward data.
