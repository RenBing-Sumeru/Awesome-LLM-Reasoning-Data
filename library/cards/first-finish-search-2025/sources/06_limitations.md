The key assumption—correct traces tend to terminate earlier—weakens on DeepSeek-V3 and is not guaranteed across models, prompts, languages, or domains. Concise wrong guesses can win, while correct derivations that check their work can be cancelled. Hitting the maximum length is also treated as finishing in Async-FFS, which is not equivalent to a valid EOS completion.

Sync-FFS selects minimum decoding length under lock-step execution, whereas Async-FFS can be affected by endpoint latency, batching, queueing, network variance, and heterogeneous token throughput. These operational factors must be logged before treating first wall-clock completion as the same data filter. Exact-answer parsers can introduce another source of error. The linked repository lacks a verified implementation and license, and no rollout release preserves cancelled traces. Benchmark gains therefore do not establish reproducibility or trace quality.
