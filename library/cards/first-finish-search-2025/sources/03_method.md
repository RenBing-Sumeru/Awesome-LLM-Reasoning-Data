Inputs are a reasoning model M, prompt x, sample count n, stochastic decoding parameters, and maximum length L. Sync-FFS initializes n copies of the prompt, samples one next token for every active trace in one batched forward pass, and stops the whole batch when any sampled token is EOS. Async-FFS starts n decoding jobs and returns the first completed or length-limited job while cancelling the rest. There is no model update and no training-data construction stage.

The reported evaluation uses n=4, temperature 0.6, top-p 0.95, zero-shot prompting, maximum generation lengths of 32K tokens for AIME and 16K for GPQA Diamond, and a deepinfra.com API. Models are DeepSeek-R1, R1-Distill-Qwen-32B, QwQ-32B, Phi-4-Reasoning-Plus, plus DeepSeek-V3 as a non-reasoning comparison. Tasks are AIME24, two AIME25 splits, and GPQA Diamond. Accuracy uses exact answer matching; compute is reported separately as total generated tokens across parallel traces and minimum sequential tokens to obtain the selected answer.

For faithful replay, record prompt and parser versions, model endpoint, n, sampler parameters, each partial trace and token count at cancellation, EOS timestamp or decoding step, scheduler mode, maximum length, selected trace, and post-hoc correctness. The paper links https://github.com/Aradhye2002/reasoning_exps, but the checked repository page exposes no implementation files or license. Raw rollouts, request timing, seeds, and a versioned evaluation manifest are not confirmed.
