Within the Rollout, Search, and Test-Time Trace Data track, FFS is a compact case for studying selector-induced bias without a learned verifier. A trace dataset modeled on it should retain every sampled prefix, EOS and cancellation event, final parsed answer, total and sequential token counts, scheduler mode, and post-hoc correctness. The winner flag should be separate from correctness.

These records would support comparisons among first-finish, last-finish, majority vote, and verifier-guided selection at equal budgets; analysis of length as a proxy for correctness; and audits of whether API scheduling changes the selected output. They could also provide censored-trajectory data for systems research. Because the official release does not include these records, the paper is presently most useful as a construction and audit recipe rather than as a source of reusable traces.
