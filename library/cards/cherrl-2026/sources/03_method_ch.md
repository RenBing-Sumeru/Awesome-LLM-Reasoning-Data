1. 普通 LLM judge 对提示、回答和量规评分；第二个 judge 检测一种目标偏差。CHERRL 以0.5权重加入其布尔加分。

2. Qwen3-4B 在 HealthBench 或 VerInstruct 上以 GRPO 训练，并分别注入词汇、格式、语气或自我称赞偏差。每次运行保留回答、带偏/无偏分数和捷径检测器。

3. 系统平滑奖励差与高分回答的捷径频率，扫描12组阈值，取两者首次共同出现时刻的众数作为参考起点。

4. RHDA 只看由步骤、提示、回答、可见分数和量规构成的脱敏镜像；检查、分析、计算和推理工具输出带证据的告警。

复现需核验代码、judge 提示、偏差规则、rollout 日志、Qwen3-4B/GRPO 配置、数据版本和阈值协议。计算预算与 judge 服务细节未完全披露。
