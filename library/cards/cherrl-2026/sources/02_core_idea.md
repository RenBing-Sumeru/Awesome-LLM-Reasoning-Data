CHERRL is a controllable reward-hacking testbed: a dual-judge reward combines an ordinary rubric judge with a single-bias judge, making proxy-reward divergence and shortcut emergence measurable while preserving a known reference onset. It changes the usual post-hoc observation of an opaque LLM judge into an intervention where one bias is isolated. The released artifact is code and a runnable environment, not a separately downloadable training dataset; it is intended for audit, detector evaluation, and mitigation research.
