对发布物存在性的证据较强，但对逐标签回放的证据不完整。ACL Anthology 记录了 EMNLP 2025 论文及 DOI；官方仓库包含数据收集、PRM 训练、回答生成和 Best-of-N 脚本，README 链接该数据集。公开 Hugging Face API 与 Dataset Viewer 报告单一 `default/train` split、73,560 行、6 列和 MIT 许可证元数据。

论文证据支持构造主张：Table 4 给出从 16,926 个提示扩展到 73,560 个实例及其来源计数；方法部分说明 GPT-4o 对最终输出作判断，视觉 ReST-MCTS 回传细粒度价值。数据集 schema 可独立支持的仅是持久化字段，而不包括完整节点历史或终局裁决。

性能结果只是语境证据，不是每条发布标签可靠的证明。论文在其测试设置中报告 PRM 相比 ORM 平均高 1.4%，并在 Table 6 报告 ViLPRM 平均准确率 31.5、URSA 为 30.6。这些是作者在刻意筛选的评测集上的基准结果；它们不度量标签错误、裁判一致性、来源数据质量或分布外表现。
