Release evidence is strong for artifact existence but incomplete for label replay. ACL Anthology records the EMNLP 2025 paper and DOI. The official repository contains data-collection, PRM-training, response-generation, and Best-of-N scripts, and its README links the dataset. The public Hugging Face API and Dataset Viewer report one `default/train` split, 73,560 rows, six columns, and MIT license metadata.

Paper evidence supports the construction claim: Table 4 gives the 16,926-prompt to 73,560-instance expansion and per-source counts; the method states that GPT-4o judges final outputs and that visual ReST-MCTS propagates fine-grained values. The dataset schema independently supports only the persisted fields, not full node histories or terminal verdicts.

Performance is contextual evidence, not proof that every release label is reliable. On ViLBench, the paper reports a 1.4% average PRM-over-ORM advantage across its tested setting and reports ViLPRM average accuracy 31.5 versus 30.6 for URSA in Table 6. These are authors' benchmark results on a deliberately filtered evaluation set; they do not measure label error, judge agreement, source-data quality, or out-of-distribution behavior.
