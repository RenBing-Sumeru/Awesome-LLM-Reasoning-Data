ViLBench joins two related but distinct artifacts. **ViLBench** is a 600-example evaluation set designed to distinguish output-level rewards from process rewards in vision-language reasoning. **ViLReward-73K** is the training-facing release: 73,560 image-conditioned partial solutions with continuous values. The paper trains a 3B scalar process reward model, ViLPRM, on the latter and uses it to select candidate answers at test time.

The release is relevant to the rollout/search/test-time trace-data track because the published rows are not ordinary question-answer pairs. Each row represents a partial natural-language process generated during visual MCTS and carries an inferred value. The public dataset has one `default/train` split and six columns: `index`, `question`, `image_path`, `process`, `value`, and `source`.

The card separates evidence from interpretation: the published row count, schema, source mixture, paper venue, and release links are directly checkable. The full MCTS tree, reference answer, terminal judge result, rejected branches, and exact construction run are not present in the released row schema and are treated as unavailable rather than reconstructed.
