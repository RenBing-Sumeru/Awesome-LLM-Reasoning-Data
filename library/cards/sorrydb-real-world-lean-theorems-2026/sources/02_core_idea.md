The main contribution is a dynamically updated database of real-world Lean tasks together with public evaluation infrastructure. SorryDB monitors active projects indexed by Reservoir and extracts open proof obligations from 78 real formalization repositories. Its nightly database records repository URLs, branches, commits, Lean versions, source coordinates, and the information needed for local reproduction.

The paper evaluates a fixed snapshot, `SorryDB_2601`: the complete snapshot contains 2,601 `sorry` statements, with 1,000 selected for the public evaluation split. The project also releases the crawler, template agents, an independent compilation verifier, result formats, and a leaderboard, allowing the data to serve both as a dynamic benchmark and as training material for retrieval and repair agents operating in real Lean projects.
