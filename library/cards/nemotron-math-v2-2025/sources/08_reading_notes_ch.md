- 定位：Nemotron-Math 为奥数与社区数学题生成 750 万条多推理预算、可选 Python 工具的长解答。
- 数据对象：750 万条解答轨迹，覆盖 8.5 万道 AoPS 题与 26.2 万道 Math StackExchange 题，单条记录包含记录编号、题目、预期答案、来源、消息、多数修正标记和用途切分。
- 生成与筛选：gpt-oss-120b 生成三档推理及有无 Python 工具的六种模式，并依据答案验证、多数答案修正标记、来源筛选和匹配下游测试保留。
- 证据锚点：在匹配 AoPS 题目上，Nemotron-Math 持续超过 OpenMathReasoning；加入 StackExchange 数据提升 HLE-Math，顺序分桶还把 128K 上下文训练加速 2 至 3 倍且未报告显著损失。
- 复用决定：适合长上下文数学推理监督微调；先审计多数答案修正可能收敛到多个教师共有的错误和署名相同方式共享子集要求按来源处理再分发。
