Use AppWorld as a reference schema for stateful tool/API-agent evaluation. Preserve task ID, app set, API docs, initial database state, hidden user context, agent code/actions, observations, final database state, direct success tests, collateral-damage tests, and budget. It is useful for recipes that need executable feedback without live-service drift. For atlas curation, it is a strong example of keeping the environment state and verifier contract alongside the model trajectory.
