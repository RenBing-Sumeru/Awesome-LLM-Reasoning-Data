Official sources describe a benchmark with 9 day-to-day apps, 457 APIs, and 750 tasks. The paper reports that frontier agents still solve only a minority of tasks, with the abstract naming a 48.8% success rate for the best model at the time and a human estimate of 100%. The decisive evidence for a row is not the aggregate score; it is whether the final state satisfies the task-specific unit tests while avoiding collateral damage. The boundary is evaluator coverage, API realism, sandbox version, task split, and scaffold budget.
