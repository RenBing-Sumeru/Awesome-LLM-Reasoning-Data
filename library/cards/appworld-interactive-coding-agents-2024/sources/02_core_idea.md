AppWorld contributes a sandboxed world of apps and people for benchmarking agents that solve tasks by writing code against APIs. The core mechanism is to expose many app APIs and hidden user/world state, let the agent interact programmatically, and grade the final database/state with unit tests. The closest comparisons are WebArena/OSWorld-style environments, tool-use benchmarks, and static API-calling datasets. The direction label is stateful API-agent evaluation: the feedback contract checks both task completion and unintended side effects.
