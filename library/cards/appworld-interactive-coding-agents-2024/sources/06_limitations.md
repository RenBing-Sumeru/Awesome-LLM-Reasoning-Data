AppWorld correctness is bounded by the fidelity of simulated apps and by unit-test coverage. Passing tests proves the encoded state predicates, not every natural-language intent or all possible side effects. Because the environment is synthetic, scores may not transfer to live apps with messy authentication, changing APIs, or ambiguous user preferences. Public tasks and API docs can become training contamination. Reported scores should be compared only with pinned split, package, scaffold, prompt, execution budget, and evaluator settings.
