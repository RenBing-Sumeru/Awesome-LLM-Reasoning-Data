Prior tool-use benchmarks often use stateless calls, final-answer grading, or live web environments with limited controllability. AppWorld changes the object by making a synthetic but stateful app ecosystem whose database state can be inspected after agent actions. The direction signal is controllable interactive coding-agent evaluation with programmatic side-effect audits. What is not new: API calling, unit tests, and simulated environments. Reuse checks must inspect task generation, split leakage, unit-test coverage, API documentation fidelity, package versioning, and license terms.
