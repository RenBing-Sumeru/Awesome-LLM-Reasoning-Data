Primary source: arXiv 2407.18901, ACL 2024 camera-ready status, and the official AppWorld project/repository. The problem is that interactive coding agents need a controllable, stateful app world where success can be checked after real API calls, not only by final text. AppWorld belongs here as an agent-environment benchmark with programmatic state verification; it is not a generic function-calling dataset. The evaluation surface is a task instruction, simulated people/apps, API calls written by the agent, world-state changes, and state-based unit-test outcomes.
