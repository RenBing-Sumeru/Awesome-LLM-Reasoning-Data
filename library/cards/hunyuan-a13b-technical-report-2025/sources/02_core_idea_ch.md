这份披露应拆成四个相互衔接、但不能混写的数据契约。

1. **推理 SFT。** 数学数据来自教育材料，并由生成式奖励模型与自动解题验证共同筛选；代码来自开源资源，经过构造流水线、critic 与 sandbox 执行；逻辑数据混合版权受限和公开的谜题集以及合成题目，再通过自动思维链评价和人工审查；科学数据先做难度与质量筛选，再由高级 LLM 验证并通过拒绝采样保留。
2. **推理 RL。** 150,000 道题按数学、代码、逻辑、科学 2:2:1:1 混合，其中 10% 与 SFT 重叠，90% 被报告为新题。GRPO 的结果奖励来自归一化后的答案—参考答案匹配，或代码 sandbox 测试。
3. **全场景 SFT。** 数据扩展到语言、写作、多语、指令遵循、角色扮演、知识问答、多轮对话和 agent。Agent 轨迹由 user、planner、tool、agent、checker 五类角色合成，工具来自真实 sandbox、MCP server 与合成工具。
4. **全场景 RL。** 一个通用奖励模型和 30 多个评分服务覆盖 16 个子主题；agent 评分把格式检查与基于参考的工具调用正确性结合起来。

最终模型支持 /think 与 /no_think 两种模式，并用特殊 think block 承载推理。报告没有披露内部记录的序列化 schema。
