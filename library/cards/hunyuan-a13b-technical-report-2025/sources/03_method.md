**Foundation and context preparation.** The report reuses the Hunyuan-TurboS-family pretraining pipeline: preprocessing, deduplication, low-quality filtering, denoising, topic labels, model-assisted extraction, and postprocessing with semantic deduplication. It reports more than 20T foundation tokens, a strengthened 250B STEM subset, a 300B-token fast-annealing phase, and context extension first to 32K and then 256K. These are aggregate corpus/process claims; record manifests are absent.

**Domain-specific SFT controls.** Each reasoning domain has a different feedback path rather than one universal judge. Mathematics combines a generative reward model with automated solution verification. Code uses critics and a sandbox. Logic uses automated chain-of-thought evaluation plus human review. Science uses an advanced LLM verifier and rejection sampling. The generator models, thresholds, acceptance rates, and reviewer protocol are not given.

**On-policy reasoning RL.** GRPO trains on 150K problems with a 2:2:1:1 domain ratio. Multiple-choice, true/false, and proof tasks are excluded. The curriculum moves from 24K to 32K context. The report states that training is on-policy, uses large batches, increases the number of sampled rollouts, omits a KL penalty, and samples at temperature 0.6-0.8. Exact rollout multiplicity, batch size, learning rate, and step count are unknown.

**All-scenarios agent construction and feedback.** The synthesis engine separates user, planner, tool, agent, and checker roles. It uses sandbox tools, MCP servers, and synthetic tools, covers more than 30 types of agent system instruction, and creates 20,000 tool/action/response format combinations, with emphasis on tasks such as Excel and deep search. All-scenarios RL uses candidate/reference comparison, optional chain-of-thought, tool calls, and length/constraint checks; more than 30 services score 16 subtopics. Agent reward checks special-marker order and tool names, parameters, and values against references. Environment snapshots and scoring weights are not released.
