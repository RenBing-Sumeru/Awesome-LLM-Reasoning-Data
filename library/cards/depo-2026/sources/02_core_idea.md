DEPO treats data-efficient RLVR as a coordinated three-stage allocation problem: select a compact offline prompt subset using diversity, influence, and difficulty; route online rollout effort using each sample's explorability under the current policy; and replay under-explored samples in later updates. The resulting data object is dynamic: a prompt and its offline selection scores, policy-generated answer-level rollouts and rewards, explorability estimates, retain/filter decisions, and replay history. It is a data-allocation recipe rather than a public standalone corpus.
