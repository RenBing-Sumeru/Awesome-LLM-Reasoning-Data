实验只覆盖 POGS 与 Crafter，使用 Llama-3.3-70B-Instruct 作为 teacher/zero-shot model、Llama-3.1-8B-Instruct 作为可训练 actor。最优 planning frequency 可能随 model capability、environment dynamics、observation format、context limit、action space 或 reward horizon 改变。POGS 与 Crafter 会在智能体响应时暂停，因此没有真实 latency cost；planning cost 仅以生成 token 近似，没有评估 wall-clock latency、价格、能耗或内存。

Synthetic SFT set 继承 teacher 的 plan quality 与 16 个手写 plan style；interval 只从固定的 2–12 范围采样，未披露的 temperature、seed、filter 和 split rule 限制可审计性。主 PPO reward 只隐式反映不稳定性；早期显式 shaping 会使模型回避规划，说明结果对 reward 很敏感。Natural-language plan 可能 drift、与状态冲突，或 plan 本身正确但 acting policy 未核实前置条件。History 截断到 16 个 observation 也可能删除判断 plan 有效性所需的证据。Human-guided completion 依赖重复 Best-of-N 尝试，不是自主 success rate 证据。Decontamination、data license、raw trajectory release、model release、准确 terminal rule 和可访问的固定 implementation 都仍为 unknown。报告的 benchmark 提升不能证明 trace 或 reward quality。
