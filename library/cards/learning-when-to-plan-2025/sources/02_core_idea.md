The method represents dynamic planning inside one monolithic LLM rather than as separate planner, router, and actor networks. Conceptually, a decision policy chooses whether to replan, a planning policy writes a new natural-language plan, and an acting policy emits the next command; operationally, all three are encoded in one output string. BALROG detects planning when the string begins with a plan block, stores that plan in subsequent context, extracts the action in either case, and executes it in the environment. The decision boundary is state dependent: a new plan should be generated when its expected improvement in future task value exceeds token cost and the implicit risk of plan drift or unstable replanning.

Training has two stages. Synthetic SFT exposes Llama-3.1-8B-Instruct to trajectories containing both planning and non-planning steps so that optional plan emission is already in its behavior distribution. PPO then optimizes the joint decision/plan/action policy using Crafter task rewards. The main feedback contract is environmental and episode-coupled, not a textual plan verifier: useful plans should lead to better future achievements, while excessive or inconsistent replanning can lower the same return. Planning-token penalties of -0.001 and -0.005 per token are studied as ablations, but explicit shaping for invalid actions, long responses, and frequent planning initially caused the agent to avoid planning, so the main setup removes that shaping.
