对 Rollout, Search, and Test-Time Trace Data，论文提供了一套自适应 agent compute 的具体 schema：episode/timestep ID、environment seed、observation 与 history truncation 边界、previous plan、prompt style、teacher planning interval、可选 plan block、plan-token count、action、parser/fallback result、transition、稀疏 achievement reward、planning penalty，以及之后保留或替换 plan 的 decision。把 plan decision 与 action 分开，可以分析计算被分配在何处、plan 是否得到执行，以及 reward 是否在多个 step 后才出现。

1,024 条 teacher trajectory 原则上可用于 SFT priming，PPO environment rollout 可用于 agent training；但缺少这些记录和可运行 implementation 时，两种用途都不能直接复现。该方法还提供评估设计，用于比较相同 action sequence 在有无 plan text 时的差异、fixed planning schedule、learned dynamic allocation 与 human-supplied plan。复用者不能把证据扩大到任意 RL domain；应先固定 model 与 BALROG revision，恢复 seed 与 terminal predicate，检查 teacher 和 rejected output，测量真实 inference cost，并区分 autonomous、Best-of-N 与 human-steered outcome。
