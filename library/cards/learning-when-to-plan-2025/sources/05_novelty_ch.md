ReAct 与 fixed-frequency plan-and-act 智能体按固定规则分配 reasoning，而 classical planning system 往往使用独立 planner 或显式 search procedure。本文改为训练一个 LLM，通过可选的自然语言 plan emission 暴露逐 timestep 的二元 compute decision。它的受控 SFT 比较使用相同 action sequence，仅改变是否保留 plan text；之后 PPO 再把这一决策与环境后果关联。这样的组合使 planning allocation 在轨迹中可观察，也可通过 token-cost penalty 调节。

Natural-language plan、behavior cloning、PPO、稀疏环境 reward、fixed-frequency ablation 和 plan-conditioned action generation 分别都不是新技术。方向信号在于用它们学习“何时重新生成 plan”，而不是要求每个 action 前都规划。对本图谱，可复用对象应保留 observation/history、previous plan、是否规划的 decision、新 plan token、action、token cost、environment transition、reward 和后续 replanning event。Benchmark progression 是 Crafter/BALROG 下 learned policy 的证据，不是 data-quality label。由于未发布 SFT/RL record，无法检查观察到的自适应行为是广泛存在，还是集中于某些 prompt style、interval、seed 或 achievement。
