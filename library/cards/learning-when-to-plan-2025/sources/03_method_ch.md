
SFT 阶段由 Llama-3.3-70B-Instruct 生成 1,024 条 Crafter trajectory。系统从 16 个 planning prompt 中均匀采样一个，覆盖 immediate subgoal、milestone、短 action sequence、information gap、high-level strategy 等 plan style；每条轨迹还从 2 到 12 中均匀采样一个固定 planning interval。在 planning step，teacher 输出 plan 加一个 action；其他步骤只根据上一 plan 与 observation 输出 action。Dynamic SFT target 保留这种混合输出，但统一配对一个 prompt，要求 student 只在必要时新建或修改 plan。Action-only 对照删除全部 plan block，同时保留相同的底层 action，使 plan representation 成为受控差异。History 最多保留 16 个 observation。

随后对 Llama-3.1-8B-Instruct 做无 LoRA 的全参数 SFT，使用 AdamW、learning rate 5e-6、8,192 context、DeepSpeed ZeRO Stage 3；SFT 配置还报告 KL coefficient 0.1、每 batch 384 个 rollout、rollout length 16 与 history length 16。PPO 使用 8B Llama-3.1 actor 和 1B Llama-3.3 critic，分别配置 RSLoRA adapter，以 vLLM 生成，并通过 BALROG/Ray 处理环境交互；六张 GPU 用于训练，两张用于数据收集。RL 设置包括最大 200 output token、每 batch 192 个 rollout、rollout/history length 16、temperature 1.0、actor/critic AdamW learning rate 5e-6、KL 0.05、一个 PPO epoch、policy clip 0.2、value clip 1.0、gamma 1.0 与 GAE 0.95。总训练 rollout 数、SFT 生成 temperature、episode seed、filter/rejection rule、准确 terminal predicate、train/evaluation split 和 checkpoint 选择规则仍为 unknown。论文链接了匿名 codebase，但本次审计无法访问其 README 与文件，因此 implementation 尚未核验。
