

Sequential agents must decide not only what action to take but whether the current state warrants extra tokens for a new plan. ReAct-style planning before every action incurs repeated inference cost and can destabilize long-horizon behavior, whereas never planning removes an explicit mechanism for updating strategy after new observations. The paper studies this allocation problem in two language-mediated environments: Partially-Observable Graph Search (POGS), which isolates navigation and backtracking under uncertainty, and Crafter through BALROG, which requires survival, resource gathering, crafting, and 22 sparse-reward achievements.

The curation object is the interleaved planning trajectory rather than a final benchmark answer. At each timestep, the context contains recent observations, actions, and a current plan; the model either emits only one environment action or first emits a plan-tagged block and then one action. The presence of the block is the planning-allocation decision, its text is the allocated test-time computation, and later task reward supplies environmental feedback. The paper constructs 1,024 synthetic Crafter trajectories for SFT and then gathers PPO rollouts, but neither the synthetic dataset nor the RL trajectories were verified as a public release. This makes the work relevant to Rollout, Search, and Test-Time Trace Data as a recipe and scaling study, not as an established downloadable trace corpus.
