Zero-shot study 在 POGS 与 Crafter 中分别用 100 个 seed 评估 Llama-3.3-70B-Instruct，并改变固定 planning frequency。Performance 与 output-token cost 呈非单调关系：中间频率优于 never planning 和 always planning，POGS 的 always-plan 条件产生最多 backtracking。这证明了所测试 prompt 与环境中的 compute/performance trade-off，但本身不能证明模型已经学会按状态分配计算。

训练实验在 base-plus-PPO 与 SFT-plus-PPO 条件下比较 dynamic-plan 和 action-only 模型。论文报告：在相同 action sequence 上，带显式 plan 的 SFT 比删除 plan 的版本取得更高 Crafter progression；plan-aware SFT 后继续 PPO 可提升 sample efficiency 并达到更高级 achievement；而 base-plus-PPO dynamic planning 反而差于 base-plus-PPO action only。定性轨迹展示了低 health 时的 replanning，也展示了一个听起来合理的 iron-pickaxe plan 因未检查 furnace accessibility 而执行失败。在单独的 human-steering Best-of-N 分析中，plan-aware SFT+PPO 智能体在约 20 次尝试后于 human plan 指引下完成 Crafter；自主智能体没有完成。这些结果是对 method 与 policy 的证据，不证明未公开的 SFT trajectory、reward 或 planning decision 整体正确。尚未核验公开 dataset、训练后 checkpoint 或当前可检查的 code snapshot。
