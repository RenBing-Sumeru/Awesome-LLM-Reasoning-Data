
For SFT, Llama-3.3-70B-Instruct generates 1,024 Crafter trajectories. One of 16 planning prompts is sampled uniformly, covering immediate subgoals, milestones, short action sequences, information gaps, high-level strategy, and related plan styles; a fixed planning interval is also sampled uniformly from 2 through 12 for each trajectory. At planning steps, the teacher emits a plan plus one action; at other steps it emits an action based on the previous plan and observations. The dynamic SFT target preserves those mixed outputs but pairs them with one prompt that tells the student to create or revise a plan only when necessary. The action-only control removes every plan block while retaining the same underlying actions, making plan representation the controlled difference. Histories are truncated to 16 observations.

Llama-3.1-8B-Instruct is then fully fine-tuned without LoRA using AdamW, learning rate 5e-6, context 8,192, DeepSpeed ZeRO Stage 3, and an SFT configuration reporting KL coefficient 0.1, batch rollouts 384, rollout length 16, and history length 16. PPO uses an 8B Llama-3.1 actor and 1B Llama-3.3 critic with separate RSLoRA adapters, vLLM generation, BALROG/Ray environment handling, six training GPUs and two collection GPUs. Reported RL settings include maximum 200 output tokens, 192 rollouts per batch, rollout/history length 16, temperature 1.0, AdamW actor/critic learning rates 5e-6, KL 0.05, one PPO epoch, policy clip 0.2, value clip 1.0, gamma 1.0, and GAE 0.95. The total training rollouts, SFT generation temperature, episode seeds, filtering/rejection rules, exact terminal predicate, train/evaluation split, and checkpoint selection rule are unknown. The paper links an anonymous codebase, but its README and files were not accessible during this audit, so the implementation remains unverified.
