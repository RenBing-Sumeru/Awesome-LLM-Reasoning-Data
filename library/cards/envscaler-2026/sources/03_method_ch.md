输入与 discovery。source pool 来自 API-Bank 和 ToolACE。任务先按有状态、领域特定的工具交互筛选，再由 LLM 转换成环境描述，随后 embedding 与 deduplication。GPT-4.1 和 Qwen3-235B-Instruct-2507 支持 discovery/programming；GPT-4.1-mini 与 Qwen3-30B-A3B-Instruct-2507 支持 checking/assessment。逐记录 upstream ID、source-mixture weight、完整 transformation prompt、model endpoint 日期、decoding setting 与 retry policy 均未发布。

环境合成与选择。SkelBuilder 生成 Python state、constraint、operation/tool、class code、definition 与 documentation。论文报告共合成 266 个 candidate。每个 candidate 接受 100 轮检查；发布 selector 在 not_fail_num / total_num 至少为 0.85 时保留环境。分子把 pass 与 warning 合并，因此 0.85 是 pass-or-warning threshold，不是严格 85% correctness rate。该过程保留 191 个环境并拒绝 75 个，即 28.2%；被拒 program 与完整 check-agent record 不可得。

scenario 构造。ScenGenerator 合成 initial configuration、task text、checklist item 和 executable Python Boolean check function。SFT 分支选择 140 个环境，发布 4,684 条 task/configuration row，并有意省略 check function。RL 分支使用其余 51 个环境，发布 2,550 条带 checklist_with_func 的 task/configuration row。split seed、除 140/51 数量之外的 selection policy、semantic overlap 与 decontamination analysis 均为 unknown。

SFT 交互与过滤。Qwen3-30B-A3B-Thinking-2507 生成 conversation 与 non-conversation trajectory。公开 filtering path 会拒绝 invalid syntax、incomplete episode、被 LLM 判断 impossible 的 task，以及 action 数不在 non-conversation 3–29 或 conversation 5–39 范围内的 trajectory。non-conversation 保留要求出现 Task Completed；conversation 保留要求 user 输出 ###STOP###。最终保留约 9K，固定 dataset 声称有 9,022 条 trajectory。由于 SFT scenario 省略 check、SFT environment 返回 zero reward，这属于 format/completion/action-count filtering，而不是 terminal-state success verification。

SFT optimization。论文与 configuration 使用 full-parameter LlamaFactory SFT，训练三个 epoch，learning rate 为 1e-6，maximum length 为 32K，effective batch size 为 256。多轮 example 使用 mask_history，只监督 final-turn reasoning/action。scaling study 训练 Qwen3-1.7B、Qwen3-4B 与 Qwen3-8B variant；每次 run 的确切 model-artifact revision 没有绑定在同一 manifest 中。

RL 交互与 reward。RL 使用 non-conversation interaction、ROLL/Reinforce++、KL coefficient 0.1，每个 update step 采样 64 个 task、每题 8 条 rollout，最多约 200 step。这意味着每个 update step 有 512 条 online rollout，而不是已发布 corpus。论文设置 maximum trajectory length 32K、每次 interaction generation length 4K；example configuration 还使用 seed 42、temperature 0.99、top-p 0.99、top-k 100、learning rate 1e-6、max_steps 201 和 max_actions 40。最终 reward 是通过 Boolean check 数除以 check 总数。

runtime 与 safety。interaction runner 可以保留 task information、tool、message、user message、逐步 observation/action/reward、terminated/truncated flag、total reward、final observation/information 和 step count。该 schema 是 runtime capability，不是 RL episode 已发布的证据。environment class string 与 check-function string 通过开放 builtins 的 Python exec 执行。该代码不是 security sandbox；任何 replay 都必须把这些 artifact 当作不受信任的 executable code 进行隔离。
