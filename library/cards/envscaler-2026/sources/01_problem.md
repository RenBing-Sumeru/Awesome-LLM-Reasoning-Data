The authoritative paper record is arXiv:2601.05808v2, revised on 2026-04-17; no formal conference or journal venue is verified, so the venue remains arXiv preprint. The evidence freeze also covers the official RUC-NLPIR/EnvScaler repository at commit 87e667397abacf274858c0964796beb8f984aafe and four official Hugging Face dataset revisions. EnvScaler addresses a concrete bottleneck in agent post-training: executable, stateful tool environments and outcome checks are expensive to author, so environment variety can lag behind model and rollout scale.

The paper turns environment scale into a data-construction variable. Starting from stateful, domain-specific API-Bank and ToolACE tasks, the pipeline induces environment descriptions, removes near-duplicates, generates executable Python worlds, checks them repeatedly, synthesizes initialized scenarios and terminal-state check functions, and then collects SFT trajectories or performs online RL. The resulting object is not one monolithic “agent dataset”; it is a linked bundle of environment code, scenarios, trajectories, and feedback programs.

The verified public bundle has four distinct objects: 191 executable environment rows; 4,684 SFT scenario rows across 140 environments without check functions; 2,550 RL scenario rows with executable checklist functions; and 9,022 claimed SFT trajectories generated by Qwen3-30B-A3B-Thinking-2507. The 4,684 and 2,550 scenario releases total 7,234. Runtime code can serialize richer episodes with observations, actions, rewards, termination and truncation, but no RL rollout corpus or complete paper-run replay archive is released.

This Card belongs in environment_agent_trajectory_data because environment state, tool schema, agent action, observation, terminal check, scalar reward, and trajectory are all material to the training interface. Evidence supports SFT, RLVR-style outcome training, and agent training; it does not support preference learning, reward-model training, process supervision, or use of EnvScaler as an evaluation dataset.
