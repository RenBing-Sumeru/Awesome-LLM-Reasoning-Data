Prompt sourcing starts from the Sky-T1 difficulty-labeled version of NuminaMath. The fixed set balances 1,667 MATH problems with difficulty above 3, 1,667 Olympiad problems with difficulty above 8, and 1,666 AIME/AMC problems. The paper reports random sampling within these strata, but the released rows do not expose upstream record IDs, source URLs, or a decontamination ledger.

Eleven named reasoning teachers, spanning 4B to 671B parameters, each generate one response for every prompt in three independent vLLM runs. This produces 11 x 3 x 5,000 = 165,000 candidates. Teacher-specific recommended chat templates and sampling settings are used; the paper gives Qwen settings of temperature 0.6, top-p 0.95, top-k 20, and min-p 0, but does not enumerate every teacher's full decoding contract. Generation has a 31,000-token budget. Over-budget outputs are resampled up to ten times and truncated if all attempts remain too long; final truncation is reported below 1%.

Each released JSON row contains only a three-message conversation: a fixed system instruction requesting step-by-step reasoning and a boxed final answer, the original problem as the user message, and one teacher trajectory as the assistant message. Raw files are organized by teacher and run. For every target student and prompt, the student model performs a forward pass over each of the 33 assistant responses, obtains token surprisals and clipped ranks, and selects the minimum-RSR response. This yields five student-specific files of 5,000 rows each. The selected rows retain the messages but not teacher/run, RSR components, correctness, candidate rank, or rejection reason.

The five pretrained base students are Qwen-3-14B, LLaMA-3.1-8B, Qwen-2.5-7B, Qwen-3-4B, and Qwen-2.5-3B. SFT uses LLaMA-Factory with FlashAttention-2, batch size 64, maximum sequence length 32,768, and learning rate 2e-5 except 5e-5 for Qwen-2.5-3B. Qwen-3-14B trains for 8 epochs; the other students train for 10. Trajectory-selection experiments use three fine-tuning seeds, whereas teacher-student distillation averages three independently generated teacher datasets without additional fine-tuning seeds.

Evaluation uses vLLM and Math-Verify on AIME 2024, AIME 2025, AMC 2023, and MATH500 with Acc@4; GPQA-Diamond is an additional evaluation-only surface. Inference uses temperature 0.6, top-p 0.95, top-k -1, and a 32,768-token maximum. The paper reports that scoring 5,000 trajectories with a 7B student takes under one hour on one H200 with FlashAttention-2, while a 7B SFT run takes about seven hours on eight H200 GPUs. A teacher-selection variant scores 200 sampled trajectories from each of six teachers and ranks teacher-level aggregates.

The official GitHub repository publishes a cleaned RSR implementation and MIT license; the Hugging Face release is also labeled MIT and exposes the 33 raw files plus five selected files. The current code later added multi-round, agent, and multimodal input support, but those extensions are not validated by the ACL paper's experiments and should not be treated as evidence of cross-domain effectiveness.
