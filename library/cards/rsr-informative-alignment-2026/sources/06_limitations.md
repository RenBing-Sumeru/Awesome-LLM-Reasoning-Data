- Minimum RSR always chooses a candidate. If all 33 responses are wrong, truncated, stylistically unsuitable, or otherwise poor, the default recipe still returns one because RSR is not a verifier and has no reject-all threshold.
- Scores are student- and implementation-conditioned. Checkpoint revision, tokenizer, chat template, assistant-span detection, maximum context, numerical precision, and r_max affect rank and surprisal. A set selected for one base student is not established as optimal for another checkpoint or an instruction-tuned variant.
- The selected files omit source teacher/run, upstream prompt ID, RSR numerator and denominator, correctness, complete candidate ranking, and rejection reasons. Although raw candidates are public, the selected messages alone do not provide a deterministic join to the other 32 alternatives.
- Exact, near-duplicate, and semantic decontamination are unknown. Training prompts derive from MATH, AIME/AMC, and Olympiad portions of NuminaMath, while evaluation includes MATH500, AMC 2023, and AIME 2024/2025; no released overlap/removal ledger resolves this risk.
- The Hugging Face release and GitHub code are labeled MIT, but released rows lack record-level upstream attribution and license provenance for NuminaMath-derived prompts and outputs from all 11 teacher models. The repository license alone does not establish a complete redistribution chain.
- Correlation uses 11 teacher-level points per student and reports absolute Spearman values. Trajectory-selection experiments average three fine-tuning seeds, but the teacher-distillation grid varies generation runs rather than fine-tuning seeds. Benchmark results therefore have different uncertainty sources and do not prove record-level quality.
- The candidate distribution is not neutral. QwQ-32B supplies 45.1%-76.6% of selected rows, so student-specific gains may also encode teacher style and candidate-pool composition. A new pool with weaker diversity or no suitable trajectory can reduce the selector's value.
- Below 1% of trajectories are ultimately truncated after repeated over-budget generation, potentially leaving incomplete reasoning or final answers. The release does not expose truncation flags in each message row.
- Experiments focus on mathematical SFT for five Qwen/LLaMA-family pretrained base students. GPQA is evaluation-only; code, commonsense, newly generated data, general-text subset selection, multimodal records, and agent trajectories are not validated by the paper. Later code support for broader formats is an implementation feature, not evidence of selection effectiveness.
