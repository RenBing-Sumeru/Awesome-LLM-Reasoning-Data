The distinctive contribution is the coupling of data construction with a reward-hacking analysis for open-ended factual reasoning. Earlier factuality pipelines could rank answers offline, but online optimization exposes different failure modes: precision favors abstention or brevity, supported-claim counts can reward tangents, and a relevance judge can itself be noisy. This work makes those competing objectives part of one explicit post-training recipe and supplies an accelerated VeriScore service intended for the training loop.

For data curation, the useful novelty is not the number of examples. It is the lineage from grounded prompt synthesis, through ten-way candidate generation and verifier-based SFT/DPO selection, to fresh current-policy GRPO rollouts. The released SFT and DPO rows let a curator inspect the static endpoint of the offline stages, while the code documents how online prompts would be converted and scored. The artifact boundary is equally important: online trajectories and the retrieval evidence behind their rewards remain unreleased, so the public object is an open recipe with partial data, not a complete replayable run.
