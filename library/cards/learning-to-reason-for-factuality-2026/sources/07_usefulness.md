For the Construction & Open Releases track, this paper is useful as a compact case study in separating what is released from what is only executable. The SFT file can support studies of long-CoT formatting, factual-answer distillation, and response-level filtering. The DPO file supports preference-learning experiments in which score margin and response-length controls are available as audit fields. Because the two schemas are simple JSONL, researchers can also test alternative filters or compare selected-response distributions without running the online verifier.

The recipe is useful for studying data-process questions that a benchmark score cannot answer: how ten-way sampling changes the retained set; how length matching alters DPO pairs; whether a relevance term reduces tangential but correct answers; and how verifier errors propagate into policy updates. The offline release and online recipe also form a natural comparison between fixed synthetic supervision and on-policy data.

These uses require scope discipline. The release is suitable for reproducing or modifying the offline SFT/DPO inputs and for reimplementing the online scaffold. It is not sufficient to replay the reported GRPO run exactly, because the original online prompt set, trajectories, live search state, and reward logs are missing. Commercial or redistributed-model use additionally requires a license review.
