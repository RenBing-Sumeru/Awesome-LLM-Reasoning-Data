The report describes a three-stage agentic-SFT synthesis pipeline: create a repository of real and synthetic tool specifications, generate agents and rubric-backed tasks for sampled tool sets, then generate tool-invoking trajectories. It reports more than 3,000 real MCP tools fetched from GitHub repositories and more than 20,000 synthetic tools. The system pairs scalable simulation with targeted real execution environments for coding and software engineering.

Its joint RL framework combines verifiable rewards with self-critique. The disclosed contracts include executable tests, deterministic instruction checks, LLM judges, a hack-check, a faithfulness reward model, safety judges, and a K2 critic that performs pairwise rankings with several types of rubric. The report gives stage-level interfaces, not released data objects or complete verification artifacts.
