The official report supports the numerical disclosure of more than 3,000 real MCP tools and more than 20,000 synthetic tools, plus the stated tool-to-agent/task/trajectory construction path. It also supports the existence of rubric-based LLM filtering, a stateful simulator, targeted real execution sandboxes, a Kubernetes SWE sandbox reported to support more than 10,000 concurrent instances, and a joint RL design that includes RLVR and self-critique.

Appendix B discloses the tool-call message structure: a declaration containing available tools and argument schemas, an assistant invocation section, and a tool-result message. It states that TypeScript is used for concise declarations and that part of training data uses JSON declarations for compatibility. This is interface evidence, not a release of the tool-training corpus, parsers, constrained-decoding implementation, or coverage audit.

The official repository and Hugging Face page support availability of code/documentation and model weights under Modified MIT. They do not establish reproducibility, data rights, environment availability, verifier validity, critic calibration, or protection against reward hacking. Reported model performance is evidence of the authors' evaluations, not evidence that those missing artifacts are available.
