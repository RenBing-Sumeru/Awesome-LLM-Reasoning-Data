# Usefulness

- **Math SFT builder:** use the public source/type fields to construct CoT-only, PoT-only, or hybrid mixtures; output matched-token ablations and check in/out-of-domain accuracy.
- **Executable-data auditor:** rerun PoT records in a pinned Python sandbox, compare outputs with references, and report execution and answer-agreement rates by source.
- **Do not use when:** one permissive license is required or the target task cannot execute Python safely; first filter licenses or replace the PoT contract.
