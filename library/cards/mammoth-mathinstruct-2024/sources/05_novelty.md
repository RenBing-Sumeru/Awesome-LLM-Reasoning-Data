# Novelty

Earlier math SFT recipes often specialize on a narrow source or train only natural-language CoT, which weakens field coverage or executable reasoning. MathInstruct changes the training record mixture by combining 13 sources with both CoT and PoT targets, adding missing rationale types where necessary. This lets one SFT consumer learn complementary linguistic and computational solution forms. Instruction tuning, CoT, PoT, and program execution are individually not new.
