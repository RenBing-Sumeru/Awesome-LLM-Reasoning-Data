The prior baseline is scattered robustness tests for individual LLM-judge biases, such as position, verbosity, self-preference, and prompt wording. CALM changes the scope by organizing a broader 12-bias taxonomy and automating perturbation-based measurement under a unified framework.

The direction signal is that judge evaluation needs its own benchmark-quality audit before judge labels are treated as gold labels or rewards. The quality signal is a public project page, code/data repository, explicit bias taxonomy, and cross-model experiments. What is not new: using LLMs as judges, perturbation testing, and score-shift metrics. Before reuse, inspect perturbation validity, parser robustness, judge model versions, prompt leakage, license, and whether the measured bias transfers to the target domain.
