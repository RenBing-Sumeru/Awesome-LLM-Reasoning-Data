This is not a data release. Its distinctive Track 12 value is a partial, multi-layer disclosure of a routed frontier system. The report names real router feedback signals rather than only saying that routing exists, describes output-centric safe-completion training rather than only listing a refusal policy, and identifies parallel test-time compute as a separate inference setting. Together these disclosures expose more of the system boundary than a single-model benchmark table would.

The report is also useful because it makes several attribution boundaries visible. Production-representative conversations appear as evaluation inputs and, for sycophancy, as the basis for a score used as a reward signal; the card does not establish that every production benchmark enters training. Biological safeguards combine training and operational controls. Factuality, safety, and capability results measure behavior under specified graders and settings, not the quality, legality, coverage, or provenance of the training mixture.

The novelty for this atlas is therefore the disclosure ledger itself: coarse source categories, a few named feedback fields, a safety objective, a routed inference scaffold, and an extensive release audit, paired with explicit unknowns. It is not a reproducible GPT-5 recipe, a released router dataset, or proof that benchmark gains came from a particular data intervention.
