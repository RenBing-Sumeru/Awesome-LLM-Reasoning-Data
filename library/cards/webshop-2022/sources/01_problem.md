WebShop: Towards Scalable Real-World Web Interaction with Grounded Language Agents asks how to close this gap: Grounded language agents need a scalable interactive shopping environment with real product language and rewards, not only static QA or expensive live-web experiments. The primary source is https://arxiv.org/abs/2207.01206; public status is NeurIPS 2022 / arXiv (2022).

Decision boundary: It is collected as a simulated e-commerce environment and reward-bearing benchmark, not as a live commerce site. The evaluation surface is a user shopping instruction, simulated product catalog page state, search/browse/customization actions, selected item, reward components, and optional human demonstration trajectory. This makes the paper useful for the atlas because the data object and feedback rule can be audited together.
