**Judge and label validity.** Claude 3.5 Sonnet decides whether each Qwen attempt matches the source solution and assigns domains; Claude 3.7 later judges final Gemini correctness. Public feature tables keep Boolean decisions but omit Qwen attempts, Claude rationales, calibrated human audits, and API snapshots. False accepts/rejects can alter both difficulty filtering and the reported 53.6% rate. Long traces can reflect verbosity, looping, or early mistakes rather than difficulty or useful reasoning.

**Selection bias and non-determinism.** Difficulty is defined by failure of Qwen2.5-7B/32B, so s1K may over-select examples idiosyncratically difficult for the target model family. The paper's uniform-domain algorithm and notebook's two-phase domain schedule differ. The notebook sets no NumPy seed; final item IDs, ranks, probabilities, and selection ledger are absent. Exact s1K cannot be regenerated from the checked notebook alone.

**Broken intermediate chain.** `qfq/train` and `qfq/train_featurized` each expose 59,029 rows, but the feature columns are misspelled relative to notebook expectations. The notebook loads `qfq/geminiall`, which returns 401 without authentication. The nearest public generated pool has 58,986 rows—43 short—with no missing-ID explanation. The standalone s1-teasers release also has 24 rows versus 23 in the paper pool.

**Teacher and version drift.** The paper pins Gemini's `-1219` experimental revision, while code calls an unversioned alias without decoding parameters or API snapshot. The repository has no tag or GitHub Release. The README now foregrounds s1.1; s1K-1.1 swaps in DeepSeek-R1 traces and declares MIT, whereas original s1K/model/data cards declare Apache-2.0. These later artifacts must not silently replace paper facts.

**Contamination and licensing.** Word-level 8-grams miss paraphrased, translated, or structurally equivalent problems and may reject benign boilerplate. Removed IDs and match evidence are unavailable. Sixteen upstream sources use Apache-2.0, MIT, CC BY 4.0, and CC BY-NC-SA 4.0, yet final rows have no per-source license field or redistribution reconciliation under the top-level Apache label.

**Budget-forcing and evaluation limits.** Repeated `Wait` injection can create repetition, overthinking, context exhaustion, and non-monotonic gains. vLLM evaluation varies with batching, continued generation, and tensor parallelism even with greedy sampling and fixed seeds. Budget forcing controls inference behavior; it does not validate the underlying trace or guarantee that extra tokens improve correctness.
