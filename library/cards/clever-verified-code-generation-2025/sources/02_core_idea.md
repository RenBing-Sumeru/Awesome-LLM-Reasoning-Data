The main contribution is a rigorous benchmark that combines specification generation with verified implementation generation. Its 161 records include function signatures, docstrings, tests, natural-language specifications, held-out formal ground truth, generated specifications, isomorphism theorems and proofs, implementations, correctness theorems, and helper lemmas. Specifications do not directly reveal implementation logic and annotations are not LLM-generated. A generated specification must be related to hidden ground truth through an equivalence or isomorphism proof, while code must satisfy a correctness theorem. Lean type checking verifies all objects, testing formal semantics rather than behavior on finite inputs.
