# 方法

1. **汇集 VQA 种子。**输入：十个通用与科学视觉问答数据集。操作：抽样并保留每条记录的图像、问题和标准答案。输出与流转：9.9 万条来源问答进入 rationale 生成。检查/停止规则：记录必须有可用图像、问题与参考答案。
2. **编写有序示范。**输入：一条来源问答与固定四阶段提示。操作：GPT-4o 依次写出 SUMMARY、CAPTION、REASONING 和 CONCLUSION。输出与流转：带标签的多模态回答进入验证。检查/停止规则：结论在语义上必须与标准答案一致。
3. **验证并发布记录。**输入：生成回答与来源答案。操作：解析四对标签、抽取结论，再让 GPT-4o 判断它是否拒答或与标准答案存在实质差异。输出与流转：通过的 JSON 记录组成 LLaVA-CoT-100k。检查/停止规则：缺失/畸形阶段、拒答和语义答案不一致均被剔除。
4. **训练并评测消费者。**输入：Llama-3.2-11B-Vision-Instruct 与通过筛选的示范。操作：进行三轮全参数 SFT，推理时可选用奖励模型引导的 SWIRES 在语义阶段上搜索。输出与流转：LLaVA-CoT 预测与 benchmark 分数。检查/停止规则：SFT 使用固定标签目标；SWIRES 在出现可接受阶段候选或达到回溯上限时停止。

**可复现性：**需核验官方 JSON revision、来源数据谱系、生成/验证提示、解析器、模型 checkpoint 与 SWIRES 代码。复现时固定 GPT-4o 版本、来源记录 ID/图像、提示文本、judge 判定、随机种子 42、三轮训练设置、奖励模型与推理预算；生成温度、教师总 token/成本和语义 judge 错误率未披露。
