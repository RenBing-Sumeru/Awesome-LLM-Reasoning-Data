# Method

1. **Assemble VQA seeds.** Input: ten general and science-focused image-QA datasets. Operation: sample records while retaining each image, question, and standard answer. Output and transition: 99k source pairs enter rationale generation. Check / stop rule: a record needs a usable image, question, and reference answer.
2. **Write ordered demonstrations.** Input: one source pair and a fixed four-stage prompt. Operation: GPT-4o writes SUMMARY, CAPTION, REASONING, and CONCLUSION spans in that order. Output and transition: a tagged multimodal response enters validation. Check / stop rule: the conclusion is instructed to match the standard answer exactly in substance.
3. **Validate and release records.** Input: generated response and source answer. Operation: parse the four tag pairs, extract the conclusion, and ask GPT-4o whether it is a refusal or differs meaningfully from the standard answer. Output and transition: accepted JSON records form LLaVA-CoT-100k. Check / stop rule: reject missing/malformed stages, refusals, and semantic answer mismatch.
4. **Train and evaluate the consumer.** Input: Llama-3.2-11B-Vision-Instruct and accepted demonstrations. Operation: full-parameter SFT for three epochs, then optionally apply reward-model-guided SWIRES over semantic stages at inference. Output and transition: LLaVA-CoT predictions and benchmark scores. Check / stop rule: SFT uses the fixed tagged target; SWIRES stops after accepted stage candidates or its retracing cap.

**Reproducibility:** verify the official JSON revision, source-dataset lineage, generation and verification prompts, parser, model checkpoint, and SWIRES code. Fix the GPT-4o version, source record IDs/images, prompt text, judge decision, random seed 42, three-epoch training setup, reward model, and inference budget; generation temperature, total teacher tokens/cost, and semantic-judge error rates are not reported.
