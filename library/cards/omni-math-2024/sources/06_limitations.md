Correctness holds only relative to the benchmark's reference answer and scoring path. A rule-based match can fail on mathematically equivalent but differently formatted answers; an LLM judge can accept or reject based on judge behavior rather than a formal proof. Omni-MATH should therefore not be read as a theorem-proving benchmark, a proof-step verifier, or a guarantee that a model's derivation is sound.

Reproducibility depends on dataset version, answer extraction, prompt wording, judge model revision, sampling budget, and model release date. Public HF/GitHub artifacts make inspection easier but also increase contamination risk. License and redistribution terms must be checked at artifact level before using records as training data, evaluation data, or reward-model supervision.
