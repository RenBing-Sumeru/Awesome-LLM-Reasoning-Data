论文明确限制是领域和语言覆盖：WebArXiv 聚焦英文 arXiv 界面。这使它适合稳定学术网页任务，但不能代表多语言界面、非学术网站、电商流程、账号个性化状态或高风险交易任务。

该基准降低了答案漂移，但没有消除所有复现风险。浏览器版本、accessibility tree 抽取、截图分辨率、页面渲染、prompt 模板、重试策略和模型 API 变化仍会影响分数。如果使用的是 live arXiv 页面而不是保存快照，即便域相对稳定，也可能出现标签或路径变化。

评测器以最终答案为中心。这适合确定性信息检索，但可能遗漏过程质量：智能体可能通过脆弱捷径得到正确答案，也可能已经找到基本正确内容却因严格字符串匹配失败。部分正确标签有助于诊断，但不是主指标。
