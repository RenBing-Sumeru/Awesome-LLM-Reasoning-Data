Read Sections 1 and 3 first. They define the reproducibility problem, the five arXiv task categories, and the filtering and annotation process that leads to 275 tasks.

Read Section 4 next for the evaluation contract. The crucial details are all-task evaluation, three runs per task, averaged task success rate, strict final-answer matching, and the distinction between general LMM-based agents and specialized web agents.

The dynamic reflection material is worth reading as a diagnosis rather than as the main dataset contribution. It gives a concrete example of how browser-agent trajectories can fail because recent-history context is selected mechanically instead of semantically.

Important unknowns to resolve from artifacts are: exact task JSON schema, whether pages are frozen or live, how final-answer normalization is implemented, how partial correct is used outside analysis, and whether the anonymous repository has a stable license and citation path.
