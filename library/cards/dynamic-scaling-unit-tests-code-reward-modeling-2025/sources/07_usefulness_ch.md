对 rollout、搜索与测试时计算方向，该工作给出了验证器侧轨迹的具体模式：题目、采样候选解答、生成测试、执行矩阵、聚合投票、被选候选、预测难度和分配的测试预算。这类记录可用于预算感知重排序、验证器校准、假接受与假拒绝审计，以及固定和自适应验证器计算的比较。若保留源数据集血缘、参考解答、修复历史、被拒测试和执行环境，该合成配方也可用于构造单元测试生成器的 SFT 数据。

复用时应明确区分两类对象：用于训练 CodeRM-8B 的样本，以及测试时用于排序候选程序的执行轨迹。论文报告的基准提升说明该反馈契约值得研究，但不能据此把生成测试视为 ground truth，也不能将论文外推为缺乏证据的 RLVR、过程监督或通用软件工程结论。
