论文的先导实验在 HumanEval Plus 上为每题使用最多 200 个候选解答和 100 个生成单元测试，并通过 bootstrap 重采样统计结果；实验显示，在多种策略模型和测试生成模型组合中，增加测试数量通常能改善 best-of-N 选择。较难题目分位上的收益更大，由此引出动态预算分配。在三项基准的主要对比中，相比随机选择，CodeRM-8B 使 Llama3-8B 和 GPT-4o-mini 在 HumanEval Plus 上的 Pass@1 分别提高 18.43 和 3.42 个百分点；在所评估策略模型上，MBPP Plus 与 LiveCodeBench 也出现提升。在固定计算量下，动态分配带来的额外收益较小，论文报告其在 MBPP Plus 上最高约为 0.5 个百分点。

论文还以准确率、F1、假接受率和假拒绝率评估测试验证器行为，并消融假阳性过滤与训练数据规模。这些结果支持“测试数量、过滤和预算分配会影响该验证器的下游选择行为”，但不能逐条证明每个合成单元测试都正确、多样、无污染，也不能证明其可迁移到论文所评估的 Python 函数生成场景之外。同样，基准提升不构成未来公开数据集质量或完整性的证据。
