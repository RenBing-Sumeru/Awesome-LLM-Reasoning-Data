该文以 ACL 2025 长文发表，研究测试时代码选择问题：重复采样可能在多个候选中产生正确程序，但最终输出仍依赖可靠的验证器。LLM 生成的单元测试能够提供可执行反馈，却可能因预期输出错误或覆盖不足而误收错误程序、误拒正确程序。因此，论文考察扩大验证器侧计算量——即增加生成单元测试的数量——能否改善奖励信号，以及是否应按题目难度分配测试预算。与本卡相关的数据对象包括编程题、候选代码解答、由输入—期望输出用例组成的生成单元测试、每个解答的执行结果、被选中的解答、难度标签或估计值，以及逐题测试预算。本卡将其视为 rollout、搜索与测试时计算数据的构造和评估配方；不据此推断完整 rollout 日志或可复用语料已经公开。
