合成流水线以 CodeFeedback-Filtered-Instruction 和 TACO 训练集为来源。Llama3.1-70B 先筛除不适合常规单元测试的问题，包括涉及随机性的任务，并将保留的参考解答转换为函数形式。随后，Llama3.1-70B 根据每个“题目—参考解答”组合重复采样单元测试。测试在参考解答上执行：通过者被保留，失败者可利用 Python 解释器反馈进行修复。质量控制阶段再由能力较弱的模型生成错误解答，并删除无法拒绝这些错误解答的假阳性测试。最后，以“题目加代码解答”为指令、过滤后的单元测试为目标，从 Llama3.1-8B 监督微调得到 CodeRM-8B。

在选择阶段，候选解答 Ci 对每个生成单元测试获得一个二元结果：只有通过该测试内全部用例时记为 1，否则为 0；最终选择这些结果之和最大的解答。动态扩展阶段先用已收集的正确测试检查策略模型的重复采样解答，以平均通过率作为难度目标；一个两层前馈探针将解码隐藏状态映射为标量预测通过率，再通过论文给出的效用函数 q(x,b)=1-(1-λ)^b 和贪心算法分配测试生成预算。主要实验使用 HumanEval Plus、MBPP Plus，以及 LiveCodeBench 中 2024-01 至 2024-09 的 168 道函数形式题目。论文报告解答与测试生成的 temperature 为 0.8、top-p 为 0.95。PDF 中给出了 ACL 论文页和项目网址，但本卡尚未核验到官方代码或数据发布链接；因此，实际发布的数据模式、记录数、划分、校验和及完整重放日志均保持 unknown。
