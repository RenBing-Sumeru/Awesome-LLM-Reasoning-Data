The paper scales the verifier rather than only the policy. For a programming problem, a policy model samples multiple candidate solutions; a unit-test generator produces multiple tests conditioned on the problem and a candidate solution; execution yields a binary result for each solution–test pair; and majority voting selects the candidate passing the most tests. The authors train CodeRM-8B, based on Llama3.1-8B, to generate tests from problem–solution inputs using synthetically constructed supervision. They also train a lightweight probe that estimates problem difficulty from model hidden states and use a greedy allocator to assign more unit-test budget to harder problems. The feedback contract is programmatic but imperfect: execution is deterministic under the stated Python setting, while the generated test inputs and expected outputs remain model-produced and can be wrong. Relative to fixed-count unit-test reranking such as CodeT, MBR-Exec, and MPSC, the distinctive object is difficulty-conditioned scaling of verifier samples under a fixed overall budget.
