A natural-language-to-PDDL output may parse and admit a plan while encoding the wrong initial state or goal, so executability does not imply semantic fidelity. Earlier datasets also often paraphrase PDDL templates too directly, making the task easy. Planetarium introduces a rigorous PDDL semantic-equivalence algorithm and a large text-to-PDDL dataset with multiple description styles, separating syntax validity, solvability, and genuine semantic correctness.
