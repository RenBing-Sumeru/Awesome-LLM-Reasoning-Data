The final NAACL version contains 145,918 text–PDDL pairs over Blocks World and Gripper, 73 unique state combinations, and varying difficulty. Each ground-truth PDDL problem has four language styles: fully abstract, fully explicit, and two mixed descriptions. The verifier parses candidates, checks solvability, and then tests semantic equivalence under object renaming and state/goal correspondence. The current Hugging Face release expands representations to about 584K rows, which should not be confused with the paper’s independent pair count.
