The disclosed scaffold is stage-level only. The Qwen blog states that outcome-based RL is first scaled for mathematics and coding from a cold-start checkpoint. Mathematics receives an accuracy-verifier signal for final solutions. Coding receives an outcome from a code-execution server that checks generated code against predefined tests. The blog then describes a later RL stage for general capabilities, trained with a general reward model and some rule-based verifiers.

The official model page additionally labels the release as having supervised fine-tuning and reinforcement-learning post-training, and identifies Qwen2.5-32B as its base model. Neither source supplies a training dataset, prompt format, chain-of-thought record format, rollout count, sampling settings, objective formula, optimizer configuration, KL treatment, reward weights, parser, test harness, or rule inventory. The official GitHub repository provides evaluation material and usage guidance; it is not evidence that the training or verifier stack is released.
