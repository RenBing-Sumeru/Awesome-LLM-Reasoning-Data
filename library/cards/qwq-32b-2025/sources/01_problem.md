An open-weight reasoning-model release can identify a model and a high-level reinforcement-learning stage without supplying a reusable data recipe. For audit purposes, the missing objects matter: task provenance, prompts, generated traces, retained and rejected outputs, executable verifier details, reward calibration, splits, contamination controls, and rights can all remain unavailable.

QwQ-32B is useful for this Track 12 disclosure question because the official release makes a compact but concrete feedback claim. It names a cold start and two RL stages, including mathematics accuracy checking, code execution against predefined tests, a general reward model, and some rule-based verifiers. This Card records those disclosed interfaces and their boundaries; it does not treat public weights, benchmark outcomes, or a reasoning-output interface as a released training-data pipeline.
