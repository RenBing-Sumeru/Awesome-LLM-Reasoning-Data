The official Qwen blog introduces QwQ-32B as a 32-billion-parameter reasoning model and states that it begins from a cold-start checkpoint. Its first RL stage scales outcome-based rewards for mathematics and coding: a mathematics accuracy verifier checks final solutions, while a code-execution server checks whether generated code passes predefined tests. A second, general-capability RL stage uses a general reward model and some rule-based verifiers.

The official model page identifies Qwen/Qwen2.5-32B as the base model and lists supervised fine-tuning and reinforcement learning as post-training stages. The release does not disclose the cold-start contents, SFT records, source mixture, sample counts, reward formula, general reward model, rule set, code server, test cases, or per-example lineage. The model's API separation between reasoning_content and final content is a deployment interface, not evidence of a training-record schema.
