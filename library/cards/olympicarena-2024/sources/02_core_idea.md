The contribution is a broad olympic-competition benchmark with fine-grained metadata, validation/test splitting, answer-level evaluators, process-level analysis, leakage checks, an annotation platform, and a leaderboard/submission path. The core mechanism is to collect publicly available competition PDFs, parse them with Mathpix, annotate problem records through a science-and-engineering student workflow, validate the annotations, deduplicate within competitions, and attach answer-type, subject, language, modality, and reasoning-skill labels.

The feedback contract has multiple layers. Most answer-level scoring uses rule-based matching by answer type, including exact option matching, numeric comparison, symbolic comparison with SymPy, interval/set/tuple comparison, multiple-quantity ordering, and code test cases. About 5% of problems require model-based evaluation with GPT-4V. Process-level analysis is separate: GPT-4 reformats gold and model solutions into steps, then GPT-4V scores each step.

Closest comparisons include OlympiadBench, MMMU/CMMMU, ScienceQA, MathVista, SciBench, AGIEval, and contest-code benchmarks. OlympicArena's direction label is broad multi-discipline olympiad evaluation with answer-type-aware scoring and explicit public-versus-hidden split handling.
