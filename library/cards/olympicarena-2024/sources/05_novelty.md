The prior baseline includes single-domain math/science benchmarks, multimodal science benchmarks, exam suites, OlympiadBench, and code-contest evaluations. OlympicArena changes the benchmark object by aggregating 62 olympic competitions across seven disciplines, preserving text-image modality, adding 13 answer types, and exposing validation/test split semantics with hidden test answers.

The direction signal is that olympiad-level evaluation can be structured as a multi-field record with rule-based scoring where possible, model-based scoring where necessary, code execution for programming tasks, and separate process-level analysis for reasoning behavior. The quality signal is the combination of annotation workflow, validation, deduplication, public fields, evaluation scripts, and leakage analysis.

What is not new: PDF OCR, answer-type prompts, symbolic math checking, LLM-as-judge, process-step scoring, and leaderboard submission are known components. Before reuse, inspect the CC-BY-NC-SA-4.0 data license, the status of the code license, hidden-test policy, source competition rights, image URL stability, annotation fidelity, model-judge drift, and whether validation results are being mixed with official test leaderboard claims.
