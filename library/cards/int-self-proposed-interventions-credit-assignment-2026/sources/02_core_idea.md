InT centers on a failed trajectory’s correct prefix, its earliest error, and a one-step intervention, converting a trajectory-level outcome into locally trainable correction supervision. The official InT-SFT release contains 2,213 Parquet records totaling about 51.5 MB. Examples preserve the problem, on-policy rollout, faulty prefix, and intervention text and are mainly used to initialize a reasoning model with finer credit assignment.

The dataset page does not state one unified license, so users must verify the current fields and access conditions.
