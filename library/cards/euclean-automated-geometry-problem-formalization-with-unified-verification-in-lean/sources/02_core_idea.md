The paper constructs 768 OMNI-Geometry and 177,597 Numina-Geometry items. The current regenerated official releases contain 780 and 183,796 records respectively, using Lean/Mathlib 4.28.0 and Codex GPT-5.4. Numina records include informal statements, proofs, answers, provenance, and `formal_statement`; Omni additionally stores `formal_proof` and a completion flag, with 525 of 780 one-pass proofs completed. The Parquet data are Apache-2.0, but compilation guarantees formal well-formedness rather than semantic faithfulness.
