The core object is the RLVR verifier as a fallible reward channel: the paper measures how deliberately corrupted or model-produced judgments alter learning while an oracle remains available for evaluation. This turns the usual all-or-nothing assumption about verifier correctness into a robustness curve, separating the effects of error rate, error granularity, and judge precision. It shows that precision is more consequential than recall for this setting and that useful learning can survive moderate noise. It uses the existing MBPP coding benchmark and GPQA science questions, but the authors do not package their training records as an official downloadable dataset or release a complete codebase.
