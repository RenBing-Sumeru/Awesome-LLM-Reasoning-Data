Weaver maps heterogeneous verifiers into binary voters and treats response correctness as a latent variable. Reward-model outputs are normalized and thresholded; judge outputs are parsed as binary verdicts; verifiers with extreme marginal behavior are removed. Under the assumption that verifier votes are conditionally independent given correctness, observable pairwise vote moments identify each verifier's true-positive and true-negative rates. A small labeled development sample supplies the class prior and threshold information, while test query-response labels are not used to fit the weak-supervision model.

The fitted parameters define a Naive-Bayes-style posterior probability that each candidate is correct. The candidate with the largest posterior is selected. Thus the feedback contract is an answer-level scalar score derived from multiple judgment-required signals, not a programmatic proof and not an oracle label.

The same posterior scores also become soft pseudo-labels for ModernBERT-Large (396M) cross-encoders. This creates two related data objects: an expensive ensemble selection ledger and a distilled verifier training set of query-response pairs paired with Weaver scores. The paper evaluates both selector effectiveness and distillation efficiency, but neither evaluation makes every pseudo-label a certified ground-truth record.
