Inputs are RapidAPI documentation filtered by the authors, with closed-chat-model-generated single-tool and multi-tool user instructions. Outputs are user instruction, selected APIs, tool-call chain, API observations, final answer or failure, and ToolEval judgment. The substrate is RapidAPI tool bank, API retriever, DFSDT solution-path search, and ToolEval judging.

Pipeline: 1. construct or load the task instance; 2. run the model or system under the official harness; 3. collect actions, observations, answers, or predicted structures; 4. apply ToolEval uses closed-model judgments of pass rate and win rate over full tool-use trajectories; 5. aggregate scores only under a pinned version of the benchmark. Reproducibility requires pinning paper=https://arxiv.org/abs/2307.16789, project=https://openbmb.github.io/ToolBench/, code=https://github.com/OpenBMB/ToolBench, data=https://github.com/OpenBMB/ToolBench, plus the exact split, runtime, scorer, prompt/scaffold, and release revision.
