Primary source: https://arxiv.org/abs/2307.16789. Public status: ICLR 2024 spotlight, 2023. Open-source language models had weak tool-use ability because ordinary instruction tuning underrepresented real API use. ToolLLM asks how to construct tool-use data and evaluate API-using behavior at scale.

The evaluation object is user instruction, selected APIs, tool-call chain, API observations, final answer or failure, and ToolEval judgment. The feedback contract is ToolEval uses closed-model judgments of pass rate and win rate over full tool-use trajectories. This belongs in the collection as an auditable benchmark or environment surface; it is not by itself proof of deployable reliability, and training use should be inferred only where the paper explicitly releases data for that purpose.
