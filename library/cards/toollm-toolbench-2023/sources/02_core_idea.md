One-sentence contribution: ToolLLM introduces ToolBench, a large tool-use dataset over 16,464 real-world APIs, plus ToolEval and ToolLLaMA for training and evaluating API-using models. The contribution has three linked parts: ToolBench data construction from RapidAPI, DFSDT solution-path search and ToolLLaMA training, and ToolEval for automatic trajectory evaluation.

The data object contains API schema, user instruction, retrieved tool, tool call, API observation, solution path, final answer, ToolEval score. Success is decided by the tool-call chain satisfies the user instruction or wins against a comparison trajectory under ToolEval. Closest comparisons are static web benchmarks, tool-use datasets, or code benchmarks in the same domain, but the direction label here is the concrete evaluation surface and its verifier rather than a general capability claim.
