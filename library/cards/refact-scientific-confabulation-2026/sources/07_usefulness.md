ReFACT can train scientific error-span localizers that output an overall label, error position, factual explanation, and correction from a question and answer. Independent detection and pairwise comparison should be evaluated separately with positional IoU or F1. Single-error variants can also test sensitivity to answer order and salient sentences. For first errors in multi-step trajectories that are not local text spans, trajectory-level data is required in addition to ReFACT. The output can highlight, explain, and minimally edit a local error rather than regenerate an entire scientific answer. Success checks should separately report independent and pairwise F1, span IoU, and repair accuracy stratified by position, discipline, answer length, and model scale. Multi-step first-error tasks need trajectory data.
