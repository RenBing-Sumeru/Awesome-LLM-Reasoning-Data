ReFACT's core set contains 1,001 expert-verified question-answer pairs from Reddit's `r/AskScience` with error-span positions, and the candidate pool includes 1,251 single-error variants controlling error count and location. Each record stores the question, original or perturbed answer, overall label, error span, and correction target. The data supports scientific-confabulation detectors, position localizers, and comparison of LLM judges under independent versus pairwise settings. The single-error design separates error content from writing quality, preventing chosen and rejected responses from differing through length, tone, or overall fluency shortcuts. Position fields enable direct token or span overlap metrics rather than only subjective judge explanations. The core set has 1,001 expert-verified AskScience QA pairs and 1,251 single-error variants. Records preserve overall labels, minimal error spans, positions, and correction targets for token or span metrics, explanations, and repair.
