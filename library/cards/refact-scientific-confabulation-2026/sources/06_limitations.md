First, the data comes from Reddit science explanations, whose style, length, and topics differ from papers, clinical notes, or laboratory reports. Second, single-error variants enable causal analysis but underrepresent real generations with multiple interacting errors. Third, span boundaries can be ambiguous when a semantic error crosses sentences, so evaluation should allow soft overlap metrics. Public release also creates contamination risk, motivating hidden variants. Reddit expert answers are not timeless truth; rapidly evolving scientific topics require source dates and renewed verification. Reddit science style does not represent papers or clinical text, single-error design underrepresents propagation, and span boundaries have equivalent granularities. Reuse should preserve source dates, allow soft overlap, and add hidden multi-error cases.
