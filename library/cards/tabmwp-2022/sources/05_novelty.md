Prior-work baseline: math word-problem datasets such as GSM8K and MathQA mainly use textual problem statements, while table QA datasets often focus on lookup, semantic parsing, or domain-specific tables. TabMWP combines the two requirements: the table is needed and the answer requires mathematical reasoning.

What changes: the benchmark pairs every question with table representations, answer labels, and natural-language solutions, while PromptPG treats in-context example selection as a learnable policy rather than random selection, fixed manual examples, or nearest-neighbor retrieval. The direction signal is a clear benchmark coordinate for semi-structured reasoning where the input object is not just a prompt but table plus question plus answer contract.

Quality signal: the paper reports construction filters, split sizes, answer-type distributions, blind ablations, baseline comparisons, and an official repository containing data files under `data/tabmwp`. What is not new: the terminal verifier is still answer-level accuracy, not a proof or executable program checker; the gold solutions are explanatory traces, not independently verified process-supervision labels. Reuse checks should focus on scorer behavior, answer extraction, table-format choice, and license constraints.
