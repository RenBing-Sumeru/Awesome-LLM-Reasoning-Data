Dynamic Prompt Learning via Policy Gradient for Semi-structured Mathematical Reasoning introduces TabMWP, a benchmark for mathematical reasoning over tabular context, and PromptPG, a policy-gradient method for choosing in-context examples. The primary paper is arXiv:2209.14610, published at ICLR 2023; the official code/data repository is https://github.com/lupantech/PromptPG and the project page is https://promptpg.github.io.

Decision boundary: the reusable data object is the TabMWP benchmark, while PromptPG is an evaluation method and prompt-selection baseline built on top of GPT-3. The concrete problem is that existing math word-problem datasets are mostly text-only, whereas many real problems require selecting cells from tables, aligning table and question text, and then performing arithmetic or logical reasoning.

The evaluation surface is a table, question, optional multiple-choice options or unit, gold answer, gold natural-language solution, split metadata, answer type, and scorer. TabMWP contains 38,431 grade-level open-domain problems with 37,644 different tables, represented as image, semi-structured text, and structured table formats. Reuse screening is supported because the paper exposes the source object, answer verifier, split policy, construction process, and prompt-learning baseline clearly enough for benchmark audit.
