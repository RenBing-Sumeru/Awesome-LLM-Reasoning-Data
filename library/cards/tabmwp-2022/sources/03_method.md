Inputs: openly available grade-level math problems that include a tabular context and a detailed solution. The authors extract table context, question, options when present, correct answer, and solution using HTML tags; they store screenshots and raw text, convert raw tables into flattened semi-structured text, and further convert tables into a structured format usable by pandas or SQL-style table models.

Construction pipeline: the authors keep only problems where the table is necessary, shuffle multiple-choice options to reduce order bias, remove redundant solution information, manually rewrite some solutions for readability, and remove duplicate records with the same table, question, and answer text. Quality control includes human filtering for problems answerable without table context or without numerical reasoning.

Outputs: 38,431 problems split 6:2:2 into 23,059 train, 7,686 development, and 7,686 test items. The data include 28,719 free-text questions and 9,712 multiple-choice questions, 6,153 different answers, and 35,442 different solutions. PromptPG uses a fixed BERT encoder plus a learned linear layer to select two examples from a 20-example candidate pool; reward is +1 or -1 according to whether GPT-3's answer matches the label.
