Existing datasets such as VerilogEval mainly measure generation of one module from a specification, usually in a single-file, single-turn setting with fixed tests. CVDP changes task coverage and interaction form by placing RTL, testbench, assertions, debugging, QoR improvement, specification correspondence, and question answering in one taxonomy, with both direct-generation and multi-turn agent repositories. The novelty is not the simulator itself, but expert task definition from real workflows and validation that complete contexts are solvable while incomplete contexts should fail.
