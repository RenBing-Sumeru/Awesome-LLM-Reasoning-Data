CVDP retains 783 tasks authored by experienced hardware engineers across 13 categories of RTL design, verification, debugging, specification alignment, and technical question answering. Of these, 617 are non-agentic and 166 are agentic. A problem may include a multi-file repository, natural-language specification, existing RTL or testbench, reference outcome, and tool configuration. Code tasks are checked by compilation and simulation, while comprehension tasks combine automatic metrics and judging. It is a broad evaluation benchmark rather than a large SFT corpus.
