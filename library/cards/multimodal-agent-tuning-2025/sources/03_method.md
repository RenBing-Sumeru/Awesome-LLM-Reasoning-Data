The pipeline can be reconstructed at the level disclosed by the paper:

1. **Inputs.** Authors manually brainstorm and double-check seed queries. Tool descriptions and randomly sampled seed demonstrations condition GPT-4o mini. For images, the pipeline builds a 93K image-caption pool from ChartQA, COCO, LLaVA, SAM, TextVQA, Web-Celebrity, Web-Landmark, and WikiArt, using ShareGPT4V captions.
2. **Query and file construction.** GPT-4o mini writes a new query and identifies required files. BGE retrieves top-similar images; GPT-4o mini generates content and Python materialization code for non-image objects such as PDF, DOCX, PPTX, XLSX, CSV, and audio.
3. **Interaction.** A zero-shot ReAct agent controlled by GPT-4o mini receives the query, files, and tool descriptions. At each step it writes a thought, emits executable Python code, and conditions the next step on the returned observation. Most reported trajectories contain two to six steps; some contain seven or eight.
4. **Environmental gate and judgments.** Only trajectories whose code executes are collected. A GPT-4o-mini query-file judge checks relevance, sufficiency, and solvability; a second GPT-4o-mini judge checks the trajectory and final answer. Retention requires both approvals.
5. **Output and training.** The paper reports 23.5K generated candidates filtered to about 20K tasks with about 15K files. MM-Traj is mixed with Cauldron and open-LLaVA-NeXT, then used for five-epoch SFT of MiniCPM-V-8.5B or Qwen2-VL-7B controllers. The vision encoder/compressor are frozen; rank-64 LoRA is applied to LM q/k/v; context length is 10,240, learning rate 1e-6, and batch size 2. Loss covers thought and code tokens, not final answer `A`.

Construction temperature is not reproducible from the paper: it says query temperature is tuned but gives no value. Checked scripts set temperature 1 and name `gpt-4o-mini-2024-07-18`, yet no immutable manifest binds those files to the paper run. Maximum rollout steps, token and tool-cost budget, timeouts, retries, concurrency, API versions, and random seed are unknown.

The pinned dataset differs from the rounded paper funnel: `mat_train.json` has 21,168 unique rows, while `data.zip` has 19,307 regular files. Reproduction must therefore pin the code, dataset, and model revisions; repair the final verifier's nonexistent prompt paths; reconstruct external caption/embedding assets; and create mappings among source files, generated attachments, JSON rows, verifier decisions, training membership, and checkpoints. There is no released split or contamination procedure to reproduce.
