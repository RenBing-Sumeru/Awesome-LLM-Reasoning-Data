1. **收集并分层题目：** 汇总高中奥赛与本科课程数学问题，保留原始自然语言、领域和难度元数据，删除无法用当前 Mathlib 表达或信息不足的题目。

2. **自动形式化：** 使用专门训练或提示的 LLM 将问题转换为 Lean4 theorem statement，并以 `by sorry` 编译检查语法、类型和 imports。

3. **语义与反驳过滤：** 多个 LLM 独立比较自然语言与形式陈述；随后构造陈述的否定或反例目标，调用现成 prover 尝试证明。被反驳、明显平凡或意见不一致的候选被拒绝或送回修改。

4. **专家复核与评测：** 人工确认保留陈述的忠实度，冻结 5,560 题 benchmark，再在固定 Lean/Mathlib、采样预算和 verifier 下评测证明器。复用时必须记录数据版本，因为后续独立审计已发现部分规格风险。
