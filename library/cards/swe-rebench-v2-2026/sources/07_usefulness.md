For `environment_agent_trajectory_data`, the reusable object is an episode substrate rather than a trajectory corpus: initialize the repository at `base_commit`, expose the task statement and tools, collect state/action/observation events downstream, and attach the final parser-derived F2P/P2P outcome to the complete patch episode. A training pipeline should never reinterpret the released historical gold `patch` as an observed agent trace.

For agent RLVR, the main 32,079-row release can provide terminal binary reward after a submitted patch, while unrecovered F2P and regressed P2P lists support failure diagnosis or cautiously designed partial rewards. Before online training, builders should freeze images by OCI digest, disable or record network access, add timeouts, validate parsers against raw logs, and isolate held-out tasks. The official release does not demonstrate that this reward produces a training gain.

For SFT and curriculum work, the task statement, gold patch, interface description, difficulty, and pathology metadata can support supervised repair examples or subset selection. Such reuse is conditional rather than automatically safe: PR-generated statements need leakage review, gold patches and tests need rights checks, source and benchmark overlap must be measured, and no official train/validation/test separation protects evaluation.

For `data_construction_open_release_recipes`, the paper is a concrete blueprint for repository mining, reusable setup synthesis, parser generation, pre/post full-suite oracle extraction, clarity filtering, and diagnostic enrichment. Useful controlled experiments include varying setup retries, comparing parsers with hand-labeled logs, replacing unanimous LLM filtering with calibrated human/LLM mixtures, and quantifying how each filter changes language and repository coverage.

Version-pinned rows and environments are useful for evaluation and verifier audits, but the current main release should be treated as conditional training reuse and the PR tier as requiring additional environment reconstruction. Unqualified training reuse is blocked pending immutable replay, overlap/contamination, rights, privacy, leakage, and failure-retention audits. The paper remains directly useful as a construction recipe and audit reference even where those checks are incomplete.
