The construction funnel is the strongest scale evidence. From 29,511,758 PRs in 145,306 repositories, the pipeline finds 8,593,722 PRs changing tests, 805,598 issue-linked test-changing PRs, 583,809 candidates after repository filtering, 41,349 tasks with successful F2P extraction, and 32,079 tasks after issue-text filtering. The resulting main release spans 3,617 repositories and 20 languages; tasks date from 2014–2025, with median patch size of three files/34 lines and 90th percentile of nine files/181 lines. These are author-reported pipeline and release statistics, not a row-level quality certificate. (Paper §§3.6–3.7, Table 1)

The setup ablation covers 103 tasks/repositories across ten languages. With Qwen3-Coder-480B-A35B-Instruct under mini-SWE-agent, the paper reports pass@1 of 25.8 at a 32k budget and pass@10 of 62.7 at 128k; the non-interactive setup baseline reports pass@1 of 12.1. This supports the value of closed-loop setup and retries under those budgets, while the production pipeline still uses one attempt per repository. (Paper §4.1, Table 2; Appendix A.1, Table 8)

The issue-clarity ensemble is calibrated on 1,699 SWE-bench Verified instances with three human annotations. For the Verified-E target, the reported precision/recall/F1 is 0.83/0.10/0.17; for mixed consensus it is 0.88/0.06/0.11. The filter is therefore conservative and high-precision under this calibration but discards many acceptable specifications; unanimous acceptance is not equivalent to human verification of the released 32,079 rows. (Paper §4.2, Tables 3 and 5)

The diagnostic study samples 300 tasks—60 each in Python, JavaScript, Go, Rust, and Scala—and runs seven models three times per task. Table 6 reports aggregate pass@1 25.2 and pass@3 32.7 for Claude Opus-4.5; Appendix C rounds these to 25% and 33%. The analysis identifies restrictive test coupling, implicit naming requirements, and external dependencies. It characterizes model behavior and task confounders on this subset, but does not validate every row or show that training on the release improves an agent. (Paper §4.3, Table 6; Appendix C)

Artifact evidence is independently inspectable: the main Hugging Face split has 32,079 rows and the PR split has 126,300; the official code contains prompts, base Dockerfiles, image builders, generated parsers, and `scripts/eval.py`. The ICML abstract's older 36,000+/3,800+/100,000+ counts conflict with arXiv v2 and current release counts. This version drift, absence of a tagged release, and absence of training ablations limit what the benchmark-style numbers can establish.
