- The single linux/amd64 container design excludes tasks requiring multiple services, databases, or external infrastructure. Even within one container, the released evaluator uses Docker host networking, supplies no explicit subprocess timeout, and depends on external resources that can drift. The public image template also wraps individual install commands with `|| true`, so a built image does not by itself certify a successful setup.
- Terminal reward is only as sound as the repository tests and generated parser. Tests may impose requirements absent from the issue, P2P may couple a task to unrelated behavior, and parsers may omit, merge, or rename tests. Exact passed-set equality detects parser-visible F2P/P2P outcomes but not semantic equivalence, maintainability, security, or untested regressions; reward hacking and verifier gaming therefore remain possible.
- Unanimous LLM clarity filtering has high reported precision but very low recall on SWE-bench Verified calibration. It is not row-level human review and may preferentially retain specifications that match the three judges' shared biases. The paper prompt defines B7 while the main release schema exposes B1–B6, and the PR `meta` schema contains irregular legacy fields.
- Both Hugging Face releases expose only a `train` split. Broad duplicate removal, overlap with existing SWE benchmarks, model-pretraining contamination, issue/PR leakage, and train/evaluation separation are unknown. For PR-derived task text, the leakage detector, threshold, rejection count, and measured residual rate are not disclosed.
- The public repository releases prompts, builders, parsers, and evaluation utilities, but not the complete GitHub Archive mining/join/distributed harvesting implementation or a complete production setup-agent orchestrator. There is no Git tag or GitHub Release, and task rows do not provide verified OCI digests, dependency lock snapshots, or a complete immutable image manifest.
- The funnel retains successful executable and clarity-approved tasks; raw failed setups, rejected candidates, parser failures, judge disagreements, and seven-model diagnostic trajectories are not released. Their contents and complete rejection counts are unknown, preventing analysis of selection bias and failed-episode learning.
- Code is MIT and both dataset cards declare CC BY 4.0, but each source repository's license still applies. Compatibility for dependencies, tests, issues, PR contributions, and contributor rights is not fully audited. Public GitHub provenance also does not settle privacy: the sensitive-information rule, audit results, consent, deletion process, and retained-PII assessment are unknown.
- The paper proposes SFT, test-reward RL/RL warm-up, curriculum selection, and agent training, yet reports no training ablation. Its diagnostic evaluation cannot establish training-data value. ICML, arXiv v2, and Hugging Face counts also differ, so unpinned reuse can silently change the claimed dataset.
