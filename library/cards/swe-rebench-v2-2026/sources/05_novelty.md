The prior baseline is a landscape of relatively small, manually curated SWE evaluation sets and training collections concentrated in high-resource languages. SWE-rebench V2 changes the target from a benchmark-only instance to a training-oriented environment record assembled automatically from repository history and executable repository behavior. Its main release joins task text, base commit, gold/test patches, F2P/P2P expectations, install/test recipe, parser, metadata, and a prebuilt image at 32,079-task scale across 20 languages.

The construction novelty is the reusable repository-level setup coupled to repository-specific parser synthesis. Instead of requiring a hand-authored environment for every task, one interactive setup agent generates install/test procedures once per repository; full-suite pre/post validation extracts the oracle; a three-model clarity ensemble filters specifications; and diagnostic metadata flags likely test/specification problems. The PR branch then trades prebuilt execution for scale, releasing 126,300 additional task rows whose problem statements are generated from PR material.

This matters directionally for reasoning-data research because environment creation, feedback extraction, and metadata enrichment become explicit construction layers that can be ablated independently. It provides a concrete route from public software history to full-episode test feedback suitable in principle for agent RLVR, while preserving enough fields to study parser noise, test coupling, language coverage, and task selection. It is more accurately classified as a data release, construction recipe, and agent environment than as a generic benchmark.

The work does not introduce GitHub mining, Docker execution, unit-test reward, F2P/P2P semantics, mini-SWE-agent, LLM-as-judge filtering, or generated task descriptions individually. Much of the contribution is scale and systems integration. Scale alone is not a quality signal: reuse still requires parser audits, immutable environment pinning, rights and contamination review, leakage measurement for generated PR statements, and a training ablation that isolates the data contribution.
