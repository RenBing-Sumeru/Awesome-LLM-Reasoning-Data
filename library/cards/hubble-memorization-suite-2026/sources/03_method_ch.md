1. 准备干净底座。作者使用源自 DCLM 的英文语料，移除与扰动材料的重叠，作为标准组训练语料。

2. 定义干预。对段落、改写、传记、对话和测试题采样，并赋予 0×、1×、4×、16×、64×、256× 的重复次数。

3. 构造扰动序列。将条目插在 2048 token 训练序列的文档之间，以 EOS 包围；100B 设置的扰动共 79.9M token。

4. 训练配对套件。训练 1B、8B 的 100B/500B token Llama 风格模型，并提供核心、时序、干扰、改写和结构变体。

5. 测量暴露。用领域评测比较标准组与扰动组；复现前须核对检查点、Hugging Face 版本和计算配置。
