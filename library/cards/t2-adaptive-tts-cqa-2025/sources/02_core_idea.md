T2, named Think-to-Think, treats a new question as an instance of a structural pattern rather than assigning it to a predefined difficulty bucket. It first separates fixed structure from replaceable entities, then creates analogous question-document examples that preserve the structure while varying those entities. Each example carries a candidate solution plan with a potentially different number of reasoning steps, allowing the system to compare ways of thinking instead of blindly extending one chain.

The selected plan is used as a test-time control object. It specifies a sequence of reasoning skills and tells the answering model which parts of the original document are relevant to those skills. Thus adaptation comes from matching the original question to a generated strategy whose coverage and uniqueness score is favorable. The key claim is that similar problems provide a model-native signal for when concise reasoning is enough and when a longer, evidence-focused analysis is worth its cost.
