For a document D and question Q, T2 uses a fine-tuned RoBERTa classifier to divide question tokens into structural tokens and typed entity placeholders, yielding a reusable question template. An LLM replaces those entities to create candidate similar questions, and a similarity check keeps only candidates above a threshold. For each retained question, the method creates supporting document segments and decomposes the problem into subquestions connected by one of seven stated reasoning skills. The number of subquestions is deliberately not fixed, which supplies strategies of different depths.

T2 evaluates the resulting example-strategy collection with multiple criteria, reported as coverage and uniqueness, and retrieves the best strategy for the original question. At answer time it extracts from D the text segments relevant to each selected skill, creates a prompt containing the original question, focused context, analogous example, and strategy, then lets an LLM produce the answer. The computation record is therefore template, analogous example, candidate plan, score, focused evidence, and answer; it gives the system visible handles for controlling the amount and direction of inference work.
