Agent-Diff Bench currently contains 224 tasks across Slack, Linear, Box, and Google Calendar. Its sandbox implements 108 API endpoints and provides an 80/20 train-test split. Each task includes an initial database template, a natural-language request, available interfaces, and expected-state assertions. The data object is an initial state–agent code/API calls–final state diff–assertion result record, usable as both a benchmark and an RL environment with outcome rewards.
