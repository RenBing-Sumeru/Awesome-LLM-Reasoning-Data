The central distinction is between “looks related” and “supports the answer after inference.” The survey organizes methods by where reasoning enters the pipeline: benchmark construction, retrieval, or reranking. This lets a reader compare systems that spend computation on query understanding, evidence selection, or final ordering without treating them as the same intervention. Its practical frame is a query, candidate evidence, an inferential connection, and a ranked result. When a system improves, ask which element changed. Did it recover better candidates, make the link between query and evidence clearer, or reorder an existing set more effectively? The answer determines both the likely cost and the evidence needed to support the claim.
