AgentHER's contribution is to convert a recoverable failed episode into positive supervision for what the same episode actually achieved, while retaining explicit selection and validation signals. Instead of rewriting the trajectory, it infers an observation-supported hindsight goal and pairs that goal with the original behavior.

The core data object has three layers. The source layer stores the original goal and a full thought-action-observation episode with its failure reason. The relabeling layer stores a six-way failure type—`incomplete`, `constraint violation`, `wrong result`, `tool error`, `hallucination`, or `off topic`—recoverability, a severity weight, actual achievements, key observations, the hindsight prompt, rationale, and judge confidences. The consumption layer packages the accepted object as SFT, DPO, or ShareGPT. For DPO, the chosen conversation uses the hindsight prompt plus the trajectory, while the rejected conversation uses the original prompt plus that same trajectory; the prompts therefore differ.

The feedback contract is mixed. WebArena or ToolBench supplies the original failure/success outcome. For relabeling, the paper uses gpt-4o-mini to extract outcomes and propose a hindsight prompt, then Qwen2.5-72B-Instruct at `T=0` as an independently trained second judge. Each judge is intended to reach `theta=0.5`, with up to `K=3` attempts. Algorithm 1 also allows a best single-judge fallback at `0.8*theta=0.4`, so the operational boundary is weaker than an unqualified “both judges agree” summary. Severity then scales the SFT loss or DPO margin; it is a sample weight, not an environment reward or RLVR signal.

The direction is failure-to-demonstration relabeling for agent trajectories. Compared with success-only SFT, AgentHER tries to recover useful behavior from failures. Compared with goal-conditioned hindsight experience replay, the relabeled goal is natural language and validated by LLM judges. Compared with ordinary synthetic preference construction, the same fixed episode appears under two different goals, so downstream DPO code must preserve prompt context rather than treating the pair as two answers to one prompt.

The category rationale follows the object and feedback surface: full episodes, pairwise preferences, and scalar weights are attached to offline environment traces. State/action fields are present, but there is no step-local correctness label, process reward, replayed success check, or policy-gradient objective. The nearest comparisons should therefore be methods that relabel failed agent trajectories or analyze failure retention, not generic agent benchmarks or RLVR datasets.
