Most software-engineering benchmarks evaluate fixing known bugs, while much real development adds new functionality to existing repositories from product requirements. Feature-driven development often spans functions and files, requiring dependency understanding, interface implementation, and developer tests. Function-level datasets lack repository context, and real issue corpora rarely provide training scale, runnable environments, and stable rewards together.

SWE-Dev reverse-constructs development tasks from complete implementations in existing repositories. It hides core implementation code, retains repository context and developer-authored unit tests, and generates product-requirement descriptions. The release contains 14K training and 500 test samples, each executable in its environment, supporting feature-development evaluation, SFT, and test-reward RL.
