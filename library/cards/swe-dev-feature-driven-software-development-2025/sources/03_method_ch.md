1. **筛选可执行项目：** 从热门 PyPI 包获取仓库，自动安装依赖并运行原测试；只保留 Docker 中可稳定通过的项目与测试文件。

2. **定位功能边界：** 用 Python tracing 记录测试触发的函数调用树，将开发者测试映射到相关实现，并选择适合独立隐藏的核心函数或类。

3. **构造不完整仓库：** 删除或替换目标实现，保留接口、上下文和测试；原始代码成为 gold implementation，执行测试确认隐藏后任务失败、恢复后通过。

4. **生成 PRD 与划分：** 根据原实现、调用关系和测试生成产品需求描述，人工检查 500 个测试实例并按难度分组。复现需固定 commit、容器、测试选择和遮蔽规则，防止其他文件残留同功能实现。
