SWE-Dev’s core object is not a bug-fix patch but a feature-development instance containing a PRD, incomplete repository, complete implementation, developer tests, and execution environment. From 8,000 popular PyPI packages, the authors retain 1,072 verifiable repositories and 9,314 executable test files. Dynamic tracing maps tests to call trees, core tested functions are hidden, and the original implementation becomes ground truth. The dataset has 14,000 training and 500 test records, with the test set manually divided into 250 easy and 250 hard tasks; an average task requires roughly 190 lines across multiple files. Unit tests filter construction and provide terminal rewards for SFT, RL, and evaluation.
