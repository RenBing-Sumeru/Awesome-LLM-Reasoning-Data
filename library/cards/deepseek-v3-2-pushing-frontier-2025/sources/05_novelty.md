For a frontier disclosure ledger, the notable contribution is the unusual specificity of the agent-task layer. The report does not merely say that synthetic tool data were used: it separates real and synthetic environments, extracted and synthetic prompts, four task families, exact prompt counts, and family-specific feedback. Search combines evidence gathering, adversarial candidate generation, verification, and rubric scoring. Code repair defines an executable gold-patch contract. General agents co-synthesize databases, tools, tasks, solutions, and verifiers.

The report also connects data design to optimization stability. Specialist distillation supplies both reasoning and direct-response behavior; cold-start examples introduce multi-call tool use; mixed RL combines rule-based and model-based feedback; and Scaling GRPO addresses KL estimation, off-policy samples, MoE routing mismatch, and truncated sampling. This is a richer report-level construction account than a benchmark-only model card.

A second useful idea is reasoning persistence around tools. Reasoning state is kept when only tool outputs are appended, but discarded when a new user message arrives, while tool-call history remains. The design reduces repeated re-derivation across calls, though it interacts poorly with frameworks that encode tool events as user messages. This makes the conversation-role convention part of the effective environment contract.

The novelty stops at disclosure. The 85K prompt ledger, illustrative templates, equations, model weights, and inference code do not expose the actual SFT records, policy episodes, rewards, environment packages, training implementation, or acceptance ledger. The Card therefore treats these mechanisms as reported design, not a reusable open recipe.
