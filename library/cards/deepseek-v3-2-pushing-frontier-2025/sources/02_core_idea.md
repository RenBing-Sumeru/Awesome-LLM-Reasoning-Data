The post-training design has three connected layers. Specialist distillation first creates domain models from the same DeepSeek-V3.2 base for writing, general question answering, mathematics, programming, logical reasoning, general agents, coding agents, and search agents. The domains support reasoning and direct-response modes, and different generators produce long reasoning responses and direct answers. Their outputs are distilled into a common checkpoint, but the specialist identities, corpus sizes, acceptance rules, and row schema are not reported.

A cold-start layer joins existing non-agent reasoning data with non-reasoning tool-use data through task-specific control instructions and dedicated reasoning delimiters. The examples teach both direct tool calling and multiple calls inside a reasoning sequence. The report publishes a few illustrative templates, not the cold-start corpus. It explicitly notes that these early tool-use reasoning patterns can be fragile and mainly provide initial trajectories for later RL.

The final layer merges reasoning, agent, and human-alignment tasks into one GRPO stage. Reasoning and agent tasks receive rule-based outcome reward, a length penalty, and a language-consistency reward; general prompts use a generative reward model with prompt-specific rubrics. DeepSeek-V3.2 undergoes thousands of continued-RL steps. Speciale instead uses reasoning-only RL with a reduced length penalty and also incorporates DeepSeekMath-V2 data and reward methods. Thus the official model and Speciale encode different cost-versus-reasoning choices rather than being interchangeable releases.
