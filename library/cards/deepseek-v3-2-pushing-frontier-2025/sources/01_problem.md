Frontier model reports can disclose impressive reasoning and agent results while leaving the training objects inaccessible. DeepSeek-V3.2 is a particularly important disclosure case because its report gives exact counts for four agent-task categories, describes several construction and verification pipelines, and explains modifications for scaling GRPO. At the same time, the official release provides model weights and inference support rather than a post-training dataset or runnable training stack.

Four claims must therefore remain separate. First, the DeepSeek-V3.2 and DeepSeek-V3.2-Speciale weights are downloadable. Second, encoding and inference code is downloadable. Third, the report describes how specialist distillation, cold-start examples, mixed RL, and agent-task synthesis were organized. Fourth, benchmark tables describe model behavior under stated and sometimes internal evaluation settings. None of these claims means that the prompts, trajectories, rewards, environments, or filtering decisions are available as data.

The audit object is a disclosure ledger, not a dataset card for a released corpus. It asks which prompts and episodes were produced, who or what generated them, which tools and verifiers supplied feedback, what entered SFT and RL, and which artifacts make those statements replayable. The report answers some questions at aggregate or method level, but record-level source lineage, complete mixture accounting, rejected candidates, rollout groups, environment snapshots, and rights remain unknown.
