The final release contains 101 single-turn research prompts across ten domain categories and more than 2,500 weighted expert rubrics, usually 20–43 criteria per task. Tasks are labelled for conceptual breadth, logical nesting, and exploration. Built with over 2,800 hours of human labour, the release includes prompts, rubrics, complexity metadata, and evaluation code for deep-research scoring, judge calibration, and error localisation.
