The main contribution is 498 autonomous-investigation optimization tasks and an expert-anchored metric. The dataset covers NumPy, pandas, SciPy, scikit-learn, Matplotlib, xarray, SymPy, Dask, and Astropy. Each record includes a base commit, slow workload, gold performance pull request, coverage-selected correctness tests, container, and repeated timing baselines. A patch receives a performance score only after passing relevant tests. `SR = model speedup / expert speedup`, aggregated by harmonic mean, with 1.0 matching the expert. The automated pipeline combines pull-request keywords, static analysis, coverage, and execution validation, supporting performance-agent benchmarking and continuous rewards.
