SWE-Perf already uses real performance pull requests but offers target-function or oracle settings and emphasizes speeding up a specified region, while SWE-bench uses fail-to-pass repair. SWE-fficiency evaluates the full investigative workflow: agents receive only a slow workload and must profile, localize files and tests, and perform pass-to-pass optimization. It also scores model speedup relative to the expert on each task instead of using raw runtime or a binary pass. The work proposes no optimizer; it changes information exposure, workflow, and metrics so minor gains are distinguished from expert-level improvements.
