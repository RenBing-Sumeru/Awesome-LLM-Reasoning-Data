作者通过改变在允许回答结束前可生成的思考 token 数来定义测试时预算控制。他们研究顺序控制：抑制思考结束标记，并追加“稍等”或“再多想想”等提示，再把准确率与平均思考 token 用量对应起来。为解释得到的曲线，论文使用一个简单概率模型：策略方差增大起初会增加与奖励区域的重叠，之后却会稀释概率质量并降低期望奖励；作者还实证测量了回答分布的熵。

在替代分配中，总预算 B 被划分给 N 条独立生成的推理轨迹，而非全部交给一条轨迹，最终答案由多数投票选择。实验在 GSM8K、MATH-500 与 AIME 2024 上比较这些流程，所用模型为 DeepSeek-R1-Distill-Qwen-1.5B、DeepSeek-R1-Distill-Qwen-7B 与 DeepSeek-R1-Distill-Llama-8B。其记录的决策表面很明确：方法、token 预算、轨迹数量、轨迹输出、聚合规则、准确率和平均 token 数。
