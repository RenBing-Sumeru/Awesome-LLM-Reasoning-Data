人们很容易把每一个额外推理 token 都用于强迫同一条推理轨迹继续，例如追加“稍等”或“再多想想”之类的提示。这一规则把测试时计算当作单调增加的量：既然少量额外思考能提高准确率，更多思考理应带来更多提升。它却没有原则性办法判断何时轨迹已不再有效，也无法决定相同预算是否应该用来产生独立尝试。

本文研究顺序延长推理轨迹是否真的改善推理，以及当它不能改善时应如何使用固定的思考 token 预算。相关对象是一条受预算约束的记录，其中包含提示、一个或多个推理轨迹、它们的 token 成本、最终答案与选择规则。论文检验有益审慎思考和过度思考之间的边界，再比较把 token 分配给一条长路径与分配给多条独立路径的效果。
