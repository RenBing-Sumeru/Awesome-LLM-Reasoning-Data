It is tempting to spend every additional inference token by forcing one reasoning trace to continue with prompts such as “Wait” or “Think more.” That rule treats test-time computation as a monotone quantity: if a little extra thinking raises accuracy, much more should raise it further. It leaves no principled way to identify when a trace has become unproductive or to decide whether the same budget should instead produce independent attempts.

This paper asks whether sequentially extending a reasoning trace really improves reasoning, and how a fixed thinking-token budget should be used when it does not. The relevant object is a budgeted record containing a prompt, one or more reasoning traces, their token cost, final answers, and a selection rule. The paper tests the boundary between useful deliberation and overthinking, then compares allocating tokens to one long path with distributing them across several independent paths.
