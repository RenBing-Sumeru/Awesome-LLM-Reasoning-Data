在论文报告的三个数学基准和三种蒸馏推理模型上，顺序策略呈现非单调曲线：开始增加思考会提高性能，而继续得足够长又会使性能下降。GSM8K 的一个报告实例显示，平均思考长度从 385 个 token 增至 1,100 个时，准确率由 82.2% 升至 87.3%，但达到 15,980 个 token 时又降至 70.3%。同一分析还报告，将一个模型的思考从 385 个 token 延长到 6,136 个时，测得的输出熵从 0.23 增至 2.79。

并行比较使用相同的总 token 预算，而不是让其方法获得无限增加的额外计算。论文报告，在 16K token 预算下，并行思考相较顺序延长最高可获得 22% 的准确率提升，并且在图示设置中会随预算增加而保持或提高准确率。这支持了更窄的结论：顺序续写可能是低效的分配策略；它并未证明多数投票对任意任务、模型家族或成本指标都是最优选择器。
