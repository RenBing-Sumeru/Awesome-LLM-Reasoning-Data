KodCode treats a coding demonstration as a question-solution-test record with visible generation trials, coverage, difficulty, and lineage, then adds a test-accepted DeepSeek-R1 reasoning response for SFT. GPT-4o regenerates both solution and tests up to ten times so hard questions are not rejected after one failure, while program execution and 100% branch coverage decide acceptance; this Card therefore belongs to instruction/demonstration/rationale data, although the same tests can also support RLVR.

Open dataset: yes. Dataset names: KodCode-V1 and KodCode-V1-SFT-R1. Official URLs: https://huggingface.co/datasets/KodCode/KodCode-V1 and https://huggingface.co/datasets/KodCode/KodCode-V1-SFT-R1. Scale: paper V1 has 447K triplets; current V1.1 exposes 484,097 train plus 3,335 caution records, and R1-SFT exposes 268,211 verified train, 210,787 incorrect, and 4,439 caution records. Record form: version/style/subset/question ID, question, canonical solution, tests and function metadata, GPT trial/pass/difficulty fields, R1 trial/pass/solution fields, conversations, lineage metadata, benchmark similarity, and caution reason. File/storage format: sharded Parquet. Domains/languages: English Python tasks across twelve families from basic functions to competitive programming and package documentation. Construction and filtering: multiple generators write questions, GPT-4o writes solution-test pairs, pytest/stdio execution plus branch coverage verifies them, and tests reject failing R1 responses. License/access constraints: public and ungated CC BY-NC 4.0; code is Apache-2.0 and upstream seed terms require review. Intended use: SFT and test-reward RL.
