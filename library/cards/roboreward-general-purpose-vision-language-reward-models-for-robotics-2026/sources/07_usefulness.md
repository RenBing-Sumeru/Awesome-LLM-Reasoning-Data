Researchers training robotic VLM reward models can directly fine-tune a model using RoboReward’s videos, tasks, five-level rewards, and validation outputs, then report MAE on RoboRewardBench. Success checks should include overall error, per-subset error, and gains over the corresponding base architecture under fixed conditions. Researchers who already possess successful demonstrations but lack failure data can reuse the counterfactual-instruction generation, video-clipping, and rubric-validation pipeline to produce reward records covering failures and near-misses, followed by a manual audit of automated validation errors. Existing VLMs can also be compared using the released prompts and 2,831 human-verified examples. The approach is unsuitable when the application requires per-action rewards, continuous control feedback, or success criteria that cannot be inferred from the rollout’s visible end state.
