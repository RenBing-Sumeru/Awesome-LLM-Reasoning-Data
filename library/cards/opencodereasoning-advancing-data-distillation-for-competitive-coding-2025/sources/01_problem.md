Published at COLM 2025, OpenCodeReasoning asks how far supervised distillation can scale competitive-programming reasoning when human-written solution traces are scarce and existing open reasoning collections are smaller or incompletely documented. Its Atlas relevance is the construction and release contract: public programming questions are deduplicated, expanded with DeepSeek-R1 reasoning-and-code responses, filtered, released with source metadata, and used for SFT.

A training record is a competitive-programming prompt (or an index that reconstructs it from a source dataset), a DeepSeek-R1 response containing a reasoning trace and final Python code block, extracted solution code, and source/split/license/difficulty identifiers. The paper reports 736,712 Python records over 28,904 questions; the Hugging Face 1.0 card instead reports 735,255 records over 28,319 questions, so revision identity is part of the data object.

The work does not introduce a new functional verifier, prove that every released answer is correct, or study RL training. It reaches L4 because the full paper and appendix, COLM/OpenReview record, dataset, models, and recipe are public and auditable, while exact OCR-1 release lineage, rejected generations, per-row execution labels, and unified source rights remain incomplete.
