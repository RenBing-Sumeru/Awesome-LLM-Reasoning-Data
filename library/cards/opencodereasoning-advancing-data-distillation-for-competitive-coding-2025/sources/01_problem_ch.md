OpenCodeReasoning 发表于 COLM 2025，研究在人写解题轨迹稀缺、已有开放推理集合规模较小或文档不完整时，竞赛编程推理的监督蒸馏可以扩展到什么程度。它对 Atlas 的价值在于构造与发布契约：对公开编程问题去重，用 DeepSeek-R1 扩展出推理与代码响应，完成筛选后连同来源元数据发布并用于 SFT。

一条训练记录包含竞赛编程 prompt（或可从源数据集重建它的索引）、带推理轨迹和最终 Python 代码块的 DeepSeek-R1 响应、提取后的解答代码，以及来源、split、许可和难度标识。论文报告 736,712 条 Python 记录、覆盖 28,904 个问题；Hugging Face 1.0 数据卡则报告 735,255 条记录、覆盖 28,319 个问题，因此版本身份本身就是数据对象的一部分。

该工作没有提出新的功能正确性 verifier，没有证明每条发布答案都正确，也没有研究 RL 训练。由于全文与附录、COLM/OpenReview 记录、数据集、模型和配方均已公开且可审计，它达到 L4；但 OCR-1 的精确发布 lineage、被拒绝生成、逐行执行标签和统一来源权利仍不完整。
