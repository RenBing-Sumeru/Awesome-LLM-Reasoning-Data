DebugLM 把原本只存在于外部文档中的来源信息改造成后训练记录里的监督字段。每个来源分配一个独立的单 token 标签;对每条指令—回答记录,普通变体保留原回答,诊断变体在输入中加入论文定义的 DEBUG 触发符,并在目标末尾附加来源标签。加权目标同时训练两种模式,使普通使用无需暴露诊断字段。

同一套标签还构成控制通道。修复样本会把记录与一个抽样得到的隔离标签配对:若隔离标签等于记录的真实来源,目标改为标准化拒答;否则仍学习原回答。部署时,开发者可以请求来源自报,也可以要求模型抑制与某个已标记来源相关的行为。

这里的反馈契约基于标签,而非程序执行。来源监督来自已知的数据集成员关系,修复监督来自来源标签与控制标签是否相等。论文没有报告用于判断某个调试步骤是否修复失败的执行器、运行时观察、补丁验证器或环境奖励。
