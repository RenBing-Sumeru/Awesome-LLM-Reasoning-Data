MTEB: Massive Text Embedding Benchmark defines an evaluation surface in embedding-evaluation, retrieval, semantic-similarity: whether model outputs or agent trajectories satisfy the task-specific feedback contract. The primary source and artifacts are paper: https://arxiv.org/abs/2210.07316; code: https://github.com/embeddings-benchmark/mteb; huggingface: https://huggingface.co/spaces/mteb/leaderboard; doi: https://doi.org/10.48550/arXiv.2210.07316; the local metadata records the source as 2022 / EACL 2023 / arXiv.

The decision boundary is benchmarks_evaluation_surfaces with roles benchmark and verification contract mixed. One benchmark instance is: dataset adapters, embedding model outputs, task-specific labels, and aggregate leaderboard metrics; Benchmark size: 初版覆盖 8 类 embedding 任务、58 个数据集；后续 leaderboard 持续扩展。 This is not a model-training recipe unless the paper separately releases training data; the card treats it as evaluation, audit. It matters for the atlas because the reusable object is an evaluation/data record with a named scorer, judge, verifier, reward, or environment predicate rather than an abstract capability claim.
