**输入与环境构造。** 对 telecom，作者先用未披露的 LLM 起草 product-requirements document、database schema、function、mock database 与 unit test，再人工修改直到测试通过。模拟 user-phone database 与 user tool 也采用相同的 LLM-assisted/人工流程。domain-specific agent policy 由 LLM 根据整理后的 task 与 solution 生成，并由人工联合修订。起草模型、确切 prompt、采样参数、拒绝数量与逐条 review history 均未披露。airline 与 retail 材料继承自 tau-bench，完整逐任务 upstream lineage 不可用。

**任务生成与选择。** 每个 telecom atomic subtask 被实现为 initialization、solution 与 assertion function。兼容 subtask 经组合后，generator 执行 initialization 与 solution、检查 final-state assertion，并验证所有 solution function 都是必要的。15 个 atomic subtask group 生成 2,285 个完整任务。评测 sampler 只保留至少包含两个 subtask 的任务，按 intent、subtask count 与 persona 分 bin，再使用 Python `random.sample` 每个 bin 最多保留三个；CLI 默认 seed 为 42。最终 114 个抽样任务由 29 个 service、36 个 mobile-data 与 49 个 MMS 任务组成，覆盖 2–9 个 subtask，并分配 None、Easy 或 Hard persona。

**Rollout 环境。** orchestrator 初始化彼此分离的 agent CRM、user-phone state 与 message history。每个 turn 由被评测 agent 或 user simulator 发出一条自然语言消息或一次 tool call，对应 tool result 随后成为 observation。实验中的 agent model 是 `gpt-4.1-mini-2025-04-14`、`gpt-4.1-2025-04-14`、`o4-mini-2025-04-16` 或 `claude-3-7-sonnet-20250219`，user simulator 固定为 `gpt-4.1-2025-04-14`。论文采用 temperature 0，每个 task 运行四个 trial。已检查的 v0.1.0 metadata 记录 `max_steps=200`、`max_errors=10`、trial id 与 seed。Default、No-User、Oracle Plan 与 workflow-policy telecom 条件用于分析协作和规划因素。

**验证与输出。** task 可从 DB、environment/status assertion、communication、natural-language assertion 与 action matching 中选择 reward component。evaluator 计算并相乘这些选定 component；environment assertion 也会逐条检查后相乘。episode 可以因 simulator 发出 STOP、TRANSFER、OUT-OF-SCOPE 或 runner guard 而结束，但终止本身不代表成功。每个 `SimulationRun` 保存 task、有序 message 与 tool call、timing、token/cost metadata、termination reason、`RewardInfo`、trial 和 seed。

**发布与用途边界。** 论文时代的 `v0.1.0` release 包含 policy、mock database、generator/evaluator code、2,285 个完整和 114 个抽样 telecom task，以及 26 个 final result JSON。已检查的 GPT-4.1 telecom-default 文件保留 114 task 乘四个 trial 的全部 456 个 episode，其中 156 个 reward-1、300 个 reward-0。这是发布的 evaluation trace set，不是经 teacher 筛选的训练语料。准确 replay 应固定 `v0.1.0`、task file、evaluator revision、model endpoint/version、LiteLLM/provider behavior、run configuration 与外部 credential。论文时代 release 没有 train/dev/test split manifest，也没有披露去污染协议。
