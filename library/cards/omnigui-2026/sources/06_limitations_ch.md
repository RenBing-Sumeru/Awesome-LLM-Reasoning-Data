正确性只是固定离线协议下与专家轨迹一致。它不证明自主 agent 在执行自己前面动作后也能完成任务，不证明能从错误中恢复，不证明能适应 app 更新，也不证明满足录制轨迹之外的用户意图。

环境高度依赖版本。移动应用、UI 布局、媒体流、账号状态、通知和网络行为都会在录制后变化。公开数据包含真实应用中的媒体内容；再分发权和商业使用边界由数据集 license 以及底层 app/媒体权利决定，不能因为 benchmark 有用就自动放开。

指标也有盲区。EM 要求参数一致，替代但有效的坐标或 UI 路径可能被判错；TM 会掩盖空间 grounding 失败；SR 对长 episode 很严格。论文和仓库的 episode/step 数有轻微差异；当前卡片没有官方证据证明存在 hidden split 或 live environment service。
