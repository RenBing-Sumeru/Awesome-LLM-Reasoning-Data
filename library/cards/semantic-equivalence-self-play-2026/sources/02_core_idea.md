Each episode starts from a reference program \(P\). With nominal 50/50 probability, Alice enters one of two games. In SEQ, she proposes a differently implemented \(Q\) and a Liquid Haskell lemma intended to establish \(P(x)=Q(x)\) for every supported input. In SINQ, she proposes \(Q\) and one input \(x_a\) for which execution should show \(P(x_a)\ne Q(x_a)\). Failed proofs or failed divergence checks are rejected before model judgment.

Bob sees only \(P\) and \(Q\), not Alice's witness, and classifies them as equivalent or inequivalent. Ten sampled judgments estimate hardness as \(10(1-N_{correct}/10)\). This separates two contracts: a machine checker determines whether Alice supplied admissible semantic evidence, while Bob's errors provide a curriculum signal rather than ground truth. The asymmetry is deliberate: positive examples require proof within Liquid Haskell's supported fragment; negative examples need only one executable counterexample.
