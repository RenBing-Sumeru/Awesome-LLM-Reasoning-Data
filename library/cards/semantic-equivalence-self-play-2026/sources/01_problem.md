Program-reasoning data often treats compilation or a finite test suite as a proxy for semantics. Neither is sufficient for teaching whether two programs agree on all inputs: compilation checks well-formedness, while passing selected tests can miss rare behavioral differences. Fully proving equivalence is also undecidable in general, so any dataset must state the fragment and oracle it actually covers.

The paper targets this gap in pure Haskell. Its data problem has two layers that must not be conflated: first, build a pool of runnable Haskell reference programs from Python-oriented instruction data; second, derive pairs in which a generator either proves equivalence or exhibits inequivalence. The public release covers the first layer. The second, which contains the proof/counterexample interactions used for agent training, is described and evaluated but not released as a standalone corpus.
