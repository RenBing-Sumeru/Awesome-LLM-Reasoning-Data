R1-Onevision makes the interface between vision and language reasoning an explicit training object: formalize the image, let a strong text reasoner write a solution, ground the solution again through image-aware role-playing, and filter the serialized trace before SFT. Compared with fixed four-stage templates such as LLaVA-CoT, it changes the target from a rigid reasoning format to a revisitable image-grounded trace; final-answer and format rules remain a separate RL feedback contract. The initial category is instruction, demonstration, and rationale data because the released trace is directly consumed as an SFT target rather than only as a reward.

Open dataset: yes. Dataset name: R1-Onevision. Official URL: https://huggingface.co/datasets/Fancy-MLLM/R1-onevision. Scale: more than 155K samples. Record form: image, question, formal visual description, conversation-style reasoning response, and final answer; the public Hugging Face release exposes tabular image-text records. File/storage format: Hugging Face-hosted Parquet/Arrow access. Domains/languages: primarily English science, mathematics, general-scene, and document/chart/screen reasoning tasks. Construction and filtering: GPT-4o describes and filters, DeepSeek-R1 reasons from the formalized view, and role-playing reconnects the trace to the image. License/access constraints: public access is governed by the Hugging Face platform terms, but a dataset-specific content license was not confirmed and platform access does not establish redistribution rights. Intended use: multimodal reasoning SFT and distillation.
