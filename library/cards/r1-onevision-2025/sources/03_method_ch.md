1. **准备并形式化视觉任务。** 输入：来自科学、数学、一般场景以及文档、图表和屏幕领域的图像与问题。操作：规范化每个任务，再让 GPT-4o 生成稠密的形式化视觉描述，显式写出文本推理模型所需的对象、关系、数值和布局。输出：图像、问题与描述记录。检查：论文没有报告确定性的描述验证器。
2. **生成文本推理。** 输入：形式化描述与问题。操作：DeepSeek-R1 根据文本表示写出详细解答和最终答案。输出：候选跨模态思维链。检查：论文未披露生成参数和 rollout 数量。
3. **重新落地并过滤轨迹。** 输入：候选轨迹和原始图像。操作：角色扮演提示让多模态流程重新查看图像，同时由 GPT-4o 删除不准确、不相关或不一致的推理步骤。输出：保留的图像、问题、轨迹与答案示范。检查：拒绝被 judge 判为有缺陷的记录；过滤提示、阈值与假阳性率仍未知。
4. **组装并消费 SFT 集合。** 输入：四个领域组中保留的记录。操作：合并超过 155K 条记录，以 batch size 128、learning rate 1e-5 训练 Qwen2.5-VL 一个 epoch。输出：具备规范化思考与答案格式的模型。检查：在固定视觉推理 benchmark 上比较 base、SFT 与 SFT+RL 版本。
5. **加入规则 RL 并评测。** 输入：SFT 模型和 10K 条 CLEVR 子集。操作：GRPO 按正则提取后的最终答案准确性或 IoU 给奖励，并要求 `<think>` 标签顺序正确；随后在 MathVision、MathVerse、MathVista、WeMath 与 R1-Onevision-Bench 上评测。输出：R1-Onevision 模型与 benchmark 分数。检查：最终分数验证的是 SFT+RL 组合配方，而不是每个生成步骤。

复现要求：固定图像来源、形式化与过滤提示、GPT-4o 和 DeepSeek-R1 版本、数据集快照、Qwen2.5-VL checkpoint、GRPO 代码、CLEVR 子集、奖励正则与评测答案提取器。论文未披露生成和过滤计算量、采样参数、精确来源比例以及 judge 错误率。
