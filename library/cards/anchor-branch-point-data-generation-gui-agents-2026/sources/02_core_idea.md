The principal data object consists of verified seed trajectories, GUI branch states, state-grounded task variants, post-branch actions, step-filter outputs, and complete execution trajectories. The Anchor dataset is publicly linked, but exact current task, trajectory, and split statistics should be taken from its official data card. A useful record preserves the input, current prefix or environment state, candidate behavior, execution or evidence, feedback label, and provenance instead of only a final outcome.
