1. **准备可重放种子。** 从 GUI benchmark 收集少量人工或高质量演示，并确认初始状态和执行结果可复现。
2. **识别轨迹分叉点。** 沿演示定位产生明显界面状态变化的位置，保存截图、应用状态、历史和已完成子目标。
3. **生成状态约束任务。** proposer 根据分叉状态创建新的局部任务变体，避免提出界面中不存在或无法执行的目标。
4. **执行并验证分支。** 代理从该状态完成新任务，state-aware verifier 检查终局，task-conditioned filter 逐步删除无依据动作。
5. **重组扩展轨迹。** 保持新任务意图一致，过滤环境异常和状态冲突，形成 branch-point supervision 与完整 GUI 轨迹。
