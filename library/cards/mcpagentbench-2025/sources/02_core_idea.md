The contribution is to provide a scale that is not fully pinned in local metadata and must be checked against the official release before quantitative reuse for tool-use, agent-environments, interactive-evaluation under a reusable evaluation surface. The core mechanism is the pairing of task inputs and model outputs with the following feedback contract: Completion rate and execution-efficiency metrics judge whether agents choose and invoke MCP tools correctly.

The data object or environment is Real-world MCP task definitions, simulated MCP tools, dynamic sandbox, candidate tool lists, and distractors. The closest comparisons are agent-environment, tool-use, and benchmark-harness papers in the same atlas category. The direction label is environment_agent_trajectory_data with a environmental, programmatic feedback contract. The main thing to preserve is not only the headline score, but the task object, evaluator, split/version, and artifact lineage.
