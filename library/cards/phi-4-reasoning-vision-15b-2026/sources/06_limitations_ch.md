完整训练数据尚未发布。公开来源虽被列出，但其选中子集、转换、混合权重、修改后的许可和训练/验证成员关系均未公开。Microsoft 内部数据和定向采购数据也有实质性未披露。模型卡引导读者查看未填写的 RRRR_nnnn data-card 标签，而不是可访问的完整 data card。

数据修复和验证无法被独立审计。报告提到 GPT-4o、o4-mini、人工审查和偶尔的验证或 majority voting，却没有发布提示、模型版本、采样、阈值、纠错率、false-accept/false-reject 率或拒绝记录。没有披露污染协议或测量。官方 Hugging Face 模型卡和 GitHub README 还错误引用了 arXiv:2511.19663；该编号属于 Fara-7B，而非本模型报告，正确主记录是 arXiv:2603.03975。

Microsoft 指出，学习到的推理/直接回答切换可能并不最优，20/80 混合未必适合每个领域，细粒度视觉理解仍有限。模型卡还提醒以英语为中心的性能、偏见、不可靠或编造的输出、不当内容，以及不适合高风险使用的情形。
