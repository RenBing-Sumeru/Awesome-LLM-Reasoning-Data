SWE-bench defines success as failing tests becoming passing, while KernelBench measures correctness and speed for isolated GPU kernels. SWE-Perf retains real performance pull requests, relevant tests, and expert runtimes within full repositories and requires agents to preserve functionality while reducing runtime. It also offers oracle target-function and realistic problem-statement settings, separating optimization with known localization from autonomous localization. The work does not propose a new optimization algorithm; it converts real repository performance patches into replayable tasks and makes runtime improvement part of the formal verifier contract.
