The authors compare file-level and repository-level methods such as Agentless and OpenHands over the same 140 environments. The best AI system still trails expert patches by about 8.59 percentage points, and tasks with longer runtimes or larger expert speedups are harder. Error analysis suggests that models may edit related code yet lack architectural performance reasoning. All 140 tasks come from real pull requests and repeated measurements, supporting realism. Results remain sensitive to whether target functions are provided, hardware noise, and agent scaffolds. Expert patches are not necessarily theoretical optima, so the evidence shows a gap to the engineers who authored those pull requests rather than an absolute human ceiling.
