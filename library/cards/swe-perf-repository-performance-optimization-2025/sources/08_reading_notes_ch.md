1. **一句话定位：** SWE-Perf 从 102,241 个 PR 筛出 140 个真实仓库性能优化任务，同时验证正确性和运行时间。

2. **方法抓手：** 性能 PR 筛选、前后版本重放、重复计时、稳定加速检查和 oracle/realistic 输入构成流程。

3. **数据抓手：** 每条含 commit、测试、目标函数、描述、专家 patch、运行时间与环境；无 train split，默认全部评测。

4. **证据锚点：** 最佳 AI 与专家仍差约 8.59 点，长运行和高专家加速任务更难，模型缺乏架构级推理。

5. **复用决定：** 适合 correctness–performance 双目标评测；最大风险是计时噪声和 test 污染，必须固定硬件并禁止训练。
