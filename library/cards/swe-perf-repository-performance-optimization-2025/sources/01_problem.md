Coding-agent benchmarks mainly check whether functionality is repaired and rarely measure whether a patch makes production code faster. Function-level kernel benchmarks reveal target locations and omit bottleneck localization, relevant-test selection, and behavior preservation in large repositories. A model can produce correct but slower code, which ordinary Pass@1 does not distinguish.

SWE-Perf constructs 140 tasks from real performance-improving pull requests. Each provides a complete repository, target functions or a realistic problem statement, performance-related tests, an expert patch, and an executable environment. Agent patches first pass correctness checks and then have before–after runtime measured. The benchmark uses real expert optimizations as references for repository-level performance engineering.
