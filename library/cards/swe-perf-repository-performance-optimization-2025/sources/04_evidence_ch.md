作者使用 Agentless、OpenHands 等 file-level 与 repository-level 方法，在同一 140 题环境中比较多种模型。最佳 AI 系统与专家 patch 之间仍有约 8.59 个百分点的性能差距，且运行时间更长、专家加速幅度更大的任务更难；错误分析显示模型常能改到相关代码却缺乏架构级性能推理。140 题均由真实 PR 和重复运行筛出，支持 benchmark 的现实性。结果仍受目标函数是否提供、硬件噪声和 agent scaffold 影响；专家 patch 也不一定是理论最优，因此证据说明“当前模型明显落后于提交该 PR 的工程师”，不能定义绝对人类上限。
