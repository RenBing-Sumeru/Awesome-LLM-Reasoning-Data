The main contribution is the first systematic benchmark for real repository performance optimization. From 102,241 pull requests across nine Python repositories, the authors filter 140 stable instances. Records include base and head commits, performance tests, target functions, oracle and realistic problem descriptions, expert patches, baseline and expert runtimes, environment versions, and fields such as `human_performance`. The contract requires both functional tests and improved runtime, distinguishing it from correctness-only SWE-bench. The Hugging Face release has no separate training split and defaults entirely to test, supporting performance-agent evaluation, bottleneck localization, and joint correctness–efficiency rewards.
