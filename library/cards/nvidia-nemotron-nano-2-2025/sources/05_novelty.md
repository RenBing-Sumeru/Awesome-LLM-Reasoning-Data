The report’s strongest contribution is end-to-end coupling of alignment data with compression recovery. Reasoning-off and deliberately truncated traces make inference budget a supervised data field; WorkBench turns database state into a terminal predicate for on-policy DPO; GRPO adds learned judgment for chat; post-RL KD and model merging explicitly recover capabilities lost during targeted optimization. The released dataset makes more of this pipeline auditable than a typical frontier report, although it is not an exact immutable snapshot of every record used.
