The early public release reports 276 long-horizon GUI tasks. Each contains a natural-language intent, causal pathway, atomic steps, environment states, and automatic checkers, together with diverse and self-correcting trajectories generated by a hierarchical agent and human-verified. The ACL 2026 version further emphasizes decoupling logical pathways from linguistic narratives. The data objects are both benchmark tasks and observation–action–state–step-verification trajectories for GUI evaluation, RFT, and recovery research.
