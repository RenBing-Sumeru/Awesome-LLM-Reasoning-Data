1. **收集真实意图：** 从人类常见 GUI 操作中抽取长程目标，保留跨页面依赖、条件分支和上下文引用。

2. **构造因果路径：** 将目标拆成有先后依赖的原子状态变化，为每一步编写程序化检查条件，并验证完整路径可执行。

3. **自然化任务叙述：** 将结构化路径转换为更接近真实用户的非线性语言，避免提示直接泄漏操作顺序。

4. **生成并审计轨迹：** hierarchical agent 先进行宏观规划和微观执行，保存包括回退与自修正在内的轨迹，再由人工复核关键状态。

5. **分层评分：** 依据原子步骤和整条 pathway 计算成功率，而非只比较最终截图。
