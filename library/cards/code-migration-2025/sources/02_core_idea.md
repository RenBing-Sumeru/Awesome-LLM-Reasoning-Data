One-sentence contribution: Code Migration evaluates whether models can reimplement real-world programs in another language and pass hidden behavioral tests in an offline sandbox. The core mechanism is to turn a realistic task substrate into an observable input-output-scoring contract rather than only reporting model impressions.

Inputs come from Repository-level source program plus target-language migration instructions.; outputs are Target-language repository/program submission.; feedback is Hidden test suite plus anti-cheat checker; CLI score averages across target-language migrations. It belongs under benchmark/evaluation surfaces because the central artifact is the measurement contract. Closest comparisons are other benchmark surfaces in the same domain, but this card should be read at the level of the released task object and scorer rather than as a broad model capability claim.
