Prior baselines are generic benchmark leaderboards, single-answer task sets, or narrower domain tests. What changes here is the measurement surface: it asks whether a model can complete Target-language repository/program submission. under hidden tests and anti-cheat checks.

The direction signal is useful because it moves evaluation toward the artifact or workflow that users actually inspect. The quality signal is strongest when the scorer, split, and artifact version are explicit. What is not new is the general idea of benchmarking models; the reusable contribution is the particular task object plus feedback contract. Reuse checks should ask: pin target-language list, task version, license, and any public/held-out split policy; do not read test pass as full semantic equivalence.
