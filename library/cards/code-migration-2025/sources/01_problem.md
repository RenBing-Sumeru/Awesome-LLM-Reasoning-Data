Primary source: https://www.vals.ai/benchmarks/code-migration. Venue/status: Vals AI benchmark page, 2025. The problem is to evaluate Target-language repository/program submission. under a benchmark surface whose feedback is hidden tests and anti-cheat checks. The decision boundary is evaluation and audit: it is not a training recipe, not a general proof of model reliability, and not a reusable reward unless the official source separately releases that contract.

The data object is composed of source repository, target language, generated migration, hidden test result, anti-cheat result, score. The benchmark matters because it measures a concrete surface that ordinary static QA or single-function coding tests do not fully cover. For screening, read the card with the source version, scorer, split policy, and released artifacts attached to any claimed score.
