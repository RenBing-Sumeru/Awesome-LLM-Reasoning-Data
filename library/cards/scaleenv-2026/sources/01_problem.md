ScaleEnv tackles the shortage of diverse, executable environments for tool-use RL. Real APIs are costly, slow, and safety-constrained; LLM simulators can hallucinate state; manually integrated sandboxes do not scale. The method therefore generates the action space, state schema, executable code, tasks, and verifier from domain names rather than adapting a fixed API collection.

The reported training universe contains 16 synthetic domains and 2,560 tasks. An environment has about 50 tools and 5–20 database tables on average; the appendix reports roughly 25 to more than 70 tools and 5 to 22 tables across domains. Per-domain task counts range from 64 to 512. Each task binds an initial database state, distractors, user profile and intent, executable seed chain, expected final state, and matching rules.

The learning object is an interactive rollout: user-simulator messages, natural-language agent responses, tool calls, tool results or errors, database mutations, and a terminal state reward. ScaleEnv documents how to synthesize these objects, but the complete environments, 2,560 tasks, rollouts, rewards, code, models, and reset/replay package were not verified as public artifacts.
