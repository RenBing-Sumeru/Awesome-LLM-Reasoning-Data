ScaleEnv separates domain foundation from task instantiation. The foundation starts with tool and database schemas, implements database code before tool code, and validates both through generated tests. A dependency graph then records data flow, pre/post-conditions, and shared-table state dependencies among verified tools.

Task construction samples an executable seed chain, instantiates the smallest consistent database state, injects schema-valid distractors, and generates a grounded user profile and intent. Dependency-aware breadth-first expansion adds tools only when their inputs and outputs are satisfiable; an LLM-gated stage adds further chains, and every extension is executed so the state can be repaired. This makes exploration space broader than the reference path.

Feedback has two programmatic layers. Procedural tests distinguish 3 outcomes: success, anticipated rejection, and unexpected failure; the last triggers debugging. Terminal reward compares final database columns under 3 policies: exempt fields, exact hard constraints, and fuzzy semantic alignment. The Qwen2.5-72B-Instruct user simulator supplies dialogue feedback, but it does not replace the database-state verifier.
