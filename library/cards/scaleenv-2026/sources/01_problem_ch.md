ScaleEnv 面向工具使用 RL 中多样、可执行环境稀缺的问题。真实 API 成本高、速度慢并受安全限制；LLM simulator 可能虚构状态；人工集成 sandbox 又难以扩展。因此，该方法从领域名称生成动作空间、状态 schema、可执行代码、任务与 verifier，而不是改造固定 API 集合。

论文报告的训练 universe 包含 16 个合成领域与 2,560 个任务。每个环境平均约 50 个工具和 5–20 张数据库表；附录显示各领域约有 25 到超过 70 个工具、5 到 22 张表。单领域任务数从 64 到 512。每个任务绑定初始数据库状态、干扰项、用户 profile 和 intent、可执行 seed chain、预期终态与匹配规则。

学习对象是一条交互 rollout：用户 simulator 消息、智能体自然语言响应、工具调用、工具结果或错误、数据库变更，以及终局状态奖励。ScaleEnv 说明了这些对象如何合成，但完整环境、2,560 个任务、rollout、奖励、代码、模型与 reset/replay 包均未核实为公开工件。
