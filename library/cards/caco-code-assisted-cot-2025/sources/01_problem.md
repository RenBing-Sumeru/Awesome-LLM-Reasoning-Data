The formal record is the NeurIPS 2025 proceedings paper, with arXiv:2510.04081 providing the full text and appendix. This Card also checks the official GitHub repository at commit `ceb525c57a9fea22dd2d0cf84bfc9dc2f5169375` and the official Hugging Face dataset at revision `664f036126e9b82533c769b74ef27c7c0ccd1398`, as visible on 21 July 2026. The formal author order is preserved in the metadata.

Caco addresses a scaling problem in reasoning-data construction. Rewriting an existing question changes surface form but tends to preserve its reasoning pattern, while asking a large language model to invent both a new problem and a solution lacks a dependable correctness anchor. Caco instead treats an executable Python program as an intermediate reasoning object: standardize source solutions into programs, learn to sample new programs without a problem prompt, execute and filter them, then reconstruct natural-language questions and solutions.

The released object is currently one Hugging Face `train` split with exactly 1,348,799 rows. Each row has four string fields: `instruction`, `output`, `answer`, and `code`. `instruction` is the reversed problem; `output` is its natural-language chain of thought and final response; `answer` is the extracted final answer; and `code` is the executable Code CoT from which the instruction was reconstructed. The single file, `cacov2_1.3M.jsonl`, is 3,130,228,421 bytes and has LFS SHA-256 `919050aa7495d1811999c1ff0f7eec1675abaf061ffa5eedddc96168d8d5e946`. There is no released validation/test split.

The source mixture contains MATH (7.5K), DeepScaleR (40K), BigMath (251K), and KodCode (40K). Qwen2.5-72B-Instruct translates their solutions into a common program template; execution and available answer checks retain 146K seed programs, reported as 122K math and 24K algorithmic/code records. An unconditional Qwen2.5-Coder-7B generator then samples about 5.3M programs, structural/execution filtering retains about 4.6M, and problem reversal plus language-solution generation and final checks produce the released 1.3M-scale corpus.

This is directly in scope for `data_construction_open_release_recipes`: the paper identifies the data object, synthesis stages, feedback layers, scale funnel, SFT use, and an open artifact. The `partial` status is also material. The release omits row-level source and parent lineage, execution logs, per-stage decisions, rejected candidates, full generation/reversal/judge code, and decontamination evidence; those absences prevent complete reproduction or audit even though the final rows and some filtering/training helpers are public.
