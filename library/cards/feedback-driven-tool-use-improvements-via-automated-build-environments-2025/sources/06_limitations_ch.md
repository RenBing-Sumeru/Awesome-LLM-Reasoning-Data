- **公开数量不是 trajectory 数量。** 2,215 个 train item 与 200 个 test item 是 executable environment definition。paper-run history、逐 epoch manifest、总 rollout 数、success/failure/error 计数、terminal answer 与 dropped-state 数均未公开。sampler 保留 initial state 与 tool-calling state，包括失败 call，却丢弃 terminal no-tool response，因此公开记录不能构成完整 episode。
- **Verifier 对文本形式敏感。** `answer_verify` 仅做有限 normalization 后使用 substring containment。预期文本泄露在冗长 observation 中或与其他字符串碰撞，可能产生 false positive；语义等价的 alias、数字/日期格式或 structured output 可能产生 false negative。论文没有报告 calibration rate、adversarial test 或 semantic adjudicator。正 reward 只能证明符合该 string contract，不能证明 reasoning 或现实事实正确。
- **Reward 可能被 gaming。** 论文自身显示，completion-only feedback 会鼓励 tool overuse。final-answer containment branch 也可能在没有完成全部预期 tool step 时给出正 reward。粗粒度 penalty 混合了 malformed markup、parser failure、missing function、timeout、environment exception 与 policy reasoning failure，使诊断更困难。
- **没有外部 sandbox 时执行不安全。** `call_function` 通过 unrestricted in-process `exec` 执行 row 提供的 Python。10 秒 timeout 不限制 filesystem、network、subprocess、import、persistence、secret、CPU 或 memory。在普通 training host 上运行不可信或被修改的 row，可能执行任意代码；隔离与 least privilege 是必需条件，不是可选优化。
- **Synthetic consistency 可能偏离现实。** GPT-4o 生成的 function 可能编码陈旧、不完整或错误事实。成功执行加 substring agreement 只说明 local environment 内部一致，不能证明 tool 忠实于真实 API、observation 符合事实，或该 call 具有因果上的用途。
- **Construction lineage 不完整。** Appendix D 提供五阶段流程的 prompt，但 repository 没有端到端 construction script、中间 GPT-4o generation、source-fact identifier、human review/adjudication log 或 item-level provenance。人工 question 与 embedded fact 的准确来源、annotator、fact-checking、privacy、consent 与权利均为 unknown。
- **Replay 与 release versioning 不完整。** 正式 publication 是 ACL 2026，而 slug 反映 2025 年 arXiv 首发。repository main 审计于 `7022ef...`，但论文没有 pin commit；也没有 tag 或 GitHub release。准确 checkpoint、seed、完整 decoding setting、paper-era VeRL revision、Python/CUDA/driver/container pin 与 checkpoint-to-table mapping 均缺失。公开 script 每次 invocation 设置为 1 个 epoch，而论文报告 3 个重新采样 epoch。
- **License 与 contamination 未解决。** Apache-2.0 明确适用于 code，但没有明确覆盖 raw data、embedded implementation/fact、人工 input 或 bundled upstream benchmark asset。只声明 custom train/test 不重叠；item-level evidence、更广泛 deduplication、public-benchmark overlap、pretraining contamination 与 privacy/consent audit 均为 unknown。
- **实验范围有限。** 结果只覆盖测试的 Qwen configuration 与 tool-use evaluation surface。Qwen 32B/72B variant 仅用于 evaluation。作者承认 tool invocation 的改善大于 underlying reasoning。benchmark improvement 不能证明 environment quality、verifier validity、安全 data reuse 或一般 reasoning improvement。
