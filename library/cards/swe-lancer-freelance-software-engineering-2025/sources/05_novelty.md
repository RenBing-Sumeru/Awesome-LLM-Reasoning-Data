SWE-bench converts authentic GitHub issues into patch evaluations but lacks client payouts, managerial choices, and the value of multi-week projects. HumanEval-style tasks contain even less repository and commercial context. SWE-Lancer does not introduce a fundamentally new testing framework; it changes the sampling unit to completed freelance contracts and preserves actual payment as an evaluation dimension. It also places code implementation and proposal selection in one benchmark. The novelty is therefore task provenance and economic measurement: models receive not only pass/fail outcomes but an estimate of real market value completed.
