SWE-Lancer’s main contribution is to convert real paid software projects into reproducible evaluation objects while preserving their dollar values. Independent tasks range from USD 50 bug fixes to USD 32,000 feature implementations and are judged by end-to-end tests triple-verified by experienced software engineers. Managerial tasks ask models to choose among implementation proposals, using the decision of the manager originally hired for the project as the label. The public Diamond split, unified container, and evaluation scripts enable partial reproduction. The release is primarily an economically grounded benchmark rather than a large open trajectory-training dataset.
