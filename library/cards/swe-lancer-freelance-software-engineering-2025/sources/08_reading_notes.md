1. **One-sentence position:** SWE-Lancer uses real Upwork contracts and payouts to measure how much market software work models can complete.
2. **Method takeaway:** Project filtering, independent/managerial task separation, triple engineer verification, and value mapping are essential.
3. **Data takeaway:** The full set has over 1,400 tasks worth about USD 1 million; public Diamond provides a unified Docker image and evaluation scripts.
4. **Evidence anchor:** Frontier models still fail the majority of tasks, within the boundary of the public subset and inference budgets.
5. **Reuse decision:** It suits economic-impact evaluation, but dollars must not be equated with technical difficulty and should accompany task-level success reports.
