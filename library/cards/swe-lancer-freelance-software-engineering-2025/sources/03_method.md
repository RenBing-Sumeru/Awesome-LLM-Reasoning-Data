1. **Collect authentic projects:** Completed Upwork contracts are organized into task descriptions, code assets, delivered results, and actual payments. Projects without usable rights, code, or replayability are removed.

2. **Separate task types:** Independent engineering tasks require direct code modification, whereas managerial tasks preserve candidate technical proposals and the original manager’s choice, creating execution and decision samples.

3. **Build executable evaluation:** Dependencies and Docker environments are reconstructed for independent tasks. End-to-end tests are written and triple-verified by engineers to distinguish correct from incorrect implementations.

4. **Score performance and value:** Independent tasks are graded by tests, managerial tasks by decision agreement, and payouts of completed tasks are aggregated. The Diamond split is public, while all private project assets are not released.
