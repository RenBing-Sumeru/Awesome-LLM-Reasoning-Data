The prior baseline is mobile-agent evaluation on Android, web/mobile GUI grounding, or isolated app tasks with limited personal state. iOSWorld changes the surface by making a persistent fictional user and cross-app data part of the task world.

The direction signal is personalization under controlled simulation: tasks can require inference over transactions, messages, travel records, social relations, or financial activity without exposing real user data. The quality signal is the open-source release of apps, seeded data, tasks, rubrics, and execution tooling.

What is not new: simulator automation, GUI action traces, rubric judging, and screenshot/XML observations already exist in adjacent agent benchmarks. Before reuse, inspect Apache-2.0 repository scope, any third-party app/data dependencies, judge reproducibility, macOS/Xcode constraints, and whether synthetic personal data matches the target deployment risk.
