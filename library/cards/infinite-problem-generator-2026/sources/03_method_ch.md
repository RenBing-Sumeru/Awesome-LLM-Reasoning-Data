1. **准备种子与公理。** 输入：165 道本科力学专家题及解答，以及教材公式汇编。操作：把公式数字化为经过测试、带类型变量的 Python 函数。输出：种子记录与可执行公理库。检查：每个公理必须能独立执行并标明有效取值范围。
2. **规划场景与公式链。** 输入：一道种子题和公式库。操作：Gemini 2.5 Flash 提出场景类型，选择 3 至 5 个相连公式及目标变量。输出：结构蓝图。检查：目标必须只靠所选公理即可推出。
3. **轮换生成变体。** 输入：结构蓝图与场景列表。操作：在不同场景间轮换，编写自然语言题目、设置受约束数值并生成 Python 求解函数。输出：候选题目与代码记录。检查：公式编号集合和目标变量组成的哈希必须唯一；冲突时重新生成。
4. **执行并修复。** 输入：候选代码。操作：在 sandbox 中运行，并把语法或运行错误反馈给生成器。输出：可执行的有限数值结果。检查：拒绝 NaN、无穷值以及违反基本符号或数量级规则的结果。
5. **审计并裁剪。** 输入：1,415 条生成候选。操作：删除少于两个推导步骤的 80 条记录，并由 Gemini 3 审计文本、公式、代码与答案的语义一致性。输出：1,335 条发布记录。检查：按公式数量报告残余问题，不能把成功执行当作语义正确的充分证明。
