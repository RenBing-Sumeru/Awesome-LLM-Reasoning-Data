The contribution is a benchmark and harness for measuring functional correctness and speed of LLM-generated GPU kernels. The core mechanism turns 250 PyTorch ML workloads into kernel-writing tasks, grouped into levels from single operators to whole architectures, then evaluates generated code with a fixed correctness and timing harness. The evaluation surface is not just pass/fail code generation: a candidate can compile and match outputs yet still fail the optimization goal if it is slower than PyTorch. Closest comparisons are HumanEval/MBPP-style code generation, EvalPlus-style executable checking, and GPU-kernel autotuning systems; KernelBench changes the objective by combining semantic equivalence with latency improvement.
