Ordinary code benchmarks verify only that implementations pass tests, which neither establishes complete specifications nor proves correctness for all allowed inputs. Formal-proof benchmarks usually provide a theorem and do not require models to jointly generate implementations, specifications, and proofs of their alignment.

VERINA decomposes verifiable code generation into code, specification, and proof modules and their combinations. Every task includes natural language, a reference implementation, formal specifications, and tests, enabling precise attribution of end-to-end failures.
