VERINA contains 189 manually curated Lean programming tasks with detailed descriptions, signatures, reference implementations, formal pre/postconditions, proof goals, and extensive tests. It evaluates CodeGen, SpecGen, and ProofGen independently and can feed generated artifacts into downstream stages to measure compositional error. Data and code are released, and the project currently lists ICLR 2026. The data object is a problem–code–specification–proof–test/Lean-result record for modular vericoding evaluation.
