The current ICLR 2026 project page reports one-sample results for OpenAI o3: 72.6% code correctness, 52.3% specification soundness and completeness, and only 4.9% proof success. Thus, test-passing code is much more common than complete specifications and machine proofs. An earlier arXiv version reported 61.4%, 51.0%, and 3.6% for o4-mini, so versions must be distinguished. Lean's kernel and tests provide deterministic evidence, although manually written specifications may still be incomplete.
