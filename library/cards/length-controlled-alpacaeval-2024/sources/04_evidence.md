The paper and official repository report that length control improves the alignment of AlpacaEval 2.0 with external human-preference leaderboards while reducing length gameability. The arXiv abstract reports a Spearman correlation increase with LMSYS Chatbot Arena from 0.94 to 0.98; the official repository README reports the operational AlpacaEval 2.0 comparison as 0.93 to 0.98 and emphasizes that LC win rates are now used by default.

The row-level evidence is still an automatic preference annotation, not a human-certified correctness judgment. The stronger evidence is diagnostic: raw win rate and LC win rate can be compared to expose when verbosity is inflating a model's apparent quality. The numbers are conditional on the official AlpacaEval evaluation set, selected reference model, evaluator prompt/configuration, API model behavior, and the leaderboard snapshot used for comparison.
