Length-Controlled AlpacaEval is a 2024 arXiv paper with a COLM 2024 status note. It asks how to make an automatic preference evaluator less vulnerable to a simple but consequential confounder: LLM judges often prefer longer model outputs, so a leaderboard can reward verbosity instead of response quality.

The evaluation surface is an AlpacaEval-style instruction, a candidate model output, a baseline/reference output, an LLM auto-annotator preference, the output-length difference, and an aggregate win-rate metric. The decision boundary is judge/reward meta-evaluation and benchmark auditing; this is not a new instruction-following dataset, a human-only evaluation protocol, or a training recipe. Its atlas value is that it makes the feedback contract inspectable: the same pairwise judge produces preferences, then the reported score is adjusted to estimate what preference would be at equal output length.
