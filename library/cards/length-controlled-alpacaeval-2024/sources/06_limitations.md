Length control fixes only one visible confounder. It does not prove that the judge understands factuality, safety, reasoning depth, task intent, or domain-specific correctness, and it does not remove other judge biases such as style preference, position sensitivity, training-data overlap, or model-family affinity.

The metric is aggregate and leaderboard-oriented. A high LC win rate is not a certificate that a particular answer is correct, nor is a low score a proof that a model cannot solve a task. Results can drift with API model versions, prompt templates, reference outputs, cached annotations, evaluator configs, and public benchmark contamination. The official repository is Apache-2.0 for code and advertises CC BY-NC 4.0 for data, so downstream redistribution and commercial use need a separate license check.
