The prior baseline is generic preference or judge-alignment data where evaluator bias is often measured after the fact. OffsetBias changes the object by making bias categories and debiased targets part of the data. The direction signal is that reward/evaluator data should include adversarial audit cases, not only high-agreement labels. The quality signal is the official release of code and data. What is not new is using LLM judges or preference labels; the reusable part is the bias-aware construction. Before reuse, inspect taxonomy coverage, annotator rules, model-specific prompt effects, and whether debiasing on these categories harms valid style sensitivity.
