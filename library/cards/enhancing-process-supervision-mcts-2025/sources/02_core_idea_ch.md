该工作的贡献是一个自训练循环：把 MCTS 的结果 rollout 转换为分级的下一步监督，并直接按这些分数训练策略，而不先拟合单独的 process reward model。从当前部分解答出发，目标 LLM 扩展并模拟搜索树。每条完整模拟与问题标准答案比较，正确记为 1，错误记为 0；访问次数和累计奖励沿路径回传。随后，每个根节点子节点获得一个分数，其大小与该节点访问次数以及“该节点平均奖励相对所有兄弟节点按访问次数加权平均奖励的差值”有关。因此，反馈对象是搜索导出的相对分数，不是人工正确性标签，也不是经过独立校准的步骤有效概率。

最终记录为`（问题，部分解答，下一步，相对分数）`。分数为 0 的步骤被排除；UCB 值最高的下一步用于延长部分解答，再从新前缀重复 MCTS，直到出现最终步骤或达到最大解答长度。下一轮策略以分数加权负对数似然训练，并通过 KL 项约束在上一轮策略附近；更新后的策略再生成下一批数据。

该工作适合指定分类，因为搜索树、rollout 结果、兄弟候选、访问统计和选择分数构成关键数据血缘。与 MCTS-DPO 的最佳—最差偏好对相比，它为更多采样下一步保留分级分数；与 ReST-MCTS* 相比，它不训练 PRM 来引导搜索。MCTS、自训练、终止答案核对、KL 正则和迭代生成均是已有组件，而非本工作的新增部件。
