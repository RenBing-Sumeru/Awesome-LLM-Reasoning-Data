输入是一组推理问题及其标准答案。论文假设没有人工过程标注，也无法访问强于目标模型的 LLM。实验使用 Llama-3.1-8B-Instruct 和 deepseek-math-7b-instruct 两个目标策略，并在 MATH 与 GSM8K 上训练和评估。推理步骤以两个换行符分隔，每个步骤视为一个树节点。

对每个当前部分解答，MCTS 执行四类操作。Selection 沿 Upper Confidence Bound 最高的子节点前进，直到遇到未完全扩展或终止节点。Expansion 以非零 temperature 从当前 LLM 采样一个新的下一步子节点。Simulation 从该节点继续生成，直至模型给出最终答案。Backpropagation 将答案与标准答案比较，赋予 1 或 0 的二元奖励，并更新访问路径上的访问次数与累计奖励。多次模拟后，部分解答根节点的每个直接子节点都获得论文定义的相对正确性分数；该分数由节点访问次数、节点平均奖励及兄弟节点按访问次数加权的平均奖励导出，并由人工设定的缩放常数控制量级。分数为 0 的子节点不进入训练元组。UCB 最高的子节点用于延长选中路径，随后递归执行，直到最终步骤或达到未披露的最大长度。

在第 `i` 轮，由第 `i-1` 轮策略生成的入选元组，以分数加权负对数似然和相对上一轮策略的 KL 惩罚训练新策略。作者将其描述为 SFT，同时指出该目标也可视为一种强化学习。实验模型全部使用 LoRA。比较方法包括 Zero-shot-CoT、rejection-sampling fine-tuning，以及从最高和最低奖励步骤构造偏好对的 Step-level DPO 变体。

verifier／reward 的适用边界较窄：终止奖励来自与给定答案的比较，但论文没有说明答案归一化或等价性检查器；中间标签是模型生成 rollout 的统计量，而非对步骤的直接核验。所提循环没有学习式 PRM 或人工 judge，也未描述外部执行环境。复现仍受以下缺失信息阻碍：模拟次数、UCB 公式与常数、temperature、分数缩放、最大长度、逐轮采样计划、优化器设置、LoRA 配置、随机 seed、精确答案检查器，以及官方代码和轨迹数据。
