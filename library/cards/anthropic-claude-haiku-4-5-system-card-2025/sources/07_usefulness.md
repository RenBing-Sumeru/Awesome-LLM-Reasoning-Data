This system card is a useful template for a minimum frontier-model disclosure ledger. It shows that source classes, collection cutoff, filtering, feedback type, preference labor, reasoning-trace origin, agent-state intervention, behavioral audits, and evaluation boundaries can all be stated even when records remain private.

For preference-data researchers, it identifies the next metadata needed for reuse: comparison schema, candidate generation, rater assignment, worker cohort, agreement, adjudication, AI-feedback model, reward version, aggregation, and source-to-checkpoint lineage.

For agentic RL, the context-usage intervention suggests treating budget awareness as an explicit process field rather than an incidental prompt feature. Open reproductions should log context-used/context-remaining signals, actions, termination choices, rewards, and episode boundaries.

For auditors, the training-distribution origin of the reward-hacking suite is a model disclosure worth emulating. Every benchmark should state membership, selection rationale, held-out scope, scaffold, mitigations, and whether scores reflect the released checkpoint or another snapshot.
