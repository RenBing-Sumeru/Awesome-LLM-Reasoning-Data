官方 arXiv 报告称有约 80 万个合成可验证软件工程任务和 807,693 个 pull-request 派生的仓库实例，还报告了约 600B 仓库级中期训练 token。这些是构建或训练规模陈述，不是已发布的不同任务、版本、容器、轨迹或记录 manifest。

报告支持记录多数共识合成测试、执行验证、完成与格式惩罚，以及对 git 或网络 reward hacking 的应对。它还称 SFT 与 RL prompt 不重叠，并描述了移除下游 benchmark 重叠以及评估 remote、branch 或 tag。报告没有披露独立评估这些控制所需的方法、阈值、benchmark、残余重叠结果或日志。

官方 QwenLM 仓库和 Qwen 模型发布可用，但未找到官方训练任务、Docker 镜像、轨迹、verifier 数据或过滤日志发布。因此，证据支持部分披露的模型报告，而不是可复用的可执行任务数据集或完全可审计的 agent-RL 配方。
