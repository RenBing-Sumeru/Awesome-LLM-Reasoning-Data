编码智能体报告可能描述可运行仓库、单元测试、工具轨迹和强化学习，却让读者无法识别构成所称监督的具体任务、来源版本、镜像、测试生成器、拒绝记录和 reward 规则。在软件工程中，一个任务并不只由 issue 和 patch 定义：仓库状态、依赖、测试 harness、远程访问和终止条件也会影响智能体能学到什么，以及结果如何被投机利用。

Qwen3-Coder-Next 对可执行任务构建和 agentic training 提供了较多但不完整的信息。它点名 GitHub pull request、开放与专有来源、合成仓库改动、Docker 环境和多种反馈机制，却保留了训练任务、环境、轨迹、审计日志和完整 provenance。本卡片记录已披露的数据与反馈契约，而不把发布的权重或推理代码视作开放训练数据配方。
