The official OpenReview version is published as a conference paper at COLM 2025; arXiv:2504.04736 v2 is dated 28 April 2025. The paper asks how an autoregressive language-model policy can learn from multi-step reasoning and tool interaction when a conventional single-response RL objective supplies no explicit training signal for the intermediate actions. Its intervention is a construction-and-training recipe, not a new benchmark and not a verified public data release. (Paper p.1; §1, pp.1–2; §2, pp.3–5)

The source object is a complete trajectory `tau=(s1,a1,...,sK,aK)`. `s1` is the task prompt; each later state contains the full preceding context, including the prior model action and tool response; an action may contain chain-of-thought and a tagged search/calculator call or the tagged final answer. A K-action trajectory is then converted into K action-ending prefix subtrajectories, so the object consumed by the primary optimizer differs from the episode originally generated. (Paper §2.1, pp.3–4; §2.2, pp.4–5; Figure 2)

This object supports `environment_agent_trajectory_data` because search and calculator observations become part of the replayed state, and `training_usage_optimization_objectives` because SWiRL attaches model-based reward to every action prefix for offline RL. The paper also evaluates SFT on the synthetic trajectories, but SFT is a comparison rather than the principal method; HotPotQA, GSM8K, CofCA, MuSiQue, and BeerQA are evaluation surfaces rather than a benchmark released by SWiRL. (Paper §2; §4; Appendix C)

The Card reaches bilingual research-review depth from the full COLM paper and Appendices A–F: task pools, prompts, trajectory schema, filters, tools, reported results, and several evaluation IDs are described. Reuse remains blocked because no official trajectory corpus, per-step labels or rewards, implementation, vector index, checkpoint, or artifact license was verified.
