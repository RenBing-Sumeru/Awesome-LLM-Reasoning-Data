The authoritative paper is the 24-page Findings of ACL 2025 version in ACL Anthology (pp. 6300–6323, July 2025), including Appendices A–F. The official project page and `OSU-NLP-Group/Explorer` repository identify the same work and affiliations. The repository exposes generation, training, and evaluation code; it does not link an immutable download of the trajectory corpus.

Explorer addresses a specific construction problem: human-written web demonstrations are expensive, while tasks proposed only from a homepage or from model memory may miss actions and constraints that appear deeper in a site. The proposed alternative lets an agent explore a live page while progressively defining the task it is carrying out, so task intent and executed behavior are created together rather than paired after the fact.

The relevant data object is a multimodal live-web episode: seed URL, evolving task descriptions, grounded and natural-language actions, screenshots and set-of-mark views, HTML/accessibility-tree state, a final high-level task description, and an episode-level verifier decision. The paper reports 175K raw attempts and 94K verifier-approved episodes; a separate 40K sample is scroll-filtered to approximately 30K records for the reported SFT experiments. These populations must not be conflated.

This belongs to `data_construction_open_release_recipes` because the main reusable contribution is the seed-to-trajectory-to-filter pipeline, including cost, scale, and selection evidence. It is not a resettable web environment, a programmatically verified dataset, or a fully released open corpus. The bilingual Card is `L4_chinese_review_ready`, while the release remains `partial`: official sources and code are verified, but the described training records, split manifests, rights, and replay substrate remain unavailable. (Paper §§1–4, Table 3, Appendix A; official repository README.)
