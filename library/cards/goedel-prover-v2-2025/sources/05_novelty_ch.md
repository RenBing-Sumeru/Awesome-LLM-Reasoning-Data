相对于只重新采样完整证明的 whole-proof pipeline，Goedel-Prover-V2 把编译器指导的修订训练成模型行为。修正对象明确保留失败输出与对应 Lean 错误，模型同时优化初始证明生成和首轮修复；论文消融还把“具体编译错误”的作用与简单重采样或仅保留先前证明区分开。

第二项贡献是围绕当前 prover 能力构造 curriculum。形式化支架把未解证明状态转化为更容易的陈述；非形式化支架则根据源定理当前是否已解，生成更易或更难的变体。因此，陈述生成受不断变化的能力边界约束，而不是固定语料。

第三项贡献是把 model averaging 纳入后训练数据解释。Expert iteration 与 RL 提高 pass@1，却可能降低样本多样性；与 base 或早期 checkpoint 平均可恢复 pass@N。这意味着最终性能来自陈述混合、接受轨迹、奖励采样与 checkpoint 组合的共同作用。

这里不把任一组件单独宣称为本文首次提出。真正的方向信号是把它们整合进一条有形式反馈的 S1/S2/S3/RL 谱系。由于核心训练行仍不可获得，最准确的定位是“部分发布的前沿训练管线披露”，而不是开放训练数据集。
