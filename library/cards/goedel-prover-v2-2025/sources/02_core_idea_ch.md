训练谱系按 S1 → S2 → S3 → RL-AVG 组织。

- **S1：完整证明监督。** DeepSeek-Prover-V2-7B 与 DeepSeek-Prover-V2-671B 在整理后的 Lean 陈述上进行大规模推理；带推理轨迹且通过 Lean 的完整证明构成初始 SFT 数据，随后用于微调 Qwen3-8B 和 Qwen3-32B。
- **S2：自我修正监督。** SFT-S1 与 DeepSeek-Prover-V2-671B 标注“陈述、SFT 模型输出、对应编译错误”组成的样本。修正记录并入 S1，再进行一轮 SFT。
- **S3：支架式陈述。** 平均后的 SFT-S2 模型参与生成新陈述。形式化路线从失败证明中提取带前提的未解 Lean 目标，并同时考虑其否定；非形式化路线让 Qwen3-32B 为未解题生成较简单子题、为已解题生成更难变体，再经过自动形式化以及正确性/难度筛选。
- **RL-AVG：验证器支持的优化。** 训练按 50/50 混合完整证明生成和首轮修正任务，Lean 提供奖励调用；SFT 后与 RL 后都进行 model averaging，以恢复输出多样性。

这是一份前沿配方披露，而不是完整数据发布。官方项目公开了模型权重、推理与自我修正代码、Lean 编译器封装、固定的 mathlib 子模块和 MathOlympiadBench，但没有公开完整 S1/S2/S3 表、全部 rollout、拒绝尝试或逐条谱系。
