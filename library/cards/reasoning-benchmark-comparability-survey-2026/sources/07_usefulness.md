Use this paper before selecting a benchmark for a reasoning-data project. Begin with the deployment failure you need to expose, then choose an Object, Setting, and Evaluation that can expose it. For example, if the concern is evidence-grounded reasoning, a final-answer-only score is incomplete; if the concern is efficient planning, a task without a budget cannot answer it. The framework helps students produce a compact benchmark brief that is much more actionable than “use the popular leaderboard.”
