WebDancer is a useful recipe paper, but its training evidence and public release do not support full reconstruction.

- **Restricted environment and task form.** The agent exposes only `search` and `visit` and is optimized for short-answer information seeking. Appendix A explicitly leaves richer tools and broader long-form synthesis to future work.
- **Cost-limited RL scale.** Appendix A describes reinforcement learning on roughly 5,000 query–response pairs because multi-turn web rollouts are expensive and training can become unstable. The paper also reports tool hallucination and over-action, motivating future hybrid thinking rather than establishing that the current policy is robust to those failures.
- **Partial public data.** The repository releases `qa_sample.jsonl` and `traj_sample.jsonl` with 200 records each. Maintainer issue #35 says these are samples and that release of the full QA and trajectory data is still under consideration. No complete supervised corpus, rollout log, reward trace, rejected trajectory set, exact split manifest, or modified `verl` training code is public.
- **Ambiguous filtering description.** Section 3.2 says trajectories “with more than two actions” are filtered out, while Table 4 reports 4.56 mean actions for the 7,678 Short-CoT trajectories. The evidence therefore does not resolve the intended inequality or exact filter implementation.
- **Reproducibility and evaluation risks.** Search and page contents come from the live web, but no immutable web snapshot or retrieval cache is released. The reward's answer component is a binary judgment from Qwen-72B-Instruct, and the paper does not report a calibration study for this judge. Main evaluation uses 103 text-only GAIA validation questions and 680 WebWalkerQA test questions, so the reported results should not be treated as a general web-agent guarantee.
- **Metadata and governance gaps.** The formal proceedings list 14 authors and use “Robert Tang,” whereas the PDF author block uses “Xiangru Tang” and the arXiv/repository metadata expose a shorter list. The WebAgent directory carries an MIT code license, but dataset-specific usage terms, privacy screening, provenance manifests, decontamination evidence, and per-example source lineage are not disclosed.

These omissions are audit findings, not evidence that the unreleased artifacts or controls do not exist.
