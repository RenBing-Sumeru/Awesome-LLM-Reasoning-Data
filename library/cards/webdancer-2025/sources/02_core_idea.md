WebDancer's central contribution is an end-to-end data-to-policy pipeline: synthesize difficult short-answer web tasks, sample and filter complete ReAct demonstrations, use them for cold-start SFT, then reuse remaining QA pairs for on-policy agent RL.

CRAWLQA recursively visits pages below knowledgeable root sites and asks GPT-4o to create typed questions such as COUNT, MULTI-HOP, and INTERSECTION. E2HQA starts from a SimpleQA-style question with a concise entity answer, searches for information about an entity in the question, and rewrites that entity into a new subproblem while preserving the answer. The trajectory stage then uses GPT-4o for Short-CoT behavior and QwQ-Plus for Long-CoT behavior, with up to five rejection-sampling attempts per QA.

The training object is a full episode history of Thought, Action, and Observation. Search receives `query` and `filter_year` and returns ten result titles/snippets; visit receives `goal` and `url_link` and returns evidence plus a Qwen-2.5-72B summary. SFT masks observation tokens, so supervision attaches to model-generated thoughts, actions, and answers while the external feedback remains context.

The RL feedback contract is mixed rather than purely environmental. A binary format checker can observe whether the whole output and JSON tool calls are valid. A Qwen-72B-Instruct judge supplies binary answer correctness against the reference. Their weighted terminal reward is `0.1 * score_format + 0.9 * score_answer`; it cannot identify the first bad reasoning step, verify citation faithfulness, or guarantee that a successful answer followed a sound search path.

Compared with prompting-only agents, Search-o1, WebThinker, R1-Searcher, SimpleDeepSearcher, and concurrent end-to-end agent RL, WebDancer's distinguishing object is the connected four-stage pipeline and its explicit Short-CoT/Long-CoT trajectory construction. It is not a new search engine, browser environment, foundation model, ReAct protocol, DAPO optimizer, or general long-form research benchmark. (Paper §§2–3 and Appendix E.)
