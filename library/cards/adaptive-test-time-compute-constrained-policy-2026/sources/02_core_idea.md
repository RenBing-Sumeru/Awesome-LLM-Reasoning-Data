The method's SOLVE-THEN-LEARN pipeline first estimates Acc(x,b), the probability that budget b produces a correct majority-vote answer for input x. Given cost C(b) and Lagrange multiplier lambda, the oracle label is the budget maximizing Acc(x,b) minus lambda times C(b). Increasing lambda prices compute more heavily; binary search finds a value whose mean selected cost approaches the target B. The paper uses discrete budgets 1, 2, 4, 8, and 16 and stochastic mixing between adjacent solutions when an exact average target falls between staircase levels.

The resulting budget labels become a five-class supervised dataset. A gradient-boosted machine predicts the oracle action from 16 lexical, structural, and difficulty features, including a normalized entropy estimate from one cheap model pass. Online routing is then one feature extraction, one classifier prediction, and self-consistency execution at the chosen budget.

The feedback contract is programmatic and answer-level: response windows are reduced to majority answers, compared with reference answers, converted into empirical utilities, and priced against sample count. The learned allocator imitates these oracle labels with cross-entropy; despite policy terminology, it is not trained by online policy-gradient RL. Relative to fixed, random, or prompt-length heuristic allocation, the novelty is the globally constrained Lagrangian labeling rule and its amortization into a cheap classifier.
