The framework uses a discrete budget set and requires an expensive offline utility table. Its labels are model-, prompt-, temperature-, parser-, and distribution-specific; API or checkpoint drift can invalidate them. Forty-eight responses yield different numbers of windows for different b, so utility estimates have unequal variance. The cost function is number of samples, not measured tokens, latency, price, energy, or memory.

Experiments use only 200 questions per dataset, with MATH concentrated on levels 2-4 and one easy-domain control. The classifier includes an entropy estimate from a model call, so routing is not purely text-only. The paper notes unresolved continuous budgets, online adaptation, multi-objective constraints, and a remaining oracle gap. Raw prompts, responses, windows, labels, seeds, decontamination, and trained policies are not confirmed as released. Formal guarantees concern the empirical objective and imitation error; they do not guarantee deployment correctness or budget feasibility under distribution shift.
