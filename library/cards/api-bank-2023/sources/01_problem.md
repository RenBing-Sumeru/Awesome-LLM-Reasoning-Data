API-Bank is an EMNLP 2023 benchmark and dataset for tool-augmented LLMs. It addresses three concrete questions: how well LLMs plan, retrieve, and call APIs; how to improve that ability with supervised tool-use data; and where tool use fails. The Card includes it as a runnable API-agent environment and trajectory-like data source, not as a live external-service benchmark. A sample is a user dialogue with available API schemas, model/API-call decisions, returned API results, assistant responses, and labels or executability checks tied to the API-Bank system.
