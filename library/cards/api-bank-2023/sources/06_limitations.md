Correctness is relative to API-Bank's simulated or runnable API system and annotated dialogues. A call sequence that is valid in API-Bank may not reflect a live service's authentication, side effects, latency, schema evolution, or error handling. The training set and evaluation set have different construction goals and should not be mixed without split checks. Public API tasks and dialogues are contamination-prone. Artifact licenses and redistribution rights should be checked at the repository, HF dataset, and ACL-paper levels before using the traces as training data.
