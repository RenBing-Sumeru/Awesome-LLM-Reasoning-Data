The ACL Anthology page and paper report 73 runnable API tools, 314 annotated evaluation dialogues with 753 API calls, and a training set of 1,888 tool-use dialogues from 2,138 APIs across 1,000 domains. The main empirical evidence is that GPT-3.5 improves over GPT-3, GPT-4 is strongest at planning, and Lynx improves over Alpaca by more than 26 points while approaching GPT-3.5 in the released evaluation. Instance-level evidence is whether the predicted tool selection, arguments, API response handling, and final answer match the annotated or executable target; aggregate scores hide which stage failed.
