The prior baseline was mostly prompt-only tool demonstrations, small function-calling tests, or non-executable API corpora. API-Bank changes the object by bundling API documentation, runnable tools, annotated multi-turn dialogues, a training set, and stage-specific evaluation for planning, retrieval, and calling. The quality signal is the combination of executable API behavior and annotated calls. APIs, supervised fine-tuning, and dialogue simulation are not new; reuse should inspect synthetic-data lineage, API implementation drift, whether execution matches real services, data license, split leakage, and benchmark contamination after public release.
