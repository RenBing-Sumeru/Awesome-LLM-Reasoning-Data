The contribution is a benchmark that separates API tool use into planning, retrieval, and calling, backed by a runnable system of 73 API tools and both evaluation and training dialogues. The mechanism is to present a user request and API inventory, ask the model to identify the needed tool sequence and arguments, execute or compare the calls, and score whether the dialogue reaches the expected result. Compared with early tool-use prompting, ToolBench-style API corpora, and generic function-calling tests, API-Bank's direction label is executable multi-step API dialogue evaluation plus supervised tool-use training data.
