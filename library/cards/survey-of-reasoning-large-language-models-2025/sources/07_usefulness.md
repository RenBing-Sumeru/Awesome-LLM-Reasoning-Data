For a researcher choosing a reasoning-data or post-training route, start with a target task and fixed evaluation budget, use the five-family taxonomy to shortlist search, reward, self-improvement, macro-action, or reinforcement-fine-tuning work, and output a traceable reading list. Success is a shortlist whose cited papers share the required task and verification setting; do not treat the taxonomy as a recipe.

For an evaluator designing a suite, begin with a stated capability claim, map it to the paper's math, code, science, agent, medical, or multimodal categories and metrics, then create a protocol sheet containing benchmark version and budget. The output is an auditable evaluation plan. Do not reuse the score tables as a normalized leaderboard.

For literature discovery, use the companion repository to find recent entries, but verify each primary paper and pin a repository date or commit before reporting coverage.
