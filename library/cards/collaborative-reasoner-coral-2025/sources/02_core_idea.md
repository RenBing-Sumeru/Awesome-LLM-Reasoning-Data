Coral turns same-model collaborative conversations into next-turn supervision. Two symmetric agents alternate under a shared task-specific prompt. Each sees the complete conversation prefix and can propose a solution, challenge the partner, ask a clarification, revise, or state a final answer. The conversation stops when the agents’ latest valid extracted beliefs match or when it reaches **20 turns / 10 rounds**. Agreement can still be wrong; the main success metric additionally requires the shared belief to match gold.

The data-expansion mechanism is shallow tree sampling rather than full search. At every turn, the current agent samples **five sibling responses** from the same prefix. One sibling is chosen uniformly at random to extend the active conversation, while the others remain available for preference construction. Sibling nodes are not recursively expanded, so the method is not MCTS. To broaden conversation-level coverage, Coral independently samples **five trees per problem**.

Belief filtering converts conversation text into supervision. A separate extraction prompt asks what final answer the candidate currently believes, or returns `not sure yet`. Task-specific matchers normalize the extracted form and compare it with the known answer. A matching belief is positive; all other candidates are negative. Persuasion, assertion, persuasion quality, and agreement are analyzed, but the reported training data are not selected by those social metrics.

For DPO, Coral pairs a positive and negative sibling from the **same conversation prefix**. The prompt is the active agent’s role instruction plus that prefix; the chosen and rejected targets differ only in the next turn. This controls conversational context better than pairing arbitrary correct and incorrect turns. For SFT, independently sampled conversations provide correct-belief next turns as targets. The paper uses 25 conversations per problem for the SFT comparison.

The method trains each model on its own synthetic interactions rather than distilling conversations from a stronger general teacher. Llama-3.1-405B-Instruct is a separate upstream generator only for MBPP-CR code candidates, which are execution-labeled into binary correctness questions. The public repository omits the MBPP-CR construction and task preset, so the four-task paper pipeline is not fully runnable.
