本卡以NeurIPS 2025 Datasets and Benchmarks Track正式论文为主要出版来源；版本记录为2025年5月16日的arXiv v3，官方实现固定检查于commit `ffee6f41fde76acd14bd792db442479c506260c2`。WASP考察两个分离的问题：web agent接触攻击者可控但属于普通网页内容的间接prompt injection后，多大概率开始遵循恶意指令，以及多大概率真正完成攻击目标。其threat model是benign user与black-box malicious environment；攻击者只能在常规、由不可信用户控制的页面元素中发布内容，并不知道agent实现（论文§2–§3.1）。

主要评测面从21个由人工构造且经人工确认可在环境中实现的attacker goal开始，其中12个属于自托管GitLab clone，9个属于基于Postmill的Reddit clone。每个goal与同一站点中的2个benign user goal、2种task-related注入模板组合，因此每个主设置运行时生成`21 × 2 × 2 = 84`个任务；另有37个无攻击utility任务。一个episode连接任务/setup字段、注入页面内容、不同scaffold的observation、模型reasoning/message与browser action、最终环境或action-log状态、compromise judgment、端到端goal success、utility success及cleanup元数据。发布的Croissant attack文件只有21条base-goal记录，并不是不可变的84条rollout manifest。

WASP属于`environment_agent_trajectory_data`，因为评测对象是带observation–action trace与terminal evaluation的可执行网站episode；它也属于`benchmarks_evaluation_surfaces`，因为核心贡献是mixed安全feedback contract，而不是policy training。论文不覆盖SFT、preference optimization、reward-model training、RLVR、desktop agent、code agent、adaptive attack generation或部署发生率。本卡基于已核验的论文、附录与代码提供双语L4内容深度，但保留accepted metadata中的`L3_summary_ready`与`partial`：不可变回放、judge calibration、canonical rollout和发布checksum仍未解决。
