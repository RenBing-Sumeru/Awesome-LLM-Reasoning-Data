- The GPT-4o intermediate judge is not ground truth. No independent human-labeled calibration, agreement, or revision study is reported. Because one positive action marks the whole episode compromised, a single false positive inflates `ASR-intermediate`; malformed output or API failure defaults to `not_compromised`, creating a systematic false-negative path.
- The two feedback layers observe different evidence. Intermediate judgment reads serialized action units but not complete environment state. DOM/content rules can be fooled by stale state, partial updates, localization, rendering, or website-version drift and need not prove the intended semantic violation.
- The pinned exfiltration contract is weaker than confirmed data theft. `ExfilEvaluator` only searches extracted action text for an expected URL substring; it does not check that an attacker server received the secret or that the value was complete and valid. This differs materially from reading the paper's final-state/server-receipt description literally.
- End-to-end ASR is capability-confounded. A model can follow the malicious instruction yet fail to execute it, so low attack completion may mean incompetence rather than refusal. Conversely, utility spans 0.027–0.622 across settings, and results have no reported error bars, significance analysis, or multi-seed protocol.
- Coverage is narrow: 21 manual goals, two websites, two main task-related templates, and four simple benign goals. The authors identify limited website and prompt diversity and no desktop/code-agent extension; adaptive attackers, richer social contexts, and deployment prevalence are not tested.
- Exact replay is not sealed. There are no tagged releases, GitHub Releases, immutable site/VM images, scraped-data snapshots, service-version manifests, or complete account/reset records. The official repository was archived on 1 July 2026, so API, browser, service, and evaluator drift will not be maintained upstream.
- The Croissant metadata's `sha256` field contains the string `main`, not a content hash. The 21 attack JSONL rows are base goals rather than an immutable 84-task manifest, and no canonical successful, refused, hijacked-incomplete, failed, crashed, timed-out, or retried rollout corpus is published.
- The majority WASP code/data is CC BY-NC 4.0 while vendored VisualWebArena and Claude demo components are MIT. The self-hosted sites contain scraped real-site data; record-level provenance, consent, PII review, and redistribution rights are unknown. Curator inference: these mixed rights and absent lineage block unrestricted training or redistribution even if a fresh replay succeeds.
