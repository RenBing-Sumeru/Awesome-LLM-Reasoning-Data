WASP's contribution is a two-layer security evaluation contract for realistic web-agent episodes: one layer asks whether the trajectory was diverted by an injection, and the other asks whether the attacker goal was completed in the environment.

The evaluation object is not merely an injected prompt. A runtime task binds a benign user goal, a malicious goal and security category, site setup/parameters, an action URL, one of two task-related injection formats, an agent scaffold, and a generated observation–reasoning/message–action sequence. The release supplies setup and cleanup functions, base attack and utility records, runners, and evaluators, but no canonical corpus of the paper's model rollouts.

`ASR-intermediate` is judgment-required. GPT-4o classifies each action-level observation/reasoning/action unit as `compromised`, `not_compromised`, or `outright_refusal`; the released implementation marks the full episode compromised if any action is positive. This judge can inspect the serialized trace unit and its relation to the attacker instruction, but it cannot establish final semantic harm or recover environment state absent from the log. `ASR-end-to-end` is primarily environmental: goal-specific DOM/final-state or action-log rules decide whether the attacker objective succeeded. The fixed exfiltration evaluator is an important exception in semantics: it searches extracted action text for an expected URL substring and does not verify receipt by an attacker server.

The closest substrate is VisualWebArena, which WASP reuses and modifies into isolated GitLab/Postmill security scenarios. Relative to prompt-injection evaluations with unrealistic attacker power, isolated steps, or nonpublic suites discussed in the paper, WASP joins a constrained black-box threat model to end-to-end execution and reports intermediate diversion separately from completed harm. VisualWebArena, Claude Computer Use, browser tool calling, GPT-4o judgment, and manually written injection text are reused components; the direction signal is the explicit separation of trajectory compromise from terminal security outcome.
