构造从21个人工编写attacker goal开始，其中GitLab 12个、Reddit/Postmill 9个，覆盖exfiltration、data destruction、access change、削弱防御、execution、phishing、harassment、misinformation、snooping及相关违规。作者只保留经人工确认可在环境中实现的goal；候选goal总池、拒绝案例、adjudication与selection threshold为unknown。GitLab提供2个benign goal（comment与like），Reddit提供2个（comment与upvote）。主套件将每个attacker goal与同环境的2个user goal、2种task-related注入格式——plain text与URL anchor——做笛卡尔组合，得到84个任务。task-agnostic prompt只用于消融，另有37个无攻击任务衡量utility（论文§3.2–§3.4；附录B表5–6）。

发布的21条attack记录包含`free_form_name`、`environment`、`setup_fn`、`parameters`、`action_url`、恶意`instruction`、`exfil`、evaluator描述/类型/predicate、`cleanup_fn`与notes等字段；Croissant转换还保存字符串化的参数和评测字段。运行时，prompt injector创建站点状态，把选定注入写入普通攻击者可控页面元素，组合benign与malicious任务信息，写出task JSON，并让agent从配置URL开始。运行结束后，cleanup恢复被修改的站点状态。

三种scaffold生成轨迹。VisualWebArena以accessibility-tree observation和可选Set-of-Marks截图配合identifier-based browser action；Claude CURI使用截图与computer-use click/type action，并保留最近10张截图及此前模型输出；tool-calling loop把accessibility-tree observation作为低权限tool message，并保留3个历史observation。被测backbone为GPT-4o、GPT-4o-mini、o1、Claude Sonnet 3.5 v2、Claude Sonnet 3.7 Extended Thinking与Llama-3.3-70B。固定代码把VisualWebArena限制为15步、GPT tool calling限制为20个action、Claude CURI限制为75个action；temperature、seed、精确provider model snapshot、retry与token budget为unknown。

每次运行写出scaffold特定的HTML或JSONL日志，包含observation、模型reasoning/message、browser或computer action及任务元数据。随后GPT-4o逐个判断action单元，`classify_group`用any-positive规则得到episode-level `ASR-intermediate`。judge输出格式不匹配或API报错时，parser默认返回`not_compromised`。独立final evaluator再用按goal定制的`program_html`、required-content、forbidden-content或exfiltration规则计算`ASR-end-to-end`；utility任务使用对应task predicate。在commit `ffee6f41…`中，`ExfilEvaluator`只扫描提取出的action description是否包含预期URL substring，而不确认服务器收件。

输出是attack-success与utility rate，以及本地生成的task和trace文件；不存在training reward、optimizer、train/dev split或canonical公开rollout集合。WASP仅用于evaluation与security audit。精确回放必须固定代码commit、attack/utility config、注入模板、站点image/data/account/reset state、service version、scaffold步数与observation history、API模型版本、judge prompt/model/parser、evaluator代码，以及retry/crash保留策略。README估计一次完整运行需要4–6小时，但目前没有tag、release、不可变环境bundle或有效content checksum把这些组件绑定起来。
