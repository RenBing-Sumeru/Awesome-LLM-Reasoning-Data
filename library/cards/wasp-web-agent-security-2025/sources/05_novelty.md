The prior-work baseline described by WASP includes prompt-injection tests with overly broad attacker control, unrealistic or isolated malicious goals, single-step evaluation, and provider security suites that are not publicly reproducible. VisualWebArena already supplies browser tasks, accessibility-tree observations, executable actions, and self-hosted websites; existing agent scaffolds already supply the policies and interaction loops.

WASP changes the evaluation object in four concrete ways. It constrains the attacker to ordinary untrusted-user-controlled page content in a black-box setting; defines 21 realizable malicious goals across GitLab and Reddit/Postmill; crosses those goals with benign tasks and injection forms into 84 end-to-end cases; and records two distinct outcomes—GPT-4o-detected intermediate diversion and goal-specific terminal success—plus a 37-task utility surface. This makes “the agent followed the attack” and “the attack caused the intended outcome” separately measurable.

For reasoning-data research, the direction signal is the feedback interface rather than benchmark scale. A web-agent trace can carry a judgment-based compromise label and an environmental/log-based outcome label that disagree for informative reasons: refusal, partial execution, agent incompetence, judge error, or verifier mismatch. The release also exposes how supervision granularity can be deceptive: actions are judged internally, but only full-episode aggregates are reusable without a canonical labeled action corpus.

The work does not introduce VisualWebArena, the GitLab/Postmill substrate, GPT-4o, Claude Computer Use, browser tool calling, LLM-as-judge classification, DOM predicates, or automated attack search. The attacks are manually written and the principal novelty is their constrained security setting and paired feedback layers. Reuse should not treat higher ASR as data-quality evidence; it must first pin the release, reconcile paper and code semantics for exfiltration, calibrate the judge, capture complete rollouts, and verify environment and license provenance.
