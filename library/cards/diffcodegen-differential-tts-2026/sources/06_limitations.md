Behavioral consensus can be wrong when many candidates reproduce the same specification error, and fuzzing can miss the input that separates a wrong majority from a correct minority. Generated programs may crash, have side effects, need unavailable dependencies, or be unsafe to execute; library-mode fuzzing also depends on a valid driver. The approach exchanges LLM token cost for execution and fuzzing cost, so it is less suitable when sandboxed execution is expensive, prohibited, or cannot faithfully model the production environment.
