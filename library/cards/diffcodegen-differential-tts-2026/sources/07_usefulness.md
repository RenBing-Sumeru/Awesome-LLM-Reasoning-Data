Use DiffCodeGen for self-contained code tasks where it is safe to run candidates but no tests are available. Isolate candidates in a resource-limited sandbox, log generated inputs and disagreements, and fall back to a human or formal checker when the largest behavior cluster is weak or suspiciously uniform. Treat fuzz time as part of the test-time budget: increase candidate diversity and fuzz coverage only while their pass@1 gain justifies the added wall-clock cost.
