**Task construction.** Application selection begins from SPA-BENCH. English apps that cannot run on virtual devices and apps with bot detection/anti-automation are removed. Authors manually write seed tasks, use Qwen3 to expand them, then manually filter/edit every generated task for correctness, diversity, and reduced lexical/structural overlap. The Qwen3 checkpoint, generation prompt/settings, candidate count, annotator count, rejection count, agreement, and adjudication are unknown.

**Environment and interaction.** English apps run in Android Emulator; Chinese apps run on a physical Android phone using ADBKeyboard. An adbutils-controlled loop sends the current screenshot, task, and history/context to the agent, parses text actions into CLICK, SWIPE, TYPE, ENTER, BACK, COMPLETE, or WAIT, and executes them on the current app. HOME is excluded. The experiment budget is 15 steps; five identical consecutive operations trigger early failure.

**Process evidence and terminal judgment.** After click actions, the main Structure Description Converter uses the a11y tree to identify the relevant node and text/content/resource description. The alternative Gemini 2.5 Pro summarizer compares before/after screenshots. State tasks send instruction plus final screenshot to Gemini 2.5 Pro. Process tasks add the complete action-description sequence. Outcomes are Uncompleted when the budget ends without `COMPLETE`, Failure when `COMPLETE` is emitted but requirements are unmet, and Success only when completion and judge requirements are both satisfied.

**Reset and reproducibility.** Researchers manually clear all in-app histories before every execution. This is not an automated emulator snapshot or physical-device restore and does not guarantee server-side/account/cookie/personalization/notification/clock/locale/network equivalence. Device model, Android versions/images, resolution, app packages/versions, accounts, region, network, repeat count, seeds, decoding settings, retries, judge API snapshot, and result manifests are unknown.

**Release boundary.** The paper and appendix describe prompts, Algorithm 1, task tables, aggregate results, and selected cases, but no official code, task JSON/CSV, Process Provider implementation, environment image, per-run result, or trajectory log was confirmed. Reconstructing the pipeline therefore requires an independent implementation and cannot establish exact deterministic replay or record-level verifier auditing.
