DVD models variant contamination as alternation between memory adherence and perturbation drift. It samples the local distribution under temperature and uses variance in the synthetic difficulty of low-probability tokens: contaminated variants are expected to fluctuate more, whereas clean items remain smoother. The contribution includes a constructed Omni-MATH/SuperGPQA variant benchmark and supplementary material. No separately verified code repository or named downloadable general dataset was found; reuse requires checking the official supplement.
