Earlier judge sets usually cover general responses or only code generation and often contain easier outputs from older generators. CodeJudgeBench changes both task coverage and error difficulty: it spans generation, repair, and unit tests, then builds good/bad pairs from recent frontier-model outputs that are checked against ground truth. The contribution is not a new functional metric; it is a harder verified pairwise evaluation surface and a reliability analysis of how judges react to presentation choices. This distinguishes high scores on old easy items from reliable choice between subtly flawed candidates, the latter being closer to the risk in practical response ranking.
