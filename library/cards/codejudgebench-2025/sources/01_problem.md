Code LLM judges are increasingly used to rank generated programs, yet existing benchmarks emphasize simple generation tasks or general-domain responses. A model that writes code well may still be unreliable at distinguishing subtle functional errors, and a stable score is needed before using a judge for selection or evaluation.

CodeJudgeBench supplies a dedicated execution-free judging benchmark for code generation, code repair, and unit-test generation. It evaluates whether a judge consistently chooses the better of two verified candidates and then probes robustness to order, source model, and prompting choices. Because its tasks and candidates concern code functionality, it tests whether a judge recognizes executable semantic differences rather than merely preferring fluent, long, or reference-like text.
