CodeJudgeBench is a 5,352-pair benchmark whose record contains an instruction, a verified good response, and a verified bad response across three coding tasks. It sources recent competition problems, collects candidate outputs from frontier generators, verifies them against ground truth or execution, and pairs opposite outcomes. The release includes dataset configurations and code under Apache 2.0; it is an evaluation surface, not a newly trained judge. Each pair label comes from external correctness verification, allowing a judge choice to be compared with traceable functional outcomes rather than another model preference.
