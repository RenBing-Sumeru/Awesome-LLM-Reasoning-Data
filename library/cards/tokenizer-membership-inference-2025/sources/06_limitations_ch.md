**谱系假设。** 只有 tokenizer 数据能代表 LLM 预训练语料时，攻击才可推出 LLM 语料成员关系；若模型复用其他家族的 tokenizer，该推论失效。归因前必须检查 tokenizer 谱系。

**真值边界。** 商业 tokenizer 没有公开训练标签，主要准确率证据来自效用相近的受控 tokenizer。商业词表差异只能当作风险信号，不能当作校准后的攻击准确率。

**范围与防御边界。** 研究主要覆盖 LLM tokenizer、尤其 BPE；min-count 与受 DP 启发机制以压缩效率换隐私，且不构成正式 DP 保证。应在目标 tokenizer 类、语料规模和威胁模型上复测。

集合级标签还会遮蔽单个文档差异，因此正分数只能引导调查，不能锁定某条被复制记录。
