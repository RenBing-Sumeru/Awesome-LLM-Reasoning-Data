核心思想是把 tokenizer 的构造视为可测量的语料成员痕迹。一个审计实例包含目标 tokenizer 词表、候选数据集和辅助数据集。最有效的方法要么将候选数据训练出的 shadow tokenizer 与目标词表的特异 token 重叠相比较，要么估计候选数据是否是特异 token 进入目标词表的必要条件。

检测器输出成员分数并按阈值判定，实验报告 AUC 和固定 FPR 下的 TPR，而非学习式奖励。官方 Apache-2.0 仓库公开训练、攻击、防御与评测脚本。它是 tokenizer 级污染/隐私审计，应与输出型 LLM MIA、数据污染检测器对照。

关键区别在证据面：它用固定的预处理 artifact 审计，同时明确区分 tokenizer 成员关系与完整模型语料归因，避免把前者误作后者。
