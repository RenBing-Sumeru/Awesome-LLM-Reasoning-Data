TraceElephant addresses a failure-analysis gap in long-horizon multi-agent systems: a binary task failure says that an episode ended incorrectly, but not which functional agent was responsible or when the failure became unrecoverable. The authoritative source is the ACL 2026 Long Paper and its official arXiv, GitHub, and Hugging Face artifacts. Its decision boundary is failure-attribution evaluation and audit, not agent, reward-model, or reinforcement-learning training.

The benchmark retains 220 failed executions from 380 cleaned runs across three systems and three public benchmarks: Captain-Agent and Magentic-One run GAIA and AssistantBench, while SWE-Agent runs SWE-Bench Verified. Each released task directory pairs `trace_metadata.json` with `step_records.json`. Metadata identifies the task, instruction, system, configuration, and architecture; the ordered records preserve each agent's input context and output, plus tool name, arguments, output, and status when a tool interaction is observable. The benchmark adds a responsible-agent label and the earliest step after which all feasible continuations are judged to fail.

This belongs in `environment_agent_trajectory_data` because its primary object is a state/action/observation episode whose outcome depends on answer references, tests, tools, and mutable environments. It does not cover successful-trajectory learning or prove that the expert attribution can serve as a deterministic process reward. The Card reaches L4 content depth through verified data counts, fields, construction, feedback, release revisions, and audit risks, while retaining the accepted `L3_summary_ready` curation level pending human Review.
