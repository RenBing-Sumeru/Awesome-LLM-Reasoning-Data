The release itself is the strongest data evidence. Table 1 reports 380 cleaned executions and 220 failures, with the five system-task counts 73, 12, 74, 17, and 44; read-only ZIP central-directory inspection independently found 220 `trace_metadata.json` files and 220 `step_records.json` files at the pinned 2026-06-02 Hugging Face revision. This establishes the current package's count and organization, not exhaustive correctness of every JSON field or deterministic replay.

For attribution quality, Table 2 reports that, with ground truth available, Static Agentic averages 65.9% agent accuracy and 30.3% step accuracy, while Dynamic Agentic averages 66.7% and 33.3%. Table 3's observability ablation removes metadata and inputs: All-at-Once falls from 0.62/0.28 to 0.51/0.16, and Static Agentic from 0.66/0.30 to 0.54/0.17, for agent/step accuracy. These are author-reported evaluation results, not an independent reproduction or evidence that the labels are deterministic.

The annotation evidence also exposes uncertainty: before consensus, Krippendorff's alpha is 0.72 for responsible-agent labels and 0.64 for decisive-step labels. Full observability helps the evaluated attribution methods, but benchmark performance does not prove data quality, schema completeness, licence compatibility, or replay fidelity. The released `evaluate.py` further uses substring containment for both agent and step matching, so published accuracy should be rechecked with normalized exact-match regression tests.
