Prior agent benchmarks usually expose terminal success, and prior failure analyses often enumerate errors after the fact. TraceElephant changes the evaluation object by pairing a complete observable failed episode with two recoverability-aware attribution labels: the responsible functional agent and the earliest inevitable-failure step. It then evaluates both trace-only methods and a dynamic method that replays from candidate points for counterfactual checks.

The individual components are not new: GAIA, AssistantBench, SWE-Bench Verified, Captain-Agent, Magentic-One, SWE-Agent, logging middleware, expert annotation, and replay all predate this benchmark. The concrete data contribution is their record-level integration across three systems and three task sources, with raw input/output/tool evidence and causal labels attached to the same failed episode. Unlike AgentErrorBench/AgentDebug's broader error taxonomy and feedback/recovery loop, TraceElephant narrows the target to agent and decisive-step attribution and studies how observability and dynamic replay affect that target.

For reasoning-data research, this is a direction signal because it separates terminal verification from judgment-required causal supervision and preserves failures rather than releasing only successful demonstrations. Before reuse, researchers must check the mutable ZIP revision, annotation disagreement, environment substitutions, evaluator semantics, missing split/schema/lineage, and whether the intended task is evaluation or audit. Scale and downstream accuracy alone do not upgrade the release into training-ready process supervision.
