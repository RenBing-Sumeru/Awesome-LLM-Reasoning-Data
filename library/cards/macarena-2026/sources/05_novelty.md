OSWorld and macOSWorld provide the closest task lineage: 372 of MacArena's 421 tasks derive from those two sources. MacArena changes the reusable evaluation object by moving inherited and 49 new macOS-specific tasks into two downloadable Apple-Silicon UTM environments, exposing raw mouse/keyboard control, and binding task setup to executable final-state evaluation. The result is a locally runnable environment/feedback package rather than a new training algorithm.

The second concrete contribution is the runtime record interface. A run can materialize timestamped screenshots, `traj.jsonl` actions and zero per-step rewards, response history, logs, final scalar score, errors, and MP4 video. This makes the distinction between task definitions, locally generated episodes, and a normalized released trajectory corpus auditable. MacArena provides the first two objects; the third was not confirmed.

For reasoning-data research, the direction signal is the end-to-end binding from source task and initialization through VM state, screenshot/action interaction, terminal declaration, evaluator, and retained result. That same binding exposes quality failures that a title/count-only benchmark list would hide: an instruction/evaluator mismatch, a second run without full VM recloning, and unresolved `synth_generation` provenance despite a manual-creation claim.

The work does not newly introduce screenshots as observations, GUI mouse/keyboard actions, virtual machines, final-state scripts, or success rate. The 421-task and 121 GB scales show coverage and distribution cost, not record-level correctness. Before reuse, one must verify upstream task revisions, evaluator tests, actual split/meta-files, reset equivalence, app/external-resource versions, public rollout manifests, privacy, decontamination, and component-level rights.
