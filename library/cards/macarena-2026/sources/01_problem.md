The primary source is arXiv:2606.06560v1, submitted on 2026-06-04, supplemented by the official MacPaw repository at commit `dcdc7d366da12641578ab90f085d69db91651c58` and the official Hugging Face VM bucket audited on 2026-07-20. The paper and official artifacts state acceptance at the Second Workshop on Agents in the Wild: Safety, Security, and Beyond (AIWILD) at ICML 2026; no paper-specific OpenReview or proceedings record was confirmed.

MacArena addresses a concrete infrastructure gap in computer-use-agent evaluation: macOS task collections need an online environment that exposes the full desktop state, mouse/keyboard actions, reset logic, and executable terminal evaluation rather than only task text or static screenshots. The release contains **421 tasks across 50 applications**, composed of **221 OSWorld-derived tasks, 151 macOSWorld-derived tasks, and 49 MacArena-specific tasks**. The 49 custom tasks span five categories and 20 applications.

A task object contains an ID, natural-language `instruction`, an initialization `pre_command` or structured `config`, and a task-specific `evaluator`, plus source/application/category and optional delay, upload, proxy, or drift-control fields. A runtime episode adds full-desktop screenshots, optional accessibility tree or terminal output, mouse/keyboard action, terminal declaration, final evaluator score, and locally written trace/result artifacts. The official runner can generate these records, but **no canonical public corpus or immutable manifest of the paper's reported rollouts was confirmed**.

MacArena belongs in `environment_agent_trajectory_data` because the VM state, observation/action loop, reset policy, terminal predicate, and evaluator jointly define an interactive episode. It also belongs in `benchmarks_evaluation_surfaces` because task success is computed by programmatic inspection of final VM state. The bilingual body is written at L4 review depth while canonical metadata remains `L3_summary_ready`; the evidenced scope is evaluation and audit, not released training trajectories.
