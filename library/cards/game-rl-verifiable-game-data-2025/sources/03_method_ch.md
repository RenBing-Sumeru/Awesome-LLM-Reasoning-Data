1. **收集任务与状态：**从公开基准、模拟环境、真实网页、机器人轨迹或多模态任务中抽取输入，并保留图像、视频、工具状态、参考答案或终止条件。

2. **生成候选与反馈：**围绕同一任务采样多个回答、动作序列或完整轨迹，通过从游戏引擎状态自动生成截图、问题、步骤推理与标准答案，并用游戏代码复算结果构造质量不同但可比较的样本。

3. **核验与筛选：**使用人工、执行器、环境反馈、专家准则或可信 judge 检查标签，删除歧义、格式异常和无法复算的记录，整理为约14万条样本，覆盖30个游戏和158类可验证任务。

4. **组织使用协议：**按语言、任务、错误类型或能力维度划分数据，并用于训练和评估VLM的多模态推理与RLVR能力；模型训练只用于验证数据效用。
