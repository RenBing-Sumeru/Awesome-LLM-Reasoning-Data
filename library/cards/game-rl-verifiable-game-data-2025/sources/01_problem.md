Real multimodal reasoning data usually requires expensive human annotation and rarely provides large-scale visual states, stepwise reasoning, and programmatically verifiable answers at the same time. Natural-image QA also lacks exact environment ground truth, limiting RLVR with noisy labels.

Game-RL automatically generates screenshots, questions, reasoning steps, and answers from game-engine states and recomputes them with game code, producing GameQA-140K across 30 games and 158 task types.
