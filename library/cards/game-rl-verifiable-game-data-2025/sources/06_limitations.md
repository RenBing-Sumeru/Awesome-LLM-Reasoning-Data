First, labels in GameQA-140K still depend on humans, environments, executors, or model judges, so missed cases and bias become reward blind spots. Second, although the release contains about 140K examples across 30 games and 158 verifiable task types, coverage of languages, environments, robots, tasks, and model sources remains limited and public release creates contamination risk. Third, offline scores do not automatically become real RL or deployment gains. Reuse should audit deduplication, agreement, false positives, unseen-environment generalization, licensing, and safety boundaries.
