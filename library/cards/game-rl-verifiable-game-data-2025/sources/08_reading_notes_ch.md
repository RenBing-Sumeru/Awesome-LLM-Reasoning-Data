1. 一句话定位：GameQA-140K 通过从游戏引擎状态自动生成截图、问题、步骤推理与标准答案，并用游戏代码复算结果构建专门反馈，解决通用评价难以覆盖多模态可验证推理关键错误的问题。

2. 方法抓手：收集任务与状态、生成候选、核验标签、按能力组织；决定质量的核心是反馈可复算性。

3. 数据抓手：约14万条样本，覆盖30个游戏和158类可验证任务，记录围绕输入、状态、候选、评价依据和反馈标签组织。

4. 证据锚点：可验证游戏数据能提升多类视觉推理任务，且程序化生成显著降低人工标注成本，但结论受模型、环境和评审配置限制。

5. 复用决定：最适合训练和评估VLM的多模态推理与RLVR能力；复用前必须检查污染、假阳性和跨环境稳定性。
