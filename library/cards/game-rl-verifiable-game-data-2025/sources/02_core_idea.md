The main artifact is GameQA-140K, containing about 140K examples across 30 games and 158 verifiable task types. Each record organizes a task input, visual or environmental state, candidate response or trajectory, evaluation evidence, and a preference, score, success, or critique label, together with task provenance and capability categories. Quality control relies on generating screenshots, questions, reasoning steps, and answers from game-engine states and recomputing labels with code, making the release suitable for training, evaluation, or auditing rather than ordinary question answering.
