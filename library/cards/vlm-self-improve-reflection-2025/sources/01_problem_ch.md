多模态 chain-of-thought 自训练不只需要生成更多文本，还需要有证据支撑的规则来决定哪些生成解进入下一轮训练。在视觉推理中，模型可能在误读图像、混淆符号或计算无效的情况下碰巧得到参考答案。因此，最终答案正确性可以提供低成本反馈，却不等同于步骤有效性或 rationale 忠实性。

R3V 研究 Vision-Language Model 能否从少量 GPT-4o rationale 热身数据起步，之后主要依靠自身反复生成的完整解答 rollout 持续改进。具体问题是：如何保留答案正确的尝试，如何在不把失败答案当作目标输出的前提下利用选中的失败，以及如何在推理时利用多个尝试而不另设 verifier model。

这一设定带来两个审计问题。第一，正负样本池中究竟有哪些对象进入 direct SFT、refinement 和 selection 记录？第二，官方发布是否保留了足够的候选、标签、选择决策和 checkpoint 谱系，以复现或检查所宣称的迭代环？论文明确了配方，但官方 release 没有冻结自生成 rollout 语料及其构造账本。
