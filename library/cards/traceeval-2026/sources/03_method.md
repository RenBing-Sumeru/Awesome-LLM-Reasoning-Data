Inputs are open-source repositories converted into runtime call-graph recovery instances through LLM-assisted harness generation and tracer validation. Outputs are source program, prompt/task metadata, predicted call-graph edges, execution-witnessed reference edges, precision, recall, and F1. The substrate is Python, JavaScript, and Java execution harnesses with language-specific tracing.

Pipeline: 1. construct or load the task instance; 2. run the model or system under the official harness; 3. collect actions, observations, answers, or predicted structures; 4. apply execution tracers mechanically witness positive runtime call edges; normalized edge sets are scored with precision/recall/F1; 5. aggregate scores only under a pinned version of the benchmark. Reproducibility requires pinning paper=https://arxiv.org/abs/2605.11006, project=https://github.com/yikun-li/TraceEva, code=https://github.com/yikun-li/TraceEva, data=https://github.com/yikun-li/TraceEva, plus the exact split, runtime, scorer, prompt/scaffold, and release revision.
