One-sentence contribution: TraceEval evaluates code semantic reasoning by asking models to recover runtime call structure whose positive edges are witnessed by validation execution. The contribution is an execution-verified, multi-language call-graph recovery benchmark, plus a pipeline for turning repositories into new verified instances.

The data object contains program source, language, split, tracer-witnessed edges, model-predicted edges, precision, recall, F1. Success is decided by predicted normalized runtime edges match the execution-witnessed reference edge set. Closest comparisons are static web benchmarks, tool-use datasets, or code benchmarks in the same domain, but the direction label here is the concrete evaluation surface and its verifier rather than a general capability claim.
