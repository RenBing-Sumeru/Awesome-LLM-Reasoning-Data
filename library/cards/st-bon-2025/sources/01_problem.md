Best-of-N (BoN) improves the chance that at least one sampled response is useful, but ordinary Full-BoN must finish all N trajectories and then rank them by answer consistency or a reward model. The paper identifies two coupled costs: KV-cache and generation cost grow with N, while an external reward model adds memory, latency, and its own training-data dependency. The decision problem is therefore not only which completed answer wins, but whether a promising trajectory can be identified while decoding is still early enough to stop the others.

ST-BoN addresses this as a white-box test-time selection problem. Its auditable data object is a set of candidate prefixes for one prompt, their token and hidden-state histories, Chain-of-Embedding (CoE) features, the first-divergence step c, per-step consistency scores during a buffer window, the final selected candidate, stopping metadata, and the completed answer. These objects support test-time compute and evaluation; the paper does not present them as a training corpus. The official repository supplies an implementation and several benchmark input files, but it does not establish a versioned release of every candidate, CoE score, rejection, or prompt manifest used in the paper.
