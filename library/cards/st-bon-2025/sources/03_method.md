For each prompt, the decoder launches N sampled trajectories in parallel. The reported main setup uses top-k 20, top-p 0.95, temperature 0.7, and Zero-Shot-CoT with Qwen2.5-7B-Instruct, Llama3-8B-Instruct, Mistral-7B-Instruct-v0.3, plus a Qwen2.5-72B-Instruct scale check. Objective evaluations cover MATH, TheoremQA, GPQA, and MMLU; subjective evaluations use revised CNNDM and AlpacaFarm. Sample counts vary from 3 to 80 in the scaling plots rather than being one fixed N.

At every early step the implementation checks whether any pair of prefixes is still token-identical. When all pairs differ, it records c. It pools token hidden states into per-layer sentence embeddings, computes the CoE curvature feature, and assigns each candidate the mean squared CoE-feature distance to all other candidates. During the buffer window, set to tau=c in the main experiments, it repeats this ranking; plurality over the per-step winners determines the surviving trajectory. The environment is white-box autoregressive inference with hidden-state access and KV caching. There is no external verifier in ST-BoN itself; correctness labels and task-specific evaluators are used only to measure final outputs, while Full-BoN baselines use majority/semantic consistency, Skywork-o1-Open-PRM-Qwen-2.5-7B, or ArmoRM-Llama-3-8B as applicable.

The official Apache-2.0 repository implements greedy, self-consistency, and ST-BoN modes and documents final-output fields including inference time, stage times, c, tau, and stop_step. Its Data directory contains MATH-500, MMLU, TheoremQA, AIME, and AMC files. Reproduction still requires checking a pinned commit, model revisions, exact prompt templates, the full six-dataset manifest, seeds, GPU allocation, and whether per-candidate hidden states and score histories can be exported; those lineage details are not fully established by the documented final-output schema.
