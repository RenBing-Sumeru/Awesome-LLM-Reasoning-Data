论文报告，在所研究设置下，ST-BoN 将动态 GPU 显存占用降低 80% 以上，并把推理时延降低约 50%。在四个客观任务上，论文称利用节省的预算扩大 N 后，可在计算成本降低约 70%–80% 时达到 Full-BoN 的相近准确率；在匹配成本下，准确率约提高 3–4 个百分点。主观任务上的优势较小，并依赖比较对象。MATH 与 MMLU 的组件消融表明，CoE 与 buffer window 的组合比随机估计更常选中正确 continuation，而基于文本字符串或语义的前缀距离在这些测试中接近随机基线。

这些结果验证的是方法与选择器，不证明已发布 trace dataset 完整或高质量。官方论文、OpenReview 条目和仓库共同支持算法及其可执行实现；仓库还记录部分 benchmark 输入和结构化结果格式。但公开文档没有证明全部 N 个前缀、逐步 CoE 特征、候选分数、截断决策、随机 seed 与完整实验 manifest 均已发布。因此，benchmark 的准确率和成本曲线只能用于评估 ST-BoN，不能替代 trace-level audit。
