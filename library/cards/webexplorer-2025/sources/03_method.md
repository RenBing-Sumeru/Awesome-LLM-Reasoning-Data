The paper's pipeline can be reconstructed at the disclosed level as follows.

1. **Task sourcing and exploration.** Collect seed entities from Wikipedia. Give an undisclosed LLM one seed plus three BrowseComp-en exemplar QA pairs. Under the ReAct scaffold, the model issues search and browse actions, accumulates observations, and synthesizes an initial question with one exact truth (Paper §2.2; Appendix B.1). The full seed inventory, generator identity, decoding settings, source-page manifest, and stopping distribution are unknown.
2. **Five-step query evolution.** Feed the first-stage trajectory and QA into a second prompt. For up to 5 iterations, remove redundant clues, obscure dates/locations/names, or search for alternative terms while retaining the same answer. The authors report approximately 40K final QA pairs (Paper §§2.3–2.4; Appendix B.2). No released code or independent answer-uniqueness checker was verified.
3. **Cold-start SFT.** Use an undisclosed commercial model to generate trajectories for the hard QA. Rejection sampling keeps only correct trajectories. Each retained ReAct record contains reasoning delimited by `think` tags, search or browse actions delimited by `tool_call` tags, observations delimited by `tool_response` tags, and a final response. Approximately 13K samples train Qwen3-8B for 4 epochs with batch size 32 and learning rate 1e-5 (Paper §3.1; §4.1; Appendix A). Candidate count, correctness checker, temperature, retry policy, and rejected trajectories are unknown.
4. **Online reinforcement learning.** Use approximately 12K synthesized QA directly, without demonstration trajectories, and generate eight rollouts per GRPO group. Batch size is 64 and learning rate is 1e-6. The scalar reward is `0.2 * R_format + R_correct`; DeepSeek-V3 supplies correctness judgment against the ground-truth answer (Paper §3.2; §4.1). Exact judge snapshot, prompt, scale, optimizer details beyond GRPO, KL settings, seeds, and checkpoints are undisclosed.
5. **Progressive horizon.** Increase maximum response length/tool-call limit from 64K/50 to 96K/75 and finally 128K/100 during RL (Paper §3.2). The paper does not disclose the schedule boundaries in examples, total tokens, hardware, wall-clock time, or API cost.
6. **Live tool substrate.** Search returns the top 10 Google results as title, URL, and snippet. Browse uses Jina to retrieve a URL and Gemini 2.5 Flash to answer a page-specific query (Paper §4.1; Appendix C). These services are observations, not a frozen replayable environment.

The outputs are WebExplorer-8B and the reported paper-scale QA/trajectory pipeline. The official repository at commit `3ca019e88a33898a9e526bedf5d64e791054acfe` releases inference/evaluation code only; the official data artifacts expose the same 100 `id/query/answer` records through GitHub and an auto-gated Hugging Face dataset. Reproduction must additionally obtain the full QA/SFT/RL manifests, teachers and judge snapshots, synthesis and training code, external-service versions, observation caches, split and decontamination logs, and exact Qwen3-8B revision.
