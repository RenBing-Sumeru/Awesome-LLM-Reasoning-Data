S* provides a schema for code-search trajectories combining generation, revision, and selection. A reusable record should preserve initial candidates, every public-test execution, revision prompt and response, stopping reason, synthesized inputs, clusters, pairwise candidates, actual outputs and errors, judge decision, vote totals, and hidden-test outcome. Public-test success, generated-test agreement, and private-test correctness should remain separate fields rather than turning the final benchmark result into labels for intermediate steps.
