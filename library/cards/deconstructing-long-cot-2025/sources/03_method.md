The paper combines about 16K NuminaMath-derived prompts with about 17K Bespoke-Stratos items. It reports 33K QwQ-32B-Preview traces and 16K DeepSeek-R1 traces, generated with top-k 1, top-p 0.5, temperature 0.5, and 32,768 maximum new tokens; only responses passing rule-based final-answer validation are retained. DLCoT then performs macro parsing, free-form approach/verification segmentation, correctness and derivation-error labeling, similarity clustering, redundancy or optional incorrectness reduction, and minimal-edit coherence reconstruction. The repository README assigns Qwen-2.5-72B-Instruct to steps 1, 2, 3, and 5 and GPT-4o to step 4, and repeatedly requires the user to run inference and append a `result` field. Its only data-directory object is the Git-LFS-backed `20250209_deepseek_r1_math_26K.jsonl`, documented as Step 1 input; Step 5 files are prompts whose inference outputs would become optimized training data. Reported students use six SFT epochs, cosine annealing, learning rate `1e-5`, and batch size 96.
