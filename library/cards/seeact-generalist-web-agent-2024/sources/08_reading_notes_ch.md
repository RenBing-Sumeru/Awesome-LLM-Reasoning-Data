要记住 “can plan” 和 “can ground” 的拆分。论文最可复用的教训是：强多模态模型可能知道网页任务应该怎么做，却仍然点错或输入到错误位置。做卡片 review 时，动作目标和成功谓词不是小实现细节，而是数据对象本身。

阅读时应把论文、官方仓库和 HF 数据集一起看，因为实践价值来自释放出的环境和多模态记录。与后续 web agents 比较时，要问清楚它们是改进了 planner、改进了 grounding、改变了 browser scaffold、使用了更多 tool calls，还是只是在更容易的 live states 上评测。

复用时要把评测面说清楚：截图/HTML 上下文、候选元素生成、动作归一化、浏览器运行环境和成功谓词应一起固定版本。否则后续分数变化可能来自 scaffold 漂移或网站漂移，而不是真正的网页智能体 grounding 提升。
