Use this paper when building or evaluating browser agents that combine screenshots, HTML, and executable actions. It is especially useful as a checklist for separating three questions: can the model understand the page and task, can it choose the right next action, and can the system ground that action into the browser without human correction?

For dataset work, Multimodal-Mind2Web is a useful source of screenshot-aware web action records. For benchmark work, the live runner is a reminder that web environments need version, date, account, location, and dependency metadata. For model work, the paper motivates grounding modules, element proposal systems, and hybrid visual-structural representations.

In this atlas, connect it to environment-agent trajectory data, GUI grounding, live-web evaluation, and failure analysis for agent scaffolds. Do not use it as evidence that a model is generally reliable on the open web unless the grounding mode and live execution assumptions are stated.
