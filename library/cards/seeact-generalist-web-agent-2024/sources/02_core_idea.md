One-sentence contribution: SeeAct shows that GPT-4V-like multimodal models can plan useful web actions, but web-agent performance depends on a separate grounding contract that maps the model's intent to page elements and browser actions. The core mechanism is a generalist web-agent pipeline that observes webpages visually, uses language instructions to produce action decisions, and compares grounding strategies over offline Mind2Web-style data and live websites.

The data object is an agent-environment step or episode: instruction, web observation, element/action space, predicted action, and execution or matching outcome. The feedback contract is environmental: an offline evaluator checks element/action correctness against annotated traces, while the online setting executes actions on live sites and measures task completion. That makes the paper a direction signal for "grounded multimodal web agents" rather than for final-answer reasoning.

Closest comparisons are Mind2Web for text/HTML web-agent supervision, WebArena and VisualWebArena for interactive web environments, WebVoyager for multimodal web browsing, and GUI-grounding papers such as SeeClick for screen-to-action localization. SeeAct is especially useful when the audit question is whether failure comes from planning, grounding, or website/runtime drift.
