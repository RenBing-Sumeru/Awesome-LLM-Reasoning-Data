The evidence is mainly comparative: SeeAct evaluates multimodal web action selection on Mind2Web-derived offline settings and introduces an online setting that can run agents on live websites. The paper reports that GPT-4V has strong high-level task potential when human or oracle-like grounding is available, while automatic grounding remains a large bottleneck. This separation is the important empirical result for the card.

The official GitHub repository and project page matter because they expose the implementation surface rather than only paper claims. The Hugging Face Multimodal-Mind2Web artifact is also important: it makes screenshots and multimodal web records available for downstream inspection. For atlas reuse, the evidence should be treated as "good enough to include" but not as a stable leaderboard unless the exact revision, split, prompt, action space, model access, and live-site date are recorded.
