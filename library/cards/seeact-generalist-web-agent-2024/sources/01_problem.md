The primary source is the arXiv/ICML 2024 paper "GPT-4V(ision) is a Generalist Web Agent, if Grounded" (arXiv:2401.01614), with the official SeeAct project page, GitHub repository, and Hugging Face Multimodal-Mind2Web dataset as artifact checks. The paper asks whether frontier multimodal models can act as general web agents on real websites when the remaining bottleneck is not high-level planning alone but grounding a plan into the correct page element and executable action.

The relevant data object is a web-agent environment and trajectory record, not a generic multimodal QA example and not a standalone post-training recipe. One evaluation instance contains a user instruction, a web page observation, screenshot and/or HTML evidence, candidate elements or action targets, an agent decision, and an offline or live success signal. The paper is useful because it turns "visual reasoning on a webpage" into separable audit surfaces: planners, grounding modules, live-browser runners, and success predicates can be inspected independently.
