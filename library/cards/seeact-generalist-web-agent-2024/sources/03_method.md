Inputs are a natural-language web task, the current webpage observation, screenshot pixels, optionally HTML-derived structure or candidate elements, and the browser action history. The pipeline separates high-level reasoning from action grounding: the multimodal model interprets the page and task, proposes an intended action, and a grounding strategy selects the concrete element/action that can be executed or compared against annotations.

Outputs are grounded browser actions and task-level trajectories. In offline evaluation, the artifacts are Mind2Web/Multimodal-Mind2Web-style records with screenshots, page context, human action traces, and element/action labels. In online evaluation, the artifact is a live-browser run whose result can change with website state, login state, UI drift, or runner dependencies.

The verifier is not a learned reward model; it is a mixture of annotated action matching and environment success checks. Reuse should verify the arXiv paper, project page, GitHub code, HF dataset, runner instructions, model prompting, action budget, website date, split definition, and license. Scores should not be compared unless the same grounding policy, browser/runtime version, and live-site assumptions are pinned.
