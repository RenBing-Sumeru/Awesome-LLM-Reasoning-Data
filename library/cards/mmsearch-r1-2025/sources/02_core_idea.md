The work combines FactualVQA (FVQA), a search-balanced training set, with a GRPO environment that exposes image and text search. Rollouts use tagged reasoning, answer, search, and information spans; retrieved content is loss-masked. Terminal feedback combines exact-match answer correctness, a penalty when a correct answer used search, and a format check. This trains selective search behavior, but it does not provide step-level correctness labels for reasoning, queries, retrieval relevance, or evidence synthesis.
