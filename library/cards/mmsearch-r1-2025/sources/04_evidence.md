The ACL paper specifies the source routes, item counts, balancing rule, episode grammar, tool stack, rollout budget, and reward components. The official FVQA endpoint currently exposes about 6.66K rows—approximately 4.86K train and 1.8K test—with an Apache-2.0 dataset tag. The official repository states that the released package includes cached image-search results, while code and a model checkpoint are also linked.

These artifacts verify the prompt dataset and cached-search release, not the release of raw GRPO episodes, rejected siblings, reward logs, or live text-search snapshots. Downstream benchmark accuracy is judged by GPT-4o and evaluates the trained policy; it is not evidence that every training answer, search classification, query, or retrieved page is correct.
