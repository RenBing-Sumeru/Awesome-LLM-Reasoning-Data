OpenAI first published the *GPT-5.4 Thinking System Card* on March 5, 2026. It is a living report: a GPT-5.4 mini appendix was added March 17, and the Chain of Thought Evaluations section was updated April 24. The current 38-page PDF retains a March 5 cover while containing both later additions, so this Card treats the retrieved July 24 snapshot as versioned evidence rather than an immutable launch artifact.

The report's core Atlas problem is attribution across four layers. Training names generic reasoning RL plus GPT-5.4-specific interventions for long rollouts, computer-use confirmation policy, prompt injection, and cyber safety. Evaluation uses dynamic adversarial conversations, deidentified production-like traffic with final-turn resampling, policy and task graders, CoT audits, hidden tests, flags, and environment predicates. Monitoring uses a GPT-5 Thinking CoT monitor in the audit suite. Deployment adds a topical cyber classifier, a safety-reasoner monitor, blocks, access controls, and human review. These components are related but not interchangeable.

The most specific training object is a long agent rollout in a changing workspace. The agent is trained to revert its own changes after extended work while preserving implicit simulated user work. A minimally faithful record would contain task and workspace state, ownership of prior changes, agent actions and tool calls, state diffs, final artifact, self-reversion and preservation judgments, and feedback. The simulator, record schema, counts, detector, reward, terminal predicate, successful and failed traces, and retention policy are undisclosed.

The report belongs in `frontier_reports_data_disclosure_ledger` because it exposes multiple agent and safety feedback surfaces while leaving the corpus and reward ledger closed. L4 means the living page, current PDF, launch page, dated updates, and section-level evidence support a bilingual audit. It does not mean the data, graders, monitors, hidden tests, weights, or environments are reusable.
