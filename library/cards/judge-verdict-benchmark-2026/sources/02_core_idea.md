The core record is a question, RAG or agent response, reference answer, and three expert scores. A judge first needs Pearson r≥0.80, then is assessed by Cohen’s kappa and its z-score within human agreement. This separates human-like judges from super-consistent judges.

The authors release the Judge’s Verdict Dataset, evaluation code, and leaderboard. The public dataset contains 600 human annotations for 200 samples plus metadata; the code evaluates the full 1,994-sample suite.
