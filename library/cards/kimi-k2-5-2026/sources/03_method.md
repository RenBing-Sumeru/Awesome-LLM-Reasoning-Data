The pretraining pipeline begins from Kimi K2 and trains a MoonViT-3D visual encoder, then jointly trains vision and language and later activates long context with higher-quality mid-training data. The report names curated web text, code, mathematics, knowledge, retrieved/crawled STEM content, image-code pairs, GUI screenshots/action trajectories, video, grounding data, and synthetic search prompts. Source inventories, mixture weights, record counts, rights, and item-level lineage are not released.

For SFT, K2, K2 Thinking, and proprietary in-house expert models synthesize candidate responses. Domain-specific pipelines combine human annotation, prompt engineering, and multi-stage verification. For visual RL, outcome-based tasks include grounding/counting, chart/document understanding, and vision-critical STEM; selected RL traces can be used for rejection-sampling fine-tuning. Exact teacher versions, prompts, selection thresholds, yields, and rejected samples are unknown.

The Unified Agentic RL Environment is described as a Gym-like system with pluggable tool, sandbox, judge, prompt-diversification, and instruction-following components. Tasks are asynchronous coroutines that can trigger subtask rollouts; the report claims a rollout manager can orchestrate up to 100,000 concurrent agent tasks. It does not release the environment code/configurations, task instances, containers, tool state, or rollout records.
