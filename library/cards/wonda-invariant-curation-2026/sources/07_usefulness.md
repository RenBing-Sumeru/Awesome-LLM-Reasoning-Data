For the assigned Data Construction and Open Release Recipes track, WONDA is a concrete blueprint for upgrading machine proof artifacts into auditable teaching targets. A builder can copy the separation between source artifact, semantics-changing proposal, formal acceptance, and model-ready serialization. The key reusable pattern is to store induction, sufficiency, and runtime utility separately rather than collapse them into one “verified” flag.

A defensible reproduction should ingest the raw Hub table, retain source IDs and every candidate, run deterministic normalization, pin Kimi and UAutomizer versions, write both verification reports and timings, group splits by source program, and publish the exact grade/length filter used for each SFT cache. It should also release grade-0/1 failures, timeout/UNKNOWN reasons, semantic-duplicate analysis, and a per-source license manifest. The public code provides modules for preprocessing, syntax validation, UAutomizer execution, SFT serialization, training, and multi-run evaluation, so this is a practical starting point rather than a paper-only recipe.

The quality grade can support several studies beyond the reported SFT experiment: grade-2 versus grade-3 target ablations; cost-aware candidate allocation; cross-verifier transfer; prediction of verifier speed from invariant syntax; and curriculum designs that separate induction from sufficiency. Grade-1 and rejected candidates may be useful as contrastive or diagnostic data, but the paper does not validate them for preference learning, reward modeling, or RLVR, so those uses require new experiments and a carefully defined negative-label contract.

Reuse class: the verified official release is usable for controlled training and audit experiments after pinning code/data/model versions and resolving the applicable upstream licenses. It is not yet a drop-in contamination-clean corpus. The evaluation split is reusable only with its UAutomizer/hardware caveat, and reported benchmark scores should be used as recipe evidence rather than proof that every released row is high quality.
