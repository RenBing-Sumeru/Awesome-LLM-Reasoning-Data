The reconstructable pipeline is:

1. **Collect.** Load InvBench training programs, run UAutomizer, and keep rows with a `TRUE` baseline and at least one extracted loop invariant. The raw public table contains source filename, original/rewritten program views, baseline decision, timing, easy/hard label, and invariant list.
2. **Normalize.** Parse each raw invariant to an AST; apply bottom-up tautology/contradiction rules, parentheses minimization, and cast removal. Reject `TRUE`, `FALSE`, `0`, and `1` targets.
3. **Generate.** If the normalized invariant is at least 20 characters, query Kimi K2 Thinking through Together with the full simplification prompt. The checked official config uses temperature 1.0, `max_tokens=16384`, and `n=4`. Exact-whitespace-normalized duplicates are removed. Compact invariants bypass the LLM.
4. **Verify and grade.** Parse each candidate as a side-effect-free C Boolean expression. In parallel, UAutomizer checks induction/correctness and target sufficiency. The maximum of the two runtimes is compared with the row's median direct-verification time. A normalized fallback is checked if all LLM variants fail.
5. **Release and select.** Deep-copy the source row and add `gt_invariant`: marker, raw/pretty/simplified/target forms, rationale, Boolean correctness/sufficiency/speedup fields, numeric speedup, grade, and per-check timings. The curated-full Hub table has 7,763 rows and is not directly SFT-ready. The paper's V2 experiment filters grade >= 2 and chat-template length <= 1,024, yielding 7,284 examples split 5,827/1,457.
6. **Train and evaluate.** Serialize one marked program and one JSON invariant target for SFT. The paper reports full fine-tuning for Qwen3-0.6B/4B/14B, Llama-3.1-8B, and Mistral-7B, with Qwen3-8B using LoRA. On InvBench, each model emits one invariant per designated loop; the same formal checks yield validity, correctness, speedup, VBP, and latency-inclusive VBP-E2E over three trials.

The paper-matching verification substrate is UAutomizer 0.3.0-dev-d790fec (SV-COMP 2025), Java 21, 32-bit `unreach-call`, 16 GB via runlim, and a 600-second timeout on an AMD EPYC 9354/L40S node. Reproduction should also pin the code commit, upstream programs, model revisions, tokenizer/chat template, Together-served Kimi revision, random seeds, baseline timing runs, and candidate/order concurrency. The checked `master` commit `678ab76b3db3ffb5cd21a726b9036cf4d8d5329b` has no release tag, and current Qwen3-8B/14B default configs do not completely mirror the paper's LoRA assignment, so paper settings must take precedence until that drift is resolved.
