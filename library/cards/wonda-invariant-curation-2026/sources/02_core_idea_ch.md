WONDA 把“高质量 invariant”写成可执行的数据契约，而不是可读性的主观判断。候选首先不能退化；归纳正确性通过 `V(A, P, I)` 检查；充分性通过 `V(A ∪ {I}, P, q)` 检查；实际效用则比较并行验证时间 `max(t1, t2)` 与直接 baseline 时间 `tb`。由此得到 0–3 级：非归纳；归纳但不充分；归纳且充分但不加速；归纳、充分且更快。论文报告的 V2 SFT 集只接收 grade 2 和 3。

构造过程有两类变换。确定性的 AST normalization 删除重言式和矛盾式、最小化括号并去除类型转换。逻辑重写规则保持语义，但论文明确说明去 cast 不一定保持语义，因此后置 verifier 不可缺少。对于长度至少 20 字符的规范化不变量，Kimi K2 Thinking 读取程序、不变量和循环 marker，并采样四个紧凑替代。候选可以比原始不变量更弱、更强、等价或不可比；只有两项形式化检查决定其能否成为训练目标。

该反馈系统可以观察指定 C 验证查询在一个固定环境中的有效性和 verifier 运行时间；它不能证明候选与来源不变量语义等价、可读、唯一，不能保证迁移到另一 verifier 或架构后仍成立，也不能证明没有来源泄漏或程序权利完整。因此，grade 3 是环境相对证据，不是普适质量标签。

最接近的 baseline 是 InvBench 使用原始 UAutomizer 不变量进行一次性训练。WONDA 保留其来源/评测设置，但改变目标分布，并把归纳正确性、充分性和加速拆成独立字段。Loopy、LaM4Inv、LEMUR 等迭代系统在 inference 时反复 generate-and-verify 或修复；WONDA 改善单次 proposal，与这些循环互补，而不是取代它们。
