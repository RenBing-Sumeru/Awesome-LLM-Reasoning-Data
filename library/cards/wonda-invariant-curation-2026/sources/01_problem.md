WONDA asks why one-shot invariant generators trained on formally correct solver output still fail to help a verifier on difficult C programs. Its ICML 2026 paper and arXiv v2 trace the problem to the training target: UAutomizer can emit inductive proof invariants that are thousands of characters long, enumerate cases, contain casts and redundant Boolean structure, and encode one solver-specific proof rather than the simpler program relation a model should learn. Directly using these targets can therefore preserve correctness while reducing pedagogical value.

The paper's object is not a free-form chain of thought. A source row contains a C verification query, a target loop location, UAutomizer's baseline decision and runtime, and one or more raw invariants. A curated row adds the normalized form, an optional Kimi K2 Thinking simplification and rationale, the selected target invariant, separate correctness and sufficiency decisions, verifier timings, a speedup label/factor, and a four-level quality grade. The SFT serializer turns that record into a marked C program and a single JSON target, `{"marker": ..., "content": ...}`.

This belongs in Data Construction and Open Release Recipes because the central contribution is a reproducible transformation and selection contract: normalize, generate semantic alternatives, formally grade them, and serialize selected targets for SFT. It is adjacent to programmatically verifiable outcome data, but the canonical category remains the construction track. It does not contribute process-supervision labels or an RLVR experiment, and it does not show that the model's unobserved reasoning process is correct.

The L4 boundary is unusually concrete: paper v2 and its appendices specify the quality function, prompts, dataset counts, SFT settings, evaluation metrics, hardware, and UAutomizer release; the official repository and Hugging Face collection publish code, raw/curated/evaluation tables, and models. What remains unresolved is item-level source licensing, grouped split construction, semantic decontamination, a tagged paper-matching code release, and independent reproduction.
