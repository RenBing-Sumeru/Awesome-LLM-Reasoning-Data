- **Identity and version boundary:** the assigned entry is the exact-title arXiv:2510.11977/OpenReview `vUaY1t64ZZ`/ICLR 2026 Poster paper, not any other work called HAL. The atlas year is 2025, while the accepted conference record is 2026; citations must preserve that distinction.
- **Scale drift:** the paper reports 21,730 rollouts and more than 2.5B tokens, the project page later displays 26,597 rollouts, and the audited HF repository has 380 encrypted run archives totaling 113,072,877,091 bytes. These are different units and snapshots. No frozen manifest maps the paper corpus to current archive names and checksums.
- **Internal count discrepancy:** Appendix A4 states 186 runs, but the nine Appendix A10 per-benchmark counts sum to 184. The unexplained two-run gap blocks exact reconstruction of the evaluation matrix.
- **Schema and retention uncertainty:** HF has no dataset card, normalized viewer schema, or corpus-level manifest. Two decrypted archives show detailed config/results/evaluator/log/usage/cost/Git fields and retain failures, but corpus-wide uniformity and completeness for successes, crashes, timeouts, partial logs, failed uploads, and optional raw submissions are unknown.
- **Verifier and gaming risk:** native benchmark evaluators can reward leaked answers, hard-coded outputs, shortcuts, or guessed submissions rather than intended task completion. TAU-bench Few Shot demonstrations contained test examples, and AssistantBench agents retrieved benchmark answers. A final success label is therefore not proof of valid reasoning.
- **Judge calibration:** Docent uses GPT-5 Medium over cleaned transcripts. Human checks estimate precision only for selected positive rubric flags; false-negative rates and overall accuracy are not reported. Exact paper-era judge snapshot, decoding settings, prompts/rubric files, and adjudication records are not fully pinned.
- **Causality:** behavioral flags correlate with outcomes but do not establish that fixing a flagged behavior would cause success. The paper identifies checkpoint-and-corrected-replay as the missing causal test.
- **Environment false negatives:** browser crashes, rate limits, unavailable packages/files, API failures, scaffold defects, and VM/container problems can be scored as agent failures. Local execution is unsandboxed, while Docker and Azure have different isolation and state behavior.
- **Statistical and coverage limits:** most evaluations use a single run because of cost. GAIA and AssistantBench use public sets, SWE-bench Verified Mini covers 50 of 500 tasks, and the paper uses original TAU-bench rather than tau2-bench. Variance and broader generalization remain underdetermined.
- **Replay gap:** run commands, Git commits, `--run_id`, and `--continue_run` improve lineage but do not freeze dynamic websites/APIs, benchmark mirrors, proprietary model endpoints, provider-side weight or quantization changes, credentials, retry policy, dependencies, or execution images. Exact deterministic replay is unsupported.

- **Rights and privacy:** the OpenReview paper record is CC BY 4.0, but the archived code repository has no license and the HF trace repository has neither a dataset card nor license metadata/file. Third-party benchmark inputs, model outputs, raw submissions, and retrieved web content have unreconciled rights. No corpus-level privacy, consent, redaction, sensitive-content, or takedown policy is published.

SFT, preference, reward-model, RLVR, or agent-training reuse remains blocked pending license, privacy, manifest, schema, contamination, retention, and replay review.
