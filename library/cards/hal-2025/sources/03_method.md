The reconstructable paper-era pipeline is:

1. **Inputs and configuration.** Select one of nine existing benchmarks and its task subset, pair it with a task-specific or generalist scaffold, configure a hosted model endpoint and reasoning settings, and record benchmark/agent arguments and a run identifier. The headline analysis covers Claude Opus 4.1, Claude 3.7 Sonnet, o3, GPT-4.1, GPT-5 Medium, o4-mini, DeepSeek R1, DeepSeek V3, and Gemini 2.0 Flash, with additional reasoning-effort variants and appendix configurations. Exact provider-side model snapshots are not uniformly immutable.
2. **Agent integration.** Adapt the scaffold to the minimal Python `run(input, **kwargs) -> dict` interface. Task-specific systems include Browser-Use, SeeAct, Open Deep Research, CORE-Agent, SAB Self-Debug, SciCode tool-calling/zero-shot variants, SWE-Agent, and USACO Episodic+Semantic. HAL also evaluates a smolagents CodeAgent-based generalist scaffold.
3. **Execution environment.** Run tasks locally, in Docker, or in per-task Azure VMs. Local execution is unsandboxed; Docker supplies lightweight isolation; Azure supports scalable parallelism, configured timeouts, artifact/log collection, and cleanup. The actual browser, repository, scientific-computing, search, or simulated customer-service state remains benchmark-specific.
4. **Trajectory capture.** Instrument model API and tool calls with Weave. `weave_task_id` links calls to tasks, while trace/parent IDs recover call graphs. Captured fields can include API parameters, inputs, outputs, exceptions, timestamps, usage and storage summaries. Instrumentation failure can still omit calls.
5. **Verification and aggregation.** Pass the agent submission to the benchmark adapter's gold-answer check, unit tests, environment predicate, or native scoring logic. Preserve task-level outputs and scores where supplied, then aggregate accuracy or benchmark score, token/dollar cost, and latency. There is no common terminal predicate or scalar reward across all nine benchmarks.
6. **Filtering and analysis selection.** The paper's main Section 4 analysis retains 142 model-scaffold-benchmark combinations and treats 44 additions as an incomplete matrix. TAU-bench Few Shot results are removed after Docent reveals that the official demonstration file contained test examples. These are evaluation-integrity decisions, not training-data rejection sampling.
7. **Behavior audit.** Remove redundant Weave calls, upload cleaned transcripts and benchmark metrics to Docent, construct benchmark/rubric-specific natural-language decision trees, and apply GPT-5 Medium as the judge. The paper initially analyzes 2,184 transcripts from 48 model-scaffold pairs over four benchmarks; after removing TAU-bench from reliability/failure analysis, 1,634 transcripts and 36 pairs remain.
8. **Packaging and release.** Aggregate run configuration, results, raw evaluator records, raw Weave logs, usage/cost totals, Git metadata, and optional raw submissions into `_UPLOAD.json`/sibling material. The upload utility encrypts each bundle into a ZIP with the published fixed password `hal1234` and uploads it to the official Hugging Face repository. Because the key is public, this is a scraping deterrent rather than access control.

The paper reports 21,730 rollouts, more than 2.5B model-call tokens, approximately USD 40,000, and 186 runs. The HAL Generalist Agent plans every four steps with a maximum of 200 steps; Anthropic high reasoning is mapped to 4,096 tokens through LiteLLM, while OpenAI reasoning-token budgets are undisclosed. Temperature is unknown, and no universal sampling or inference budget covers all configurations. High cost led to single runs without statistical validation for most evaluations.

Reproduction must freeze the paper/arXiv version, harness commit, benchmark revisions and task subsets, scaffold/model arguments, dependency and runner images, provider endpoint behavior, reasoning settings, credentials assumptions, timeout/retry logic, and Weave/Docent configuration. Run IDs, commands, Git metadata, `--run_id`, and `--continue_run` help lineage and continuation, but they do not provide deterministic replay of dynamic websites/APIs, hosted models, benchmark services, or unpinned VM/container state. A corpus-level manifest tying the 21,730 paper rollouts to archive names and checksums is unavailable.
