Post-hoc methods infer leaks from behavior or require a clean reference set; ordinary canaries are easy to remove or memorize weakly. This work moves the intervention before release: it watermarks question wording, then tests learned token bias with a p-value whose false-positive rate is defined for watermark memorization. It also adapts reading-mode radioactivity to mismatched tokenizers. The contribution is not generic decontamination: it needs a secret key and white-box model access.
