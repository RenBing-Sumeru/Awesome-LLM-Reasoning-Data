All prompts come from named public datasets spanning mathematics, code, science, instruction following, and chat. Cleaning removes duplicates, URLs, image-dependent items, and evaluation-set matches using exact and semantic deduplication. Mathematical prompts undergo completeness filtering and ground-truth checking: multiple DeepSeek-R1 answers are compared with the original answer through `math_verify`; when they disagree, o4-mini supplies an alternative answer whose equivalence to the common DeepSeek-R1 answer is checked with `math_verify` before the ground truth is revised. Proofs and multi-part questions are removed and multiple-choice items are rewritten.

SFT uses about 2.84M responses. Synthetic responses are filtered by perplexity from a prior 32B model, repeated n-grams, and complete think/answer span structure. Training starts from Qwen2.5-32B base with LR `8e-5`, 32K packed sequences, global batch 64, two epochs, and 5% cosine warmup.

For RL, the SFT model estimates prompt difficulty through repeated attempts. The retained pool contains 32K math and 22K code prompts. Math receives binary `math_verify` reward; code receives binary all-tests-pass reward in a secure sandbox; strict IFEval scores instruction following; an unnamed reward model averages helpfulness, correctness, and coherence for non-verifiable responses. GRPO removes KL, sets overlong-response advantages to zero, and samples 16 rollouts for each of 256 prompts per batch. Stage 1 allows 24K responses; Stage 2 allows 32K, removes prompts solved in every Stage-1 attempt, and adds 15K chat plus 5K instruction-following prompts.
