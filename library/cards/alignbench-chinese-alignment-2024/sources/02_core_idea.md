AlignBench uses a human-in-the-loop pipeline to build 683 native Chinese queries rooted in real scenarios across eight major categories, each with a human-verified reference. Knowledge-intensive questions additionally include URLs and quotations from reliable webpages to reduce reference hallucination. Automatic evaluation uses a rule-calibrated, multidimensional LLM-as-a-judge with chain-of-thought explanations and category-specific scoring rules. Data, model outputs, and evaluation code are released.
