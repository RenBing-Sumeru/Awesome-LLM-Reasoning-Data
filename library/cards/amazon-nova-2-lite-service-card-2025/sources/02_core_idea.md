The report exposes two different objects. The deployment object is a prompt—possibly multimodal and optionally augmented for features such as Web Grounding—followed by a generated completion after input and output filtering. The model can use a one-million-token context and offers low, medium, or high extended-thinking effort; step-by-step reasoning is displayed as `[REDACTED]`, although `reasoningContent` blocks indicate that thinking was used.

The training disclosure is much coarser: curated licensed/proprietary, open-source, and public data; weight adjustment through SFT and RLHF; and tuned privacy, profanity, and safety filters. It does not disclose a record schema, preference object, reward model, calibration, rollout allocation, or optimizer. The runtime reasoning interface therefore must not be mistaken for released reasoning traces.
