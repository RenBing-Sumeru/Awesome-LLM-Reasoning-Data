RoboMonkey is useful for designing verifier-training data for embodied action selection. A reusable record should include demonstration and policy revisions, observation frame(s), instruction, expert action, raw candidates, cluster assignment, representative actions, RMSE values, pairwise winner/loser and margin, verifier score, selected action, environment outcome, and safety flags. This schema allows downstream users to replace the RMSE proxy or study disagreement between imitation distance and actual success.
