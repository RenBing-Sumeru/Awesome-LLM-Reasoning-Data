The verification contract is environmental. AgentBench-FC task workers evaluate performance and normalize task rewards to the interval from zero to one. When a task lacks an intrinsic reward, a correct response receives one and an incorrect response receives zero. The multi-task RL objective uses a binary whole-trajectory correctness score; trajectories that exceed maximum interaction rounds or response length, and abnormal terminations, receive minus 0.2. A session ends after task completion or lifecycle/timeout policy. These disclosures identify reward categories and penalties, but they do not release one immutable cross-task ledger of task-specific evaluator decisions, observations or terminal records.
