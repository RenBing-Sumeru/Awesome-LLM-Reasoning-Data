For this atlas, the differentiating contribution is a framework-level view of the environment-feedback interface: asynchronous controller/task-worker sessions, structured Function Calling actions, online rollouts and task-specific feedback are disclosed together. This makes it possible to audit the construction recipe, environment contract and trajectory-level reward design without mistaking the environment repository for a paper-data release. Its source roles are construction recipe, data release, verifier/reward and agent environment; the evidence-backed declared uses are agent training and evaluation. Comparisons should distinguish a runnable task stack from the missing record-level inputs, rollout events, policy-version state and reward decisions.
