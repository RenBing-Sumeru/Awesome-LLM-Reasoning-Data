AgentRL is curated for the Frontier Reports and Data Disclosure Ledger because it makes a multi-turn agent-environment interface concrete without releasing a complete paper-run trajectory corpus. Training is built around refined AgentBench Function Calling tasks: ALFWorld, DB, Knowledge Graph, OS and WebShop. A task worker builds system and user prompts, parses and executes OpenAI Function Calling responses, injects observations and reward history, and maintains a session to completion or abnormal termination. The disclosed record schema includes task index, prompts, tool definition and calls, action, observation, environment state, reward, termination signal and trajectory. The framework is asynchronous and containerized: a controller manages task workers and sessions, and repository materials describe FastAPI workers, HTTP/gRPC transports and Docker-backed environments.
