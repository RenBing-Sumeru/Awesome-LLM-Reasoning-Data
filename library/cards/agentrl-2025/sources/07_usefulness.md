Evidence-backed uses are agent training and evaluation at the level of the released framework and linked environment contract. This Card supports comparison of multi-turn session schemas, Function Calling interfaces, environmental terminal feedback, asynchronous rollout/training behavior and disclosed reward penalties. It is not evidence that a reader can recreate the paper's data mixture, reproduce its runtime behavior, reuse undocumented synthetic instances or inspect the reward path for a published rollout.
