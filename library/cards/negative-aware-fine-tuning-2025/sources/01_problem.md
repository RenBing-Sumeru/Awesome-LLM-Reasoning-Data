Online math post-training can generate answers from the current policy and label them with a binary correctness verifier. Rejection Fine-Tuning (RFT) keeps only correct answers for supervised learning, so expensive incorrect rollouts are discarded; policy-gradient methods such as GRPO use both reward signs but require an RL optimization formulation. NFT asks whether supervised maximum-likelihood training can also learn directly from the model's own failures.

The ICLR 2026 work uses DAPO-Math-17k questions and, at each rollout step, samples 512 prompts with 16 answers each. The data object is an online prompt group containing every answer trajectory, binary correctness, per-question success rate, and old-policy token likelihoods. This supports positive and implicit-negative likelihood terms rather than a static paired preference dataset. The official paper, NVIDIA project page, NVlabs/NFT Apache-2.0 code repository, DAPO-Math-17k dataset, and NFT-7B/NFT-32B weights are confirmed. The repository improves reproducibility, but it does not establish a complete release of all 320 rollout steps, rejected traces, verifier decisions, and optimizer lineage.
