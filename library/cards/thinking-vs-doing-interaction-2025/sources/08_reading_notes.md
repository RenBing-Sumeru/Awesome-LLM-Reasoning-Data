Read the paper as a budget-allocation study, not only as a web-agent training paper. First separate the prompting intervention from the learned TTI curriculum, and compare each against per-step reasoning or best-of-n under the same token accounting. Then examine the horizon schedule, reward timing, task-generation boundary, and failure cases. The decisive question is whether an added action obtained information that changes a later choice; if it did not, a longer interaction trace should not be interpreted as evidence of useful test-time scaling.
