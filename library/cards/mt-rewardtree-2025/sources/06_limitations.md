Method limits begin with the search approximation. Expanding only the top-2 logits can miss a lower-probability token whose later translation is better, while three rollouts per child give a noisy node mean. The 0.04–0.4 score-gap filter changes the retained difficulty distribution by excluding very small and very large contrasts. Retaining the superior branch for the next cycle further couples future data to earlier metric errors. As a curator inference, COMETKiwi false positives can promote fluent but inadequate branches, and false negatives can remove valid alternatives; without human agreement or calibration data, their rates are unknown.

The judge is also part of the measurement stack. COMETKiwi assigns construction labels and reappears among downstream COMET-family metrics, creating partial circularity. MT-PRMBench therefore measures recovery of metric-conditioned preferences, not an independent human preference standard. Gemini-2.0-Flash and other learned judges used in related applications introduce additional version, prompt, language, and calibration dependence.

Release limits block full search audit. The public records omit raw trees, node/parent IDs, explicit sibling tokens and prefixes, all three rollout sets, variance, averaged node values, discarded branches, and rejection manifests. The meaning of `chosen_score` and `rejected_score` relative to node means is undocumented. Each repository exposes only a split named `train`; source-sentence grouping, prefixed/arbitrary linkage, duplicate control, decontamination, and downstream WMT23 overlap are not documented.

Reproducibility and rights are also incomplete. Exact WMT/FLORES versions and record IDs, generator/judge checkpoint revisions, seeds, maximum length, total compute, optimizer settings, and an immutable cross-artifact manifest are unknown. Dataset pages display Apache-2.0 metadata, but compatibility with WMT/FLORES source terms and generated-output rights is unresolved; the LLaMA PRM lacks a visible license, and the GitHub code license was not verified.

The authors explicitly limit the study to high-resource language directions and leave low-resource extension and RL integration for future work. Test-time evidence uses 500 WMT23 cases per reported setup and automatic metrics, without human evaluation. These limitations prevent benchmark performance from serving as proof of release quality or general multilingual validity.
