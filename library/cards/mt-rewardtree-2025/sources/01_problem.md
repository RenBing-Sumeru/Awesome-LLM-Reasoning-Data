The final ACL Anthology record places MT-RewardTree in Findings of EMNLP 2025 (November 2025, pp. 18556–18567). The paper addresses a specific gap: machine-translation process reward models lacked a documented procedure for producing fine-grained token preferences and an MT-specific surface for testing whether a reward model ranks them correctly. It belongs in `rollout_search_test_time_trace_data` because each retained preference is selected through repeated translation rollouts, learned-metric scores, and token-branch search; the selector and budget are part of the data object rather than incidental inference settings.

For a source sentence from WMT17–WMT20 test data or FLORES development/test data, TowerInstruct-7B-v0.2 generates a shared translation prefix, the top-2 next-token siblings, and three complete EOS-terminated rollouts from each sibling. COMETKiwi-derived values select the superior branch. What the public prefixed release stores is narrower: `instruction`, `input`, `chosen`, `rejected`, `chosen_score`, and `rejected_score`. The corresponding benchmark omits `input`; the arbitrary variants compare completions that need not preserve the same sibling-prefix relation. Raw tree nodes, all six rollouts, discarded branches, explicit prefix/token identifiers, and averaged node values are not released.

This Card does not treat COMETKiwi labels as human ground truth, does not claim the unreleased search tree is reusable, and does not extend the paper to RL training—the authors leave RL integration to future work. L4 is supported by the final ACL paper, author project page, four official dataset repositories, and two model repositories; status remains `partial` because score semantics, raw-tree lineage, grouped splits, decontamination, code revision, and several licenses remain unresolved.
