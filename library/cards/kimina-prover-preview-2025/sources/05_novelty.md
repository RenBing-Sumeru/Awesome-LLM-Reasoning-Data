For Track 12, the central contribution is the ability to audit a formal-RL report without collapsing three claims into one. First, Lean compilation can supply a strong terminal predicate for a whole proof. Second, an autoformalized statement still needs semantic scrutiny, for which the report uses LLM judgment, expert monitoring, and structural filters. Third, neither of these mechanisms provides the model with interactive step feedback while it writes the proof.

The report also exposes an uncommon amount of pipeline structure—prompt counts, cold starts, model roles, code-coverage filtering, decontamination description, and public distills—while withholding the actual artifacts needed to reproduce it. This makes it a useful disclosure boundary rather than an open training-data release.
