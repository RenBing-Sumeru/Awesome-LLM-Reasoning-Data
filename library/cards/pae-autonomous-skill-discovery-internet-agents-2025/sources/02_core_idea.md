The principal data object consists of environment context, autonomously proposed web tasks, grounded thought/action trajectories, VLM success judgments, and reinforcement-learning rewards. The public PAE data entry contains proposed tasks and web-interaction trajectories; exact release counts and split details should be verified from the dataset card. A useful record preserves the input, current prefix or environment state, candidate behavior, execution or evidence, feedback label, and provenance instead of only a final outcome.
