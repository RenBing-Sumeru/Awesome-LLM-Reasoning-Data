Internet-agent skill-discovery data usually retain only final success or a completed answer, so they cannot reveal which step in planning, retrieval, tool selection, environment execution, or evidence synthesis creates value or introduces an error.

Rather than merely adding complete successful trajectories, this work records environment context, automatically proposed web tasks, grounded thought/action trajectories, VLM success decisions, and reinforcement-learning rewards, allowing each local behavior to be accepted, rejected, or corrected for an explicit reason.
