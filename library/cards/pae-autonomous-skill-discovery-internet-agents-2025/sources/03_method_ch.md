1. **读取环境上下文。** proposer 使用网站名称、当前页面或少量用户演示理解可练习的技能空间。
2. **自动提出任务。** 根据环境生成新的网页任务，并对不可执行、危险或重复目标进行初步过滤。
3. **执行真实操作。** agent 输出 thought，并在真实或自托管网站执行点击、输入和导航，保存完整 grounded trajectory。
4. **VLM 评价成功。** evaluator 根据任务与终局页面判断是否完成，并生成可用于策略更新的 reward。
5. **持续发现技能。** 成功与失败轨迹反馈给 proposer 和 agent，形成任务提议—实践—评价—RL 的闭环。
