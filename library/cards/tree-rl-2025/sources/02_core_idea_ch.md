EPTree 先生成 M 条完整回答链，再按不确定性对可用 token 位置排序，选取前 N 个位置，并从每个位置续写 T 个分支，重复 L 轮扩展。论文的主设定为 (M,N,L,T)=(6,2,1,2)，每个提示得到 30 个叶节点。

其反馈契约以终点为锚：完成的叶节点获得二值最终答案正确性。对每个树节点，TreeRL 用正确后代叶节点所占比例估计价值；随后把相对虚拟根节点的全局 advantage 与相对父节点的局部 advantage 结合。共享的非叶片段会出现在多条抽取序列中，因此其更新值再除以入选后代 trace 数的平方根。

与独立采样的 ChainRL 相比，它同时改变了样本拓扑与监督粒度；与静态 PRM 相比，过程信号由当前策略生成的树重新计算。它不会使终点正确性成为每一步都有效的证明，公开发布也没有提供可供独立检查这些派生信号的静态树语料。
