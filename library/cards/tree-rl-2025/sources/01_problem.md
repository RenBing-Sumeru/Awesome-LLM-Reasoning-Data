Conventional on-policy reasoning RL commonly samples independent completions and gives only an outcome reward. TreeRL asks whether the same on-policy search episode can both explore more alternatives and provide intermediate credit without separately training a process reward model. Its relevant object is therefore not one selected answer: it is a prompt-indexed EPTree containing initial chains, selected fork positions, branch continuations, leaf outcomes, descendant-derived values, and step rewards.

This belongs to **Rollout, Search, and Test-Time Trace Data** because the outcome depends on a set of sampled paths, their shared prefixes, terminal checking, and a generation-token budget. It is not a released trace dataset: the official repository exposes a prompt-answer JSONL input file and code, while raw EPTrees, rejected branches, node-level rewards, and leaf-to-training-trace selection records were not verified as public artifacts.

The paper was accepted as an ACL 2025 long paper. The Card reaches L4 after checking the ACL record and full paper, arXiv full text, official THUDM repository, license, launcher, EPTree code, and remote-reward implementation. This is evidence for the recipe and artifact boundary, not for the quality of unreleased runtime traces.
