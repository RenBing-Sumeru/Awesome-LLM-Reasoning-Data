The prior baseline is final-answer reasoning evaluation or method papers showing that critique can improve outputs. CriticBench changes the benchmark object to the critique-correct loop and evaluates generation, critique, and correction as separable capabilities across domains. The direction signal is feedback-quality measurement for self-improvement and evaluator design. The quality signal is cross-domain coverage, multiple source datasets, multiple response families, and published ACL metadata with project/data links. Critique prompting and answer-key scoring are not new. Reuse requires auditing source dataset licenses, split provenance, prompt templates, generated-response lineage, judging rules, and contamination from public reasoning benchmarks.
