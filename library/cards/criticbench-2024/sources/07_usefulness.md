Use CriticBench as a schema for feedback records: task, domain, source dataset, original response, critique, corrected response, critique target, self-versus-other relation, scoring rule, and final metric. It is useful for evaluating critic models, reward-model candidates, self-correction pipelines, and judge calibration. For atlas reuse, preserve whether the feedback is explanatory, corrective, preference-like, or scalar-scored, because those contracts support different downstream uses.
