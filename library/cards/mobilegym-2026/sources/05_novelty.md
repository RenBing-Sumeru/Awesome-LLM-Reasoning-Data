Prior mobile benchmarks typically trade off fidelity, controllability, and cost. Emulator systems expose screenshots and some programmatic hooks but require gigabytes per instance and cannot readily clone proprietary account/backend state; real-device systems cover actual apps but make reset, safe online RL, and deterministic hidden-state verification difficult. AppWorld demonstrates programmatic state evaluation in a tool-oriented simulated world, while AndroidWorld and AndroidLab supply mobile interaction benchmarks (Paper Related Work and Table 1).

MobileGym's concrete change is to make the mutable mobile world a compact JSON object and use it throughout the pipeline. The same state representation configures an instance, forks identical GRPO group starts, supplies task-specific terminal checks, and supports whole-environment side-effect diffs. Declarative EFSM navigation and modular app contracts are engineering mechanisms that make the simulator analyzable and extensible; AnswerSheet turns query answers into typed GUI state rather than judging free-form model text (Paper §§3–4; Appendices B and F).

For reasoning-data research, the new object is not merely a task prompt or transcript. It is a controllable episode generator whose hidden state and verifier outputs can be serialized beside visual observations and actions. That interface supports online agent RL, evaluation, failure collection, verifier testing, and intentional state-coverage synthesis from the same substrate.

Several components are established rather than novel: browser UI implementation, Playwright action execution, programmatic checks, state-diff testing, GRPO, vLLM rollouts, and shaped scalar reward. The paper's contribution is their mobile-specific integration and scale, plus a limited real-device transfer study. Reusers should verify task-check coverage, app fidelity, split semantics, release pins, and whether the current code reproduces paper-era behavior before attributing gains to the environment design.
