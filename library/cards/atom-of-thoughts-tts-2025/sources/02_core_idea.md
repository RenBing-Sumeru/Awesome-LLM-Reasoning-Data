The framework uses a Markov-style claim: a well-formed current state should carry the information needed for the next transition, so the system need not repeatedly carry a full verbal history. Each transition first decomposes the current question into a dependency-based directed acyclic graph, then contracts its subquestions into a simpler atomic question that remains answer-equivalent to the original task. Repeating this process moves the state toward directly solvable atomic questions.

This state representation can sit underneath other inference strategies. A system may branch with tree search or revise a state through reflective refinement, but its prompts are anchored on the compact atomic state rather than on a growing transcript. The contribution therefore changes where the budget is spent: on state decomposition, contraction, and targeted reasoning for the current unit. The record makes each transition inspectable instead of treating a long chain as an opaque text sequence.
