Earlier chain, tree, and graph procedures mainly vary how many thoughts or branches are retained, while their next-step prompts still depend on accumulated history. AoT changes the unit of inference from an appended thought to a contracted question state. Its decomposition-contraction contract explicitly asks whether a smaller state remains answer-equivalent, making context consumption an object of the inference algorithm rather than an incidental implementation detail.

The framework's additional novelty is compositionality: tree search and reflective refinement can operate over the atomic-state sequence rather than requiring a separate long-context formulation. It does not provide a universal formal proof that the model's decomposition is correct, and it is not merely a prompt-length reduction trick. The reusable decision is whether each state transition maintains the dependencies necessary for a later answer while eliminating history that no longer affects it.
