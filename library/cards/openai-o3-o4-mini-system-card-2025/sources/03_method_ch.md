报告披露的是高层谱系，而不是可执行配方。宽泛来源的数据经过质量与风险过滤，之后由未具体说明的训练阶段产生推理模型。报告称大规模强化学习改善策略调整与错误识别；审慎对齐让模型学习依据安全政策推理；指令层级样例则监督 system、developer 与 user 消息之间的优先关系。发布材料还称模型学习何时以及如何调用浏览、Python、图像/文件分析、图像生成、canvas、automations、文件搜索与记忆等工具。

这些阶段的边界没有公开。哪些来源分别进入预训练、监督式后训练、推理 RL、工具使用训练或安全对齐，阶段间是否共享 prompt，谁生成轨迹，候选采样数量以及样本如何过滤或加权，均为 unknown。基础 checkpoint、teacher、解码设置、rollout 数、训练期推理上限、RL 算法、奖励聚合、验证器校准与终止判据同样未知。

系统卡另行记录自动评测、外部红队和 Preparedness 测试。例如，它描述了拒答指标的自动评分器，也报告第三方在评测环境中观察到的 reward hacking 行为。这些信息揭示了评测风险和模型行为，但报告没有说明这些评分器或环境曾生成训练数据或用于优化发布模型。
