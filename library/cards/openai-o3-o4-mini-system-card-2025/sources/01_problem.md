For o3 and o4-mini, the official report names broad pretraining source classes and high-level filtering operations. It also states that o-series reasoning is trained with large-scale reinforcement learning over chain-of-thought behavior. It does not identify the unit of an RL record, prompt source, trace producer, reward or verifier, rollout budget, selection rule, optimizer, split, or released dataset. This Card therefore separates explicit statements from unknown implementation details and from deployment-time evaluations.
