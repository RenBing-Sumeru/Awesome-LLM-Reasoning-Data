HWE-Bench contains 417 tasks from six major open-source hardware projects covering Verilog/SystemVerilog and Chisel, RISC-V cores, SoCs, and roots of trust. Each JSONL record includes repository and PR metadata, problem statement, ground-truth patch, test patch, modified files, bug categories, container preparation, and hidden fail-to-pass tests, with pass-to-pass outcomes when available. The pipeline verifies that the buggy baseline fails native simulation and the reference fix passes before containerization.
