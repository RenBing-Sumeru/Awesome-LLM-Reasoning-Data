The paper evaluates seven LLMs with four agent frameworks. The best agent solves 70.7% overall, exceeds 90% on smaller core projects, and falls below 65% on complex SoCs. Failures are traced to fault localization, hardware-semantic reasoning, and coordination across RTL, configuration, and verification artifacts; project scope and bug type explain difficulty better than code size. This supports real-repository evaluation, although some OpenTitan flows require Synopsys VCS and are not fully open.
