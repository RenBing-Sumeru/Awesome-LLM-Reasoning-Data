The study defines the Answer Convergence Ratio as the earliest sentence-prefix fraction after which all subsequent prefix answers match the full-trace answer. It then proposes three stopping mechanisms. Answer Consistency periodically appends an end-of-reasoning marker at sentence boundaries and stops after the same greedily decoded answer repeats for a fixed number of chunks. Think Token Adjustment increases the end-of-reasoning token logit at likely boundaries. Learn-to-Stop trains an LSTM over final-layer activations; prefixes before the earliest stable point are labeled 0 and that point onward 1. All three predict when to stop, while answer correctness remains an external evaluation outcome.
