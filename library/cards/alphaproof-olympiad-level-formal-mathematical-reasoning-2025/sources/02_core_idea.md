AlphaProof casts Lean tactic mode as an RL environment. A state is the complete logical context of hypotheses and goals, the observation is its string rendering, an action is a Lean tactic, and the transition is Lean's execution result. Episodes end with a kernel-verified proof or when the compute budget is exhausted; actors may also be assigned to disprove a statement. Each tactic receives reward −1, so the return favors short longest proof branches while handling AND nodes with multiple subgoals.

A 3B encoder–decoder proof network proposes tactics and estimates value for an AlphaZero/Sampled-MuZero-style tree search. Main RL learns from successful proofs and disproofs stored in replay; failed attempts are filtered from network updates. TTRL generates a bespoke curriculum of related formal variants for a hard target and runs focused RL/search adaptation at inference time.
