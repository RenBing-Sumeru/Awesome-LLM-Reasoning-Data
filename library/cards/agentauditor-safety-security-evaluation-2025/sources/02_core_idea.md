The main data contribution is ASSEBench, which contains 2,293 carefully annotated agent interaction records spanning 29 application scenarios and 15 safety or security risk types. Ambiguous cases receive both Strict and Lenient labels. The methodological contribution, AgentAuditor, converts previous cases into experiential memories structured around scenario, risk, behavior, and reasoning, then retrieves relevant experiences through a multi-stage process when judging new trajectories. The data objects are not isolated question-answer pairs but interaction records with behavioral processes, risk categories, and judgment rationales, making them suitable for agent judging, trajectory-risk detection, and safety auditing.
