The reconstructable pipeline is:

1. **Source tasks.** For seeded agents, draw from the GSM8K and MATH training splits. A standard 150K agent dataset targets 75K unique post-filter problems from each source. Taxonomy-Based Key Concepts instead starts from a curated combination of cited math taxonomies; QFT generates after question fine-tuning and is not prompted with a specific seed example.
2. **Generate problems.** Qwen2.5-32B-Instruct runs one of 12 agents: Few-Shot, Paraphrasing, Key Concepts, Seeded Key Concepts, Suggester-Editor, IQC, Ask Me Anything, Self-Verification, FOBAR, QFT, Taxonomy-Based Key Concepts, or Distraction Insertion. The agents may create key concepts, edit plans, composed questions, statements, reverse questions, or irrelevant details before emitting a new problem.
3. **Deduplicate and decontaminate.** Apply exact-match problem deduplication. Remove a synthetic problem if at least 95% of the 8-grams in a GSM8K or MATH test problem occur in it. This is lexical filtering, not semantic decontamination, and the paper does not report comparable controls for CollegeMath, GSMPlus, or OlympiadBench.
4. **Generate solutions.** Qwen2.5-Math-7B-Instruct writes worked solutions. Problem and solution generation use temperature 0.7, top-p 0.9, top-k 50, repetition penalty 1, and at most 2,048 new tokens.
5. **Study quality control.** For the six-way comparison, generate three solutions for each of 150K Suggester-Editor problems. Strict Self-Consistency retains all-three agreement; Majority retains two-of-three agreement; Solvability+RM combines a Qwen solvability judgment with InternLM2-7B-Reward ranking; the remaining variants combine filters with the first solution. `First` retains all problems and the first solution. The subsequent FLAMES construction uses `First`, so three-sample self-consistency is not a field or gate for every final record.
6. **Build the mixture.** Mix 50% Suggester-Editor, 20% IQC, 20% Taxonomy Key Concepts, and 10% Distraction Insertion. The paper defines FLAMES Small (150K), Large (1M), and XL (1.5M).
7. **Train and select.** In the controlled scaffold, full-parameter SFT runs on one Amazon EC2 P4 instance with 8 A100 GPUs, DeepSpeed ZeRO-3, batch size 4, five epochs, and ten checkpoints, using SWIFT default hyperparameters. The primary student is DeepSeek-Math-7B; transfer tests use Qwen2.5-Math-7B, Qwen2.5-14B, Mathstral-7B, and Mistral-7B-v0.3.
8. **Evaluate.** Use GSM8K (1,319), MATH5K (5,000), CollegeMath (2,818), GSMPlus without its critical-thinking portion, and OlympiadBench (675); report the GSMPlus distraction subset separately. Choose the checkpoint with the highest average GSM8K/MATH score. Decode at temperature 0 with at most 2,048 tokens and use the Qwen2.5-Math answer extractor/matcher.

Exact seeds, total synthesis GPU-hours/cost, retry and failure behavior, per-agent raw generation yields, all SWIFT optimizer defaults, and a complete runnable implementation are unknown. A reproduction must pin every upstream dataset/model revision, inherited prompt and parser, taxonomy version, random seed, generation endpoint, answer normalizer, and checkpoint-selection protocol.
