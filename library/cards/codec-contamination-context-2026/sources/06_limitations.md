The authors state that CoDeC requires gray-box access to token probabilities, excluding many API-only frontier models. It is also a dataset-level indicator: related data, style, or augmentation can elevate a score without establishing exact record membership. Their analysis warns that highly diverse datasets can retain scores near 50% across models, so a threshold should not be applied mechanically. Before reuse, construct matched post-cutoff controls and inspect score distributions rather than treating one percentage as a verdict. For products without log-probability access, any substitute must be validated separately; apparent confidence in generated text is not the same signal.
