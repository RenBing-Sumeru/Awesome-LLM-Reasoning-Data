- **数量与 schema 漂移：** 论文第 3.2 节写 5,670，而 Table 9 合计为 5,870。当前 HF raw tree 缺少 sequential Email；Viewer 还缺少 parallel Mapping，且只暴露 28 个 configuration。托管字段 `tool_list` 与代码侧 `tool list` 也不一致。缺少带 tag 和 hash 的 manifest 时，不能假设 record count 与 schema 可互换。
- **Verifier 盲点：** Inclusion 只计算 recall，不惩罚额外 call；Usage 只检查 prediction 与 reference 共同工具的参数；基于名称的 EM 可能拒绝语义等价工具，也可能在没有有效执行时接受同名匹配。sequential exact order 还可能拒绝有效的替代 plan。这些是依据发布 metric implementation 得出的 curator inference。
- **Judge 风险：** Traj-Satisfy 与 final-answer accuracy 依赖未固定的 Claude-4/default LLM-judge 设置。论文没有报告 calibration set、human agreement、重复运行方差、semantic-equivalence study、adversarial audit 或 false-positive/false-negative rate。因此 judge preference 可能在 agent behavior 不变时改变分数。
- **动态回放风险：** ReAct 执行 live production-style API。endpoint behavior、content、availability、authentication、subscription tier、rate limit、cost 与 output format 都可能漂移。未核验到不可变 response snapshot、endpoint-version map、reset semantics 或 offline replay bundle，因此不变的 agent 也可能收到不同 observation 与 answer。
- **构造 lineage 风险：** 确切 generation/checking model、prompt、temperature、seed、command line、validation flag、rejection count、reviewer identity、rubric、agreement 与 adjudication 均未披露。发布的 checking path 是可选项，所以 repository default 不能证明托管数据采用了该流程。
- **划分与污染风险：** 发布仅暴露一个公开 `test` surface，没有 train/dev/hidden-test 或 decontamination policy。公开 query、reference、tool 与 metric code 会带来未来 training contamination、reference memorization、retrieval leakage 与 benchmark-specific optimization。
- **保留与完整性风险：** 一些可见 final answer 包含 API 或 JSON-generation failure，但没有 ledger 统计成功、失败、被拒、畸形或 dropped record，也未核验到完整 evaluated-model trajectory archive。可见失败样本不能证明 failure retention 无偏。
- **权利与隐私风险：** GitHub 与 HF 声明 MIT，论文称数据为 synthetic 或来自适当许可的公开数据。这些表述不能证明逐工具 RapidAPI term、schema/output redistribution right、third-party-content right 或 generated-provider-output right。逐记录 PII scan、consent 与 API-output privacy review 均未披露。
- **范围限制：** sequential case 是 chain 而非一般 graph；评测依赖有限的整理 API catalog；provider 推荐/默认 decoding 也没有完整固定。benchmark score 不能证明 trajectory quality、真实部署有效性、合法训练复用，或对已测试 model、tool 与 budget 之外的泛化。
