The pipeline separates an upstream structured substrate from an LLM-authored supervision object. A rule-based translator narrates intersections, lanes, signs, signals, ego and surrounding-agent state, relative positions, and future trajectories. GPT-4 Turbo receives that text and generates five ordered categories: map environment, ego motion, surrounding-agent motion, pairwise interaction, and ego intention.

The first three categories are called factual content and are intended to describe the current scene. Interaction and intention are the reasoning content. The released prompt explicitly tells the model to use both current and future descriptions for interaction answers and to summarize future-period interactions when inferring ego intention. Thus rule-derived input, generated factual Q&A, and generated future-conditioned reasoning are distinct evidence classes even though they appear in one scene record.

There is no programmatic correctness contract for a row. Human evaluation asks whether the correct answer is included, while model evaluation uses reference-overlap metrics, GPT Score, and limited numerical metrics. These are aggregate evaluation surfaces, not per-record verifiers or rewards.
