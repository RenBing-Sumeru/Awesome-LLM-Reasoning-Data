Use this work to design a contamination stress test for an LRM pipeline: preserve an explicit member/non-member split, apply the intended SFT and RL stages, and report detector AUROC before and after each stage. The output is a failure analysis, not a clean-training certificate.

Teams choosing an RL objective can test whether clipping changes detector separation while holding data and base model fixed. Do not use the method to accuse a black-box model or to clear a benchmark without independent provenance evidence.
