MC-Search contains 3,333 multimodal retrieval tasks averaging 3.7 hops across five reasoning structures. Each record stores subquestions, required retrieval modality, supporting facts, intermediate answers, and the final answer, with every hop verified by HAVE for evidence attribution and answer consistency. The data serves both as an agentic MM-RAG benchmark and as process supervision for Search-Align fine-tuning.

The chains also label retrieval modes, separating text, image, and mixed search strategies.
