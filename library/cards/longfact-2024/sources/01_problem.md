Long-form factuality in large language models defines an evaluation surface in factuality, long-form-generation: whether model outputs or agent trajectories satisfy the task-specific feedback contract. The primary source and artifacts are paper: https://arxiv.org/abs/2403.18802; code: https://github.com/google-deepmind/long-form-factuality; the local metadata records the source as 2024 / arXiv.

The decision boundary is benchmarks_evaluation_surfaces with roles benchmark, verifier_reward and verification contract judgment_required, mixed. One benchmark instance is: prompt, long-form answer, atomic or claim-level factuality labels, and aggregate factuality score. This is not a model-training recipe unless the paper separately releases training data; the card treats it as evaluation, audit. It matters for the atlas because the reusable object is an evaluation/data record with a named scorer, judge, verifier, reward, or environment predicate rather than an abstract capability claim.
