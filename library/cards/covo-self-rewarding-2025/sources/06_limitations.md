The central validity risk is that internal consistency is only a proxy for truth. A confidently wrong trajectory can remain stable, and several trajectories can share the same misconception. Because distances are computed by the policy being optimized, reward calibration changes with the policy and may amplify its own blind spots.

Implementation choices are part of the reward contract. Newline segmentation changes the state sequence; answer extraction and exact-string grouping can split equivalent answers or merge malformed ones; the set of sampled candidates limits what each state can be compared against. Prompts with all-identical sampled answers provide no comparative signal, so the optional filter can remove both genuinely easy items and items on which the policy fails uniformly. Computing all state-to-answer distances scales as O(NTK) for N trajectories, T states, and K distinct answers.

Reproducibility is partial. The paper reports 4096 generated tokens and uses curiosity in the proposed reward, whereas the public example script uses 2048 and leaves curiosity disabled by default. The public data repository exposes prompt/reference files, not reward-bearing paper runs, and its train/test schemas currently prevent a unified hosted build. Seeds, run manifests, logs, reward matrices, filtered-example lists, and checkpoints are absent. The paper's chronology-based cleanliness argument is not a measured contamination audit, and the dataset-card MIT declaration does not resolve upstream rights or the code license scope.
