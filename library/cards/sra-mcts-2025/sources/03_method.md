Training prompts come from medium and hard LeetCode questions. The authors discard source answers and remove training questions that overlap test questions using 10-gram duplicate detection with a 0.3 similarity threshold, leaving 1,819 unique prompts. For each prompt, SRA-MCTS repeats selection, expansion, Evaluation & Reflection, and backpropagation. The reported search uses UCT with exploration constant 0.5, expands three child nodes, retries duplicate steps up to five times, caps the overall search at five iterations, and uses expansion temperature 0.9 with top-p 0.98. The LLM judges single-step correctness, solution coherence, completeness, and overall correctness; Reflection either guides the next iteration or emits an end signal. Backpropagation uses alpha=0.5.

After search, code-like text is removed from thinking with regular expressions. The question and thinking prompt the same model to generate final code, and question, thinking, and code form the SFT record. Experiments use gemma-2-2b-it, Meta-Llama-3.1-8B-Instruct, and Qwen2.5-14B-Instruct; LoRA training via LLaMA-Factory uses learning rate 1e-4, two epochs, warmup ratio 0.05, batch size 4, and two RTX A6000 GPUs. The official repository is Apache-2.0, while the linked BinXD/SRA-MCTS-Llama-3.1-8B dataset is CC-BY-NC-4.0 and displays a final JSON schema with question and solution. Its card and repository claim process data covering reasoning paths and code, but the verified public schema does not expose tree parent IDs, node rewards, reflection fields, visit counts, or rejected branches; completeness at that granularity remains unknown.
