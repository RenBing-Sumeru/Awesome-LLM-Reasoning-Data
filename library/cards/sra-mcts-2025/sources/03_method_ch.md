训练提示来自 LeetCode 的 medium 与 hard 问题。作者丢弃源答案，并用 10-gram 重复检测和 0.3 相似度阈值删除与测试题重叠的训练问题，最终保留 1,819 个唯一提示。对每个提示，SRA-MCTS 重复 selection、expansion、Evaluation & Reflection 和 backpropagation。论文设置 UCT exploration constant 为 0.5，每次扩展三个子节点，重复步骤最多重试五次，总搜索最多五轮；扩展 temperature 为 0.9、top-p 为 0.98。LLM 依次判断单步正确性、解法连贯性、完整性和整体正确性；Reflection 要么指导下一轮，要么输出结束信号。回传使用 alpha=0.5。

搜索后，用正则表达式从 thinking 中去除代码类文本。Question 与 thinking 再提示同一模型生成最终代码，三者组成 SFT 记录。实验使用 gemma-2-2b-it、Meta-Llama-3.1-8B-Instruct 和 Qwen2.5-14B-Instruct；通过 LLaMA-Factory 进行 LoRA 训练，学习率 1e-4、两轮、warmup ratio 0.05、batch size 4，并使用两张 RTX A6000。官方仓库采用 Apache-2.0，而链接的 BinXD/SRA-MCTS-Llama-3.1-8B 数据集采用 CC-BY-NC-4.0，展示的最终 JSON schema 为 question 与 solution。其数据卡和仓库声称 process data 覆盖 reasoning paths 与代码，但已核实公开 schema 没有暴露 tree parent ID、node reward、reflection 字段、visit count 或 rejected branches；这一粒度的完整性仍为 unknown。
