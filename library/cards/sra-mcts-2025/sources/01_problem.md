Code models can generate solutions for simple tasks yet struggle when a problem requires decomposition before implementation. SRA-MCTS, published in the IJCAI 2025 Main Track, targets the missing intermediate data object: a natural-language “thinking” path generated before code and reused as an SFT target. It uses Monte Carlo Tree Search to propose, score, reflect on, and select reasoning steps, then asks the same backbone to turn the resulting thinking into code. For the atlas, the central distinction is between the internal search record, with states, actions, self-evaluation rewards, reflections, and rejected branches, and the flattened released question-solution record. Final benchmark execution can score code, but it does not retroactively validate every model-scored reasoning step.
