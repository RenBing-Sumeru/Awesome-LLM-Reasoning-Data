Prior CoT augmentation samples a linear explanation, and Tree-of-Thought explores alternatives without necessarily turning the selected reasoning into training data. ReST-MCTS-style work searches complete answers or uses a separate process reward model. SRA-MCTS instead applies MCTS specifically to the pre-code natural-language thinking portion, asks the same backbone to generate and evaluate steps, carries a reflection field into subsequent expansion, and then serializes the selected thinking with code for SFT. The direction signal is the explicit intermediate object linking question decomposition to code generation. MCTS, UCT, reflection, self-training, and SFT are not new components, and the method does not establish that self-evaluation is calibrated or that the chosen natural-language plan caused the code to pass tests.
