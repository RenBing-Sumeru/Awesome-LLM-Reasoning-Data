GRIP 的具体贡献，是用概念关系条件替代种子题改写。Qwen2.5-32B 从每道 MATH 种子题中提取最多 5 个关键概念，Qwen2.5-7B 与 BGE-M3 再过滤、归并成约 10K 个概念。概念共现形成关键概念关系图中的加权显式边；one-hop 概念对、two-hop 路径、以枢纽为中心的 three-hop 路径，以及由 3 或 4 个概念组成的全连接社群，随后成为生成条件。新题生成提示不包含原始种子题。（论文第 3.1-3.3 节；附录 D。）

数据对象是概念条件问题及其自然语言解答。一个未命名模型先预测难度；Qwen2.5-Math-7B 解决低、中难度题，Qwen2.5-Math-72B 处理高难度题。官方子集只序列化两个概念字符串、问题和解答，因此无法逐行恢复图距离、社群归属、难度、生成器版本、源种子或评审输出。

反馈合同是整项模型判断。DeepSeek-R1-Distill-Qwen-7B、Qwen2.5-Math-Instruct-7B 与 DeepSeek-Math-RL 分别给题目质量打分；分数按模型报告的数学能力加权，平均值须达到 0.85。每个模型还分别给解答 0 或 1，任意一个否决就淘汰该对。论文没有公布题目分数权重。该合同会选择被评审模型认可为逻辑/表述完整且解答正确的样本，但不是对每个推导步骤的形式化验证。（论文第 3.4 节。）

最接近的既有方法会改写种子，或依据外部主题生成。GRIP 的变化是图导出的条件界面及其对隐式概念关系的利用，并把它与难度路由和开放模型投票组合起来。概念抽取、LLM 生成、拒绝筛选和 SFT 单独看都不是新组件；新意在于把它们组合成可扩展的数学数据配方。
