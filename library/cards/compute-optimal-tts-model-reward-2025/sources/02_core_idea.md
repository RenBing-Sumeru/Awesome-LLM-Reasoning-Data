The core claim is that compute-optimal scaling must be reward-aware. In sampling methods a process reward model decides which completed candidates are selected; in search methods it also changes the trajectory distribution by pruning and expanding intermediate steps. A verifier trained on traces unlike the current policy can therefore alter both the final ranking and the search path itself. The same nominal budget can yield very different results when the policy–verifier pairing changes.

The paper treats best-of-N, beam search, and diverse verifier tree search as alternatives to be selected according to the policy, PRM, and difficulty regime. Its empirical message is not that a small model is intrinsically better than a large one. Rather, a small model coupled with an appropriate verifier and allocation strategy can exploit extra inference work more effectively than a much larger model used with an unsuitable or untuned test-time policy.
