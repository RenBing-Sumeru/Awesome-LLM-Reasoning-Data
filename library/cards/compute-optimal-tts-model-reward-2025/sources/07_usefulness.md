Use this study when selecting a test-time policy for a known generator and verifier pair. Build a small validation matrix over problem difficulty, best-of-N/beam/tree-search settings, PRM versions, and budgets; log candidate lengths, PRM scores, selected paths, exact accuracy, tokens, latency, and failure patterns. The goal is to reproduce the decision process, not to copy a winning setting from another model. The public code and project page make it practical to test whether a verifier is aligned with the current policy before giving it control over a large inference budget.
