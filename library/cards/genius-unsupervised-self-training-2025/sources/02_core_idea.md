In one sentence, Genius turns a model’s own non-myopic continuation likelihood into weighted step-local trajectory preferences, then trains the model with Advantage-Calibrated Optimization (ACO). For a query and current response prefix, the policy maintains a beam of paths, samples candidate next steps, and generates a future continuation after each candidate. The average token log probability of that future is the foresight score. Normalized scores define a distribution used twice: sampling from it preserves multiple paths for exploration, while the highest-scoring path and a re-sampled alternative form a preference for exploitation. Each path’s advantage is its foresight value minus the value carried from the preceding step. (Paper §2.2)

The feedback contract is entirely policy-internal. It observes token probabilities for same-policy continuations, relative values between the current and previous decision, and which trajectories the search scaffold retained. It cannot observe whether a mathematical conclusion is true, code executes, a logical inference is valid, or a user would prefer the result. The supervision attaches locally at each decision but compares complete trajectories extending that decision; it is therefore both step-level and trajectory-valued. ACO then uses the chosen/rejected advantage gap to relax optimization when the nominal negative appears to have greater estimated advantage. It calibrates the strength of a noisy preference but adds no new correctness information. (Paper §2.3 and Appendix A)

The reusable record is concrete in the official code. The exploration stage can save `question`, a copied input `ground_truth`, the selected `response`, `response_all_beams`, `traj_pool`, `step_pool`, `prob_pool`, `adv_pool`, `step_prob`, and `sample_id_pool`. The preference constructor reduces that process state to `prompt`, assistant-message lists for `chosen` and `rejected`, their weights, and an average chosen weight. This reduction matters for audit: a final pair alone does not reveal the alternatives, random rejected-path draw, scoring distribution, or policy revision that created it.

The closest comparisons clarify the direction. Self-Rewarding has the model assign response-level 1–5 judgments; ScPO derives response preferences from self-consistency; step-level methods can remain myopic; MCTS-style rewarding adds more expensive backtracking; and the authors’ related φ-Decoding work uses foresight for inference-time exploration. Genius combines foresight with training-data construction and ACO. Candidate generation, beam search, DPO-style implicit rewards, and future simulation are inherited ingredients; the specific change is to make future-continuation likelihood the step-local selection interface for a label-free preference dataset.
