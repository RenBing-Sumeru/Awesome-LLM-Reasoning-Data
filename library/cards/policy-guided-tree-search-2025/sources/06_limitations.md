**Reward validity.** Target-model likelihood is a probability/fluency signal, not a verifier of intermediate logical correctness. A fluent but invalid step may receive favorable shaping, while an unusual correct step may be penalized. Node hidden states and intermediate rewards originate from the same target model, so representation error and reward error can be correlated. Terminal comparison or an outcome reward model can judge the final answer, but does not repair unfaithful intermediate paths. The mixed contract must not be relabeled as fully programmatic verification.

**Policy, generator, and budget entanglement.** The learned controller does not choose from an independently defined set of reasoning states. Expansion first asks the target LLM for a breadth-limited sibling set and sorts candidates by action log-probability. Generator quality, sampling, sibling ordering, action costs, depth, breadth, and maximum search steps all affect which states the policy can reach and what return it receives. Reported accuracy and token ratios cannot isolate controller quality from these coupled choices. Per-example generated tokens, calls, latency, cost, retries, and stop reasons are not released.

**Paper–code termination drift.** The paper assigns an explicit terminate action and describes a \(D+2\) action space. The audited code exposes `depth_limit + 1` actions for continue, branch, and depth-indexed backtracking, and terminates only when the generated task state is terminal or the step budget is exhausted. This changes both the behavior policy and the meaning of terminal transitions. Without a paper-matching configuration or explanation, the public implementation cannot be assumed to reproduce the stated termination policy.

**Missing raw search records.** Runtime objects can retain the root, all attached children, visits, traces, rewards, and a selected policy trajectory. They can represent zero-visit generated children and visited paths later abandoned. Yet the release contains no paper-run raw trees, serialized `outputs.pth`/`auxiliary.pth`/`metrics.pth`, replay buffers, or stable record IDs. No manifest distinguishes selected, rejected, abandoned, unvisited, and visualization-pruned nodes. Consequently, branch coverage, backtracking behavior, false exploration, reward attribution, and item-level compute cannot be audited.

**Incomplete policy supervision.** Stored trajectories include only the selected navigation action’s log-probability and the value prediction, not the full policy logits or probabilities for chosen and unchosen actions. This blocks off-policy reassessment, action-calibration analysis, and counterfactual replay. The trained GPS checkpoint is absent, as are learning rate, batch size, update count, rollout count per update, seeds, and complete paper-exact task/PPO configs.

**Data lineage and split gaps.** The paper describes benchmark-specific splits, but exact policy-training IDs, StrategyQA’s sampling seed, GPQA’s full setup, and a unified item-level manifest are unknown. The repository bundles some Blocksworld, MATH, and PrOntoQA material, but that is not a complete source-mixture or transformation ledger. No exact or semantic deduplication, benchmark-overlap check, or decontamination analysis is disclosed. Benchmark gains cannot resolve these risks.

**Release rights.** No root `LICENSE` or project-license declaration was found at the pinned repository revision, and no dataset card or upstream rights manifest covers bundled task inputs or generated outputs. The code’s public visibility therefore does not establish permission for redistribution, commercial use, checkpoint training, or derivative trace release. The paper and arXiv access terms do not substitute for code/data licensing.

**Generalization and evidence limits.** Experiments cover mathematics, commonsense, logical deduction, science questions, and Blocksworld planning with LLaMA 3.1 8B/70B. Transfer to other model families, open-ended generation, tools, agents with external environments, formal proofs, or safety-critical settings remains unknown. Results are author-reported and were not independently reproduced in the audited artifacts.

Status remains `partial`. The citation, paper, appendices, official code attribution, runtime schema, budget disclosure, and aggregate results are verified; raw traces, full policy distributions, branch manifests, checkpoints, exact configs, licenses, and decontamination remain missing.
