Store outcomes in a question-by-trial integer matrix and define the category weights before comparing models. Tally each row's categories, add the prior counts, and apply the closed-form posterior moments in Algorithm 1. Prior observations can be supplied when their reuse is justified. In the categorical experiments, correctness, formatting, length and log-probability signals define rubric categories; some schemas also use calibrated CompassVerifier-3B label probabilities. The statistical estimator depends on those category assignments rather than validating answers itself.
