- **Public-object boundary:** Hugging Face releases 311 QA/image/source-reference rows in one `train` split and a decryption helper. It does not release the complete successful or failed search episodes, framework, evaluator, SoM boxes, search results, Gemini summaries, caches, judge logs, or deterministic replay manifest. The GitHub README still places framework code, evaluation script, and SoM annotations in its pending-release checklist.
- **Answer judge:** GPT-4o scores semantic agreement with acceptable answers, not citation support or step provenance. Reported manual agreement lacks a disclosed sample size and raw labels; judge prompt, API settings, calibration by answer/category, and optional rule implementation are unavailable. Alternative valid answers can be rejected and unsupported answers accepted.
- **Dynamic substrate:** Live SerpAPI rankings, thumbnails, pages, regional availability, query locale, dead links, and near-duplicates change. Gemini-generated page/image summaries can omit or distort evidence before the evaluated model sees it. Without frozen responses and caches, later runs need not receive the same observations.
- **Replay and release drift:** Model/API versions, prompts, seeds, browser/runtime, dates, locale, reset semantics, retries, and source snapshots are incompletely pinned. Current Hugging Face data uses five Arrow shards while `state.json` references two obsolete names, so consumers must pin the audited revision and inspect actual files.
- **Split and contamination:** The sole public split is named `train`, but no independent dev/test or hidden holdout exists and author use is evaluation-only. New/rare event selection, no-search filtering, Google image-search resistance, masking, and public XOR encryption reduce shortcuts but do not establish pretraining-overlap measurement, cross-benchmark deduplication, or future contamination control. The public canary and decryptor make encryption a speed bump.
- **Lineage, privacy, and rights:** Rows retain `video_url` or `arxiv_id`, but lack source snapshots, annotator/edit/filter/redaction logs, SoM mapping, and item-level rights classification. The paper and HF card declare CC BY 4.0, while the GitHub tree has no license file and video frames or arXiv figures/tables retain heterogeneous third-party rights. Masking, exclusion, and takedown claims lack a public record-level audit.
- **Experimental attribution:** SoM uses human-curated boxes, Qwen receives a lower 10-call cap, and the error taxonomy assigns one dominant cause. Reported score differences therefore mix model capability, privileged localization, tool policy, search/summarizer state, budget, and judge behavior; benchmark performance alone cannot certify the data object.
