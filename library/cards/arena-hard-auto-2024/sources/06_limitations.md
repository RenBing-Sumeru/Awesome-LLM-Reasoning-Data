Arena-Hard correctness is preference-relative. A judge win does not certify factual accuracy, safety, or task completion; it only records the configured judge's preference under a prompt and answer pair. Judge models, prompt formatting, response length, markdown style, baseline answers, and endpoint versions can move scores. Public prompts and judgments can be trained on. The current repository advertises newer v2.0 configurations with GPT-4.1/Gemini-2.5, so paper-era scores and current leaderboard scores must not be mixed without version labels.
