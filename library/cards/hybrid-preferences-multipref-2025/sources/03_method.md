1. Build MultiPref from prompt–answer pairs that have both human and GPT-4 preference labels, then describe each pair with textual and instruction tags. 2. Sample human-label budgets and use the tags to assemble candidate mixtures: records inside the selected subset retain human labels, and the rest retain GPT-4 labels. 3. Train reward models on 200 such mixtures and use their RewardBench results to fit the quadratic performance prediction model. 4. For a target pool, score 500 simulated allocations with that model and retain the highest-scoring route; pairs tied by either source are excluded from reward-model training.

The input is a dual-labeled preference pool; the output is a routed label set for reward-model training. The acceptance signal is predicted RewardBench performance. Reproduction requires the MultiPref revision, tagging implementation, GPT versions, reward-model recipe, candidate-sampling seed, human budget, and RewardBench revision; serving cost for a new run is not fully disclosed.
