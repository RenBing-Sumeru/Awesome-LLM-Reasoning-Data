# 阅读笔记

- **定位：**论文中心对象是公开的 1200 万 rationale 混合数据，8B 模型是其消费者与验证载体。
- **方法抓手：**来源分流、分类专用开放模型改写和视觉一致性过滤共同决定记录去留。
- **数据/Artifact 抓手：**Apache-2.0 的公开仓库提供 10M/2M JSON manifest 与 WebDataset 形式的单图/多图可下载 shard。
- **证据锚点：**受控的 100 万记录过滤实验把 15 项平均分从 42.6 提高到 49.9，同时有一项 benchmark 退化。
- **复用决定：**完成按类别的来源许可、假阳性与去污染审计后，才用于大规模多模态 SFT。
