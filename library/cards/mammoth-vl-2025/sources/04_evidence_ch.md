# 证据

**主张：**self-filtering 能显著提高改写记录的训练效用。**受控设置：**附录表 A1 在相同条件下，用过滤前与过滤后各随机抽取的 100 万条记录训练同一 Qwen2.5-1.5B-Instruct 风格模型。**结果：**15 项 benchmark 平均分从 42.6 升到 49.9；ChartQA 从 26.8 升到 63.0，DocVQA 从 71.7 升到 76.5，但 MMMU-Pro Vision 从 15.5 降到 13.7。**边界：**该实验在 100 万规模上隔离了报告的过滤决策，但 filter 与改写使用同一模型家族，收益不能证明每条保留 rationale 都正确。
