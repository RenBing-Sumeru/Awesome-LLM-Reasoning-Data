# Method

1. **Screen and categorize sources.** Input: 153 public multimodal datasets. Operation: inspect 1,000 sampled records per source, place 58 strong sources in Group A, 60 improvable sources in Group B, discard 35 weak sources, and map survivors to ten task categories. Output and transition: retained originals and rewrite candidates. Check / stop rule: keep sources with adequate content and modality alignment; standardize media dimensions/aspect ratios.
2. **Rewrite task-specific demonstrations.** Input: Group B media plus original QA/caption and category prompts. Operation: use InternVL2-Llama3-76B for visual categories and Llama-3-70B-Instruct for caption data to create harder instructions and detailed rationale-bearing responses. Output and transition: rewritten instruction-response candidates enter filtering. Check / stop rule: prompts enforce category-specific record formats and image-conditioned content.
3. **Filter visual consistency.** Input: rewritten candidate and corresponding image. Operation: InternVL2-Llama3-76B judges relevance to the image, logical consistency, and factual accuracy. Output and transition: a Yes decision admits the record to the released mixture; No rejects it. Check / stop rule: all three criteria must pass, with OCR/chart records experiencing the largest removal rates.
4. **Mix and train consumers.** Input: retained originals, accepted rewrites, Qwen2.5-7B-Instruct, SigLIP, and an MLP projector. Operation: use a 70% rewritten/30% original mixture, then run alignment, 10M single-image SFT, and 2M one-vision SFT. Output and transition: MAmmoTH-VL-8B checkpoints and 23-benchmark results. Check / stop rule: each stage trains one epoch on its fixed manifest; Stage-3 single-image records do not overlap Stage 2.

**Reproducibility:** verify the 10M/2M JSON manifests, media shards, source IDs/licenses, category prompts, model revisions, filter outputs, and released checkpoints. Fix the 153-source snapshot, 1,000-item screening samples, teacher/judge versions, image normalization, rewrite/original ratio, random seeds, and three training manifests; total rewriting compute, generation temperature, source-level acceptance counts, and benchmark decontamination are not disclosed.
