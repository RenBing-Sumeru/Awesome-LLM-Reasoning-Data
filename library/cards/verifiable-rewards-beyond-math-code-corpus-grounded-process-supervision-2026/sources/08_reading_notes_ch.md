1. 一句话定位：用固定语料和证据蕴含为事实回答逐句打过程奖励。 收录时应确认核心贡献是过程反馈，而非仅有模型权重。
2. 方法抓手：回答生成、claim 拆分、证据检索、蕴含判断、unknown 区分。
3. 数据抓手：问题—句子声明—证据—verifier result—奖励。 复用需核查规模、字段、split、许可、去污染和 lineage。
4. 证据锚点：轻量 verifier 改善过程判定并减少 LLM judge 成本。 证据仅覆盖论文模型、预算和 benchmark，跨域需重测。
5. 复用决定：适合 corpus-grounded QA；最大风险是检索不到被误判为错误。
