Use ScreenSpot-Pro as a grounding-evaluation schema: screenshot ID, application, operating system, professional domain, instruction language, target type, bounding box, predicted coordinate or box, evaluator rule, model version, and search budget.

For this atlas, it is useful as a perception-layer benchmark for GUI agents. It should be linked to, but not confused with, full environment benchmarks: it tests where to act on a screen, not whether an agent can complete a workflow after acting.
