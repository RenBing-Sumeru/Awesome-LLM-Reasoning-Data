可以把 ScreenSpot-Pro 用作 grounding-evaluation schema：screenshot ID、application、operating system、professional domain、instruction language、target type、bounding box、predicted coordinate 或 box、evaluator rule、model version 和 search budget。

对 atlas 来说，它是 GUI agent 的 perception-layer benchmark。它应该和完整环境 benchmark 关联，但不要混淆：它测试的是屏幕上应该在哪里动作，不测试 agent 动作后能否完成 workflow。
