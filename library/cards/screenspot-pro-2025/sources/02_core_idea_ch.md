核心贡献是一个由真实高分辨率专业软件截图构成的更难 GUI grounding benchmark。ScreenSpot-Pro 覆盖 23 个应用、五个行业和三个操作系统，包括开发、创意软件、CAD/工程、科学分析工具、办公软件和 OS commons。

数据面是 screenshot-plus-instruction grounding。反馈契约检查预测点或区域是否落入人工标注 target box。论文还提出 ScreenSeekeR 搜索式 grounding 方法，但可复用 benchmark 对象是带标注的 GUI target set。最接近的对比是 ScreenSpot、SeeClick、OSWorld grounding subtasks 和其他 GUI grounding 数据集。方向标签是 high-resolution professional GUI localization。
