The accepted venue for **The Signal is in the Steps: Local Scoring for Reasoning Data Selection** is recorded neutrally as **ICML 2026**. Official presentation surfaces are not expressed consistently enough for an exclusion claim: the ICML poster landing page links a related Oral presentation page, whose title and badge say Oral, while an OpenReview author profile labels the paper `ICML 2026 spotlight`. The paper identity is also verified by arXiv:2510.03988 and OpenReview ID `GcB3a6IonG`. The arXiv v2 PDF remains headed `Preprint`. All three authors are affiliated with Virginia Tech on the paper's first page.

The paper studies a narrower problem than prompt selection: for a fixed prompt, multiple teachers may produce several long reasoning responses whose final answers are all correct, but training the student on different responses can produce different downstream results. The question is which **complete response** should become the SFT target for that particular student.

The main data object is an offline candidate group and one selected record:

| Field | Role in the pipeline |
|---|---|
| prompt and ground truth | Defines the task and the nominal final-answer admission check |
| candidate responses | Long, complete solutions generated by DeepSeek-R1, QwQ-32B, or Qwen3-32B |
| candidate admission | Every candidate is stated to match the ground-truth final answer before scoring |
| step boundaries | GLM-4.5-Air groups the unchanged response into logical JSON `sentence_groups` |
| local scores | The pretrained target student supplies per-token log probabilities within each step under a short step context |
| response score | Equal-weight mean of the candidate's per-step LocalLP values |
| selection decision | The full response with maximum LALP is retained as one SFT record |

The principal mixed-teacher selection set uses all **817 GAIR/LIMO prompts** and retains one complete response for each prompt, yielding 817 selected responses. The number of main candidates per prompt, candidate identities, step boundaries, per-step scores, ties, failures, and final decisions are not released. A separate within-teacher study uses 8,890 filtered MATH level-3-to-5 prompts and explicitly generates 16 candidates per prompt; that experiment must not be confused with the 817-response main selected corpus.

This belongs in **Data Construction and Open Release Recipes** because it changes how candidate reasoning traces are scored and selected before ordinary SFT. The step decomposition is an internal selection interface, not the released or trained target. LALP provides no step-correctness labels, process rewards, or intermediate supervision, and it does not turn the work into Process and Trace Supervision Data. The selected complete answer-correct response is the training record.

The method is also an audit of Global Average Log Probability (GALP). GALP scores an entire response under its full generated prefix; the authors find that in long mixed-teacher data it can reward fluency, discourse, and self-conditioning rather than transferable reasoning transitions. LALP shortens the conditioning context and equalizes step contributions to reduce that failure mode.
