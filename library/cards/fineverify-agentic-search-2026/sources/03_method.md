For a user question, the system constructs checkable sub-questions and samples complete agentic-search trajectories. It evaluates each candidate against every sub-question under the same criteria, records the resulting judgments, aggregates them, and returns the candidate with the highest aggregate. This is an inference-time reranking procedure; it does not require training a new reward model in the reported workflow.

The experiments use GPT-5-mini and Gemini-3-flash across four agentic-search benchmarks. FineVerify is compared with majority voting, weighted voting, Best-of-N, solution aggregation, and confidence verification as the number of sampled trajectories grows. The paper releases code and data, so a replication can inspect the decomposition prompts, verification prompts, aggregation rule, and benchmark-specific answer extraction rather than treating the final leaderboard score as the whole method.
