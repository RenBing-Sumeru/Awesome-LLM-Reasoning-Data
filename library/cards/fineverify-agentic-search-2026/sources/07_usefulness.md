Use this work when a search agent must answer questions containing several factual conditions and a simple vote over trajectories is not credible. The operational template is to log a shared decomposition, retain candidate-level verification traces, measure accuracy at equal trajectory budgets, and separately account for verifier calls. The released repository is the right starting point for audit and reproduction, but a deployment should add held-out checks for decomposition completeness and evidence grounding before allowing the aggregate score to decide a high-stakes answer.
