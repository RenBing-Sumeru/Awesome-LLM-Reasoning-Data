FS-Researcher 为长程 agent 轨迹提供了具体记录模式。可复用记录应保留任务 ID、会话与 agent 身份、来源 URL 和获取时间、原始网页哈希、笔记到来源的引用、文件路径、编辑差异、待办/检查表状态变化、工具调用与观察、大纲和章节版本、模型/工具版本、成本与终止决策。这类工作区可用于血缘审计、交接分析、故障恢复实验，以及研究增加上下文构建计算如何改变信息覆盖。

复用时应区分原始证据、模型撰写笔记、控制状态与最终文本；未经独立检查，任何一类都不应被视为 ground truth。论文的基准提升说明环境设计值得研究，但不能证明公开工作区记录（若存在）天然洁净或具备后训练许可。
