Each agent follows a ReAct loop and can inspect or edit workspace files through list, search, read, insert, delete, and replace operations; web collection uses Google SERP and Jina-based page reading. The workspace separates deliverables from control files. Context Builder maintains `index.md`, hierarchical notes under `knowledge_base/`, and raw pages under `sources/`; statements in notes carry citations to archived files. It updates the index and notes non-linearly while browsing, then reviews the workspace against a checklist at session end. Report Writer creates an outline and writes sections against the saved knowledge base rather than carrying all evidence in its active context.

The paper evaluates DeepResearch Bench (100 tasks across 22 fields), DeepConsult (103 mainly business/consulting queries), and a random 100-query BrowseComp subset. Context-building sessions are varied to study test-time scaling; exact workspace records depend on backbone, tools, live web state, and run settings. The official repository is linked and the ACL page says code and data are open-sourced, but this Card has not verified a complete immutable release of every evaluated task, web snapshot, workspace revision, rejected source, judge record, and replay configuration. Those fields remain unknown or incomplete.
