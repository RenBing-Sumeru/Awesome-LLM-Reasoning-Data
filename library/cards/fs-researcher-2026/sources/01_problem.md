Deep-research agents must browse many pages, preserve fine-grained evidence, and write long reports. Keeping the entire trajectory in one model context forces observations, notes, and report drafts to compete for a fixed token budget; summarizing observations extends the run but can discard provenance and still remains context-bounded. FS-Researcher studies whether a persistent file-system workspace can externalize this state and support additional research sessions. The relevant data object is a task-linked workspace containing archived web pages, citation-grounded notes, plans, checklists, logs, and report sections—not only the final benchmark report.
