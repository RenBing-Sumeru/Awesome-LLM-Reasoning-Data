持久化不等于正确。Context Builder 可能归档无关或错误网页、错误转述内容，或给笔记附上并不支持陈述的引用；检查表式自审也可能继承生成器盲点。Report Writer 受工作区内容限制，仍可能综合出缺乏支持的主张。实时搜索结果、网页内容、Jina 抽取、模型版本和外部 API 都会变化，使重放更困难。

开放式基准依赖 judge 模型，论文的扩展分析也主要考察分配会话数与结果的相关性。更多轮次可能增加冗余证据并降低可读性。完整审计需要任务与划分清单、不可变网页快照、指令、工具和模型版本、随机种子、全部工作区修订、被拒来源、检查结果、judge 输入输出以及基准和网页内容许可证。除非从发布物逐项核验，否则这些记录级工件的可得性与完整性仍为 unknown。
