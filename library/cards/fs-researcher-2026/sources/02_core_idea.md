FS-Researcher separates evidence accumulation from report composition. A Context Builder browses with search and page-reading tools, decomposes the topic, archives raw pages, and writes a hierarchical knowledge base whose claims point to archived sources. A Report Writer later reads that workspace on demand and drafts the report section by section. Markdown deliverables and control files—todos, a manually curated checklist, and execution logs—persist across sessions, so the file system acts as external memory and a coordination substrate. The control contract is environmental and checklist-based; the paper does not establish a learned per-action reward or an oracle process verifier.
