Prior deep-research systems use static pipelines, sub-agents, or observation summaries to manage context pressure, and coding agents already use file-system workspaces. FS-Researcher's distinctive integration is a two-stage research harness in which raw web evidence, structured notes, navigation indexes, todos, checklist findings, logs, and report sections are durable, revisitable trace objects shared across sessions. This makes workspace revisions and agent handoff auditable in principle. ReAct, web search, Markdown files, dual-agent decomposition, and section-wise generation are not individually new. The paper contributes an agent environment and scaling study, not a new process-label dataset or guaranteed evidence verifier.
