论文在 DeepResearch Bench 上报告报告质量与引用指标，在 DeepConsult 上使用比较式判断，并在可验证的 BrowseComp 子集上报告答案准确率。实验还在相同 backbone 下比较系统，消融持久工作区、双 agent 分工与逐章节写作，并改变 Context Builder 的轮次。更多构建计算通常扩大知识库，并与若干报告质量指标正相关；案例同时显示，证据密度提高时可读性可能下降。论文还报告文件 I/O 只占极小的墙钟时间。

这些证据支持“持久工作区会改变已测试 harness 下的长程搜索与写作行为”这一系统结论，但不能认证每个归档页面、笔记、引用或报告主张。开放式评测多数依赖 LLM-as-a-judge，网页状态会变化，而且构建计算与报告得分的相关性不是逐记录数据质量证明。
