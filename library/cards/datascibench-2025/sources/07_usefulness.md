Use DataSciBench as a schema for data-science agent evaluation where each task carries its own function and metric. Preserve prompt, data files, task type, GT provenance, metric function, metric validation notes, model code, execution logs, package versions, random seed, timeout/error state, and score. For atlas work, it helps design benchmark records that distinguish generated code, executed result, metric output, and verified GT. It is also a useful audit checklist for whether a data-science benchmark has only easy answer keys or a real executable feedback contract.
