DataSciBench asks how to evaluate LLM agents on realistic data-science tasks where ground truth and metrics are not always simple or single-task. The primary source is the arXiv paper submitted on 19 February 2025, with official code/data links to the THUDM GitHub repository and Hugging Face dataset. It is in scope as a benchmark and executable metric surface for data-science agents. It is not only a table QA set or a Kaggle-style leaderboard clone. A task contains a natural data-science prompt, task type, data files or context, generated code/output, ground truth, metric function, and programmatic scoring rule. The atlas value is its explicit Task-Function-Code feedback contract.
