The contribution is a data-science agent benchmark that combines curated natural prompts, semi-automated ground-truth generation, metric validation, and a Task-Function-Code framework for evaluating executed code outcomes. The core mechanism is to use predefined task types and aggregate functions, then apply LLM self-consistency plus human verification to produce or validate ground truth. The data object is a data-science task with executable metric logic, not just a final text answer. The feedback contract is programmatic: code outputs are assessed by defined metrics and rules. Closest comparisons are single-task data benchmarks and straightforward metric datasets. Direction label: executable data-science evaluation surface.
