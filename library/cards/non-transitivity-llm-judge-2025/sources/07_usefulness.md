Use this protocol when ranking several instruction-following systems with an LLM judge. Supply pairwise outputs, run cycle checks and a tournament aggregation, then compare the resulting ranking with an external human-preference reference. Do not use a baseline-only leaderboard as evidence of stable ordering when comparison budget or judge position control is absent.

For a release audit, fix the candidate set and prompts, collect comparisons to inspect cycles, then fit Bradley--Terry and report both graph and ranking. Success is improved agreement with a separately maintained human-preference reference, not a higher internal score. If full round-robin is infeasible, use Swim with a stated budget and a budget-matched comparison. It is unsuitable without a credible external reference or controlled pairing.
