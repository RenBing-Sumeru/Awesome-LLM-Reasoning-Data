**Feedback mismatch and verifier scope.** Search sees public code tests, ARC demonstrations, or an MLE validation split, while final success uses hidden tests or held-out outputs. Repeated search can overfit these visible surfaces. A high node score does not prove hidden correctness, and none of the evaluators validates intermediate reasoning, causal faithfulness, or semantic quality. ARC-AGI-2 Pass@k says that some branch discovered an exact solution; it does not prove that a deployable selector will choose it.

**No released raw trace corpus.** The paper-run response trees are not public. Missing objects include the exact task-to-run manifest, every generated answer, parent/child edges as realized, widen/deepen choices and generation order, evaluator payloads, node scores and backups, model-call responses, token/price usage, and final selection history. Unselected branches are especially important: no explicit pruning/deletion path was found, so the implementation can retain them locally, but the public release contains neither all branches nor the rejected/non-winning subset. Aggregate figures and example trees do not support record-level replay.

**Model and API drift.** GPT-4o is pinned to `gpt-4o-2024-08-06`, but main DeepSeek-V3 calls use the mutable `deepseek-chat` alias. The exact served revision, provider-side implementation, retry behavior, and any later endpoint drift are unknown. ARC-AGI-2 names `gemini-2.5-pro-preview-05-06`, `o4-mini-2025-04-16`, and `deepseek-r1-0528`, but reproducing model behavior can still depend on provider infrastructure and unavailable historical endpoints.

**Budget comparability.** Counting one generated node as one API call hides completion length, context growth along revision chains, evaluator runtime, parallelism, retries, wall-clock time, and monetary cost. MLE candidates additionally run on one H100 with a one-hour limit. Main results use up to 128 calls, appendix ARC-AGI can use 512 nodes, and ARC-AGI-2 uses 250 calls; collapsing these into one “search budget” would misstate the protocols. TreeQuest also warns that large asynchronous batches can bias the tree toward wider shapes.

**Stochasticity and coverage.** Temperatures are non-zero, but replication is uneven: five runs for LiveCodeBench, three for CodeContest and ARC-AGI, and one for MLE-Bench. The benchmark families all expose executable or scalar feedback; transfer to open-ended reasoning, subjective judgment, safety tasks, long-horizon agents, or settings without a cheap evaluator remains unknown. External evaluators can also be unavailable or more expensive than generation, an assumption acknowledged by the paper.

**Contamination, splits, and rights.** Restricting LiveCodeBench to August–November 2024 is a documented contamination precaution, not a comprehensive audit of model training overlap, benchmark cross-overlap, or generated traces. Code search feedback uses public tests, MLE uses an internal 80/20 split, and ARC uses demonstrations, so partition integrity must be preserved in reproduction. TreeQuest and the ARC-AGI-2 repository are Apache-2.0, but that license does not grant rights to benchmark prompts, Kaggle-derived data, model responses, or provider logs. The NeurIPS supplemental experiment bundle has no verified root license; its reuse terms remain unknown.

**Release and reproduction status.** The entry remains `partial`, not because the citation is weak, but because code-level capability is much stronger than instance-level disclosure. Direct trace reuse, independent score-history audit, stable API reproduction, and supplemental redistribution remain blocked by the missing raw trees, paper-run logs, model revision pin, and supplemental license.
