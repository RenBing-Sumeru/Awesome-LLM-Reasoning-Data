The official *GPT-5.1-Codex-Max System Card* is a first-party OpenAI report dated November 18, 2025; the associated OpenAI index page is dated November 19. It addresses how a frontier coding agent was trained and evaluated for long-horizon software-engineering work and safety-sensitive behavior, but it is not a conventional paper, an open dataset release, or a complete post-training recipe. Its Atlas role is therefore a disclosure ledger: identify the post-training data objects and feedback interfaces that are actually named, then preserve everything else as unknown.

The report gives three partially observable training objects. First, a synthetic malware pipeline produces prompts, code snippets, and environment configurations, including edge cases and adversarial examples, to teach refusal, contextual or defensive assistance, and calibrated dual-use behavior (PDF §4.1.2.1, p.7). Second, new prompt-injection safety data following the Instruction Hierarchy framework teaches the model to ignore attacks in coding environments (§4.2.2.1, pp.7–8). Third, destructive-action RL episodes contain a coding rollout in which a separate user model makes conflicting edits; the target behavior is preserving those changes rather than reverting them, and successful non-reversion receives positive reinforcement (§4.3.2.1, p.8).

A plausible episode schema, limited to disclosed fields, is task prompt plus code or environment context, user-model edit, agent actions or response, resulting patch or artifact, policy or environment outcome, preservation decision, and reward. The report does not publish serialized records, counts, prompt origins, repository revisions, generators, rejected attempts, or record lineage. Evaluation objects such as CTF tasks, CVE-Bench, Cyber Range, SWE-Lancer, MLE-bench, internal pre-PR tasks, and OpenAI-Proof are important evidence surfaces but are not identified as training data.

This belongs in `frontier_reports_data_disclosure_ledger` because its main research value is the gap between unusually concrete mechanism-level disclosures and the missing corpus-level evidence. It does not establish an open coding-agent dataset, a reusable verifier, or global benchmark decontamination. L4 here means the official HTML and 27-page PDF support a bilingual, section-located audit Card; it does not mean the hidden training pipeline is independently reproducible.
