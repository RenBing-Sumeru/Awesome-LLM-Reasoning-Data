The evidence for inclusion is the official arXiv paper plus a public project page and GitHub repository that expose the benchmark as runnable software rather than only a leaderboard. The paper reports 100 tasks across 10 open-source apps and evaluates existing mobile agents including AppAgent and MobileAgent. The repository README confirms the install path through AndroidStudio/ADB/emulators, lists the default benchmarking apps, and describes a dummy agent used to test whether task-completion detection works.

The strongest row-level evidence is the validator result on an executed episode. A model trace is credible only when the emulator state, action log, and task-specific success check are available under the same task release. Aggregate benchmark scores are therefore evidence about a particular harness version and model scaffold, not universal mobile-agent competence.

The evidence boundary is important. The public artifacts verify that code and project materials exist, but they do not by themselves prove stable reproduction across devices, OS images, app versions, or accounts. Any comparison should state the exact repository revision, task subset, emulator setup, app data, prompt, action interface, timeout or step budget, and validator code used for scoring.
