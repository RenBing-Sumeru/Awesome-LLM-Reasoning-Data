The core contribution is a user-friendly benchmark harness for mobile LLM agents that keeps realistic Android interaction while reducing setup and evaluation friction. Instead of treating mobile control as a screenshot-only benchmark or as a closed agent demo, MobileAgentBench packages tasks, environment wrappers, evaluator logic, and baseline-agent integration into a reproducible repository and project release.

The data object is a mobile task episode from the reported 100-task, 10-app suite. It starts from a configured emulator/app state, exposes observations to an agent, records actions, and ends with a task-specific success validator. The feedback contract is environmental: a task passes when the validator can confirm the expected app state or data condition from the emulator, not merely when the model describes the correct action.

Closest comparisons include AndroidWorld, AndroidEnv, Mobile-Bench, AppAgent, and other GUI-agent benchmarks. The direction label is lightweight executable mobile-agent evaluation. The work is most useful when the question is not "which static screen element should be clicked" but "can an agent run an end-to-end mobile task under a runnable Android harness?"
