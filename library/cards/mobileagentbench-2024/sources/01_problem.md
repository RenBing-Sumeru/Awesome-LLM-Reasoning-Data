MobileAgentBench asks how to evaluate mobile LLM agents efficiently when the agent must operate real Android applications but the benchmark should still be easy for researchers to install, run, and extend. The primary source is the arXiv preprint submitted on 2024-06-12, with official project and GitHub pages maintained by the authors.

The engineering gap is that realistic mobile-agent benchmarks are often expensive to set up, unstable across app versions, or tied to one heavy evaluation scaffold. MobileAgentBench is included as an agent-environment and benchmark-harness surface, not as a training dataset, reward model, or general GUI screenshot collection.

The evaluation surface is an Android emulator task: a natural-language instruction is executed through UI actions, the environment returns screenshots and/or structured UI state, and task-specific validators decide whether the requested state was reached. The paper reports 100 tasks across 10 open-source apps, and the official README lists the default benchmarking apps as SimpleMobileTools Calculator, Calendar, Contacts, FileManager, Gallery, AppLauncher, Messager, MusicPlayer, Notes, and Recorder. Its atlas value is the reusable contract between task instruction, mobile state, action trace, and validator, with audit risk concentrated in emulator setup, app data, task validators, and version drift.
