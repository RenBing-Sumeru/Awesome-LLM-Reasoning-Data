The evidence to trust is the official task release, data schema, and scoring contract, not only leaderboard numbers. The local audited scale is: 9.6K human-written questions and 23.1K machine-generated questions reported by the paper; repository documents chart images, tables, splits, and annotations. Instance-level evidence is a single record containing chart image, natural-language question, answer string or number, source split, chart table, and optional visual annotations in the full release., the model output or trajectory, and the verifier/judge result from answer-level match or normalized comparison to the gold text/numeric answer under the evaluation script.

Reported aggregate scores should be interpreted only within the official setup. Evidence boundaries include Exact split, hidden/public policy, live-refresh policy, and subset version should be pinned from current official artifacts before score reuse.; License and redistribution terms require artifact-level review unless explicitly recorded in official sources.; Public benchmark records can leak into future training data; post-release score claims require versioned contamination evidence. Additional audit note: arXiv verifies authors, ACL Findings status, and question counts; official GitHub verifies dataset layout, full release, annotations, and license file. If a paper uses a judge or rubric, the judge prompt/model/version is part of the evidence; if it uses programmatic checking, the exact checker and runtime are part of the evidence.
