The math pool begins with 699k noisy problems. Completeness and answer-verifiability checks, removal of proof and multipart tasks, and reformulation of multiple-choice items leave 501k. Difficulty filtering first uses sampled Mistral Large 2 solutions, then trains a 24B RL checkpoint as a stronger grader. That grader produces 16 responses per original problem; easy, persistently unsolved, and reference-disagreement cases are removed, leaving 38k items.

The 35k code pool is assembled from contest data gathered from unspecified sources. Problems without solutions or enough tests are removed. Candidate solutions are executed on available tests; low-agreement tests are discarded, tests on which no solution succeeds are revised to the modal output, and missing tests may be generated and checked through the same process. Applicable statements are duplicated to request Python or C++ solutions. During RL, C++ code is compiled with C++20 and a ten-second compile timeout, then run on 20 randomly selected tests shared across the response group, with four seconds and 300 MB per test.

Formatting is a gate: one paired reasoning tag block is required; math must place its final expression in a box and code must use a language-labelled Markdown block. A valid format earns 0.1, and a correct final answer adds 0.9. A soft penalty applies near the completion limit. To reduce language switching, 10% of English problems are translated into French, Spanish, Italian, German, Chinese, and Russian; after LaTeX and code removal, fastText classifies the problem, reasoning, and answer and adds a reward when all three languages match.

The online system keeps trainers, generators, and verifiers active asynchronously. Finished sequences are routed to data-parallel ranks, queue size bounds off-policy lag, and in-flight generations continue with an older key-value cache when weights refresh. Modified GRPO removes KL regularization, normalizes token loss and minibatch advantages, raises the upper clip bound to 0.26-0.28, and removes all-correct or all-wrong groups. For Small, correct later Medium traces and Medium generations on selected OpenThoughts and OpenR1-code prompts are mixed with 10% general instruction data; four epochs of SFT precede RL with 2048 sequences per batch, temperature 1.0, and a 32k non-penalized length limit.
