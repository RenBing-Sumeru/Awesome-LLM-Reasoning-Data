The ACL 2026 version of OlymMATH contains 350 problems, each with parallel Chinese and English versions across four mathematical domains. OlymMATH-EASY/HARD includes 200 computational problems with rule-checkable numeric answers, and OlymMATH-LEAN contains 150 Lean 4 formalized tasks checked by the kernel. The project also releases 582,400 reasoning trajectories from 28 models, expert solutions, and visualization tools. The early arXiv version had only 200 natural-language problems; the final version is expanded.
