The paper's data-level novelty is where privileged information enters the pipeline and how it is removed or transformed before deployment.

- Behavior cloning imitates an optimal path directly; SoS imitates symbolic search traces; ReST filters successful policy samples; sparse-reward PPO updates the policy from terminal outcomes. Guided-ReST instead uses the optimal path to choose and edit a recovery point inside a failed self-search, then distills the completed trace.
- Countdown defines an explicit node-level transformation: replace one explored child operation and resulting state with the next optimal subgoal, truncate the inconsistent suffix, and resample. The retained trace contains both failed policy context and a localized oracle intervention.
- Code repair introduces an episode-level analogue when subgoals are difficult to define. The reference program guides generation inside feedback, but the trainable view substitutes a dummy marker and applies loss only to the final response. The privileged field therefore changes the sampled target without remaining as the real program in the learner input.
- Guidance is applied at successive failure points rather than as a single demonstration or one-round strong-teacher continuation. This repeated guide-policy interaction is the main difference the authors draw from the closest guide-model data-generation work.
- Guided-ReST SFT and operation-level PPO are separate components. Action grouping and the dense-reward negative result matter for downstream optimization, but they do not change the provenance or masking contract of the SFT records.

What is not new in isolation includes self-training, outcome filtering, tree-search traces, execution feedback, PPO, and teacher-student distillation. The direction signal for reasoning-data research is the three-view contract: a privileged construction view, an edited or masked training view, and an unassisted inference view. Reuse requires preserving the transformation and intervention provenance, not collapsing both tasks into a generic `teacher-generated` label.
