The main contribution is an RL-oriented acceptance contract for mathematical data rather than a generic pre-training corpus. The current Big-Math-RL-Verified release contains 251,122 problems, including 47,010 Big-Math-Reformulated items. Records contain problem, answer, source, domain, and a solve rate estimated from 64 Llama-3.1-8B rollouts. Ten sources are represented, the files are released as Parquet under Apache-2.0, and access requires accepting the repository conditions. The artifact is a pool of verifiable prompts, not a set of verified full reasoning traces.
