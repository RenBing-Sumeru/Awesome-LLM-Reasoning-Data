For a system that must rank many answers with a fixed pairwise rubric, use judge probabilities as PoE inputs, query high-reordering pairs first, and return both a ranking and uncertainty. Validate success with rank correlation and calibration against a human-held-out subset at the intended budget. It is useful for comparison-budget planning and for flagging unstable rank regions. Do not use it as a drop-in correctness verifier when the task lacks a meaningful pairwise preference signal, or when posterior calibration cannot be checked.
