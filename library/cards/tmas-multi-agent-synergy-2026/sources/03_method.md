For each problem and iteration, a solution agent produces N trajectories in parallel. A verification agent performs M independent checks on each trajectory, returning analytical feedback and scores. A summary agent condenses those checks into a rollout-level record. The experience and guideline agents then update their separate banks from the collection of rollout-summary pairs, and both banks condition the next iteration.

The solution policy uses an exploration coefficient: one branch conditions on prior rollouts and experience for refinement, while another follows the guideline bank to seek non-redundant routes. Hybrid-RL adds incentives beyond final correctness for useful experience consumption and novel strategy exploration. Evaluation reports iterative scaling on reasoning benchmarks, and the official repository supplies code and data for checking the agent prompts, memory updates, and budget configuration.
