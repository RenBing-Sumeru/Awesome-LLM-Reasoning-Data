Prior parallel scaling often aggregates completed answers, and prior memory methods can accumulate trajectory history without a clear retention policy. TMAS changes the reusable object into two explicit memory layers: local verified signals are separated from global strategic coverage. It also makes role-specialization and cross-iteration communication part of the inference allocation mechanism rather than an informal prompt recipe.

The novel claim is not that more agents universally improve reasoning. It is that selective memory and an exploration-exploitation split let multiple agents use a larger budget more coherently. The key audit questions are whether the verifier genuinely filters errors, whether the banks avoid propagating stale conclusions, and whether the reported gain survives equalized context and call budgets.
