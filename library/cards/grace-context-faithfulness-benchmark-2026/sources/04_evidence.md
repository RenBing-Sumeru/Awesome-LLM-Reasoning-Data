GRACE evaluates proprietary, open-weight, and GRACE-fine-tuned models on one test set using both Step F1 and error-category F1. The strongest Gemini-3.1-Pro reaches 81.46 Step F1 but only 72.08 category F1, showing that detecting unfaithfulness is easier than diagnosing its type. Small models fine-tuned on GRACE-train approach larger models, and adding step-faithfulness rewards to RL improves both task accuracy and reasoning reliability. When split by track, grounding and inference errors have different difficulty, so aggregate F1 cannot replace category-level reporting. Category confusion matrices further show frequent confusion between evidence-extraction and deductive errors. The main experiment supports GRACE supervision for contextual-faithfulness classification and rewards in this setup, but not reliability on open-web, visual, or tool trajectories. The two evaluation tracks must be reported separately.
