The useful reading lens is “calibrate before allocating,” not “self-consistency is a verifier.” Check how confidence targets are produced, whether the calibration set overlaps the evaluation distribution, and whether sample savings include all auxiliary computation. Plot accuracy against both mean and high-percentile sample count. If a result is reported only at a nominal N without the realized per-query allocation, it does not establish that adaptive inference is more efficient; it establishes only that the final aggregate score changed.
