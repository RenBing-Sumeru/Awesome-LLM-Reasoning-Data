Prior pruning methods generally use a confidence scalar or a hand-written stopping rule. ZIP-RC changes the information available to inference: each prefix carries an in-model joint forecast of both outcome quality and remaining cost, allowing the controller to value branching, early finishers, and pruning in one common utility. The prediction consumes no additional model forward pass because it is encoded in otherwise reserved logits.

The paper does not claim that a frozen base model magically acquires introspection. It trains an auxiliary prediction target and relies on a learned verifier to form rollout labels. The new reusable object is therefore the reward–length prediction grid plus the policy that consumes it. Reuse should check whether reserved tokens are truly unused, whether the verifier labels match the deployment objective, and whether the chosen utility weights reflect actual parallel hardware cost.
