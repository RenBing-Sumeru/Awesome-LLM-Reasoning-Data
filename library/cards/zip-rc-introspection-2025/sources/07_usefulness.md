Use this work when an inference system already runs parallel candidates but wants to avoid an external verifier pass at every token or completed trace. The reusable design is to train an in-model signal that predicts both outcome and remaining work, retain a traceable utility function, and compare quality, FLOPs, and sequential latency under matched budgets. The official repository includes an end-to-end smoke test and pipeline documentation. Before production use, calibrate the reward–length grid on the deployed model, fix the resource coefficients with measured hardware data, and log why every prefix was expanded or pruned.
