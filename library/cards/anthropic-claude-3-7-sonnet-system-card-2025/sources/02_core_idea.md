The most concrete disclosed data construction concerns appropriate harmlessness. Anthropic generated prompts with different harmfulness levels and multiple Claude responses, then scored candidates with refusal, policy-violation, and helpfulness classifiers. If any response violated policy, the less violating response was preferred; if neither did, the more helpful and less refusing response was preferred. This defines a pairwise feedback contract, but not its scale, classifier implementation, policy version, thresholds, tie handling, or record schema.

Extended thinking is a second data object at the interface: a thinking block precedes the final answer, and the user selects whether to enable it and how many tokens to allow. The report says this behavior was trained with reinforcement learning, yet it does not disclose the trace sources, reward, rollouts, optimizer, or selection rules. A deployed streaming classifier may encrypt harmful spans, so the visible block is not guaranteed to be a raw or complete training-style trace.
