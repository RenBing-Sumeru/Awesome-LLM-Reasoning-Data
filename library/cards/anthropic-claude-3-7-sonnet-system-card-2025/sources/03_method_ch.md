训练过程仅披露到阶段层级。专有混合包含公开互联网信息、非公开第三方数据、标注服务与付费承包商数据，以及内部生成数据。公开互联网数据覆盖至 2024-11，知识截止时间则为 2024-10 月底；清洗包括去重和分类。Anthropic 表示 Claude 3 系列未使用 Claude 用户或客户提交的提示与输出进行训练。来源清单、数量、混合权重、过滤配置和来源级权利均未公布。

后训练包含人类反馈和强化学习中的 Constitutional AI。适当无害性流水线通过分类器构造成对回答偏好；扩展思维也经强化学习训练，但其奖励合同和优化过程未知。必须把这些训练组件与两类机制分开：一类是部署中分析思维标签、加密被标记有害内容的流式补全分类器；另一类是仅用于评测的分类器或模型裁判。

评测协议并不统一。无害性研究把来自偏好数据源集合的提示与另行整理的分布外提示相比较，并在扩展模式使用 8,192 个思维令牌。其他 RSP 研究还使用工具、智能体脚手架、迭代提示优化、仅有用快照、Best-of-N 或 Pass@30。官方发布页的高算力 SWE-bench 设置另含并行尝试、拒绝破坏可见测试的补丁及评分模型。这些评测脚手架都不能证明未披露的训练采样协议。
