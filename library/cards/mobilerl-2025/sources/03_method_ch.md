当前 arXiv v2 pipeline 可在概念层按以下流程重建。

1. **Reasoning-free SFT。** AndroidControl training record 被转换为 MobileRL 的 screenshot/XML 与 bounding-box action 格式，再与经过 sanitation 的 human-annotation/model-exploration record 合并。总计 97.9k action step：AndroidControl-Low 21.3k、AndroidControl-High 14.3k、human-origin 62.2k。
2. **Reasoning SFT。** 未披露身份的 off-the-shelf Instruct model 采样 reasoning-action candidate；只有 action 与 expert action 相同的 candidate 被保留。先训练 initial reasoning policy，再迭代产生新 candidate，把其中正确且最优的 explanation 加回数据。最终 23.6k-step corpus 按同一来源分为 7.2k、4.1k、12.2k，训练两个 epoch。
3. **RL task 构造与 split control。** AndroidWorld template 通过替换内容与 initial state 生成任务；与 116 个 test task 在具体内容和初态上相同的 instance 被删除，得到 2,000 个 training task。AndroidLab application 自动生成 candidate，人工核查 feasibility 与相对 138 个 test task 的 non-overlap，得到 1,103 个 training task。这是 exact/manual split defense，不是 semantic 或 pretraining-contamination audit。
4. **Online interaction。** 两阶段 SFT 后的 Qwen2.5-VL-7B-Instruct 或 GLM-4.1V-9B-Base 接收 screenshot 与 compressed XML，输出结构化 GUI action。XML preprocessing 删除 off-screen/redundant node，简化 attribute，合并 text/content description 并保留 bounds。rollout 使用 temperature 1.0、每个 task group 16 个 sample、max new tokens 4,096、最多 50 turn。
5. **Terminal verification。** AndroidWorld 返回 rule-based binary success。AndroidLab 先让多种 medium-capability agent 产生 trace，再由三个 strong proprietary VLM judgment majority-vote；training item 保留 reasoning。若干千条 label 用于微调 GLM-4.1V-9B-Thinking reward model，最终选择在 1,000 条 verified trace 上为 86% 的版本。
6. **Reward transformation 与 selection。** SPA 以 `alpha=1.0` 相对同任务最短成功路径降低较长成功路径的 reward，failure 保持零。group-relative advantage 驱动 GRPO。AdaPR 使用 buffer size 256、`gamma=1.0` 与 `kappa=0.25` 保留 top-advantage trajectory。low-advantage negative 被随机剪除，使 positive-to-negative ratio 不超过 1:2；FCF 对持续全零任务 cooldown 后移除。
7. **Optimization 与 infrastructure。** Verl-based setup 使用 FSDP、learning rate `1e-6`、train/validation batch 256、每 GPU PPO micro-batch 4、一个 PPO epoch、gradient clip 1.0、clip ratio 0.2、KL coefficient 0.001。四台 rollout machine 各有 1 TB RAM；每个 AVD 需要超过 5 GB memory 与 30 GB storage。系统稳定支持最多 256 个 parallel rollout，每个 step 超过 10 分钟，100 个 training step 超过 25 小时。

官方仓库目前提供 AgentRL-based evaluation stack、Docker configuration/image、AndroidLab evaluation code，以及固定并 patch 的 AndroidWorld dependency。训练复现仍缺 SFT corpus/task、teacher manifest、reward model、rollout/replay record、training implementation、AVD/APK version、seed、optimizer state 与 paper-era environment/result manifest。
