- **训练 artifact 不完整。** 官方仓库在已检查 HEAD 下提供 evaluation、AndroidLab 支持、script、Docker config 与 patch，但没有论文 SFT data、3,103 个 RL task、training implementation、AndroidLab reward model/data、replay buffer、failure history 或完整 rollout corpus。Hugging Face artifact 是 model checkpoint，不是 trajectory release。
- **Learned verifier 有误差。** AndroidLab reward model 在 1,000 条 verified trace 上为 86% accuracy，即该 set 上有 14% 误判；没有 confusion matrix、class-conditional rate、adversarial suite 或 independent calibration。proprietary VLM majority label 可能带来 correlated bias。
- **Reward 与 selection 可能被 gaming。** 如果 terminal checker 漏掉 collateral change 或 unsafe action，SPA 会偏好更短的 verifier-satisfying shortcut。AdaPR 放大被判为成功的 episode，negative pruning 与 FCF 则删除低 reward behavior/task；aggregate success 上升时，failure diversity 仍可能下降。
- **不同 backbone 的 best-result scope 不同。** Qwen 从 AndroidWorld/AndroidLab mixed RL 获益，而 MobileRL-9B 的最佳结果只在 AndroidWorld 上做 RL，因为 learned AndroidLab reward 更不可靠。单一 “MobileRL” 分数不对应唯一 task mixture 或 verifier regime。
- **Decontamination 有限。** AndroidWorld 删除具体 task content 与 initial state 同时相同的冲突；AndroidLab 人工检查 test non-overlap。论文没有 semantic/template deduplication、cross-source overlap 或 evaluated-model pretraining contamination analysis。
- **版本敏感。** full-resolution MobileRL-9B 为 80.2%/53.6%，compressed image 为 75.8%/46.8%。evaluation README 预计 deployment、inference engine 与 image compression 会造成 1–2 point 变化；training release 没有完整固定 APK、AVD/OS image、random seed 与 paper-era result manifest。
- **表示限制。** compressed XML 可能漏掉热门复杂 app 的可交互 element，bounding-box grounding 也依赖 accessibility metadata。作者把转向 vision-only interaction 留作 future work。
- **Domain 与 reset 限制。** 由于 login、VM reliability、manual judgment 与 state restoration 困难，论文不测试 out-of-domain public-use app。emulator success 不能证明在 real device、unseen UI、authenticated service 或 irreversible action 上可靠。
- **资源门槛。** 每个 AVD 占用超过 5 GB memory 与 30 GB storage；四台 1-TB CPU machine 只能稳定支持 256 个 parallel rollout。每 step 超过 10 分钟，100 个 training step 超过 25 小时，限制独立复现与 ablation breadth。
- **Privacy 证据只是流程描述。** 论文说明对文本 identifier 做 regex masking，对 face、QR code 与 OCR text 做 visual masking，但没有公布 recall/precision audit、residual sensitive-data sample 或 annotator consent/compensation record。
- **移动端 security 披露不足。** 没有完整 permission、credential、network、prompt-injection、malicious-content、collateral-action 或 data-exfiltration evaluation。emulator isolation 本身不能证明 deployment 安全。
- **Rights 不会自动传递。** code 为 MIT、model card 为 Apache-2.0、manuscript 为 CC BY 4.0；这些许可不能证明未发布 screenshot/XML、human annotation、AndroidControl transformation、generated task、app content、rollout 或 proprietary-VLM label 的 rights。
