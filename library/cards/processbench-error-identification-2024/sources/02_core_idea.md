The contribution is a human-annotated benchmark that turns process-error detection into an index-prediction task over natural model-generated math solutions. The core mechanism is deliberately simple: construct solutions for public math problems, standardize paragraph-level step segmentation, ask doctoral-level math experts to locate the earliest error, and score evaluated systems by whether they return the same index.

The data object is not a preference pair or a free-form critique. It is a problem plus a segmented solution and an earliest-error label. PRMs are adapted by converting step correctness scores into the first predicted erroneous step; general LMs are adapted as critic models by prompting them to inspect the solution and output the earliest-error paragraph index. The feedback contract remains the human expert label, not a learned judge.

Closest comparisons are PRM800K, MathCheck, and CriticBench. ProcessBench changes the evaluation target by using competition- and Olympiad-level problems, twelve solution generators, and expert earliest-error annotations across 3,400 test cases. The direction label is process-supervision evaluation: useful for auditing reward models and critic scaffolds, but risky to reuse as training data unless split, contamination, license, and prompt/evaluator settings are pinned.
