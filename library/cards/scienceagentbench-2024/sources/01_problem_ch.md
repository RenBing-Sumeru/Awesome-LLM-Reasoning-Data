ScienceAgentBench: Toward Rigorous Assessment of Language Agents for Data-Driven Scientific Discovery 定义了 scientific-agents, code-executable-benchmark 的评测面：模型输出或智能体轨迹必须满足任务特定的反馈契约。主来源与产物是 paper: https://arxiv.org/abs/2410.05080; venue: https://openreview.net/forum?id=6z4YKr0GK6; openreview: https://openreview.net/forum?id=6z4YKr0GK6; project: https://osu-nlp-group.github.io/ScienceAgentBench/; code: https://github.com/OSU-NLP-Group/ScienceAgentBench; data: https://huggingface.co/datasets/osunlp/ScienceAgentBench; huggingface: https://huggingface.co/datasets/osunlp/ScienceAgentBench; doi: https://doi.org/10.48550/arXiv.2410.05080；本地元数据记录的年份/来源为 2024 / ICLR 2025 / arXiv。

收录边界是 benchmarks_evaluation_surfaces，来源角色为 benchmark，验证契约为程序化。一个评测实例 里包含：官方记录 expose scientific task inputs, optional expert knowledge, generated self-contained Python programs, execution artifacts, 评测 logs, costs, and rubric/程序化 scores。除非官方产物另有训练数据说明，否则这张卡把它视为评测、审计，不是训练配方。它对 atlas 的价值在于把任务对象、输出和验证器/裁判/奖励/环境谓词 绑定起来，而不是只记录抽象能力结论。
