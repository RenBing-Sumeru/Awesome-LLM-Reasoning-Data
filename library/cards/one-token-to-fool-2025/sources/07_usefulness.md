Before using an LLM judge as a reward, run this paper's red-team pattern on your own question/reference/prompt stack: score empty symbols, lead-ins, truncated genuine answers, and correct answers together, then report false-positive and false-negative rates. If empty responses pass, add task-matched incomplete responses as explicit NO examples and retrain or gate the judge. The released Master-RM and 180K JSON set are a starting point for reference-based English judging, not a substitute for a domain-specific verifier or a production RL audit.
