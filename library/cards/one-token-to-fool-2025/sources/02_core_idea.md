The paper treats a generative judge as the attack surface: given a question, reference answer, and candidate response, its YES/NO output becomes reward 1/0. It shows that a content-free “master key”—a punctuation mark or a phrase such as “Thought process:” — can be rewarded despite containing no solution. The defense is deliberately narrow and data-driven. Starting from 160K reference-based reward tuples, the authors regenerate 20K answers with GPT-4o-mini, retain only each first generic sentence, label it NO, and fine-tune Qwen2.5-Instruct 7B and 32B into Master-RMs. The released JSON data contains 179,733 records and the released model can judge question/reference/response triples. This makes the missing-content failure visible in a trainable reward format, but it does not programmatically verify correctness or defend against every adaptive reward hack.
