论文把生成式裁判本身视为攻击面：它读取题目、参考答案和候选回答，其 YES/NO 会直接变成 1/0 奖励。作者发现，冒号等标点或“Thought process:”这类开场语没有解题内容，却可能被判为正确。防御是有意收窄的：在 160K 条参考式奖励元组上，从 GPT-4o-mini 重生成的回答中截取首句开场白，构造 20K 条 NO 负例，再微调 Qwen2.5-Instruct 7B/32B 得到 Master-RM。官方 JSON 数据含 179,733 条记录，发布模型可判断题目—参考答案—回答三元组。它把“缺少实质内容”的漏洞变成可训练信号，但不等于程序化验证，也不能覆盖所有自适应奖励攻击。
